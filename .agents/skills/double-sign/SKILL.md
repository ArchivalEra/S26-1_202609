# 双签：先算后看，能上机器就别手算

独立性 = 信息隔离。重算的子代理**只拿题面，不拿仓库解答**——解答一旦进了它的上下文，
重算就退化成确认。

**验算工具优先级（2026-10-12 升级）**：凡 Octave 能算的，**一律用 Octave 算，不再手算**——
手算既慢又容易在中间步出错，而且「我自己又算了一遍」和「换个方式确认」不是一回事。
手算只留给 Octave 覆盖不到的地方（见下方分工表）。

## 验算分工表（先查表再动手）

| 题面属于 | 用什么验 | 为什么 |
| :--- | :--- | :--- |
| **矩阵**：加减、数乘、乘法、转置、求逆、伴随、行列式、解 $AX=B$／$XB=C$、$f(A)$、$A^k$ | **Octave** | 一条 `inv`／`\`／`det` 就是一次完整独立重算；求逆/解方程另可用 `[N,D]=rat(...)` 取**精确有理数**核对分数 |
| **方程组**：线性方程组、克莱姆法则、解的存在性 | **Octave**（`A\b`、`det`、`rank`、`rref`） | 同上 |
| **进制/编码**：二进制↔十进制、8421BCD、其他进制 | **Octave**（`bin2dec`、`dec2bin`；BCD 每 4 位切组后逐组 `bin2dec`） | 一行一题，比按权展开手算快且不出错 |
| **纯整数算术**：行列式、组合数、大整数、精确分数 | **Python `fractions.Fraction`／`int`**（BigInt） | Octave 是双精度浮点，**$2^{53}$ 以上整数失精**（实测 `2^53+1 == 2^53`）；大整数与精确分数必须走 BigInt |
| **符号恒等式**：$\det$ 含参、$A^k$ 归纳式、$x^2y^2$ 这类代数恒等式 | **Python（数值抽查多组 + 符号推演）** | Octave **未装 symbolic 包**，符号运算不可用；恒等式取多组数值（含 0、负数、大数）代入抽查 |
| **非计算题**：概念、证明结构、物理判据、图文判读 | **独立子代理语义复核**（不适用数值验算） | 这类没有「答案数值」可算，靠另一个脑子独立读一遍 |

> **Octave 的两个硬边界**（实测，别踩）：① 双精度浮点，整数超过 $2^{53}\approx9\times10^{15}$ 就不再精确
> ——大整数一律回 Python BigInt；② `pkg list` 为空、**symbolic 未安装**——符号题不要指望它。

> **现成帮手**：本目录的 `ratfmt.m` 把数值矩阵按精确分数打印（内部走 `rat()` 求有理逼近），
> 求逆/解方程/代数余子式这类含分数的答案用它核对，**不要拿浮点近似比对**。
> 用法：把 `ratfmt.m` 与你的脚本放同一目录，`ratfmt(inv(A))` → `-2  1  0 ; -13/2  3  -1/2 ; -16  7  -1`。

## 执行清单

1. **出题**：主会话从文档里只抽题面（题号 + 原题），连同「**禁止读取仓库任何解析/答案文件**」
   一起交给子代理；明确告诉它**可以用 Octave 验算**（`octave-cli --no-gui -q script.m`）。
2. **重算**：子代理逐题独立解出，**先用 Octave 算一遍**（按分工表选工具），
   只返回**最终答案 + 一行方法 + 所用命令**，不写过程文章。
3. **三方对照**：独立结果 vs 仓库答案 vs 书末参考答案（若覆盖）。三方一致才算过。
   分数题用 `format rat` 或 `[N,D]=rat(...)` 取精确分数比对，**不比浮点近似**。
4. **落笔**：全部一致 → 在文档「完成边界/验算」节写一行
   `双签：<日期>，独立子代理按题面重算 <N> 题全部一致（Octave 复核）`；
   任何不一致 → **只报差异，不改任何答案**，交人（或第三个独立算）裁决后再动笔。

## 主会话自己也要跑一遍 Octave

子代理的双签是**独立第三方**；主会话在落笔前**另用 Octave 复核一遍**（同一批命令，
交叉确认子代理没算错），两道都过才写「双签」行。这一段在提交信息里写明所用命令与版本。

## 别把这些当验算

- 把定理重述一遍再打勾（结论与定理同真同假，验不出东西）；
- 拿浮点近似当精确值（分数题必须回精确有理数）；
- 「我自己又手算了一遍」——同一个人同一套方法，不算独立；要么换工具（Octave/BigInt），要么换人（子代理）。
