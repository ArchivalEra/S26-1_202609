# 双签：先算后看

独立性 = 信息隔离。重算的子代理**只拿题面，不拿仓库解答**——解答一旦进了它的上下文，
重算就退化成确认。精确算术（整数/分数），禁浮点、禁「扫一眼」、禁顺手确认。

## 执行清单

1. **出题**：主会话从文档里只抽题面（题号 + 原题），连同「禁止读取仓库任何解析/答案文件」
   一起交给子代理；允许它用 node/Bash 做精确算术。
2. **重算**：子代理逐题独立解出，只返回**最终答案 + 一行方法**，不写过程文章。
3. **三方对照**：独立结果 vs 仓库答案 vs 书末参考答案（若覆盖）。三方一致才算过。
4. **落笔**：全部一致 → 在文档「完成边界/验算」节写一行
   `双签：<日期>，独立子代理按题面重算 <N> 题全部一致`；
   任何不一致 → **只报差异，不改任何答案**，交人（或第三个独立算）裁决后再动笔。
