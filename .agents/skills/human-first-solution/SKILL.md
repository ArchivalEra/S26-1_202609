# 更适合人的解法

「试探 / 凑 / 巧妙看出 / 注意到」= 没写完。停下，先找它背后的**机械做法**，机械做法优先落笔，巧解只作对照；实在只剩巧解，必须写出「怎么想到的」，否则不算解法。

**机械做法长什么样**（判据：一个只会做上一道题的同学，照着能走到同一结果）：

- 找线性关系 → **挑 0 最多的行**消元，不「试」一组系数；
- 定基准行/列 → 由矩阵里**现成的 ±1** 决定，不「观察」哪个好算；
- 展开多项式 → 逐个元素列全，不「合并同类项后直接写出」。

**改写模板**：先说这一步在做什么（一句），再列每一步的依据（法则名），中间量逐个写出。
全文搜「巧妙／显然／容易看出／注意到／试探／凑／一眼」应为 0——查到就按上面的模板重写这一步。

样例：作业1 题 1.2 1(2) 的「找系数」。
