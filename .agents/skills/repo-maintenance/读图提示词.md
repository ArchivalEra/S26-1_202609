# 读图提示词与规程（repo-maintenance 的分册）

只在**有图要读**时打开本文件。主对话每对话读图上限 60 张，这是硬上限。

## 一、主代理的活：生成阅读副本

```bash
python3 .githooks/prepare-photos.py 源目录/ --out /tmp/reading
```

HEIC 无损解码为全分辨率 PNG、非 ASCII 名统一改 ASCII、横版统一转成竖版，**源图不动**。
手机陀螺仪会让竖拍存成横版，所以工具默认做竖屏校正；但**正立与否只能看图才知道**，不要预先假设备注里的角度。

## 二、分批：一个子代理 ≤6 张

派 12 页给一个子代理会直接不返回、整轮作废（实测）。子代理返回文字，主代理只汇总。

## 三、提示词模板（照抄，只替换「只答这几行字」）

```text
只用 Read 工具看图，每张图只打开一次。
禁止 OCR／识别工具，禁止装包，禁止裁剪/放大/增强，禁止写文件。

【先声明】开头列出实际打开的文件清单 + 打不开的。
【倒立就自己转】若某张能看清内容、但版面明显倒立（版头页码在下方），
自己执行：python3 <仓库根>/.githooks/flip-photo.py <该文件>
转完重新 Read 一次即可。这只是纠正方向，不算重复读。
【只答这几行字】<列出具体问题，例：p38 例 2.9 第一次变换的交换下标是几；
p22 编号写"引例"还是"案例"；p6 图中各下标逐字读出>
不要转录整页正文，只回报上面列出的内容。
【看不清就停】内容真的看不清（模糊/反光/遮挡）时写〔看不清〕+原因 + 页码，
继续下一项，不要自救、不要重看。
```

## 四、四条纪律

- **每张图只读一次**（倒立时的转正重读除外）：不重复打开、不换副本、不"再确认"。
- **只问具体几行字**。让子代理抄整页要烧十几倍 token（实测同一批图 20 万 vs 3.3 万）。
- **看不清就报页码重拍**：格式为 文件名 + 原书页码 + 看不清的位置 + 原因。裁剪放大这类自救没有用；
  方向问题则用 `flip-photo.py` 自己解决，不必报重拍。
- **禁 OCR 代替看图、禁图片加工**（含装识别工具、旋转裁剪缩放）。

## 五、登记照片（原件不入库）

- 图片二进制不入库，由拍摄者本地保存。在 `原始资料/index.md` 逐张登记文件名、原书页码、内容、SHA-256；
  **文件名写纯文本、不加链接**（链接会变死链）。
- 登记后逐张核对：登记哈希 = 本地原件。
- 只有文本类原始资料（如转写）才进 `.gitignore` 白名单。
