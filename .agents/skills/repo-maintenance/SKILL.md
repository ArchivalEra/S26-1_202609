# 学期课程仓库维护

`课程/<课名>/` 默认五类：**作业、教材解析、课堂笔记、原始资料、音频**（确无某类的课程在
`.githooks/hook_lib.py` 的 `COURSE_SKIPPED_KINDS` 声明豁免）。动手前读 `维护细则.md`（规程）与
`维护条例.md`（原则），冲突以那两份为准。**判据只有两条：钩子全绿、读者打开网页能用。**

## 一、入库流水线

| 步 | 做什么 | 判据 |
| :--- | :--- | :--- |
| 1 | 原件入库**字节不变**（转写是 UTF-8 HTML 伪装 `.doc`，**别用 catdoc/libreoffice**）→ `原始资料/index.md` 登记：文件名（**纯文本、不加链接**）+ 日期 + 覆盖范围 + SHA-256 | 仓库内 SHA-256 = 本地原件 |
| 2 | 写正文——**过第二节两道闸** | 见 2.1、2.2 |
| 3 | 同批改对应分类 `index.md`（含 `last_updated`） | 索引里找得到该资料 |
| 4 | 新课程：从 `模板/` 复制各类 `index.md` 建目录 + `课程/index.md` 登记 + `.gitignore` 逐文件白名单 + `build.mjs` 的 `TARGET_FILES` **与 `NAV`** | 钩子全绿；**NAV 无校验**，漏了渲染死链，靠人眼 |
| 5 | 收尾五连（§五）+ 提交推送 | 五项全过 |

## 二、内容闸（作业1 与第 1 章攻略就是这么写出来的）

### 2.1 禁止反人类解析

**「试探 / 凑 / 巧妙看出 / 注意到」= 没写完**，必须回落成机械做法：

- 找线性关系 → **挑 0 最多的行消元**；定基准行/列 → **由现成的 ±1 决定，不由位置决定**（例：作业1 题 1.2 1(2)）。
- **提示层不许写试探**：提示的作用是缩小搜索空间，必须给能照着做的步骤。
- 巧解只作对照，且要写清「怎么想到的」；只给巧解不算解法。
- 判据：**读者只拿题面、照你的步骤能做出同样结果**；做不到就是返工。细则见 `human-first-solution` skill。

### 2.2 盲测（入库硬闸）

验算必须是**独立重算**——复述定理、照答案点头、换说法确认，都不算。

1. 主会话**只抽题面**（题号 + 原题）给子代理，明令**禁止读取仓库任何解析/答案文件**——解答进了它的上下文，重算就退化成确认。
2. 子代理逐题独立解出，只回**最终答案 + 一行方法**；精确算术（整数 / `fractions.Fraction`），**禁浮点、禁「扫一眼」**。
3. **三方对照**：独立结果 vs 仓库答案 vs 书末参考答案（若有），全一致才算过。
4. 过 → 文末「完成边界」记一行 `双签：<日期>，独立子代理按题面重算 <N> 题全部一致`；**不过 → 只报差异，一个答案都不改**，交人裁决。
5. 完整版见 `double-sign` skill（「双签」「他证」「校对答案」时必用；新解析/作业入库后主动跑）。

### 2.3 正文体例（照这两份的骨架写，别自创）

- **作业**：每题「提示 → 完整解答 → 复盘」三层折叠（原生 `<details>`，**默认收起**）；开头「怎么用 + 依赖表」；末尾「小结：这份作业真正想教的三件事」+ 完成边界。
- **通关攻略**：前置检查（要什么基础、**不要**什么）→ 知识地图（一条主线串起各节）→ 逐节「**你要会的事** / 最容易错的点 / 过关题」→ 通关自测（**全部独立完成 = 通关**）→ 完成边界。
- **教材解析**（先抄后析）：**一节一个文件**，`教材解析/第NN章-章名/第NN章-<节号>-<节名>.md`；先**原书抄录**（按页码抄印刷正文与原编号），紧跟**解析**（概念、条件、推导、例题解法、易错点、验算）；教材陈述与整理者补充分开标注。
- **通用**：记号要**可点**（符号气泡令牌），不能让人卡在记号上；确定性结论用 `fractions.Fraction` 验算，不照抄书上过程；**矩阵化简箭头的标注由前后矩阵唯一确定**，数值验算通过就直接记，不必标〔待核对〕。
- **每篇文末必须有完成边界**：已抄录／已解析／〔待核对〕／未完成各占哪些，**不夸大**。学生手写答案不是标准答案；教材习题不是教师布置的作业。

## 三、读图：主代理一张都不读

**主代理不看图**——不分"关键点"、不看一眼、不"验证一下"，全部交子代理；一个子代理 **≤6 张**
（派 12 页会直接不返回，整轮作废）。完整规程与**照抄用的提示词模板**在
[读图提示词.md](./读图提示词.md)：读图前先打开它，别自己现编提示词。
照片原件不入库，只在 `原始资料/index.md` 登记文件名（纯文本）、页码、内容与 SHA-256。

## 四、常见故障

- **白名单**：`*` → `!*/` → 逐文件 `!/完整相对路径`，**禁通配符**；先加白名单再 `git add`（漏了本地能过、**CI 必挂**）。
- **提交被拦**：按提示修命名、索引或两处自动区块（README 目录、`维护细则.md` 状态，由钩子从暂存区重算，**不要手改**）；不要 `--no-verify`。
- **断链**：资料增删移后同批改分类 `index.md`；跨课程链接在 `课程/A/课堂笔记/` 里写 `../../B/index.md`。
- `git fsck` 报对象损坏：核对工作区哈希 → 删 `.git/objects/xx/…` → 重新 `git add` → 重跑；别用 `git gc` 掩盖。
