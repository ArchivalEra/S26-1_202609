# 学期课程仓库维护

`课程总览/<课名>/` 四类：作业、教材解析、课堂笔记、原始资料（没有该类的课程在
`.githooks/hook_lib.py` 的 `COURSE_SKIPPED_KINDS` 声明豁免）。原则 `维护条例.md`、规程 `维护细则.md`，
冲突以条例为准。**判据：钩子全绿、网页能读。**

**先选一条线**，照做完；每条线末尾的判据就是完成条件。

## 读图线：教材照片 → 可读的阅读副本（派单前必做）

**派给子代理的必须是 `prepare-photos.py` 产出的副本，不是原件。** 2026-11-06 作业 4 抄题面的
教训：直接 `vips copy in.jxl out.png` 就派单，副本没统一竖屏、文件名也没走 ASCII 约定。

```bash
python3 .githooks/prepare-photos.py <源文件或目录...> [--out /tmp/reading-copies]
```

它做三件事：**统一竖屏**（拍摄一律竖持，手机陀螺仪常把竖拍存成横版）、**无损解码**（HEIC→PNG）、
**ASCII 文件名**（中文名会让子代理误报「分辨率不足」）。源图一律不动，副本不入库、不作证据引用。

副本里版面**明显倒立**时，子代理可自行 `python3 .githooks/flip-photo.py <副本.png>` 转 180° 再读一次
（`--degrees 90/180/270`）——**只允许旋转**：禁止裁剪、放大、增强、换副本重试（这三样是「看不清」，
不是「方向不对」，按看不清处理即可）。读图规程全文见 [读图提示词.md](./读图提示词.md)。

### 读图与写作**必须拆成两段**（2026-11-06 实测）

一个代理同时做「读图 + 写教材解析」会**跑 1–3 小时、磁盘上一个字没有**：
读 6–7 张图本身就把图片预算吃满，写作被挤到后面，代理读完就没力气落盘。
实测四路这样派，跑满 3 小时，`第4章-线性方程组/` 目录都没建出来。

所以拆两段：

1. **读图 → 落盘文本**：代理**只抄不写**，把逐页抄录写进 `/tmp/<课>-<主题>-transcript.md`。
   硬要求：**读完一张立刻追加进文件**，不许攒到最后一次性写（攒着写就是超时 + 全部丢失）。
2. **写作**：另一代理**只读那份文本、不碰图**，写教材页/作业页。一节一个代理。

判据：读完图**磁盘上必须已经有文本文件**；没有就说明第一段没落盘，别派第二段。

## 笔记线：课堂转写 → 课堂笔记

1. `python3 .githooks/extract-transcript.py <源.doc>` → 纯文本 + 元信息（时间戳范围、说话人、手机号命中），**通读一遍再落笔**。
2. 写 `课程总览/<课>/课堂笔记/YYYY-MM-DD-名称.md`，骨架照 `模板/课堂笔记.md`。**两层，物理分开**：
   分隔线以上是**正文**（同学读的）——这节课在干什么 → 行政与考核 → 题号条目（解析 + 这一题在讲什么）
   → 没编号但讲了的知识点 → 本篇没讲的 → 转写与术语；分隔线以下是**校对层**（整理者/复核用）——
   条件备注（按题号索引）→ 双签 → 三签。**不写「待办」节**——资料页零未竟表述，缺什么/待复核都进 GitHub issue（§3.5，open=没补 closed=补了）。
   正文只写两样：**题怎么做**、**老师为什么这么讲**；溯源/时间轴/SHA-256/隐私说明不抄进来（在 `原始资料/index.md`）。
   条件不全时正文只写站得住的链条 + **一行 ⚠**，细节进校对层；题号解析过三道闸（反人类解析 + 双签 + 三签），
   双签在校对层**一次记完**（哪几道条件自足、哪几道不足）；转写把术语读错的，就地标一句 + 收进「转写与术语」。
3. 三处登记，**最小 diff**：`课堂笔记/index.md` 加一行、`原始资料/index.md` 加一行并更新共同说明、`课程总览/<课>/index.md` 改「资料入口」那一格。
4. 白名单加两行（`.md` 与 `.doc`）、`站点/页面清单.mjs` 与 `站点/build.mjs` 的 `NAV` 各加一条。
5. 收尾一条（下下节）→ `git push`。

判据：`update-readme.py --worktree` 绿、构建页数 +1、笔记有「正文 / 校对层」两层分界、页面**零未竟表述**（缺什么已在 issue 里，不在页面上）。

## 作业线：学习通任务 / 习题 → 作业页

1. 题面：截图 → 按 [读图提示词.md](./读图提示词.md) 派子代理**逐字抄题干与选项**（只抄题面，不让它作答）；
   教材照片 → 先过上面的「读图线」再派。文本 → 直接抄。
   **标题取截图的页眉**（平台任务名）**逐字**，别自己另起名字——页眉是「2026-9-23作业」标题就照它写；
   页眉附近的题型字样（「简答题」「客观题」）与题号（教材习题号）写进 frontmatter 的 `sources`（≤30 字）。
   ⚠️ 平台给的**题号清单**（只有「习题 3.2 1-(2)」这种编号、没有题干）**不是题面**：
   去教材照片里找对应页；找不到就不开写，归档 issue（**不猜补**）。
2. **过三道闸**（下节），拿到双签行与三签行。
3. 写 `课程总览/<课>/作业/YYYY-MM-DD-名称.md`，骨架照 `课程总览/工程数学/作业/作业3.md`：
   **依赖（第一节）** → 逐题「提示／完整解答／复盘」折叠（默认收起）→ 完成边界
   （≤150 字，只写 `已解析`／`已验证`／`已知限制` 各一句；**不写「来源与口径」一栏**——出处在
   frontmatter 的 `sources` 气泡里；缺什么进 issue，不写页面上）。
   **完整解答必须自足**（2026-11-06 站长定案）：每道题的完整做法写在本页，技术页/教材解析只作
   「已收录」旁注，**不许接管步骤**——「照…条目走」「完整演算见…」「详见…」这类句子是硬错，
   `站点/plugins/solution-selfcontained.test.mjs` 会报红。
4. 登记同笔记线第 3、4 步（`作业/index.md`、`原始资料/index.md`、课程 index、白名单、页面清单/NAV）。

判据：双签 N/N 全一致、三签行已写、解答自足闸绿、钩子全绿。

## 课程线：新增一门课

从 `模板/` 复制四类 `index.md` 建 `课程总览/<课名>/`，`课程总览/index.md` 登记，白名单四条，
`站点/页面清单.mjs` 与 `站点/build.mjs` 的 `NAV` 各加一节。判据：钩子全绿、站点侧栏出现新课（**NAV 没有钩子校验，人眼核一眼**）。

## 三道闸（解析／作业／攻略必须过；课堂笔记不受限）

顺序固定：**反人类解析 → 双签 → 三签**（答案没对就谈依赖没意义）。每道闸的判据、
工具分工、子代理话术都在各自的 skill 里，这里只留路由：

- **反人类解析**（`human-first-solution`）：「试探／凑／巧妙看出／注意到」= 没写完。
- **盲测双签**（`double-sign`）：子代理只拿题面重算，**只报差异不改答案**；验算工具查它的分工表（Octave 优先、BigInt 兜底）。
- **三签**（`triple-sign`）：双签过后，另一个子代理只拿题面 + 依赖试做；**可直接改锚点与步骤**，数值仍归双签。

**双签/三签的子代理调度纪律**（2026-11-06 站长定案）：
- **一篇一代理**。一次吞多篇/多题会让代理在互相之间稀释注意力、读成一片——实测踩过三次。
  同理，**读图也一人最多 6 张**。
- **一次可并行三路**（站长 11-06 明确许可），但**每路仍是一篇/一张**。
- 抽给盲测的「题面」**必须真的只有题面**：解答层的话（「见解答」「与简报同口径」）混进去会松动隔离。
- 抽给三签的「依赖」**必须包含依赖表指向的段落 + 依赖节里的裸正文**：裸正文不在任何锚点后面，
  漏抽会让盲做缺语义桥梁（11-02 实测：依赖缺「低电平有效/同步异步」导致答案差一档）。

教材解析另外三件事：**先抄后析**（原书抄录紧跟解析）、**一节一个文件**、数值验算照
`double-sign` 分工表。样板见 `课程总览/工程数学/教材解析/第一部分-线性代数/`；
学生手写答案是草稿，不是标准答案。

## 收尾一条（复制即用，一次跑完六项）

```bash
python3 .githooks/update-readme.py --worktree && python3 .githooks/test-update-readme.py \
  && python3 .githooks/check-markdown.py && (cd 站点 && node build.mjs) \
  && git fsck --no-progress && git diff --check
```

改过 `课程总览/` 或 `站点/` → 同轮更新 `.zcode/handoff.md`（pre-commit 强制）。
提交被拦就按提示修命名、索引或两处 AUTO 区块（那两个区块由钩子从暂存区重算，交给它写）。
**提交即止，不推送**——推送由站长发话。

## 卡住时

- **白名单**：`.gitignore` 逐文件 `!/完整相对路径`；先加白名单再 `git add`（漏了本地能过、CI 必挂）。
- **跨课程链接**：在 `课程总览/A/课堂笔记/` 里写 `../../B/index.md`。
- **闸门报红先判「是不是我改出来的」**：`站点/plugins/solution-selfcontained.test.mjs`、
  `站点/plugins/symbol-coverage.test.mjs` 都是对**真实产物**的断言——报红是内容坏了，不是闸门坏了；
  历史遗留的坏内容按「不猜补」归档 issue，**不许改口径让闸门闭嘴**。

## 性能纪律（入库预算：2–3 分钟、**约 6 次工具调用**）

一次入库就六步：①提取转写 → ②通读 → ③写正文 → ④登记（4 个文件**一批改完**）→ ⑤收尾一条 → ⑥推送。
调用数明显超出，就是哪里在重来一遍。

- **同一会话已挂过本 skill → 不重复挂**（正文不会变，每次重挂约 2k token 纯属浪费）；每个新会话的第一条内容任务照常先挂。
- **转写用第 1 步的脚本提取**，随手重写 python 解析是浪费。
- **照片用 `prepare-photos.py` 统一处理**，不要自己拼 `vips` 命令——竖屏校正与 ASCII 命名都在里面。
- **索引最小 diff**：只加行，不整篇重写，也不先通读（新写的内容本就在上下文里）；`last_updated` 是推导字段，pre-commit 按各文件自己的提交日期自动写，不手抄。
- **handoff 最小更新**：§1 该课那一行 + §6 该课小节追加 2–4 行 + §9 加一行。
- **推送即结束，禁止等 CI**（2026-09-24 用户定案）：本地构建与 CI 等效（同一个 `node build.mjs`、同一套钩子），
  所以 `git push` 就是终点——不 `sleep`、不轮询、不为「看 CI 绿不绿」多花一分钟；线上页面只在改动 `站点/`
  或用户要看时抓。只有部署步骤本身报错（如密钥被拒）时才偶尔看一眼运行状态。
- 读图规程（含照抄用的提示词模板、照片登记）在 [读图提示词.md](./读图提示词.md)，有图才打开。
