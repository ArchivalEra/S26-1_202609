# 学期课程仓库维护

仓库以中文课程名为主分类，每门课五个固定类别：作业、教材解析、课堂笔记、原始资料、音频。**动手前读 `维护细则.md`（操作规程）与 `维护条例.md`（原则）**，冲突以那两份为准。

## 读图：主代理一张都不读

主对话每对话最多 60 张图片，这是硬上限。**主代理不碰 Read 看图，一张都不看**——不分"关键点"、不分"看一眼"、不分"验证一下"。全部交子代理，主对话预算全程留空。

1. 主代理跑 `python3 .githooks/prepare-photos.py 源目录/ --out /tmp/reading` 生成阅读副本（HEIC 转全分辨率 PNG，源图不动）。
2. **副本文件名先改成 ASCII**（`p38.png`、`page1.jpg`）：中文名会让子代理读不出图，实测两个子代理因此误报"分辨率不足"。
3. 一个子代理读 **≤6 张**，提示词照下面模板。分批要小：派 12 页给一个子代理会直接不返回，整轮作废（实测）。
4. 子代理返回文字，主代理只汇总。全都读不了时，报页码给用户重拍。

提示词模板：

```text
只用 Read 工具看图，每张图只打开一次。
禁止 OCR／识别工具，禁止装包，禁止加工图片（旋转裁剪缩放增强），禁止写文件。

【先声明】开头列出实际打开的文件清单 + 打不开的。
【只答这几行字】<列出具体问题，例：p38 例 2.9 第一次变换的交换下标是几；
p22 编号写"引例"还是"案例"；p6 图中各下标逐字读出>
不要转录整页正文，只回报上面列出的内容。
读不清写〔看不清〕+原因，继续下一项，不要自救、不要重看。
```

- **每张图只读一次**：不重复打开、不换副本、不"再确认"。
- **只问具体几行字**。让子代理抄整页要烧十几倍 token（实测 20 万 vs 3.3 万，同一批图）。
- **读不清就报页码重拍**，格式：文件名 + 原书页码 + 看不清的位置 + 原因。放大裁剪这类自救没有用。
- 单张正常约 1 万 token，远超说明提示词写成了抄整页。

## 登记照片（原件不入库）

- 图片二进制不入库，由拍摄者本地保存。在 `原始资料/index.md` 逐张登记文件名、原书页码、内容、SHA-256；**文件名写纯文本、不加链接**（链接会变死链）。
- 登记后逐张核对：登记哈希 = 本地原件。
- 只有文本类原始资料（如转写）才进 `.gitignore` 白名单。

## 写教材解析（先抄后析）

- **一节一个文件**：`教材解析/第NN章-章名/第NN章-<节号>-<节名>.md`。
- 文件内先**原书抄录**（按页码抄印刷正文与原编号），紧跟**解析**（概念、条件、推导、例题解法、易错点）。教材陈述与整理者补充分开标注。
- **独立验算**：用 `fractions.Fraction` 精确算术把例题习题重算一遍，不照抄书上手写过程；差异写进解析。
- **矩阵化简箭头的标注由前后矩阵唯一确定**：数值验算通过了就按数值记录，不必标〔待核对〕。
- 文末写「本节完成边界」：已抄录／已解析／〔待核对〕／未完成，不夸大。
- 学生手写答案不是标准答案；教材习题不是教师布置的作业。

## 新增课程

建 `课程/<课名>/` 与五类子目录，从 `模板/` 复制各类 `index.md`，在 `课程/index.md` 登记，逐文件加白名单。两处自动区块会自己反映新课，不必改 README 或钩子。

## 收尾固定动作

```bash
python3 .githooks/update-readme.py --worktree   # 同步两处自动区块
python3 .githooks/check-markdown.py             # 错误必须为 0
python3 .githooks/test-update-readme.py         # 必须全绿
git fsck --no-progress                          # 不应有输出
git diff --check
```

README 的课程目录与 `维护细则.md` 的状态区块由钩子从暂存内容重算，**不要手改这两块内部**。

## 常见故障

- `git fsck` 报对象损坏：确认工作区文件哈希无误 → 删 `.git/objects/xx/…` → 重新 `git add` → 重跑 fsck。不要用 `git gc` 掩盖。
- 提交被拦：按提示修命名、索引链接或自动区块。不要 `--no-verify`（推送端仍会拦）。
- 断链：新增／移动／删除资料后，同步更新对应类别的 `index.md`。
