# 电路原理 2026-10-12：习题册收尾与电路的等效变换

**这节课在干什么**：先用两道题把**习题册第一章的计算题收尾**（受控源求功率，教师带做的第 11、13 题），
再把**第一章整体复习**一遍，然后开始**第二章「电路的等效变换」**：讲**二端网络**与**等效的概念**，
并用一道例题演示「两个二端网络端口伏安关系相同即为等效」。

**行政与考核**：讲完两题后**收习题册检查作业**（两个班分开收，交到学委处）；
教师说第一章的题基本讲完，第二章起进入等效变换。本次课还提到「下节课」继续讲电阻等效变换后的内容。

## 题号条目

### 习题册第 11 题（受控电压源求功率）

**解析**：

1. **认元件**：电路里的受控源是**受控电压源**（$5I_1$ 一类），先列 KVL 求出控制量与支路电流。
2. **列 KVL 求 $I_1$**：取**顺时针**绕行方向（与所设电流方向一致更省事），
   沿回路列电压代数和——与绕行同向的项取正、反向取负：
   $5I_1-10I_1-1=0$，得 $I_1=-0.2$ A。
3. **求受控源电压**：由 $I_1$ 算出受控源两端电压为 $-2$ V。
4. **求支路电流 $I_2$**：对另一回路取**逆时针**方向列 KVL：$10I_2-(-2)-50=0$，
   得 $I_2=4.8$ A；再由节点电流关系得受控源支路电流 $I_1+I_2=4.6$ A。
5. **判关联/非关联定功率**：受控源电压与电流方向**相反（非关联）**，
   所以发出功率带负号：$P=-UI=-(-2)\times4.6$ 一类算式，**结果 9.2 W**。

**这一题在讲什么**：受控源题目的固定流程——**先由 KVL/KCL 把控制量与支路量求出来，最后才判关联性乘功率**；
教师借它强调「回路方向可以随便选，但要**先定方向再逐项定正负**」。

### 习题册第 13 题（受控电流源求功率）

**解析**：

1. **认元件**：受控**电流源** $3I$，与支路电流 $I$ 有倍数关系。
2. **节点电流定支路电流**：对节点列 KCL——流入 $3I$、流出 $I$ 与 $2I$，
   即另一支路电流为 $2I$（也可按「从正极流出」设为 $-2I$，**两种设法结论一致**，教师说选哪种都行，只是符号方向问题）。
3. **列 KVL 求 $I$**：取顺时针：$10I+10-5I=0$，得 $I=-2$ A。
4. **求受控源电流与电压**：受控源上的电流为 $6$ A（负号按方向取）；
   再对其所在回路列 KVL 求两端电压 $U$：$2\times(-6)+5\times(-10)-U=0$，得 $U=-22$ V。
5. **算功率**：$P=UI$，得 **132 W**。

**这一题在讲什么**：与上一题的**同一套流程**（先控制量 → 再电压电流 → 最后功率）；
教师重复强调**方向与符号的记账**，这是第一章所有计算题的共同动作。

## 没编号但讲了的知识点

### 第二章开篇：电路的等效变换（2.1 与 2.2 开讲）

- **框架**（教师给的章节地图）：**2.1–2.2 等效的概念与电阻等效变换** → **2.3 电源的等效** →
  **2.4 电路的等效分析** → **2.5 无源二端网络的等效**；教师点名**最重要的是 2.3 与 2.4**，
  且「先学会 2.2、2.3，综合电路就好分析」。
- **二端网络**：具有**两个端子**并与外部相连的电路（从电路里取出的任意一部分，
  只看这两个端口内部的关系）。**特点**：从一个端口流入的电流等于从另一端口流出的电流
  （大小相同、方向相反）——所以它自动满足 KCL。
- **有源/无源二端网络**：内部**含电压源或电流源**的称为**有源二端网络**；
  **只有电阻**的称为**无源二端网络**。
- **等效的概念与条件**（本节课重点）：两个二端网络若**端口具有相同的电压电流关系（VCR）**，
  则它们**对外等效**——可以用一个去替代另一个，**对「外电路」而言电路中的任何电压、电流、功率都保持不变**；
  但**内部并不一定等效**。等效变换的**对象是相对外电路而言的**，**目的是简化电路、方便计算**。
- **等效不因内部结构复杂而变**：教师举例——内部 10 个电阻串联等效成一个电阻，只要端口 VCR 相同，
  对外就是同一个东西。
- **例题（书 35–36 页一带）**：对一个含电阻与电源的二端网络，用 **KCL 推出 $I$ 与 $U$ 的关系**、
  再用 **KVL 推出 $I_1$ 与 $U$ 的关系**，两个关系式**恰好相同** → 说明这两个电路**等效**。
  教师提示：这一步的推导后面讲**电源等效**时会正式给出。
- **笔记方法**：教师留了几分钟让大家读 35–36 页，说概念部分「一句话」，重点靠**例题反复理解**。

### 电阻的等效变换（2.2）

- **串联**：电流相同；**等效电阻 = 各电阻之和**；用**分压公式**求各电阻电压
  （记不住就用「总电压 ÷ 总电阻 = 总电流，再乘各部分电阻」）。
- **并联**：**电压相同**；**电阻越并越小**；总电流等于各支路电流之和；
  等效电阻按**倒数相加**（$\dfrac{1}{R}=\dfrac{1}{R_1}+\dfrac{1}{R_2}+\cdots$）。
- **分流公式**（教师建议直接记结论，别每次现推）：总电阻 × 总电流 = 总电压，
  再用总电压除以各支路电阻得各支路电流。
- **求解串并联电路的一般步骤**（教师总结）：① 先求**等效电阻**；
  ② 用**欧姆定律**求总电流；③ 再用**分流/分压公式**算出各电阻上的电流、电压。
- **难点在识别串并联**：复杂图里要**顺着电流流向来画**——从一端流入，把「同一节点」的线并到一起
  （教师强调「很多人不知道这几条线其实是同一个点」），逐层化简；**等效永远是针对「某两个端点」而言的**，
  「不指明两个点，等效没有任何意义」——同一张图问 A-B 和问 A-C，等效结果不同。
