# 电路原理 2026-09-21：开课说明与第 1 章电路的基本概念

**这节课在干什么**（第一次课）：前一半时间讲**这门课怎么考、怎么学**（本课与往届最大的不同是**教考分离**），后一半正式进第 1 章——**1.1 电路的组成与电路模型全部讲完**、1.2 讲了**元件与电路的分类**，最后停在**电流的参考方向**上，下节课接着讲。教师给的三个重点：**参考方向、元件特性、基尔霍夫定律**（第三个本次课只预告）。

**行政与考核**（教师当堂口头说明，**以学院正式文件为准**）

- **教考分离（本学期最大的变化）**：教师原话「我讲课，我跟朱老师讲课，但我俩不出题，出题都是**学院统一抽题**」——讲课的人不命题，所以复习要回到教师划的考点与**习题册**上，不能靠猜重点。
- **作业改为统一习题册**（已发到群文件）：**近 300 道题**、四十多页、按章做了目录，题型是选择、填空、大题；教师原话「**考试的所有的题全部都是这里边，而且都是原题**」。他会**逐题讲**（时间紧就过一遍答案）。收交：**每讲完一章或两章收一次**（次数口径不一致，见校对层）；**必须在国庆节后拿到**——「讲完我就要讲练习册上的题了」。必须**装订成册**，不许一张一张交。
- **成绩构成**：**卷面 50%**（期末笔试）＋**实验成绩 + 考勤 + 平时作业**折算后相加。**硬性挂科线：卷面低于 45 分（含 45）直接挂科，平时分救不回**（教师全篇反复强调；另有「45 分的咱们稍微多加 1 分」一句与之冲突，见校对层「条件备注」）。
  - 折算例子：卷面 80 → 折 40 分，其余各项折 45 → 总评 85；卷面 60 → 折 30，平时 40 多 → 总评七十多。
  - **实验占比**：PPT 原写 15%，教师当堂说改成 20%（未最终确认）。
  - **平时作业**：不交记 60 分；交了通常 80–90 多（有独立思考的更高，抄答案的 80 出头）。
  - **考勤**：全勤 100；请假按次扣分；多次无故缺勤按学院规定**直接不许考试、重修**（具体次数教师说「我忘了」，**不可引用**）。
  - **实验成绩**＝操作 + 报告：操作「来了、做了都满分」；报告「做了、不是完全抄别人的」默认 75–95 或 100；**只来不交报告只有 60 分**。
- **考试安排**：学院**统一考试、统一出卷**（三个班一起考），「一般都是 **18 周**考试」。**缺考即挂**——特殊情况须先向**班主任或辅导员请假**，再告知任课教师并**申请缓考**（教师说这是「极其特殊的事情」）。
- **考试形式**：**只有选择、填空、计算**，**连判断题都没有**，明确**没有简答题**——所以「概念性的东西知道怎么用就可以」。

### 1.1 电路的组成与电路模型

- **电路的定义**：由电气设备与器件按预定目标连接成的**电流通路**（教师随即说「像这种概念，考试不会考」）。
- **组成电路的三个基本部分**（教师反复强调「至少必须要有这三个」，课本第 1 页蓝色字体也写了）：

| 组成部分 | 作用 | 实例 |
| :--- | :--- | :--- |
| **电源** | 提供电能的装置 | 干电池、手机电池、发电机 |
| **负载** | 消耗、使用电能的装置 | 小灯泡、电动机、其他用电设备 |
| **中间环节** | 传输、分配与控制电能 | 导线、开关、保险丝 |

- **两个例子**：**手电筒**（电池 + 灯泡 + 导线与开关，「最简单的电路」）；**远距离输电**（发电机 + 变压器与输电线 + 用户）。
- **电路的作用分两类**：**强电电路**（如电网）主要**传输与分配电能**；**弱电电路**实现**信号传递**（教师举的链路是输入放大 → 高频放大 → 低频放大 → 扬声器；手机、电脑属弱电）。
- 应试要求：**「你实在不理解你就记住」**——能分清哪部分是电源、中间环节、负载即可。

### 1.2 电路元件及模型

**元件的定义**：「具有**某一单一电磁特性**的元件」。本课程常用：**电阻、电感、电容、电压源、电流源**。

| 元件 | 性质 | 符号 | 备注 |
| :--- | :--- | :--- | :--- |
| 电阻元件 | 消耗电能 | **R** | 前四章的主角；「跟我们初中学的电阻一样，是个固定的值」 |
| 电感元件 | — | **L** | 第五章以后才展开 |
| 电容元件 | — | **C** | 符号是「两条平行的、长短一样的线」 |
| 电压源 | 提供电压 | 符号「一个长一个短」 | **与电流源容易混**，注意区分 |
| 电流源 | 可直接提供电流 | — | 同上 |

- **为什么要认符号**：考试不会单独问「这是什么元件」，但做题时「求电感两端的电压或电流，你至少要知道电感是哪一个」。
- **有源／无源**：**无源**＝电阻、电感、电容（「不能够提供电能的」）；**有源**＝电压源、电流源、电池（「提供电能的」）。教师说自己不太习惯这套叫法，介绍它只是「防止大家看到其他课程上会有这么讲」——属通用术语。
- **二端元件**：有两个端口的元件；无源二端＝R、L、C，有源二端＝电压源、电流源。

**理想电路元件与建模**：

- **核心思路**：具有**相同电磁特性**的实际元件，分析时可以用**同一个理想模型**代替。
- **按电磁特性对应模型**：消耗电能 → **电阻**；存储电场能量 → **电容**；存储磁场能量 → **电感**。
- **模型取决于工作条件**（本节最值得记的一条）：

| 工作条件 | 用什么模型替代 |
| :--- | :--- |
| 直流线圈 | 只用**电阻** |
| 低频交流 | **电感 + 电阻** |
| 高频交流 | **电感与电容并联** |

  教师原话：「实际模型当中，要看它的工作条件，才能决定它用什么器件替代」。
- 本课程**不深入建模**，一般只分析电路模型图——「最后我们做的元件都是指理想电路当中的元件」。

### 电路的分类

1. **集总参数电路 / 分布参数电路**（出现频率最高的分类）：
   - **判据**：比较**电路尺寸**与**信号波长**——**波长远远大于尺寸时是集总参数电路**，反之是分布参数电路。
   - **性质差别**：集总参数电路里电压电流**只与时间有关**；分布参数电路里**还与空间坐标有关**。
   - **归属**：低频电路（如电网）多为**集总参数**；**远距离输电**与**微波电路**是典型**分布参数**。
   - **本课程只研究集总参数电路**；教师对本块的要求是「做一个了解就可以」。
2. **线性电路 / 非线性电路**：教师以**二极管**为例说明非线性。
3. **时变电路 / 时不变电路**：时不变即不随时间变化。

> **必须记住的数字**：**我国交流电频率 50 Hz**——教师明确要求记住，说**第五章会用到**。

### 1.2 电路的基本物理量：电流与参考方向

- **三个基本物理量**：**电流、电压、功率**（本次课只讲到电流）。教师点明整门课在做什么：**「我们整个电路当中就是在求电流、求电压、求电功率，有的时候求电阻」**。
- **电流**：**带电离子的定向运动**形成电流；大小（电流强度）＝单位时间内通过截面的电荷量（教师口述为对电荷量做微分，**未念出公式符号**）。符号 **I**，单位**安培**（常用毫安、微安；单位换算教师说「这里就不说了」）。
- **直流与交流（必须记清）**：

| | 定义 | 符号写法 | 出现章节 |
| :--- | :--- | :--- | :--- |
| **直流电** | 大小、方向**不随时间变化** | **大写 I** | 第 1–4 章 |
| **交流电** | 大小、方向**随时间变化** | **小写 i** | 第 5 章起 |

  补充：直流电路中只要**电路结构不变**，各处电流固定；只有结构变化（开关断开、支路接入与否）才改变。
- **电流的实际方向**：**正电荷移动的方向**（国际规定）。
- **为什么要引入参考方向**：**「复杂的电路中电流随时间变化，实际方向很难判断」**——没法用眼睛看出正电荷往哪走。初高中其实也在假定方向（默认「从正极出来回到负极」），只是没有正式提出这个概念。
- **两种表示方法**：① **箭头**（直接在图上画）；② **双下角标** $I_{ab}$（表示电流**从 A 流向 B**）。教材常用箭头或文字说明（顺时针、逆时针），双下角标用得不多。
- **教师举的例子**：简单电路可直接看出电流从正极流出回到负极；但**两条支路汇合成一条线以后，中间那条线的电流方向无法确定**（「可以假设它向下，也可以假设它向上」），所以必须假定参考方向。
- 本次课在「假设电流的参考方向」处结束，**下节课接着讲**。
