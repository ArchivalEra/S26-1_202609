# 电机学符号入门

**这本书自己带了一张「主要符号表」**（在目录之后、正文之前，两页），第一章开头就直接用其中的符号，而且**一个都不解释**——教材默认你已经认识。这一页把第一章会遇到的符号按族整理好，**每个符号在正文里都能点**：点到就出气泡，气泡里是一句话解释。

- 正文里把符号写成 `[tex]{#词条id}` 令牌（如 `[B]{#sym-B}`）即可获得点击气泡；词条在下面围栏里维护，**渲染时围栏被剥掉、不出现在页面上**。围栏每行一个词条，格式 `id | 标题 | 气泡文本`；新增符号族 = 新面板（带 `{#id}`）+ 新词条行，两处 id 必须一致。
- **符号表里只有"是什么"，没有"怎么用"**。要会算，看各节解析；要背，看下面这张速查。
- **下标与上标是本书的语法**，不认它就等于读不懂公式：`1` 是定子侧/一次侧/基波，`2` 是转子侧/二次侧/二次谐波，`N` 是额定，`st` 是起动，`σ`（西格玛）是漏，`*` 是标幺值；上标 `′` 是归算值或瞬态值，`″` 是超瞬态值，`·`（点）是相量。
- **单位必须跟着符号走**（第一章就靠这个分辨物理量）：$B$ 用 T，$\Phi$ 用 Wb，$H$ 用 A/m，$\mu$ 用 H/m，$F$ 与 $U_M$ 用 A，$L$、$M$ 用 H，$e$ 用 V，$T$ 用 N·m。

## 一族一族的记法

:::collapse accordion
- 磁场的三个基本量：B、H、μ :+ {#sym-family-bh}

  **三个量，两句话**：

  - [B]{#sym-B} 是**磁通密度**（也叫磁感应强度），描述"磁有多强"，是矢量；[H]{#sym-H} 是**磁场强度**，也是矢量，描述"外界激励有多强"；两者由 [μ]{#sym-mu} 联系起来：$B=\mu H$。
  - 谁跟介质有关：**$H$ 只看电流（激励）**，$B$ 还要乘上介质的磁导率。所以同一个电流，铁心里的 $B$ 比空气里大几千到上万倍——**这一条在第一章会反复考**（真空、铜、铝的 $\mu$ 都可以当成 $\mu_0$）。

- 磁通与磁链：Φ、Ψ :+ {#sym-family-flux}

  - [Φ]{#sym-Phi} 是**磁通**（穿过某面积的磁感应线根数，标量，Wb）；[Ψ]{#sym-Psi} 是**磁链**（$N$ 匝线圈每匝的磁通加起来，$\Psi=N\Phi$，本质是"磁通乘以匝数"）。
  - 一句话区分：**Φ 是"几根线"，Ψ 是"几根线 × 几圈"**。磁链变化才产生感应电动势，所以电机里论"变化"用 Ψ。

- 磁路三件套：F、U_M、R_m、Λ :+ {#sym-family-circuit}

  - [F]{#sym-F} 是**磁动势**（安匝数 $NI$，单位 A——注意单位不是"安培·匝"）；[U_M]{#sym-UM} 是**磁位差/磁压**（$\int H\,\mathrm dl$，单位也是 A）。
  - [R_m]{#sym-Rm} 是**磁阻** $R_m=l/(\mu S)$；[Λ]{#sym-Lambda} 是**磁导** $\Lambda=1/R_m=\mu S/l$。
  - 与电路一一对应：**磁动势 ↔ 电动势，磁通 ↔ 电流，磁压 ↔ 电压降，磁阻 ↔ 电阻**。第一章的整张类比表在[小结与习题](./第01章-概述/第01章-小结与思考题习题.md)里。

- 电路与机电转换：L、M、e、F_e、T :+ {#sym-family-elec}

  - [L]{#sym-L} 是**电感**（单位电流产生的磁链，$\Lambda N^2$）；[M]{#sym-M} 是**互感**（一个回路的电流在另一个回路里造出的磁链）。
  - [e]{#sym-e} 是**感应电动势**（$e=-\mathrm d\Psi/\mathrm dt$）；[Fe]{#sym-Fe} 是**电磁力**（$F_e=Bli$）；[T]{#sym-T} 是**电磁转矩**（$T=Blir$）。
  - 方向靠三个定则分工：**右手螺旋**（电流→磁场）、**右手定则**（运动→电动势）、**左手定则**（电流＋磁场→受力）。分工表见[第三节解析](./第01章-概述/1.3-电机的电磁基本理论.md)。

- 材料与损耗：Br、Hc、p_Fe :+ {#sym-family-mat}

  - [磁滞回线]{#sym-hysteresis} 的两个交点：[Br]{#sym-Br} **剩磁**（撤掉外磁场后还剩的磁通密度）、[Hc]{#sym-Hc} **矫顽力**（要把磁性消掉所需的反向磁场）。
  - [铁耗]{#sym-pFe} $p_{Fe}=p_h+p_e$：**磁滞损耗 + 涡流损耗**，都发生在铁心里，与频率、磁通密度有关。
  - 记忆钩子：**回线越胖（面积大）磁滞损耗越大；片子越薄、电阻率越高，涡流损耗越小**。

- 储能与下标约定 :+ {#sym-family-misc}

  - [W_m]{#sym-Wm} 是**磁场储能**（能量密度 $w_m=\frac12 BH$，线性介质下 $w_m=\frac{B^2}{2\mu}$）。旋转电机的磁场能量主要存在**气隙**里——第一章特别强调这一点。
  - [下标约定]{#sym-sub} 与 [上标约定]{#sym-prime} 是本书的语法，读公式前先认号。

:::

:::glossary-dict
sym-B | B：磁通密度（磁感应强度） | 描述磁场强弱的矢量，单位 T（特斯拉）。穿过垂直于它的单位面积的磁感应线根数就是它的大小，所以又叫磁通密度。B = μH——与介质有关：同一个电流在铁心里的 B 比空气里大几千倍。
sym-H | H：磁场强度 | 描述磁场"激励"的矢量，单位 A/m。只看电流和几何（长直导线 H = I/(2πr)、螺线管 H = NI/l），与介质无关；介质的影响全部由 B = μH 里的 μ 承担。
sym-mu | μ：磁导率（μ₀、μᵣ） | B = μH 里的比例系数，单位 H/m，由介质决定。真空磁导率 μ₀ = 4π×10⁻⁷ H/m；相对磁导率 μᵣ = μ/μ₀，空气、铜、铝都近似取 1，铁磁材料可达 10²～10⁵ 倍。
sym-Phi | Φ：磁通（磁通量） | 穿过某一面积的磁感应线根数，标量，单位 Wb（韦伯）。均匀磁场且磁感应线与面正交时 Φ = BS；一般情形 Φ = ∫B·cosθ dS。注意它是有向的，进出要相减。
sym-Psi | Ψ：磁链 | 与线圈各匝相链的磁通之和，Ψ = NΦ，单位 Wb（也写 Wb·匝，数值上等于 Wb）。它比 Φ 多带了"匝数"，所以电感和感应电动势都用它来定义。
sym-Rm | R_m：磁阻 | 磁路的"电阻"，R_m = U_M/Φ = l/(μS)，单位 H⁻¹ 或 A/Wb。铁磁材料 μ 大 → 磁阻小；气隙 μ 小 → 磁阻极大，往往占去几乎全部磁动势。
sym-Lambda | Λ：磁导 | 磁阻的倒数，Λ = 1/R_m = μS/l，单位 H 或 Wb/A。用电感表达就是 L = ΛN²——电感与磁导成正比、与匝数平方成正比。
sym-F | F：磁动势 | 激励磁路的"电动势"，等于回路所匝链的安匝数 F = NI，单位 A（不是安匝）。永磁体也可以当磁动势源。
sym-UM | U_M：磁位差（磁压） | 磁场强度沿一段路径的线积分 U_M = ∫H dl，单位 A。闭合磁路的全部磁压之和等于全部磁动势之和，这就是全电流定律。
sym-L | L：电感（自感） | 单位电流在线圈里产生的磁链，L = Ψ/I = ΛN² = N²/R_m，单位 H（亨利）。只与匝数和磁路介质有关，与所加电压、电流、频率无关。
sym-M | M：互感 | 一个回路的电流在另一个回路里造出的磁链与之比，M₂₁ = Ψ₂₁/I₁，单位 H。两个回路的互感相等：M₁₂ = M₂₁。
sym-e | e：感应电动势 | 线圈磁链变化所生的电动势，e = −dΨ/dt（正方向按右手螺旋与磁通一致）。由"磁通本身在变"产生的叫变压器电动势，由"线圈与磁场相对运动"产生的叫速度电动势 e = Blv；方向用右手定则。
sym-Fe | F_e：电磁力 | 磁场对载流导体的作用力，F_e = Bli（B、l、i 三者互相垂直），单位 N。方向用左手定则；乘上到转轴的距离就是转矩。
sym-Br | B_r：剩余磁感应强度（剩磁） | 极限磁滞回线与纵轴（H = 0）的交点，表示撤去外磁场后材料里还剩的磁通密度。剩磁大 → 适合做永磁体。
sym-Hc | H_c：矫顽磁力（矫顽力） | 极限磁滞回线与横轴（B = 0）的交点，表示要把磁通密度降到零所需的反向磁场。H_c 小、回线窄 → 软磁（做铁芯）；H_c 大、回线宽 → 硬磁（做永磁）。
sym-hysteresis | 磁滞回线与磁化曲线 | 反复磁化时上升与下降曲线不重合，围成的封闭曲线叫磁滞回线；充分饱和后最大的一条叫极限磁滞回线。软磁材料工程上用连接各回线顶点的曲线（基本磁化曲线）代表它的 B-H 关系，手册上查的就是这条。
sym-pFe | p_Fe：铁芯损耗（铁耗） | 交变磁化时铁心里的能量损耗，p_Fe = p_h + p_e：磁滞损耗 p_h = k_h·f·V·B_mⁿ（正比于回线面积，n 约 1.5～2）+ 涡流损耗 p_e = k_e·V·f²·τ²·B_m²（正比于频率平方、片厚平方）。工程上按材料的比损耗（W/kg）乘重量算。
sym-Wm | W_m：磁场储能 | 磁场里储存的能量，是能量密度 w_m = ½BH 的体积分，线性介质下 w_m = B²/(2μ)。旋转电机的气隙 μ 小、储能集中，气隙储能的大小直接决定电机能转换多大功率。
sym-sub | 下标约定 | 本书语法：1 = 定子侧／一次侧／基波；2 = 转子侧／二次侧／二次谐波（3、4…类推）；+ / − / 0 = 正序／负序／零序及空载；* = 标幺值；a = 电枢；d / q = 直轴／交轴；f / m = 直流／交流励磁；k = 短路、换向极；N = 额定；st = 起动；av = 平均；v = v 次谐波；σ = 漏；max / min = 最大／最小。
sym-prime | 上标约定 | ′ = 归算值或瞬态值；″ = 超瞬态值；·（点）= 相量（矢量）值。读带撇的公式前先确认它是"归算过来"还是"瞬态"。
:::
