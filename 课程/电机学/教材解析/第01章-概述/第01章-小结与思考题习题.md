## 原书抄录

### 小结（第 17 页）

本章介绍了有关磁场、磁路的基本概念，磁路的基本定律和电机电磁基本关系。

（1）工程上常将磁场化为磁路来处理，所谓等效磁路或磁路的模拟电路均是求解磁路的有效而简单的方法。电路和磁路的类比见表 1-2。

〔表 1-2 电路和磁路的类比〕

| 电　路 | 磁　路 |
| :--- | :--- |
| 电动势 $E$（V） | 磁动势 $IN$ 或 $F$（A） |
| 电流 $I$（A） | 磁通 $\Phi$（Wb） |
| 电阻 $R=\rho\dfrac{l}{S}$（$\Omega$） | 磁阻 $R_m=\dfrac{l}{\mu S}$（$\mathrm{H^{-1}}$） |
| 电导 $G=\dfrac{1}{R}$（S） | 磁导 $\Lambda=\dfrac{1}{R_m}$（H） |
| 电路〔图〕 | 等效磁路〔图〕 |
| 欧姆定律 $U=IR$ | 欧姆定律 $F=\Phi R_m$ |
| 节点 $\Sigma I=0$ | 节点 $\Sigma\Phi=0$ |
| 回路 $\Sigma E=\Sigma U$ | 回路 $\Sigma F=\Sigma U_m$ |
| 场强 $\oint E\,\mathrm{d}l=U$ | 场强 $\oint H\,\mathrm{d}l=IN$ |
| 电流密度 $j=\dfrac{I}{S}$（A/m²） | 磁通密度 $B=\dfrac{\Phi}{S}$（T） |
| 电导率 $\sigma=\dfrac{j}{E}$（S/m） | 磁导率 $\mu=\dfrac{B}{H}$（H/m） |

磁路与电路有可类比之处，可以帮助学习了解磁路的基本概念和分析方法，但是它们的本质是不同的，在分析计算时应注意。

（2）铁磁材料的磁导率为非线性的，它是 $B$ 的函数。因此，在求解磁路时应与解非线性电路一样处理。在定量计算时，我们并不计算磁路的磁阻（或磁导），而是用 $B\text{-}H$ 曲线，由磁通求出磁动势（$\Phi\to B\to H\to F$），而反之由磁动势求磁通，通常用试探法，先假设 $\Phi$ 求出 $F$。
但鉴于铁磁材料的 $\mu$ 可达 $10^3\sim10^5$，而电机中又存在着 $\mu_r=1$ 的空气隙，铁芯部分一般只需耗所需总磁动势的百分之几到百分之十几。换句话说，铁芯部分所需磁动势的计算即使不太精确，也不会给整个磁路计算带来明显影响，甚至在估算时干脆略去其影响，只计算空气隙所需磁动势，这就大大简化了计算过程。

（3）电感是沟通电、磁关系的一个重要参量，电磁感应定律也可由电感来表达，即

$$e=-\frac{\mathrm{d}\Psi}{\mathrm{d}t}=-\frac{\mathrm{d}\Psi}{\mathrm{d}i}\frac{\mathrm{d}i}{\mathrm{d}t}=-L\frac{\mathrm{d}i}{\mathrm{d}t}$$

电机学中常常把某些感应电动势用电抗电压降来处理，这样做易于建立电机的数学模型。于是，针对电机中的各种磁通，引出了相应的各种电抗。电抗是电机分析的一个十分重要的参数。读者在今后的学习中，应给予充分重视。

（4）电机可逆性原理告诉我们，原理上，发电机和电动机是一种电机的两种不同运行方式；实际上，某些电机常称为发电机（或电动机），只说明该类电机作为发电机（或电动机）时有较多优点，而不是说只能用做发电机（或电动机）。

（5）电机学是一门工程性质的课程，因此对电机的材料应有一定的认识，了解电机的电路、磁路构成的主要材料。有些数据还应记忆在心，如常用绝缘材料的级别及其极限允许温度，各种物理量的单位及在电机中这些量值的范围等。

## 解析

### 一、类比表怎么用（表 1-2 的机械用法）

把磁路当电路算，**逐个量替换**即可：

| 电路里的 | 换成磁路里的 | 单位也跟着换 |
| :--- | :--- | :--- |
| 电动势 $E$ | 磁动势 $F=IN$ | V → A |
| 电流 $I$ | 磁通 $\Phi$ | A → Wb |
| 电阻 $R=\rho l/S$ | 磁阻 $R_m=l/(\mu S)$ | Ω → H⁻¹ |
| 电导 $G$ | 磁导 $\Lambda=1/R_m$ | S → H |
| 电压降 $U$ | 磁压 $U_M$ | V → A |
| 欧姆定律 $U=IR$ | $F=\Phi R_m$ | — |
| 节点 $\Sigma I=0$ | $\Sigma\Phi=0$ | — |
| 回路 $\Sigma E=\Sigma U$ | $\Sigma F=\Sigma U_m$ | — |

**用法**：画等效磁路（把每段铁芯、每个气隙各画成一个磁阻）→ 套串并联与基尔霍夫定律 → 求出各段磁通/磁压。教材图 1-8、1-9 就是"实际磁路 → 等效磁路"的示范。

**但教材点名三处"不可类比"**（小结第（1）条后的那句"本质是不同的"），后面各章反复用到：

1. **磁通不是"运动的东西"**：电流是带电粒子的真实运动，磁通只是描述磁现象的手段（铁芯磁化是磁畴转轴）。
2. **磁阻不耗能**：直流电流过电阻发热；恒定磁通过磁阻**不产生任何损耗**，而表示该段**储存能量**。
3. **磁阻非线性**：$\mu$ 是 $B$ 的函数，所以磁路"电阻"会随工作点变——电路大多线性，磁路天生非线性。

### 二、把教材的"试探法"写成机械步骤（本页最要紧的一条）

小结第（2）条与习题 1-2 的提示里，教材都用"试探法"这个词。它的机械做法就是**两点线性插值**（教材提示的后半句已经写出来了），可以照着执行、不需要"感觉"：

**求磁通（已知 $F$ 或 $I$）**：

1. 先取两个试探磁通 $\Phi_1<\Phi_2$（可取上一题结果或按 $B$ 落在 1.0～1.6 T 估）；
2. 对每个 $\Phi_k$ 走一遍正向链：$\Phi_k\to B_k\to$（查表 1-3 或插值）$H_k\to F_k=H_k\cdot l$（有气隙就把气隙段加上）；
3. 得到两点 $(\Phi_1,F_1)$、$(\Phi_2,F_2)$，在**这两点之间按直线插值**求出目标 $F$ 对应的 $\Phi$：

$$\Phi=\Phi_1+(\Phi_2-\Phi_1)\frac{F-F_1}{F_2-F_1}$$

4. 若要求精度更高，用插值结果再取一对更近的点重算一次（教材说"通过几次计算"）。

**查表插值的机械式子**（教材表 1-3 下的注②）：

$$H = H_a+(H_b-H_a)\frac{B-B_a}{B_b-B_a}$$

其中 $B_a<B<B_b$ 是表中相邻两点。**必须写出这两行式子**，不能只写"试出来是……"。

### 三、七道思考题的答法要点（每题抓一句话）

| 题 | 要点（机械记忆） |
| :--- | :--- |
| 1-1 | 材料用**电工钢片（硅钢片）**叠成；主要特征：**磁导率高、电阻率高（含硅 0.8%～4.8%）、片薄且片间绝缘**（降涡流），属**软磁材料**（回线窄、$H_c$ 小、易磁化易退磁） |
| 1-2 | 用处：把**磁路各段所需的磁动势**与激励电流联系起来（$\Sigma U_M=\Sigma F=NI$）；用法：沿闭合主磁路取回路（绕行方向与电流方向按右手螺旋），把每段的 $Hl$ 加起来，等于所匝链的安匝数 |
| 1-3 | 三者依次是**附加条件越来越多**的写法：$\mathrm d\Psi/\mathrm dt$ 最普遍；$N\mathrm d\Phi/\mathrm dt$ 要求**全部匝链**；$L\mathrm di/\mathrm dt$ 还要求**线性介质（$L$ 为常数）** |
| 1-4 | $e=Blv$ 是"磁通不变、**面积（位置）在变**"时的 $-\mathrm d\Phi/\mathrm dt$：把 $\Phi=Blx$（$x$ 为切割扫过的位移）代进去微分即得 |
| 1-5 | 当**电动势的正方向不按右手螺旋与磁通取一致**时写成正号（正方向约定决定符号，不是物理规律变了） |
| 1-6 | 电抗＝电感在正弦交流下的"电压/电流比"（$X_L=\omega L$）；与**匝数平方、磁路磁导、频率**有关；因 $\mu$ 随饱和变，**电抗也随磁路饱和而变**（饱和→$\mu$ 降→电抗降） |
| 1-7 | "不能同时"指的是**能量流向**只能有一个（$e>u$ 还是 $u>e$）；但**两种作用同时存在**：发电机里也有电磁力（叫电磁阻力），电动机里也有感应电动势（叫反电动势） |

### 四、六道习题的下手路线（只给方法，不给答案）

| 题 | 类型 | 机械路线 |
| :--- | :--- | :--- |
| 1-1 | 正向链（求匝数） | $\Phi\to B=\Phi/S$（$S$ 由直径算）→ 查表 1-3（或用注②插值）得 $H$ → 铁环平均周长 $l=2\pi r$ → $F=Hl$ → $N=F/I$。**单位**：表里 $H$ 是 A/cm |
| 1-2 | 反向链（已知 $F$ 求 $\Phi$） | 加气隙后磁路分两段：铁芯段＋气隙段（$\mu_0$，$R_m$ 极大）。第（1）问仍走正向链（$\Phi$ 已知）但**两段磁动势相加**再除 $I$；第（2）问是标准的**两点插值**（见上节机械步骤），或先按"只算气隙"估再修正 |
| 1-3 | 旋转线框的**速度电动势** | $e=-N\mathrm d\Phi/\mathrm dt$，其中 $\Phi=BS\cos\theta$、$\theta=\omega t$（$\omega=2\pi n/60$）→ 微分得正弦式；最大值 $E_m=NB S\omega$，出现在**线圈平面与 $B$ 平行**时（穿过面积为零、变化率最大）；有效值 $E_m/\sqrt2$。$S=a\times b$ |
| 1-4 | 交变磁场里的**变压器电动势** | 线圈不动：$\Phi=\Phi_m\sin\omega t$（$\Phi_m=B_mS$），$e=-N\mathrm d\Phi/\mathrm dt$；与磁力线成 60° 时，穿过的磁通乘 $\cos 60°$（**有效面积**变化），幅值乘 $\cos60°=\tfrac12$；第（3）问把"旋转"与"交变"叠加，注意**磁通最大时刻**对应 $\theta$ 的位置 |
| 1-5 | 受力与转矩 | 用 $F_e=Bli$（$B$、$l$、$i$ 互相垂直），**逐边判断**哪些边受力（与磁力线平行的边受力为零）；$T=Blir$（$r$ 为边到转轴的距离，本题转轴在**长边中点连线上**）；第（2）问写出 $T(\theta)$ 的表达式 |
| 1-6 | 电感 | $L=N^2/R_m$，$R_m=l/(\mu S)$，$\mu=\mu_r\mu_0$；$l=2\pi r$（平均半径），$S=20\mathrm{mm}\times20\mathrm{mm}$。**注意** $\mu_r=100$ 是非铁磁量级，题里给定，直接用 |

### 五、本章知识地图（一条主线）

$$\text{磁场 }\xrightarrow{\text{简化为}}\text{ 磁路 }\xrightarrow{\text{等效电路化}}\text{ 磁路定律 }\xrightarrow{\text{三种电磁关系}}\text{ 电感、电动势、电磁力 }\xrightarrow{\text{材料与损耗}}\text{ 可设计、可估算的电机}$$

- **主线一句话**：第一章把"电—磁—机"的**共同语言**立起来：磁路（含磁路定律）+ 三个基本电磁关系（电感、电磁感应、电磁力/转矩）+ 材料与损耗（铁耗、绝缘等级）。后面变压器、异步、同步、直流四篇，都是在具体结构上重复这四个工具。
