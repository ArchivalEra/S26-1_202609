## 3. 单选题（第 1–12 题）

### 第 1 题

铁、钴、镍及其合金的相对磁导率（　）真空磁导率。A 远大于　B 略小于　C 略大于　D 等于

:::collapse accordion
- 提示：相对磁导率是在跟谁比
  $\mu_r=\mu/\mu_0$，真空的 $\mu_r$ 就是 1。所以问题等价于：铁磁材料的磁导率比真空大多少？
- 完整解答
  **答案：A 远大于。** 铁、钴、镍是典型的**铁磁性材料**，其 $\mu_r$ 可达数百到数万，比真空中大好几个数量级，所以是「远大于」，不是「略大于」。
- 复盘：别把「大」写成「略大」 :-
  「略大于」是顺磁材料的量级（$\mu_r$ 比 1 大一点点）；铁磁材料是**量级上的差别**，这是两类材料最本质的区别。
:::

### 第 2 题

铁磁性物质的磁滞损耗与磁滞回线面积的关系是（　）。A 面积越小，损耗越大　B 以上答案均不正确　C 面积越大，损耗越大　D 面积大小与损耗无关

:::collapse accordion
- 提示：磁滞损耗是每周期「绕回线一圈」浪费的能量
  沿磁滞回线绕一圈所消耗的能量，就等于**回线所围的面积**；交变磁化每周期绕一圈，所以损耗与面积成正比。
- 完整解答
  **答案：C 磁滞回线包围的面积越大，磁滞损耗也越大。** 单位体积、每周期磁滞损耗 = 回线面积；面积越大（矫顽力越大），反复磁化的损耗越大。
- 复盘：一个等式记住这条 :-
  **磁滞损耗 ∝ 回线面积**。推论：要省铁耗，就选回线**窄**的材料——这正是软磁材料的定义性特征（第 17 题）。
:::

### 第 3 题

电机是指依据（　）定律实现能量转换或信号传递的一种电磁装置。A 电磁感应　B 牛顿运动　C 热力学　D 欧姆

:::collapse accordion
- 提示：电机里发生的是什么
  电机里是「电」与「磁」的相互作用：线圈与磁场相对运动或磁场变化时，线圈中产生感应电动势。这条规律就是**电磁感应定律**（法拉第定律），再加上电流在磁场中受力，合起来实现机电能量转换。
- 完整解答
  **答案：A 电磁感应。** 电机实现能量转换或信号传递所依据的是**电磁感应定律**。牛顿运动定律管的是转子的机械运动，热力学管的是发热与效率，欧姆定律只管电阻上的电压电流关系，都不是「电机之所以是电机」的那条依据。
- 复盘：一句话的电机定义 :-
  电机 = 依据**电磁感应**实现能量转换或信号传递的**电磁装置**。这句话就是本课程的第一句定义，也解释了为什么本课先讲磁场与磁介质。
:::

### 第 4 题

如图所示，直线电流与通电矩形线圈同在纸面内，线框所受磁场力合力的方向为（　）。A 水平向右　B 垂直向下　C 垂直向上　D 水平向左

〔题面配图〕左侧竖直线电流 $I_1$ 箭头向上；右侧矩形线框内电流 $I_2$ 沿顺时针：上边向右、右边向下、下边向左、左边向上。

:::collapse accordion
- 提示：四条边一分为二，先看哪两条会抵消
  直线电流产生的磁场穿过线框平面。**上边和下边**处在同样的水平位置范围，受力大小相等、方向相反 → 抵消；**左边和右边**离导线远近不同，磁场强弱不同 → 抵消不掉，合力由这一对决定。
- 完整解答
  **答案：D 水平向左。**
  1. 无限长直导线通向上电流，在其**右侧**产生的磁场**垂直纸面向里**，且离导线越远越弱（$B\propto 1/r$）。
  2. 线框四边受力用 $F=BIL$ 判断（也可用左手定则）：
     - 左边（离导线近，电流向上）：与 $I_1$ **同向**，被**吸引**，受力**向左**（指向导线）；
     - 右边（离导线远，电流向下）：与 $I_1$ **反向**，被**排斥**，受力**向右**，但该处磁场更弱，力更小；
     - 上边（电流向右）受力**向上**，下边（电流向左）受力**向下**，大小相等，**抵消**。
  3. 左边受力大于右边 → 合力**水平向左**，指向直线电流。
- 复盘：同向相吸、反向相斥 :-
  两条平行电流**同向相吸、反向相斥**，这条结论比逐边算 $BIL$ 快得多。再补一句：距离近的一边「嗓门更大」，所以合力总指向导线。
:::

### 第 5 题

为减小剩磁，电磁线圈的铁心应采用（　）。A 非磁性材料　B 软磁性材料　C 矩磁性材料　D 硬磁性材料

:::collapse accordion
- 提示：剩磁大小看回线落在哪个轴上
  去掉磁化电流后仍保留的磁感应强度就是**剩磁**，它在磁滞回线与纵轴的交点处读出。问「哪种材料剩磁小」，等价于问「哪种材料的回线最窄、最贴近原点」。
- 完整解答
  **答案：B 软磁性材料。** 软磁材料磁滞回线**窄**、矫顽力与剩磁都**小**，适合做电磁线圈与变压器铁心（要的是导磁好、损耗小、断电后磁性基本消失）。其余三项：硬磁材料剩磁**大**（正适合做永磁体）；矩磁材料回线接近**矩形**、剩磁也大（用于记忆元件）；非磁性材料不能导磁，做铁心没有意义。
- 复盘：软磁 vs 硬磁，一句话记牢 :-
  **软磁要「软」**——容易磁化、也容易退磁（窄回线、小剩磁）；**硬磁要「硬」**——一旦磁化就顽固保留（宽回线、大剩磁，永磁体就是它）。
:::

### 第 6 题

如图所示，两圆环 A、B 同心放置且半径 $R_A>R_B$，将一条形磁铁置于两环的圆心处且与圆环平面垂直，则穿过 A、B 两环所围的面积的磁通量大小是（　）。A $\Phi_A<\Phi_B$　B 无法判断　C $\Phi_A>\Phi_B$　D $\Phi_A=\Phi_B$

〔题面配图〕条形磁铁垂直于环面、位于两环共同圆心处。

:::collapse accordion
- 提示：磁力线是闭合的，出去还要回来
  条形磁铁的磁力线从 N 极出来，在外部空间绕回 S 极。**大环多包住的那部分（两环之间）**，磁力线是从外面**返回**的，方向与中心区域**相反**。
- 完整解答
  **答案：A $\Phi_A<\Phi_B$。**
  1. 磁通量是**有向**的：方向相反的磁通要相减。
  2. 小环 B 围住的区域里，磁力线基本是同一方向穿出（或穿入）；大环 A 等于「小环区域」**加上**「两环之间的环带」。
  3. 环带里的磁力线是磁铁外部**返回**的那部分，方向与中心区域**相反**，于是把总磁通**抵消掉一部分**。
  4. 所以 $\Phi_A=\Phi_{\text{中心}}-\Phi_{\text{环带}}<\Phi_B$。
- 复盘：磁通量是「净根数」 :-
  磁通量数的是**穿过面积的净磁力线根数**，方向相反要相减。不要以为「面积大磁通就一定大」——这正是本题的陷阱（大环反而小）。
:::

### 第 7 题

下列与磁导率无关的物理量是（　）。A 磁场强度　B 磁通　C 磁阻　D 磁感应强度

:::collapse accordion
- 提示：把四个量的定义式各写一遍，看哪个式子里没有 μ
  $B=\mu H$、$\Phi=\int B\,\mathrm{d}A$、$R_m=l/(\mu A)$、$H=NI/l$——逐个数，哪一个是「算的时候根本不需要知道介质」的。
- 完整解答
  **答案：A 磁场强度。**
  - **磁场强度 $H$**：只由**电流（激励）与几何尺寸**决定（如 $H=NI/l$），**与介质磁导率无关**；
  - 磁感应强度 $B=\mu H$ —— 与 $\mu$ 有关；
  - 磁通 $\Phi=\int B\,\mathrm{d}A$ —— 因 $B$ 而随 $\mu$ 变；
  - 磁阻 $R_m=l/(\mu A)$ —— 分母里就有 $\mu$。
- 复盘：H 是「起因」，B 是「结果」 :-
  $H$ 描述**外因**（电流怎么激励），$B$ 描述**介质中的实际响应**。记住这条，第 18、20 两题一起就通了。
:::

### 第 8 题

1820 年 4 月，科学家（　）在一次通电演示时发现了电流的磁效应。A 法拉第　B 奥特曼　C 奥斯特　D 法拉利

:::collapse accordion
- 提示：这是课本上的科学史第一句
  1820 年，丹麦物理学家在一次课堂演示中发现通电导线能使旁边的小磁针偏转——从此「电」与「磁」被联系起来。
- 完整解答
  **答案：C 奥斯特。** 奥斯特（H. C. Ørsted）于 1820 年 4 月发现**电流的磁效应**（通电导线使小磁针偏转）。法拉第的贡献是**电磁感应**（1831 年，反向的那一步：磁生电）；「奥特曼」「法拉利」是外形相近的干扰项。
- 复盘：两个人的方向别搞反 :-
  **奥斯特：电 → 磁**（1820）；**法拉第：磁 → 电**（1831）。电机能转起来，靠的正是这两步合起来。
:::

### 第 9 题

如图所示，两个完全一样的环形线圈相互垂直地放置，它们的圆心位于共同点 O 点，当通以相同大小的电流时，O 点处的磁感应强度与一个线圈单独产生的磁感应强度之比是（　）。A 1.414：1　B 1：1　C 2：1　D 1：1.414

〔题面配图〕两个相同的环形线圈互相垂直，圆心重合于 O 点，各通电流 $I$。

:::collapse accordion
- 提示：两个矢量成 90°，合起来是几倍
  两个线圈的圆心重合、平面互相垂直 → 它们在 O 点产生的磁感应强度**大小相等**、**方向互相垂直**。两个互相垂直的等长矢量相加，模长是多少？
- 完整解答
  **答案：A 1.414：1。** 设单个线圈在 O 点产生 $B_0$。两线圈相同、电流相同 → 两个 $B_0$ 大小相等；两平面互相垂直 → 两个磁感应强度方向**互相垂直**。合成：$B=\sqrt{B_0^2+B_0^2}=\sqrt2\,B_0$，所以比值 $\sqrt2:1\approx1.414:1$。
- 复盘：$1:1.414$ 是「反过来问」的陷阱 :-
  $\sqrt2\approx1.414$ 记住这个数。选项 D 把比值写反了（那等于问「单线圈与合磁场的比」）；B 是「同向相加」的错误（同向才是 $2:1$，即选项 C 的情形）。
:::

### 第 10 题

空心线圈插入铁心后，（　）。A 磁性将大大增强　B 磁性将减弱　C 磁性基本不变　D 不能确定

:::collapse accordion
- 提示：同样的电流，换介质会怎样
  线圈的激励（安匝数）没变，但线圈内部的介质从空气换成了铁磁材料。用 $B=\mu H$ 判断。
- 完整解答
  **答案：A 磁性将大大增强。** 激励不变时 $B=\mu H$，铁心的 $\mu_r$ 可达数百至数万（第 1 题），所以线圈内及其周围的磁感应强度、穿过线圈的磁通都大大增强。这正是电磁铁、变压器都装铁心的原因。
- 复盘：铁心是「磁放大器」 :-
  同样的电流，加铁心能把磁通放大几百到几万倍。反过来看第 7 题：$H$ 没变，变的是 $B$。
:::

### 第 11 题

如图所示，处在磁场中的载流导线，受到的磁场力的方向应为（　）。A 垂直向上　B 水平向左　C 水平向右　D 垂直向下

〔题面配图〕水平方向四根平行箭头表示磁场 $B$，**由左指向右**；导线用「圆圈内加叉」符号表示，即**垂直于纸面、电流方向流入纸面**（图右侧标 $I$）。

:::collapse accordion
- 提示：先认符号，再定方向
  「⊗」表示电流**垂直纸面向里**；箭头表示磁场**水平向右**。求受力方向有两条路：左手定则，或直接算 $F=IL\times B$。
- 完整解答
  **答案：D 垂直向下。**
  - **左手定则**：让磁感线穿入手心（手心朝左，磁感线向右穿入），四指指向电流方向（指向纸面里），拇指指向受力方向——拇指指向**纸面内向下**，即垂直向下。
  - **矢量法**：$F=I\,L\times B$，取 $\hat{L}=-\hat{z}$（向里）、$\hat{B}=+\hat{x}$（向右），则 $\hat{L}\times\hat{B}=(-\hat{z})\times\hat{x}=-\hat{y}$，受力沿 $-\hat{y}$，即**向下**。
- 复盘：受力三要素缺一不可 :-
  判断受力必须同时知道**电流方向**与**磁场方向**，两个都是矢量；「⊗」是一种电流方向画法（向里），「⊙」则相反（向外）。
:::

### 第 12 题

判定通电导线或通电线圈产生磁场的方向用（　）。A 左手定则　B 欧姆定律　C 楞次定律　D 右手螺旋法则

:::collapse accordion
- 提示：把「电生磁」和「磁生电／受力」分开
  题目问的是「电流**产生**的磁场」方向——这是「电生磁」，属于安培定则（右手螺旋法则）那一格。
- 完整解答
  **答案：D 右手螺旋法则。** 用右手握住导线，拇指指向电流方向，四指绕向就是磁场方向；对线圈则四指沿电流绕向、拇指指向线圈内部磁场方向（也叫安培定则）。
- 复盘：三个定则各管一段，别混 :-
  **右手螺旋**：电流→磁场（本课程反复用）；**左手定则**：电流＋磁场→受力（电动机）；**右手定则**：运动＋磁场→感应电动势（发电机）。楞次定律管的是**感应电流的方向**（阻碍变化），欧姆定律与本题无关。
:::

## 4. 判断题（第 13–24 题）

### 第 13 题

铁磁性物质在反复交变磁化过程中，磁感应强度 B 的变化总是滞后于磁场强度 H 的变化，称为磁滞现象。

:::collapse accordion
- 提示：这一句在问「磁滞」这两个字是什么意思
  「滞」就是滞后：B 跟不上 H 的变化。
- 完整解答
  **答案：对。** 这就是**磁滞现象**的定义：反复交变磁化时，$B$ 的变化**滞后**于 $H$，正因为滞后才形成有面积的磁滞回线。
- 复盘：一句话串起三题 :-
  定义（本题）→ 回线面积（第 2 题）→ 损耗与剩磁（第 2、5、22、23 题）。磁滞这一族题全从这句定义出发。
:::

### 第 14 题

非晶合金是利用超急冷技术形成的，可用来制造变压器铁芯以降低损耗。

:::collapse accordion
- 提示：新型软磁材料为什么省电
  非晶合金把熔融金属以极快速度冷却，原子来不及排成晶格，形成**非晶**（无序）结构；这种结构电阻率高、磁滞回线窄。
- 完整解答
  **答案：对。** 非晶合金由**超急冷**（快速凝固）技术制成，具有高电阻率、低矫顽力、窄磁滞回线的特点，用它做变压器铁心可以同时降低**磁滞损耗**与**涡流损耗**（铁耗），所以又称「节能变压器铁心材料」。
- 复盘：非晶的两个好处 :-
  **窄回线 → 磁滞损耗小**；**高电阻率 → 涡流损耗小**。两条都指向「省铁耗」。
:::

### 第 15 题

一个磁体有 N 极和 S 极两个极，若该磁体截成两段，则一段只有 N 极，另一段只有 S 极。

:::collapse accordion
- 提示：磁力线闭合意味着什么
  磁力线是**闭合曲线**，没有起点也没有终点——这决定了磁极能不能被「单独切出来」。
- 完整解答
  **答案：错。** 磁极**不能单独存在**：把磁体截成两段，每一段各自都成为**有 N、S 两极的完整小磁体**（继续截下去同样如此）。这与电荷不同——正负电荷可以分开，磁极不行。
- 复盘：与「电」对照记 :-
  **电荷能分开，磁极分不开。** 物理原因就是磁力线闭合（不存在磁单极）。
:::

### 第 16 题

一个线圈通过单位电流时所产生的磁链称为该线圈的电容 C。

:::collapse accordion
- 提示：磁链除以电流，得到的是什么
  单位电流产生的**磁链**——把「磁链」当分子、「电流」当分母，看这个比值叫什么，单位是什么（$1\,\mathrm{Wb}/1\,\mathrm{A}=1\,\mathrm{H}$）。
- 完整解答
  **答案：错。** 单位电流产生的磁链是线圈的**电感** $L=\Psi/i$（单位：亨利 H，$1\,\mathrm{H}=1\,\mathrm{Wb/A}$），不是**电容** $C$。电容描述的是「储存电荷」的能力（$C=q/u$），对应的是电场而不是磁场。
- 复盘：一对「对偶」概念 :-
  **电感 L 管磁场储能**（$\tfrac12Li^2$）；**电容 C 管电场储能**（$\tfrac12Cu^2$）。题面把「电感」写成了「电容」，这是最常见的偷换。
:::

### 第 17 题

与硬磁材料的磁滞回线相比，软磁材料的磁滞回线较宽。

:::collapse accordion
- 提示：软磁材料用来干什么，就知道回线该宽还是窄
  软磁材料要反复磁化（变压器、电机铁心），必须「来去自如」——回线应当**窄**。
- 完整解答
  **答案：错。** **软磁**材料的磁滞回线**窄**（矫顽力小、剩磁小、损耗小）；**硬磁**材料的磁滞回线**宽**（矫顽力大、剩磁大）。题面把两者说反了。
- 复盘：宽窄对应用途 :-
  回线**窄**→软磁→**铁心**（要反复磁化）；回线**宽**→硬磁→**永磁体**（要长期保持磁性）。记用途比记名词牢。
:::

### 第 18 题

在均匀磁介质中，磁场强度的大小与媒介质的性质无关。

:::collapse accordion
- 提示：$H$ 与 $B$ 谁是「起因」
  拿出 $B=\mu H$ 与 $H=NI/l$ 对照：换了介质，$B$ 会变，$H$ 会不会变？
- 完整解答
  **答案：对。** 磁场强度 $H$ 只取决于**电流激励与几何条件**（如 $H=NI/l$、长直导线 $H=I/(2\pi r)$），与介质无关；随介质变化的是磁感应强度 $B=\mu H$。这也正是引入 $H$ 的意义——把「外因」从「介质响应」里分离出来。
- 复盘：与第 7、20 题同一条原理 :-
  **$H$ 无关介质、$B$ 有关介质。** 这一条在这份作业里考了三次（第 7、18、20 题），说明它是本课第一个要背死的结论。
:::

### 第 19 题

铁磁性物质的磁导率是一常数。

:::collapse accordion
- 提示：想一想 B–H 曲线是不是直线
  铁磁材料的 $B$–$H$ 关系是不是过原点的直线？有没有饱和？同一个材料在小电流和大电流下的 $\mu$ 一样吗？
- 完整解答
  **答案：错。** 铁磁材料的 $\mu=B/H$ **不是常数**：起始段 $\mu$ 随 $H$ 增大而增大，随后因**磁饱和**而下降；再加上磁滞，同一个 $H$ 值在升磁和退磁时对应的 $B$ 都不一样（$B$–$H$ 是闭合的回线而不是一条直线）。铁磁材料的磁导率是**非线性**的，只有真空与非铁磁材料的 $\mu$ 才近似为常数。
- 复盘：为什么本课不能只会算线性电路 :-
  正因为 $\mu$ 不是常数，铁心线圈不能像电阻那样「一个系数算到底」，本课后面才要用**磁化曲线**和**磁滞回线**来处理。
:::

### 第 20 题

通电导体周围的磁感应强度只取决于电流的大小及导体的形状，而与媒介质的性质无关。

:::collapse accordion
- 提示：这句话对哪个量才是对的
  把句子里的「磁感应强度」换成「磁场强度」——就成立了。可见本题在赌你分不清这两个量。
- 完整解答
  **答案：错。** 取决于电流大小与导体形状（而**与介质无关**）的是**磁场强度 $H$**；**磁感应强度** $B=\mu H$，还要乘上介质磁导率，因此**与介质性质有关**——同样的电流，放进铁心比放在空气中 $B$ 大得多（第 10 题）。
- 复盘：一字之差就是错 :-
  $B$ 与 $H$ 差一个 $\mu$。读完题先在心里把两个量的名字互换着念一遍，这类偷换就露馅了。
:::

### 第 21 题

两根靠得很近的平行直导线，若通以相同方向的电流，则他们相互吸引。

:::collapse accordion
- 提示：一边的电流在另一边产生磁场，再让那一边受力
  甲电流在乙处产生磁场，乙电流在这个磁场里受力；反之亦然。方向用左手定则判断，或者直接用已知结论。
- 完整解答
  **答案：对。** **同向**平行电流相互**吸引**，**反向**相互**排斥**（每条导线处在另一条产生的磁场中受力；也可理解为同向电流之间的磁场相互抵消、侧向压力把它们压在一起）。第 4 题正是用这条结论定性地判断线框合力方向。
- 复盘：和电流「抱团」 :-
  **同向相吸、反向相斥**——这条结论在第 4 题省掉了大量逐边计算，值得背。
:::

### 第 22 题

极限磁滞回线与纵坐标交点 $B_r$ 称为剩余磁感应强度，与横坐标交点 $H_C$ 称为矫顽磁力。

:::collapse accordion
- 提示：两个交点分别在什么状态
  纵轴对应 $H=0$（外加磁场撤掉），横轴对应 $B=0$（磁性被完全抵消）。
- 完整解答
  **答案：对。** 极限磁滞回线在 $H=0$ 处的纵坐标 $B_r$ 叫**剩余磁感应强度**（剩磁）；在 $B=0$ 处的横坐标 $H_C$ 叫**矫顽力**（矫顽磁力）。前者衡量「撤掉外磁场后还剩多少磁性」，后者衡量「要加多大反向磁场才能把它消掉」。
- 复盘：两个交点，两个用途 :-
  $B_r$ 大 → 适合做**永磁体**；$H_C$ 小且回线窄 → 适合做**铁心**。第 5、17 题用的就是这两把尺子。
:::

### 第 23 题

铁块在交变磁场中会发热，这部分损耗叫做铁耗。它包括磁滞损耗和涡流损耗。

:::collapse accordion
- 提示：一个在回线里，一个在导体内
  交变磁化带来两种发热：磁性材料本身的（与回线有关）和感应电流引起的（与电阻率、厚度有关）。
- 完整解答
  **答案：对。** 铁耗包括两部分：**磁滞损耗**（磁畴反复翻转，与磁滞回线面积成正比）与**涡流损耗**（交变磁通在铁心中感应出的涡流在电阻上发热）。工程上把两者合称**铁耗**（也叫铁损），变压器与电机的铁心片做得薄、片间绝缘、或改用高电阻率的非晶合金（第 14 题），都是为了压这两种损耗。
- 复盘：铁耗 vs 铜耗 :-
  **铁耗**发生在铁心里（磁滞＋涡流，与频率、磁密有关），**铜耗**发生在绕组电阻上（$I^2R$，与电流有关）。别把两者混在一句里。
:::

### 第 24 题

磁场中载流导体的电流流向与磁场方向及该载流导体受到的电磁作用力遵循右手定则。

:::collapse accordion
- 提示：数一数这句话里有几个「矢量」
  电流方向、磁场方向、受力方向——三个矢量定方向，用的是哪只手？回想第 11 题你用的是哪只手。
- 完整解答
  **答案：错。** 「电流＋磁场 → **受力**」用的是**左手定则**（电动机定则）；**右手定则**管的是「导体运动＋磁场 → **感应电动势**」（发电机），即磁生电那一侧。所以这句话把定则用错了位置。
- 复盘：一手管电、一手管力 :-
  **左手（Left）管力（L 与力都在「电生磁的下一格」）**：受力；**右手管发电**：感应电动势。再叠加第 12 题的右手螺旋（电生磁），三个定则就分清了。
:::

## 5. 多选题（第 25 题）

### 第 25 题

电机学课程中对电机分类的以下说法，**错误的有**（　）。

- A 电机包括静止电机和旋转电机
- B 直流电机包括直流发电机和直流电动机
- C 异步电机只有电动机
- D 交流电机包括异步电机和同步电机
- E 旋转电机包括交流电机和直流电机
- F 变压器不是电机

:::collapse accordion
- 提示：先找「太绝对」的词，再找「自相矛盾」的两项
  多选题里，含「只有」「不是」这类绝对说法的选项要先怀疑；另外注意 A 与 F 说的是同一件事的两面——不可能同时成立。
- 完整解答
  **答案：C、F。**
  - **A 对**：电机按运动形式分**静止电机**（变压器）与**旋转电机**——这是本课程的第一层分类。
  - **B 对**：直流电机＝直流发电机＋直流电动机，常规说法。
  - **C 错**：异步电机**不是「只有电动机」**——异步电机也可以作发电机运行（如风力发电中的异步发电机），「只有」太绝对。
  - **D 对**：交流电机＝异步电机＋同步电机，按转速与磁场同步关系划分。
  - **E 对**：旋转电机按电流种类分交流电机与直流电机。
  - **F 错**：按 A 的分类，**变压器属于静止电机**，所以「变压器不是电机」是错的。
  > 〔待核对〕C 这一条的判定取决于课程/教材口径：若教材只讲「异步电机主要作电动机」，可能只判 F 错。以教师课上口径与教材表述为准；**F 是确定项**（与 A 直接矛盾）。
- 复盘：分类树自上而下记 :-
  **电机 →（静止 / 旋转）**；旋转 →（交流 / 直流）；交流 →（异步 / 同步）；直流 →（发电机 / 电动机）。把这棵树画出来，六条说法逐条挂上去，对错立刻分明。

## 6. 小结：这份作业真正想教的三件事

1. **两个量必须分清：$H$ 与 $B$。** $H$ 由电流与几何决定（与介质无关），$B=\mu H$ 才是介质里的实际响应。第 7、18、20 三题都在考这一条——它是本课第一个要背死的结论。
2. **磁滞回线是一把万能尺。** 回线**面积**→磁滞损耗（第 2 题）；回线**宽度**→软磁/硬磁与用途（第 5、17 题）；与纵轴交点→剩磁 $B_r$、与横轴交点→矫顽力 $H_C$（第 22 题）；加上涡流损耗就是铁耗（第 14、23 题）。
3. **三个定则各管一段。** 右手螺旋＝电生磁（第 12 题）；左手定则＝电流在磁场中受力（第 11、24 题）；右手定则＝磁生电。判断受力类题目还要记住**同向电流相吸**（第 4、21 题）这条捷径。
