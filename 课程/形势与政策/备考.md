## 考试形式

- **开卷**：带**课本**；教师发的「**铸牢中华民族共同体意识**」材料也可带。

- **违纪后果**：**记过处分、记入档案**。

## 专题二：经济热点——四个知识点

教师原话「**这四个点都是考点**」。每个知识点记住「名字 + 关键词」：

**① 加快培育壮大新动能** —— 四个方面：
优化提升传统产业（是「老树发新芽」，**不是摒弃**）→ 培育壮大新兴产业和未来产业 →
扩能提质服务业（这就是引出知识点②的钩子）→ 打造智能经济新形态。

**② 促进服务业优质高效发展**（讲得最完整）—— 框架四点：**需求牵引、改革空间、科技赋能、开放合作**。

- 服务业是**国民经济第一大产业**：对经济增长贡献率 **64.1%**、就业占比 **49.4%**（稳就业的压舱石）。
- 两大类：**生活性服务业**（面向居民——餐饮零售、家政物业、文旅健康）与
  **生产性服务业**（面向企业——金融、物流、信息技术、研发设计）。
- 目标：国务院印发《关于推动服务业扩能提质的意见》，**到 2030 年服务业总规模迈上 100 万亿元台阶**。

**③ 深入整治内卷式竞争** —— 教师只设问未展开，说「**课本上都有**」：什么是内卷式竞争、为什么整治、**如何整治（3 点）**。

**④ 防范化解重点领域风险** —— 三个领域（课本 44–45 页）：

| 领域 | 关键词 |
| :--- | :--- |
| 房地产 | 「房子是用来住的，**不是用来炒的**」；核心是**稳市场、保民生** |
| 地方政府债务 | **遏制增量、化解存量** |
| 中小金融机构 | 风险主要在**农村**；方针「该整合则整合、该清退则清退」；核心**改革化险、减量提质**，底线**不爆雷** |

> ⚠ 易混：知识点①里的「扩能提质服务业」是引出知识点②的，**别把两条答成同一个**。
> 知识点③的整治方法与成因在课本对应页，开卷直翻。

## 专题三：人工智能——三个知识点

**① 人工智能引领新一轮科技革命和产业变革**

标志性时间线（只记节点，别背流水账）：

| 年份 | 事件 |
| :--- | :--- |
| 1950 | **图灵**提出「机器能否思考」 |
| 1956 | **达特茅斯会议**上「人工智能」正式命名 |
| 1997 | **深蓝**战胜国际象棋世界冠军 |
| 2006 | **辛顿**团队提出**深度学习** |
| 2012 | 从**计算到学习**的质变 |
| 2016 | **AlphaGo** 胜李世石 |
| 2022 | **ChatGPT** 等展示生成与推理 |
| 2025 | 从**生成式 AI 迈向智能体 AI** |

两个新概念（考点）：

- **智能体（AI Agent）**＝可自主感知环境、规划任务、调用工具、执行交付的「**数字员工**」。
  **与生成式 AI 的区别：一个被动回答，一个主动完成任务。**
- **具身智能**＝给智能体**装上身体**，从知到行；载体是**人形机器人**。

**② 牢牢掌握人工智能发展和治理的主动权** —— 核心技术攻坚：**开源自立**
（中美路径对比：中国全栈开源 vs 美国闭源垄断）。

**③ 人工智能是年轻的事业，也是年轻人的事业。**

> ⚠ 易混：**智能体 ≠ 生成式 AI**（被动问答 vs 主动交付）；**具身智能 ≠ 智能体**（具身是多走一步「有了身体」）。
> 课本 69 页有妈祖气象 AI 的深入分析。

## 专题五：美丽中国建设——四个方面

**① 历史性成就：四个重大转变**（本专题的骨架，**顺序和名字都要背准**）：

| 转变 | 关键事实 |
| :--- | :--- |
| 由**重点整治**到**系统防治** | 点面结合、标本兼治；蓝天碧水净土保卫战——**2024 年优良天数比例 87.2%**；长江干流连续六年、黄河干流连续四年稳定二类水质；受污染耕地安全利用率连续五年 90% 以上 |
| 由**被动应对**到**主动作为** | 不走先污染后治理的老路；江豚数量 **1012 → 1426 头**（2017–2025）；绿电占全社会用电 **4/10** |
| 由全球环境治理**参与者**到**引领者** | 推动《巴黎协定》签署生效；**双碳：2030 碳达峰、2060 碳中和**；昆明—蒙特利尔全球生物多样性框架；第一批国家公园 |
| 由**实践探索**到**科学理论** | **绿水青山就是金山银山**——安吉余村从矿山村到联合国最佳旅游乡村 |

**② 法治根基——生态环境法典**：今年表决通过、**8 月 15 日开始施行**。
（教师原话「**讲这些都是考试的题目**」。）

**③ 全面推进人与自然和谐共生**：当前形势、美丽中国的内涵与建设目标、任务举措与个人行动。

> ⚠ 易混：「四个转变」答错一个顺序就是硬伤；法典的**施行日期（8 月 15 日）**是教师点名的题。

## 开卷策略

- **先定位、后翻书**：教师反复强调「至少要知道每个知识点在课本的什么位置」——他每次第一节课就在划重点。
- **抓提示词**：教师把「重点掌握」「务必把握」「这些都是考试的题目」直接标在考点上——上文加粗处就是收拢。
- **作业即模拟**：题型、题库都和作业一样；考前把两次作业过一遍。
