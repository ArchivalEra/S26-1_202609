## 专题二：经济热点（09-21）

### 考点：加快培育壮大新动能

**要会**：说出新动能的四个方面，各配一句。

| 方面 | 一句话 |
| :--- | :--- |
| 优化提升传统产业 | 「老树发新芽」——是升级，**不是摒弃** |
| 培育壮大新兴产业和未来产业 | 新兴产业＋未来产业两个层次 |
| 扩能提质服务业 | 这就是引出下一个考点的钩子 |
| 打造智能经济新形态 | 经济与人工智能接轨 |

**案例**：武汉「稻米造血」——基因工程让水稻生产人血清白蛋白，已建成年产 100 万支注射液的智能工厂。

**容易记混**：这一考点讲「新动能的四个方面」，下一考点是其中第三方面展开——两条别答成同一个。

[笔记原文 ↗](./课堂笔记/2026-09-21-经济热点专题与考试安排.md#知识点-1-加快培育壮大新动能)

### 考点：促进服务业优质高效发展

**要会**：四点框架 + 为什么重要。

- **四点框架**：需求牵引、改革空间、科技赋能、开放合作。
- **两大类**：生活性服务业（面向居民——餐饮零售、家政物业、文旅健康）；生产性服务业（面向企业——金融、物流、信息技术、研发设计）。
- **为什么重要**：**国民经济第一大产业**——对经济增长贡献率 **64.1%**、就业占比 **49.4%**。
- **目标**：国务院印发《关于推动服务业扩能提质的意见》，**到 2030 年服务业总规模迈上 100 万亿元台阶**。

**案例**：胖东来创始人于东来受邀参加国务院经济形势座谈会（全国唯一基层零售代表）；教师总结其成功三点——向善的能量、承担责任、家国情怀。

[笔记原文 ↗](./课堂笔记/2026-09-21-经济热点专题与考试安排.md#知识点-2-促进服务业优质高效发展-本次课最完整的一段)

### 考点：深入整治内卷式竞争

**要会**：三问 + 一句定义。

- **定义**：经营主体为维护地位或争夺市场，不断投入大量精力资源，却没带来相应增量。
- **三问**：什么是内卷式竞争、为什么整治、**如何整治**。
- **整治方法 3 点** + 成因：教师说「**课本上都有**」，开卷直翻课本（教师提示**可能出多选题**）。

**容易记混**：教师本次课**没展开**这三点——别在笔记里找答案，去课本找。

### 考点：防范化解重点领域的经济风险

**要会**：三个领域 + 各自方针（**课本 44–45 页**）。

| 领域 | 方针 |
| :--- | :--- |
| 房地产 | 「房子是用来住的，**不是用来炒的**」；核心是**稳市场、保民生** |
| 地方政府债务 | **遏制增量、化解存量** |
| 中小金融机构 | 风险主要在**农村**；「该整合则整合、该清退则清退」；核心**改革化险、减量提质**，底线**不爆雷** |

**数据**：农村中小金融机构涉农贷款余额 **13.11 万亿元**、服务农户约 **4494 万户**（截至 2024 年末）。

## 专题三：人工智能（09-28）

### 考点：人工智能引领新一轮科技革命和产业变革

**要会**：时间线上几个标志节点 + 两个新概念。

| 年份 | 事件 |
| :--- | :--- |
| 1950 | **图灵**提出「机器能否思考」 |
| 1956 | **达特茅斯会议**正式命名「人工智能」 |
| 1997 | **深蓝**战胜国际象棋世界冠军 |
| 2006 | **辛顿**团队提出**深度学习** |
| 2012 | 从**计算到学习**的质变 |
| 2016 | **AlphaGo** 战胜李世石 |
| 2022 | **ChatGPT** 等展示生成与推理 |
| 2025 | 从**生成式 AI** 迈向**智能体 AI** |

**两个新概念**（考点）：

- **智能体（AI Agent）**：可自主感知环境、规划任务、调用工具、执行交付的「**数字员工**」。
  **与生成式 AI 的区别：一个被动回答，一个主动完成任务。**
- **具身智能**：给智能体**装上身体**（载体是**人形机器人**），实现从知到行。

**容易记混**：**智能体 ≠ 生成式 AI**（被动问答 vs 主动交付）；**具身智能 ≠ 智能体**（具身是多走「有了身体」一步）。

[笔记原文 ↗](./课堂笔记/2026-09-28-人工智能专题.md#知识点-1-人工智能引领新一轮科技革命和产业变革)

### 考点：牢牢掌握人工智能发展和治理的主动权

**要会**：三个方面（技术攻坚、应用导向、治理体系），各带一句。

- **核心技术攻坚**：中美路径对比——算法模型**开源赶超 vs 闭源垄断**；算力硬件**体系突围 vs 芯片封锁**；支撑要素**规模碾压 vs 质量壁垒**。
- **中国时间表**：2016 写入「十三五」规划 → 2017 新一代人工智能发展规划 → 2021「十四五」列为七大攻关领域 → 2025《关于深入实施「人工智能+」行动的意见》→ 2026 政府工作报告提出**打造智能经济新形态**。
- **算力**：首个全国产 **100000 卡** AI 超算集群「**曙光 8000**」（郑州国家超算互联网核心节点）；已建**八大算力枢纽节点 + 10 个国家数据中心集群**。
- **数据/网络**：**2025 年我国数据产量占全球 27.44%**；5G 基站约 **484 万个**（约占全球 60%）；全国光缆线路总长 **7499 万公里**。
- **能源**：特高压「**西电东送**」——准东—皖南工程 **3300 公里**「闪送」仅 **0.01 秒**，每年为华东输电超 **600 亿千瓦时**。
- **应用导向**：从「拿着锤子找钉子」改为**需求倒逼技术迭代**；案例——杭州萧山包装工厂 AI 设计引擎把设计费**从 5000 元降到 200 元以内**。
- **治理体系**：四点意见（开放共赢、安全可控、文明互鉴、全球治理）；「**发展和安全并重**」，让人工智能**始终处于人类控制之下**。

[笔记原文 ↗](./课堂笔记/2026-09-28-人工智能专题.md#知识点-2-牢牢掌握人工智能发展和治理的主动权)

### 考点：人工智能是年轻的事业，也是年轻人的事业

**要会**：一句判断 + 三件事。

- **判断**：AI 的**年轻属性**突出——传统基建用几十年上百年，AI 更新以**小时、天数**计；年轻一代是创新主体。
- **三件事**：① **筑牢知识底座**（数学、物理、统计学等基本功）；② 在「**AI+**」领域找赛道（做复合型交叉人才）；③ **永葆人文精神，为技术安装方向盘**。
- **数据**：ChatGPT 研发团队平均年龄 **32 岁**；DeepSeek 核心成员平均 **28 岁**。

[笔记原文 ↗](./课堂笔记/2026-09-28-人工智能专题.md#知识点-3-人工智能是年轻的事业-也是年轻人的事业)

## 专题五：美丽中国建设（10-12）

### 考点：我国生态环境保护的历史性成就——四个重大转变

**要会**：四个转变的名字与顺序 + 各自的关键事实。

| 转变 | 关键事实 |
| :--- | :--- |
| 由**重点整治**到**系统防治** | 蓝天碧水净土保卫战：**2024 年优良天数比例 87.2%**；长江干流连续六年、黄河干流连续四年稳定二类水质；受污染耕地安全利用率连续五年 90% 以上 |
| 由**被动应对**到**主动作为** | 不走先污染后治理的老路；江豚数量 **1012 → 1426 头**（2017–2025）；绿电占全社会用电 **4/10** |
| 由全球环境治理**参与者**到**引领者** | 推动《巴黎协定》签署生效；**双碳：2030 碳达峰、2060 碳中和**；昆明—蒙特利尔全球生物多样性框架；第一批国家公园 |
| 由**实践探索**到**科学理论** | **绿水青山就是金山银山**——安吉余村从矿山村到联合国最佳旅游乡村 |

**容易记混**：「四个转变」**顺序和名字都要背准**（重点整治→系统防治、被动应对→主动作为、参与者→引领者、实践探索→科学理论）。

### 考点：全面推进人与自然和谐共生

**要会**：内涵 + 目标 + 任务举措（教师点名「重点掌握」「务必把握」的地方）。

- **当前形势**（两面）：机遇——经济实力跃升、科技创新厚积薄发、「两山」成为全民共识；挑战——转型压力、新「三样」退役物（动力电池、光伏组件、风电组件）、新污染物风险。
- **美丽中国的三重内涵**（**课本 109–110 页**）：不只是**环境美**，还要**聚焦高质量发展**，**制度机制跟得上、持续优化**。
- **十五五目标**：**到 2030 年生态环境质量全面改善，美丽中国建设取得重大进展**；具体目标在**课本 110 页第三段**（教师提示「**容易出多选题**」）。
- **任务举措**（**课本 110–112 页**）：**推进绿色化**（国家生态文明试验区、美丽中国先行区；工业、城市建设、交通运输、能源等领域绿色低碳转型）；**守护生态圈**（按生态系统整体性系统性统筹——山上山下、地上地下、岸上水里、城市农村、陆地海洋、流域上下游；从聚焦城市农村转向**整体保护、系统修复、综合治理**）。
- **个人怎么做**：践行绿色低碳生活，响应「**美丽中国，我是行动者**」。
- **数据**：能耗强度是世界平均水平的 **1.5 倍**（教师原话）；公众生态环境满意度连续 **5 年**超 **90%**。

## 开卷怎么答

- **先定位、后翻书**：教师反复强调「至少要知道每个知识点在课本的什么位置」——他每次第一节课就在划重点。
- **抓提示词**：教师把「重点掌握」「务必把握」「这些都是考试的题目」直接标在考点上——上文引号处就是。
- **多选预警**：整治内卷式竞争的**方法 3 点**；美丽中国**具体目标**——教师都提示过可能出多选题。
- **作业即模拟**：题型、题库与作业完全相同，考前把两次作业过一遍。
