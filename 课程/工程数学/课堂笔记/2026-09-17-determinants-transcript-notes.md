# 工程数学 2026-09-17：行列式的展开、三角结构与基本性质

## 题号条目

### 例 1.6（余子式与代数余子式的辨识）

⚠ **本题条件未经独立核实**：转写里出现「第三行第四列」与「第三行第一列」两种说法，元素与余下的数字串无法可靠复原，**不重构矩阵**（原因见文末「条件备注」）。

- 能确定的部分：这道题用**四阶行列式**演示「定位一个元素 → 划去它所在的整行整列 → 剩下的数字按原相对顺序构成低一阶行列式」，讨论对象是**第三行第四列**那个元素。
- **这一点必须分清**：划剩下的那个低阶行列式是**余子式**（记 $M$）；**代数余子式**还要按位置定符号（$A_{ij}=(-1)^{i+j}M_{ij}$）。转写把奇偶两种情况都读成了「−1」，不能照抄。

**这一题在讲什么**：把「展开」这件事拆成两个可操作的动作——**划行列**（几何动作）与**定符号**（位置动作）。这两步分开做，后面所有高阶计算都是它的重复。

### 例 1.7（改按第三行展开）

⚠ **本题条件未经独立核实**：矩阵与各余子式的数字串在转写里缺乏可靠分行分列，**不写题目数据与答案**（见文末「条件备注」）。

- 能确定的部分：这道题故意**不照书上按第一行展开**，改按**第三行**展开，用来体会「同一行列式按不同行展开得到同一个值」。
- 教师顺带给的择零原则：**优先挑零元素多的行或列展开**——零元素对应的乘积项直接是零，那一项余子式根本不用算；降成三阶后如果零还多，**继续展开比机械套沙路法则更省**。
- 规范书写顺序：**定展开行（列）→ 定位元素 → 定代数余子式的符号 → 划去行列、保持剩余顺序 → 算低阶行列式**。
- 整理者补充的易错点：继续展开新得到的子行列式时，符号要按**当前子行列式**的位置判，**不能混用原行列式的行列编号**。

**这一题在讲什么**：展开位置是**可以自己选的**，选得好（零多）能省一半计算。这是「高阶题先观察、再动手」的第一个动作。

### 例 1.8（上三角、下三角与对角行列式）

⚠ **本题条件未经独立核实**：转写只保留了结论与证明思路，题面矩阵不全（见文末「条件备注」）。

- 能确定的部分与结论见下面「三角结构」一节：**上（下）三角与对角行列式都等于主对角线元素的乘积**。
- 教师讲法：沿上三角行列式的**第一列反复展开**，每次只有一个可能非零的贡献，展开后剩下的部分仍然是上三角，于是归纳到底。

**这一题在讲什么**：给出一个「值一眼可读」的形状，也就是后面所有化简的**目标形态**——把行列式朝三角形状变，值就等于对角线之积。

## 没编号但讲了的知识点

### 余子式与代数余子式

- **余子式 $M_{ij}$**：把元素 $a_{ij}$ 所在的**第 $i$ 行与第 $j$ 列整条划掉**，剩下的元素保持原有相对顺序，构成低一阶的行列式。
- **代数余子式 $A_{ij}$**：在余子式上再乘一个**由位置决定的符号**，$A_{ij}=(-1)^{i+j}M_{ij}$（位置指标之和为偶数取正、奇数取负）。
- 两者不能混用；也不要拿一个元素去乘**别的位置**的代数余子式。

### 按行（列）展开

**按某一行（列）展开**＝该行（列）每个元素乘**它自己的**代数余子式，再求和。四阶展开成 3 个三阶（那行哪个元素是零，对应项直接省掉），三阶再展开成二阶。

### 三角结构

- **上三角**：主对角线**下方**全为零；**下三角**：主对角线**上方**全为零；**对角**：两侧都为零（同时是上三角也是下三角）。
- 三者的值都等于**主对角线元素之积**（不是所有元素之积，也不是随便什么方阵都能这么算）。对角线上**允许出现零**。
- 证明不能只写「非零项只有对角线那一项」，要把展开的步骤写出来。

### 六条基本性质（把难算的变成好算的）

| 性质 | 内容 | 易错边界 |
| :--- | :--- | :--- |
| 转置 | 行列互换，值不变 | 转置 ≠ 只交换两行 |
| 互换两行（列） | **变号** | 两行（列）完全相同 → 行列式为 $0$ |
| 某行（列）数乘 | 该行所有元素乘 $k$ → 值乘 $k$；反过来可提公因子 | 不是全体元素都乘却只记一个 $k$ |
| 零行与成比例 | 有全零行，或两行成比例 → 值为 $0$ | 要整行对应着看，别只看几个相同元素 |
| 拆分 | 固定其他行，只把一行拆成两部分之和，可拆成两个行列式之和 | 只对**一行**成立，不是两个矩阵相加就值相加 |
| 倍加 | 某行加上**另一行**的 $k$ 倍，值**不变** | 来源行不动；别记成「单独乘一行也不变」 |

两条论证思路（老师给的）：**相同行判零**——交换两行后排列没变，但按交换性质应变号，只能为零；**倍加不变**——沿被修改的那行拆成两个行列式，其中一个是原行列式，另一个有两行成比例、为零。

**结尾的四阶示范**：利用**交换列**与**行倍加**制造更多零，再简化展开。要分开记两件事——**交换带一个负号，倍加不改变值**，不能把两种变换都说成「不改变值」。

## 转写与术语

这份转写的同音误识别集中在术语上，**照抄会抄错**：

- 「**行业是**」→ **行列式**；「**杀戮法则**」→ **沙路法则**；「**转制**」→ **转置**。
- 「**鱼子式／代数离子式**」→ **余子式／代数余子式**（全篇反复出现）。
- 「−1」在讲代数余子式符号处被读成两种奇偶都是「−1」→ **符号规则是偶正奇负**，别跟转写。
- 「**所有元素的乘积**」是口语不严谨说法 → 只有**三角／对角**行列式等于主对角线之积。
