# 第1章 1.4 用 MATLAB 进行行列式的计算（原书 p20–p21）

> 本文件同时保存**原书抄录**与**解析**。教材输出按书页登记；本轮**没有**在本机运行 MATLAB，命令与输出不表示已在本机复现。

## 原书抄录

〔原书 p20〕

采用 `det` 函数来求行列式的值，一般格式为：`D=det(A)`，其中 $A$ 为 $n\times n$ 个数按一定顺序排成的一个 $n$ 行 $n$ 列的数表。

**【例 1.18】** 求行列式

$$\begin{vmatrix}1&-2&4\\-5&2&0\\1&0&3\end{vmatrix}$$

的值。

解

```matlab
>> A=[1 -2 4;-5 2 0;1 0 3]
A=
     1    -2     4
    -5     2     0
     1     0     3
>> D=det(A)
D=
   -32
```

**【例 1.19】** 求行列式

$$\begin{vmatrix}
1&2&3&2\\
1&2&0&-5\\
1&0&1&2\\
4&3&1&2
\end{vmatrix}$$

的值。

解

```matlab
>> A=[1 2 3 2;1 2 0 -5;1 0 1 2;4 3 1 2]
A=
     1     2     3     2
     1     2     0    -5
     1     0     1     2
     4     3     1     2
>> D=det(A)
D=
   -48
```

〔原书 p21〕

**【例 1.20】** 求行列式

$$\begin{vmatrix}1&2&3\\4&5&6\\7&8&9\end{vmatrix}$$

的值。

解

```matlab
>> A=[1 2 3;4 5 6;7 8 9]
A=
     1     2     3
     4     5     6
     7     8     9
>> D=det(A)
D=
   -9.5162e-16
```

## 解析

**教材用法**：`D=det(A)`，`A` 为方阵；同一行元素用空格或逗号分隔，分号分隔行。

**例 1.18–1.19**：教材输出分别与整数精确值 $-32$、$-48$ 一致。例 1.19 就是 1.2 节例 1.10 的同一行列式，手工降阶法与 `det` 互相印证。

**例 1.20（浮点残差）**：

```matlab
A=[1 2 3;4 5 6;7 8 9];
D=det(A)      % 教材输出 -9.5162e-16
```

精确值为 $0$，因为 $r_3=2r_2-r_1$，三行线性相关（第 3 行 = 第 2 行的 2 倍减第 1 行）。教材输出的是一个极小的**浮点残差**，不是数学上的非零值；不同 MATLAB 版本或计算环境可能给出不同的微小残差或零。

**整理者补充的数值实践**：

- 不要用 `det(A)==0` 判断奇异；浮点下几乎永远不恰好为零。
- 也不要用不考虑矩阵尺度的固定阈值；一般需结合奇异值、条件数或带容差的判据。
- 数值求解线性方程组一般用 `A\b`，而不是重复算行列式再做除法；克莱姆法则主要用于理论推导和小规模精确计算。
- 若要判断例 1.20 这类行列式，直接看行（列）之间的线性关系比看浮点输出更可靠。
