### MATLAB 输出的复现状态

教材每章末尾都有 MATLAB 小节（1.4、2.5），这些小节的价值建立在"输出可复跑"上，所以书页数值要单独标注复现状态。

工具：`工具/教材复现/工程数学MATLAB复现.m`，在本机用 **GNU Octave 11.3.0**（MATLAB 语法兼容的开源实现，不是 MATLAB 本身）一条命令跑完全部例子并自检。

复现结论分三类，**不可跨环境复现的数值必须在正文里标注，不能当成结论**：

| 类别 | 例 | 处理 |
| :--- | :--- | :--- |
| 由精确算术唯一确定，跨实现一致 | 1.18、1.19 的 `det`，2.16、2.18–2.22、2.24、2.25 | 已逐条 PASS |
| 浮点残差，取决于 LU/BLAS 实现 | 1.20 的 `det`（书页 `-9.5162e-16`，本机 `6.6613e-16`，**符号都相反**） | 标注为不可复现；精确值为 $0$ 用行关系与 `rank` 双重确认 |
| 随机数或奇异矩阵求逆 | 2.17 的 `rand`（取决于种子）、2.23 的 `RCOND` 与 `inv` 量级 | 标注为不可复现；`inv` 只验证"方向 ∝ 伴随阵" |

这条经验对后续章节通用：以后遇到 MATLAB 小节，先分类再登记，**确定的算确定的，随机的标随机**。
