## 3. 安全域：静态与动态

- **安全域是什么**：约束条件由**数学方程定义的一个范围**——安全范围（也用于描述可靠性）。教师说现阶段**不要求**用数学去求解它，「知道安全是怎么回事」即可。
- **按描述它的方程分类**：

| 类型 | 用什么方程描述 | 说明 |
| :--- | :--- | :--- |
| **静态安全域** | **代数方程**（组） | 描述**平衡态**，完全没有动态的微分方程或差分方程 |
| **动态安全域** | **两类方程** | 动态的**微分方程或差分方程**（状态参数描述）＋代数方程 |

- **动态安全域的性质**（教师列举）：内部**连通**、没有空洞、**可微**（边界连续）、安全域与边界不会缠绕交错、不存在扭曲；在**同一种失稳模式下**对应的局部边界是连续的——教师说这是专业性概念，「由有限的失稳子模式表面的定义共同决定」。
- **线性系统的叠加性**：安全边界具有**线性叠加性**，「所有线性系统都满足」；判定一个系统是否线性，看它是否满足**叠加原理**——满足即线性，不满足即非线性。教师举的例子是简单线性电路（电阻 + 电容/电感）。
- **稳定性判据（复习第一讲）**：用状态空间模型的特征方程，看**特征根**——
  - 所有特征根的**实部都小于 0** → 稳定；
  - 只要存在一个特征根实部**不小于 0** → **失稳**（失去稳定）。
- **局部线性化**：电力系统是非线性系统，但在平衡点的**无穷小邻域**内可以线性化——教师用圆周运动打比方：在轨道上某点作**切线**，局部就是线性的；于是可写出该点处的线性状态空间方程，再判这个微小扰动是否稳定（同样看矩阵特征根）。
- **规模问题（本讲反复出现的引子）**：电力系统维数高、节点多（教师用「一个宿舍楼就是一个节点」打比方），特征根数量多到**无法手算**——「怎么办？人工智能」。

## 4. 物理参数与状态参数

教师说这一块**「有个认识就可以了，不用深究」**，但它解释了数据从哪来。

- 电力系统本质上是一个**非线性的动力系统**、一个物理系统；分析它时用到的参数分两类：

| 类别 | 又叫 | 内容 | 来源 |
| :--- | :--- | :--- | :--- |
| **物理参数** | 结构参数 | 描述物理结构的参数，如交流电机的电感、电抗、互感，铁心的磁性能 | 各类**传感器**测得（声、光、温等）——教师原话：这些数据「我们都是大数据」 |
| **状态参数** | 状态变量 | 描述状态连续变化的量：**电流、电压、功率、频率**等 | 由系统运行状态决定 |

- **两类参数共同表示能量**（教师用线性电路举例，元件是电阻、电容、电感）：
  - 电感储能：`(1/2)·L·i²`；电容储能：`(1/2)·C·u²`；
  - 也就是说，一个能量由**物理结构参数**与**状态参数**两类参数共同表达。
- 教师提示：这一周会有另一位专业老师把结构建模等相关内容上线到学习平台（**教师姓名不登记**），此处的结构参数、等效模型、状态分布等内容届时再补。

## 5. 潮流与雅可比矩阵

- **潮流**＝**功率分配**。教师强调不要被「潮流」这个词吓住：本课程里的潮流就是功率，网络与发电机之间有**潮流交换**。
- **雅可比矩阵**：潮流计算里用到的矩阵（转写作「压缩机」，见第 12 节），教师说这只是专业概念，知道它在潮流/节点电压计算里出现即可；**简化节点电压计算**是它的用途之一。

## 6. 时域仿真法（数值仿真法）

这是教师讲的**第一类经典方法**，讲得最细，也是「检验其他方法的标准」。

### 6.1 做法（一条完整的链条）

1. 建立电力系统**所有元件**的模型：原动机（驱动发电机的旋转机械）、发电机、电力网络、负荷；
2. 由**物理定律**写出等效物理模型——教师点名的定律是**基尔霍夫电流定律与电压定律**；
3. 由等效物理模型写出**数学模型**：一组**微分代数方程组**；
4. 用数字计算工具**求解大规模微分代数方程组**；
5. 得到故障前后**状态变量与代数变量的时间响应**；
6. 由**发电机相对功角曲线**的收敛性或发散性判断系统稳定性；若某台或多台机组与系统中其余机组的功率差超过一定**阈值**，就是失稳（教师说阈值的选取「由研究人员的经验判断」）。

### 6.2 方程结构（教师特别强调的一处）

| 方程 | 性质 | 角色 |
| :--- | :--- | :--- |
| **微分方程 / 差分方程** | 微分是连续的，差分是离散的 | 描述动态，是**目标（函数）** |
| **代数方程** | — | 描述**平衡态**，是**约束条件** |

两类方程组合起来，才构成电力系统这个复杂系统的求解问题。

### 6.3 判稳的时间区间

- 研究暂态稳定的时间区间通常是**扰动结束后 3–5 秒内**；
- 对于有**潜在区间震荡模式**的大型系统，时间区间可以延长到 **15–20 秒**（转写把单位写成了「年」，见第 12 节）。

### 6.4 优点与致命缺陷

- **优点**：**计算精度高**，因此长期以来是检验其他暂态稳定判据的**标准**。
- **缺陷**：
  - **计算量巨大**——节点规模一大，「在有限的时间内算不出结果」，甚至直接卡死；
  - 更要命的是**不能在线**：只能在**离线**情况下算好结果，**不满足在线暂态评估的要求**——教师称之为「致命缺陷」。
- 由此引出两件事：
  1. **数据中心**：发电站、变电站、换流站都要建数据中心，目的是**提高响应速度与计算速度**（因为在线评估要求快）；
  2. **两条提速路线**（见 6.5）。

### 6.5 提速的两条路线

- **路线一：在损失一部分精度的前提下用简化模型。** 教师提醒不能一味追求简单——「你一味地追求简单……求解出来了跟实际的系统相差十万八千里，没有指导意义」。要在**逼近真实物理系统**与**保证快速性**之间折中。
- **路线二：分布式并行计算**（最高级的形式是**云计算**）。
  - 云计算为什么快：不卖服务器、不卖资源，**只卖服务**；可以分解单个节点的复杂度与压力，从而提高运算速度。
  - **三个研究方向（教师要求记住）**：

| 方向 | 做法 |
| :--- | :--- |
| **时间并行算法** | 把**微分方程差分化（离散化）**后与代数方程**联立求解**，可保持严格**牛顿法**的收敛性 |
| **空间并行算法** | 把大的电力系统按物理分布**分成若干子网**，各子网分别单独计算 |
| **波形松弛算法** | 把大系统拆成若干小系统，利用**不同子系统间的交替迭代**计算，每个子系统可以多次计算 |

- 结论（教师原话的意思）：随着算法改进与计算设备性能提升，时域仿真法的计算速度已有较大提升，**但规模庞大时仍不能满足实时要求**——所以「只能说用 AI 了」「只能采用云计算和人工智能」。

## 7. 直接法（能量函数 / 李雅普诺夫方法）

这是教师讲的**第二类经典方法**：不求全部特征根，而是**构造一个能量函数**来判断稳定。

### 7.1 基本思想与「充分非必要」

- 构造一个**能量函数**来反映电力系统的暂态特征，用它判断暂态稳定。
- **关键性质**：找到这样的能量函数，**可以证明系统稳定**；但**找不到，不能说明系统就不稳定**——所以它是**充分条件，不是必要条件**。教师反复强调了三遍这个「充分但非必要」。
- 判据形式（教师口述）：若存在一个**正定**的函数，且沿轨线的**导函数非正定（半负定）**，则系统稳定；这样的函数称为**李雅普诺夫函数**。

### 7.2 正定与负定的直观含义

- **正定**（教师用系数打比方）：无论哪个分量增大或变化，能量都**逐渐增大**（发散）；
- **负定**：无论哪个分量怎么变，总能量都在**减少**（耗散）——这正是稳定系统该有的样子。

### 7.3 李雅普诺夫与拉萨尔

| 定理 | 要求 | 差别 |
| :--- | :--- | :--- |
| **李雅普诺夫定理** | 函数正定（各项系数都**大于 0**） | 条件更**保守** |
| **拉萨尔（LaSalle）定理** | 只要求**非负定**（各项系数**大于等于 0**） | 在李雅普诺夫基础上**放宽**了正定要求 |

### 7.4 稳定域与临界能量

- 求解**稳定域** ⟺ 构造满足该原理的**能量函数**；求解**稳定边界** ⟺ 确定该能量函数的**临界能量**。
- **临界能量的取法**：最初取**稳定平衡点周围所有不稳定平衡点中能量最低点**的能量作为临界能量。缺点：平衡点多时**计算量最大**，而且分析结果**非常保守**。
- 后来的发展方向：考虑故障与系统实际（故障前后比例、转移电导的变化）→ **主导不稳定平衡点法（BCU）**，被认为是最有效的暂态能量函数方法之一；还有结合四种界面法等方法。
- **另一条路线：基于非线性动力学稳定边界的拓扑方法**——把稳定域边界描述为**所有不稳定平衡点的稳定流形的并**，不依赖能量函数、通用性强，适用于一般非线性动力系统。

### 7.5 这个方法的缺点（教师逐条列）

- 能量函数的形式**非常复杂**，目前**没有统一的构造方法**；因此只能用于一些**较简单的系统**，复杂系统很难找到满足条件的能量函数。
- 早期能量函数里发电机一般用**经典二阶模型**，且**不考虑调速器的动态**；随着研究推进，高压直流输电模型、带调控器的三级发电机模型、考虑负荷动态的模型等被逐个加进能量函数——**每加一个新模型都要构造一个相应的能量函数**，难度剧增，这「限制了能量法则的发展」。
- 教师由此再次回到主线：**发展人工智能与云计算是必由之路**。

### 7.6 顺带讲清的几个概念

- **自治系统**：控制理论里的概念——**没有输入、没有输出的系统**，是一个理想化的系统；用数学表示就是对应**齐次**的微分方程。教师打的比方是：一个没有外界干扰、没有激励、完全**自发**行为的人。加了输入/激励就不是自治系统了。**电力系统经过适当假设与建模，可以看成一个非线性自治系统**。
- **平衡点与平衡集**：动态过程分三个阶段——
  1. **故障前**：系统运行于**稳定平衡**（所有运行点构成的集合叫稳态平衡点，简称平衡集）；
  2. **扰动过程中**：离扰动近的发电机组**电磁功率突然减少**，而**机械功率基本不变**，于是机械功率与电磁功率不平衡，**转子开始加速**；
  3. **扰动后（故障切除后）**：作用于系统的外力消失，系统重新成为封闭系统，扰动过程中积累的能量开始释放。
  - 因此，**判断扰动后系统是否稳定的本质，是判断最后一次扰动清除后系统状态能否回到稳定平衡点**。
- **局部线性化与特征根**（与第 3 节呼应）：在平衡点处做局部线性化得到线性状态空间方程，再求其矩阵的特征根来判稳。

## 8. 第三类：基于故障后系统响应的方法

- **思路**：直接用**故障后系统的实际轨迹/时间响应**判断稳定性，例如看**故障电流**是衰减还是发散。
- **成熟条件**：随着**广域测量系统**（WAMS）日益成熟，利用故障后的实际量测信息，可以与仿真法、直接法**结合**改进传统方法：
  - 用**故障切除时刻的量测量**替代故障的数值计算点，既省下巨大成本，又让数据更接近真实；
  - 广域信息包含全局、实时的海量信息，从中**选取能反映暂态稳定特性的量测信息**，再结合事先设定的**稳定判据**判别。
- **可用于判稳的曲线**（教师列举）：功率特性曲线、发电机转速曲线、转速差与功率差的变化曲线等。

## 9. 第四类：数据挖掘与机器学习（大数据、人工智能）

- **为什么走这条路**（教师把前两条路一起否了）：时域仿真法**太慢、不利于在线**；直接法只能判断平衡点附近，也很困难。「那怎么办？靠信息技术了。」
- **技术条件已经具备**：电力系统已积累**海量的一线仿真数据**，计算机性能大幅提升；机器学习、神经网络、专家系统属于人工智能的高层次发展阶段。
- **典型流程**（对应教材第 9 页图 1-1，图未附）：**离线仿真 → 实时评估**——把离线仿真的计算结果与系统实测数据一起构成数据库，做**特征分析**与**模型**训练，得到**稳定判别模型/预测模型**，最后给出评估结果。**优点是不占用在线计算**。
- 20 世纪 80 年代起研究者在该领域做了大量工作：输入特征选择、特征分析算法、评估模型算法、输出等环节。
- **教师对 AI 的清醒提醒（本讲出现两次）**：人工智能算法**都是近似计算，不是精确的**，有时算出来的解**根本不对**（异常模式）；因此算完可能还要**筛选**。「这也是为什么必须发展人工智能和云计算」——是必由之路，但不是万能。
- 教师把**基于数据挖掘**的方法划为**当前研究热点**，前面几种（仿真、直接法、基于响应）都是**经典方法**。

## 10. 紧急控制决策方法

教师说，**评估的目的是用于控制**。

- **集中式控制决策**：由**控制中心下发**紧急控制措施，以**尽可能小的代价**使故障后的系统**尽快恢复稳定**。教师顺带讲到我国的停电时间在全世界属于最短、可靠性最高（**课堂叙述，未核实**）。
- 离线决策 vs 实时紧急控制决策：实时决策对**计算速度**的要求更高，于是有了下面三类「可行研究方向」。

| 方法 | 做法要点 |
| :--- | :--- |
| **启发式方法** | 通过**少量仿真**寻找控制方案，避免大量的仿真搜索；用指标排序（如切机切负荷的有效性指标）来决定控制动作，显著降低空间复杂度 |
| **基于响应的方法** | 直接利用 **PMU** 采集的故障后动态量测，避免复杂的时域计算；例如用发电机转速轨迹预测稳定性，若判为不稳定，先把系统**等效为两机模型**，用**加速面积与减速面积**计算切机/切负荷量。教师强调它**不需要复杂的计算**，可直接在线计算 |
| **基于安全域/稳定域的方法** | 通过**切机、切负荷**等措施**改变稳定边界**，把运行点从域外移回域内；控制措施引起的**边界移动可近似线性叠加**；研究过切机切负荷**时刻**对边界外移距离的影响，并对多摆系统提出**最优时间切机控制策略** |

- **局限**（教师指出的）：基于响应的方法效果与「简化、等值」的过程关系很大；基于安全域/稳定域的方法，效果**很大程度上依赖算法对安全域/稳定域描述的准确程度**。
- **灵敏度**：即**参数的一阶导**（教师举例：电流对负载电阻的灵敏度，衡量电流受该电阻影响的大小）。利用灵敏度建立**优化模型**（目标函数最小，属动态规划），**计算量与备选控制措施的数量无关**——只需**两次积分/两次仿真**即可求得，因此可以大幅减少仿真搜索。
- **切机与切负荷是什么**：切机＝切除发电机（不让它发电），切负荷＝把负荷摘掉；教师说这两件事本质上是**调频**手段——用电高峰或低谷时发电机要投入或切除。

## 13. 给同学的复习顺序

1. **先分清两组「三个方法」**（第 2、10 节，教师点名说考试易混）：**稳定性评估**——时域仿真法、直接法（能量函数/李雅普诺夫）、基于故障后响应、数据挖掘（后两类是发展中的方向）；**紧急控制决策**——启发式、基于响应、基于安全域/稳定域。**两组不要串**。
2. **安全域的两种类型**（第 3 节）：静态→代数方程（平衡态）；动态→微分/差分方程 + 代数方程。记住动态安全域的性质（连通、无空洞、边界连续可微、不缠绕交错）与线性系统的**叠加性判据**。
3. **判稳的工具箱**（第 3、7 节）：特征根实部是否全为负；局部线性化在平衡点处做；平衡点/平衡集三个阶段的物理图像（故障前、扰动中转子加速、扰动后能量释放）。
4. **时域仿真法**（第 6 节）：把链条背下来——元件模型 → 等效物理模型（基尔霍夫定律）→ 微分代数方程组 → 数值求解 → 时间响应 → 功角曲线判稳；记牢**精度高但不能在线**，以及**3–5 秒 / 15–20 秒**的时间区间；记住**数据中心**的意义。
5. **分布式并行计算的三个方向**（第 6.5 节）：时间并行、空间并行、波形松弛——教师明确要求记住。
6. **直接法**（第 7 节）：能量函数的**充分非必要**；李雅普诺夫（正定）与拉萨尔（非负定）的差别；临界能量的取法与其保守性；BCU 与拓扑法各自的思路；以及**每加一个模型就要重造能量函数**这个致命短板。
7. **为什么必须上大数据与 AI**（第 6.4、9 节）：仿真法慢且不能在线、直接法只能用于简单系统且难构造 → 离线仿真数据 + 机器学习做实时评估；同时记住教师两次强调的「**AI 是近似计算，可能算错，还要筛选**」。
8. **紧急控制**（第 10 节）：三类方法各自的做法；**灵敏度＝参数的一阶导**，用它能只用两次仿真就建优化模型；切机/切负荷是什么、为什么要动边界。
9. **别提前背第二章及以后**（第 11 节）：本讲没有教材页面、没有公式推导、没有作业；等材料到了再整理，避免照抄不存在的板书。
