# 电力大数据与人工智能 2026-09-22：暂态稳定评估方法与紧急控制决策

**这节课在干什么**（第二讲）：把第一讲的概念推到「**怎么算**」——安全域用什么方程描述、稳定性用什么判据、经典的两类计算方法各有什么死穴。**主线一句话**：传统算法在**规模**面前算不动（设备越多 → 节点越多 → 方程阶数越高 → 解析计算「是不现实的，也是不可能的」），所以大数据与人工智能不是外加的花样，而是**被迫上的**；但 AI 也不万能（下面会看到教师两次提醒）。

**行政与考核**（教师当堂口头说明，**以正式考核文件与学习通为准**）

- **选择题要动笔算**：教师原话「考试考一些选择题……选择题的地方要多算一点」——不是背概念，要算。
- **考试最容易混的一处**：**两组「三个方法」要分清**——「**稳定性评估**」的三个方法与「**紧急控制**」的三个方法，教师说「到时候考试的时候很容易」混。
- 教师讲完紧急控制三类方法后有一句「也是……我们不考主体」，**原句残缺**（疑为「不考大题」），**不作结论**，见校对层待办。

## 没编号但讲了的知识点

### 安全域：静态与动态

**安全域是什么**：由**数学方程定义的一个范围**（安全范围）。教师说现阶段**不要求**用数学去求解，知道「安全是怎么回事」即可。

| 类型 | 用什么方程描述 | 说明 |
| :--- | :--- | :--- |
| **静态安全域** | **代数方程**（组） | 描述**平衡态**，完全没有动态的微分／差分方程 |
| **动态安全域** | **两类方程** | 动态的**微分方程或差分方程**（用状态参数描述）＋代数方程 |

- **动态安全域的性质**（教师列举）：内部**连通**、没有空洞、**可微**（边界连续）、安全域与边界不缠绕交错、不存在扭曲；**同一种失稳模式下**对应的局部边界连续。他说这是专业性概念，由「有限的失稳子模式表面的定义共同决定」。
- **线性系统的叠加性**：安全边界具有**线性叠加性**，「所有线性系统都满足」；判定一个系统是否线性，看是否满足**叠加原理**——满足即线性，不满足即非线性（例子是电阻 + 电容／电感的简单电路）。
- **稳定性判据**（复习第一讲）：用状态空间模型的特征方程看**特征根**——**全部实部小于 0 → 稳定**；**只要有一个实部不小于 0 → 失稳**。
- **局部线性化**：电力系统是非线性系统，但在平衡点的**无穷小邻域**内可以线性化（教师用圆周运动打比方：在轨道某点作**切线**，局部就是线性的）→ 写出该点的线性状态空间方程，再判这个微小扰动是否稳定（同样看特征根）。
- **规模问题**（本讲反复出现的引子）：维数高、节点多（教师用「一个宿舍楼就是一个节点」打比方），特征根多到**无法手算**——「怎么办？人工智能」。

### 物理参数与状态参数

教师说这块**「有个认识就可以了，不用深究」**，但它解释了数据从哪来。

| 类别 | 又叫 | 内容 | 来源 |
| :--- | :--- | :--- | :--- |
| **物理参数** | 结构参数 | 描述物理结构：交流电机的电感、电抗、互感，铁心磁性能 | 各类**传感器**测得（声、光、温等）——教师原话「这些都是大数据」 |
| **状态参数** | 状态变量 | 描述状态连续变化的量：**电流、电压、功率、频率** | 由系统运行状态决定 |

**两类参数共同表示能量**：线性电路里电感储能 $\frac12Li^2$、电容储能 $\frac12Cu^2$——一个能量同时由**物理结构参数**与**状态参数**表达。（教师提示这一周会有另一位专业老师把结构建模的内容上线到学习平台，到时再补。）

### 潮流与雅可比矩阵

- **潮流**＝**功率分配**（不要被词吓住）：网络与发电机之间有**潮流交换**。
- **雅可比矩阵**：潮流计算里用到的矩阵（转写读成「压缩机」）——知道它出现在**潮流／节点电压计算**里即可，**简化节点电压计算**是它的用途之一。

### 时域仿真法（第一类经典方法，讲得最细）

**做法（一条完整链条）**：

1. 建立电力系统**所有元件**的模型：原动机（驱动发电机的旋转机械）、发电机、电力网络、负荷；
2. 由**物理定律**写等效物理模型——教师点名**基尔霍夫电流定律与电压定律**（KCL/KVL）；
3. 写出**数学模型**：一组**微分代数方程组**；
4. 用数字计算工具**求解大规模微分代数方程组**；
5. 得到故障前后**状态变量与代数变量的时间响应**；
6. 由**发电机相对功角曲线**的收敛／发散判稳；若某台（或多台）机组与其余机组的功率差超过某个**阈值**就是失稳（阈值「由研究人员的经验判断」）。

**方程结构**（教师特别强调）：**微分／差分方程**描述动态，是**目标（函数）**；**代数方程**描述**平衡态**，是**约束条件**——两类合起来才构成求解问题。

**判稳的时间区间**：通常看**扰动结束后 3–5 秒**；对有**潜在区间震荡模式**的大型系统可延长到 **15–20 秒**（转写此处把单位写成「年」，见转写与术语）。

**优点与致命缺陷**：**精度高**，长期是检验其他判据的**标准**；但**计算量巨大**（规模一大「在有限时间内算不出结果」），更致命的是**不能在线**——只能在**离线**算好，不满足在线暂态评估要求。由此引出两件事：① **数据中心**（发电站、变电站、换流站都要建，为的是**提高响应与计算速度**）；② 两条提速路线。

**两条提速路线**：

- **用简化模型换速度**：但不能一味求简——「求解出来了跟实际的系统相差十万八千里，没有指导意义」，要在**逼近真实**与**保证快速性**之间折中。
- **分布式并行计算**（最高形式是**云计算**：不卖服务器、只卖服务，分解单节点的复杂度与压力）。**三个研究方向（教师要求记住）**：

| 方向 | 做法 |
| :--- | :--- |
| **时间并行算法** | 把微分方程**差分化（离散化）**后与代数方程**联立求解**，可保持严格**牛顿法**的收敛性 |
| **空间并行算法** | 把大系统按物理分布**分成若干子网**，各子网分别单独计算 |
| **波形松弛算法** | 把大系统拆成若干小系统，用**不同子系统间的交替迭代**计算，每个子系统可多次计算 |

**结论**：算法与设备都在进步，但**规模庞大时仍不满足实时要求**——「只能说用 AI 了」「只能采用云计算和人工智能」。

### 直接法（能量函数 / 李雅普诺夫方法）

第二类经典方法：**不求全部特征根，而是构造一个能量函数**来判断稳定。

- **充分非必要**（教师反复强调三遍）：**找到**这样的能量函数**可以证明系统稳定**；**找不到**不能说明系统不稳定。
- 判据形式（教师口述）：若存在**正定**函数，且沿轨线的**导函数非正定（半负定）**，则系统稳定；这样的函数称**李雅普诺夫函数**。
- **正定／负定的直观含义**：**正定**——无论哪个分量变化，能量都逐渐**增大**（发散）；**负定**——总能量都在**减少**（耗散），这正是稳定系统该有的样子。
- **两个定理的差别**：**李雅普诺夫定理**要求函数**正定**（各项系数都大于 0），条件更**保守**；**拉萨尔（LaSalle）定理**只要求**非负定**（系数大于等于 0），是在李雅普诺夫基础上**放宽**了。
- **稳定域与临界能量**：求**稳定域** ⟺ 构造满足该原理的**能量函数**；求**稳定边界** ⟺ 定该函数的**临界能量**。
  临界能量最初取「稳定平衡点周围所有**不稳定平衡点中能量最低点**的能量」——缺点是平衡点多时**计算量最大**
  且结果**非常保守**。后来的方向：**主导不稳定平衡点法（BCU）**（被认为是最有效的暂态能量函数方法之一），
  还有结合四种界面法等方法；另一条路线是**基于非线性动力学稳定边界的拓扑方法**——把稳定域边界描述为
  **所有不稳定平衡点稳定流形的并**，不依赖能量函数、通用性强。
- **缺点（教师逐条列）**：能量函数形式**非常复杂**、目前**没有统一的构造方法**，只能用于**较简单的系统**；早期发电机用**经典二阶模型**、**不考虑调速器动态**，随着 HVDC 模型、带调控器的三级发电机模型、考虑负荷动态的模型逐个加进来——**每加一个新模型都要重造一个能量函数**，难度剧增，「限制了能量法则的发展」。→ 又回到主线：**发展 AI 与云计算是必由之路**。

**顺带讲清的概念**：

- **自治系统**：**没有输入、没有输出**的系统（理想化；数学上对应**齐次**微分方程）。比方是「一个没有外界干扰、没有激励、完全自发行为的人」；加了输入／激励就不是自治系统。**电力系统经适当假设与建模可看作非线性自治系统**。
- **平衡点与平衡集**：动态过程分三段——① **故障前**：运行于**稳定平衡**（所有运行点构成**平衡集**）；
  ② **扰动过程中**：离扰动近的机组**电磁功率突然减少**而**机械功率基本不变** → 功率不平衡 → **转子开始加速**；
  ③ **扰动后（故障切除后）**：外力消失，系统重新成为封闭系统，扰动中积累的能量开始释放。
  **所以判断扰动后稳不稳，本质是判断最后一次扰动清除后系统能否回到稳定平衡点**。

### 第三类：基于故障后系统响应的方法

- **思路**：直接用**故障后系统的实际轨迹／时间响应**判稳，例如看**故障电流**是衰减还是发散。
- **成熟条件**：随着**广域测量系统（WAMS）**成熟，用故障后的实际量测可以与仿真法、直接法**结合**改进传统方法——用**故障切除时刻的量测量**替代故障的数值计算点，既省成本又更接近真实；从广域信息的海量实时信息里**选取能反映暂态稳定特性的量测信息**，结合事先设定的**稳定判据**判别。
- **可用于判稳的曲线**：功率特性曲线、发电机转速曲线、转速差与功率差的变化曲线等。

### 第四类：数据挖掘与机器学习（大数据、人工智能）

- **为什么走这条路**（教师把前两条一起否了）：时域仿真法**太慢、不利于在线**；直接法只能判平衡点附近，也很难。「那怎么办？靠信息技术了。」
- **技术条件已具备**：已积累**海量一线仿真数据**，计算机性能大幅提升；机器学习、神经网络、专家系统属人工智能的高层次发展阶段。
- **典型流程**（教材第 9 页图 1-1，图未附）：**离线仿真 → 实时评估**——离线仿真结果与实测数据一起构成数据库，做**特征分析**与**模型**训练，得到**稳定判别／预测模型**，最后给出评估结果。**优点是不占用在线计算**。
- 20 世纪 80 年代起研究者做了大量工作：输入特征选择、特征分析算法、评估模型算法、输出等环节。
- **教师对 AI 的清醒提醒（本讲出现两次）**：AI 算法**都是近似计算，不是精确的**，有时算出来的解**根本不对**（异常模式），因此算完可能还要**筛选**。——是必由之路，但不是万能。
- 教师把**基于数据挖掘**的方法划为**当前研究热点**，前面几种（仿真、直接法、基于响应）都是**经典方法**。

### 紧急控制决策方法（评估的目的是用于控制）

- **集中式控制决策**：由**控制中心下发**紧急控制措施，以**尽可能小的代价**让故障后的系统**尽快恢复稳定**。教师顺带讲到我国停电时间在全世界最短、可靠性最高（**课堂叙述，未核实**）。
- 离线决策 vs **实时**决策：实时对**计算速度**要求更高，于是有下面三类「可行研究方向」。

| 方法 | 做法要点 |
| :--- | :--- |
| **启发式方法** | 用**少量仿真**找控制方案，避免大量仿真搜索；用指标排序（如切机切负荷的有效性指标）决定控制动作，显著降低空间复杂度 |
| **基于响应的方法** | 直接用 **PMU** 采集的故障后动态量测，避免复杂时域计算；例如用发电机转速轨迹预测稳定性，若判为不稳定，先把系统**等效为两机模型**，用**加速面积与减速面积**算切机／切负荷量。教师强调**不需要复杂计算**、可直接在线算 |
| **基于安全域／稳定域的方法** | 用**切机、切负荷**等措施**改变稳定边界**，把运行点从域外移回域内；控制措施引起的**边界移动可近似线性叠加**；研究过切机切负荷**时刻**对边界外移距离的影响，并对多摆系统提出**最优时间切机控制策略** |

- **局限**：基于响应的方法效果与「简化、等值」过程关系很大；基于安全域／稳定域的方法**很大程度上依赖算法对安全域／稳定域描述的准确程度**。
- **灵敏度＝参数的一阶导**（教师举例：电流对负载电阻的灵敏度，衡量电流受该电阻影响的大小）。用灵敏度建**优化模型**（目标函数最小，属动态规划），**计算量与备选控制措施数量无关**——只需**两次积分／两次仿真**即可求得，能大幅减少仿真搜索。
- **切机与切负荷**：切机＝切除发电机，切负荷＝把负荷摘掉；本质是**调频**手段（用电高峰或低谷时发电机要投入或切除）。
