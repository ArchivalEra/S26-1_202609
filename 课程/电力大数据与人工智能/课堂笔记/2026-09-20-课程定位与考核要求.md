# 电力大数据与人工智能 2026-09-20：考核要求、课程地图与安全稳定基本概念

**这节课在干什么**（开课第一讲）：讲三件事——**这门课怎么考**（考核与课堂要求）、**这门课要学什么**（八章地图），以及**这门课处理的对象**：电力系统的安全稳定。第三部分是本次课唯一的概念硬核，从「平衡态与扰动」讲到「特征值判据」，再落到**安全域**这个核心概念。教师反复强调的动机链是：**人工判不了 → 所以要智能分析**。

**行政与考核**（教师当堂口头说明，**以课程正式考核文件与学习通发布为准**）

- **开卷考试，只允许带教材**；教室内不得使用手机，带手机按作弊处理。
- **成绩构成：平时成绩 50% + 卷面成绩 50%**，平时成绩含课堂表现。
- **考勤**：旷课一次扣 20 分；**旷课四次取消全部平时成绩**；**旷课五次取消考试资格**（教师原话「考满分也过不了」）。
- **没有期中考试**。**第 17 周上完课当天考试**；最后两节课总复习并练计算题；教师说**不考原题**。
- **作业约五次**，用最简单的作业本（不要单张纸、不要厚本子）；算法类题课上先带着练一遍。
- **题型**：转写能确认的是名词解释、判断、简答、计算/算法题；**是否含选择题转写被噪声打断，不能确认**。
- **考点提示（最有价值的一条）**：名词解释与简答**集中在三处「现状」**——「电力系统安全性分析的现状」「电力系统暂态稳定评估方法的现状」「紧急控制决策方法的研究现状」，教师在课件里专门点了位置。

### 数据链与「为什么必须用智能分析」

**数据链**（第 3 章以后都挂在这条线上）：

**采集 → 预处理（采集、存储、传输、计算）→ 特征选择／特征提取 → 辨识 → 执行（决策）**

- **在线／离线／实时**：在线＝即采即用（采到就算、算完马上出结果）；实时强调延迟短（教师用下单、订餐、看视频类比）。
- **数据丰富但信息贫乏**：海量数据里哪些有用要靠**数据挖掘与可视化**转成信息与知识。
- **目标形态**：教师转述教材思路——用数据挖掘与 AI 学出稳定规则，故障后**快速、准确**评估稳定性，给调度控制提供决策依据；他的说法是「建立一个经验丰富的**机器调度员**」。
- **调度指令**是在分析运行实时数据之后生成的，不是凭空发出的。

**人工做不了的四条理由**：① 数据量激增；② 电网复杂化（联网范围扩大、电压等级提高、受控元件剧增、控制模式难协调）；③ 设备老化损坏带来隐患，极端环境（深海、太空、火星探测）排查人工做不到；④ **大停电的机理链**——事故初期调度中心无法迅速预判并及时干预 → 暂态稳定被破坏 → 易发展成连锁故障 → 大面积停电。

**四个「不及时」**：不能及时发现、不能及时传输、不能及时计算、不能及时处理——这正是要靠大数据与 AI 去补的环节。

**建模的两难**（教师反复强调的一对矛盾）：专业方法本质都是**建模**（物理模型 → 按物理定律列方程 → 数学模型）。
**模型越精确、计算越复杂**，精确到一定程度计算量大到不现实，所以要在**准确性**与**快速性**之间权衡。
传统理论计算的结果**过于保守**（教师解释「保守」＝约束条件苛刻、限制多，类比「一套班规只适用于本班」），
既不利于电网高效稳定运行、也不利于未来规划——**这就是引入 AI 与大数据的原因**。

### 安全稳定的概念群：平衡态、扰动与特征值判据

- **平衡态**：教师用匀速直线运动类比（加速度为零就是平衡）；推广到振动情形要靠**复数**描述（实部＋虚部）。
- **扰动**：参数或负荷的变化。他的例子是一个简单电路里可变的电阻——**微小**变化（如增加 0.01 Ω）是**小扰动**，从 1 Ω 变到 100 Ω 这种大幅变化是**大扰动**。「记得一个变化我们就叫做扰动」。
- **二阶系统**：一个电感加一个电容（两个储能元件）就是二阶系统，动态方程是二阶微分方程——用它引出下面的判据。

**特征值判据**：把运动写成 $\lambda=\sigma+j\omega$（$\sigma$ 实部、$j\omega$ 虚部）——

| 虚部 | 实部 | 运动形态 | 稳定性 |
| :--- | :--- | :--- | :--- |
| $\omega=0$ | — | 非振荡（教师说「直线运动」） | 看实部 |
| $\omega\neq0$ | — | 振荡（教师用圆周运动类比） | 看实部 |
| 任意 | $\sigma<0$ | 收敛、振幅越来越小 | **稳定** |
| 任意 | $\sigma>0$ | 发散、振幅越来越大 | **不稳定** |
| 任意 | $\sigma=0$ | 临界 | 教师未展开 |

- 教师用**弹簧加阻尼**类比 $\sigma<0$：阻力让振幅越来越小，直到停下 → 收敛。
- **稳定性的定义来自李雅普诺夫**（教师称他既是数学家也是物理学家），本课程用的稳定性定义就是他提出的。
- 他把特征值叫「运动的特征」，本课程的做法就是**用运动的特征去分析运动本身**。
- 由特征值区分出三类考察角度：**静态稳定约束、小扰动稳定、暂态（大扰动）稳定**。

> 整理者说明：$\lambda=\sigma+j\omega$ 这套记号按通用写法补的；转写里教师只用「实部」「虚部」口语表述，未见板书公式。

### 稳定性评估方法、安全域与安全裕度

**两类基本方法**：**数值法**（教师口语叫「终点法／驻点法」，同音用字待核实）——按指定运行方式、固定故障下用数字计算近似求解，近似且规模越大代价越高；**解析法**——求解析表达式（他举 $y=ax^2+bx+c$），**精确**但规模大时求不出，只适合小规模简单系统。**结论**：规模越大越只能走数值路线，而数值路线复杂度又随规模上升，所以最终**不得不借助 AI 与大数据**。

**暂态稳定评估的三种具体方法**：① **仿真计算法**（后文常用工具，教师要求自行安装 **MATLAB**，约 30 GB，说下学期三门专业课都要用）；② **直接法**（定性分析，用李雅普诺夫方法，回到「特征值实部是否小于零」）；③ **故障响应法**（直接看波形：故障电流幅值越来越小、衰减到零 → 稳定；越来越大、发散 → 不稳定。教师说这个方法**直观**）。

**安全域**：能够在**预想故障**下保证系统安全稳定运行的**运行点的集合**。教师说这是**名词解释的考点**，提醒「考试时一定要找到位置」。

- 按保证的性质分：**静态安全域**、**电压稳定安全域**、**小扰动稳定安全域**、**动态安全域**（保证暂态稳定）；实际电网要运行在这些域构成的**综合安全域**内。
- **为什么研究它**：拿到边界后，域内的运行点在预想故障下都能稳定、域外会出问题 → **在线安全评估变得方便**；第二个用处是给出运行点到边界的**距离**，即**安全裕度**与最优控制信息，实现预防控制与安全预警。
- **参照概念**：下学期《自动控制原理》里的**稳定裕度**（含**幅值裕度**与**相角裕度**两个由频率分析得到的指标，转写误识别成「扶持力度／向导力度」，此处按标准术语补正）。只需了解概念。
- **动态安全域的三个性质**（教师明确说**不在考试范围**）：内部连通且稠密；边界连通、不缠绕交错；边界可微。他还提到文献证明动态安全边界可表示成**超平面叠加**的形式。
- **求解动态安全域**：有两类方法，转写只说清了其中一类是解析法（见校对层待办）。

**稳态分析与暂态分析的区分**：

| 分析类型 | 方程类型 | 本课程要求 |
| :--- | :--- | :--- |
| 稳态分析（用相量／复数表示，相当于微分项为零） | **代数方程** | **只要求会解代数方程** |
| 暂态／动态分析（量随时间变化） | **微分方程**（连续）或**差分方程**（离散） | 难度大，只要求有概念、不要求解 |

暂态再细分：**机电暂态**——原动机与发电机之间的过程（水轮机、汽轮机、风力机驱动发电机）；**电磁暂态**——单纯研究电力系统内部的电磁过程（如故障本身）。现阶段主要学机电暂态，且电网具有**特高维度**。
