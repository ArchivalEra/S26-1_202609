## 2026-09-20 ｜ 课程定位、安全稳定概念群

### 考点：为什么必须用智能分析（数据链论证）

**要会**：把这条链条讲出来。

**链条**：电力系统**规模大、状态量多** → 传统方法**算不过来** → 所以要**把数据变成可用于决策的信息** → 用智能分析。
教师强调这是全课的动机，第一讲、第二讲、第三讲各出现一次，**答题时先写它**。

**容易记混**：这条是**动机**不是**方法**——别和后面「四个评估方法」答成一回事。

[笔记原文 ↗](./课堂笔记/2026-09-20-课程定位与考核要求.md#数据链与-为什么必须用智能分析)

### 考点：稳定的判据是特征值

**要会**：一句话判据。

- 系统状态由**特征值实部**判：**实部 < 0 稳定**（实部 = 0 临界，实部 > 0 失稳）。
- 与之配套的两个概念：**平衡态**（系统稳定运行的点）、**扰动**（打破平衡的外来作用）。

**容易记混**：判据看的是**实部**（不是模、不是虚部）——虚部只管**振荡频率**。

[笔记原文 ↗](./课堂笔记/2026-09-20-课程定位与考核要求.md#安全稳定的概念群-平衡态-扰动与特征值判据)

### 考点：安全域与安全裕度

**要会**：两个定义各一句。

- **安全域**：状态空间里**「安全的那些点」构成的区域**。
- **安全裕度**：**当前运行点离安全域边界的距离**。
- 细分：**静态安全域**（看潮流约束）与**动态安全域**（看暂态约束）。

**容易记混**：**安全域是「区域」，裕度是「距离」**——一个是集合、一个是数，别答反。

## 2026-09-22 ｜ 暂态稳定评估方法与紧急控制

> **本讲最容易混的地方**：有**两组**方法，一组 4 个（评估）、一组 3 个（控制），**别答串**。

### 考点：评估的四个方法（按出现顺序）

**要会**：四个方法的名字 + 每个的一句话特征 + 为什么被淘汰/保留。

| # | 方法 | 一句话 | 关键点 |
| :-: | :--- | :--- | :--- |
| 1 | **时域仿真法** | 建全元件模型、解微分代数方程组、看功角曲线 | **精度最高**（其他方法的标准），但**不能在线** |
| 2 | **直接法**（能量函数/李雅普诺夫） | 构造能量函数判稳，不求特征根 | **充分非必要**——找不到函数**不能**说系统不稳 |
| 3 | **基于故障后响应** | 直接用故障后实际轨迹判（如故障电流衰减/发散） | 靠 **WAMS/PMU** 实测，可与前两种**结合** |
| 4 | **数据挖掘与机器学习** | 离线仿真建库 → 训练模型 → 在线评估 | **当前研究热点**；AI 是**近似计算、可能算错、要筛选** |

**AI 方法（第 4 类）单独记一句**：它是**近似计算、可能算错、还要筛选**——**不能盲信**。
教师把基于数据挖掘的方法划为**当前研究热点**，前三种都是**经典方法**。

**容易记混**：前三类叫**经典方法**，第 4 类才是**热点**；**时域仿真「不能在线」是本讲反复出现的理由**——
数据中心、并行计算、AI 全是为了解决它。

[笔记原文 ↗](./课堂笔记/2026-09-22-暂态稳定评估方法与紧急控制.md#时域仿真法-第一类经典方法-讲得最细)

### 考点：时域仿真法的两条提速路线

**要会**：说出两条路线，以及并行计算的**三个研究方向**。

- **路线一：用简化模型换速度**——但不能一味求简（差太远就「没有指导意义」）。
- **路线二：分布式并行计算**（最高形式是**云计算**）。**三个研究方向（教师要求记住）**：
  1. **时间并行算法**——微分方程差分化后与代数方程联立求解；
  2. **空间并行算法**——大系统按物理分布**分成子网**各自算；
  3. **波形松弛算法**——拆小系统、**子系统间交替迭代**。

**关键数字**：判稳通常看**扰动结束后 3–5 秒**；有潜在区间震荡模式的大系统可延长到 **15–20 秒**。

**容易记混**：**微分方程描述动态＝目标，代数方程描述平衡态＝约束**——两类合起来才构成求解问题。

[笔记原文 ↗](./课堂笔记/2026-09-22-暂态稳定评估方法与紧急控制.md#时域仿真法-第一类经典方法-讲得最细)

### 考点：直接法（能量函数）的三个要点

**要会**：充分非必要、两个定理的差别、为什么发展不下去。

- **充分非必要**（教师强调三遍）：**找到**能量函数可**证明稳定**；**找不到不能**说明不稳定。
- **两个定理的差别**：**李雅普诺夫定理**要求函数**正定**（系数都 > 0，条件更保守）；
  **拉萨尔（LaSalle）定理**只要求**非负定**（≥ 0，是放宽）。
- **发展不下去的原因**：能量函数**没有统一构造方法**，只能用于较简单系统；
  **每加一个新模型（HVDC、三级发电机、负荷动态）就要重造一个能量函数** → 又回到「发展 AI 与云计算是必由之路」。

**容易记混**：**正定**＝能量逐渐增大（发散）；**负定**＝总能量减少（耗散，稳定系统该有的样子）。

[笔记原文 ↗](./课堂笔记/2026-09-22-暂态稳定评估方法与紧急控制.md#直接法-能量函数-李雅普诺夫方法)

### 考点：紧急控制的三个方法（与评估组分开记）

**要会**：三个方法的名字 + 各自做法要点。

| # | 方法 | 做法要点 |
| :-: | :--- | :--- |
| 1 | **启发式方法** | 用**少量仿真**找方案，靠指标排序（如切机切负荷有效性指标）降复杂度 |
| 2 | **基于响应的方法** | 直接用 **PMU** 量测；判不稳时把系统**等效为两机模型**，用**加速/减速面积**算切机切负荷量 |
| 3 | **基于安全域/稳定域** | 用**切机切负荷**改变稳定边界，把运行点从域外移回域内；边界移动**可近似线性叠加** |

**关键概念**：**灵敏度 = 参数的一阶导**（如电流对负载电阻的灵敏度）。用灵敏度建优化模型，
**计算量与备选措施数量无关**——只需**两次积分/仿真**。

**容易记混**：**切机＝切除发电机，切负荷＝摘掉负荷**，本质都是**调频**手段。
三个方法各自的局限：启发式靠少量仿真、响应法依赖「简化等值」、安全域法依赖「域描述准不准」。

[笔记原文 ↗](./课堂笔记/2026-09-22-暂态稳定评估方法与紧急控制.md#紧急控制决策方法-评估的目的是用于控制)

## 2026-09-29 ｜ 电力大数据特点与人工智能算法

> **本讲教师按考试题型讲，条条对着考点**——下面是逐条。

### 考点：大数据 4V 特点（判断题陷阱）

**要会**：四个 V 的中英文 + **Value 的正确含义**。

| V | 中文 | 含义 |
| :--- | :--- | :--- |
| **Volume** | 规模大 | 发输变配用调度各环节长期积累，且爆炸式增长 |
| **Variety** | 多样性 | **结构化 / 半结构化 / 非结构化**三类并存 |
| **Velocity** | 速度快 | 实时系统，异常要**立即切除**，响应要快 |
| **Value** | 价值 | **潜在价值巨大，但价值密度低、藏在海量数据中，需要挖掘** |

**关键数字**：数据量 GB → TB → PB → EB → ZB → YB，**每级差 3 个数量级**（$10^3$ 倍）。

**容易记混**：**value 不能简单译成「价值高」**——正确含义是**价值密度低、潜在应用价值巨大**。
这是判断题专门设的坑。

[笔记原文 ↗](./课堂笔记/2026-09-29-电力大数据特点与人工智能算法.md#电力大数据的来源与特点-4v)

### 考点：数据结构的三种类型（选择题）

**要会**：三种结构类型各举一例。

- **结构化**：能装进关系数据库表格的（如电表读数表）。
- **半结构化**：有标签但不严格（如 XML、JSON 报文）。
- **非结构化**：图片、视频、音频、文本等。

**容易记混**：教师说**按结构类型分是三种**（书上有五种分法，本课**只按这三种考**）。

### 考点：两类数据来源（电网分析计算，选择题）

**要会**：两类来源 + **各自的存储/建模形式**（这才是选择题的区分点）。

| 来源 | 存储/建模形式 |
| :--- | :--- |
| **离线形成的计算数据文件**（仿真软件输出） | **母线支路模型** |
| **能源管理系统（EMS）提供的实时数据**（通常在内存） | **节点开关模型** |

**容易记混**：选择题考的是**「母线支路模型 vs 节点开关模型」这个对应关系**——
不是「离线/实时」这两个词本身；别和「数据结构三类型」答混。

### 考点：电力系统运行状态分几类（5 分简答题）

**要会**：五类，按顺序写。

1. **正常** 2. **警戒** 3. **紧急** 4. **测试** 5. **恢复**

**为什么重要**：状态一旦确定，对应状态该做的操作就发给操作员；**大数据技术有助于状态分类与物理过程识别**。

**容易记混**：**五个**（不是三、四个）；顺序按「正常→警戒→紧急→测试→恢复」。

### 考点：人工智能的定位与沿革

**要会**：一句话定位 + 几个关键年份。

- **定位**：人工智能是**计算机科学的分支**，也是**交叉学科**。
- **沿革**：**1956 年**达特茅斯会议立为独立学科（约 70 年）→ 几经兴衰 →
  **2006 年** Hinton 深度学习网络使神经网络崛起 → 现在是**第三次** AI 阶段（深度学习阶段）。

**容易记混**：**1956（学科成立）** 与 **2006（深度学习崛起）** 两个年份别搞反。

[笔记原文 ↗](./课堂笔记/2026-09-29-电力大数据特点与人工智能算法.md#人工智能是什么-定位与学科属性)

### 考点：人工智能的两个技术范式（多选题）

**要会**：两个范式的名字 + 各自对应哪一代。

- **符号主义**——对应第一代的**知识驱动**方法。
- **连接主义**——对应第二代的**数据驱动**方法。
- **结论**：靠单个范式推不动人工智能，**知识与数据融合**是必经之路。

**容易记混**：**符号主义↔知识驱动、连接主义↔数据驱动**，两个别配反。

### 考点：人工智能的三个发展阶段

**要会**：三级各一句（教师补充：**书上只讲到第三代，这三级分类「不考」**——了解即可）。

1. **弱人工智能**——智能汽车、无人机等（现在）。
2. **强人工智能**——类人机器人，能绘画、能诊断。
3. **超人工智能**——超过人类智慧边界，会自学习自我迭代，**人类无法控制**（中美好标准严防的就是它）。

**关键年份（可能考）**：**1956 年**达特茅斯会议把 AI 立为**独立学科**（距今约 70 年）；
**2006 年** Hinton 提出**深度学习网络**，神经网络再次崛起（当前是**第三次** AI 阶段）；
**1997 年**深蓝胜国际象棋、**2016 年** AlphaGo 胜围棋。

### 考点：两类常用算法（SVM 与集成学习）

**要会**：各解决什么问题、在算法谱系里的位置。

- **支持向量机（SVM）**：**监督学习**算法；用映射函数把样本映射到**高维空间**，
  找一个**间隔最大**的线性超平面做分类。电力系统里用于**稳定评估**（输出 $+1$ 稳定／$-1$ 不稳定）。
- **集成学习**：按策略训练**多个「弱监督模型」**，**组合**成一个**强监督模型**，性能大幅提升。
  为什么会有弱学习器：理论上「各方面都好」的模型几乎不存在。

**容易记混**：教师说 AI 有**「九种」算法**，但**当堂只讲了 SVM 与集成学习两类**——
答题写这两类即可，别硬凑九个（其余没念出来的名字不要编）。
