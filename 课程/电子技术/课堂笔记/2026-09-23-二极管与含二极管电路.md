# 电子技术 2026-09-23：二极管与含二极管电路的分析

**这节课在干什么**：上一讲把 PN 结的**单向导电性**讲完，这一讲是它的第一次实用——**拿到含二极管的电路，
判断管子通不通、通了以后各点电位是多少**。教师给的本次课四件事：**结构**（管子长什么样）、
**电特性**（伏安特性曲线）、**主要参数**（使用限制）、**会用会分析会设计**（重点是含二极管电路的分析）。
四道例题串出四种作用：**钳位、隔离、单向限幅、双向限幅**，末尾补稳压二极管。

## 题号条目

### 例题一：求 $U_{ab}$（课件例题；电路图在课件上，本仓无照片）

**解析**（本次课的方法第一次完整走一遍）：

1. **先假设二极管断开**。断开时支路里没有电流，电阻两端就没有压降，各点电位直接等于与之相连的电源电位：两条支路的电压源都是**下正上负**（6 V 与 12 V），于是二极管**阳极 = −6 V、阴极 = −12 V**。
2. **比电位定通断**：阳极电位高于阴极 → **正向导通**。
3. **替换后重算**：理想二极管导通相当于一根**导线**，A 点电位被拉到 −6 V，而 B 点是参考点 0 V，所以 **$U_{ab}=-6$ V**。
4. **换管子只换压降**：锗管导通后串入 0.3 V → **−6.3 V**；硅管串入 0.7 V → **−6.7 V**。

> **条件备注**：本例的电路图只在课件上，口述条件**不足以独立重做**——缺两条支路与二极管的接法、缺电阻值（见末尾「待办」的盲测记录）。上面四步是**教师当堂给出的链条**，不是从口述条件自行推出来的。

**这一题在讲什么**：老师用最简的一张图把「假设断开 → 比电位 → 替换 → 重算」走了一遍，答案 −6 V 不是重点，**「导通以后这个节点的电位由谁说了算」**才是——二极管把节点与电源锁在一起，**电阻不影响它**（课上就有同学问「电阻对它没有影响吗」）。这条判据正是后面钳位、限幅一路要反复用的东西。

### 例题二：两个二极管 → 优先导通与隔离

**解析**：

1. 同样先假设**两个管子都断开**，取 B 点接地：D1 两端电位差 6 V，D2 两端电位差 12 V。
2. **电位差大的先导通**（D2）。它一导通就把 A 点电位钳到参考电位附近，D1 两端的条件随之被破坏、转为**反向截止**，那条支路等于**不存在**了。
3. 剩下一条回路：参考点 → 电源 → D2 → 电阻（教师读作 3000 Ω）→ 电源负极，相当于 **12 V 落在 3000 Ω 上**，于是 **$I=12\ \mathrm{V}/3000\ \Omega=4$ mA**（电阻值本身是从转写读出来的，以课件为准）。

**这一题在讲什么**：多管电路的机械顺序——**先比各管电位差、让最大的先导通**，再回头看其余管子是否被关掉，不必逐个试。两个管子的角色是老师点明的：D2 起**钳位**作用、D1 起**隔离**作用。

### 例题三：单向限幅（阈值 8 V）

**解析**：

1. 输入端是**幅值 18 V 的正弦波**，输出端并联一条「**理想二极管 + 8 V 直流电源**」的支路。
2. 有输入输出信号的电路**不必逐个假设**，直接看二极管何时导通：**$u_i>8$ V** 时二极管导通（理想管＝短路），输出被直流电源顶住，**恒为 8 V**；**$u_i<8$ V** 时二极管截止，输出跟随输入。
3. 波形结果：输入超过 8 V 的部分被**削平**，转折点正好落在 8 V。

**这一题在讲什么**：同一套判据换用法——有输入输出的电路改成**分段讨论**，一次只判一个条件。这在工程上叫**限幅（削波）**，用来保护后续电路不被大信号打坏。

> **条件备注**：「削掉超过 8 V 的部分」是教师当堂给出的结论；二极管与 8 V 电源那条支路的**朝向只在课件上**，光凭口述条件判不出削在哪一侧（见末尾「待办」的盲测记录）。

### 例题五：双向限幅（上限 2.7 V、下限 −4.7 V）

**解析**：

1. 两个**硅**二极管都要算 0.7 V 管压降：D1 阴极接 **+2 V**，D2 阳极接 **−4 V**。
2. **$u_i$ 高于 $2+0.7=2.7$ V** → D1 导通，输出被限在 **2.7 V**；**$u_i$ 低于 $-4-0.7=-4.7$ V** → D2 导通，输出被限在 **−4.7 V**；两者之间两个管子都截止，输出跟随输入。
3. 阈值为什么这么算：导通后管子自己要「吃掉」0.7 V，所以触发点比参考电压高（或低）一个 0.7 V——**正门槛加 0.7、负门槛减 0.7**，方向别搞反。

**这一题在讲什么**：双向限幅就是把单向限幅对折，**上下各钉一个门槛**。学会这一道，保护电路的输出范围就由两个参考电压直接算出来。

### 例题四：硅管电路求各支路电流（**数据待核，见待办**）

- 教师讲的**方法链条**照记：取参考点 → 节点电位 +15 V 与 +12 V → 判为正向导通 → 从 15 V 减去 0.7 V 得该节点 **14.3 V** → 输出支路两端就是 14.3 V，$I_o=14.3/R_L$；中间支路两端 $14.3-12=2.3$ V，电流 $=2.3/R$（教师读作 2.3 mA）；最后用**基尔霍夫电流定律** $I_1=I_2+I_o$ 反求 $I_1$。
- **只记方法**：14.3 V 与 2.3 V 是由 0.7 V 管压降直接推出的中间量，可以留；后续算式与数值**不补**。
- 原因：**电阻值与电流的数值在转写里含糊**（「3 3000 欧」「3 10 欧」「14.30 除以 3 10 欧」），**教师本人讲到中途也自查过一次**（「我是不是哪里搞错了什么」）。以课件为准，课件页到手再补齐。

**双签**：2026-09-24，独立子代理**只拿题面**（不读本仓）重做这四道题——**例题二**（$I=4$ mA）与**例题五**（$2.7$ V／$-4.7$ V）条件自足、结论一致；**例题一**与**例题三**的口述条件经判定**不足以独立重做**（缺电路图与二极管朝向），这两道只记教师当堂给出的结论，不自行补图。

## 没编号但讲了的知识点

### 二极管的结构三类型与选用

先说现实中常见的**发光二极管**：颗粒型显示屏由许多组 LED 组成，「有多少个像素点就有多少个发光二极管」。再看结构分类：

| 类型 | 结构特点 | 结电容与电流 | 典型用途 |
| :--- | :--- | :--- | :--- |
| **点接触型** | PN 结**截面积很小** | 结电容小；**正向电流也小**（教师打比方：管径小，流量自然小） | **检波、变频**等**高频**场合（老式收音机的检波管） |
| **面接触型** | 接触面积**很大** | 正向电流大，结电容也大 | **工频大电流整流**（我国工频 **50 Hz**，欧美多为 60 Hz） |
| **平面型** | 结面积**可大可小**，做在芯片上 | — | **集成电路**内部；也用于**高频整流**与**开关电路** |

### 引脚识别与万用表判别

- **看封装**：玻璃封装的圆柱管外面有一圈**色环**，靠近色环的一端是**阴极**；贴片封装的管子，**阴极**一端有**横线标记**。
- **吃不准用万用表**：拨到二极管档，红黑笔各接一端——显示**约 0.7 V 或 0.3 V**（硅管／锗管）说明**红笔接的那端是阳极**；显示**不通**就是接反了。
- 为什么必须认：接反的后果要先看懂伏安特性曲线（下一节）。

### 二极管的符号

一个**三角形**加一根**横线**，再用一根长竖线穿过两者。**三角形底边引出的一端＝阳极**（A），**三角形顶点引出的一端＝阴极**（K）——电路原理图里二极管就是这个符号，先会看符号。

### 伏安特性曲线

- **坐标系与参考方向**：横轴是加在管子两端的电压，纵轴是通过的电流；正向电流的参考方向**从阳极到阴极**（此时电压与电流关联）。
- **第一象限（正向偏置）**：电压小时电流几乎为零，这一段叫**死区电压**——原因是 PN 结的**内电场**，加正向电压是在**不断抵消内电场**，抵消到突破死区电压，才转为**加剧多子的扩散运动**，电流按**指数形状**猛增；管子一旦导通，**电流迅速增大而电压几乎不变**，像个开关。**教师口述数值：硅管死区电压约 0.5 V，锗管约 0.1 V**（未与教材核对）。
- **导通压降怎么取（做题关键）**：

  | 题目条件 | 处理办法 |
  | :--- | :--- |
  | **理想二极管** | 忽略导通压降（当 0）：导通＝**直接短路**，截止＝**断开** |
  | **硅管** | 一般取 **0.7 V**（教师说通常认为 0.6–0.8 V，也提到 0.75） |
  | **锗管** | 一般取 **0.3 V**（教师说 0.2–0.3 V 都有人取） |

- **第三象限（反向偏置）**：加反向电压会**加强内电场**，只有少量少子的漂移运动，反向电流**很小**、曲线几乎贴着横轴；反向电压加到某个值后电流**突然增大**，这是**反向击穿**。**普通二极管**一旦反向击穿，常因电流过大**过热烧毁**（教师称**热击穿**），彻底失效。这里埋了伏笔：还有一种管子**就是要它反向击穿**——**稳压二极管**。
- **导通后的等效模型**：正向导通时二极管等效为一个**恒压源**——硅管 0.7 V、锗管 0.3 V。「这个后面做电路分析时很重要。」

### 主要参数与选型

| 参数 | 含义 | 使用要点 |
| :--- | :--- | :--- |
| **最大整流电流** $I_{OM}$ | 正向导通时允许流过的**最大正向平均电流** | **注意是平均电流，不是瞬时电流**；超过就过热烧坏，是正常使用的限制条件 |
| **最高反向工作电压** | 反向截止时必须保证的电压上限 | 教师说取**击穿电压的 1/2 到 2/3** 作为上限 |
| **反向电流** | 加最高反向工作电压时的反向电流 | **越小越好**（说明关断能力强、单向导电性好）；**受温度影响**，温度越高越大；**硅管小，锗管大几十到几百倍** |

**选型对照**：要导通压降低 → **锗管**；要反向电流小 → **硅管**；要大电流 → **面接触型**；要高频 → **点接触型**；要耐高压耐高温 → **硅管**。

### 含二极管电路的分析方法

1. **先定性判断**：这个管子工作在**正向导通**还是**反向截止**。
2. **看清题目条件**：给的是**理想管**、**硅管**还是**锗管**——压降分别是 0、0.7 V、0.3 V。
3. **具体做法**：**先假设断开** → 选**参考节点**（题目给了接地点就用它，没给就自己设一点）→ 算**阳极所接节点**与**阴极所接节点**的电位 → 比较：阳极高 → 导通，阳极低 → 截止。
4. **替换后重算**：理想管导通用**导线**代替、截止处**断开**；实际管子导通相当于串入 0.7 V（硅）或 0.3 V（锗）的恒压源；再求各节点电压与支路电流。

> **有输入输出信号**的电路（如限幅）不用逐个假设：直接判断二极管两端满足什么电位条件才导通，**分段讨论**即可。

### 总回顾（教师最后收的两句话）

- **第一步永远是分析二极管的通断**。
- 有输入输出的信号电路：**分段讨论**；只含直流电源的电路（例题一、二这类）：**假设断开 → 选参考点 → 比阳极阴极电位 → 替换后重算**。别忘了先看清给的是理想管、硅管还是锗管。

### 稳压二极管

**特殊二极管**，后面电力电子与电子技术常用。

- **符号**：比普通二极管**多一个拐角**，且**参考电压方向与普通管相反**——说明它工作在**反向**状态。
- **原理**：工作在**反向击穿**，击穿后**电流变化很大而电压变化很小**，管子两端电压基本恒定，所以能稳压。
- **必须加限流电阻**：否则电流无限增大会把管子烧穿。

| 参数 | 含义 | 为什么要它 |
| :--- | :--- | :--- |
| **稳定电压 $U_z$** | 反向击穿时管子两端的电压 | **最主要的参数**：选型号就是看它符不符合需要的稳压值 |
| **电压温度系数** | 温度每变化 1 ℃ 引起稳压值变化的**百分数** | 说明稳压值不是绝对不变的 |
| **动态电阻** | 稳压值变化率与电流变化率之比 | **越小越好**：越小 → 曲线越陡 → 稳压性能越好 |
| **稳定电流 / 最大稳定电流 $I_{ZM}$** | 允许工作电流与上限 | 超过上限容易烧坏，所以要限流 |
| **最大允许耗散功率 $P_{ZM}$** | $U_z\times I_{ZM}$ | 超过有**热击穿**危险，管子真正击穿报废 |

**光电二极管与发光二极管**：教师说「作为常识性知识了解一下就行，后面的电路基本不会涉及」。

## 转写与术语

这次转写的同音误识别密集在器件名上，**照转写抄会抄错**：

- 「**前卫作用**」→ **钳位作用**（本次课最核心的概念之一，全篇被读成「前卫」）。
- 「折管／则管／直管」→ **锗管**；「微管／非管」→ **硅管**（两族成对出现）。
- 「起钠击穿」→ **齐纳击穿**；「热积餐」→ **热击穿**；「反向计算」→ **反向击穿**。
- 「公平」→ **工频**（「对于我国来说工频是 50 赫兹」）。
- 「拼接／偏点／偏结／天劫」→ **PN 结**；「空间耗电层」→ **空间电荷层**；「解电容／节电容量」→ **结电容**。
- 「反向工作分子电压」→ **最高反向工作电压**；「I ON」→ $I_{OM}$；「功恒压值」→ 稳定电压值。
- 「点接负性／面结面结合性」→ **点接触型／面接触型**；「基层芯片」→ **集成电路（芯片）**；「采访方向」→ **参考方向**。
- 「震荡电流」疑为**正向电流**（讲点接触型时「它的震荡电流也很小」，下文都在说正向电流）；「低压强度特性曲线」应为**电压传输特性曲线**。
