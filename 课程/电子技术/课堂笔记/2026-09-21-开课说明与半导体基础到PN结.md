### 什么是电子技术

**定义**（教师说取自百度百科，属引用）：**根据电子学的原理，运用电子元器件来设计和制造具有某种特定功能的电路，以解决实际问题**。四个要素：**原理**（依据）、**元器件**（用什么搭）、**特定功能的电路**（做出什么）、**解决实际问题**（为了什么）。

**两大分支**：

- **信息电子技术**（典型应用是**手机**）再分两支：**模拟电子技术**处理**模拟信号**（**连续变化**，电路里的信号多以**电压电流波形**出现）；**数字电子技术**处理**数字信号**（**只有高低电平两种状态**，对应计算机里的 **0 和 1**）。教师说低电平例如 **0.7 V 以下**（同段又说「或者说 0.3 V 以下」，两个数字都记）。
- **电力电子技术**处理**电能形式转换**：多数输电线路传**交流电**，只有**特高压直流输电**这类极个别线路是直流；而**手机用的是直流电**（电池）——把交流变直流、直流变交流，就要用电力电子技术。

**一句话**：电子技术主要是**对电子信号进行处理**的技术。

**四种主要的处理方式**：

| 处理方式 | 教师讲的道理与例子 |
| :--- | :--- |
| **信号的产生（发生）** | 要先有信号。打电话拨号后先产生一个信号去呼叫（发到转接中心）；这个信号在手机内部刚产生时**很微弱** |
| **放大** | 信号传输中会**衰减**，要传得远、传得久就得放大。电力电子领域里相当于**升压或增大电流**，信息电子里是**增强信号能量** |
| **滤波** | 接收端信号含很多**杂波**，要滤出所需信息；电力电子里交流变直流后也要滤波，作用是把**抖动的信号变平稳** |
| **转换** | 模拟与数字信号常要互相转换。麦克风讲话产生**连续的模拟信号**，计算机要用就做**模数转换**，存内存、存存储器；播放时读出数据经**扬声器**（一层膜随不同电流震动发出连续的声音） |

**应用领域与基本单元**：**电力系统**、**工业**（「但凡带有控制设备、信号设备的都离不开电子技术」）、交通、医疗、广播等；要组成庞大的控制系统，**最基本的单元就是元器件**——**二极管、三极管**（以及场效应管一类），这些是本课程的主要内容。

### 从单体器件到集成芯片（课程动机）

- 现实中**单体器件用得比较少**，实际系统里的器件基本都做成了**集成芯片**：在一块**硅片**上用**光刻机**刻出 **MOS 管的沟道**。
- **特征尺寸**：高端芯片目前可做到 **3 纳米以下**（教师估计）；指的是半导体工艺中**最小的尺寸**，也就是 CMOS 工艺里**沟道的长度**。尺寸越小 → **集成度越高** → 单位面积里的晶体管越多 → **处理与存储能力越强**。
- 产业背景（**教师课堂叙述，未核实**）：美国对我国芯片封锁主要卡**光刻机**；华为 Mate 40 之后 **5 nm 以下**芯片被断供；真正能做小特征尺寸的还不是大陆企业，最大代工厂是**台积电**，全球集成电路厂排前面的**以欧美企业为主**。教师的动员：学这门课不一定立刻改变现状，但可以在**配套的生产与研发岗位**上起作用。

### 半导体基础（一）：本征半导体

- **半导体**的电阻率**介于导体与绝缘体之间**：某些条件下扮演**导体**，条件改变又可能呈现**绝缘体**状态。
- **本征半导体的定义**（书上）：**完全纯净的、具有晶体结构的半导体**。**两个关键词缺一不可**（教师反复强调）：**完全纯净**、**具有晶体结构**（原子核与电子排列成**立体的、整齐有规律**的结构）。
- 教材讲到的材料教师提到**硅**与**砷化镓**等，常用的是**硅**；硅是**四价元素**（外层**四个电子**）。
- **共价键**：相邻两个硅原子**各出一个电子、两两配对**，每个硅原子与周围**四个**硅原子以**共用两个电子**的形式结合。共价键「在学化学的时候是相当牢固的」，要破坏需要**很大的能量**。结构上每个原子处于一个**四面体的中心**，四个相邻原子在**顶点**。
- **本征激发**：给价电子提供能量（**光照**或**加热**），价电子挣脱共价键跑出来。跑出来的叫**自由电子**（**带负电**），它留下的空位**带正电**，叫**空穴**。
  > **教师明确说这里是考点**：半导体中**自由电子带负电荷、空穴带正电荷**——后面讲单向导电性都要用。
- 自由电子的活跃度与**温度成正比** → 本征半导体具有**热敏性**与**光敏性**（半导体三大特性中的两个）。
- **载流子的运动与电流方向**：没有外电场时自由电子做**杂乱无章**的运动；加外电场后，**空穴**靠相邻价电子
  来填补空位而**等效地移动**，**自由电子**沿一定方向移动。**半导体的电流由两部分组成**（电子 + 空穴）。
  **最容易糊涂的一点**：两者**移动方向相反，但电流方向相同**——因为规定**正电荷移动方向为电流的参考正方向**，
  所以自由电子的移动方向与电流方向相反。具体分析电路时先**假设参考方向**，算出的代数值为负说明假设反了。

### 半导体基础（二）：掺杂半导体与载流子

半导体的**三大特性**至此讲全：**热敏性、光敏性、掺杂性**。

- **为什么必须掺杂**：实际用的半导体**一般不用本征半导体**——它的导电特性太弱（教师也说「带负载的能力太弱」）。做法是掺入**微量**的其他元素，整体仍呈现本征半导体的特性，只是**提高了导电性能**。
- **P 型半导体**（掺**三价**元素，教师举例**硼**）：三价元素最外层只有 3 个电子，比硅**少一个** → 相当于**多了一个空穴**，即「掺了空穴」。以空穴为主的叫 **P 型**（P 取 **positive** 之意，因为相对 N 型它相当于带正电）。
  > **重要澄清**：半导体材料**本身呈电中性**——没有外加电场时**不带电荷**（原子核与电子数仍一一配对）。「带正电」只是相对本征半导体、相对 N 型的说法。
- **N 型半导体**（掺**五价**元素，教师举例**磷**）：五价元素最外层 5 个电子，比硅**多一个** → 电子偏多，叫 **N 型**（**negative**）。N 型里的空穴来自**本征激发**（受光受热仍会产生少量空穴）。
- **载流子、多子与少子**（教师点明是考点）：载流子＝运输正负电荷的**微粒**（空穴带正电、自由电子带负电）。掺杂半导体里两种载流子数量**不对等**：

| 半导体 | 多数载流子（多子） | 少数载流子（少子） | 少子从哪来 |
| :--- | :--- | :--- | :--- |
| **P 型** | **空穴**（掺杂掺进来的） | 自由电子 | **本征激发** |
| **N 型** | **自由电子** | 空穴 | **本征激发** |

### PN 结的形成

- **为什么要做 P 型和 N 型**：目的是**形成单向导电的效果**——把 N 型与 P 型**接触在一起**，形成一个**交界面**。
- **形成过程**（五个环节）：

  1. **多子扩散**：交界面左边 P 型（多空穴）、右边 N 型（多自由电子），「异性相吸」——左边空穴往右跑、右边自由电子往左跑，这叫**多子扩散运动**。
  2. **复合耗尽**：跑到对面的载流子相遇，电荷相反而**成双成对地复合**（互相抵消）。
  3. **形成内电场**：复合后留下**不能移动的原子核离子**——N 侧**带正电**、P 侧**带负电**，内部形成**内电场**，方向由**正指向负，即从 N 侧指向 P 侧**。
  4. **少子漂移**：内电场又**促进少子的漂移运动**（N 区少子空穴往左、P 区少子自由电子往右）——**漂移方向与多子扩散方向相反**。
  5. **动态平衡**：多子扩散的量与少子漂移的量最终相等，成为**动态平衡**；此时该区域**没有净的电荷运动**，**空间电荷区宽度固定不变**。

- **名称**：这一段区域叫 **PN 结**，也叫**空间电荷区**或**耗尽层**。
- **两条方向（务必记牢）**：**多子扩散使空间电荷区加宽**、内电场增强；**少子漂移使其变窄**。
- **内电场的作用**：**阻碍** P 区空穴、N 区电子向对方**扩散**；**促进少子漂移**。空间电荷区里**没有载流子**（已耗尽）。
- **不加外加电压时**：虽然内电场促进少子漂移，但少子量很小，漂移电流**几乎为零** → PN 结形成后**对外呈现不导电**的状态。

### PN 结的单向导电性（本节最重要的特性）

**正向偏置（加正向电压）→ 导通**：外接电源**正极接 P 区、负极接 N 区**，外电场由 **P 指向 N**，与内电场（N→P）**方向相反**：

| 环节 | 变化 |
| :--- | :--- |
| 内电场 | 被外电场**削弱** |
| 多子扩散运动 | 被**促进**，扩散电流增大 |
| 空间电荷区（耗尽层） | **变窄（变薄）** |
| 电阻 | **正向电阻变小** |
| 状态 | **正向导通**，形成较大的正向电流 |

教师补充两点：① 当**外电场大过内电场**时，「耗尽层相当于不存在了」，电流可畅通通过；② 外电压**从零逐渐增大**时必须**增大到内电场的强度**，导通才明显——这对应一个**死区电压**的概念（下节课讲伏安特性曲线时体现）。

**反向偏置（加反向电压）→ 截止**：外接电源**正极接 N 区、负极接 P 区**，外电场仍由 **N 指向 P**，与内电场**同向叠加**：

| 环节 | 变化 |
| :--- | :--- |
| 内电场 | 被**加强** |
| 多子扩散运动 | 被**狠狠抑制** |
| 少子漂移运动 | 被加强，但**少子量很少**，形不成大电流 |
| 空间电荷区（耗尽层） | **变宽** |
| 电阻 | 反向电流很小、电压一定时**反向电阻很大** |
| 状态 | **截止** |

**这个特性有什么用**：改变加在 PN 结两端的电压就能改变电路的**通断状态**——既可用于**数字开关**，也可用于模拟信号的**滤波、斩波**。教师强调「这个部分务必请大家静下心来捋一遍」，因为**这个特性不掌握，后面学起来会更吃力**。

## 转写与术语

半导体术语是这次转写的重灾区，**照抄会抄错**：

- 「**本身半导体／本真半导体**」→ **本征半导体**（全篇最高频的概念名）。
