## 4. 什么是电子技术

### 4.1 定义与四个要素

教师说明这个定义是从百度百科提取的（**属引用，非教师自拟**）：电子技术是**根据电子学的原理，运用电子元器件来设计和制造具有某种特定功能的电路，以解决实际问题**的一门课题。把关键词串起来就是它的内涵：

| 要素 | 含义 |
| :--- | :--- |
| 电子学的原理 | 依据是什么 |
| 电子元器件 | 用什么搭 |
| 某种特定功能的电路 | 做出什么 |
| 解决实际问题 | 为了什么 |

### 4.2 两大分支

- **信息电子技术**：典型应用是**手机**（教师课上提问，学生答「手机」，教师确认这是信息电子技术的典型应用）。它再往下分两支：
  - **模拟电子技术**：处理**模拟信号**，即**连续变化**的信号——电路中的信号绝大多数以**电压和电流**的波形形式出现，处理这类连续信号的电子电路叫模拟电子电路。
  - **数字电子技术**：处理**数字信号**，即**只有高低电平两种状态**的信号。教师举例说低电平例如 **0.7 V 以下**（同一段又说「或者说 0.3 V 以下」，两个数字都记，见第 11 节），对应计算机里表示开关状态的 **0 和 1**；计算机、手机内部用的这些 0/1 信息就属于数字电子技术。
- **电力电子技术**：处理**电能形式转换**。教师从电能的传输形式讲起：
  - 电能传输有**交流电**与**直流电**两种形式；**大多数输电线路传的是交流电**，只有**特高压直流输电**这类**极个别**线路是直流。
  - 而**手机用的是直流电**（电池）。要把输电线上的交流电变成电子设备要用的直流电，就要用**电力电子技术**——用电力电子元器件组成具有相应功能的电路，**把交流电变成直流电、把直流电变成交流电**。

**一句话总结**（教师原话意思）：电子技术主要是**对电子信号进行处理**的技术，学的是怎么运用电子学原理来处理这些电子信号。

### 4.3 四种主要的处理方式

| 处理方式 | 教师讲的道理与例子 |
| :--- | :--- |
| **信号的产生（发生）** | 要先有信号。打电话拨号后要先产生一个信号去呼叫（发到转接中心）；这个信号在手机内部刚产生时**很微弱** |
| **放大** | 信号在传输中会**衰减**，要传得够远、够久就得放大，才能被设备接收。在电力电子领域，放大相当于**升压或增大电流**（增大驱动）；在信息电子里是**增强信号能量** |
| **滤波** | 接收端收到的信号里含很多**杂波**，要滤出所需信息。电力电子里把交流变直流的环节也要滤波，作用是把原来**抖动的信号变平稳** |
| **转换** | 模拟信号与数字信号在很多场合要互相转换。例：用麦克风讲话产生的是**连续变化的模拟信号**，计算机要用它就得做**模数转换**，转成数字信号后先存内存、再存到存储器；播放时从存储读出数据，通过**扬声器**——扬声器就是让一层膜随不同电流不停震动，震动产生连续的声音 |

### 4.4 应用领域与基本单元

- **应用领域**（教师列举）：**电力系统**、**工业领域**——「但凡带有控制设备、信号设备的都离不开电子技术」，还有**交通、医疗、广播**等。
- **基本单元**：要实现这些功能、组成庞大的控制系统，最基本的单元就是接下来要学的**元器件**——**二极管、三极管**（以及场效应管一类器件）。这些是本课程的主要内容。

## 5. 从单体器件到集成芯片

这一段是教师结合实际产业讲的，属于**课程动机**，其中的产业判断按教师叙述记录。

- **现实中单体器件用得少**：单个的二极管、晶体管、三极管「用是用得到，但是几乎比较少」，实际系统中的器件基本都做成了**集成芯片**。
- **集成芯片怎么做**：在一块**硅片**上用**光刻机**刻出 **MOS 管的沟道**（一条一条沟道）。
- **特征尺寸**：高端芯片目前可以做到 **3 纳米以下**（教师估计，见第 11 节）。所谓 3 纳米指的是**特征尺寸**——半导体工艺中**最小的尺寸**，也就是 CMOS 工艺里**沟道（通道）的长度**。
- **为什么要把尺寸做小**：特征尺寸越小，**集成度越高**——单位面积里能装的晶体管个数越多，意味着**处理能力或存储能力越强**。
- **产业背景**（教师课堂叙述）：美国对我国芯片封锁，卡的主要是**光刻机**，使高端芯片难以生产；教师提到华为 Mate 40 之后 **5 nm 以下**芯片被断供；说到真正能做小特征尺寸的**还不是大陆企业**，最大的代工厂是**台积电**，全球集成电路生产厂排在前面的**以欧美企业为主**，个别日本企业也生产。
- **教师的学习动员**：作为工科同学，学这门课不一定能立刻改变芯片技术落后的状态，但应该抱着决心和信心把知识学好，「哪怕对这个行业能产生那么一点点贡献」；顶尖的高端攻关有科学家在前面努力，我们可以在**配套的生产与研发岗位上**起作用。
- **教材与考研的再次提醒**：本课教材是两门课合一，**光学这本不够**；考研考电子方向要另找经典教材与线上课程（慕课、在线平台、B 站等）扩展学习面。

## 6. 半导体基础（一）：本征半导体

### 6.1 半导体是什么

- 初中就学过**导体**（电阻率非常低）与**绝缘体**（电阻率非常高）。
- **半导体**的电阻率**介于两者之间**：在某些条件下可以扮演**导体**的角色，条件改变时又可能呈现**绝缘体**的状态。具有这种特性的材料叫半导体。

### 6.2 本征半导体的定义

书上给的定义（教师让学生看书上定义）：**完全纯净的、具有晶体结构的半导体**，叫本征半导体。

> **两个关键词，缺一不可**（教师反复强调）：**完全纯净**、**具有晶体结构**。

- **什么叫晶体结构**：原子核与电子之间排列成一个**立体的、非常整齐有规律的**结构。
- **有哪些材料**：教材里讲到的本征半导体材料，教师提到**硅**与**砷化镓**等（材料名在转写中失真，见第 11 节）；常用的纯净半导体是**硅**。
- **硅是四价元素**：外层有**四个电子**。教师顺带提到与之并列的另一种四价元素（转写为「硅和子」，疑为**锗**，见第 11 节）。

### 6.3 共价键

- 以硅为例：中间是一个硅原子，外围有四个电子；**相邻的**一个硅原子也出一个电子，两个硅原子**各出一个电子、两两配对**，形成**共价键**。
- 也就是说，每个硅原子与它周围的**四个**硅原子，都以**共用两个电子**的形式结合成共价键。
- 共价键「在学化学的时候是相当牢固的」，要改变它需要**很大的能量**才能破坏，所以是相当稳定的一种晶体结构。
- 结构形状：每个原子处于一个**四面体的中心**，四个相邻原子位于四面体的**顶点**。

### 6.4 本征激发：自由电子与空穴

- 要让**价电子**从共价键里挣脱出来，一般要给它提供**能量**；教师问能量用什么形式提供，答案是**光照**或**加热**。
- 温度升高或用光照射时，价电子获得足够能量，挣脱原子核（共价键）的束缚跑出来——这叫**本征激发**。
- 跑出来的电子叫**自由电子**，定义它**带负电荷**；它原来在共价键里留下的那个空位置，**带正电荷**，叫**空穴**。

> **教师明确说这里是考点**：在半导体中**自由电子带负电荷、空穴带正电荷**。这个概念后面讲单向导电性等都要用到，务必记牢。

- 自由电子的「活跃度」与**温度成正比**，因此本征半导体具有**热敏性**与**光敏性**——导电特性与光和热相关。这是半导体**三大特性中的两个**。

### 6.5 载流子的运动与电流方向

- **没有外加电场**时，本征激发出来的自由电子只是在做**杂乱无章**的运动。
- **加了外电场**以后：
  - **空穴**会吸引相邻原子的价电子来填补自己这个空位，填补的过程**等效于空穴在移动**（相当于带正电的载流子在移动）；
  - **自由电子**则沿一定方向移动（外电场作用下的定向移动）。
- **半导体的电流由两部分组成**：**自由电子的移动**与**空穴的移动**之和。
- 关键辨析（教师说这是最容易糊涂的点）：两者的**移动方向相反**，但**电流方向相同**。原因是电路中的规定——**规定正电荷的移动方向为电流的参考正方向**，因此**自由电子的移动方向与电流方向相反**。
- **关于参考方向**：具体分析电路时会先**假设一个参考方向**；如果按假设方向算出的**代数值为负**，说明假设的方向反了。教师提醒「学电路的时候、包括学电子技术的时候」都要注意这个问题。

## 7. 半导体基础（二）：掺杂半导体与载流子

### 7.1 第三个特性：掺杂性

半导体的**三大特性**至此讲全：**热敏性、光敏性、掺杂性**。

- **为什么必须掺杂**：实际使用的半导体**一般不用本征半导体**，因为它的导电特性（半导体呈现出来的特性）**太弱**，教师说也叫「**带负载的能力太弱**」。
- 做法是往本征半导体里掺入**微量的**其他元素。教师强调掺入的量相对本征半导体是**微量**的，所以整体仍呈现本征半导体的特性，只是**提高了导电性能**。

### 7.2 P 型半导体（掺三价元素）

- 在硅晶体中掺入**三价元素**（教师举例**硼**），让它**取代晶格中原来的硅原子**。
- 硅原子最外层有 4 个电子，三价元素最外层只有 **3 个**，**少了一个电子**——相当于**多了一个空穴**，即向本征半导体中「掺了空穴」。
- 这种以空穴为主的半导体叫 **P 型半导体**；P 是英文里「正」那个词的缩写（**positive**），因为**相对 N 型**而言它相当于带正电。

> **重要澄清**：半导体材料**本身是呈电中性的**——在没有外加电场的情况下，它**不带电荷**。因为原子核与电子数仍然一一配对，既没有多出电子也没有少掉电子。所谓「带正电」只是相对本征半导体、相对 N 型而言的说法。

### 7.3 N 型半导体（掺五价元素）

- 在硅晶体中掺入**五价元素**（教师举例**磷**）。五价元素最外层有 **5 个电子**，比硅**多一个电子**。
- 这种掺杂后**电子偏多**的半导体叫 **N 型半导体**（N 取 **negative** 之意）。
- N 型里的空穴从哪来？**本征激发**——本征激发的特性仍然存在，受光、受热时仍会产生少量空穴。

### 7.4 载流子、多子与少子（教师点明是考点）

- **载流子**的定义：运输正电荷和负电荷的**微粒**。**空穴**是带正电荷的载流子，**自由电子**是带负电荷的载流子。
- 在掺杂半导体中，两种载流子的数量**不对等**，于是有多数与少数之分，简称**多子和少子**：

| 半导体 | 多数载流子（多子） | 少数载流子（少子） | 少子从哪来 |
| :--- | :--- | :--- | :--- |
| **P 型** | **空穴**（掺杂掺进来的） | 自由电子 | **本征激发**（掺杂后本征激发的特性仍在） |
| **N 型** | **自由电子** | 空穴 | **本征激发** |

- 教师要求**在讲 PN 结形成之前把这对概念弄清楚**。

## 8. PN 结的形成

### 8.1 为什么要做出 P 型和 N 型

教师先问「为什么要搞一个 P 型、搞一个 N 型」——目的就是**让它形成一个单向导电的效果**。做法是把 **N 型与 P 型两种半导体材料接触在一起**（教师口语说「焊在一起」「接触在一起」），形成一个**交界面**。

### 8.2 形成过程：扩散 → 复合 → 内电场 → 漂移 → 动态平衡

1. **多子扩散**：交界面左边是 P 型（**多空穴**），右边是 N 型（**多自由电子**）。本着「异性相吸」，左边的空穴往右边跑、右边的自由电子往左边跑——这叫**多子扩散运动**。
2. **复合耗尽**：跑到对面的载流子相遇，因为电荷相反，**成双成对地复合**（互相抵消、消耗掉）。
3. **形成内电场**：复合后留下来的是**不能移动的原子核离子**——右边（N 侧）**带正电**、左边（P 侧）**带负电**，于是在内部形成了一个**内电场**，方向由**正电指向负电，即从 N 侧指向 P 侧**。
4. **少子漂移**：内电场一形成，又**促进少子的漂移运动**——N 区的少子空穴往左边走、P 区的少子自由电子往右边走。**漂移的方向与多子扩散的方向相反**。
5. **动态平衡**：内电场增强后，多子扩散的量与少子漂移的量最终相等，成为**动态平衡**。此时该区域内**没有净的电荷运动**，**空间电荷区的宽度固定不变**。

### 8.3 两个名称与两条方向

- **名称**：这一段区域叫 **PN 结**；也叫**空间电荷区**，或**耗尽层**。
- **方向关系（务必记牢）**：

| 运动 | 对空间电荷区的作用 |
| :--- | :--- |
| **多子扩散运动** | 使空间电荷区**加宽**，内电场增强 |
| **少子漂移运动** | 使空间电荷区**变窄（缩窄）** |

- **内电场的作用**：**阻碍** P 区空穴、N 区电子向对方方向**扩散**；**促进少子漂移**。
- **空间电荷区里没有载流子**（已耗尽）——这一点教师单独提了一句。
- **不加外加电压时的表现**：虽然内电场促进了少子漂移，但少子**量很小**，漂移形成的电流**几乎为零**。所以 PN 结形成后，在**不外加偏置电压**的情况下对外呈现**不导电**的状态。

## 9. PN 结的单向导电性

教师说这是本节**最重要的特性**，也是后面电路应用的基础。

### 9.1 正向偏置（加正向电压）→ 导通

- **接法**：外接电源的**正极接 P 区**、**负极接 N 区**。
- **电场方向**：外电场由 **P 指向 N**；而内电场是由 **N 指向 P**——**两者方向相反**。
- **结果**：

| 环节 | 变化 |
| :--- | :--- |
| 内电场 | 被外电场**削弱** |
| 多子扩散运动 | 被**促进/加强**，扩散电流增大 |
| 空间电荷区（耗尽层） | **变窄（变薄）** |
| 电阻 | **正向电阻变小** |
| 状态 | **正向导通**，形成较大的正向电流 |

- 教师补充两点：一是当**外电场大过内电场**时，「耗尽层相当于不存在了」，电流就可畅通通过 PN 结；二是外电压**从零逐渐增大**时，必须**增大到内电场的强度**，导通状态才明显——这就对应一个**死区电压**的概念，是**下节课讲伏安特性曲线**时会体现出来的特征。

### 9.2 反向偏置（加反向电压）→ 截止

- **接法**：外接电源的**正极接 N 区**、**负极接 P 区**。
- **电场方向**：外电场仍然由 **N 指向 P**，与内电场**同向**——两者**叠加**，等于**加强了内电场**。
- **结果**：

| 环节 | 变化 |
| :--- | :--- |
| 内电场 | 被**加强** |
| 多子扩散运动 | 被**狠狠抑制** |
| 少子漂移运动 | 被加强，但**少子量很少**，形不成大电流 |
| 空间电荷区（耗尽层） | **变宽** |
| 电阻 | 反向电流很小、电压一定时**反向电阻很大** |
| 状态 | **截止** |

### 9.3 这个特性有什么用

- 通过**改变加在 PN 结两端的电压**，就能改变电路**通断的状态**：
  - 既可用于**数字开关**的作用；
  - 也可用于模拟信号的**滤波、斩波**等作用。
- 教师说这些都是**基于 PN 结的单向导电性**，并强调「这个部分务必请大家一定要去……静下心来给它捋一遍」，因为**这个特性不掌握，后面学起来会更吃力**。

5. **背半导体三大特性**（第 6、7 节）：**热敏性、光敏性、掺杂性**。
6. **分清三种半导体**（第 6、7 节）：本征半导体两个关键词（**完全纯净、晶体结构**）；掺杂的目的（本征的导电能力太弱）与两个方向（三价→P 型多空穴、五价→N 型多电子）；**自由电子带负电、空穴带正电**（教师点名的考点）；**P 型多子是空穴、N 型多子是自由电子**，少子都来自本征激发；**半导体整体呈电中性**。
7. **把 PN 结的形成过程默写一遍**（第 8 节）：多子扩散 → 相遇复合 → 留下离子形成内电场（N 指向 P）→ 促进少子漂移 → 动态平衡；记住两个名字（空间电荷区、耗尽层）与两条方向（**扩散加宽、漂移变窄**）；不加电压时**不导电**。
8. **正偏与反偏做成对照表背下来**（第 9 节）：外电场方向、内电场是被削弱还是加强、耗尽层变宽还是变窄、电阻大小、导通还是截止；并记住**死区电压**这个名字——下节课讲伏安特性曲线时会用到。
9. **别提前背后面章节**（第 10 节）：二极管的伏安特性曲线、稳压管、三极管、场效应管、含二极管电路分析本次都没有讲；等到对应课次再整理，避免照抄不存在的板书。
