# 电子技术 2026-10-12：卡诺图化简法与无关项

**这节课在干什么**：把化简手段从**公式法**换到**卡诺图法**——不再靠挑公式，而是**把最小项摆成方格图、圈相邻的 1**。本讲要会四件事：
① 卡诺图的**排列规则**（按循环码，**不是**二进制递增）；② **相邻关系**（含同行首尾、同列首尾、四个角这些看着不相邻的位置）；
③ **圈组四条原则**（画圈判对错的完整判据）；④ 从圈**读出与项**（留相同变量、消相异变量）。收尾讲**无关项**（约束项＋任意项）怎么用，并把逻辑函数的**四种表示**凑齐。

**行政与考核**

- 作业**已发到学习通**，教师说题目也是**课本后面的习题**（本次未报题号）。

## 题号条目

### 例：三变量「四个 1」——两两圈出三组

**解析**（教师边讲边在图上标，题面以课件图为准）：四个最小项先填 1，**圈不出 4 格的大圈**，于是**两两成对、得三个圈**：

- 红圈：$A$、$B$ 相同，$C$ 相异 → 留 **$AB$**；
- 绿圈：$B$、$C$ 相同，$A$ 相异 → 留 **$BC$**；
- 棕圈：$A$、$C$ 相同，$B$ 相异 → 留 **$AC$**。

三圈用或号连接，得 $Y=AB+BC+AC$。与这个结果相容的四个最小项是 $m_3$、$m_5$、$m_6$、$m_7$——三圈**共享 $m_7$**，而 $m_3$、$m_5$、$m_6$ 各由其中一圈首次圈到，合第四条原则（转写把四个最小项读得含糊，编号由结果反查，见校对层）。

**这一题在讲什么**：卡诺图化简的标准流程一次走完——填 1 → 按四条原则圈 → 每圈留相同消相异 → 相或。它也示范「**圈不出大的就两两圈**」。

⚠ 四个最小项的**具体编号**转写未报（以课件图为准）；圈法与结果照教师原话。

### 例：判错一——多余的圈（第二个圈没有新 1）

**解析**：教师给出一张「看着合理」的化简图，让学生用四条原则判断。问题在于：**第二个圈里的 1 都已经被别的圈圈过了**，它没有带来任何新 1。按第四条原则（每个新圈至少要包含一个没被圈过的 1），这个圈**是多余的**，图不是最简。

**这一题在讲什么**：判多余圈就看一条——**新圈里有没有新 1**。教师提醒这是自己画图时最容易漏看的错误。

### 例：判错二——圈得不够大

**解析**：另一张图里有两个 1 被圈成一对（2 格），但它们与旁边两个 1 其实能拼成 **4 格大圈**，用大圈可以**多消一个变量**。原图没违反「2 的幂」也没画出多余圈，但仍不是最简：**圈的规模不够大**。

**这一题在讲什么**：四条原则里「尽可能大」是最常被违反的一条。判最简不能只数圈的个数，还要看每圈**能不能再长大**。

### 例：两图都对——最简结果不唯一

**解析**：左右两图都符合四条原则（没有多余圈、每圈至少一个新 1），只是**分组方式不同**，两个结果都成立。这说明**最简与或式不唯一**——与上一讲公式法配项法「一题两解」是同一个结论：逻辑功能相同即可。

**这一题在讲什么**：判对错看「是否符合四条原则」，不看「和某份答案长得一样不一样」。

### 思考题：给状态表用卡诺图化简

**解析**：状态表八行里 $Y=1$ 的只有三行：**010、011、100**。

- **010 与 011**（$m_2$、$m_3$）：落在卡诺图 A=0 那一行的 BC=11 与 10 两列（列序 00、01、11、10，这两列相邻）→ 圈成一对，消去 $C$，留 $\overline{A}B$；
- **100**（$m_4$）：三个相邻格 000、101、110 的 $Y$ 都是 0，**没有可合并的伙伴**，只能自己一圈 → 留 $A\overline{B}\overline{C}$（三个变量一个都消不掉）。

两圈相或：$Y=\overline{A}B+A\overline{B}\overline{C}$。

**这一题在讲什么**：**真值表 → 卡诺图**这条入口——状态表里每个 $Y=1$ 的行直接落格，圈法与前面完全一样；也示范**孤立 1** 的处置。

## 没编号但讲了的知识点

### 为什么卡诺图能化简：相邻就是只差一个变量

卡诺图按**循环码（格雷码）**排列：**相邻两格只有一个变量取值不同**。两个只差一个变量的最小项可以合并，**消去那个变量**（互补律 $X+\overline{X}=1$）——这是全部原理，后面讲的相邻关系都是为它服务。教师把这条挂回第七章讲编码时提过的格雷码。

### 排列规则：不能按二进制递增列

| 变量数 | 格子数 $2^n$ | 行列安排 |
| :--- | :--- | :--- |
| 2 | 4 | 行 $A$，列 $B$ |
| 3 | 8 | 行 $A$，列 $BC$ |
| 4 | 16 | 行、列各两个变量 |

- **三变量**：两行（行变量 $A$ 取 0／1）＋四列（列变量 $BC$ 按 **00、01、11、10**）；
- **四变量**：行、列各两个变量，**行的编码也按 00、01、11、10**。

**最容易错的一处**：把列（或行）按**二进制递增顺序** 00、01、10、11 去排。教师原话「那个是错的，不能按照二进制的递增序列」——这么排整张图就失效了。

### 相邻关系：三种看着不相邻的相邻

| 相邻情形 | 在图上长什么样 |
| :--- | :--- |
| 左右相接 | 同一行并排两格（**含同一行的首列与末列**——两头相连） |
| 上下相接 | 同一列上下两格（**含同一列的首行与末行**——上下相连） |
| 四个角 | 四角之间是绕边相邻，**四角都是 1 时可以直接圈成一圈** |

- **理解法**：把表格**横着卷成圆柱**（首尾相连）、再**纵着卷**（上下相连），抽象起来就是**球面**上的相邻；课件把这件事说成「任一行或列的两头、**对折后位置相邻**」。
- 更根本的判据是**逻辑相邻**：两个最小项**只有一个变量取值不同**。看着不相邻但逻辑相邻的照常合并——教师点名「**最容易被大家忽略的是 $m_0$ 和 $m_2$**」（同一行的头与尾）。
- 课件补充一句：**对角线上的格子不相邻**。

### 最小项与编号

- **最小项**：$n$ 个变量**每个都以原变量或反变量恰好出现一次**的乘积项；$n$ 个变量共 $2^n$ 个最小项（二变量 4 个、三变量 8 个、四变量 16 个）。教师原话「所有的输入变量组合的乘积项，就是最小项」。
- **编号 $m_i$**：把「使该最小项为 1」的那组取值当**二进制数**，转十进制就是下标——$m_0$=000、$m_1$=001、$m_3$=011、$m_4$=100……
- 卡诺图里格子的编号**不是连续的**：三变量第一行是 **0、1、3、2**、第二行是 **4、5、7、6**（后两列互换）——这是循环码排列的必然结果，不是笔误。

### 两种填入法

| 方法 | 怎么做 | 何时用 |
| :--- | :--- | :--- |
| 配项成最小项式 | 每项缺的变量用 $X+\overline{X}=1$ 配齐，全化成最小项式再逐格填 | **不熟练时**（教师建议先这样，稳） |
| 直接按项找区域 | 项 $AB$ → $A=1$ 且 $B=1$ 的那一行整片标 1；项 $A$ → $A=1$ 的两行整片标 1 | 熟练后（快） |

函数里**没有的最小项**对应格子填 **0**。

### 画圈四条原则（判对错的完整判据）

1. **圈内 1 的个数是 $2^n$ 个**：2、4、8、16……**不能圈 3、5、6、10、12 个**；
2. **只圈相邻的 1**（相邻＝只差一个变量）：$2^n$ 个相邻项合并，**消去 $n$ 个变量**——2 个消 1 个、4 个消 2 个、8 个消 3 个；
3. **圈的个数尽可能少、每圈尽可能大**：圈越大消的变量越多，与项越少、每项变量也越少；
4. **同一个 1 可以被圈多次**，但**每个新圈必须至少包含一个没被圈过的 1**——没有新 1 的就是多余圈。

### 从圈读出最简与或式

每圈**保留相同变量、消去相异变量**写成一个与项；各圈的与项**用或号连接**，就是最简与或式。
对账口径：**与项个数＝圈的个数**，**与项里的变量数＝该圈消剩的变量数**。

### 无关项：约束项与任意项

| 类型 | 含义 | 例 |
| :--- | :--- | :--- |
| **约束项** | 某些取值**根本不可能出现** | 电机正转 $A$／反转 $B$／停转 $C$：「三样都不发生」（000）与「又反转又停转」（011）等都不可能 |
| **任意项** | 取值出现与否**都不影响函数值** | 8421BCD 码只用 0000～1001，1010～1111 六种组合无意义 |

- 卡诺图里用 **×** 标出（也写 $\varphi$ 或 $d$）；化简时**可以当 0、也可以当 1**——**想让圈更大就把它当 1**。教师例：把几个 × 都当 1，能圈出 8 格大圈，变量消得最多；
- 教师口径：**合理使用无关项能让化简更方便**；圈法本身仍受四条原则约束。

### 逻辑函数的四种表示（本讲凑齐）

| 表示 | 形态 | 特点 |
| :--- | :--- | :--- |
| **逻辑状态表**（真值表） | 左列输入全部组合、右列输出 $Y$ | 直观；变量一多就烦琐 |
| **逻辑式** | 与项相或的表达式 | 便于运算与化简 |
| **卡诺图** | 最小项方格图 | 便于化简（本次课） |
| **逻辑图** | 门电路符号连成的图 | 下节课起讲门电路 |

四者表示**同一个逻辑功能**，可互相转换。回看上一讲的三人控制灯题：状态表、逻辑式、逻辑图三样，加本讲的卡诺图就齐了。

## 课件补充

### 最小项的正式定义与三条性质（课件 §7.3.3）

- 定义：$n$ 个变量的与项中，**每个变量都以原变量或反变量形式仅出现一次**，称为最小项；$n$ 个变量共 $2^n$ 个最小项。
- 三条性质：① 对任一最小项，**只有一组变量取值使它为 1**、其余组合下为 0；② **任意两个不同最小项之积恒为 0**；③ 对变量的任一组取值，**全部最小项之和恒为 1**。
- **任何逻辑函数都可写成若干最小项之或，这个最小项表达式唯一**——与「最简与或式不唯一」不矛盾：前者说的是「化成最小项的写法唯一」，后者说的是「最简的写法可以有多种」。
- 课件例 7.3.11：由逻辑式写出最小项表达式，记作 $Y(A,B,C)=\sum m(2,3,5)$ 这种形式。

### 几何相邻的正式表述

最小项按「相邻」原则排列；相邻含**逻辑相邻**（只有一个变量取值不同、可以合并）与**几何相邻**（紧挨在一起，**包括任一行或列的两头、对折后位置相邻**）。变量取值按**循环码顺序** 00、01、11、10 排列；**对角线上不相邻**。

### 课件例题对照（与课上例题同一套考点）

| 课件例题 | 内容 | 与课上的关系 |
| :--- | :--- | :--- |
| 例 7.3.12 | 三变量 $\sum m(2,3,4,6)$ 的卡诺图化简 | 图中**虚线圈③**「已分别被圈过、无新最小项，故为多余圈，应去掉」——正是课上判错一的同一考点 |
| 例 7.3.13 | 四变量化简（项不是最小项时按项覆盖多格） | 对应课上「直接按项找区域」的填法 |

- 课件收尾口径：卡诺图直观方便，但**变量多于 5 个就复杂麻烦**——它是 4 变量以内的化简工具。
