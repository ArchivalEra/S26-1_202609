## 四变量卡诺图化简 → 与非门电路 {#m-kmap-nand}

**认出它**：给 $Y(A,B,C,D)=\sum m(\cdots)$（或真值表），两问固定搭配：先化简，再「用与非门画逻辑电路图」。
看到「与非门实现」就要想到**把最简与或式原样翻成两级与非**，不要再化第二次。

**路径**：

1. **画四变量卡诺图**。行取 $AB$（按格雷码 $00,01,11,10$ 排），列取 $CD$（同样 $00,01,11,10$）。
   把 $\sum m$ 里每个编号转成四位的二进制（**最高位是 A**），编号 $n$ 对应 $AB=n$ 的前两位、$CD=n$ 的后两位，
   在对应格填 1，其余填 0。
2. **圈组，按「能圈 8 圈 8、能圈 4 圈 4、剩了再圈 2」的顺序**。判一个矩形状组能不能圈，只看一条：
   组内每个格都是 1，且组**不能包含任何 0**。相邻包括最左列与最右列、最上行与最下行**卷起来相接**。
3. **每个圈写一个乘积项**：圈内**不变的变量**留下（取 0 写反变量、取 1 写原变量），**变的变量划掉**。
   全部乘积项相加，得最简与或式。
   圈完把所有 1 检查一遍：每个 1 至少被一个圈盖住；有富余的圈删掉（保持覆盖不变的前提下）。
4. **翻成与非门**：对最简与或式 $Y=P_1+P_2+P_3$ 两次取非，
   $Y=\overline{\overline{P_1}\cdot\overline{P_2}\cdot\overline{P_3}}$——外层一个与非门、
   里层每个乘积项一个与非门（乘积项有几个因子，与非门就做几个输入）。
   单个变量的反量（如 $\overline{D}$）用**一个与非门两输入并接**当非门用。

**坑**：

- 编号转二进制时把最高位当成了 D。约定 $Y(A,B,C,D)$ 里 **A 是最高位**，编号 $n$ 的二进制从左到右是 $A,B,C,D$。
- 圈组时把「数量多」当目标去凑含 0 的组。圈的唯一合法性判据是**组内无 0**；先找大组，再让小组补漏。
- 与非门实现时先对与或式再做一次化简（比如套摩根展开）。**不要**：两级与非结构吃的就是最简与或式，直接翻。

**自检**：把最简式按 16 组输入逐个代回（或写 16 行真值表），1 的行集合必须与题面 $\sum m$ 的编号集合**完全相同**——
多出一个或漏一个都说明圈错了。本题 16 组验算全一致（Octave 逐组核对）。

**原题**：[2026-10-14作业 习题 7.14](作业/2026-10-14-化简与两地控制灯.md)。

## 双投开关电路 → 逻辑函数式 {#m-switch-lamp}

**认出它**：题面给一张**实物电路图**（电源、灯、两只单刀双投开关分装两处），并已把状态赋值好
（开关向上 $=1$、灯亮 $=1$），只要求「写出灯亮的逻辑函数式」。

**路径**：

1. **给每个开关状态赋值**（题面已给）：$A=1$ 表示 A 向上扳，$B$ 同。
2. **追电流**：从电源一端出发，经过灯，走到两只开关之间的**两条联络线**。
   灯要亮（电路通），电流必须从 B 的刀出发、沿**某一条**联络线、穿过 A 的刀回到电源另一端。
3. **翻译成条件**：B 的刀接上联络线（$B=1$）时，需要 A 也接上联络线（$A=1$）才通；
   B 接下联络线（$B=0$）时，需要 A 接下联络线（$A=0$）才通。
4. **两种通电情形相或**：$Y=AB+\overline{A}\,\overline{B}$。
   即「两开关掷向同一侧灯就亮」——这正是**同或**（$Y=A\odot B$）。

**坑**：

- 把「A 向上 = 1」定成接**下**联络线。赋值必须跟题面的文字走（向上扳 $=1$），再跟图核对刀的画法。
- 忘了「两处都可以开闭」的含义：A、B **任一**个扳动都要能改变灯的状态——列完函数式后
  换 A、换 B 各试一次，Y 必须跟着翻转，否则电路抄错了。

**自检**：把 $AB+\overline{A}\,\overline{B}$ 列成两变量真值表，四行应是 $1,0,0,1$——
与「同侧亮、异侧灭」的直觉对上。本题已按四组逐行验算（Octave）。

**原题**：[2026-10-14作业 习题 7.15](作业/2026-10-14-化简与两地控制灯.md)。

## 状态表 → 多输出函数式与电路 {#m-truth-circuit}

**认出它**：题面给一张**逻辑状态表**（两个输入 $A,B$，三个输出 $Y_1,Y_2,Y_3$，各列写着
$A>B$、$A<B$、$A=B$ 这类含义），要求「写出**各输出端**的逻辑函数式，并画出逻辑电路图」。
多输出是它的标志：**每个输出单独走一遍「挑 1 写项」，最后画在同一张图里**。

**路径**：

1. **逐列挑 1**。对每个输出列：把该列 $=1$ 的行挑出来，每行写一个最小项
   （输入取 1 写原变量、取 0 写反变量），最小项相加。能合并的相邻项先合并（卡诺图或并项），
   剩不下合并的就逐项写。
2. **能化简的化简**。两输出若形状相同（比如都是「输入相同才为 1」），共用一个同或结构，图里少画一半。
3. **画电路图**。同一张图：先画公共的反相器（每个输入变量最多一个非门，输出供多处用），
   再画与门（每个乘积项一个），最后画或门（每个输出一个，把属于它的乘积项相加）。
   连线从左到右：输入 → 非门/与门 → 或门 → 输出端，**每个输出端标上它的符号**。

**坑**：

- 三个输出列各写各的、图里把同一变量的非门画了三遍。**非门公用**：一个变量一个非门。
- 把「$A=B$」这一列写成 $A\oplus B$。逐行核一遍：相同为 1 是**同或**，
  $Y_3=\overline{A}\,\overline{B}+AB$，与异或恰好相反。

**自检**：写完函数式后按状态表**逐行代回**——四个输入组合各自代入三个函数式，
得到的四行三元组必须与题面表格**逐格一致**。本题已按四行逐行验算（Octave，全一致）。

**原题**：[2026-10-19作业 习题 7.16](作业/2026-10-19-比较器与数据选择器.md)。

## 八选一数据选择器实现任意函数 {#m-mux-151}

**认出它**：题面点名 **74LS151 型 8 选 1 数据选择器**，给一个三变量函数
$Y(A,B,C)=\sum m(\cdots)$，要求「用该器件实现」。

**路径**：

1. **先写下器件的行为**（这是全部关键，卡在「不知道 151 是什么」就补这一条）：
   74LS151 有三个地址输入 $A_2A_1A_0$、八个数据输入 $D_0\sim D_7$、使能端 $\overline{S}$（低有效）、
   输出 $Y$。$\overline{S}=0$ 时，
   $$Y=\sum_{i=0}^{7} m_i\cdot D_i,$$
   其中 $m_i$ 是**地址变量** $A_2A_1A_0$ 的第 $i$ 个最小项：地址二进制读数等于 $i$ 的那一路，$D_i$ 被选通到 $Y$。
2. **把函数变量接到地址端**：函数的最高位接 $A_2$、次高位接 $A_1$、最低位接 $A_0$
   （题面写 $Y(A,B,C)$，则 $A_2=A,\ A_1=B,\ A_0=C$）。接好之后，$Y=\sum m_i\cdot D_i$
   里的 $m_i$ 恰好就是函数的最小项 $m_i(A,B,C)$。
3. **按函数的最小项清单设数据端**：清单里有的编号，$D_i$ 接 **1**（接电源 $V_{CC}$）；
   没有的编号，$D_i$ 接 **0**（接地）。
4. **使能端接地**：$\overline{S}=0$ 让器件工作。写答案时把四件事一次说全：
   地址接法、哪些 $D_i$ 接 1、哪些接 0、使能端怎么接。

**坑**：

- 地址高低位接反。$A_2$ 是**最高位**：$Y(A,B,C)$ 的 $A$ 接 $A_2$、$C$ 接 $A_0$。
  接反了数据端清单整个错位。写完把每个最小项「地址读数」核对一遍。
- 忘了使能端。$\overline{S}$ 悬空或接 1，器件不工作，$Y$ 恒 0。
- 把数据端接成函数值以外的「 clever 组合」。八选一实现三变量函数**不需要任何额外门**：
  数据端只有接 1 与接 0 两种。

**自检**：八个地址逐个代入——地址 $i$ 被选通时 $Y=D_i$，所以 $Y=1$ 的地址集合必须与题面
$\sum m$ 的编号集合一致。本题已按八组逐组验算（Octave，$Y=1$ 的地址恰为 $\{1,2,4,7\}$）。

**原题**：[2026-10-19作业 习题 7.20](作业/2026-10-19-比较器与数据选择器.md)。

## 基本 RS 触发器：由输入波形画 Q {#m-rs-basic}

**认出它**：题面给**基本 RS 触发器**（与非门构成，**低电平有效**）的 $\overline{R}_D$、$\overline{S}_D$ 波形，
要求画 $Q$ 端波形，且**初始状态 0 和 1 两种情况都要画**。

**路径**：

1. **默写功能表**（低有效，这是全部规则）：
   $\overline{S}_D=0,\ \overline{R}_D=1$ → 置 1（$Q=1$）；
   $\overline{S}_D=1,\ \overline{R}_D=0$ → 置 0（$Q=0$）；
   两个都 1 → **保持**；两个都 0 → **禁用**（题面波形里应避免出现）。
2. **把时间轴按「某个输入发生跳变的时刻」切段**。段内三个量（$\overline{R}_D,\overline{S}_D,Q$）都不变。
3. **逐段走**：段内看两个输入——有 0 的那侧生效（置 1 或置 0）；两个都 1 就把 Q 原样抄过来。
4. **两种初态各走一遍，画在上下两行**，并检查它们**何时汇合**：一旦某个输入的有效电平
   把 Q 强置成同一个值，之后两行必然重合（触发器的「记忆」被覆盖）。

**坑**：

- 把低有效看成高有效（看到 $\overline{S}_D$ 出现**低**电平才置 1，不是高电平）。
- 忘了「保持」：输入都无效时 Q **不是**归零，是原样保持——Q 的线在段内是一条平线。
- 两种初态各画各的、忘记标「从哪一刻起两行重合」。标出来（一句话或箭头）才是完整的答案。

**自检**：画完后逐段核——每段里 Q 的值，必须能从功能表**单独推出**（哪条规则、哪个输入电平）。
推不出任何一条规则的段就是画错了。本题已按 0.25 步长全程仿真核对（Octave，两初态翻转时刻逐点一致）。

**原题**：[2026-10-21作业 习题 8.1](作业/2026-10-21-触发器波形.md)。

## 钟控 RS 触发器：由输入波形画 Q {#m-rs-sync}

**认出它**：题面给 **CP、S、R** 三路波形，触发器是**钟控（同步）RS**——
**只有 CP 为高电平的时段里 S、R 才起作用**，CP 为 0 时无论 S、R 怎么变 Q 都保持。
要求画 $Q$ 波形（初始 0 和 1 两种情况）。

**路径**：

1. **默写行为**：CP $=1$ 期间按**高有效** RS 走——$S=1,R=0$ → 置 1；$S=0,R=1$ → 置 0；
   $S=R=0$ → 保持；$S=R=1$ → 禁用（题面应避免）。CP $=0$ → **无条件保持**。
2. **只列「CP 为高的窗口」**，从左到右编 CP₁、CP₂……对每个窗口问三个问题：
   窗口内 S 是几？R 是几？（S/R 在窗口内若中途跳变，按跳变点再细分。）
   按行为表得出「本窗口结束时 Q 应是几」。
3. **窗口之外全部平线**：CP $=0$ 的时段里 Q 一条平线拖过去——哪怕 S、R 正在翻转。
4. **两种初态各走一遍**：每一列窗口写两行结果，观察从哪个窗口起两行汇合。

**坑**：

- CP $=0$ 期间把 S 或 R 的脉冲当有效。**钟控的全部意义就在这条**：窗口外一律无效。
- S、R 在窗口**中途**跳变没细分。窗口内也要按跳变点切段逐段判（例如窗口前半 $R=1$ 后半 $S=1$，
  Q 在窗内就要翻两次）。
- 只画了一种初态。题面写明「初始状态为 0 和 1 两种情况」就**必须两行都画**。

**自检**：对每个 CP 窗口写一行「窗口内 S/R 取值 → 用了功能表哪一条 → Q 变成几」；
两种初态的 Q 波形从汇合时刻起必须**完全重合**。本题已按 0.25 步长全程仿真核对（Octave，翻转时刻逐点一致）。

**原题**：[2026-10-21作业 习题 8.2](作业/2026-10-21-触发器波形.md)。
