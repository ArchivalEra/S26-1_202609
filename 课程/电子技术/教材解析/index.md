# 电子技术教材解析

[返回课程索引](../index.md) · [教材章节解析模板](../../../模板/教材章节解析.md)

**教材版本待提供**，在确认书名、作者与版次前不建立章节解析文件。

- 教师当堂说明了教材的**性质**：本课教材把**模拟电子技术**与**数字电子技术**两门课**合成一门**，因此「讲不了那么深」；考研考电子方向的同学需另找经典教材与在线课程扩展。
- 教师给的**第一章学习顺序**（由浅入深）：半导体基础知识 → 半导体器件（二极管 → 特殊二极管 → 晶体管 → 场效应管 → 光电类器件）。
- 教师给的**第一章重点**：**PN 结的工作原理与单向导电性**；三极管的**电流分配与电流放大作用**；二极管、稳压管、三极管、场效应管的构造、工作原理、特性曲线与主要参数的意义；**含二极管的电路分析**。
- 教材名称、作者、版次与目录均**未给出**（转写中没有出现书名），待提供后按[维护条例](../../../维护条例.md)的「版本—章—节」结构建立解析。
- 教材解析的进度届时记在本索引下，并按 `第NN章-章名/` 建章节目录。
