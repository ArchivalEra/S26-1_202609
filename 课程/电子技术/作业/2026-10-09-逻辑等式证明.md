## 一、习题 7.8(1)（提公因子 + 消去法）

证明 $AB' + BD + A'D + DC = AB' + D$。

:::collapse accordion
- 提示
  后三项都含 $D$——先把它们凑到一起提公因子
  ① $BD + A'D + DC$ 每一项都有 $D$，提出来：$D(B + A' + C)$。
  ② 提出来的括号 $B+A'$ 正好是 $AB'$ 的**反**（因为 $\overline{AB'}=A'+B$）——这就是**消去法**的形状 $X+X'Y$。
- 完整解答
  **第一步：把三个含 $D$ 的项凑到一起**

  $$AB' + \big(BD + A'D\big) + DC.$$

  **第二步：从 $BD + A'D$ 提公因子 $D$**（分配律反用）

  $$BD + A'D = D(B + A').$$

  代入：

  $$AB' + D(A' + B) + DC.$$

  **第三步：对 $AB'$ 与 $D(A'+B)$ 用消去法**。取 $X=AB'$，则 $X'=\overline{AB'}=A'+B$，于是
  $D(A'+B)=X'\cdot D$。由消去法 $X + X'Y = X + Y$（取 $Y=D$）：

  $$AB' + D(A' + B) = AB' + D.$$

  **第四步：剩下的 $DC$ 被 $D$ 吸收**（吸收律 $D + DC = D$）

  $$AB' + D + DC = AB' + D. \qquad\blacksquare$$

  **答案**：左边 $= AB' + D =$ 右边。

  **验算（真值表穷举）**：$A,B,C,D$ 的全部 16 组取值代入左右两边，逐组相等；上面每一步也都与原式逐组比对过（Octave 16/16 一致）。
- 复盘
  这题的钥匙是「**先提公因子，再消去**」
  三个含 $D$ 的项是明摆着让你提取公因子的信号。提完之后括号里出现 $A'+B$，它正好是第一项 $AB'$ 的反
  （$\overline{AB'}=A'+B$），直接套消去法收尾。**凡某变量在多项里都出现，第一步永远是提公因子**；
  **提完看括号是不是另一项的反**——是，就能消去。
:::

## 二、习题 7.8(2)（展开消零 + 两次消去法）

证明 $BC + D + D'(B'+C')(DA+B) = B + D$。

> **先看清题面**：中间一项是 $D'(B'+C')(DA+B)$——**$D$、$B$、$C$ 各自带横线**（$B'$ 与 $C'$ 是**两个字母分别取反**，
> 不是整段 $\overline{B+C}$）。$D'$ 与后面两个括号是**相乘**关系。

:::collapse accordion
- 提示
  先把括号展开、划掉必为 0 的项，式子会立刻瘦下来
  ① $(DA+B)$ 展开成两项；② $D'$ 乘 $DA$ 里有 $D'D=0$，整项归零；
  ③ $B$ 乘 $(B'+C')$ 里有 $BB'=0$，也只剩一项；④ 剩下两项之间用消去法，最后吸收收口。
- 完整解答
  **第一步：展开 $(DA+B)$**

  $$D'(B'+C')(DA+B) = D'(B'+C')DA + D'(B'+C')B.$$

  **第二步：第一项含 $D'D=0$，整项归零**

  $$D'(B'+C')DA = (D'D)(B'+C')A = 0.$$

  只剩

  $$D'(B'+C')B.$$

  **第三步：展开 $(B'+C')B$，划掉 $BB'=0$**

  $$(B'+C')B = BB' + BC' = 0 + BC' = BC'.$$

  所以第三项 $= D'BC'$。原式化为

  $$BC + D + D'BC'.$$

  **第四步：对 $BC$ 与 $D'BC'$ 提公因子 $B$**

  $$BC + D'BC' = B\big(C + D'C'\big).$$

  **第五步：对括号用消去法**。取 $X=C$，则 $X'=C'$，由 $X+X'Y=X+Y$（取 $Y=D'$）：

  $$C + D'C' = C + D'.$$

  于是 $BC + D'BC' = B(C + D') = BC + BD'$。原式 $= BC + BD' + D$。

  **第六步：对 $BD'$ 与 $D$ 用消去法**。取 $X=D$（则 $X'=D'$），$BD'=D'\cdot B$：

  $$BD' + D = D + B.$$

  原式 $= BC + B + D$。

  **第七步：吸收**（吸收律 $B + BC = B$）

  $$BC + B + D = B + D. \qquad\blacksquare$$

  **答案**：左边 $= B + D =$ 右边。

  **验算（真值表穷举）**：$A,B,C,D$ 全部 16 组取值代入左右两边，逐组相等；上述七步每一步也与原式逐组比对，全部等价（Octave 16/16 一致）。
- 复盘
  摩根拆括号（本题不用）+ 展开消零 + 两次消去法
  拆完**先展开划掉必为 0 的项**（$D'DA=0$、$BB'=0$），式子会立刻瘦下来；
  剩下的互补对（$C$ 与 $C'$、$D$ 与 $D'$）就是消去法的下手点。**本题消去法用了两次**
  （先关于 $C$ 消掉 $C'$，再关于 $D$ 消掉 $D'$），最后一步吸收律收口。
  读题时务必看清**横线盖住谁**：$B'+C'$（两个字母各自取反）与 $\overline{B+C}$（整段取反）是两个不同的函数。
:::

## 三、习题 7.8(3)（互补律：四个最小项凑成 1）

证明 $AB + AB' + A'B + A'B' = 1$。

:::collapse accordion
- 提示
  四项正好是 $A$、$B$ 的全部四种组合
  ① 前两项提 $A$、后两项提 $A'$：$A(B+B') + A'(B+B')$。
  ② 括号里 $B+B'=1$（**互补律**），式子变成 $A\cdot1 + A'\cdot1 = A + A' = 1$。
- 完整解答
  **第一步：分组提公因子**

  $$AB + AB' + A'B + A'B' = A(B+B') + A'(B+B').$$

  **第二步：互补律 $B+B'=1$**

  $$= A\cdot 1 + A'\cdot 1 = A + A'.$$

  **第三步：再互补律**

  $$A + A' = 1. \qquad\blacksquare$$

  **答案**：左边 $= 1 =$ 右边。

  **验算**：四组取值代入，四项里**恰有一项为 1**（对应该组取值），左边恒为 1（Octave 4/4 一致）。
- 复盘
  这是「最小项之和恒为 1」的实例
  四个与项正好是二变量全部 4 个最小项。**一个逻辑式若列全了某几个变量的所有组合，它就恒等于 1**
  ——这是互补律的推广，也是后面卡诺图「全 1 可以圈成一整块」的根据。
:::

## 四、习题 7.8(4)（两边都化到最小项再比）

证明 $AB' + BC' + CA' = A'B + B'C + C'A$。

:::collapse accordion
- 提示
  两边结构对称（三项轮换）——都化到最小项再比集合
  ① 每项缺一个变量，用 $X+X'=1$ 补上，把两边都展开成**最小项表达式**。
  ② 两边最小项集合相同 ⇒ 逻辑函数相同 ⇒ 恒等。最小项表达式是唯一的，所以这是恒等的**机械判据**。
- 完整解答
  **左边展开成最小项**（每项缺的变量补齐）：

  - $AB'$ 缺 $C$：$AB'=AB'(C+C')=AB'C+AB'C'$；
  - $BC'$ 缺 $A$：$BC'=BC'(A+A')=ABC'+A'BC'$；
  - $CA'$ 缺 $B$：$CA'=CA'(B+B')=A'BC+A'B'C$。

  左边 $= AB'C+AB'C'+ABC'+A'BC'+A'BC+A'B'C$。

  **右边展开成最小项**：

  - $A'B$ 缺 $C$：$A'B=A'BC+A'BC'$；
  - $B'C$ 缺 $A$：$B'C=AB'C+A'B'C$；
  - $C'A$ 缺 $B$：$C'A=ABC'+AB'C'$。

  右边 $= A'BC+A'BC'+AB'C+A'B'C+ABC'+AB'C'$。

  **两边的最小项完全相同** ⇒ 逻辑函数相同 ⇒ 恒等。 $\blacksquare$

  **验算**：$A,B,C$ 全部 8 组取值代入左右两边，逐组相等（Octave 8/8 一致）。
- 复盘
  「两边都复杂」时就都化到最小项
  证明恒等式有个机械判据：**两边各自化成最小项表达式，集合相同就恒等**（教材原话：最小项表达式唯一）。
  本题两边都是三项轮换，本质是**三变量奇校验**（1 的个数为奇数时输出 1）。
:::

## 小结：这份作业要带走的东西

1. **提公因子是第一步**：某变量在多项里重复出现（7.8(1) 的 $D$）就先提出来，提完再看括号里有没有互补对。
2. **消去法 $X+X'Y=X+Y$ 是主力**：本题用了三次。用法——认准 $X$，把另一项写成 $X'\cdot Y$，就能消掉 $X'$ 只留 $Y$。
3. **展开后先划掉必为 0 的项**：$D'D=0$、$BB'=0$ 这类项一出现就整项归零，式子立刻变短（7.8(2)）。
4. **互补律把「全组合」收成 1**：式子若列全了某几个变量的所有组合，恒等于 1（7.8(3)）。
5. **恒等式的机械判据 = 最小项集合相同**：两边都复杂时，各自展开成最小项再比集合，不靠灵感（7.8(4)）。
6. **横线盖住谁必须看清**：$B'+C'$（各自取反）与 $\overline{B+C}$（整段取反）是两个函数——读错一处整题就废。
