## 一、习题 7.8(1)（提取公因子 + 消去法）

证明 $AB' + BD + A'D + DC = AB' + D$。

:::collapse accordion
- 提示
  后三项都含 $D$——先提公因子
  ① $BD + A'D + DC$ 每一项都有 $D$，提取：$D(B + A' + C)$。
  ② 提出来的括号里有 $A'$，而第一项 $AB'$ 里带着 $A$——$A$ 与 $A'$ 是一对互补变量，正是**消去法**的形状。
- 完整解答
  **第一步：后三项提取 $D$**

  $$AB' + BD + A'D + DC = AB' + D(B + A' + C).$$

  **第二步：对 $AB'$ 与含 $A'$ 的项用消去法**。把 $AB'$ 记作 $X$，则 $A'$ 就是它的"反变量"位置上的因子，
  用 $X + X'Y = X + Y$：$AB' + A'D = AB' + D$。

  **第三步：余下的 $D$ 项被 $D$ 吸收**（$D + D(\cdots) = D$，吸收律 $A+AB=A$）：

  $$AB' + D + D(B + C) = AB' + D. \qquad\blacksquare$$

  **答案**：左边 $= AB' + D =$ 右边。

  **验算（真值表穷举）**：$A,B,C,D$ 的全部 16 组取值代入左右两边，逐组相等（Octave 16/16 一致）。
- 复盘
  这题的钥匙是"公共因子 + 消去"
  三项都含 $D$ 是**明摆着让你提取公因子**的信号。提完之后 $A'$ 与第一项的 $A$ 构成互补对，
  直接套消去法 $X+X'Y=X+Y$ 收尾。**凡某变量在多项里都出现，第一步永远是提公因子**。
:::

## 二、习题 7.8(2)（摩根定律 + 两次消去法）

证明 $BC + D + D'(\overline{B+C})(DA+B) = B + D$。

:::collapse accordion
- 提示
  先拆整段横线，再"提公因子 + 消去"
  ① $\overline{B+C}$ 是**整段取反**，用摩根定律拆成 $B'C'$（第二个括号 $(DA+B)$ 上**没有**横线，原样保留）。
  ② 拆完把第三项展开，用 $D'\cdot D=0$ 划掉含 $D$ 的因子——式子会立刻瘦下来。
  ③ 剩下的项与 $BC$、$D$ 之间用**消去法** $X+X'Y=X+Y$，先后关于 $C$、关于 $D$ 各消一次。
- 完整解答
  **第一步：摩根定律拆第一个括号**

  $$\overline{B+C}=B'C'.$$

  代入原式：

  $$BC + D + D'B'C'(DA+B).$$

  **第二步：展开第三项，划掉必为 0 的因子**。$B'C'\cdot DA$ 里的 $D$ 与外面的 $D'$ 相与为 0，
  故只剩 $B'C'\cdot B = B C'$（幂等）：

  $$D'B'C'(DA+B) = D'B'C'DA + D'B'C'B = 0 + D'BC' = D'BC'.$$

  原式化为

  $$BC + D + D'BC'.$$

  **第三步：对 $BC$ 与 $D'BC'$ 用消去法**（关于 $C$ 的互补对，取 $X=C$、$Y=BD'$）：

  $$BC + D'BC' = B\,(C + D'C') = B\,(C + D') = BC + BD'.$$

  于是原式 $= BC + BD' + D$。

  **第四步：对 $BD'$ 与 $D$ 再用消去法**（关于 $D$ 的互补对，取 $X=D$、$Y=B$）：

  $$BD' + D = D + B.$$

  所以原式 $= BC + B + D$。

  **第五步：吸收**。$BC + B = B$（吸收律 $A + AB = A$，取 $A=B$）：

  $$BC + B + D = B + D. \qquad\blacksquare$$

  **答案**：左边 $= B + D =$ 右边。

  **验算（真值表穷举）**：$A,B,C,D$ 的全部 16 组取值代入左右两边，逐组相等（Octave 16/16 一致）；
  上述五步中的每一步也各与"原式"逐组比对过，全部等价。
- 复盘
  摩根定律 + 两次消去法
  凡看到**整段括号带横线**，第一步一律用摩根拆开成"与/或"互换 + 逐项取反。
  拆完先**展开划掉必为 0 的项**（如 $D'DA=0$），式子会立刻瘦下来；剩下的互补对（$C$ 与 $C'$、$D$ 与 $D'$）
  就是消去法的下手点。**本题消去法用了两次**（先关于 $C$ 消掉 $C'$，再关于 $D$ 消掉 $D'$），
  最后一步吸收律收口。
:::

## 三、习题 7.8(3)（互补律：四个最小项凑成 1）

证明 $AB + AB' + A'B + A'B' = 1$。

:::collapse accordion
- 提示
  四项正好是 $A$、$B$ 的全部四种组合
  ① 前两项提 $A$、后两项提 $A'$：$A(B+B') + A'(B+B')$。
  ② 括号里 $B+B'=1$（**互补律**），式子变成 $A\cdot1 + A'\cdot1 = A + A' = 1$。
- 完整解答
  **第一步：分组提公因子**

  $$AB + AB' + A'B + A'B' = A(B+B') + A'(B+B').$$

  **第二步：互补律 $B+B'=1$**

  $$= A\cdot 1 + A'\cdot 1 = A + A'.$$

  **第三步：再互补律**

  $$A + A' = 1. \qquad\blacksquare$$

  **答案**：左边 $= 1 =$ 右边。

  **验算**：四组取值代入，四项里**恰有一项为 1**（对应该组取值），左边恒为 1（Octave 4/4 一致）。
- 复盘
  这是"最小项之和恒为 1"的实例
  四个与项正好是二变量全部 4 个最小项。**一个逻辑式若列全了某几个变量的所有组合，它就恒等于 1**
  ——这是互补律的推广，也是后面卡诺图"全 1 可以圈成一整块"的根据。
:::

## 四、习题 7.8(4)（两边都化到最小项再比）

证明 $AB' + BC' + CA' = A'B + B'C + C'A$。

:::collapse accordion
- 提示
  两边结构对称（三项轮换）——都化到最小项再比集合
  ① 每项缺一个变量，用 $X+X'=1$ 补上，把两边都展开成**最小项表达式**。
  ② 两边最小项集合相同 ⇒ 逻辑函数相同 ⇒ 恒等。最小项表达式是唯一的，所以这是恒等的**机械判据**。
- 完整解答
  **左边展开成最小项**（每项缺的变量补齐）：

  - $AB'$ 缺 $C$：$AB'=AB'(C+C')=AB'C+AB'C'$；
  - $BC'$ 缺 $A$：$BC'=BC'(A+A')=ABC'+A'BC'$；
  - $CA'$ 缺 $B$：$CA'=CA'(B+B')=A'BC+A'B'C$。

  左边 $= AB'C+AB'C'+ABC'+A'BC'+A'BC+A'B'C$。

  **右边展开成最小项**：

  - $A'B$ 缺 $C$：$A'B=A'BC+A'BC'$；
  - $B'C$ 缺 $A$：$B'C=AB'C+A'B'C$；
  - $C'A$ 缺 $B$：$C'A=ABC'+AB'C'$。

  右边 $= A'BC+A'BC'+AB'C+A'B'C+ABC'+AB'C'$。

  **两边的最小项完全相同** ⇒ 逻辑函数相同 ⇒ 恒等。 $\blacksquare$

  **验算**：$A,B,C$ 全部 8 组取值代入左右两边，逐组相等（Octave 8/8 一致）。
- 复盘
  "两边都复杂"时就都化到最小项
  证明恒等式有个机械判据：**两边各自化成最小项表达式，集合相同就恒等**（教材原话：最小项表达式唯一）。
  本题两边都是三项轮换，本质是**三变量奇校验**（1 的个数为奇数时输出 1）。
:::

## 小结：这份作业要带走的东西

1. **提公因子是第一步**：某变量在多项里重复出现（7.8(1) 的 $D$）就先提出来，提完再看括号里有没有互补对。
2. **摩根定律拆整段横线**：见到 $\overline{B+C}$、$\overline{DA+B}$ 这种整段取反，第一步一律用摩根拆成与/或互换（7.8(2)）。
3. **互补律把"全组合"收成 1**：式子若列全了某几个变量的所有组合，恒等于 1（7.8(3)）。
4. **恒等式的机械判据 = 最小项集合相同**：两边都复杂时，各自展开成最小项再比集合，不靠灵感（7.8(4)）。
5. **消去法 $X+X'Y=X+Y$ 出现频率最高**：凡「一项与另一项的反相乘」都先想它。
