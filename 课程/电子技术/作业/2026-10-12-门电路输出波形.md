# 2026-10-12作业：门电路输出波形（习题 7.4）

## 1. 来源与边界

- **来源**：**学习通**上的作业，平台页眉（任务名）**逐字为「2026-10-12作业」**；共 **1 题**，平台小节写作「**简答题**」——即**教材习题 7.4**。
- **题面来源**：用户提供的 **1 张答题页截图**；截图**原件不入库**，文件名与 SHA-256 登记在[原始资料索引](../原始资料/index.md)。题面与图 7.01 已与**教材第 7 章章末习题 7.4 逐字核对一致**（该章原文档已归档，图 7.01 取自原文档内的图片对象）。
- **题型**：**画波形**——已知输入 A、B、C、D 的波形，画出 (b)~(g) 六个门电路的**输出波形**。
- **配图**：题面**有图**（图 7.01(a) 输入波形 + (b)~(g) 六个门电路），已按「题面必须完整」把**输入波形与六个门电路一并画在题面里**（下方两图）；六个门的**输出波形**是本作业的答案，在解答层给出。

## 一、六个门的逻辑表达式（先立式，再画波形）

| 门 | 结构 | 表达式 | 化简结果 |
| :-: | :--- | :--- | :--- |
| (b) | 与门（输入 A 与常数 1），输出取反 | $Y_b=\overline{A\cdot 1}$ | $Y_b=\overline{A}$ |
| (c) | 与门（输入 C 与常数 0），输出取反 | $Y_c=\overline{C\cdot 0}$ | $Y_c=1$ |
| (d) | 三输入与门（A、B、C），输出取反 | $Y_d=\overline{ABC}$ | $Y_d=\overline{ABC}$ |
| (e) | 或门（B、D），输出取反 | $Y_e=\overline{B+D}$ | $Y_e=\overline{B+D}$ |
| (f) | 异或门（A、D），输出取反 | $Y_f=\overline{A\oplus D}$ | $Y_f=A\odot D$（同或） |
| (g) | 与或非门：上 $(A\cdot B)$、下 $(C\cdot D)$ 各进一个与门，再进或门取反 | $Y_g=\overline{AB+CD}$ | $Y_g=\overline{AB+CD}$ |

> **两个「接常数」的门先看穿**：$A\cdot 1=A$（常数 1 让与门「透明」，再取反就是**把 A 反相**）；
> $C\cdot 0=0$（常数 0 把与门钉死为 0），取反后**恒为 1**——C 的波形再怎么样都不影响 (c) 的输出。

## 三、逐门解析

### (b) 与门（A、1）取反

:::collapse accordion
- 提示
  与门一个输入接常数 1，先化简再想取反泡
  ① $A\cdot 1=A$，所以这就是**把 A 取反**；② 输出端的小圆圈再做一次取反，合起来就是 $\overline{A}$。
- 完整解答
  表达式：$Y_b=\overline{A\cdot 1}=\overline{A}$。

## 小结：这份作业要带走的东西

1. **常数输入先化简**：与门接 1 → 透明（等于另一个输入）；接 0 → 死门（恒 0）。取反泡再翻一次。
2. **取反泡只在输出端**：读门时先看门体符号（`&`/`≥1`/`=1`），再看输出端有没有小圆圈——有泡就把整个结果取反。
3. **或非 / 与非 / 同或**：分别是「或门 + 泡」「与门 + 泡」「异或门（`=1`）+ 泡」；`=1` 加泡 = 同或，别看成异或。
4. **画波形三步**：写表达式 → 化简 → 逐段代入。多输入门就找「高电平重叠区」。
5. **复合门拆开读**：像 (g) 这种与或非门，拆成「与门 → 或门 → 取反」再逐块写式子。
