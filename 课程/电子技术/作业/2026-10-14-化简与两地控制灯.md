## 2. 习题 7.14

**题面**（逐字）：

> 7.14　设 $Y(A,B,C,D)=\sum m(2,4,8,10,12,14)$。要求：(1) 化简逻辑函数式；(2) 画出用与非门实现的逻辑电路图。

:::collapse accordion
- 提示
  入口判据：本题落在[技法库 · 四变量卡诺图化简 → 与非门电路](../技法库.md#m-kmap-nand)，照条目走。
  本题特有的一眼：六个最小项编号（2,4,8,10,12,14）写成四位二进制后**末位全是 0**——D 在每个 1 里都取 0。
- 完整解答
  **卡诺图**（行 $AB$、列 $CD$，格雷码排布）：

  | $AB\backslash CD$ | 00 | 01 | 11 | 10 |
  | :---: | :-: | :-: | :-: | :-: |
  | **00** | 0 | 0 | 0 | **1** |
  | **01** | **1** | 0 | 0 | 0 |
  | **11** | **1** | 0 | 0 | **1** |
  | **10** | **1** | 0 | 0 | **1** |

  **圈组**（三组，全部只含 1）：

  - 四连框 $m_8,m_{10},m_{12},m_{14}$：$A=1,D=0$ 不变 → $A\overline{D}$；
  - 竖对 $m_2,m_{10}$：$B=0,C=1,D=0$ 不变 → $\overline{B}C\overline{D}$；
  - 竖对 $m_4,m_{12}$：$B=1,C=0,D=0$ 不变 → $B\overline{C}\,\overline{D}$。

  四连框 $A\overline{D}$ 走的是**卷边**：列 $CD=00$ 与 $CD=10$ 首尾相接，两个列编码的公共位是
  $D=0$（$A,B$ 在行方向也公共为 $A=1$），被消去的是 $C$——**逐位比对**：$m_8=1000$、$m_{10}=1010$、
  $m_{12}=1100$、$m_{14}=1110$，四个编号里 $A=1$、$C$ 有 0 有 1、$D=0$。

  **(1) 最简与或式**：

  $$Y=A\overline{D}+\overline{B}C\overline{D}+B\overline{C}\,\overline{D}.$$

  **(2) 两级与非**：对与或式两次取非，
  $Y=\overline{\;\overline{A\overline{D}}\cdot\overline{\overline{B}C\overline{D}}\cdot\overline{B\overline{C}\,\overline{D}}\;}$——
  三个乘积项各用一个与非门（输入数 2、3、3），输出再接一个三输入与非门；四个反量
  $\overline{A},\overline{B},\overline{C},\overline{D}$ 用四个非门（与非门两输入并接）产生。

图 7.05　习题 7.15 图（两处控制照明灯；上端子与下端子接 ~220 V，灯 ⊗ 标 $Y$，
A、B 为两只单刀双投开关，两条水平联络线在 A、B 之间交叉换位）。

:::collapse accordion
- 提示
  入口判据：本题落在[技法库 · 双投开关电路 → 逻辑函数式](../技法库.md#m-switch-lamp)，照条目追电流。
  本题特有：图里 A 的刀画在**向上**位置、B 的刀画在**向下**位置——那是「画出来的当前状态」，
  不是答案；答案要覆盖 A、B 的**全部四种**组合。
- 完整解答
  **追电流**：电源上端 → 灯 $Y$ → 右侧竖线 → **B 的刀**。B 的刀只会接在两条联络线之一上：

  - $B=1$（向上扳）：B 的刀接**上联络线** → 电流走上线 → 到 A 端。A 要把电流送回电源下端，
    A 的刀也必须接上联络线，即 $A=1$。**通**。
  - $B=0$（向下扳）：B 的刀接**下联络线** → 电流走下线 → A 的下触点。A 的刀接下联络线
    （$A=0$，向下扳）才通。**通**。

  其余两种组合（一上一下）：B 的刀走的联络线，A 的刀没有接到——断路，灯灭。
  （图里画着的当前状态——A 向上、B 向下——正是一上一下的**异侧**断电态。）

  $$Y=AB+\overline{A}\,\overline{B}.$$

  即**同或**：$Y=A\odot B$。真值表（四行验算，与 Octave 逐行一致）：

  | $A$ | $B$ | $Y$ | 含义 |
  | :-: | :-: | :-: | :--- |
  | 0 | 0 | 1 | 都向下，通 |
  | 0 | 1 | 0 | 异侧，断 |
  | 1 | 0 | 0 | 异侧，断 |
  | 1 | 1 | 1 | 都向上，通 |
- 复盘 :-
  这道题的「图」是实物图，逻辑藏在**连通性**里：把「B 的刀接哪条线」「A 的刀接哪条线」
  翻译成 $B$、$A$ 的取值，通电条件就自动写成了 $AB+\overline{A}\,\overline{B}$。
  画成电路恰好是「一根同或」——两处开关各动一个，灯的状态必翻转，这正是两地控制的本意。
:::
