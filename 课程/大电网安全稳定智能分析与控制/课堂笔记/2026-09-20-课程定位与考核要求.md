## 4. 数据链与「为什么必须用智能分析」

### 4.1 课堂上给出的数据链

按顺序记住这条流水线，第 3 章以后都挂在这条线上：

**采集 → 预处理（采集、存储、传输、计算）→ 特征选择 / 特征提取 → 辨识 → 执行（决策）**

几个配套概念：

- **在线 / 离线 / 实时**：在线是即采即用——采到就运算，运算完马上有结果；实时强调延迟短。教师用「网上下单、网上订餐、看视频」类比实时性。
- **数据丰富但信息贫乏**：海量数据里哪些是有用的、哪些对判断稳定可靠与经济性有帮助，需要**数据挖掘与可视化技术**把数据转成信息与知识。
- **目标形态**：教师转述教材的思路——用数据挖掘与人工智能学出稳定规则，从而在故障后**快速、准确**地评估稳定性，给调度控制提供决策依据。他用的说法是「建立一个经验丰富的机器调度员」。
- **调度指令的位置**：调度中心的指令是在分析运行实时数据之后生成的，不是凭空发出的。

### 4.2 为什么人工做不了（动机链）

1. **数据量激增**：教师举例说，翻一下手机、下一个单都立刻产生大量数据，存储与处理靠人工不现实。
2. **电网复杂化**：联网范围扩大、电压等级提高，受控元件（电机、变压器、开关电器等）急剧增多，**控制模式难以协调**。
3. **设备老化与损坏**带来故障隐患；极端环境下的故障排查（教师举深海、太空、火星探测）人工做不到，只能靠人工智能。
4. **大停电的机理链**（教师讲授的重点逻辑）：事故初期，调度中心无法迅速预判故障后系统的稳定性并及时干预 → 暂态稳定被破坏 → 极易发展成连锁故障 → 大面积停电。
5. **四个「不及时」**：不能及时发现、不能及时传输、不能及时计算、不能及时处理——这正是要靠大数据与人工智能去补的环节。
6. **评价视角**：教师提出，看一个国家的电力系统水平可以看每年的停电小时数（课堂说法，未给出数据来源）。

### 4.3 建模的两难（教师反复强调的一对矛盾）

- 技术路线是「物理模型 → 按物理定律列方程 → 数学模型」，所谓专业方法本质上都是**建模**。
- **模型越精确，计算越复杂**：精确到一定程度，计算量会大到不现实；教师甚至提到超大规模计算机也难以承载。
- 因此要在**准确性**与**快速性**之间权衡，找最优方案。
- 传统电力系统理论计算得到的结果**过于保守**。教师对「保守」的解释是**约束条件苛刻、限制多**（他用的类比是「一套班规只适用于本班」）。过于保守既不利于电网高效稳定运行，也不利于未来规划——**这是引入人工智能与大数据的原因**。

## 5. 安全稳定的概念群：平衡态、扰动与特征值判据

这一段是本次课唯一的「硬概念」部分，教师讲得很口语，下面按他的讲授顺序整理。

### 5.1 平衡态与扰动

- **平衡态**：教师用匀速直线运动类比——加速度为零就是平衡。推广到振动情形，要靠**复数**描述：实部加虚部。
- **扰动**：参数或负荷的变化。教师的例子是一个简单电路里可变的电阻：电阻值**微小**变化（如增加 0.01 欧姆）是**小扰动**，从 1 欧姆变到 100 欧姆这种大幅变化是**大扰动**。他说「记得一个变化我们就叫做扰动」。
- **二阶系统**：一个电感加一个电容，两个储能元件就是二阶系统，动态方程是二阶微分方程。教师用它引出下面的判据。

### 5.2 特征值判据（整理者按教师讲授内容规范化表述）

把运动写成 $\lambda=\sigma+j\omega$ 的形式，$\sigma$ 是实部、$j\omega$ 是虚部：

| 虚部 | 实部 | 运动形态 | 稳定与否 |
| :--- | :--- | :--- | :--- |
| $\omega=0$ | — | 非振荡（教师说「直线运动」，虚部为零） | 看实部 |
| $\omega\neq0$ | — | 振荡（教师说「非直线运动」，用圆周运动类比） | 看实部 |
| 任意 | $\sigma<0$ | 收敛：振幅越来越小 | **稳定** |
| 任意 | $\sigma>0$ | 发散：振幅越来越大 | **不稳定** |
| 任意 | $\sigma=0$ | 临界 | 教师未展开 |

- 教师用**弹簧加阻尼**类比 $\sigma<0$：阻力作用使振幅越来越小，直到停下来，所以收敛；反之发散。
- **稳定性的定义来自李雅普诺夫**（教师称其为数学家兼物理学家）。他说本课程用到的稳定性定义就是他提出的。
- 教师把特征值叫做「运动的特征」，本课程的做法就是**用运动的特征去分析运动本身**是平衡态、稳定态还是不稳定态。
- 由特征值区分出**静态稳定约束、小扰动稳定、暂态（大扰动）稳定**三类考察角度。

> 整理者说明：$\lambda=\sigma+j\omega$ 这套记号和符号命名是整理者按通用写法补的，转写中教师只用「实部」「虚部」口语表述，未见板书公式。

### 5.3 扰动大小与稳定类型

- **小扰动稳定**：扰动足够小（如电阻变化 0.01 欧姆）时的稳定性。
- **暂态稳定 / 大扰动稳定**：扰动很大（如电阻从 1 欧姆变到 100 欧姆）时的稳定性。
- 教师强调这一分类的意义在于：**稳定与否要看是哪种扰动下的稳定**，判据虽然都回到特征值，但考察的场景不同。

## 6. 稳定性评估方法、安全域与安全裕度

### 6.1 两类基本方法

| 方法 | 教师的口语说法 | 含义 | 特点 |
| :--- | :--- | :--- | :--- |
| 数值法 | 「终点法」「驻点法」（同音，具体用字待核实） | 按指定运行方式、在固定故障方式下用数字计算近似求解 | 近似；规模越大复杂度越高，代价高 |
| 解析法 | 解析法 | 求出解析表达式（教师举 $y=ax^2+bx+c$ 为例） | **精确**，但规模大时难以获得解析解，只适合小规模简单系统 |

**结论**：规模越大越只能走数值路线，而数值路线的复杂度又随规模上升，所以最终**不得不借助人工智能与大数据技术**。

### 6.2 暂态稳定评估的具体方法

- **仿真计算法**：后文常用的工具，教师要求自行安装 MATLAB（他说「矩阵实验室」，学名 MATLAB，约 30 GB，最新版可能更大），并说下学期三门专业课（电力电子技术、自动控制原理、电力系统分析）都要用。本仓库已在工程数学部分做过 MATLAB 命令的复现，见 [1.4 用MATLAB计算行列式](../../工程数学/教材解析/第一部分-线性代数/第1章-行列式/1.4-用MATLAB计算行列式.md) 与 [2.5 用MATLAB进行矩阵运算](../../工程数学/教材解析/第一部分-线性代数/第2章-矩阵/2.5-用MATLAB进行矩阵运算.md)。
- **直接法**：定性分析，用李雅普诺夫方法，回到「特征值实部是否小于零」。
- **故障响应法**：直接看故障响应的波形——故障电流幅值越来越小、衰减到零，说明稳定；越来越大、发散，说明不稳定。教师说这个方法**直观**。

### 6.3 安全域与稳定域

- **安全域**：能够在**预想故障**下保证系统安全稳定运行的**运行点的集合**。教师说这是名词解释的考点，并提醒「考试的时候一定要找到位置」。
- 按所保证的性质分类：**静态安全域**（保证静态稳定）、**电压稳定安全域**、**小扰动稳定安全域**、**动态安全域**（保证暂态稳定）。实际电网需要运行在以上安全域构成的**综合安全域**内。
- **为什么研究安全域**：如果拿到安全域的边界，落在域内的运行点在预想故障下都能稳定运行，落在域外则会出现安全稳定问题，于是**在线安全评估变得方便**。
- **安全域的第二个用处**：给出当前运行点到边界的**距离信息**，从而提供安全裕度与最优控制信息，实现预防控制与安全预警。（最优控制是研究生阶段课程。）
- **参照概念**：`自动控制原理`（下学期）里的**稳定裕度**，包含**幅值裕度**与**相角裕度**两个从频率分析得到的指标（转写把这两个词误识别成「扶持力度/向导力度」，此处按标准术语补正）。教师说这些只需了解概念。
- **动态安全域的三个性质**（教师明确说**不在考试范围**）：内部连通且稠密；边界连通、不缠绕交错；边界可微。他还提到文献证明动态安全边界可以表示为**超平面叠加**的形式。
- **求解动态安全域**：教师说有两类方法（转写只说清了一类是解析法，另一类的名称转写不明确，见第 8 节），取决于系统给定拓扑与元件后的唯一确定性。

### 6.4 稳态分析与暂态分析的区分

| 分析类型 | 教师说法 | 方程类型 | 本课程要求 |
| :--- | :--- | :--- | :--- |
| 稳态分析 | 用相量（复数）表示，相当于微分项为零 | **代数方程** | **只要求会解代数方程** |
| 暂态/动态分析 | 量随时间变化，需要求解 | **微分方程**（连续）或**差分方程**（离散） | 难度大，本课程只要求有概念，不要求解 |

- 暂态再细分：**机电暂态**——原动机与发电机之间的过程，如水轮机、汽轮机、风力机驱动发电机；**电磁暂态**——单纯研究电力系统内部的电磁过程，如故障本身。教师说现阶段主要学机电暂态，且电网具有**特高维度**（这里转写有几处错别字）。
- 教师强调本课程「求的都是代数方程」，不要求解微分方程。

## 9. 与既有材料的关系与复习顺序

**与既有材料的关系**：本课程此前在仓库里只有目录骨架（[课程索引](../index.md)）。本篇是这门课的第一份实质内容；原始转写已按课程分类归档到[原始资料](../原始资料/index.md)。

**给同学的复习顺序**：

1. 先记死考核与题型（第 2 节）：开卷、只带教材、平时 50% + 卷面 50%、旷课规则、五大题型、名词解释与简答集中在那三处「现状」。

4. 记硬概念（第 5 节）：扰动的大小之分、特征值的实部定稳定/发散、三类稳定。
