## 2. 样式表口径（076 §1 定的基准，我实际用的值）

- **框体**：74LS290 用 3.2×4.4（局部单位），74LS161 用 3.4×5.6，与 076 给的数一致；触发器单元框 1.9×2.4。
- **线宽**：统一 0.7 pt；框体 0.8–1.0 pt（`thick`），比导线略粗以分层次。
- **字号**：框内端子名 `\small`，框名/子图号 `\footnotesize`，引脚电平标注 `\small`。**这一项我改过一次**：初版用 `\scriptsize`，按 SVG 的自然尺寸换算只有 6.6 px，达不到 076 §1 的「≥12px 等效」；上调后正文/端子名在自然尺寸下是 **13.3 px**，仍低于 12px 的只剩上标下标（`CP₀` 的 `0`、`D₃` 的 `3`，8.0 px）——下标比正文字号小是排版惯例，若你们要求下标也 ≥12px，说一声我把下标改成全尺寸写法（`CP0`）。
- **引脚间距**：输入侧 0.6–0.7 局部单位，≥ 字高。
- **门符号**：IEC 60617 矩形框，与门/与非门框内标 `&`，与非门输出端加直径 0.16 的圆圈。
- **走线**：全部水平/垂直直角；为满足「不穿框、不压字」，我给每张图分配了互不重叠的走线通道（下面 §3 有说明），文字一律落在导线上方或下方，不让线穿过字符。

## 3. 4 张图的画法与歧义处理

**图 8.04**（六子图）：6 个触发器单元按 3×2 排布。反馈线从本框右侧 `Q` / `Q̄` 引出，先向右出到框外的竖直通道，再下到底部通道，横穿到左侧通道，上到目标输入脚。通道置于输出标签（`Q` / `Q̄`）之外，所以竖线不压标签。悬空端画短引线，电平写在该引线**上方**（`1` / `0`），这与框内端子名同位，不额外占通道。

**图 8.05**（波形）：10 个等分段，段边界即沿。CP 四个正脉冲（0–↑1 起高、↑1–↓1 低……按 076 §3 表格逐段实现）；D 前段高，`↓2` 起落到低，`D↑` 落在 `↓3` 与 `↑4` 之间回到高，末尾保持高。**不画刻度**（076 说原图无刻度）。左端标 `CP` / `D`，右端不封口。

**图 8.12**（两片 74LS290）：片 1 标 `unit (ones)`，片 2 标 `tens`（076 说框外标「片 1（个位）」/「片 2（十位）」——我用英文标签，理由见 §4）。
- 片 1：`CP₀` 接外部输入端子（左端标 `CP`），`CP₁` 接本片 `Q₀`，`R₀(1)`/`R₀(2)`/`S₉(1)`/`S₉(2)` 全部接地（短引线 + `0`）。
- 片 2：`CP₀` 接片 1 的 `Q₃`（两片之间一条水平直线），`CP₁` 接本片 `Q₀`，`R₀(1)` 接本片 `Q₂`，`R₀(2)` 接本片 `Q₁`，`S₉(1)`/`S₉(2)` 接地。
- **这里我要说明一处取舍**：片 2 的三条片内反馈（`Q₀→CP₁`、`Q₂→R₀(1)`、`Q₁→R₀(2)`）**至少要有 2 处导线交叉**，这不是我布线没优化：三个源引脚自上而下是 `Q₂(3.2) / Q₁(2.5) / Q₀(1.8)`，三个目标自上而下是 `CP₁(3.2) / R₀(1)(2.5) / R₀(2)(1.9)`，映射 `Q₀→CP₁`、`Q₁→R₀(2)`、`Q₂→R₀(1)` 展开成目标次序是 `3.2, 1.9, 2.5`，**逆序对数 = 2**；单层平面布线的最小交叉数就是这个值（我写了个检查器穷举左/右竖通道与顶部通道的取值组合验证过）。
  我把三条做成顶部嵌套绕行（内 `y=5.2` / 中 `y=5.9` / 外 `y=6.6`），**交叉点全部落在片体上方的空白区**——不穿框、不压字，这是我能做到的最干净的形态。若你们要求交叉处画跨接弧（jump/hop），说一句我加；那种画法在印刷教材里也常见。级联标注 `Q₃ → CP₀` 放在两片之间的直线段上方（初版放在偏右，被最外侧反馈竖线压住，已修）。
