# 静态阅读站前端实现计划书

本文件交**前端实现者**执行：把这个仓库的 Markdown 内容做成一个**纯文本 + 公式的静态阅读站**，部署后由反向代理提供给**中国大陆**用户（本仓库直连 GitHub 基本不可用）。

仓库维护规则见[维护条例](../维护条例.md)与[维护细则](../维护细则.md)；内容侧（`.md` 正文）由维护者负责，不要改动正文内容。

## 1. 目标与范围

**要做**：把仓库里的 Markdown 渲染成可读、可导航、公式正确的中文网页，并保证**离线自持、零第三方外网请求**。

**不做**：网页**不提供任何图片**。仓库内的照片原件不随站点发布；页面里出现的资源链接一律降级为纯文本说明。

### 纳入站点的内容

| 范围 | 说明 |
| :--- | :--- |
| `README.md` | 仓库总入口，含自动生成的课程目录 |
| `课程/**` | **主体**：各级 `index.md` + 11 篇正文（9 篇教材解析 + 2 篇课堂笔记） |
| `维护条例.md`、`维护细则.md` | 可选，作为「仓库说明」区 |

### 排除（不要渲染进站点）

`模板/`（含未填写占位符）、`knowledge/`（历史迁移存根，只有一行跳转）、`.agents/`、`.zcode/`、`.githooks/`、`Original/`（空目录）。

## 2. 内容事实（供你估算工作量，均为实测）

- 正文：**11 篇**。最重的单页 `课程/工程数学/教材解析/第一部分-线性代数/第2章-矩阵/2.1-矩阵的概念及运算.md` 为 **652 行、445 个公式**。
- 全部 Markdown 约 **252 KB**，全仓约 **1,595 个行内公式 `$…$`** 与 **264 个块级公式 `$$…$$`**。
- 每个文件都有 YAML frontmatter（见 §5）。
- 文件与目录名**含中文**，且章节目录形如 `第02章-矩阵`、文件名形如 `第02章-2.1-矩阵的概念及运算.md`。
- 正文语言为简体中文，数学符号用 LaTeX。

## 3. 公式兼容性要求（最重要的一节）

全仓约 1,859 个公式。下表逐类列出**真实位置与规模**及必须满足的行为。**渲染器选型由你决定**：可以用 KaTeX、MathJax，也可以多套解析器并存、按构造特征或文件名分类分派渲染管线——只要最终结果一致且零报错。

**解析顺序的硬要求**：`代码围栏 → 数学 → 链接/强调`。先切出代码块，再提取数学，最后才处理 Markdown 的链接与强调语法。

| # | 构造 | 真实位置与规模 | 要求 |
| :--- | :--- | :--- | :--- |
| 1 | **数学模式内裸中文** | `第02章-2.3-矩阵的初等变换与初等矩阵.md` 原 154/165/178 行，`\begin{matrix}` 内标注「第 i 行」 | KaTeX 在数学模式遇非 ASCII 会**直接解析失败**，MathJax 可渲染。维护者已把这三处改成 `\text{第 }i\text{ 行}`，但**不要依赖这一点**：渲染管线应能兜住未包裹的裸中文（例如预处理自动包裹，或该文档走 MathJax）。**验收要求：必须渲染出中文标注，不得报错、不得丢字。** |
| 2 | `\tag{...}` 原书公式编号 | 7 处：`第01章-1.1`:37/41/48/54、`第01章-1.3`:36/95/190 | KaTeX 仅在 display 模式支持；MathJax 需开启 tags。**编号必须显示**（抄录可核对性依赖它），不得报错、不得吞掉编号 |
| 3 | `\begin{array}{ccc\|cc}` 沙路法则 | 1 处：课堂笔记 `2026-09-17-determinants-order-2-3.md`:43 | 列格式里的竖线必须渲染为**列间分隔线** |
| 4 | 矩阵与分段环境 | `pmatrix` 303 次、`vmatrix` 139 次、`cases` 20 次、裸 `matrix` 7 次 | 必须支持 amsmath 矩阵族与 `cases` |
| 5 | **行内公式内含 `\\`**（单行内嵌矩阵） | **126 处**，例如 `$AB=\begin{pmatrix}13&-1\\0&-5\end{pmatrix}$` | 必须先提取 `$…$` 再交渲染器；**Markdown 层不得把 `\\` 当硬换行**，否则矩阵会被拆散 |
| 6 | `\xrightarrow[\substack{...}]{...}` | 31 处，其中 5 处上层参数为空 `{}`（`1.2`:384/398/411、`1.3`:133、`2.3`:264） | 需 amsmath 与 `\substack`；**空参数不得报错** |
| 7 | 命令紧挨圆括号 | `\bigl[…\bigr]` 4 处（`1.2`:448/455、`1.3`:72/75），另有 `\operatorname{diag}(…)` 等 4 处 | 数学解析必须**先于**链接解析。若先跑链接规则，`\bigr](a-b)^{n-1}` 这类会被误判成 Markdown 链接 `[…](…)` |
| 8 | `$$…$$` 与正文同行 | 全仓 **398 行**含 `$$` 同行 | 必须支持同行块公式，**不得要求 `$$` 独占一行** |
| 9 | 表格单元格内的行内公式 | 42 行 | 表格结构不得被公式破坏。正文已用 `\vert` 规避公式内裸竖线，你的管线也不得把公式里的竖线当列分隔 |
| 10 | 超长公式行 | 最长 1 处 **644 字符**（`第02章-2.2-逆矩阵.md`:112），另有 8 处 250–400 字符 | 需横向滚动或允许断行，**不得撑破版心** |
| 11 | 定界符紧贴中文/全角标点 | 32 行，如 `（$D=0\Rightarrow$ 有非零解）` | 用正则配对公式时不得误判；全角括号与 `$` 之间没有空格是**正常写法** |
| 12 | 代码块内含反斜杠 | `第02章-2.5`:154 的 `>> C=A\B`（MATLAB 左除） | 代码围栏解析必须**优先于**公式解析；不得把 `\B` 当 LaTeX |
| 13 | `\text{中文}` | 25 处，如 `第02章-2.2`:31「工厂一」、笔记 `order-2-3`:63「正项」 | 字体栈必须有**中文回退**，不得出现豆腐块 |
| 14 | 词内下划线 | 少量（链接文本里的文件名，如 `20260917_13301545-原文.doc`；YAML 里的 `id`） | 不得被解析成斜体。YAML 只出现在 frontmatter，不要当正文渲染 |

**汇总一句话**：渲染器需支持 amsmath（矩阵族、`\tag`、`\xrightarrow`、`\substack`）、支持同行 `$$`、公式内 `\\` 与竖线不被 Markdown 层破坏、中文有字体回退。渲染器 JS/CSS/字体必须**随仓库自持**（见 §6）。

## 4. 页面与呈现要求

### 4.1 frontmatter 处理

每个文件以 `---` 包裹的 YAML 开头，字段：`id`、`name`、`type`、`spec_version`、`status`、`last_updated`、`stewards`、`course`、`category`、`sources`（部分文件另有 `date`、`tags`）。

- **不要原样显示 frontmatter**。
- `name` → 页面标题（与正文 H1 基本一致）。
- `course` / `category` / `status` / `last_updated` / `sources` → 页首或页尾的**元信息条**。
- `id` → 稳定的路由键，可用于生成锚点。

### 4.2 导航

- **侧栏树**：课程 → 五个类别（作业、教材解析、课堂笔记、原始资料、音频）→ 文档。类别与文件从目录结构推导。
- **面包屑**：`总入口 / 工程数学 / 教材解析 / 第2章 矩阵 / 2.1 …`。
- **同章上一节 / 下一节**：教材解析文件按章内节号排序给出相邻链接。
- 每页提供「回到所属索引」的链接。

### 4.3 链接重写

仓库内 Markdown 之间的相对链接要改写成生成的 `.html` 目标。**两种写法都要兼容**：

- README 的自动目录用**百分号编码**的中文路径，如 `./%E8%AF%BE%E7%A8%8B/%E5%B7%A5%E7%A8%8B%E6%95%B0%E5%AD%A6/index.md`；
- 手写索引文件里是**未编码**的中文路径，如 `./工程数学/index.md`。

链接里可能出现 `../` 上跳多级（如 `../../../模板/教材章节解析.md`）。指向**被排除内容**（如 `模板/`）的链接不应生成死链，可标注为「不随站点发布」。

### 4.4 非 Markdown 资源

正文里存在指向 `.jpg`、`.heic`、`.doc` 的链接。**站点不提供这些文件**：

- 渲染为**纯文本文件名**，并注明「原件不入库，网页不提供」。
- **不得留下指向不存在文件的死链。**

### 4.5 结构细节

- **隐藏 HTML 注释**：README 的 `<!-- AUTO-CATALOG:START/END -->` 标记与末尾内容摘要注释必须隐藏。
- **宽表格**：`第02章-2.1`:258–262 有一个九列拼版表，容器需可横向滚动，不得破版。
- **表格样式**：正文是 GitHub 风格表格（表头 + `| :--- |` 分隔行）。
- **代码块**：等宽字体，MATLAB 提示符 `>>` 与输出原样保留；建议标出语言。
- **公式排版**：`\tag` 编号靠右且不溢出；长公式容器可横向滚动。
- **中文排版**：字体栈含中文回退（正文与公式内一致）；行宽舒适、行高适中；移动端可用。
- **可选优化**（你有充分的发挥空间，不强制）：全文搜索、深色模式、标题锚点、键盘翻页。

## 5. 部署与反代要求

站点会被挂在**反向代理的子路径**下（不一定在域名根），例如 `https://example.com/repo/`。

1. **资源引用必须与基路径无关**：用相对路径，或构建期注入可配置前缀。**禁止**使用 `/assets/...` 这类根绝对路径。
2. **不建议使用 `<base href>`**：它会改写页面内所有相对 URL 与锚点的解析基准，容易连带破坏目录锚点。
3. **中文路径统一百分号编码**，且请反代侧确认**不对已编码的 UTF-8 路径做二次解码**，否则会 404。
4. **目录与末尾斜杠**：`/x/` 与 `/x` 都应正确命中 `index.html`。
5. **MIME**：`.woff2` 需以 `font/woff2` 返回；若直接转发 `.md` 则为 `text/markdown; charset=utf-8`。
6. **零第三方请求**：渲染器的 JS、CSS、字体全部由仓库自持、同源提供。**不得引用** unpkg / jsdelivr / cdnjs 等 CDN——国内访问它们时通时断，最坏情况是公式全部以裸 LaTeX 源码显示。
7. **构建可离线、可重复、结果确定**：写明依赖清单与版本；依赖要么随仓库 vendored，要么固化在构建脚本里。提供一条可重复执行的构建命令（clone/pull → 构建 → 输出目录）。
8. 站点形态**推荐多文件静态站**（每个 `.md` 生成一个 `.html`，目录结构镜像仓库）：反代只需纯静态转发，无需服务端 rewrite，刷新不会 404。若你选择 SPA，需自带 history fallback 规则并在交付说明里写清。

## 6. 仓库集成约束（否则提交会被钩子拒绝）

本仓库的提交与推送由 `.githooks/` 校验，**必须遵守**：

1. **精确白名单**：`.gitignore` 为 `*` → `!*/` → 逐文件 `!/完整相对路径`，**禁止通配符、不能只放行目录**。你往仓库新增的**每一个文件**（HTML、CSS、JS、字体、脚本）都要单独加一行白名单。这是本仓库最需要注意的维护成本。
2. **构建产物不入库**：只提交源码与手工资产（如 KaTeX 的 JS/CSS/20 个 woff2 字体）；`站点/输出/` 之类的构建产物目录应被忽略，不要提交。
3. **除本计划书外，不要在 `站点/` 下放 `.md` 说明文件**：钩子会对非 `模板/` 的 Markdown 做全量链接校验，容易误伤。本计划书是仓库文档（虽位于 `站点/` 下，但不属于站点产物），构建时请将其排除。
4. **不要创建符号链接**：钩子只接受普通文件，符号链接会被拒绝。
5. **不要手工修改两处自动区块**：`README.md` 的 `AUTO-CATALOG` 与 `维护细则.md` 的 `AUTO-MAINTENANCE` 由钩子在每次提交时从暂存内容重算并自动暂存。要加入口，请加在区块之外的正文，或按 §7 协商。
6. **不要用 `--no-verify` 绕过**：推送端的 `pre-push` 仍会校验提交树。
7. 提交前跑仓库的收尾检查（见 `维护细则.md` 第 1 节）：`check-markdown.py` 错误必须为 0，`test-update-readme.py` 必须全绿。

## 7. 协作边界

- **不要改动 `课程/**` 的正文内容**（数学内容与〔待核对〕项由维护者负责）。若发现与渲染无关的内容问题，**只报告**。
- 若需要把站点入口加进 README 或调整钩子逻辑，**先与维护者协商**，不要直接改自动区块或 `.githooks/`。
- 不提交音频二进制、不写入任何凭据或令牌。
- 网页**不提供图片访问**：仓库内的照片原件不随站点发布。

## 8. 验收标准

实现完成后按以下清单验收：

1. 11 篇正文 + 各级索引全部可读，**公式零报错**（无红色错误文本、无控制台报错）。
2. 7 处 `\tag` 公式编号可见；沙路法则的数组竖线可见；126 处行内矩阵**未被拆行**。
3. 宽表格与超长公式**不破版**（可横向滚动）。
4. **无死链**：内部 Markdown 链接全部命中；非 Markdown 资源为纯文本、无链接。
5. 浏览器 DevTools 网络面板：**除同源资源外零请求**。
6. 在任意子路径（如 `/repo/`）下打开，资源与页内锚点均正常。
7. 构建可离线完成、可重复执行，结果确定。
8. 交付说明中写明：渲染器选型与版本、依赖清单、构建命令、资源目录结构、反代需要配合的点（基路径、MIME、斜杠行为）。
