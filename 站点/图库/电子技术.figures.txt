# 一条一个图元：`<id> | <DSL>`，续行（缩进的）属于上一个图元。
# 页面里写 `:::figure <id> | 图注` 引用；一个图元可被多页引用，
# 改这里就等于改所有引用处（这是它住在独立文件而不是内联的原因）。
#
# ── DSL 速查 ───────────────────────────────────────────────────────────
#
# logic（门电路，首词是元件名，`;` 分隔子句，`->` 指向输出，`!X` 表示取反输入）
#   and B C -> Y            与门
#   or A B C -> Y           或门（输入几个就几个输入）
#   not B -> nB             非门
#   nand A B -> Y           与非门（输出取反泡）
#   xor A D -> Y            异或门
#   同名标签自动成网：`not B -> nB` 与 `and A nB -> Y` 里的 nB 是同一根线
#
# wave（波形，首行 `wave <格数>`，之后 `标签: 电平串`）
#   电平：0/1 为电平，`.` 保持上一格，`-` 高阻
#
# kmap（卡诺图，首行 `kmap <变量数>`，之后格值行，`box r?a-b c?c-d` 圈组）
#
# ── 标签写法 ───────────────────────────────────────────────────────────
#
# 纯文本 + `~x~` 表示下标（`U~1~` → U₁）。图内**不能写 LaTeX**：
# KaTeX 的 <span> 塞进 SVG <text> 会毁掉文本布局。要写公式请写进图注。

# ═══ 门电路（作业 2026-10-12 门电路输出波形，全部输出带取反泡）═════════

# 门(b) 与门：输入 A 与常数 1，输出取反 → Y = /(A·1) = /A
gate-b | nand A 1 -> Y

# 门(c) 与门：输入 C 与常数 0，输出取反 → Y = /(C·0) = 1
gate-c | nand C 0 -> Y

# 门(d) 三输入与门，输出取反
gate-d | nand A B C -> Y

# 门(e) 或门，输出取反
gate-e | nor B D -> Y

# 门(f) 异或门，输出取反
gate-f | xnor A D -> Y
