## 3. 我们已经做过、并且确认能跑的（供你在此基础上给建议）

我们现在是自己画的：每帧 `cla` + 重画全部图元 + `print -dpng`，然后 ffmpeg 合成。核心代码大致是：

```matlab
graphics_toolkit('fltk');
fig = figure('visible', 'on', 'position', [0 0 820 660], 'color', 'w');
ax = axes('parent', fig, 'position', [0.04 0.04 0.92 0.92]);
set(ax, 'dataaspectratio', [1 1 1], 'xtick', [], 'ytick', [], 'box', 'on');
hold(ax, 'on');
for k = 0:N
  A = (1-s)*eye(2) + s*M;          % s 由阶段表算出
  cla(ax); xlim(ax, [-Lx Lx]); ylim(ax, [-Ly Ly]);
  plot(ax, ...); patch('parent', ax, 'xdata', ..., 'ydata', ..., ...);
  text(ax, ...);
  print(fig, sprintf('f%04d.png', k), '-dpng', '-r100');
end
```

**已确认可行的**：这条路能出图，数学正确，镜头固定，坐标范围由内容包围盒反推。

## 4. 我们踩过的坑（请确认、纠正、补充）

这些是我们实际撞过的，请**逐条判断对错**，并补充我们没遇到的。

### 4.1 Octave / headless 环境

1. `print` 报 `rendering with fltk toolkit requires visible figure` → 我们改成 `figure('visible','on')` +
   `xvfb-run` 才行。**这是唯一办法吗？`gnuplot` 工具包是否更适合 headless 批量出图？**
2. 缺 `FreeSans.otf` 时连 `axes` 都创建不了（`__go_axes__: invalid bounding box, cannot render`）。
3. Octave 的 `patch` 属性名必须是 **`xdata`/`ydata`**，写 `'x'`/`'y'` 会 `unable to create graphics handle`。
4. 脚本文件**第一行必须是 `1;`**，否则 Octave 按函数文件解析、报变量未定义。
5. `quiver` 在 `dataaspectratio=[1 1 1]` 下箭头比例不稳、短向量几乎看不见箭头 → 我们自己用
   `patch` 画三角形箭头。**有没有更标准的做法？**

### 4.2 版面与镜头（这几个是「什么都没画出来」的根源）

6. **坐标范围每帧重算** → 镜头跟着内容缩放，单位方格永远撑满同一个框，
   「方格被拉伸」这件事完全看不出来。我们改成整段算一次、固定住。
7. **坐标范围把「变换后网格的全部角点」也算进去** → ±4 的网格经 $M=\begin{pmatrix}2&1\\1&2\end{pmatrix}$
   映射到 ±12，视野撑到 `Lx=16.7`，单位方格缩成一个点，整张图像空的。
   我们改成只按**教学内容**（单位方格、平行四边形、基向量）算范围，网格线交给坐标轴自动裁剪。
8. 等比性靠「按坐标框宽高比反推 Lx/Ly」碰巧成立 → 我们补了显式 `dataaspectratio`。
9. 读数文字被网格线横穿、像加了删除线 → 我们在文字下铺了一块白色 `patch` 底板。

### 4.3 时间设计

10. 一开始是「一个 ease 从头扫到尾」2 秒，学生看不清哪段在干什么。
    我们改成**显式阶段表**：静止（看清初态）→ 渐变（主段，给 3 秒）→ 收尾（停住读结果）。

### 4.4 一个我们还没解释清楚的现象

11. 渲染出来后，单位方格内部的左上角出现一支**灰色的、位置看着不对的小箭头**。
    我们在灰色里画的只有 e₁=(1,0) 与 e₂=(0,1) 两支。我们的猜测是这两支的箭头画法或位置有问题。
    **请你判断：可能是哪里的问题？**

## 7. 关于「不猜」

图中出现的每个数值都应由脚本从矩阵算出来，**不许硬编码**。
我们已经把教材第 1、2 章 MATLAB 小节的命令输出用 Octave 全部复现核对过，
所以数值正确性不是问题，**图形与动画才是**。另外提醒：教材里有些输出是**不可跨环境复现**的
（例如 `det` 对奇异矩阵会给出 `±1e-16` 量级的浮点残差，我们实测得到 `+6.6613e-16`，
而书上印的是 `-9.5162e-16`，连符号都相反；精确值是 0）。你给的脚本如果涉及这类输出，请标注出来。
