# 归档：MATLAB/Octave 教学动画路

**状态：已封存，不再推进。** 归档日期 2026-09-19。

## 为什么封存

目标是「用动画解释数学」。但按《工程数学基础》的实际内容核对后，
**这条路的投入产出比不成立**：

1. **教材第 1–2 章不讲几何意义**。扫过已完成的 9 个解析文件，「面积/体积/几何意义/
   曲面/平面」零命中。教材用消元法与沙路法则讲行列式，不走几何直觉这条路。
   我们做的「方格 → 平行四边形、面积 = det」演示的是**书上没有的内容**。
2. **真正缺的是静态图，且那是「抄录欠账」不是「缺插图」**。
   `第01章-1.1` 正文写着「具体见图 1.2」，而该文件自认「未逐字复刻图 1.1、1.2」。
   ——这是抄录工作没做完，用不着动画。
3. **动画的正当用途是作业，不是教材解析**（用户判断）。教材解析要的是**忠实**，
   作业才需要**降低解题门槛**。而作业要的是「分层提示」，不是「演示动画」。
4. **成本对比悬殊**：矢量 SVG 52KB / gzip 2.9KB / 文字可搜 / 跟随主题；
   视频线 MB 级（会逼上 CDN）、文字不可搜、固定白底、每换一个矩阵要重跑全部帧。

## 保留什么

- `det2_transform.m`、`build.sh`、`t1_probe.m`：**配方存档**。
  多元微积分部分（曲面、切平面、重积分分割）的 3D 动画增量价值远大于线性代数，
  届时这套配方可直接启用。
- 实测结论（省得重查）：
  - `print -dpng -S1920,1080` **严格**得到 1920×1080；`-r` 是 DPI（默认 150），会差 1 像素 → **用 `-S`**
  - xvfb 必须 `-s "-screen 0 1920x1080x24"`，默认屏幕 1280×1024 会裁切
  - fltk 的 `print` 要求 figure **可见**（`visible='on'`），headless 靠 xvfb
  - HUD 用**独立 overlay axes**（`position=[0 0 1 1]`、`color='none'`、`handlevisibility='off'`），
    程序化验证过：主 axes 的 xlim/ylim **不受影响**
  - 中文能渲染，但警告 `substituting font to 'Noto Sans CJK JP'`——部分汉字用日文字形
  - 箭头头部必须**固定尺寸**（按 unitScale），否则 `e2=(0,1)` 的头部会侵入单位方格内部
  - 含文件内函数的脚本第一行要写 `1;`
  - 收尾时偶发 `段错误 (core dumped)`（帧已全部输出，退出阶段崩）

## 不要做什么

- 不要为「好看」而做动画。动画只在「数量」或「过程」上有增量价值时才有意义
  （例：沙路法则六条斜线逐条画出，比静态图数得清——那条已由矢量 SVG 实现）。
- 不要把视频产物接进站点（体积会逼上 CDN）。
