# 待填写已核实章序与节名

本文件仅为模板，不是教材目录或已完成解析。

## 用法与命名

- **一节一个文件**，不把整章塞进一个 md。文件放在章目录 `课程/<中文课名>/教材解析/第NN章-章名/` 下，命名为 `第NN章-<节号>-<节名>.md`；一节内容过多时，在该文件内按二级小节继续拆。
- 每个文件内部固定先写**原书抄录**，紧跟**解析**：
  - **原书抄录**：按原书页码抄录印刷正文与编号（定义、性质、定理、例、习题的原始编号），作为可逐句核对的底本；看不清处标〔待核对〕，学生手写旁注不进入抄录。
  - **解析**：写概念怎么理解、公式在什么条件下成立、例题怎么做、易错点在哪、结果如何独立验算；教材陈述与整理者补充必须分开标注。
- 节号、节名、页码须与原书一致，不按课堂日期命名，不虚构章节或解析进度。

## 教材与本节定位

- 书名、作者、出版社、版次、出版年、ISBN：待提供。
- 本文件对应的原书章序、节号、节名、页码范围：待提供。
- 教材照片或其他来源及 SHA-256：待提供。
- 解析状态：未开始 / 整理中 / 待核对 / 已核对（保留真实状态）。
