# 05: 单语言包仓库被要求给每个包补键（上游 #35）

**What to build:** 本仓只用 `REFLECT_LANG=zh`，en/de 两个包只服务 `check_i18n`
的自证夹具，没有第二读者。但 `knobs.pack_coverage_problems()` 按
`zreflect/lang/*/` 目录发现「已装包」，于是**目录存在**被当成**我在维护这个语言**，
每新增一条 `M("...")` 消息，`registry.py --gates` 就 FATAL，除非给 zh/en/de
各写一份译文。

已报上游：[ArchivalEra/Einfacht#35](https://github.com/ArchivalEra/Einfacht/issues/35)
（建议加 `REFLECT_LANGS_MAINTAINED` 声明式旋钮，或把套件自证样本包移出
按目录发现的范围）。

**临时处置（本仓侧，不改上游机制）：** 新增消息时仍给三个包补齐键，
保证 `registry.py --gates` 全绿；把这条欠账记在这里，等上游合入声明式旋钮后
再删掉 en/de 的冗余键。`zreflect/` 保持逐字节照抄，本地不为绕开它打补丁。

**Settling:** `python3 -c "import sys;sys.path.insert(0,'zreflect');import knobs;print(len(knobs.pack_coverage_problems()))"`
—— `0` ⇒ 当前三包齐全、本仓侧无欠账（上游未修时这是靠补译文达成的）；
非 `0` ⇒ 有包缺键、`registry --gates` 会 FATAL。
上游 issue #35 关闭后，此条改 `resolved` 并删去 en/de 的冗余译文。

**Status:** ready-for-human
