# 11-10-二次调频与无功电压

## 这节课在干什么

这一节完成第四章的剩余两部分：**二次调频（AGC）在线性能评估**与**电网无功电压控制（励磁系统监测）**。

1. 先承接上一节把一、二、三次调频定位拉齐，随后展开二次调频在线评估的两大类指标：运行区域性能指标（以北美 A1/A2、CPS1/CPS2 为例）与我国重点采用的 AGC 机组性能指标（投运率、调节容量、调节速率、调节精度及效能系数）。
2. 交代 AGC 的单机控制与集中控制方式、电厂考核电量规则、分钟/小时/全天三级时间尺度，以及火电机组指令周期与分段评价概念。
3. 后半段转入「无功控制电压」：讲清电感/电容无功调节方向、AVR 与 PSS、一次与二次设备界定，以及励磁系统稳态监测指标与动态（小扰动、大扰动）监测指标，至此结束第四章。

## 没编号但讲了的知识点

### 一、复习：一、二、三次调频分工与本阶段要求

- **三类调频定位**：
  - **一次调频**：有差调节，依托硬件设备完成较大幅度的初步调节（类似「粗调」）；
  - **二次调频**：无差调节，依托硬件设备完成进一步微调（对比见教材 77 页）；
  - **三次调频**：借助软件实现的更精确控制，但成本较高；一般工况下采用一、二次调频即可满足要求。
- **学习口径**：现阶段重点掌握各类方法的**性质、特征、定义及所用手段与设备**，不要求推导机理公式或确定具体控制参量。

### 二、二次调频在线评估指标体系

电网频率正常波动允许范围为 50 Hz 附近 $\pm 0.02\ \text{Hz}$ 至 $\pm 0.05\ \text{Hz}$ 以内；一旦越出该误差带，即需启动调频控制。⚠ 口述此处未再细分火电与水电的死区取值。

二次调频的在线评估指标分为**运行区域性能评价指标**和 **AGC 机组性能评价指标**两大类：

#### 1. 运行区域性能评价指标（北美 NERC 标准）

我国控制权归属国家电网，但参数计算逻辑与北美电力可靠性协会（NERC）标准大同小异，主要包括两套标准：

| 标准 | 核心评价规则 | 课堂指出的局限与缺陷 |
| :--- | :--- | :--- |
| **A1 标准** | 任意 10 分钟间隔内，区域联络线控制偏差（ACE）必须至少过零一次 | 频繁过零会使系统处于无谓调节状态，使发电机组反复加减负荷、增大调节负担并损害设备 |
| **A2 标准** | 10 分钟间隔内 ACE 的平均值须小于控制限值（转写记为 `LD`） | 当某一控制区发生故障/事故时，相邻互联区域难以通过联络线及时提供功率交换支援 |
| **CPS1 / CPS2** | CPS1 考核长时间段（一般为 1 年）内 ACE 是否满足给定不等式（式 4-25～4-30）；与 CPS2 一同评估 AGC 性能 | 同样存在工程局限性；具体参数物理意义与公式推导本课不作要求 |

- **A2 限值两种参考算法**（了解即可，每个控制区通常每年修改一次）：
  1. 取冬季或夏季负荷高峰时段日小时电量的最大变化量；
  2. 取一年中任意 10 小时电量变化量的平均值。
- **CPS1 / CPS2 达标口径**：⚠ 转写记为两个指标分别要求「大于等于 2%、大于等于 6%」，未对照教材原文核实，按转写照录，不作臆测改写。

#### 2. AGC 机组性能评价指标（国内重点）

针对单台或全厂 AGC 机组的调节能力进行评估，定义式见教材 **4-31 至 4-34（或 4-35）**。

- **四项核心指标**（多项选择题重点）：
  1. **投运率**：机组投入 AGC 运行的比例。投运率**不能等于 1（100%）**——必须留出一定备用机组应对突发故障，否则系统失去后备支撑，可靠性反而降低。
  2. **调节容量**：机组可用于参与二次调频的功率范围。
  3. **调节速率**：反映机组响应 AGC 指令的实时速度。
  4. **调节精度**：机组实际出力跟踪目标指令的准确程度（落在允许误差带内即可）。
- **「稳、快、准」的工程权衡**：稳定性、快速性与准确性三项要求相互制约，无法同时全部取极值；必须依据机组与电网需求突出重点、对另外两项适当放宽。
- **补充/辅助指标**：除上述四项外，课堂还点出**正确动作率**、**响应时间**（评价调节速率时配合考察响应速度）以及**差动功率**（工程中评价调节精度时引入）。⚠ 转写先后出现「共 7 个指标」与「分解为 6 个指标」两种说法，此处如实并列已口述名称。

### 三、AGC 调节过程、控制方式与电网考核

#### 1. AGC 的定义与调度体系

- **调度三级结构**：**国调**（中央，北京）→ **中调 / 省调**（省级调度中心）→ **地调**（市级）；原有区调已取消，县级无调度权。
- **AGC 功能链条**：电网调度中心（最低一般到中调/省调）通过机组的**分散控制系统（DCS）**，自动向机组下发增减目标负荷指令，依据机组自身条件、性能与网内地位分配任务，维持发电功率与负荷实时平衡，使联络线控制偏差（ACE）持续减小直至为零，从而稳定系统频率（如南方水电在汛期需配合调度安排机组投停以完成调频）。

#### 2. 电厂侧两种控制方式

| 控制方式 | 调度指令内容 | 厂内执行链路 |
| :--- | :--- | :--- |
| **单机控制** | 调度机构直接计算得到每台机组的 AGC 指令 | 指令直接下发至电厂每台参与 AGC 的**机炉协调控制系统**，直接驱动机组升降功率 |
| **集中控制** | 调度中心下发全厂**总功率设定值** | 由电厂内部**分布式控制系统（DCS）**对全厂各台机组进行综合协调控制与经济负荷分配 |

- **双重评价视角**：从**系统**角度，AGC 服务于维持频率与联络线潮流在规定范围内；从**机组**角度，AGC 服务体现为跟踪指令变化的能力，评价质量即考核机组出力跟随指令变化是否达标。

#### 3. 考核规则与时间尺度（湖北电网案例）

教材结合清华课题与湖北电网样本库（图 4-11、表 4-2、表 4-3）给出了三项具体考核规则：

1. **月成功率考核**：AGC 月成功率须达到 **90% 以上**；每低于 1 个百分点，每台机组考核电量 **50,000 kWh**（5 万度电）。经调度机构同意退出的时段不纳入考核。
2. **投运与达标考核**：具备 AGC 功能的机组须按调度指令投入；若无法投入或调节性能不满足表 4-2、表 4-3 任一项要求，每日按 **0.5 万 kWh** 计为考核电量。每月由电力调度机构对所有 AGC 控制单元进行测试，结果在「**电力三公**」（公开、公平、公正）调度网站公布并报电力监管机构备案。
3. **免考情形**：当电网出现异常或存在安全限制因素导致电厂不具备投入条件时，不考核机组的 AGC 服务。

- **考核时间尺度**：按**分钟级**、**小时级**、**全天级**分段统计。其中**分钟级**因机组动态特性差异而设不同窗口：
  - **火电机组**：分钟级定义为 **2 分钟**；
  - **水电机组**（调节较快）：分钟级定义为 **30 秒**。

### 四、AGC 效能系数与在线分段评价算法

#### 1. 效能系数

- **作用与本质**：针对各项 AGC 性能指标分别设立对应的**效能系数**（计算综合指标时乘在对应指标前）。其核心目的是对有量纲的性能指标进行类似**标幺化**处理，将其归一化为无量纲参数，既便于呈现评估结果，又可对不同参数、不同类型的机组进行横向比较。
- **机组惯性差异的影响**：不同发电方式的物理惯性不同，效能系数参数取值随之区分（例如火电、水电、核电、风电各有对应参数）。按教师当场纠正后的清晰排序：

$$\text{风电机组惯性} < \text{火电机组惯性} < \text{水电机组惯性}$$

#### 2. 在线迭代与分段评价参数

- **在线计算背景**：电力系统指标与效能系数数据量大、计算复杂，需借助大数据、云计算与人工智能算法，基于实时发电曲线和 AGC 控制指令曲线不断迭代学习，求取全局最优的评估参数。
- **采样与指令周期（以湖北电网为例）**：火电机组惯性较大，下发指令过于频繁对控制效果提升不明显，因此 AGC 控制指令发出的最小时间间隔为 **1 分钟**，机组实际出力采样周期为 **5 秒**（最小可达 **1 秒**），数据加密存至云数据库后以曲线形式供调度员查看。
- **评价段概念**：包含统一时间段定义、控制段定义（涉及式 **4-54、4-55**）及**分段评价算法**（划分**快速控制段**、**考核控制段**、**超时控制段**），各段均预设阈值，越过门槛即由微机自动触发对应动作。

### 五、电网无功电压控制与励磁系统监测

#### 1. 有功调频 vs 无功调压

- **有功功率控制频率**：通过一次（有差）、二次（无差）、三次（精确）调频完成；
- **无功功率控制电压**：通过调节系统中的无功功率，维持节点及机端电压稳定。

#### 2. 无功储能与电压调节机理

- **无功元件储能**：电感（磁场）与电容（电场）储存的能量均属无功范畴：
  - 电感储能：$W_L = \frac{1}{2} L I^2$；
  - 电容储能：⚠ 课堂口述该处片段断续，未完整念出 $\frac{1}{2} C U^2$，本笔记不以转写补全。
- **负荷波动时的无功调节步骤**：
  1. **负荷加重**（如集中开启空调）→ 系统电压下降 → 投入**电容**释放容性无功 → 电压回升；
  2. **负荷变轻**（如大面积关灯停机）→ 系统电压上升 → 投入**电感**吸收多余无功 → 电压回落。
- **励磁的本质与装置**：动态调节电感与电容（无功补偿设备）的过程即与励磁控制密切相关。关键控制装置包括**发电机自动励磁调节器（AVR）**与**电力系统稳定器（PSS）**，用于保持机端电压恒定、控制并联运行机组间的无功分配，并改善电力系统稳定性。

#### 3. 一次设备与二次设备辨析

| 类别 | 判别标准 | 课堂举例 |
| :--- | :--- | :--- |
| **一次设备** | 直接对电能进行传输、变换与分配的设备 | 发电机/电机、变压器、输电线（电线） |
| **二次设备** | 对电能及主电路进行控制、保护与测量的设备 | 继电保护装置、⚠ 断路器（课堂口述将断路器一并归入二次设备；工程常规分类中高压断路器属一次设备，建议复习时核对教材口径） |

#### 4. 励磁系统监测指标体系

- **稳态监测指标**（目的：监测并统计全网励磁稳态运行状态及安全运行范围；**多项选择题重点**）：
  1. **AVR 状态监视与统计**；
  2. **PSS 状态监视与统计**；
  3. **发电机无功安全裕度在线计算与展示**。
- **动态（暂态）监测指标**：包含**捕捉扰动启动判定**与**评价指标体系**两部分，按扰动性质分为小扰动与大扰动两类（当前多采用智能化算法自动计算，不作手工求解要求）：

| 扰动类型 | 对应工况 | 四项评价指标 |
| :--- | :--- | :--- |
| **小扰动指标** | 不改变系统拓扑结构，仅小幅改变电感、电容或电压幅值，用于评价系统动态响应 | 1. 调节精度（稳态误差）<br>2. 振荡频率（如单调曲线无振荡，图 4-17 为幅值单调递减的收敛振荡即渐近稳定；有界不收敛亦为不稳定）<br>3. 阻尼比 $\zeta$（涉及式 4-76 衰减指数项）<br>4. **调节时间 $t_s$**：从 $t=0$ 起，响应首次进入稳态值 $\pm 2\%$（或 $\pm 5\%$）误差带且不再越出所持续的时间 |
| **大扰动指标** | 系统结构发生变化（故障或质量异常），用于故障分析，评价消除故障的时效性与质量 | 1. 强励电压倍数<br>2. 强励电流倍数<br>3. 强励电压响应速度<br>4. 强励时间与反馈时间（⚠「反馈时间」按转写照录，未作猜改） |

## 转写与术语

- 「**A, T, C / A, C, C / acc / ADC / ABC / APP / A, C, D / 自动化技术**」→ **AGC（自动发电控制）**（全篇高频语音误识，指同一系统与机组控制功能）。
- 「**投影率 / 投用力 / 投运力 / 我运力**」→ **投运率**（AGC 四大核心指标之一）。

- 「**正确工作率 / 正确工作力量**」→ **正确动作率**。
- 「**延长线 / 联动线 / 延路线**」→ **联络线**；A2 限值处的「**LD / 2B**」→ **联络线控制偏差限值**（如 $L_{10}$）。
- 「**人民医院系统 / C1S2 / C31 / C34**」→ **CPS1、CPS2 标准**；「**电子商务协会**」→ **北美电力可靠性协会（NERC）**。
- 「**雾化带 / 绿化带 / 交通发带**」→ **频率死区 / 允许误差带**。
- 「**效力系统 / 消毒系统 / 效度系数 / 教育制度**」→ **效能系数**；「**标价化 / 标要值**」→ **标幺化 / 标幺值**。
- 「**火箭机组 / 火箭技术**」→ **火电机组**；「**合同技术**」→ **核电机组**；「**风电阻**」→ **风电机组**。
- 「**耗电量**」→ **考核电量**；「**电力电子机构**」→ **电力调度机构**；「**电力三孤 / 第三公告**」→ **电力三公（公开、公平、公正）**。
