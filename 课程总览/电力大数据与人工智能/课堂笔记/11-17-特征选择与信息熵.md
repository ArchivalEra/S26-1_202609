# 11-17-特征选择与信息熵

## 这节课在干什么

这一节开第五章：把「电网安全属性的高维数据」压到「少数几个说得清物理意义的特征」上。
主线只有两条，一问「**怎么选**」，一问「**拿什么尺子量**」。

1. 先说为什么必须筛：电力系统节点规模大、数据维度高、特征冗余，靠人工经验挑关键量已经撑不住，
   而**特征提取**会把原始特征变成映射值、丢掉物理意义，所以本章选**特征选择**这条路线。
2. 再把特征选择按「**是否独立于后续学习算法**」分成**过滤式**与**封装式**两类，说清各自的原理、代价与互补性；
   过滤式的度量标准归为**距离、一致性、相关性、信息论**四类，其中**信息论**这一类是本课程要用的尺子。
3. 然后给出**两阶段组合算法**：第一阶段用 **Relief** 给特征打分初筛，第二阶段用**支持向量机**在剩余特征上做封装式终选，
   顺带讲清 SVM 的超平面、优化问题、松弛变量、对偶与核函数，以及最终分类规则 $F$ 的正负怎么判。
4. 后半段进入**信息论工具箱**：熵、联合熵、条件熵、互信息、标准化互信息、联合互信息，
   以及图 5-5 给出的四者关系，最后交代为什么教材要用它来补「潮流断面」之外的信息。

课上反复重申的一句话是「**安全性是第一位**」——筛特征时宁可保守地保留原始特征，也不要为了降维把关键属性漏掉。

## 没编号但讲了的知识点

### 一、为什么高维特征必须筛

- **数据本身的性质**：电力系统节点数规模非常大（教师拿校区、城市作比），因此运行控制中产生的数据
  「**维度高、规模大、迭代次数多，特征存在冗余**」，难以满足实时运行和调度控制的需求。
- **算不动**：用物理服务器计算，计算量与延迟都大，「速度和效率都比较慢」，所以要上**云计算**；
  同时要保证可靠性，还涉及**数据链技术**（教师解释为一种加密技术）。
- **人工经验这条路走到头了**：过去关键控制对象的选取**依赖人工经验**——没有专业背景就看不懂数据的物理意义，
  无从下手。电网越来越复杂后，「运行规律难以把握，仅靠人工经验难以把握现有关键监控对象与其他变量的内在耦合关系」。
- **旧方法的第二个毛病是物理意义**：「现有的各种选择方法筛选出的特征物理意义不明确，不便于调度运营人员的监控」，
  所以教材（源自清华大学电力系统国家仿真实验室的课题）要给出新的关键特征选择方法，
  并用算例验证其「可靠性、可信性、效率高又精确」。
- **价值排序**：安全第一，其次是可靠性与经济性——这条顺序是后面「宁选特征选择、不选特征提取」的理由。

### 二、特征选择与特征提取：两条降维路线

两者都能实现特征空间的压缩，但概念不同：

| | 特征选择（feature selection） | 特征提取（feature extraction） |
| :--- | :--- | :--- |
| 做法 | 从已获得的 $N$ 个原始特征中**直接选出**所需子集，寻找 $N$ 维特征空间的**低维代表性子空间** | 先对 $N$ 个原始特征做**坐标变换**，再在取值空间降维 |
| 得到的东西 | 原始特征的**子集** | 原始输入特征的**映射**（新构造的低维特征） |
| 物理意义 | 保留原始输入特征的信息，便于解释 | **物理意义不够明确** |

- **结论（本章的选择）**：电网安全属性的研究需要**保留原始输入特征的信息**，以便后续生成的安全稳定评估规则能解释说明；
  特征提取「不利于后续生成的安全稳定评估规则的解释说明」，且**容易把关键特征漏掉**（`13:53`），
  而电网安全性是最高要求，所以**倾向用特征选择实现输入空间降维**。
- **坐标变换这一段是插入的数学铺垫**：变换包括「从旋转变换到静止变换」这类数学方法；
  为什么要变换——物理世界的运动形态很复杂，用数学建模时模型只是对现实对象的**近似**，
  追求误差更小则模型更复杂、计算量更大、效率更低，而「**精度和复杂度是相互冲突的指标**」。
  教师举的例子是天体（地球、月亮）既有公转又有自转，把**运动的坐标系转成静止的坐标系**才便于分析；
  另一层是**降维**：维度越高抽象性越强，要把多维数据降到三维、二维（平面坐标系）才好分析。
  ⚠ 教师举例时说的「比如 12 变换」转写不清，本页不据此断言具体变换名称。

### 三、分类：过滤式与封装式

判据只有一条——**是否独立于后续的学习算法**，据此分两类。

| | 过滤式（filter） | 封装式（wrapper） |
| :--- | :--- | :--- |
| 与学习算法的关系 | **独立**，用统计量自己打分 | 把**分类算法作为特征选择的一个组成部分** |
| 评价标准 | 一定度量标准下「与目标属性最相关」的特征 | 直接拿**分类准确率**当特征评价标准 |
| 采用的方法 | 各类统计度量（见下节四类） | **交叉验证** |
| 优点 | 计算量小、速度快 | 偏差小、性能高、可靠性高 |
| 缺点 | 结果与后续学习算法的性能偏差可能较大，**不一定最优** | **计算量大**、样本库规模大、计算速度慢 |

- **交叉验证的做法**（教师口述的机械步骤）：把样本**均分为几份**，**依次**把其中一份作为**测试样本**、
  其余作为**训练样本**，用训练得到的分类器在测试样本上的**分类准确性**来最终确定所选特征的好坏。
- **教师对过滤式「性能不高」的归因**：样本数量较少、主要局限于样本量，
  「样本数量比较低，它的学习性能比较差」。⚠ 这是教师的两处口述（`24:29`、`27:14`），
  转写里没有说明「样本量少为什么导致过滤式差而封装式好」，本页照录不补机理。
- **两者的关系**：各有优缺点、互补，实际常**结合使用**（见下节两阶段法）。

### 四、过滤式的四类度量标准

教师明确「将特征选择的度量标准总结为**四类**」：

1. **基于距离**的度量标准，例如 **Relief**（转写读作「release」，教师又把它口译成「切片」；另出现「I release」，疑为 ReliefF，⚠ 转写不清，不单独断言）；
2. **基于一致性**的度量标准；
3. **基于相关性**的度量标准；
4. **基于信息论**的度量标准——**最关键、本课程采用的那一类**。

**为什么信息论这一类最好用**（教师给了四条理由）：

- 利用信息熵等方法**量化类别的不确定程度**，以及特征／特征子集中所包含的分类类别的**信息含量**；
- **不需要提前知道样本分布**：不管规则分布还是不规则分布，都可以通过一定方法**直接由样本计算概率分布**；
- 能很好地量化变量之间的（转写作「边界性关联关系」，含义未展开）关联关系，对概率性研究有利；
- **不依赖变量的具体取值，只与取值的分布有关**——不受某一次测量或某一次计算的影响，
  但因此**依赖大量样本**：「样本数量越大，分析出来的结果越可靠」，本质上靠统计量说话。
  教师用「量子系统是不确定性的」作类比，强调单次或上百次的数据都不可靠，只能靠分布。

### 五、两阶段组合算法：Relief 初筛 + SVM 终选

目前特征选择研究多采用「**两种模型构成的混合算法**」，即 **filter 与 wrapper 依次使用**的两阶段法：

- **第一阶段（filter）**：先用 **Relief** 初步剔除大部分无关和冗余特征，只保留少量特征，**减少后续搜索规模**；
  对输入特征打分排序后，按实际需要选排名靠前的 $N$ 个。
- **第二阶段（wrapper）**：把剩余特征连同同样的数据作为输入传给封装式算法（**支持向量机**）进一步优化选择。
  教师给的组合是「**Relief 作为 filter 阶段的初筛方法，支持向量机作为 wrapper 阶段的终选方法**」。
- **样本库不大时的取巧**：可用**遍历**的方式计算——遍历即搜索，包括**广度优先搜索、深度优先搜索**，
  搜索树本身就是一种遍历；教师把核函数的枚举也归到这类「离散的计算方法」。

#### Relief：按特征权重打分

- **算法性质**：一种**基于特征权重（转写作「特征程度」）**的算法——按各特征与类别的相关性给特征赋**不同的权重**，
  再选取**权重大于某一阈值**的特征。
- **式 5-1 的作用**：对第 $K$ 个候选特征的取值，用 $\max$ 取其**最大值**、$\min$ 取集合中的**最小值**，
  把样本之间的差别归一化，据此计算距离。教师只说「用这个 5-1 这个切片的公式，令样本之间的差别如 5-1」，
  ⚠ 式 5-1 的完整表达式转写未念出，本页不代写公式。
- **距离度量**：`33:54` 教师明确「说到距离的时候……**一共有四种距离**，我们**最常用**的一个**曼哈顿距离**，
  一个**欧氏距离**」——⚠ **四种里只点名了这两种**，另两种的名称与四种距离的公式转写都没有，
  教师只说「具体的定义你可以问一下」。
- **权重更新**：选取与样本点 $X$ **距离最近的若干个样本**，据此**更新权重**；「**权重每算一次、每迭代一次就改变一次**」，
  即整个算法是迭代的。教师顺带把「迭代／训练速度越高，模型智慧越高」讲成一句题外话
  （举大模型谁先用谁占市场的例子），与算法本身无关。
- **原理的直观说法**：判别候选特征对分类的意义，看「若该特征重要则相应的权重应当增加，反之权重应当减小」。

#### 支持向量机：超平面、优化问题与对偶

- **它是什么**：教师把它定位为「**最初步的人工智能方法**」，在图像处理、图像识别（无人机拍摄、机器人视觉）里用得较多。
- **原理链条**：通过**拟合两类数据样本区域间的分界线**实现分类——先用某种**映射函数**把样本映射到**高维空间**，
  在高维空间里用**一个线性超平面**区分两类样本，再映射回原空间得到原空间的分类器（图 5-2）。
- **它的假设（前提）**：低维空间中难以线性可分的数据，映射到高维空间中**更容易线性可分**。
- **最优超平面怎么定**：为最大程度把两类样本分开，取**距离两类样本点最远**的那个线性超平面作分界面（图 5-2、图 5-3）。
- **优化问题（式 5-2）**：目标是使**权重向量的模的倒数最大**，约束条件（转写念作「subject to」）是 $y_i$ 那一串**大于等于 1**。
  （注：「模的倒数最大」与「间隔 $2/|w|$ 最大、$|w|^2/2$ 最小」等价——这层等价是本页的补注，
  教师原话只说到「模的倒数最大值」与约束「大于等于 1」。）
  教师把这个「求 $w,b$ 的规划问题」反复称作**动态规划／静态规划**；
  并延伸说：约束里若含微分方程属动态规划，这类问题在电力系统里很多——求潮流的叫**最优潮流**，
  求建厂/建站成本最低的叫（成本）**规划**，求解手段都是**智能算法**（神经网络、专家算法、蚁群、模拟退火等），只是自动化程度不同。
- **硬约束太保守 → 引入松弛变量（式 5-4）**：要求所有样本都正确分离「太保守」，「很难甚至写不出来」；
  实际电力系统中样本难以完全可分，所以在权重前再引入**松弛变量**，把「大于等于」的**不等式改成等式**，
  **允许部分样本被错分**。其中 $C$ 是**惩罚因子**，反映松弛变量对分类效果的影响；$w$ 是超平面的参数向量，$b$ 是门槛值。
- **转对偶问题**：求解上述优化问题的方法是**转化为对偶问题**（式 5-4），对偶问题是一个**典型的二次规划**，
  可用成熟算法（含各种智能算法）计算。
- **核函数**：利用对偶形式可以直接用**核函数**在高维内积，**避免显式地把低维数据映射到高维再映回来造成的维数灾难**
  （转写读作「维修爆炸／维数单」，教师自己也说成「维数灾／维数爆炸」）。
  常用核函数：**线性核、多项式核、RBF 核**。教师把 RBF 归到决策树一族并预告了 20 分大题。
- **分类规则（式 5-7）**：把样本 $X$ 代入规则 $F$，**由 $F$ 的符号定类别**：
  - $F(X) > 0$ → $Y = +1$：在本书的潮流算例中，样本点的**潮流值（功率值）等于 1，判为系统稳定**，样本点位于**安全域内**；
  - $F(X) < 0$ → $Y = -1$：**系统不稳定**，样本点位于**安全域外**。
  教师补一句底层原因：计算机最终处理的是二进制数据，「要么 1 要么 0」，所以输出归结为正负两类。
- **约束起不起作用**（`49:27`）：「如果这个 $R_i$ 等于 0，说明**该约束对于规则的获取不起作用**；
  只有这个约束**不等于 0** 的时候，样本才会决定分类规则。」
  这说的是：只有**等式成立**（约束起作用）的那些样本才决定分界面，也就是前面定义的**支持向量**——
  「满足等式的这个样本，我们叫它支持向量」，在图上就是落在**超平面上**的那些运行点。
  ⚠ 转写把这个乘子记作「$R_i$」，对偶问题里通常记作 $\alpha_i$，本页不据此断言教材符号；
  两者语义相同：乘子为 0 的样本不参与决定超平面。

### 六、信息论工具箱：熵、联合熵、条件熵、互信息

#### 从热力学熵到信息熵

- **信息论的出处**：最早出现在**数据通信**领域的研究中，由**香农**提出；教师点名香农是**美国贝尔实验室**的数学家，
  并连带提到**香农定理**与**奈奎斯特（采样）定理**（转写读作「加农定理」「奈菲斯特定理」）。
  信息论的方法就是「利用**概率论和数理统计**的方法研究信息的数量和传递」。
- **熵是什么**：「描述一个系统**混乱程度**的一个度量」。系统越混沌，熵值越大；
  **孤立系统**（与外界没有信息交换）的熵**只增不减**——教师把它类比成人不社交、班风没人管就越来越散。
- **热力学熵 → 信息熵**：热力学中熵描述**分子状态的混乱程度**；
  信息熵刻画的是**随机变量的不确定性**——不确定性越大、越找不到规律，信息熵越大；
  反过来说，「随机变量不确定性越大，则需要更多的信息来确定它」。

#### 熵的定义与性质（式 5-8、5-9）

设 $X$ 为离散随机变量、概率分布为 $p(x)$，信息熵为

$$H(X) = -\sum_{x} p(x)\log_2 p(x)$$

⚠ 转写只念到「用 $p$ 分布的这个概率，然后乘以这个二的这个对数」，**没有念出负号与求和范围**；
上式按信息熵的标准定义写出，非逐字转写。

教师逐条报的性质（式 5-8、5-9）：

1. **连续变化**：熵是连续变化的量，**概率分布的小幅变化对熵的影响很小**；
2. **常量熵为零**：对常量（某个 $p=1$），显然 $H = 0$；
3. **均匀分布熵最大**：当样本取值分布不均匀、而每个取值概率相等时，熵取最大值；
4. **$0\log 0$ 的规定**：对离散变量，若某概率为 0，$0\cdot\log_2 0$ 本身没有意义，但**规定取 0**；
5. **非负**：离散变量的熵值总是为正。

#### 联合熵（式 5-11）

- **定义的对象**：用于描述**随机变量构成的联合随机变量**的不确定度，可以认为它度量了**同时确定多个变量所需的信息量**。
- **怎么算**：已知 $X$ 与 $Y$ 的**联合概率分布**，按联合分布的概率乘以 $\log_2$ 求和，记作 $H(X,Y)$。
- **推广**：多变量按两变量的形式**类推**，式 5-11 后面那一项与两变量的式子相似。

#### 条件熵

- **结构上的对应**：概率论里有**联合分布**与**条件分布**，信息论里就对应**联合熵**与**条件熵**——「跟分布是对应的」。
- **定义**：给定一个变量（已知 $X$）后，**另一个变量 $Y$ 还有多大的不确定度**，即 $H(Y\mid X)$。
- **概率类比**：教师用「今天阴天 → 迟到的概率」讲条件概率，再过渡到「阴天情况下迟到这件事的不确定性」，
  即条件熵类似条件概率那样的描述。
- **语义**：可以理解为**随机变量 $Y$ 对 $X$ 的依赖强弱**。

#### 互信息（式 5-16）

- **定义**：描述两个随机变量之间**共同拥有的信息量**，可以表示两个随机变量的相互关系；
  也叫「交互信息」。
- **与条件熵的关系（式 5-16 的说法）**：已知随机变量 $Y$（或 $X$）后，另一个变量**不确定度的减少量**就是两者的互信息，即

$$I(X;Y) = H(X) - H(X\mid Y)$$

  教师由此说：**已知互信息与条件熵，就可以反求信息熵**。
  ⚠ 式 5-16 本身转写没有念出，上式按「不确定度的减少量」这句口述补为标准定义式；教师原话未念等号。
- **单调性**：两随机变量相互依赖程度越高，互信息的值越大。
- **一个必须记住的坑**：两随机变量**完全依赖**时，互信息**并不是一个常量**，而是与它们的**熵有关**——
  所以不能直接拿原始互信息比较，要改用**标准化互信息指标（式 5-17）**，教师说这「相当于一个标准／协议」。
- **与皮尔逊相关系数的区别**：比较常用的线性相关系数（皮尔逊）**只能描述线性相关关系**，
  互信息**还能体现变量间的非线性相关关系**。
- **在电力系统里为什么重要**：变量间多存在较复杂的空间关系，线性相关分析「比较局限于在某一运行点附近」；
  而本书研究的动态安全性是在**预想故障下不断改变运行点**形成大量样本，
  所以仅用线性相关系数判断特征与类别属性的相关关系「较为片面」。

#### 联合互信息（式 5-18）

- **它是什么**：互信息的**拓展**。普通互信息描述两个随机变量之间共有的信息含量；
  联合互信息描述的是「多个随机变量组合成的**联合变量**与 $Y$ 之间」共有的信息含量或相互依赖程度。
- **变量数为 2 时的特例**：可以推导出**联合互信息与条件互信息**之间的等式关系，
  教师说「这些关系将在后续的学习算法中起到很大的作用」。
- **实际实现上的难点**：需要计算多维联合变量的**联合概率分布**，变量一多（教师说「N 个值」）计算难度非常高——
  这正是课结束的地方（`1:18:43` 学生追问「N 个值是多少」，课就此下课）。

#### 图 5-5：四个量的关系

教材图 5-5 用**两个集合**（两个随机变量）的形象展示信息熵、条件熵、联合熵与互信息的关系：
两个圆的并集对应**联合熵**，各自独占的部分对应**条件熵**，重叠部分对应**互信息**（共有信息）。
教师点名让学生看这张图，并强调互信息既能描述共同信息含量、又能描述相关程度。

### 七、为什么要用信息论补潮流断面

- **教材的出发点**：希望以**断面潮流量**构成的断面特征来训练「稳定 / 不稳定」的边界。
- **潮流断面为什么被寄望**：断面概念的产生是为了便于**调度运行人员监控**，特别是互联系统；
  调度运行人员多年经验积累，总结出实际运行方式下系统安全性与这些**关键潮流断面的定量关系**，
  由此就不必同时监控全网数量庞大的各种变量。
- **它的三个短板**：
  1. 这种定量关系「费时、费力」（转写还有「费解、比较舒畅」等含混字串）得出；
  2. 人工筛选出的潮流断面**难以包含电网全部的潮流信息**；
  3. 有研究表明，在固定电网控制结构及事故前提下，用潮流断面变量作特征得到的边界**并不唯一**，随运行点变化而变化。
- **所以要用信息论**：借助信息熵等工具把**不同特征提供的信息量化**，
  从而找出「潮流断面特征之外还能提供**补充信息**」的量——这就是本章信息论特征选择的动机。

## 课件补充

- **图 5-1：特征选择的四种典型情形**（`55-1` 为转写误读）。教师拿「输入一 / 输入二」两个坐标讲四种分布：
  1. **线性可分**：两类样本分布规律，**分界面几乎是线性的**；
  2. **大面积重叠**：两种不同类型的样本很大程度上互相重叠，此时输入一与输入二「从直观来看就不能被认为是较好的特征」；
  3. **能分但分界面非线性**：两个输入可实现两类区分，但分界面是非线性形式，**不便于给出显式数学表达式**；
  4. **线性可分且分类几乎只由输入二决定**：输入一在很大范围内变化都基本不影响分类结果，
     因此可以**进一步压缩维度，用更少的特征**表达同样效果。
  - 教师由此给的判据用法：这四种情况的对比，就是判断「特征选择在哪种场合效果更好」。
- **线性的判据**：检验一个系统是不是线性，就看它是否满足**叠加原理**——满足即为线性，否则为**非线性**。
