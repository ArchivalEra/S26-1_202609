# 11-03-一次调频性能评价

## 这节课在干什么

这一节是第四章的续篇，把**一次调频**从「有几个静态参数」推到「怎么在数据上把它的性能算出来」。

以及**大扰动与小扰动**的判据口径），然后摆出**一次调频的七项指标体系**——两个关键项加五个主要指标，

它由「数据处理」和「关键时间点搜索」两大块组成，数据处理又分**坏数据剔除 → 平滑处理 → 二次调频影响剔除**三步。

以及一次调频（有差）与二次调频（无差）的对比。末段开了二次调频在线评估的头，未讲完。

要带走四件事：

1. 七项指标各是什么、哪个最关键、哪些有算式号；
2. 评价算法的三步数据处理与「只在频率大幅变化时才计算」的判据；
3. 六个关键时间点的含义与方差比较法的机械做法；
4. 联络线、区域 $\beta$ 系数，以及一次调频与二次调频「有差 / 无差」这条分界。

## 没编号但讲了的知识点

### 一、复习：两个关键指标与「静态 / 动态」的分界

#### 一次调频调的是什么

教师先回到**手段**上：调频是**调有功**（有功管频率、无功管电压），一次调频调的是**发电机的转速**，
发电机的出力由转速控制。方向上：频率降要提高转速（出力升），频率升要降低转速（出力降）；
但不能一味地提转速，还要考虑**发电机的稳定性范围**与**其它机组的协同**——
「你可以停一些发电机组」「投入几个发电机组」，用这些手段把频率稳住。

#### 调差系数（式 4-1）：静态指标

定义式与几何意义在 10-27 已讲透（[密度初筛与调频](./10-27-密度初筛与调频.md)），本节只补**它属于哪一类指标**：

$$\delta = -\frac{\Delta f / f_N}{\Delta P / P_N}$$

- **静态指标**：因为调差系数是按**调节前后的稳态值**算出来的，反映的是一次调频的**有差调节**特性。
- 教师给的分界线是**方程的类型**：
  - **稳态分析**的指标，方程是**代数方程**，没有微分方程，也不是参数方程；
  - **动态分析**则要写**微分方程／微分方程组**，或者**差分方程／差分方程组**。
  所以「调差系数是静态指标」不是一句定性话，它的判据是**这个指标靠代数方程还是靠微分方程描述**。

#### 调频死区：控制环节里的一环

- **它和调差系数一样，都是发电机调速系统控制环节中的重要一环**。从**理想的发电机组一次调频特性**看，
  调速系统需要时刻针对频率变化做出响应；但实际运行中为了维持机组稳定运行，调速系统通常要设置**人工调节死区**。
- **国内的一般要求**（教师说是常识）：
  - **电液型汽轮机调节控制系统**（火电机组）的一次调节死区控制在 **0.033 Hz 以内**；
  - **水电系统**的一次调频死区控制在 **0.05 Hz 以内**。
- **为什么火电比水电严**：火电机组的响应速度比水电快。
- **范围**：燃煤机组、燃气机组、垃圾发电、沼气发电等火电技术路线，
  都是「加热水蒸气 → 蒸汽驱动汽轮机 → 汽轮机驱动发电机」，所以**遵从的都是火电机组的死区要求**。
- **设置死区的意义**：
  - 当电网频率基本维持在 50 Hz 规定值、未超出调频死区要求时，机组**不用对频率的微小波动做出响应**——
    偏差在误差带内就不动作；
  - 只有当系统频率偏差**超过死区阈值**时，调速系统才对频率差做出响应，调节**汽轮机阀门开度**，改变机组出力；
  - 这样机组能保持较好的稳定性、减少不必要的损耗。
- **死区阈值与稳定性的关系**：死区参数跟机组的稳定程度息息相关，所以死区的**参数估计**尤为重要。
  **故意把死区阈值调高**，会让机组在面对系统较大频率波动时**不动作**，进一步**危害电网的安全稳定**。

#### 大扰动与小扰动：判据是「结构变没变」

教师给的分界只有一条：**系统的结构（拓扑）变没变**。

| | 结构 | 参数 | 属于哪类分析 | 教师的例子 |
| :--- | :--- | :--- | :--- | :--- |
| **小扰动** | 不变 | 幅值小幅变化 | **稳态分析** | 纯电阻负载的阻值上下改变一点 |
| **大扰动** | 改变 | — | **动态（暂态）分析** | 突然增加一个电感或一个电容；负载性质改变；**电压幅值大幅跌落甚至停电** |

- **运行轨道**这个比喻是教师用来解释**稳态稳定性**的：稳态相当于一条运行轨道，
  像地球绕太阳的公转轨道，轨道上的角频率是固定的；小扰动是把运行点「撞开」一点、稍微脱离轨道。
- **大扰动下怎么处理**：图 **4-3** 是「大扰动下机组典型一次调整过程」。负载性质改变时各机组的表现不同，
  所以要靠**调节转速**，或者**投入／切除机组**，把频率稳住，不至于大幅偏离误差带。

### 二、一次调频的指标体系：七个指标、两个关键项

教师反复强调的一句话是「**一次调频的指标体系有七个**」，并点明**其中两个最关键**。
按教师自己给的编号，七个是：

| # | 指标 | 性质 | 教师给的口径 |
| :--- | :--- | :--- | :--- |
| 1 | **调差系数** | 静态 | 关键项；按调节前后的稳态值算，反映**有差调节**特性；式 4-1 |
| 2 | **调频死区** | 静态 | 关键项；火电 0.033 Hz 以内、水电 0.05 Hz 以内 |
| 3 | **一次调频贡献电量** | 积分量（120 秒） | 计算原理 **4-6** |
| 4 | **一次调频贡献率** | 比率 | 计算原理 **4-7**、**4-8**；多数电网拿它当考核标准 |
| 5 | **一次调频正确动作率** | 单机长期统计 | 阈值一般取 0，也可取 $-0.1$ 以识别**反调** |
| 6 | **一次调频投运率** | 长期统计 | 投切信号经**远程终端 RTU** 送省调 |
| 7 | **一次调频滞后时间和稳定时间** | 动态特性 | 时间常数取**电感/电阻** $L/R$ |

下面按编号逐个展开。

#### 一次调频贡献电量（式 4-6）

- **地位**：各区域电网分析判断发电机组一次调频能力的**重要指标之一**。
- **算式怎么来的**（教师口述的链条，不含教材未讲的细节）：
  1. 以**一次调频的调节起点**（转写读作「要求时期点」）和**实际发电有功**为基点；
  2. 向后**积分发电变化量**；
  3. **积分时间长度取 120 秒**（2 分钟）；
  4. 若 120 秒内**系统频率恢复到系统一次调频时间**（转写此处句子断续，含义未讲全），积分到此为止；
  5. 若这期间有 **AGC 指令**或**机组发电计划**致使机组发电变化，
     则该变化量**应减去机组正常爬坡速率的变化部分**及**机组计划提升电量**。

#### 一次调频贡献率（式 4-7、4-8）

- **它衡量什么**：整个调节过程中贡献的**能量占比**，因此是一次调频评估的**重要标准**。
- **为什么它能当考核标准**：它**对数据采样率和精度要求不高**，
  现有的采集系统数据可以满足**粗略的评估要求**——所以**目前多数电网采用贡献率作为一次调频的考核标准**。
- **定义**：贡献率 = **实际贡献电量** 与 **理论贡献电量** 的比值。
- **两个量的获取难度不对等**：
  - **实际贡献电量**：直接从测量得到；
  - **理论贡献电量**：计算**比较复杂**——要用到一个**积分**，涉及一个**时间段**内的频率变化，还涉及**长度系数**。
    所以式 4-8 是「先算出理论值，再与实际值作比」这一步。
- **符号**：
  - $\Delta F_t$：**电网频率与阈值（考核限值）的偏差**；
  - $\Delta F_{set}$：理论上的**调差系数设定值**，或电网规定的**调差系数考核值**，**一般取 5%**。
- **它反映什么**：反映机组的一次调频**性能与预期之间的关系**。

#### 一次调频正确动作率

- **归属**：**属于单机**，不是多机、不是机组层面的量；是**单机长期统计**指标。
- **它统计的是什么**：单机在**日常运行**下的**贡献率统计值**（转写此处读作「日常小劳动」，
  词义未讲全，正文只记「日常运行」）。
- **为什么单看贡献率不够**（教师给的两条机制）：
  1. 日常平均波动很小，一次调频**可能尚未开始明显动作**，频率就已经回到阈值以内；
  2. 或者部分机组**调速器死区设置过大**，在频率超过阈值期间**一次调频并没有动作**，
     但记录本身有功功率的**自然波动**使过程中算出的**贡献率为正值**——这个正值**并不属于机组的主动行为**。
  所以**仅用单次调节的贡献率对机组进行考核是不合理的**，还要看正确动作率。
- **判定规则**：当机组并网运行时，在**电网频率超过机组一次调频死区的一个积分期间**内，
  若机组的一次调频功能**贡献量大于阈值**，则记为**该机组一次调频正确动作一次**，否则记为**不正确动作一次**。
- **阈值取值**：**一般取零**；但贡献率受机组出力随机波动的影响较大，
  也可以取一个**较小的负数**（如 $-0.1$）——**只有负的贡献电量且绝对值较大时，才判定机组发生了反调**。
- **统计口径**：用**机组一次调频月正确动作率**作为考核机组日常一次调频性能的指标，**按月计量**。

#### 一次调频投运率

- **性质**：**长期的统计指标**。
- **信号怎么采**：机组一次调频的**投切信号**由**实际运行的能量管理系统实时采集**。
- **信号怎么走**（这条链路是本指标的关键）：
  1. 机组**控制系统**通过其**主站**；
  2. 以**软开关**形式把机组一次调频投切信号发出；
  3. 经**远程终端（RTU）**送至**省调**，甚至送至**中调**；
  4. **能量管理系统自动记录**机组一次调频的**投切时间**，**计算一次调频投运率**，并作为考核依据之一。
- **软开关是什么**：教师顺带点了一句——软开关技术属于**电力电子技术**，
  它使能量转化效率**接近 1**，损耗可以忽略。
- **为什么信号要往调度走**（这一段把调度层级讲清楚了，是投运率指标能成立的前提）：
  - **国调** = 中央，**国家电网**的调度中枢**在北京**；
  - **省调 = 中调** = 省会城市的调度，省内电网；
  - **地调** = 市级调度；**县没有调度权**；
  - 原先还有**区调**（如华东区），现在这一级已经**去掉**。
  - 所以是**三级调度**。
  - **调频归调度管理**：没有调度中心的指令，**不能擅自投入或切除机组**——
    哪怕是大发电厂也要听从调度中心的指令；教师把擅自投运机组说成**安全事件**。

#### 一次调频滞后时间和稳定时间

- **它们衡量什么**：**响应速度的快慢**。
- **一次调频动态特性包含哪些环节**（教师逐项列）：**阀门动作**、**指令延迟**、**执行环节的时间常数**；
  水轮机侧还有**水头**环节，汽轮机侧是**蒸汽**环节——燃煤、燃气、火电、垃圾、核电等各条火电技术路线
  都要经过「加热水蒸气 → 汽轮机」，所以这一段是**共同的**。
- **时间常数取什么**：用电力元器件组成时，时间常数就是**电感除以电阻** $L/R$。
  下学期学自动控制原理时会正式遇到这个量。
- **方向**（教师当场更正过一次口误，以更正后的为准）：
  - **时间常数越大 → 响应速度越慢**；时间常数越小 → 响应速度越快；
  - **滞后时间越长 → 速度越慢**；滞后时间越短 → 速度越快。

### 三、基于 WAMS 的一次调频性能评价算法

#### 这套算法要解决的关键问题

**发电机组一次调频的关键问题，就是机组是否快速响应频率变化**——
具体是「它的有功是否快速地跟踪了频率的变化，频率变化被准确地抑制、达到稳定」。

#### 评价方法的两段式结构

一次调频评价方法**分成两部分**：

1. **假定机组各项参数设置正确**，按评价算法的计算公式进行计算；
2. 如果计算结果表明**一次调频没有正确动作**，则进入**第二部分**——**估计调差系数**和**实际的死区设置阈值**。

也就是说：先用「参数设置正确」这个前提跑一遍主判据，跑不出「正确动作」时，
再回头估计「你到底设错了多少」——调差率估偏了多少、死区阈值实际设成了多少。

#### 算法流程与「不需要编程」的口径

- 流程是：**读入一组数据 → 数据处理 → 基于调差率与死区设定的一次调频评价算法**。
  教师给的口径是「编程的时候按照这个流程去编程就行了」，同时又说明
  **本课不要求编程**，只要求知道**组成、特点、基本原理**。
- **关键时间点参数**是整个评价的落点：从 WAMS 数据处理得到四个时刻——
  **频率起始时刻**、转写读作「**记录处理时刻**」的那一个、**处理结束时刻**和**频率回到稳定时刻**；
  对它们做分析计算，才能得到**调差率**与**死区设置的阈值和估计值**，
  最终得到**基于调差率和死区估计的机组一次调频评价方法**。
- 关键时间点算不出来，是因为它要考核**机组是否快速响应**——
  所以要先**剔除干扰、排除干扰**，评价结果才是干净的。

#### 数据处理第一步：坏数据剔除（判据 4-13）

- **为什么要做**：一次调频指标要用的两个基础数据是**电网频率**和**发电机有功功率**；
  而实际过程中，**测量、数据采集、数据传输、数据存储**各环节都难免有错误。
  所以对 WAMS 提供的数据，**首先要做坏数据的剔除**，即**辨识、修正**。
- **判据是式 4-13**（教师说「超过了这个误差带就认为是异常数据」）：
  - 具体口径：**实测频率对基准值的变化，超过基准值频率量的 50%**，即判为**异常数据**；
  - 处理动作：**剔除**明显超出正常范围的数据。
- **怎么修正**：利用**频率特性曲线的连续性**，**用前一个时刻的数据代替坏数据**。

#### 数据处理第二步：平滑处理

- **要解决的问题**：各类指标要从**大量数据**中提取关键信息，而**数据的波动**让信息提取变困难，
  容易引起**误判**——比如这一次跳出去、下一次直接上很陡的曲线。
  所以要**滤除干扰**，得到平滑的数据。
- **做法**：**平均值方法**——把**固定时间周期内的所有数据进行平均**，
  用平均值代替这段时间内的**所有数据**，以**消除单点测量的偏差**。
- **取样与周期的取舍**（教师用班级平均成绩作类比）：
  - 周期**取得越长**，平滑效果**越好**，但**预期的信息就会丢失越多**；
  - 周期**取得越短**，**数据扰动就大**——就像用**一个同学的成绩**代表**一个班的普遍成绩**，不成立；
    班级成员越多，这个平均值越精确，也就是**样本量越大，个别干扰被削弱得越厉害**。
  - 平滑周期取 **0.1 秒**。
- **相对其它数据滤波方法的优点**：相比其它数据滤波的平滑方法，
  这个方法**可以取得很好的平滑效果，又不丢失必要的信息**，而且**方法简单、便于应用**。

#### 数据处理第三步：二次调频影响剔除

- **为什么要剔除**：**大扰动发生时，一次调频与二次调频会耦合在一起**。
  用 WAMS 数据考核一次调频性能时，**应该把二次调频的作用剔除掉**，这一章算出来的才是**纯的一次调频效应**。
- **方法依据**：**AGC 指令是矢量**——既有**方向**又有**幅值**（模就是复功率的模）。
  凡具有这种性质的量，就按「矢量」的方式处理：把它的**方向**与**量值**分别确定，再整体剔除。
  剔除掉这一项，就等于剔除掉二次调频的影响。
- **两个关键点**：
  1. **剔除方向**：根据 **AGC 指令数据**以及**二次调频在线评估系统的计算结果**，
     确定在响应过程中二次调频的方向——方向包括**增速率**（上升速率）与**减速率**（下降速率），
     以及**总的功率改变量**；
  2. **剔除量值**：根据二次调频在线评估系统的计算结果，得到响应的**上升速率和下降速率**，
     最后把量值与方向**拟合成一条 AGC 响应指令曲线**，作为**剔除 AGC 指令**的依据。

#### 什么时候才计算：大扰动与小扰动的判据

- **前提**：**只有在频率大幅度发生变化时**才进行计算，所以**需要设置相应的判断依据**。
- **判据怎么定的**：经过**分析和仿真验证**。为什么只能做仿真——教师说得很直白：
  「因为电力系统我们不能说去为了做一次实验」，**只能用电网的过往历史数据做仿真**；
  而这些历史数据**都是电网系统里提取出来的，一般人拿不到**，属于**战略数据**。
- **大扰动判据**：在线频率对基准值的变化**超过 $\Delta F_1 = 0.033\ \text{Hz}$**，
  **且持续 $T_1 = 0.3\ \text{s}$**——**两条均满足**时，判断系统发生大扰动。
  - 0.033 Hz 这个数值的来源与前面的死区一致：**火电机组的响应时间要求比较快**。
- **小扰动判据**：**只取第一条**（频率阈值），但**时间阈值取 $T_1 = 8\ \text{s}$**。
- **为什么不能只看单个机组的频率**：电网日常运行中，**发电机的开停是经常发生的**，
  而**机组启动或关停过程中，计算测量的频率就会发生很大的变化**，
  所以不能简单地用发电机组处的频率来判断。
  **做法**：取**分布在电网不同地理位置的几个大型变电站**的频率数据，**求平均**，
  用这个**平均值**作为判断依据，**更加可靠**。

### 四、关键时间点搜索：六个时间点与方差比较法

#### 指标计算的难点在哪儿

教师把难点说得很准：**从单机的三个指标来看，指标计算的难点在于寻找调节开始和结束的关键时间点**。
六个时间点画在**有功功率随时间、频率随时间**这两条特性曲线上。

#### 六个关键时间点

| 时间点 | 含义 |
| :--- | :--- |
| $T_1$ | **频率超过阈值**的关键时间点 |
| $T_2$ | **频率回到阈值内**（回到误差带内）的时间点 |
| $T_3$ | **频率开始变化**的时间点 |
| $T_4$ | **有功功率开始变化**的时间点 |
| $T_5$ | **频率稳定**的时间点 |
| $T_6$ | **有功功率稳定**的时间点 |

- **$T_5$ 的「稳定」不是精确值**：不是达到某个精确值，而是**与基准值的误差在允许范围内**。

#### 搜索方法有哪几类

教师点的搜索算法包括：**决策式算法**、**距离算法**、**神经网络算法**、**支持向量机算法**，
另有**专家算法**等。这些方法的共同目标是**计算最优值**——即尽可能精确地解出关键时间点。

#### $T_1$ 怎么取

- 启动判断的**第一个条件**是「**频率超过阈值持续一定的时间**」；
- 在判断过程中**记下频率超过阈值的第一个点所对应的时间**，记为 $T$，这一步算法就**直接得到** $T_1$。

#### 方差比较法（图 4-7）

- **出处**：这套教材的**清华大学教授**提出的方法，教材称之为**方差比较法**。
- **它利用的数学特征**：**频率突变点的数学特征**。做法的机械步骤是：
  1. 对**频率超过阈值前的 1 个数据窗**进行**扫描**；
  2. 对**每个数据点**，比较它**前 1 秒的频率序列方差**与**后 1 秒的频率序列方差**之**差**；
  3. **前后方差变化最大的点**即为**频率变点**（突变点）。
- **图 4-7 的例子**：突变点就是曲线上那个**冲击**所在的位置，教师报出该点的坐标为
  **$X = 8.5$、$Y = 50.1$**。
- **方法的评价**：教材通过**仿真验证**了该方法的**可行性和有效性**；
  它的优点是**简单直观、便于编程**。
- **怎么降计算量**：**只需要搜索到之前已经搜索出的时间点**——
  因为**频率发生突变的点，一定在频率超过阈值之前**。

#### 判据 4-14：怎么认定「一次调频没有动作」

- **为什么要这个判据**：为了**准确评估一次调频的作用**，要**避开机电暂态过程对有功功率曲线的影响**——
  此处**忽略有功功率在机电暂态过程中的变化**。
- **判据的两个条件**：
  1. **突变前 1 秒的功率模值**大于 **0.4% 的基本功率**（基本功率即**有功功率的基准值**）；
  2. **$\Delta P$ 与 $\Delta F$ 反方向变化**：$\Delta P$ 取该数据点**之前 1 秒**的有功变化量，
     $\Delta F$ 取该数据点**之前 1 秒**的频率变化量；$\Delta P > 0$ 则 $\Delta F < 0$，反之 $\Delta F > 0$。
- **结论**：**满足这个判据，就认为一次调频没有动作**。
- ⚠ 条件②的方向语义（$\Delta P>0 \Longleftrightarrow \Delta F<0$）与式 4-1 推出的**一次调频正常动作方向相同**。
  这个口径出自**教材判据 4-14 本身**（两条条件与结论都是教师原话），本页照录；**建议按教材 4-14 复核**
  （issue #31）。

#### $T_5$、$T_6$ 的计算口径

- **$T_5$（频率稳定）**：这段时间**可取 3 秒**，带宽取 **0.005 Hz**。
- **$T_6$（有功功率稳定）**：教师交代「了解一下就可以了」，没有给判据数值。

### 五、一次调频分布特性对联络线潮流的影响与区域 $\beta$ 系数

#### 联络线与联络线潮流

- **联络线是什么**：多台机组**同时（同步）运行**时，机组与机组之间**有功率交换**，
  这个交换功率的**渠道／线路**就叫**联络线**。
- **为什么要有它**：既然交换功率要通过联络线走，这个**交换功率是多少**就要**计算分析**——
  属于**动态分析**的内容，下学期「电力系统分析」会学一部分。
- **联络线功率**：就是**连接线路的潮流**——潮流指的是**有功功率的分配**。
  稳态分析里做**有功与频率控制**时要计算联络线功率。

#### 区域自然频率特性系数 $\beta$

- **区域一次调频的特性由什么决定**：由**区域内的发电机和负荷特性**决定。
- **用哪个量表示**：一般用**区域自然频率特性系数 $\beta$** 表示。
  - 它**表示各区域所具备的一次调频能力**；
  - 它是**一次调频与二次调频的纽带**。
- **定义式的位置**：教材 **4-3**（教师报出页码并说「它的定义式是由这个定义式来表示的」，
  课堂上**没有推导**、也没有代数值算例）。
- **教师把它和二次调频串起来讲的那一条**：当二次调频系统的**频率偏差系数等于这个特性系数**时，
  各区域的**负荷扰动**要**完全由本区域的自动控制系统（AGC）来承担**，
  从而**完全补偿扰动过程中暂时提供的扰动功率**。
  由此得出：**区域自然频率特性系数 $\beta$ 描述的是互联系统的一次调频与二次调频，
  也决定了系统频率控制效果和区域二次调频**。

#### 一次调频与二次调频：有差与无差

当前**互联电网的调频手段由一次调频和二次调频共同组成**，两者的分工是：

| | 一次调频 | 二次调频 |
| :--- | :--- | :--- |
| 应对的对象 | 系统中的**有功功率突变** | **区域控制偏差（ACE）** |
| 做什么 | 快速抑制系统频率的变化，对功率扰动区域**产生功率支援**，保证一次调频后的**准稳态频率**不会导致各类保护动作 | 使**系统频率**与**联络线交换功率**恢复到**计划值** |
| 调节性质 | **有差调节** | **无差调节** |

- **为什么一次调频之后紧接着要二次调频**：正因为一次调频是**有差调节**——频率回不到原值，
  所以紧接着要由二次调频把它**拉回计划**。
- **教材的位置**：教师指教材 **77 页**最后一段就是**一次调频与二次调频的比较**。
- **二次调频的主要手段是 AGC**（自动发电控制）。
- **结论性的一句**：**功率扰动下区域间联络线有功功率的变化，体现了区域间一次调频能力的临时支援，
  体现了互联电网的优势**。
- **但要有公平**：为了保证**联络线的安全稳定**以及**互联电网一次调频的公平公正**，
  互联电网应根据**各区域电网功率扰动的数学特性**，为**各区域一次调频能力的分布**提供**合理的参考值**，
  让各区域的一次调频能力与**负荷扰动的统一特性比例相同**，
  从而**规范和约束区域一次调频能力**，实现**一次调频调节成本的公平分配**。
