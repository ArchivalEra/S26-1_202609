# 09-29-大数据与AI算法

**这节课在干什么**：这是第二章的第一次课，主题是**大数据技术与人工智能技术的原理**，以及它们
**在电力系统里的应用**。前半段讲**电力大数据**：它从哪来（发输变配用五个环节、各类传感器与信息系统）、
有哪**四个特点（4V）**、面临哪些**挑战**、数据来源分哪**两类**；后半段讲**人工智能**：
它的定位（计算机科学的分支、交叉学科）、**三个发展阶段**、**两个技术范式**，以及
**支持向量机、集成学习**等算法的原理与相关概念。教师全程按**考试考点**来讲，
明确点出判断题、选择题、简答题、计算题各考什么。

**行政与考核**

- 教师把本章内容直接对应考试题型：**判断题**（大数据 4V 中的 value 怎么翻译、数据特点）、
  **选择题**（数据结构分类、数据来源两类、人工智能两个范式）、**简答题 5 分**（电力系统运行状态分几类）、
  **计算题 20 分**（人工智能里的**决策树算法**）。
- **作业**：一学期约 **5 次**。第一次作业布置了两小问——**简述大数据的特点**、**简述人工智能技术的常用算法**，
  要求「写得详细一点，写一遍相当于学三遍」；**国庆节放假回来交**，建议用作业本、按学号排。
- 教师提到**学信网**也会有通知，作业计入平时成绩。
- **期末开卷**，但考试时**手机要收上去**。

### 考点：电力系统运行状态分几类（5 分简答题）

**解析**（教师直接给出答案框架）：电力系统运行状态分**五类**——

1. **正常**状态；2. **警戒**状态；3. **紧急**状态；4. **测试**状态；5. **恢复**状态。

教师解释这个分类的重要性：**一旦电力系统状态确定下来，对应状态该做的操作就会发给操作员去完成**；
而**大数据技术有助于状态的分类与物理过程的识别**。

**这一题在讲什么**：把大数据技术的应用落到**电力系统运行状态识别**这个具体场景上。
教师说总复习时不会再逐题讲一遍，所以这里就点明。

### 考点：大数据 4V 特点中 value 的翻译（判断题）

**解析**：大数据的四个特点（4V）是 **Volume（规模大）、Variety（多样性）、Velocity（速度快）、
Value（价值）**。教师特别把 **value** 拎出来做**判断题**，说「**容易出错的就是这个点**」，
要学生回去**查准确的中文翻译**，并说「如果翻成『价值高』就错了」——
教师的意思是 **value 不能简单译成「价值高」**，其含义是**价值密度低、但潜在应用价值巨大**。
（转写里教师原话前后矛盾，正确翻译未给出。）

**这一题在讲什么**：大数据 4V 是本章最基础的考点，value 的中文译法是判断题的「陷阱点」。

### 考点：数据结构分类（选择题）

**解析**：从**结构类型**分，电力大数据包含三类——

- **结构化数据**：形式固定，如 **Excel 表格里的数据、成绩单、班级名单**。
- **半结构化数据**：如 **Word 文档、PPT 文档**。
- **非结构化数据**：没有固定结构，如**微信、博客、在线主播聊天/视频**等产生的数据。

教师说这里会**给例子出选择题**，问某个例子属于哪一类。

**这一题在讲什么**：数据类型的**分类方式不止一种**（教师提到还有五种分类方式），本课按**结构类型**考这三种。

### 考点：电网分析计算的数据来源分两类（选择题）

**解析**：电网分析计算的数据来源主要两类——

1. **离线形成的计算数据文件**：如仿真软件计算输出的数据，以**母线支路模型**形式存储。
2. **能源管理系统（EMS）提供的电网实时数据**：通常在内存中，以**节点开关模型**形式存储。

**这一题在讲什么**：两类数据来源对应的**存储/建模形式不同**（母线支路模型 vs 节点开关模型），
这是选择题的区分点。

### 考点：人工智能里的决策树算法（期末计算题 20 分）

**解析**：教师明确说，人工智能技术里的**决策树算法**将作为**期末考试的一道计算题，20 分**。
本次课只点名、未展开讲解，说「下边」再讲。

**这一题在讲什么**：人工智能部分的**唯一确定的大题**，重点备考对象。

## 没编号但讲了的知识点

### 电力大数据为什么必须上

- 大数据技术、人工智能技术都**始于上世纪**（人工智能始于**五六十年代**），到现在是**第三个阶段**，
  也是真正落地的阶段。
- 电网规模越来越庞大、智能电网推进，电力系统朝**信息化、数字化**发展，靠**信息系统与技术**来提升。
- 变电站、换流站已经**无人值守十几年**，靠**机器人**支撑；**线路巡检用无人机**；
  人工智能取代了大量人力工作，但**信息类工作仍需人去做**。
- 人工智能擅长应对**高维、非线性问题**。这类问题解析解求不出，只能**数值计算**；
  而维数、阶次很高时，**计算机（包括量子计算机）也算不动**，这时只能靠**人工智能＋大数据**。
- 三者的分工：**高性能计算**为人工智能提供**算力**，**大数据**提供**训练样本**，
  **机器学习/深度学习**提供**模型与算法**，三者合力推动人工智能进步。
- **算电系统**：今年人大会议首次提出，**算力加电力**——**算力是大脑，电力是躯干**，
  没有电力就没有动力。教师说美国高端技术强但在市场上受限，一个原因就是**电力不足**；
  中国电力「独领风骚」，且**提前十年二十年规划**抽水蓄能、水电，为 AI 发展做准备。
- 大数据技术的第一步是**数据采集**，采集终端有很多**传感器**——温度传感器、声感传感器、
  各种信号传感器，与**物理状态相结合**，实现**智能传感**，进而**数据驱动＋仿真模型**辅助决策。

### 电力大数据的来源与特点（4V）

**电力系统的五个环节**：**发、输、变、配、用**（加上**调度**）。配电网信息化、自动化、互动化水平提高，
以及互联网融合，使电力企业积累了大量数据，例如：

- **用户用电数据**、**调度运行数据**、**GIS 数据**、**设备监测检测数据**、**故障数据**；
- 还有大量**运营数据**：客户服务数据、企业管理数据、电力市场数据等。

数据来源的**物理载体**：发电机、变压器、开关设备（智能断路器、隔离开关等）、输电线路、架空/吊篮架构、
光缆等，都靠**传感器**监测获取状态数据。

**电力大数据的四个特点（4V）**：

1. **Volume（规模大）**：电力系统涉及发、输、变、配、用和调度各环节，长期运行积累海量数据；
   智能电网建设、监控精细化，数据还在**爆炸式增长**（例如手机上查电费、交易，每个动作都产生数据）。
   因此需要**高可扩展的存储方案**、**渐进式建设**，并走向**云计算/云平台**（不自己装服务器，租用服务）。
2. **Variety（多样性）**：数据类型繁多，狭义看主要是智能配电网大数据，包含**结构化、半结构化、非结构化**
   三类；广义还包括数据状态、数据规范、数据分析方式的多样性，表现为**数据种类繁杂**、
   **保存方式多样**（文件形式、数据库形式）。
3. **Velocity（速度快）**：电力系统是实时大系统，涉及众多设备与线路，任一环节出错都可能造成事故，
   所以要对设备状态**实时监控**，数据产生速度极快，要求**响应快**——状态异常要**立即切除**，
   否则停电会造成巨大经济损失。
4. **Value（价值）**：智能配电网大数据有**巨大的潜在应用价值**，但价值**隐藏在规模巨大的多元海量数据**中，
   价值**在不同数据源、不同时间断面、不同数据类型中体现**，需要**挖掘**。

**数量级**：数据量从 **GB → TB → PB → EB → ZB → YB** 逐级上升，**每个单位之间差三个数量级**
（$10^3$ 倍）。教师让学生自己查各单位的名称与数量级。

### 电力大数据的两类数据来源（含专业系统）

- **离线仿真数据**：国内外电网仿真一般采用**文件或关系数据库**存储。
- **实时运行数据**：电网运行状态数据从**能量管理系统（EMS, Energy Management System）**的
  内存实时服务中，经状态处理导出形成 **CIM/CIME 文件**（转写作「CIME」），供电网逻辑计算程序使用；
  或用 **BPA 输入文件**（电力系统分析软件，中国电科院开发，国家电力调度控制中心在线系统上路过程约两分钟）。
- 电网数据模型广泛用于**规划设计、调度运行**。

### 大数据面临的挑战

1. **数据质量**：数据质量好坏直接影响分析结果的准确性。海量数据中要**筛选**出对分析有效的部分，
   剔除**垃圾数据**；电力系统传感器处于复杂自然与电磁环境，采集难免出错，导致数据质量偏低。
2. **数据类型**：结构化、半结构化、非结构化并存，处理方式不同。
3. **数据安全**：大数据涉及用户**隐私信息**（账户信息等），需要保护。
4. **数据存储与处理**：数据量达到 P 级、E 级，对存储与计算能力提出高要求——既要**升级系统**适应存储与交换，
   又要开发**效率更高的数据挖掘算法**满足快速处理要求。

### 大数据在电力系统中的六类应用

教师列举了电力大数据技术的应用方向：

1. **负荷（复合）预测与用户特征提取**——预测精确才能做后续调度决策；
2. 利用数据**分析电力系统故障点关系**；
3. **电力系统稳定性分析与安全性评估**；
4. **电力系统运行中变化与异常的检测和识别**；
5. 用**归纳法**从事故案例分析中构造**专家系统**（样本数据库，本质是模型题、数据题、数学问题）；
6. 最终目标是**高效调度**——**经济调度**。

教师强调：**经济调度首先要考虑全系统经济性，但民生是第一位**（如汛期要保证民生），
**民生前提下再考虑环境因素**。

### 人工智能是什么：定位与学科属性

- 人工智能是**计算机科学的一门重要分支**，是当前**非常活跃**的研究领域，
  已成为**产业领域最高端的技术**之一；中国与美国**共同制定人工智能发展标准**。
- 它是**交叉学科**，涉及**应用数学、机械、材料、计算机、电气、控制技术、通信技术、生理/生物技术、
  神经生理学、心理学、哲学、伦理学**等（伦理学是因为人工智能将带来伦理问题，
  这也是马斯克、比尔·盖茨担忧超人工智能的原因）。
- 人工智能的定义：**研究用于模拟、延伸和扩展人的智能的理论与方法的技术**。
  它既给出原理性理解，也为后续专业课（自动控制原理、电力系统分析等）打基础。
- **原理与算法是实现人工智能应用的基础与核心**，决定人工智能的能力与性能。

### 人工智能的三个发展阶段

教师明确说这部分**书上没有**：

1. **弱人工智能**：现在的**智能汽车、无人机**等；
2. **强人工智能**：类人机器人——能绘画、能诊断病人等；
3. **超人工智能**：**超过人类智慧边界**，会**自学习、自我迭代**，人类无法控制。
   中国与美国制定标准、严防超人工智能失控，就是因为这个风险。

（教师补充：书上只讲到第三代，这三级分类「不考」。）

### 人工智能的两个技术范式与三代发展

- 人工智能长期存在**两个技术范式**（多项选择题考点）：
  **符号主义**（对应第一代人工智能的**知识驱动**方法）与
  **连接主义**（对应第二代的**数据驱动**方法）。
- 依靠单个范式无法推动人工智能真正进步，**知识与数据融合**是人工智能发展的必经之路。
- 发展史要点：
  - **图灵测试**：教师说「1900 年图灵设计了图灵测试」——〔史实为 1950 年，见「转写与术语」〕。
  - **1956 年达特茅斯会议**正式将人工智能作为**单独学科**命名，开启人工智能研究历程。
    距今已约 **70 年**，现在才真正在产业链广泛应用。
  - 从 1950 年起，人工智能经历**几次兴衰**（感知机热潮等）。
  - **2006 年** Hinton（转写作「新盾团队」）提出**深度学习网络**，使神经网络再次崛起，
    引领新一轮人工智能浪潮；目前处于**第三次**人工智能阶段，被称为**深度学习**阶段，
    能处理**复杂非线性问题**、实现**端到端学习**，并在迭代中产生「顿悟/灵感闪现」式的突跃。
  - **1997 年** IBM 深蓝击败国际象棋世界冠军（转写作「ibm 芬兰」）。
  - **2016 年** AlphaGo 战胜围棋世界冠军（转写作「2001 六年阿尔法狗战胜了媒体世界冠军」）。
  - **波士顿动力**的「大狗」机器人（由波士顿大学、麻省理工学院研发，后由波士顿动力公司商品化），
    主要涉及**四项关键技术**：**远程控制、触控爬坡、行进速度、平衡能力**。
- **模式识别**：人脸识别、文本识别、车牌识别、指纹识别等，逐渐在自动工程方向取得成就，
  主要有**自动驾驶技术**、**流水线生产**、**猎鹰系统的自动技术**等。
  教师用俄乌战场上无人机追踪并击杀老兵的新闻，说明**模式识别**能识别敌方战斗人员（后台操作员控制）。

### 支持向量机（SVM）原理与相关概念

教师说人工智能有**九种算法**，本次课主要讲**支持向量机**和**集成学习**，只要求懂原理，不要求推公式。

**定位**：支持向量机（SVM）是一种**监督学习算法**，也是一种**集成学习**思路（教师口述如此），
是较传统、用得较多的算法。

**背景**：传统方法难以求得实际的**稳定边界**；本书用**数据挖掘**方法**拟合稳定边界**。
**稳定评估是分类问题**，稳定边界是**稳定区与不稳定区的分界线**，SVM 通过拟合这个分界面来解决分类问题，
分类效果好、模型简单透明、物理意义明确。

**基本概念**：

- **样本**：由**输入向量 $X$** 和**输出 $Y$** 两部分组成。
- **输入向量 $X$**：由各**物理量**组成，每个分量表示一个物理量，如「故障清除时刻某发电机的**有功出力 $P$**」。
- **输出 $Y$**：代表**分类结果**，是**二进制数**，取 **$+1$（稳定）** 或 **$-1$（不稳定）**。
  对电力系统稳定评估问题：$X$ 是系统物理量，$Y$ 代表稳定性。
- **分类规则**：通过监督学习，从已知样本的输入输出关系中得到，也称**分类器**；
  对电力系统稳定问题也叫**稳定评估规则**。
- **训练**：利用已知样本**寻找分类规则**的过程；用于训练的样本称为**训练样本**。

**原理**：SVM 是一种**迭代方法**，利用**映射函数**把训练样本**映射到高维空间**，
在高维空间中找一个**线性超平面**，使该超平面**到两边样本点的距离（间隔）最远**。

**数学形式**（教师说「只需会读，不需掌握」）：

- **目标函数**：教材**公式 2-1**，由两项组成，要求**目标函数值最小**；其下是**约束条件**，
  用 **s.t.（subject to，受限于/约束条件）** 标出。
- **约束条件**里含 $y_i$（分类结果）与输入变量的表达式，是一个**不等式**。
- **松弛变量**：把**不等式约束转换成等式**以便计算，引入的变量叫**松弛变量**。
  例：$x+y\ge 10$ 用一个松弛变量改写成等式形式。
- **惩罚因子 $C$**：松弛变量前面的系数，起**惩罚**作用——取值越大就适当「惩罚」（收缩）一些，
  使求解范围可控。
- **拉格朗日函数**：引入约束条件、松弛变量与乘子后，把原问题构造成**拉格朗日函数**（公式 2-2）。
- **静态规划 vs 动态规划**：目标函数是**代数方程**的叫**静态规划**；含**微分形式**的叫**动态规划**。
- **对偶问题**：通常把公式 2-1 转化为**对偶问题**（公式 2-4），好处是把**复杂函数计算转化为简单函数计算**，
  **直接在低维空间完成计算**，降低计算量与复杂度，**避免维数灾**——动态规划问题维数过高时
  「永远解不出来」（计算机一直跑、像死机一样）。

### 集成学习算法

- 支持向量机属于**监督学习**，是最初级的一类算法。
- **集成学习**的基本思想：按一定策略**训练出多个「弱监督模型」**，再**组合**得到一个**强监督模型**，
  使其性能大大提升。
- 为什么会有「弱学习器」：基于统计理论（概率论）的机器学习模型，**各方面都好在理论上几乎不存在**；
  模型往往在某方面表现好——要么是**低自由度模型**泛化性（转写作「天体性」）较高，
  要么是**高自由度模型**在结构上**方差较大**，所以被称为**弱学习器**。
- **集成学习是机器学习领域的一种模型融合方式**：对给定样本与目标问题，按一定策略把多个弱模型组合起来。
- 提升学习方法**原理简单、精度比支持向量机高**，被广泛应用。

### 数据的离散与连续（拓扑结构变化）

教师用**暂态稳定分析**举例说明两类信息：

- **离散信息**：如**拓扑结构的变化**——正常工作时是一个电路结构，一旦发生**短路**（电感短路、电容击穿等），
  **结构就改变**，状态空间方程、数学模型都变了。这种突变是**离散**的。
- **连续信息**：正常工作时的**状态量**随时间连续变化（交流量是瞬时、周期变化的），是**连续**的。
- **噪声（干扰）**：电力系统信号传输速度接近光速，**弱电信号（数据通信）会对强电信号造成干扰**，
  例如高压输电线路下方的手机信号会受影响；数据量大时电力信号也会变化，严重时噪声较大。
  教师指出：**直流电路稳定**，受影响的是**交流电路**。
