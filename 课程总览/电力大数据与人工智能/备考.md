### 考点：为什么必须用智能分析（数据链论证）

### 考点：稳定的判据是特征值

**要会**：一句话判据。

- 系统状态由**特征值实部**判：**实部 < 0 稳定**（实部 = 0 临界，实部 > 0 失稳）。
- 与之配套的两个概念：**平衡态**（系统稳定运行的点）、**扰动**（打破平衡的外来作用）。

**容易记混**：判据看的是**实部**（不是模、不是虚部）——虚部只管**振荡频率**。

[笔记原文 ↗](./课堂笔记/09-20-开课第一讲.md#安全稳定的概念群-平衡态-扰动与特征值判据)

### 考点：安全域与安全裕度

**要会**：两个定义各一句。

- **安全域**：状态空间里**「安全的那些点」构成的区域**。
- **安全裕度**：**当前运行点离安全域边界的距离**。
- 细分：**静态安全域**（看潮流约束）与**动态安全域**（看暂态约束）。

**容易记混**：**安全域是「区域」，裕度是「距离」**——一个是集合、一个是数，别答反。

## 2026-09-22 ｜ 暂态稳定评估方法与紧急控制

> **本讲最容易混的地方**：有**两组**方法，一组 4 个（评估）、一组 3 个（控制），**别答串**。

### 考点：评估的四个方法（按出现顺序）

**要会**：四个方法的名字 + 每个的一句话特征 + 为什么被淘汰/保留。

| # | 方法 | 一句话 | 关键点 |
| :-: | :--- | :--- | :--- |
| 1 | **时域仿真法** | 建全元件模型、解微分代数方程组、看功角曲线 | **精度最高**（其他方法的标准），但**不能在线** |
| 2 | **直接法**（能量函数/李雅普诺夫） | 构造能量函数判稳，不求特征根 | **充分非必要**——找不到函数**不能**说系统不稳 |
| 3 | **基于故障后响应** | 直接用故障后实际轨迹判（如故障电流衰减/发散） | 靠 **WAMS/PMU** 实测，可与前两种**结合** |
| 4 | **数据挖掘与机器学习** | 离线仿真建库 → 训练模型 → 在线评估 | **当前研究热点**；AI 是**近似计算、可能算错、要筛选** |

**AI 方法（第 4 类）单独记一句**：它是**近似计算、可能算错、还要筛选**——**不能盲信**。
教师把基于数据挖掘的方法划为**当前研究热点**，前三种都是**经典方法**。

**容易记混**：前三类叫**经典方法**，第 4 类才是**热点**；**时域仿真「不能在线」是本讲反复出现的理由**——
数据中心、并行计算、AI 全是为了解决它。

[笔记原文 ↗](./课堂笔记/09-22-暂态稳定评估.md#时域仿真法-第一类经典方法-讲得最细)

### 考点：时域仿真法的两条提速路线

**要会**：说出两条路线，以及并行计算的**三个研究方向**。

- **路线一：用简化模型换速度**——但不能一味求简（差太远就「没有指导意义」）。
- **路线二：分布式并行计算**（最高形式是**云计算**）。**三个研究方向（教师要求记住）**：
  1. **时间并行算法**——微分方程差分化后与代数方程联立求解；
  2. **空间并行算法**——大系统按物理分布**分成子网**各自算；
  3. **波形松弛算法**——拆小系统、**子系统间交替迭代**。

**关键数字**：判稳通常看**扰动结束后 3–5 秒**；有潜在区间震荡模式的大系统可延长到 **15–20 秒**。

**容易记混**：**微分方程描述动态＝目标，代数方程描述平衡态＝约束**——两类合起来才构成求解问题。

[笔记原文 ↗](./课堂笔记/09-22-暂态稳定评估.md#时域仿真法-第一类经典方法-讲得最细)

### 考点：直接法（能量函数）的三个要点

**要会**：充分非必要、两个定理的差别、为什么发展不下去。

- **充分非必要**（教师强调三遍）：**找到**能量函数可**证明稳定**；**找不到不能**说明不稳定。
- **两个定理的差别**：**李雅普诺夫定理**要求函数**正定**（系数都 > 0，条件更保守）；
  **拉萨尔（LaSalle）定理**只要求**非负定**（≥ 0，是放宽）。
- **发展不下去的原因**：能量函数**没有统一构造方法**，只能用于较简单系统；
  **每加一个新模型（HVDC、三级发电机、负荷动态）就要重造一个能量函数** → 又回到「发展 AI 与云计算是必由之路」。

**容易记混**：**正定**＝能量逐渐增大（发散）；**负定**＝总能量减少（耗散，稳定系统该有的样子）。

[笔记原文 ↗](./课堂笔记/09-22-暂态稳定评估.md#直接法-能量函数-李雅普诺夫方法)

### 考点：紧急控制的三个方法（与评估组分开记）

**要会**：三个方法的名字 + 各自做法要点。

| # | 方法 | 做法要点 |
| :-: | :--- | :--- |
| 1 | **启发式方法** | 用**少量仿真**找方案，靠指标排序（如切机切负荷有效性指标）降复杂度 |
| 2 | **基于响应的方法** | 直接用 **PMU** 量测；判不稳时把系统**等效为两机模型**，用**加速/减速面积**算切机切负荷量 |
| 3 | **基于安全域/稳定域** | 用**切机切负荷**改变稳定边界，把运行点从域外移回域内；边界移动**可近似线性叠加** |

**关键概念**：**灵敏度 = 参数的一阶导**（如电流对负载电阻的灵敏度）。用灵敏度建优化模型，
**计算量与备选措施数量无关**——只需**两次积分/仿真**。

**容易记混**：**切机＝切除发电机，切负荷＝摘掉负荷**，本质都是**调频**手段。
三个方法各自的局限：启发式靠少量仿真、响应法依赖「简化等值」、安全域法依赖「域描述准不准」。

### 考点：大数据 4V 特点（判断题陷阱）

**要会**：四个 V 的中英文 + **Value 的正确含义**。

| V | 中文 | 含义 |
| :--- | :--- | :--- |
| **Volume** | 规模大 | 发输变配用调度各环节长期积累，且爆炸式增长 |
| **Variety** | 多样性 | **结构化 / 半结构化 / 非结构化**三类并存 |
| **Velocity** | 速度快 | 实时系统，异常要**立即切除**，响应要快 |
| **Value** | 价值 | **潜在价值巨大，但价值密度低、藏在海量数据中，需要挖掘** |

**关键数字**：数据量 GB → TB → PB → EB → ZB → YB，**每级差 3 个数量级**（$10^3$ 倍）。

**容易记混**：**value 不能简单译成「价值高」**——正确含义是**价值密度低、潜在应用价值巨大**。
这是判断题专门设的坑。

### 考点：人工智能的三个发展阶段

**要会**：三级各一句（教师补充：**书上只讲到第三代，这三级分类「不考」**——了解即可）。

**要会**：教师**明确点名**这是**期末考试的一道计算题（20 分）**。**10-13 第二次点名**时把**期末范围**收窄到：

### 考点：人工智能常用算法地图（10-13 新增）

**要会**：每种算法**是什么、属于哪一类、用在什么场合**（教师本讲只讲这三样，**不展开流程原理**）。

| 算法 | 一句话定位 | 关键点 |
| :--- | :--- | :--- |
| **支持向量机 SVM** | 优化计算方法 | 映射到**高维空间**找**间隔最大**的线性超平面；本质是全局最优化（目标函数 + 约束，约束常为不等式） |
| **集成学习** | 多个弱监督模型 → 一个强监督模型 | 原理简单、精度较高、应用广 |
| **决策树 / 二叉树** | 分类树 / 回归树 | 叶节点 = 一次运算 = 一个数据样本（数据列表）；过拟合要修剪 |
| **启发式搜索** | 深度优先 + 记忆功能 | **期末大题**（第 28 页第 7 个算法） |
| **GBDT 梯度提升决策树** | 集成学习中应用最广 | 以回归树为子模型迭代叠加、损失函数递减；**预排序**选分裂点，精度高但**耗内存、不适合海量数据** |
| **LightGBM 轻量级梯度提升** | GBDT 的大数据版（2017） | **按叶子分裂**（带最大深度）；直方图 + 单边梯度采样（GOSS）+ 互斥特征绑定；**适合大规模/云数据** |
| **深度信念网络 DBN** | 深层次模型 | 若干**受限玻尔兹曼机（RBM）**堆叠；逐层无监督贪婪训练 |
| **堆栈自动编码器** | 深层次模型 | 多个自动编码器堆叠；**编码**（输入→隐含层）/ **解码**（隐含层→输出层） |
| **卷积神经网络 CNN** | **有监督**学习 | 卷积层（特征提取）+ 池化层（降维、鲁棒性）+ 全连接层；**图像/机器视觉** |
| **循环神经网络 RNN / LSTM** | 处理**序列数据** | 有**记忆**（前一时刻输入也进当前计算）；LSTM 加门控，解决长期依赖、避免梯度消失 |

**容易记混**：**异或门式的「同一符号两种身份」——GBDT 与 LightGBM**：GBDT **不能**用于海量数据，
LightGBM **就是**为大数据改进的；记「**轻**量级 = 大数据」。

### 考点：为什么电力系统要上 AI（10-13 新增）

**要会**：新能源（风、光）高比例接入 → **电力电子设备占比升高** → 系统**惯性变小**

### 考点：两类常用算法（SVM 与集成学习）

**要会**：各解决什么问题、在算法谱系里的位置。

- **支持向量机（SVM）**：**监督学习**算法；用映射函数把样本映射到**高维空间**，
  找一个**间隔最大**的线性超平面做分类。电力系统里用于**稳定评估**（输出 $+1$ 稳定／$-1$ 不稳定）。
- **集成学习**：按策略训练**多个「弱监督模型」**，**组合**成一个**强监督模型**，性能大幅提升。
  为什么会有弱学习器：理论上「各方面都好」的模型几乎不存在。

## 2026-10-20 ｜ 聚类方法与神经网络

### 考点：为什么先讲「不智能」的方法

**要会**：神经网络是**基于距离的聚类方法**的继承者——教师原话「神经网络算法它这个最基础的，它的基础是基于……聚类方法」。
先讲 K 平均这类**自动化但不智能**的方法，是为了看清它们错在哪，才说得出神经网络智能在哪、代价是什么。

[笔记原文 ↗](./课堂笔记/10-20-聚类与神经网络.md#为什么先讲这些-不智能-的方法)

### 考点：聚类的五大类方法（期末 5 分简答）

**要会背五类名字与各自一句话思路**：

| 类别 | 基本思路 |
| :--- | :--- |
| 划分 | 把样本切成 $k$ 堆，迭代优化到「堆内够紧、堆间够开」 |
| 层次 | 凝聚（自下而上合并）或分裂（自上而下拆分），形成一棵树 |
| 基于密度 | 邻域内点数够多就连成一簇，能找出任意形状、能识别噪声 |
| 基于网格 | 把对象空间量化为有限单元形成网格，一切操作在网格上做 |
| 基于模型 | 先假定一个模型，再找最贴合该模型的那一族数据 |

[笔记原文 ↗](./课堂笔记/10-20-聚类与神经网络.md#聚类方法的五类-期末-5-分简答题的骨架)

### 考点：K 平均法（k-means）

**要会步骤**：随机选 $k$ 个初始中心 → 按最近距离归类 → 用**每类均值**更新中心 → 迭代到不动。

**缺点（简答要写）**：对**初始值**敏感、对**离群点**敏感、$k$ 要**人为定**。隐含假定簇是凸的、大小相近的一团。

[笔记原文 ↗](./课堂笔记/10-20-聚类与神经网络.md#划分方法之一-k-平均法-k-means)

### 考点：K 中心点法（k-medoids）

**与 K 平均只差一处**：代表每类的不是**均值**，而是「**类内实际存在的一个点**」（medoid）。

**取舍**：对离群点更稳（均值会被离群点拽走，实际点不会），代价是**计算量更大**。

[笔记原文 ↗](./课堂笔记/10-20-聚类与神经网络.md#划分方法之二-k-中心点法-k-medoids)

### 考点：密度聚类的基本思想

**要会**：「**密度**」在 DBSCAN 里的定义是**某点给定半径的邻域内数据点的个数**（教师重复两遍，是要背的），
**不是**空间意义上的密度。邻域密度超过阈值就连成一簇；高密度区域被低密度区域分割。

**一维改进**：一维场合可以直接按「相邻点距离」判孤立点，比多维省算，这就是「基于密度的一维孤立点检测」。
