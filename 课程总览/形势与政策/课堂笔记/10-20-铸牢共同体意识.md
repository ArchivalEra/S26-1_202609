# 10-20-铸牢共同体意识

**这节课在干什么**：讲**专题四「铸牢中华民族共同体意识」**——四个考试专题里的最后一个。教师用约 **28 分钟**把下发材料的三段式串完——**战略意义 → 丰富内涵 → 实践路径七条**，
`30:44` 起转入**考试规则**说明（转写在此中断）。全程口头串讲配 PPT，**五处直接点明「会考」或点名「要掌握」**，另有**两条题型情报**（下表后两行），**三次抛出问题但一次也没点人回答**。
材料上的条目本身没有新东西；这节课真正多出来的是**教师的偏重、本校（浙江水利水电学院）的三个案例、若干具体例证，以及题型情报**。
正文里凡材料上没有的，标 **口头增量**。

**教师点名的「会考」处与题型情报**（原话摘录；前五行是「要掌握／会考」，后两行是题目形式）

| 教师原话 | 指向 |
| :--- | :--- |
| 「这个法律也是非常重要的，过会儿考试的话，可能也会考到」 | **民族团结进步促进法**（3 月 12 日通过、主席令第七十一号、7 月 1 日施行） |
| 「四个共同的主要内容**也需要各位同学掌握**」 | 四个共同（共同开拓疆域／书写历史／创造文化／培育精神） |
| 「五个认同……**需要各位同学着重的掌握**」 | 五个认同（核心任务） |
| 「这四对关系的一个主要内容，**也需要各位同学着重掌握**」 | 四对关系 |
| 「**基本上是考的内容**……你刚讲完就会考」 | 实践路径第 3 条「推动各民族共同走向社会主义现代化」 |
| 「我们也有一个题目专门是讲这个的」「**有一个题目四个空，但是只给你一个答案**」 | 实践路径第 7 条的四个「大力宣传」 |
| 「你们的题目可能是不太一样的」 | 考试按人抽题，题库随机 |

**行政与考核**（教师当堂口头说明，一切以正式文件为准）

- **开卷考试**，学习通作答——本节重申一次。
- **强制收卷风险**：教师说学习通使用中「老师会出现一些失误，出现一些情况」，后果是「**你的手机会被强制收卷**」；
  一旦被强制收卷，原话是「**你就考表示啊，当时你**」——句子在此截断，含义按上下文是一次考试就此作废，**转写不完整，不补全**。
  这是本份转写记录的**最后一句**，考试规则主体未录到。
- **材料不必打印**：专题四的材料没打印的「就不要出去了」（指出去印）；教师随后解释「你现在再出去回来来不及了」。
- **作业即复习**：前两讲（经济热点、人工智能）的作业已发，「你们翻看的过程中其实也有复习的一个功能」「所以不用担心」。
- 教师另有一句**劝留**：「我一会儿还要给大家讲考试规则啊……出去了听不到有可能就会违反我们的考试纪律」。

## 题号条目

本次课为思政课专题讲授，**教师未报任何题号**，故无题号条目。

## 没编号但讲了的知识点

### 一、战略意义：为什么现在讲

- **时代背景**（开场两个入口问题：时代背景是什么、重大意义是什么）：世界处于**百年未有之大变局**，我国处于**实现中华民族伟大复兴的关键时刻**；
  要推动中华民族成为「**认同度更高、凝聚力更大**」的命运共同体。
- **口头增量：民族地区的四重定位**——教师说这是「我国的**基本国情**，需要大家了解一下」：民族地区是
  ①**资源富集区**；②**水系源头和生态屏障区**；③**应对极端情况的战略纵深区**；④**关键能源通道和战略大后方**。
  他补一句地理判据：这些地区**多数处在与其他国家的边界处**，且民族区域建设「是在中国共产党的领导之下的」。
- **口头增量：立法信息**（教师当场提示会考）：今年 **3 月 12 日**全国人大会议**高票通过**《中华人民共和国**民族团结进步促进法**》，
  习近平签署**第七十一号主席令**公布，**7 月 1 日**起施行。教师紧接着说「过会儿考试的话，可能也会考到」——
  并列一句「**每个人同学的题目可能是不太一样的**」。
- 战略意义教师分**外部环境**与**内部民族领域**两条讲：

**外部**——「应对各种风险挑战的战略决策」，关系到与其他国家的关系；「**特别是一些西方国家，他们也是在逐渐地渗透**」。
PPT 展开为：美西方反华势力颠倒黑白、无中生有、炮制散布虚假信息、抹黑中国形象、**诋毁中国治疆政策**、干涉中国内政、蒙骗国际社会、干扰破坏新疆安全稳定。

- **口头增量：2009 年乌鲁木齐暴力犯罪事件**——教师对学生说「可能大家比较小，没有（印象）」；定性为**民族分裂分子与极端宗教思想**所致，
  并用一句概括其成因：「**境外有种子、境内有土壤、网上有市场**」。

**内部**——「强化建设民族复兴的重大战略举措」；一段时间受**历史虚无主义**影响，社会、学术界特别是互联网出现错误思想或模糊言论，
有的鼓吹「**民族自决**」、有的宣扬「**一族一国**」，教师定性：「本质上都是曲解和解构我们的中华民族共同体」。

- **口头增量：电视剧《天下大同》**——教师先说「为国献乐的天下大同」，随即改口「**江山大同**」（剧名转写两个说法，不择一断言）；
  **杨幂、刘学义**主演，讲少数民族在历史时期对中华民族的贡献，教师说 **明年** 播出。他要立的两条判据：
  **不能把汉族文化等同于中华文化**；**也不能只强调本民族的历史文化**——中华优秀传统文化是 56 个民族共同创造的。
- **口头增量：三项非遗举例**——**傈僳族刺绣、藏族藏戏、苗族刺绣**；收束为「文化上**兼收并蓄**、经济上**相互依存**、情感上**相互接近**」。
- **口头增量：六个短板**（教师说民族工作自身仍有短板，所以专门设「这一章一节」）：
  ①对**主线**要求的认识不到位；②**理论体系**还在发展、「还是不完备的」（对学生说「也需要我们各位同学去见证」）；
  ③「三个意义」的成果还不够多；④宣传教育「容而不深」；⑤**依法治理能力**需要提高；⑥**对外宣传教育**薄弱。
- **脉络**：新中国成立以来中央一直重视民族工作，「**从 1992 年到 2021 年**」都在加强各民族大团结；
  **2021 年提出「十二个必须」**，把铸牢明确为新时代党的民族工作**主线**，同时成为加强和改进民族工作的**根本指针**。

### 二、丰富内涵：四个方面

教师说内涵**共四个方面**：体现**十二个必须**、树立**四个共同**、根植**四个与共**、把握**四对关系**——
五观、三个意识、五个认同都挂在「四个与共」这一支下面讲。

**十二个必须**——教师只举三条大意，**未逐条读原文**：①从中华民族伟大复兴的战略高度把握新时代党的民族工作的**历史方位**；
②把推动各民族为全面建设社会主义现代化国家共同奋斗作为**重要任务**；
③第三条转写残缺（「以铸牢中华民族共同体意识为新时代党的民族工作……历史观」），**照原样记录，不补全**。
定性：习近平关于加强和改进民族工作重要思想**核心要义**；阐明**战略地位、总体要素、工作主线、重点任务、重要保障**；
深刻回答「**举什么旗、走什么路**」；是党的民族工作的**根本遵循**。

**四个共同**——教师给的定义是「我们 56 个**共同做的事情**」：共同**开拓**辽阔疆域、共同**书写**悠久历史、共同**创造**灿烂文化、共同**培育**伟大精神。

- **口头增量：960 多万平方公里**——「我们当前 960 多万平方公里的国土，就是各民族先民给我们留下的神圣故土」。
- **口头增量：文学例证**——唐诗、宋词、元曲、明清小说、中华古典诗词，都是各民族共同创作的文化瑰宝。
- **口头增量：三大文明气质**——**农耕文明的勤劳质朴**、**草原文明的热情奔放**、**海洋文明的海纳百川**，共同融入以爱国主义为核心的伟大民族精神。

**四个与共**——休戚与共、生死与共、荣辱与共、命运与共。教师当堂立判据：
**四个与共讲的是各民族之间的关系，四个共同讲的是各民族共同做的事情——「大家要注意区分」**。

- **口头增量：一张图的来历**——课上那张「中华民族一家亲，同心共筑中国梦」的图，是**庆祝新中国成立 70 周年大会群众游行中的民族团结方阵**。

**五观**（**思想基础**）：国家观、历史观、民族观、文化观、宗教观。
**三个意识**：国家意识、公民意识、法治意识（教师说「大家之前也都接触过」）。
**五个认同**（**核心任务**，教师说「需要着重掌握」）：对**中华民族**、对**中国共产党**、对**伟大祖国**、对**中华文化**、对**中国特色社会主义**的认同。

**四对关系**（教师说「主要内容也需要着重掌握」）：

| 关系 | 教师给的判据 |
| :--- | :--- |
| 共同性与差异性 | **共同性是主导、是方向、前提和根本**；差异性**不能削弱和危害**共同性；**增进共同性不意味着消灭差异性**，**尊重差异性也不是固化差异** |
| 中华民族共同体意识与各民族意识 | 本民族意识要**服从和服务于**中华民族共同体意识；在实现好**整体利益**过程中实现好各民族的**具体利益** |
| 中华文化与各民族文化 | **中华文化是主干，各民族文化是枝叶，根深干壮才能枝繁叶茂** |
| 物质与精神 | 落到**三个意义**上：赋予改革发展以彰显共同体意识、维护统一反对分裂、改善民生凝聚人心的意义 |

- **教师对第四对的取舍**——他把物质与精神这对关系直接压在「三个意义」上，**没有展开**材料里「经济发展不会自然而然带来民族团结与共同体意识」那一层。
- **口头增量：为什么不能套西方理论**——中华民族有自身独特的「历史解析」（疑为**历史逻辑**）；中华民族的历史**不能套用西方那一套理论**；
  共同体的发展壮大**从来不是靠把自己的价值观念与政治体制强加于人**，这是由**中华文明的突出特性**决定的；坚持**大一统**，
  始终相信**和而不同、多元一体**。

### 三、实践路径七条

教师先说「这一部分的内容**非常的多**」，但「给我们的信息也是**非常的明确**」。

1. **加强中华民族共同体理论体系建设**——理论研究越深入，对意识形态的支撑越坚强有力；立足中华民族悠久历史；
   加强习近平关于加强和改进民族工作的重要思想研究；加强**铸牢中华民族共同体意识研究基地**建设。
   **口头增量**：「比如刚才给大家展现的**我们浙江水利水电学院**的做法，那就是**研究基地之一**」。他还插一句玩笑——在座同学在学习过程中「也可以成为加强理论体系建设的一个问题」。
2. **全面推进中华民族共有精神家园建设**——「必须**久久为功**」；精神家园承载最深层的**价值追求与道德准则**、**共有的历史记忆**、**情感归属**和**美好期许**。
   四件事：树立正确的**中华民族历史观**、培育践行**社会主义核心价值观**、实施**中华优秀传统文化传承发展工程**、完善**宣传教育体系**。
3. **推动各民族共同走向社会主义现代化**（教师当场说「**基本上是考的内容**」）——赋予所有改革以**三个意义**；
   引导民族地区**科学定位**；继续实施**差别化支持政策**；积极发展各级各类教育；贯彻「**治国必治边**」的战略思想。
4. **促进各民族广泛交往交流交融**——始终把**中华民族利益放在首位**；**坚定不移推广国家通用语言文字**；
   加强**空间嵌入**（空间地理上的合理布局）、**文化嵌入**（文化元素与文化活动）、以及**经济社会心理**的嵌入；
   各民族相互照顾、关联和共享；社区、学校、工作环境都要体现共同发展；**守望相助、手足相亲**。
5. **提升民族事务治理体系和治理能力现代化**——坚持和完善**民族区域自治制度**；及时健全完善**民族政策与法律法规体系**；
   把民族事务纳入**共建共治共享**的社会治理格局；教师强调**树立对法律的敬仰**（疑为**敬畏**，见「转写与术语」）——「只有树立对法律的敬仰，各民族群众才能自觉按照法律办事，
   民族团结才有保障，民族关系才能牢靠」。
   **口头增量：行走的国徽**——少数民族地区交通非常不便（高山峡谷），村民有法律事务要开庭，以前一定要跑到法庭；
   **云南的法官经常背着国徽到村民家中或者田地间开庭**；教师现场点评：「怎么样是为人民服务？**那这就是为人民服务**」。
6. **防范民族领域重大风险隐患**——贯彻**总体国家安全观**；继承和发扬**爱国主义传统**；推进防范化解体制机制建设；
   推进反恐维稳**法治化、常态化**；牢牢掌握**网络意识形态阵地**的主导权；提高防范化解能力，「**发现早，处置才会小**」；
   守住**不发生区域性系统性风险的底线**。
7. **大力宣介中华民族共同体意识**（教师说「有一个题目专门是讲这个的」）——四个「**大力宣传**」：
   宣传**中华民族的历史**、宣传**中华民族共同体理论**、宣传**新时代党的民族工作取得的历史性成就**、
   宣传**中华民族同世界各国人民携手构建人类命运共同体的美好愿景**。
   **题型情报**：「有一个题目**四个空**，但是**只给你一个答案**，就是这个题目」。传播方式：丰富传播内容、拓宽传播渠道、讲好故事；
   讲好「**党的领导和社会主义制度是我国各民族共同发展进步的可靠保障**」；讲清楚中华民族是**具有强大认同度和凝聚力的命运共同体**；
   讲清楚**中国特色解决民族问题正确道路**的明显优势；推动中外学术界、民间团体交流互动。

结语：「中华民族是**一家亲**的，同心共筑中国梦，推动中华民族**复兴号**的巨人扬帆起航」。

### 本校案例（口头增量的集中处）

教师三次把浙江水利水电学院的做法插进理论，材料上没有：

| 插入位置 | 本校做法 |
| :--- | :--- |
| 十二个必须之后 | 把铸牢**融入办学治校全过程**；为落实浙江省的工作部署，与**南浔区**合力打造「**之江同心**」「**水晶晶**」「**石榴红**」「**浔水家园**」（转写为四项并列，实际如何断词不明）；推动省级「之江同心·**石榴红**」民族团结工作品牌在南浔**落地生根** |
| 实践路径第 1 条 | 本校做法即**铸牢中华民族共同体意识研究基地之一** |
| 实践路径第 2 条 | **阿木工作室**：党建＋民族团结进步示范；成立**省内首个民族团结进步党建联盟**、石榴籽党支部；构建少数民族学生思想教育示范体系；开办大讲堂；邀请专家学者来校指导**家国情怀教育** |

### 教师的三次现场提问

三次都抛了问题，**一次也没点人回答**：

1. 讲完战略意义：「**结合我们当前的国际形势，请各位同学思考一下，我们为什么要铸牢中华民族共同体意识**」——无下文，直接进第二部分。
2. 讲完四对关系：「**如何理解共同性和差异性**」——教师当场说明「**由于时间关系，老师就不找同学一起来回答了**」「大家材料上也都有的」。
3. 讲完全篇：「**你作为一个新时代的大学生，应该如何积极地投身于中华民族共同体建设**」——「**这个题目给到大家**」。

与 10-12 课对照：那次是学习通抢答、多人作答、答了加分；这次**全程无学生发言记录**，教师明确以「时间关系」跳过。
