## 一、页内从零推导：串联谐振（电压谐振）

考察 $R$、$L$、$C$ 串联接正弦电源 $\dot U$，总复阻抗为（依赖 [04 篇](./04-微积分变乘除与复阻抗.md)）：

$$Z(j\omega) = R + j\left(\omega L - \frac{1}{\omega C}\right) = R + j(X_L - X_C)$$

**串联谐振定义**：调节电源角频率 $\omega$ 或 $L,C$ 参数，使端口电压 $\dot U$ 与电流 $\dot I$ 同相位（等效阻抗虚部归零，功率因数 $\cos\varphi=1$）：

1. **谐振频率 $\omega_0$ 与 $f_0$**：令总电抗 $X_L - X_C = 0 \implies \omega_0 L = \dfrac{1}{\omega_0 C}$，解得：
   $$\omega_0 = \frac{1}{\sqrt{LC}},\qquad f_0 = \frac{\omega_0}{2\pi} = \frac{1}{2\pi\sqrt{LC}}$$
   - 当 $\omega > \omega_0$：$X_L=\omega L$ 增大而 $X_C=1/(\omega C)$ 减小 $\implies X>0$ 呈**感性**（**选 14**）；
   - 当 $\omega < \omega_0$：$X_C > X_L \implies X<0$ 呈**容性**。
2. **电流最大、全部电压落到电阻 $R$**：谐振时 $|Z|_{\min}=R$，电流达最大值 $I_0=\dfrac{U}{R}$，此时有功功率 $P=I_0^2 R=\dfrac{U^2}{R}$ 亦达最大值（**选 25、填 9** 的解题切口）。
3. **品质因数 $Q$ 与过电压（电压谐振）**：串联谐振时电感电压 $\dot U_L=jX_{L0}\dot I_0$ 与电容电压 $\dot U_C=-jX_{C0}\dot I_0$ **大小相等、方向相反**（$\dot U_L+\dot U_C=0$），定义**品质因数** $Q=\dfrac{\omega_0 L}{R}=\dfrac{1}{\omega_0 C R}=\dfrac{1}{R}\sqrt{\dfrac{L}{C}}$，则：
   $$U_L = U_C = Q U$$
   当感抗/容抗远大于电阻（$Q\gg 1$）时，$L$、$C$ 上会产生远高于电源电压的过电压，故串联谐振又称**电压谐振**（**选 23** 为仅电抗串联的部分抵消预演）。

## 二、并联谐振的两套口径：电流直角三角形 vs 导纳虚部抵消

与串联谐振「电压叠加抵消」对偶，并联电路端口电压 $\dot U$ 固定，谐振目标仍是使**端口总电流 $\dot I$ 与 $\dot U$ 同相（$\cos\varphi=1$，电源仅供应有功）**。本册题目同时涉及以下两套等价但侧重点不同的口径：

1. **口径 A：导纳实虚分离 $B=0$ 定 $\cos\varphi=1$（算参数最稳，[填 11 / 计 7](../../电路原理/作业/习题册第五章.md#填-11-图-5-17-与-计-7-图-5-28)）**：
   先求各并联支路导纳并相加得总导纳 $Y=G+jB$。谐振（$\cos\varphi=1$）等价于**总电纳虚部 $B=0$**：
   - 有功功率全部由实部电导给出：$P=U^2 G$（或用同相总电流 $I=P/U$）；
   - 无功部分电纳相互抵消：$B_1+B_2=0 \implies$ 直接解出缺失的电抗。
2. **口径 B：电流直角三角形几何合成（秒杀选择题，[选 22](../../电路原理/作业/习题册第五章.md#选-22-图-5-8)）**：
   对「纯电感支路 $L$（电流 $I_1$ 滞后 $\dot U$ $90^\circ$）并联 $R$ 串 $C$ 支路（电流 $I_2$ 超前 $\dot U$ 某锐角）」：当总电流 $\dot I=\dot I_1+\dot I_2$ 恰好落在水平轴（与 $\dot U$ 同相）时，**$\dot I_1$ 竖直向下、$\dot I$ 水平向右、$\dot I_2$ 作斜边**恰好围成一个直角三角形，直接读出：
   $$I = \sqrt{I_2^2 - I_1^2}$$
   （若为理想 $L\parallel C$ 无损并联，则 $I_L$ 与 $I_C$ 完全反向抵消、端口总电流为零，分流远大于干路电流，故并联谐振又称**电流谐振**。）

## 三、从第 4 章直流最大功率推交流共轭匹配 $Z_L = Z_{th}^*$

将任意含源线性交流网络对负载端口作戴维南等效（见 [04 篇](./04-微积分变乘除与复阻抗.md)），得到 $\dot U_{oc}$ 与等效内阻抗 $Z_{th}=R_{th}+jX_{th}$（假定 $R_{th}>0$），外接可变负载 $Z_L=R_L+jX_L$，则负载电流有效值与有功功率为：

$$I = \frac{U_{oc}}{\sqrt{(R_{th}+R_L)^2 + (X_{th}+X_L)^2}},\qquad P_L = I^2 R_L = \frac{U_{oc}^2\,R_L}{(R_{th}+R_L)^2 + (X_{th}+X_L)^2}$$

从直流 [10-28 最大功率传输](../../电路原理/课堂笔记/10-28-戴维南与诺顿.md#最大功率传输-4-4)（$R_L=R_{eq}$）起步，分两步用高数求极大值：

1. **第一步先令电抗彻底抵消**：对任意固定 $R_L>0$，分母中 $(X_{th}+X_L)^2\ge 0$。要使分式 $P_L$ 最大，必须令非负平方项取最小值 $0$，即：
   $$X_L = -X_{th}$$
   电抗抵消后，电路退化为只剩纯电阻分压：$P_L(R_L)=\dfrac{U_{oc}^2 R_L}{(R_{th}+R_L)^2}$。
2. **第二步对 $R_L$ 求导（与 Ch.4 完全同形）**：
   $$\frac{\mathrm d P_L}{\mathrm d R_L} = U_{oc}^2\frac{(R_{th}+R_L)^2 - 2R_L(R_{th}+R_L)}{(R_{th}+R_L)^4} = U_{oc}^2\frac{R_{th}-R_L}{(R_{th}+R_L)^3} = 0 \implies R_L = R_{th}$$
   二阶导数在该点为负，确为全局极大值。

合并两步，得交流最大功率传输**共轭匹配条件**（与直流 $R_L=R_{th}$ 仅差电抗取负共轭）：

$$Z_L = R_{th} - jX_{th} = Z_{th}^*,\qquad P_{\max} = \frac{U_{oc}^2}{4 R_{th}}$$

## 四、真题演算（对齐《习题册第五章》）

1. **串联谐振判别、部分抵消与参数反求（选 14、选 23、选 25、填 9）**：
   - **选 25**（[习题册第五章#选-25](../../电路原理/作业/习题册第五章.md#选-25)）：$RLC$ 串联谐振时阻抗模最小 $|Z|_{\min}=R$，**电流最大**。
   - **选 14**（[习题册第五章#选-14](../../电路原理/作业/习题册第五章.md#选-14)）：$\cos\varphi=1$ 处于谐振态（$X_L=X_C$），电源频率升高后 $X_L$ 增、$X_C$ 减，$X_L>X_C$ $\implies$ 呈**感性**。
   - **选 23**（[习题册第五章#选-23-图-5-9](../../电路原理/作业/习题册第五章.md#选-23-图-5-9)）：$X_L=3\ \Omega$ 串 $X_C=1\ \Omega$ 接 $U=10\ \text{V}$，先相减抵消得 $|Z|=|j3-j1|=2\ \Omega \implies I=10/2=5\ \text{A}$，$U_L=5\times 3=\mathbf{15\ \text{V}}>U$。
   - **填 9**（[习题册第五章#填-9](../../电路原理/作业/习题册第五章.md#填-9)）：$u=10\sqrt 2\sin(250t+15^\circ)\ \text{V}$，$C=8\ \mu\text{F}$ 时有功达最大 $100\ \text{W}$。$P$ 最大即发生串联谐振（Octave 复核 `L=2, R=1`）：
     $$L=\frac{1}{\omega_0^2 C}=\frac{1}{250^2\times 8\times 10^{-6}}=\mathbf{2\ \text{H}},\qquad R=\frac{U^2}{P_{\max}}=\frac{10^2}{100}=\mathbf{1\ \Omega}$$
2. **并联谐振两套口径（选 22、填 11 / 计 7）**：
   - **选 22**（[习题册第五章#选-22-图-5-8](../../电路原理/作业/习题册第五章.md#选-22-图-5-8)）：并联谐振时 $L$ 支路 $I_1=9\ \text{A}$、$R$ 串 $C$ 支路 $I_2=15\ \text{A}$，由电流直角三角形（口径 B）：$I=\sqrt{I_2^2-I_1^2}=\sqrt{15^2-9^2}=\mathbf{12\ \text{A}}$。
   - **填 11 / 计 7**（[习题册第五章#填-11-图-5-17-与-计-7-图-5-28](../../电路原理/作业/习题册第五章.md#填-11-图-5-17-与-计-7-图-5-28)，原书图 5.17 与 5.28 共用同图同参）：$\dot U_S=100\angle 0^\circ\ \text{V}$、$P=300\ \text{W}$、$\cos\varphi=1$，电路为 $(12+jX_L)\ \parallel (-jX_C)$。按口径 A 写总导纳并利用 $P=U_S^2 G$（实虚方程天然解耦，Octave 复核 `XL=16, XC=25`）：
     $$Y = \frac{12}{144+X_L^2} + j\left(\frac{1}{X_C}-\frac{X_L}{144+X_L^2}\right)$$
     由 $G=P/U_S^2=300/10000=0.03\ \mathrm{S}$ 得 $\dfrac{12}{144+X_L^2}=0.03 \implies X_L^2=256\implies X_L=\mathbf{16\ \Omega}$；再令 $B=0$ 得 $\dfrac{1}{X_C}=\dfrac{16}{400}=0.04 \implies X_C=\mathbf{25\ \Omega}$。
3. **交流共轭匹配（选 8、计 6、计 8）**：
   - **选 8**（[习题册第五章#选-8-图-5-3](../../电路原理/作业/习题册第五章.md#选-8-图-5-3)）：原书重印第 4 章图 4.2（$5\ \text{V}$ 串 $4\ \Omega$、$2\ \text{A}$ 串 $2\ \Omega$ 并负载 $R$）。独立源置零时 $2\ \text{A}$ 支路开路整支消失，得 $R_0=\mathbf{4\ \Omega}$。
   - **计 6**（[习题册第五章#计-6-图-5-27](../../电路原理/作业/习题册第五章.md#计-6-图-5-27)）：$2\ \text{A}\parallel 100\ \Omega$ 再串 $-j200\ \Omega$。开路时 $-j200\ \Omega$ 无电流，$\dot U_{oc}=2\times 100=200\angle 0^\circ\ \text{V}$；置零后 $Z_{th}=100-j200\ \Omega$。共轭匹配得 $Z=Z_{th}^*=\mathbf{100+j200\ \Omega}$，$P_{\max}=\dfrac{200^2}{4\times 100}=\mathbf{100\ \text{W}}$。
   - **计 8**（[习题册第五章#计-8-图-5-29](../../电路原理/作业/习题册第五章.md#计-8-图-5-29)）：按整理者核实拓扑（$4\ \text{A}\parallel 2\ \Omega$ 经顶 $2\ \Omega$ 再与 $j4\ \Omega\parallel Z_L$），独立源转戴维南或写节点方程得 $\dot U_{oc}=4(1+j)\ \text{V}$、$Z_{th}=(2+2)\parallel j4=2+j2\ \Omega$。共轭匹配得 $Z_L=Z_{th}^*=\mathbf{2-j2\ \Omega}$，$P_{\max}=\dfrac{|4+j4|^2}{4\times 2}=\frac{32}{8}=\mathbf{4\ \text{W}}$（注：作业页另留存盲测拓扑的并列口径 $Z_{th}=3.6+j0.8\ \Omega$、$P_{\max}=2.22\ \text{W}$）。
