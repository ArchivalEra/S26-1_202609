## 一、定转子结构、同步转速 $n_1$、转差率与电角度 $\alpha_e=p\alpha_m$

1. **三部分与两种电机**：旋转电机由**定子 + 转子 + 气隙**构成；磁场沿气隙分布，一对 N–S 磁极完成一个电周期 $360^\circ$。当转子或旋转磁场有 **$p$ 对极**（磁极数 $2p$）时，机械转 1 圈等于 $p$ 个电周期，于是：
   - **电角度与机械角度换算铁律**：$\alpha_{\text{电}} = p\cdot\alpha_{\text{机械}}$（凡与感应电动势相位差有关的角，一律看电角度！）；
   - **同步转速与交流频率**：$n_1 = \dfrac{60 f}{p}$（$f=50\ \text{Hz}$ 时 $p=1\to 3000\ \text{r/min}$、$p=2\to 1500\ \text{r/min}$）；
   - **转差率 $s$ 口径区分**：$s = \dfrac{n_1-n}{n_1}$；`11-12` 课堂笔记同时记有**正常运行一般范围 $0.01\sim 0.06$** 与**轻载/近空载点名的 $0.005$**（需按运行工况区分，不混为一谈）。
2. **交流绕组四个几何公式（[3.1.1 第 9 题](../../电机学/作业/3.1.1旋转电机及交流绕组.md#第-9-题) 直接秒杀）**：
   设总槽数 $Z$、极对数 $p$、相数 $m$（$60^\circ$ 相带下每极每相依次占 $q$ 槽，按 $A\text{-}C'\text{-}B\text{-}A'\text{-}C\text{-}B'$ 轮排）：
   $$\tau = \frac{Z}{2p}\ (\text{极距槽数}),\qquad q = \frac{Z}{2pm}\ (\text{每极每相槽数}),\qquad \alpha = \frac{360^\circ p}{Z}\ (\text{槽距角，电角度}),\qquad q\alpha = \frac{180^\circ}{m} = 60^\circ$$
   （例：$Z=36,2p=4,m=3\implies \tau=9,\ q=3,\ \alpha=20^\circ$；$Z=24,2p=4,m=3\implies \tau=6,\ q=2,\ \alpha=30^\circ$。）

## 二、四级相量相加两次打折 $\to E_\Phi = 4.44 f N k_w \Phi$

旋转电机与集中整距变压器（$k_w=1$）本质共享同一个电磁感应定律，只是多出来的「**分布摊槽 + 短距省铜消谐波**」让各线圈感应电动势相位错开，必须按 `05` 篇作**相量几何相加**（弦长永远 $\le$ 弧长/算术和，见 [11-19 五·绕组因数](../../电机学/课堂笔记/11-19-交流绕组电动势与谐波.md#五-绕组因数与相电动势-约-56-06-1-03-46)）：

1. **第 1 级（一根有效边导体）**：由 $e=Blv$、$v=2\tau f$ 与半波正弦平均磁密 $\Phi = \frac{2}{\pi}B_m\tau l$ 得单根导体电动势有效值 $E_1 = \dfrac{\pi}{\sqrt{2}}f\Phi = \mathbf{2.22 f\Phi}$；
2. **第 2 级（一个 $N_c$ 匝线圈：节距因数 $k_p$）**：整距（$y=\tau$）两边恰好差 $180^\circ$ 直接算术翻倍得 $4.44f N_c\Phi$；若采用**短距**（跨距少于 $\tau$ 个槽，差短距角 $\beta = \frac{\tau-y}{\tau}\cdot 180^\circ$），两正交等腰向量合成的弦比算术和打第一道折：
   $$k_p = \cos\frac{\beta}{2} \le 1$$
3. **第 3 级（一个线圈组 $q$ 个槽：分布因数 $k_d$）**：相邻槽相量依次偏转槽距角 $\alpha$ 排在圆弧上，$q$ 段总弦长除以 $q$ 段算术和，由上下两个直角三角形弦弧比打第二道折：
   $$k_d = \frac{\sin\dfrac{q\alpha}{2}}{q\sin\dfrac{\alpha}{2}} \le 1$$
4. **第 4 级（整相绕组，每相串联匝数 $N = \dfrac{Fpq}{a}N_c$，$F=1$ 单层 / $2$ 双层，$a$ 为并联支路数）**：两次折扣相乘定义**绕组因数** $k_w = k_p k_d \le 1$，合成相电动势：
   $$E_\Phi = \mathbf{4.44\,f N k_w \Phi}$$
   - **24 槽 4 极算例（$y=\frac{5}{6}\tau\implies \beta=30^\circ,\ q=2,\ \alpha=30^\circ$，Octave 复核）**：
     $k_{p1}=\cos 15^\circ=\mathbf{0.9659}$，$k_{d1}=\dfrac{\sin 30^\circ}{2\sin 15^\circ}=\mathbf{0.9659}$，$k_{w1}=0.9659^2=\mathbf{0.9330}$；若取 $f=50\ \text{Hz},\ N=100,\ \Phi_1=0.01\ \text{Wb}$，工程式得 $E_\Phi=4.44\times 50\times 100\times 0.9330\times 0.01\approx\mathbf{207.13\ \text{V}}$（如取 $k_w=0.945$ 则为 `11-19` 算例 $209.79\ \text{V}$）。

## 三、谐波电动势（$v$ 次角乘 $v$）与削弱谐波 5 招

气隙磁场半波对称只含奇次空间谐波（$v=1,3,5,7,\dots$）；$v$ 次谐波极距缩为 $\tau/v$、极对数增为 $vp$、频率升为 $vf$，因此所有电角度参数一律乘 $v$：**$k_{pv}=\cos\dfrac{v\beta}{2}$**、**$k_{dv}=\dfrac{\sin(vq\alpha/2)}{q\sin(v\alpha/2)}$**。工程常用**五招消谐波**（[11-19 七·削弱手段](../../电机学/课堂笔记/11-19-交流绕组电动势与谐波.md#七-削弱谐波电动势的五种手段-约-1-12-42-1-24-38)）：

1. **改善气隙磁极形状**（治本）：凸极机极靴占 $70\%\sim 75\%$ 且气隙边缘略大（$1.5\sim 2.0$ 倍），隐极机小齿占 $70\%\sim 75\%$；
2. **Y 接（或 D 接）天然消线电动势 3 的倍数次谐波**：3 倍次三相电动势同相（与 `16` 篇同源），Y 接**线电动势**两相相减完全抵消（**⚠ 注意陷阱：星接相电动势里三次谐波仍在！**）；
3. **短距绕组重点杀 5、7 次**（核心考点，Octave 复核）：令 $\cos(v\beta/2)=0\implies y=(1-1/v)\tau$。选 $y=\frac{4}{5}\tau$ 彻底消 5 次（$k_{p5}=0$），选 $y=\frac{6}{7}\tau$ 彻底消 7 次（$k_{p7}=0$）；工程折中**常用 $y=\frac{5}{6}\tau$（$\beta=30^\circ$）**，基波仅折 $0.9659$，同时把 5 次与 7 次均猛压至 $\pm 0.2588$（$k_{p5}=\cos 75^\circ=+0.2588$，$k_{p7}=\cos 105^\circ=-0.2588$，注意不能丢失反相负号！）；
4. **分布绕组 $q=2\sim 6$**（在 $60^\circ$ 相带约束 $\alpha=60^\circ/q$ 下，$q>6$ 后 $k_{d1}$ 饱和在 $0.956$ 附近而成本大涨，故一般取至 $q\le 6$；$\alpha=30^\circ,q=2$ 时 $k_{d5}=+0.2588, k_{d7}=-0.2588$）；
5. **斜槽 / 磁性槽楔**：沿轴向扭斜一个齿距抹平齿谐波。
