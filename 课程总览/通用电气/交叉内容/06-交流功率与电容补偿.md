## 一、由瞬时功率积分导出有功 $P$ 与无功 $Q$

在关联参考方向下，设端口电压、电流为 $u(t)=\sqrt{2}\,U\sin(\omega t+\varphi)$、$i(t)=\sqrt{2}\,I\sin\omega t$（其中相位差 $\varphi=\varphi_u-\varphi_i$）。利用高数三角积化和差公式 $2\sin\alpha\sin\beta=\cos(\alpha-\beta)-\cos(\alpha+\beta)$ 展开瞬时功率（对应 [11-18 推导](../../电路原理/课堂笔记/11-18-交流功率与功率因数.md#从瞬时功率到有功功率-一次积化和差加一次积分)）：

$$p(t)=u(t)i(t)=2UI\sin(\omega t+\varphi)\sin\omega t = \underbrace{UI\cos\varphi}_{\text{恒定有功项}} - \underbrace{UI\cos(2\omega t+\varphi)}_{\text{2}\omega\text{ 倍频脉动项}}$$

1. **有功功率 $P$（平均功率，单位 $\mathrm{W}$）**：把 $p(t)$ 在一个周期 $T=2\pi/\omega$ 上作高数定积分求平均，$\cos(2\omega t+\varphi)$ 整周期积分为零，仅留常项：
   $$P=\frac{1}{T}\int_0^T p(t)\,\mathrm dt = UI\cos\varphi$$
   关联方向下 $P>0$ 表示消耗/吸收有功。结合阻抗三角形 $R=|Z|\cos\varphi$、导纳极坐标反写 $Y=1/Z=|Y|\angle(-\varphi)=|Y|\cos\varphi - j|Y|\sin\varphi$（即 $G=|Y|\cos\varphi$、$B=-|Y|\sin\varphi$），配合 $U=I|Z|$ 与 $I=U|Y|$，立刻得到串联与并联最速计算式：
   $$P = UI\cos\varphi = I^2 R = U^2 G$$
   （**选 27、28、填 1** 均直接套此式，注意并联用 $U^2 G$，串联用 $I^2 R$，绝不把 $G$ 误写为 $1/R$。）
2. **无功功率 $Q$（单位 $\mathrm{var}$）**：把上面 $p(t)$ 用和角公式拆出含 $\sin(2\omega t)$ 的无功往返分量，并代入 $X=|Z|\sin\varphi$ 与 $B=-|Y|\sin\varphi$，得：
   $$Q = UI\sin\varphi = I^2 X = -U^2 B$$
   - **符号规定（对应 $\varphi=\varphi_u-\varphi_i$）**：**感性**（电压超前电流，$\varphi>0, X>0$）取 **$Q>0$**（吸收感性无功）；**容性**（电流超前电压，$\varphi<0, X<0$）取 **$Q<0$**（即吸收负无功＝发出感性无功，见 **选 7**）。
   - 纯电感 $p_L=UI\sin 2\omega t$ 与纯电容 $p_C=-UI\sin 2\omega t$ 相位差 $180^\circ$，二者在磁场和电场间互倒能量，在总功率平衡中可互相抵消（$p_L+p_C=0$）。

## 二、页内自补：视在功率 $S$、功率三角形与共轭复功率 $\bar S=\dot U\dot I^*$

> **闭环说明**：[11-18 笔记](../../电路原理/课堂笔记/11-18-交流功率与功率因数.md#本篇没讲的) 明确记录整节课未命名视在功率 $S$、未画功率三角形、也未引入复功率 $\bar S$；以下由正弦定义与欧拉公式就地补全。

1. **视在功率 $S$（单位 $\mathrm{VA}$）与功率三角形**：电源额定输出受限于最高允许电压 $U_N$ 与最大允许电流 $I_N$，二者乘积衡量设备「最大供电容量」，称为**视在功率** $S=UI$。由 $P=S\cos\varphi$、$Q=S\sin\varphi$ 与 $\cos^2\varphi+\sin^2\varphi=1$ 立即合出**功率直角三角形**：
   $$S = UI = \sqrt{P^2+Q^2},\qquad \cos\varphi = \frac{P}{S},\qquad \tan\varphi = \frac{Q}{P}$$
   （它与电压三角形 $U=\sqrt{U_R^2+U_X^2}$、阻抗三角形 $|Z|=\sqrt{R^2+X^2}$ 三者严格相似，斜边与直角边夹角皆为阻抗角 $\varphi$。）
2. **为什么共轭复功率必须定义成 $\bar S=\dot U\dot I^*$（而不能写 $\dot U\dot I$）**：
   设 $\dot U=U\angle\psi_u$、$\dot I=I\angle\psi_i$，有效相位差为 $\varphi=\psi_u-\psi_i$。
   - 若错误地直接相乘：$\dot U\dot I = UI\angle(\psi_u+\psi_i)$，辐角变成**相加** $\psi_u+\psi_i$，随参考计时起点 $t=0$ 的选取改变而乱变，实部和虚部**不是** $P$ 与 $Q$；
   - 将电流相量取**复共轭** $\dot I^* = I\angle(-\psi_i)$ 后再相乘：
     $$\bar S = \dot U\dot I^* = (U e^{j\psi_u})(I e^{-j\psi_i}) = UI e^{j(\psi_u-\psi_i)} = UI(\cos\varphi+j\sin\varphi) = P + jQ$$
   **实部恰好是有功功率 $P$，虚部恰好是无功功率 $Q$，模长 $|\bar S|=UI=S$**！且对多条并联或复杂支路网络，复功率守恒 $\sum \bar S_{\text{发}}=\sum \bar S_{\text{耗}}$ 一步同时给出总 $P$ 与总 $Q$（如 **计 9**）。

## 三、页内自补：并联电容无功补偿公式（纠偏 `11-18` 口播矛盾）

[11-18 功率因数经济意义](../../电路原理/课堂笔记/11-18-交流功率与功率因数.md#功率因数低为什么浪费电源容量-经济意义) 指出：相同负载有功功率 $P$ 下，$\cos\varphi$ 越低，所需总电流 $I=\dfrac{P}{U\cos\varphi}$ 越大，不仅白白挤占电源/变压器的视在容量 $S=UI$，还会增大输电线路损耗 $\Delta P=I^2 R_{\text{线}}$；课堂还出现过一次并联/串联口误矛盾（见 `11-18` L261）。工程提高感性负载功率因数的**铁律**是（对应 **选 16**）：

1. **必须采用「在负载两端并联电容」（禁止串联）**：
   - **负载端电压 $U$ 维持额定不变**，负载原有有功功率 $P$、原有感性电流 $\dot I_L$ 与原有无功 $Q_{\text{前}}=P\tan\varphi_1>0$ 均**完全不受影响**（串联电容会分压降低负载工作电压、改变负载状态）；
2. **页内推导补偿电容值 $C$**：
   并联电容 $C$ 接在电压 $U$ 两端，其复阻抗 $Z_C=-j/(\omega C)$，电纳 $B_C=+\omega C$，只吸收负的无功功率（等效向感性负载就地供给感性无功）：
   $$Q_C = -\frac{U^2}{X_C} = -\omega C U^2 < 0$$
   补偿后总有功仍为 $P$，总无功由 $Q_{\text{前}}=P\tan\varphi_1$ 降为目标值 $Q_{\text{后}}=P\tan\varphi_2$：
   $$Q_{\text{后}} = Q_{\text{前}} + Q_C \implies P\tan\varphi_2 = P\tan\varphi_1 - \omega C U^2$$
   解得提高功率因数从 $\cos\varphi_1$ 到 $\cos\varphi_2$ 所需的**并联补偿电容公式**：
   $$C = \frac{P(\tan\varphi_1 - \tan\varphi_2)}{\omega U^2} = \frac{P}{\omega U^2}\left(\frac{\sqrt{1-\cos^2\varphi_1}}{\cos\varphi_1}-\frac{\sqrt{1-\cos^2\varphi_2}}{\cos\varphi_2}\right)$$
   - **不过补原则**：一般补偿至 $\cos\varphi_2\approx 0.9\sim 0.95$ 即可，不能补过头变成总容性（否则增大电网谐振与过电压风险）。
   - **定量算例（衔接 计 2，Octave 验算）**：某感性负载 $U=220\ \text{V}$、$\omega=500\ \text{rad/s}$、$P=96.8\ \text{W}$，原 $\cos\varphi_1=0.8$（$Q_1=72.6\ \text{var}$），欲提高至 $\cos\varphi_2=0.95$（$\tan\varphi_2\approx 0.3287$），需并联电容 $C=\frac{96.8\times(0.75-0.3287)}{500\times 220^2}\approx \mathbf{1.685\ \mu\text{F}}$，总电流由 $0.55\ \text{A}$ 降至 $0.463\ \text{A}$，负载本身状态丝毫未变。

## 四、真题演算（对齐《习题册第五章》全部 16 道功率题）

4. **综合大题（计 2、计 5、计 9）**：

     $$P=I_{LR}^2 R=\mathbf{96.8\ \text{W}},\qquad Q=X_L I_{LR}^2 - X_C I_C^2=193.6-121=\mathbf{72.6\ \text{var}},\qquad S=\sqrt{P^2+Q^2}=\mathbf{121\ \text{VA}}$$

   - **计 9**（[习题册第五章#计-9-图-5-30](../../电路原理/作业/习题册第五章.md#计-9-图-5-30)）：$\dot U=20\angle 0^\circ\ \text{V}$ 接 $6+j8\ \Omega$ 并 $16-j12\ \Omega$。总导纳 $Y=\frac{1}{6+j8}+\frac{1}{16-j12}=(0.06-j0.08)+(0.04+j0.03)=0.1-j0.05\ \mathrm{S}$；直接用共轭复功率一步求出（Octave 复核 `P=40, Q=20, S=44.7214`）：
