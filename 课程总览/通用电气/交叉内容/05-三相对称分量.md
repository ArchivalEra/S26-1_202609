# 05 · 三相对称分量

<figure class="fig"><img src="figures/fig-ge-05.svg" alt="三相对称分量示意图：不对称三相分解为正序、负序与零序三组对称分量" loading="lazy"><figcaption>不对称三相分解：任意不对称三相量拆成正序、负序与零序三组规则分量之和</figcaption></figure>

## 一、为什么要把不对称量拆开

在三相电路中，分析完全对称的系统非常简单：三相电压、电流大小相等，各相之间规律互差 120°，只要算出其中一相，其余两相直接推知。

但在实际电网和电机运行中，经常遇到不对称故障（例如单相接地短路）或三相不对称负载。三相不对称时，各相电压、电流大小各异且夹角杂乱，无法直接套用对称三相的简便算法。

对称分量法的核心思想是把复杂问题化简：**任一组不对称的三相量，可以拆成三组对称分量之和（正序、负序、零序）**。

为什么值得拆？因为**对称的分量各自可以用单相的办法算，算完再叠回去**。电机学用它分析不对称故障与不对称负载。

## 二、旋转算子 $a$：乘一次转 120 度

为了用数学式子简洁地表示平面上互差 120° 的向量，引入一个旋转工具 $a$：

$$a = e^{j120^\circ}$$

$e^{j120^\circ}$ 在复平面上的含义是一句直白的大白话：**把任意向量逆时针旋转 120 度**，而向量的长度保持不变。

- 乘一次 $a$：逆时针转 120°
- 乘两次 $a^2 = e^{j240^\circ}$：逆时针转 240°（相当于顺时针转 120°）
- 乘三次 $a^3 = e^{j360^\circ} = 1$：转满一整圈 360°，回到原位

把三个均匀间隔 120°、长度都是 1 的单位向量加在一起，三个方向的力互相平衡抵消：

$$1 + a + a^2 = 0$$

## 三、三序定义与合成式

任一组三相量（以相量 $\dot A$、$\dot B$、$\dot C$ 为例），拆开后的三组对称分量定义如下：

1. **正序**（下标 1）：大小相等、互差 120°、相序为 A→B→C（顺时针走，A 先到、B 滞后 120°、C 滞后 240°）。各相与 A 相正序分量 $\dot A_1$ 的关系为：
   $$\dot B_1 = a^2\dot A_1,\quad \dot C_1 = a\dot A_1$$
2. **负序**（下标 2）：大小相等但反序（B 超前 A，相序反过来，即 A→C→B）。各相与 A 相负序分量 $\dot A_2$ 的关系为：
   $$\dot B_2 = a\dot A_2,\quad \dot C_2 = a^2\dot A_2$$
3. **零序**（下标 0）：三者同相位、大小相等，三个相量步调完全一致、指向同一个方向：
   $$\dot A_0 = \dot B_0 = \dot C_0$$

将三序分量各自相加，得到原始三相量的合成式：

$$\dot A = \dot A_1 + \dot A_2 + \dot A_0$$

$$\dot B = a^2\dot A_1 + a\dot A_2 + \dot A_0$$

$$\dot C = a\dot A_1 + a^2\dot A_2 + \dot A_0$$

直觉理解：每一相真实的物理量，都由「顺着转的平衡轮」（正序）、「倒着转的平衡轮」（负序）和「三相同步齐步走的分量」（零序）叠加而成。

## 四、反解式：由三相求三序

已知不对称的三相量 $\dot A$、$\dot B$、$\dot C$，如何反求这三组分量？

**怎么解出来的（一步，可复算）**：把三条合成式相加。

$$\dot A+\dot B+\dot C=(1+1+1)\dot A_0+(1+a+a^2)\dot A_1+(1+a^2+a)\dot A_2=3\dot A_0$$

后两组系数正是 $1+a+a^2=0$，所以和里只剩零序项，得到 $\dot A_0=\frac13(\dot A+\dot B+\dot C)$。
另外两条同理（分别给三相乘 $a$、$a^2$ 后再相加，正序系数留下、其余抵消）。得到：

$$\dot A_1 = \frac{1}{3}(\dot A + a\dot B + a^2\dot C)$$

$$\dot A_2 = \frac{1}{3}(\dot A + a^2\dot B + a\dot C)$$

$$\dot A_0 = \frac{1}{3}(\dot A + \dot B + \dot C)$$

三条反解式的几何直觉非常清楚：
- **零序**：把三相向量直接首尾相加取平均值（除以 3）。如果三相相加为零，说明电路中完全没有零序分量。
- **正序**：把 B 相转 120°（乘 $a$）、C 相转 240°（乘 $a^2$），把它们都旋转到与 A 相正序同方向对齐，加总后除以 3。
- **负序**：把 B 相转 240°（乘 $a^2$）、C 相转 120°（乘 $a$），对齐负序分量后求平均。

其余两相的分量按序次规则即可直接写出，例如 $\dot B_0 = \dot C_0 = \dot A_0$。

## 五、算例：极端单相接地的分解

设某三相系统在 A 相发生单相接地故障，测得故障点电流为：$\dot A = 3\,\text{A}$（幅值 3，初相角 0°），而正常两相断开无电流：$\dot B = 0$，$\dot C = 0$。这是一个极度不对称的工况。

代入反解式计算各序分量：

1. **正序分量**：
   $$\dot A_1 = \frac{1}{3}(3 + a\cdot 0 + a^2\cdot 0) = 1\,\text{A}$$
2. **负序分量**：
   $$\dot A_2 = \frac{1}{3}(3 + a^2\cdot 0 + a\cdot 0) = 1\,\text{A}$$
3. **零序分量**：
   $$\dot A_0 = \frac{1}{3}(3 + 0 + 0) = 1\,\text{A}$$

验算合成式：
- A 相：$\dot A = \dot A_1 + \dot A_2 + \dot A_0 = 1 + 1 + 1 = 3\,\text{A}$
- B 相：$\dot B = a^2\dot A_1 + a\dot A_2 + \dot A_0 = a^2(1) + a(1) + 1 = 1 + a + a^2 = 0$
- C 相：$\dot C = a\dot A_1 + a^2\dot A_2 + \dot A_0 = a(1) + a^2(1) + 1 = 1 + a + a^2 = 0$

原来孤零零的一个单相电流，拆成了三组各为 $1\,\text{A}$ 的标准正序、负序和零序网络。后续分析只需分别对正序、负序、零序单相等效电路求解，极大简化了电机的故障计算。
