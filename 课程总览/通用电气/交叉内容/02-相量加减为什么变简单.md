# 02-相量加减为什么变简单

## 同频前提与相量表示

两个随时间变化的正弦量相加减，直接运算需要展开复杂的三角恒等式。相量法把同频率的正弦量用复数表示，将三角函数的加减化简为复数的加减。

必须**同频**（即角频率 $\omega$ 相同）才能画在同一张相量图上并进行相量加减。若频率不同，两者的相对夹角随时间一直在变，无法定义固定的相位差与合成相量。

正弦量 $u(t) = \sqrt{2} U \sin(\omega t + \varphi)$ 对应的有效值相量记为：

$$\dot U = U \angle \varphi$$

其中模 $U$ 是有效值（正弦量幅值 $U_m = \sqrt{2} U$），相角 $\varphi$ 是初相位。相量与正弦量是一一对应关系，不带时间 $t$，二者不能画等号。

## 代数形式三步加减法

极坐标形式适合乘除，代数形式适合加减。计算两个同频相量之和或差分三步：

1. **化代数**：把极坐标形式化成代数形式（$a = U \cos \varphi$，$b = U \sin \varphi$）：
   $$\dot U_1 = a_1 + j b_1,\qquad \dot U_2 = a_2 + j b_2$$
2. **实加实、虚加虚**：实部与实部分别相加减，虚部与虚部分别相加减：
   $$\dot U = \dot U_1 \pm \dot U_2 = (a_1 \pm a_2) + j (b_1 \pm b_2)$$
3. **化回极坐标**：需要数值时，由直角坐标求模与相角：
   $$U = \sqrt{a^2 + b^2},\qquad \varphi = \arctan\left(\frac{b}{a}\right)\quad (\text{按象限定角})$$

由合成相量 $\dot U = U \angle \varphi$ 反写回时域正弦量时：
- 幅值取 $\sqrt{2} \times U$（$\sqrt{2}$ 倍有效值模）；
- 角频率 $\omega$ 沿用题给同频条件；
- 初相位沿用合成相量的角 $\varphi$：

$$u(t) = \sqrt{2} U \sin(\omega t + \varphi)$$

## 相量图与平行四边形定则

相量在复平面上可以用有向线段表示：线段长度代表有效值模 $U$，与实轴（或参考量）的夹角代表初相位 $\varphi$。

- **加法**：按**平行四边形定则**合成，以两个分相量为邻边作平行四边形，对角线即为合成相量 $\dot U_1 + \dot U_2$。
- **减法**：改成**加反向相量**，即 $\dot U_1 - \dot U_2 = \dot U_1 + (-\dot U_2)$。把被减相量 $\dot U_2$ 沿反向延长（模不变，相角移 $180^\circ$），再与 $\dot U_1$ 按平行四边形定则合成。

## 计算范例

设同频正弦电压的两个有效值相量分别为：

$$\dot U_1 = 3 + j4\ \mathrm{V},\qquad \dot U_2 = 3 - j4\ \mathrm{V}$$

### 1. 求和 $\dot U_{\text{sum}} = \dot U_1 + \dot U_2$

- **实加实，虚加虚**：
  $$\dot U_{\text{sum}} = (3 + 3) + j(4 - 4) = 6 + j0\ \mathrm{V}$$
- **化回极坐标**：模为 $6\ \mathrm{V}$，相角为 $0^\circ$，即 $\dot U_{\text{sum}} = 6\angle 0^\circ\ \mathrm{V}$。
- **反写正弦函数**：
  $$u_{\text{sum}}(t) = 6\sqrt{2} \sin(\omega t + 0^\circ)\ \mathrm{V} = 6\sqrt{2} \sin(\omega t)\ \mathrm{V}$$

### 2. 求差 $\dot U_{\text{diff}} = \dot U_1 - \dot U_2$

- **实减实，虚减虚**：
  $$\dot U_{\text{diff}} = (3 - 3) + j[4 - (-4)] = 0 + j8\ \mathrm{V}$$
- **化回极坐标**：模为 $8\ \mathrm{V}$，虚轴正半轴相角为 $90^\circ$，即 $\dot U_{\text{diff}} = 8\angle 90^\circ\ \mathrm{V}$。
- **反写正弦函数**：
  $$u_{\text{diff}}(t) = 8\sqrt{2} \sin(\omega t + 90^\circ)\ \mathrm{V}$$
