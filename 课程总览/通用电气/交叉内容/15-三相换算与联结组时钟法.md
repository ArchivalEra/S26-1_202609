## 一、页内自推 Y/Δ 的 $\sqrt{3}$ 与 $30^\circ$（补垫 Ch.7 空缺）

设对称正序（$A\to B\to C$ 顺时针依次滞后 $120^\circ$）三相相量：$\dot U_A=U_\Phi\angle 0^\circ$、$\dot U_B=U_\Phi\angle(-120^\circ)$、$\dot U_C=U_\Phi\angle(+120^\circ)$（线电流 $\dot I_A,\dot I_B,\dot I_C$ 同此对称规律）。由 `05` 篇相量减法与等腰三角形几何：

1. **星形接法（Y/y，三个末端 $X,Y,Z$ 并为中性点）**：
   线电流即相电流 $\mathbf{I_L = I_\Phi}$；线电压为两相电位差 $\dot U_{AB}=\dot U_A-\dot U_B$。
   把 $-\dot U_B = U_\Phi\angle(+60^\circ)$ 与 $\dot U_A = U_\Phi\angle 0^\circ$ 合成底角为 $30^\circ$ 的等腰三角形：
   $$\dot U_{AB} = U_\Phi\angle 0^\circ - U_\Phi\angle(-120^\circ) = U_\Phi\left(1 - \left(-\frac{1}{2}-j\frac{\sqrt{3}}{2}\right)\right) = U_\Phi\left(\frac{3}{2}+j\frac{\sqrt{3}}{2}\right) = \mathbf{\sqrt{3}\,U_\Phi\angle(+30^\circ)}$$
   结论：**Y 接「流等压 $\sqrt{3}$ 倍，且线电压超前相应相电压 $30^\circ$」**。
2. **三角形接法（D/d，头尾顺接 $A\text{-}Z,\ B\text{-}X,\ C\text{-}Y$）**：
   每相绕组直接跨接两根线，故线电压即相电压 $\mathbf{U_L = U_\Phi}$；以正序相电流 $\dot I_{AB},\dot I_{BC},\dot I_{CA}$ 写节点 KCL 得线电流 $\dot I_A = \dot I_{AB} - \dot I_{CA}$：
   $$\dot I_A = I_\Phi\angle 0^\circ - I_\Phi\angle(+120^\circ) = I_\Phi\left(\frac{3}{2}-j\frac{\sqrt{3}}{2}\right) = \mathbf{\sqrt{3}\,I_\Phi\angle(-30^\circ)}$$
   结论：**Δ 接「压等流 $\sqrt{3}$ 倍，且线电流滞后相应相电流 $30^\circ$」**。

## 二、三相变压器额定电流与变比 $k$（为什么不用背线变比）

铭牌给定永远是**额定容量 $S_N$、一次额定线电压 $U_{1N}$、二次额定线电压 $U_{2N}$**。照 [10-08](../../电机学/课堂笔记/10-08-磁路例题与变压器概述.md#课堂计算-三相变压器额定电流-例) 与 [10-15](../../电机学/课堂笔记/10-15-空载运行与负载运行.md#变比与联结组别-什么时候在) 只记两条铁律：

1. **额定线电流**：$I_{1N}=\dfrac{S_N}{\sqrt{3}\,U_{1N}},\quad I_{2N}=\dfrac{S_N}{\sqrt{3}\,U_{2N}}$；
2. **变比 $k$ 永远定义为相电压之比（绝不硬套线电压比）**：先按 Y/D 把两侧线电压转为相电压再相除（两边同接法 $\sqrt{3}$ 消掉，不同接法 $\sqrt{3}$ 必在）：
   - **Y,d 例**（$S_N=5000\ \text{kVA},\ 35\ \text{kV}(\text{Y}) / 10.5\ \text{kV}(\text{d})$，Octave 复核）：$I_{1N}=\mathbf{82.48\ \text{A}}$，$I_{2N}=\mathbf{274.93\ \text{A}}$，$k=\dfrac{35/\sqrt{3}}{10.5}=\mathbf{1.925}$；
   - **Dyn 例**（$500\ \text{kVA},\ 10\ \text{kV}(\text{D}) / 0.4\ \text{kV}(\text{yn})$，[2.0 #pass-2-1](../../电机学/教材解析/第02章-变压器的基本作用原理与理论分析/2.0-通关攻略.md#pass-2-1)）：高压侧相电压 $10\ \text{kV}$、低压侧相电压 $0.4/\sqrt{3}\ \text{kV}\implies k=\dfrac{10}{0.4/\sqrt{3}}=25\sqrt{3}\approx\mathbf{43.30}$。

## 三、绕组同极性端与三色时钟法（`Yy10` / `Dyn11` / `Dd8`）

联结组标号用钟表指针直观表示**二次侧线电动势 $\dot E_{ab}$ 相对一次侧线电动势 $\dot E_{AB}$ 的滞后角度**（把 $\dot E_{AB}$ 永远钉在 **12 点**，顺时针一格 $=30^\circ$）。按 [10-29 五·时钟法](../../电机学/课堂笔记/10-29-三相变压器与三次谐波.md#五-绕组标号-极性-联结组标号-时钟法-27-00-48-20) 四步走绝不出错：

1. **认清同柱同相位对（最易错步）**：套在**同一铁芯柱**上的高压绕组（A/X）与低压绕组（a/x），若首尾同极性标 `*` 都在同端，则两者的相电动势**严格同相**；若低压绕组被**反绕/反接**或**跨柱换相接线**（如 [10-29 教材 58 页 Yy10](../../电机学/课堂笔记/10-29-三相变压器与三次谐波.md#教材-58-页-7-3-2-求连接组标号) 的 $a x\parallel YB$），先把这三条相电动势平行方向锁定（三色笔或一/二/三道杠标记）；
2. **画高压侧正序骨架**：把 $\dot E_{AB}$ 指向 **12 点**，顺时针画等边三角形 $\triangle ABC$（A $\to$ B $\to$ C 顺时针排布，逆时针会变负序颠倒！）；
3. **平移低压侧向量（平移不改相位）**：按第 1 步同相位规则画出 $\dot E_a, \dot E_b, \dot E_c$（或 D 接时的末端连接关系），把低压侧线电动势 $\dot E_{ab}$ 平移到与高压侧共圆心；
4. **顺时针数表读点数**：
   - **奇偶快筛**：两侧**同接法**（Y,y 或 D,d）恒为**偶数点** $\{0,2,4,6,8,10\}$；两侧**异接法**（Y,d 或 D,y）因差 $30^\circ$ 相移恒为**奇数点** $\{1,3,5,7,9,11\}$；
   - **实案对比**：`Yy10`（[10-29](../../电机学/课堂笔记/10-29-三相变压器与三次谐波.md#教材-58-页-7-3-2-求连接组标号)）：$\dot E_{ab}$ 超前 $\dot E_{AB}$ $60^\circ$ $\equiv$ 顺时针滞后 $300^\circ \implies 300^\circ/30^\circ=\mathbf{10\text{ 点}}$；`Dyn11`（[2.3.1 第 1 题](../../电机学/作业/2.3.1三相电力变压器.md#第-1-题)）：指 11 点即低压侧线电压**滞后 $330^\circ$**（超前 $30^\circ$）；`Dd8`（[11-05](../../电机学/课堂笔记/11-05-并联运行与瞬态过程.md#教材-58-页-7-3-2-三角形-三角形小题-求连接组标号)）：顺时针转 $240^\circ \implies 240^\circ/30^\circ=\mathbf{8\text{ 点}}$。
