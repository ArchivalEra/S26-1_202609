# 交叉内容

[返回课程索引](../index.md) · [Walkthrough](../Walkthrough.md)

## 这个栏目是什么

把跨课程共用但各自默认前置知识的数学工具与分析接口逐篇拆开接通，每篇先列出精确依赖锚点，再给完整推导与例题。

## 篇目

| 篇 | 交叉什么 | 读完能做到 |
| :--- | :--- | :--- |
| [01-电路矩阵与消元判解](./01-电路矩阵与消元判解.md) | 电路原理第 3–4 章 × 工程数学第 2、4 章 | 把网孔/节点标准方程写进增广矩阵，用两秩判据与行变换判清解的情形 |
| [02-行最简形与通解结构](./02-行最简形与通解结构.md) | 电路原理第 3–4 章 × 工程数学第 4 章 | 从行最简形读取非主元自由量，构造基础解系与非齐次通解，对齐未设参考点零空间与叠加算子 |
| [03-正弦量、有效值与相量](./03-正弦量、有效值与相量.md) | 高数定积分与欧拉公式 × 电路原理 5.1–5.2 | 从定积分推 $I=I_m/\sqrt2$、剥离时间因子 $e^{j\omega t}$，用四象限定角与四层记号对齐正弦相量 |
| [04-微积分变乘除与复阻抗](./04-微积分变乘除与复阻抗.md) | 复指数求导 × 电路原理第 1–4 章与 5.3–5.4 | 推出 $Z_L/Z_C$ 与导纳分解 $Y=G+jB$（纠偏 $G\neq 1/R$），把直流分析法全套平移至相量域 |
| [05-相量加减与仪表读数](./05-相量加减与仪表读数.md) | 复数代数与矢量几何 × 电路原理 5.2–5.4 | 分清有效值表读模长与相量 KCL/KVL，掌握串联/并联/混联相量图参考基准倒推 |
| [06-交流功率与电容补偿](./06-交流功率与电容补偿.md) | 三角积分与复共轭 × 电路原理 5.5 交流功率 | 推全 $P,Q,S,\bar S=\dot U\dot I^*$ 功率链，并在页内自足推出并联电容无功补偿公式 |
| [07-谐振与最大功率匹配](./07-谐振与最大功率匹配.md) | 高数求极值与电路 Ch.4 × 谐振与共轭匹配 | 以「电抗抵消」为主线自推串联谐振、并联谐振两套口径与交流共轭匹配 $Z_L=Z_{th}^*$ |
