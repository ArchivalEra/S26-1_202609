# 交叉内容

[返回课程索引](../index.md) · [Walkthrough](../Walkthrough.md)

## 这个栏目是什么

四门课各自讲同一个东西时用了不同的语言，这里是**那些语言的互译表**。
每一篇是一个交叉点，读法统一：**先用一句话说清它是什么 → 再给最小可用的做法 → 再给一个例子**。

## 读法

按编号顺序读。01–04 是**电路原理这一条线**（正弦→相量→阻抗），
05–06 是**电机学这一条线**（三相→谐波），07 是**电子技术这一条线**（直流/交流分离）。
三条线在 03 与 07 之间有一处汇合：**微变等效电路本质上就是「把交流小信号写成相量」**——
07 篇的末尾会指回 03。
