## 一、空载与短路试验为什么刚好把参数拆成两半

依据 [13 篇](./13-变压器电路化与归算.md) 近似等效电路（试验公式 2-44/2-45 按单相相值写，三相先将 $U_N, I_N, P$ 换为相值，功率除以 3）：

| 试验名称 | 接线与激励条件 | 忽略项物理依据 | 测算结果与归算 |
| :--- | :--- | :--- | :--- |
| **空载试验** | 二次开路；**常在低压侧加额定电压** $U_N$（低压安全且饱和点弯，**必须加到额定点**） | $I_0\ll I_N$，$I_0^2 r_1\ll p_{Fe}$ | $p_0\approx p_{Fe}$；$Z_0=\frac{U_0}{I_0}\approx Z_m$、$r_m=\frac{p_0}{I_0^2}$、$x_m=\sqrt{Z_m^2-r_m^2}$（低压值 $\times k^2$ 归回高压侧） |
| **短路试验** | 二次短路；**常在高压侧加很低电压** $U_k$（仅 $4\%\sim 10\%$ 额定）使 $I_k=I_N$（线性直，任一点可按比例推） | $U_k$ 极低，主磁通与铁耗 $\propto B^2$ 仅剩千分之几 | $p_k\approx p_{Cu}$；$Z_k=\frac{U_k}{I_k}$、$r_k=\frac{p_k}{I_k^2}$、$x_k=\sqrt{Z_k^2-r_k^2}$（电阻按铜 $234.5$ 换算至 $75\,^\circ\mathrm{C}$，漏抗不随温度变） |

- **单相 1000 kVA、60/6.3 kV 高压侧短路算例（[10-22](../../电机学/课堂笔记/10-22-参数测定与电压变化率.md#课堂练习一-单相-1000-kva-60-6-3-kv-高压侧短路试验求)，Octave 复核）**：
  $U_k=3.6\ \text{kV}, I_k=I_{1N}=16.67\ \text{A}, p_k=17\ \text{kW} \implies Z_k=3600/16.67=\mathbf{216.00\ \Omega}$，$r_k=17000/16.67^2=\mathbf{61.20\ \Omega}$，$x_k=\sqrt{216^2-61.2^2}=\mathbf{207.15\ \Omega}$。

## 二、标幺值（无单位、免归算）把 $u_k\%$ 和 $z_k^*$ 焊成同一个数

取各侧自身额定值作基准（单相 $Z_b=\dfrac{U_N}{I_N}=\dfrac{U_N^2}{S_N}$，三相相阻抗基准同理 $Z_{\Phi b}=\dfrac{U_{\Phi N}}{I_{\Phi N}}=\dfrac{U_{lN}^2}{S_N}$）：

$$\text{标幺值} = \frac{\text{实际值}}{\text{基准值}} \implies u_k^* = \frac{U_{kN}}{U_{1N}} = \frac{Z_k I_{1N}}{U_{1N}} = \frac{Z_k}{Z_{1b}} = \mathbf{z_k^*},\qquad r_k^* = u_{kr}^* = \frac{p_{kN}}{S_N},\qquad x_k^* = u_{kx}^* = \sqrt{(u_k^*)^2-(r_k^*)^2}$$

标幺值**绝对不能写单位**，且折算前后一、二次侧标幺值**严格相等**，彻底消掉 $k$ 与 $\sqrt{3}$ 的来回换算。

## 三、运行两大指标：电压变化率 $\Delta U\%$ 与损耗分离最大效率

（[2.2.3 第 6 题](../../电机学/作业/2.2.3变压器运行性能.md#第-6-题) 明定变压器运行性能主要指标只有两项：**电压变化率 $\Delta U$** 与 **效率 $\eta$**。）

1. **电压变化率实用公式与容升现象（[10-22](../../电机学/课堂笔记/10-22-参数测定与电压变化率.md#实用公式-单位圆上的一段线段)）**：
   以 $\dot U_{20}$ 为基准作单位圆投影，扔掉二阶小弧段（精确需加 $+\frac{1}{2}[\beta(x_k^*\cos\varphi_2-r_k^*\sin\varphi_2)]^2$），得：
   $$\Delta U\% = \frac{U_{20}-U_2}{U_{20}}\times 100\% \approx \beta\big(r_k^*\cos\varphi_2 + x_k^*\sin\varphi_2\big)\times 100\%$$
   - **感性滞后（$\varphi_2>0,\sin\varphi_2>0$）**：$\Delta U\%>0$，$U_2<U_{20}$（端电压下降；**额定电压变化率**固定在 $\beta=1,\cos\varphi_2=0.8$ 滞后）；
   - **容性超前（$\varphi_2<0,\sin\varphi_2<0$）**：当 $|x_k^*\sin\varphi_2|>r_k^*\cos\varphi_2$ 时出现 $\Delta U\%<0$，即二次电压比空载还高的**容升现象**（[2.2.3 第 5 题](../../电机学/作业/2.2.3变压器运行性能.md#第-5-题)：$\Delta U$ 与参数、负载大小 $\beta$ 及性质 $\varphi_2$ 三者均有关）。
2. **损耗分离法与最大效率条件（[10-29 一](../../电机学/课堂笔记/10-29-三相变压器与三次谐波.md#一-损耗分离法与效率定义式-作业讲评-约-03-27-12-00) + [二 $P_k$ 坑](../../电机学/课堂笔记/10-29-三相变压器与三次谐波.md#二-与-考试题里的那个坑-约-12-42-19-30)）**：
   把全损耗拆为不变铁耗 $p_0$ 与随负载电流平方增长的可变铜耗 $\beta^2 p_{kN}$（其中 $\beta=I_2/I_{2N}$）：
   $$\eta(\beta) = \frac{\beta S_N\cos\varphi_2}{\beta S_N\cos\varphi_2 + p_0 + \beta^2 p_{kN}}$$
   分母除 $\beta$ 后由高数均值不等式（或对 $\beta$ 求导置零）立即得到最大效率点：
   $$\frac{p_0}{\beta} = \beta p_{kN} \implies \mathbf{\beta_m^2 p_{kN} = p_0} \implies \mathbf{\beta_m = \sqrt{\frac{p_0}{p_{kN}}}}$$
   因电力变压器设计 $p_0/p_{kN}\approx 1/4\sim 1/3$，故最高效率通常落在 **$\beta_m\approx 0.5\sim 0.6$**（轻载高效，不在额定点 $\beta=1$）。
   - **⚠ 高频防坑（$P_k$ vs $P_{kN}$）**：只有短路电流**恰好等于额定电流**时的短路损耗才叫 $p_{kN}$；若题给非额定电流 $I_k\neq I_N$ 下的 $p_k$，必须先按铜耗平方律换算成 **$p_{kN} = p_k\,(I_N/I_k)^2$** 才能代入效率与标幺式！
3. **综合实战验算（`2.0` 习题 2-7，Octave 与独立盲测双签一致）**：
   已知 $S_N=1800\ \text{kVA}$、$u_k\%=4.5\%$、$p_0=6.8\ \text{kW}$、$p_{kN}=22\ \text{kW}$、$U_{2N}=400\ \text{V}$、$\beta=1,\cos\varphi_2=0.8$ 滞后：
   - $r_k^*=22/1800=\mathbf{0.01222}$，$x_k^*=\sqrt{0.045^2-0.01222^2}=\mathbf{0.04331}$；
   - 一阶 $\Delta U_1\%=(0.01222\times 0.8+0.04331\times 0.6)\times 100\%=\mathbf{3.58\%}$（含二阶项 $\Delta U_2\%=\mathbf{3.61\%}$），得 $U_2\approx 400\times(1-0.03614)=\mathbf{385.55\ \text{V}}$（一阶 $385.69\ \text{V}$）；
   - $\eta = \frac{1440}{1440+6.8+22} = \mathbf{98.04\%}$，最大效率负载系数 $\beta_m = \sqrt{6.8/22} = \mathbf{0.5560}$。
