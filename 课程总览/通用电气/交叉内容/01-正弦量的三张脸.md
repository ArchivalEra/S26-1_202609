# 01-正弦量的三张脸

<figure class="fig"><img src="figures/fig-ge-01.svg" alt="正弦量的三张脸：波形、旋转相量、复平面静态相量" loading="lazy"><figcaption>同一个正弦量在时域、旋转几何与复平面上的三张面孔</figcaption></figure>

## 一、三张脸：波形、转动的箭头、复数

正弦交流电 $u(t)=U_m\sin(\omega t+\psi)$ 在不同场合有三种表达形式，本质是同一对象的不同投影：

1. **第一张脸（波形）**：随时间 $t$ 变化的正弦曲线。横轴为时间 $t$，纵轴为瞬时电压 $u$。它解决时域直观展现的问题。
2. **第二张脸（转动的箭头）**：长度为 $U_m$、以角速度 $\omega$ 逆时针匀速旋转的有向线段（旋转矢量）。它在纵轴上的垂直投影恰好是瞬时值 $u(t)$。它解决旋转几何与振荡周期的对应问题。
3. **第三张脸（复平面上的静态箭头 / 复数）**：旋转箭头在 $t=0$ 瞬间拍摄的「快照」，固定在复平面上，写作复数 $\dot U$。在同频率前提下，旋转速度 $\omega$ 保持一致，运算时省去时间因子，直接用静态相量参与计算。

**相量与正弦量是一一对应但不相等的**。相量是正弦量在 $t=0$ 时的快照，就像人的照片是一张平面的纸，照片不是本人，但凭借照片和已知的频率，可以精确找回原本的正弦量。

## 二、三要素与有效值

### 1. 三要素各管什么

正弦量由三个参数唯一确定：

$$u(t) = U_m \sin(\omega t + \psi)$$

- **幅值（最大值）$U_m$**：管变化的**幅度**有多大，决定正弦波峰的高度。
- **角频率 $\omega$**：管变化的**快慢**。与频率 $f$、周期 $T$ 的关系为 $\omega = 2\pi/T = 2\pi f$。工程中常见的工频交流电 $50\ \mathrm{Hz}$，对应的角频率为 $\omega = 2\pi \times 50 \approx 314\ \mathrm{rad/s}$。
- **初相位 $\psi$**：管 $t=0$ 瞬间的**起始位置**，决定曲线在纵轴上从哪个高度开始起跑。

### 2. 有效值

正弦量的最大值 $U_m$ 与直流在发热效果上等价的数值称为有效值 $U$：

$$U = \frac{U_m}{\sqrt{2}}$$

工程铭牌、仪器仪表所标注的「家庭电压 220 V」，指的是**有效值** $U=220\ \mathrm{V}$，其幅值最大值约为 $U_m = 220\sqrt{2} \approx 311\ \mathrm{V}$。

### 3. 相位差

只有**同频率**的正弦量才能比较相位。设两个同频正弦量的初相分别为 $\psi_1$ 与 $\psi_2$，它们的相位差为初相之差：

$$\Delta\psi = \psi_1 - \psi_2$$

$\Delta\psi > 0$ 表示第一个量超前于第二个量；$\Delta\psi = 0$ 为同相；$\Delta\psi = \pm 180^\circ$ 为反相；$\Delta\psi = \pm 90^\circ$ 为正交。

## 三、复数互转：代数形式与极坐标形式

复数有两种核心表达形式：**代数形式** $a + jb$ 与**极坐标形式** $r\angle\theta$。

- **代数形式 $\to$ 极坐标形式**：
  - 模长：$r = \sqrt{a^2 + b^2}$
  - 幅角：先算锐角参考值 $\theta_0 = \arctan(|b|/|a|)$，**必须按所在象限定角**：
    - 第一象限（$a>0, b>0$）：$\theta = \theta_0$
    - 第二象限（$a<0, b>0$）：$\theta = 180^\circ - \theta_0$
    - 第三象限（$a<0, b<0$）：$\theta = \theta_0 - 180^\circ$（或 $-180^\circ + \theta_0$）
    - 第四象限（$a>0, b<0$）：$\theta = -\theta_0$
- **极坐标形式 $\to$ 代数形式**：
  - 实部：$a = r\cos\theta$
  - 虚部：$b = r\sin\theta$
  - 代数式：$a + jb = r\cos\theta + j r\sin\theta$

加减法采用代数形式（实部加实部、虚部加虚部），乘除法采用极坐标形式（模相乘除、角相加减）。

## 四、三张脸互转范例：以 $311\sin(314t + 0^\circ)$ 为例

以家庭市电正弦电压 $u(t) = 311\sin(314t + 0^\circ)\ \mathrm{V}$ 为例，完成三张脸之间的标准转换：

### 1. 正弦波形 $\to$ 相量

从表达式中读出三要素：幅值 $U_m = 311\ \mathrm{V}$，角频率 $\omega = 314\ \mathrm{rad/s}$（对应 $50\ \mathrm{Hz}$），初相 $\psi = 0^\circ$。

- **有效值相量（工程默认）**：模取有效值 $U = U_m/\sqrt{2} = 311/\sqrt{2} \approx 220\ \mathrm{V}$，角取初相位 $\psi = 0^\circ$：
  $$\dot U = 220\angle 0^\circ\ \mathrm{V}$$
- **幅值相量（若需标注幅值）**：模取幅值 $U_m = 311\ \mathrm{V}$，角取初相位 $0^\circ$，模为有效值相量的 $\sqrt{2}$ 倍：
  $$\dot U_m = 311\angle 0^\circ\ \mathrm{V}$$

### 2. 相量 $\to$ 复数代数形式

将极坐标相量 $\dot U = 220\angle 0^\circ\ \mathrm{V}$ 展开为代数形式：

$$\dot U = 220\cos 0^\circ + j220\sin 0^\circ = (220 + j0)\ \mathrm{V}$$

在复平面上，它是一支从原点指向实轴正方向、长度为 220 的有向线段。

### 3. 相量 $\to$ 正弦波形反写

已知相量 $\dot U = 220\angle 0^\circ\ \mathrm{V}$ 与系统工频 $\omega = 314\ \mathrm{rad/s}$：

- 幅值取有效值相量模的 $\sqrt{2}$ 倍：$U_m = 220\sqrt{2} \approx 311\ \mathrm{V}$；
- 角频率沿用 $\omega = 314\ \mathrm{rad/s}$；
- 初相位沿用相角 $0^\circ$；
- 还原瞬时时域函数：
  $$u(t) = 311\sin(314t + 0^\circ)\ \mathrm{V}$$
