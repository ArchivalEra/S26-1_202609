## 一、主磁通、漏磁通与为什么一次电流要「补位」

1. **两股磁通各自化成等效阻抗**：
   - **主磁通 $\Phi$** 同时交链一、二次绕组，走铁芯，非线性且承担功率传递 $\implies$ 等效为并联励磁支路 **$Z_m = r_m + jx_m$**（$r_m$ 等效铁耗、$x_m$ 表征主磁导，因空载主要建磁场，$\dot I_0$ 滞后 $\dot U_1$ 近 $90^\circ$，以无功为主，且只占额定电流 $<1\%$）；
   - **漏磁通 $\Phi_{1\sigma},\Phi_{2\sigma}$** 只交链各自绕组，走非磁性油/空气路径，**线性不饱和** $\implies$ 与绕组直流电阻合并成串联漏阻抗 **$Z_1=r_1+jx_{1\sigma}$**、**$Z_2=r_2+jx_{2\sigma}$**。
2. **负载磁动势平衡方程**：一次电压 $U_1$ 与频率 $f$ 不变时，$\Phi_m\approx \dfrac{U_1}{4.44 f N_1}$ **被电源死死锁住**。二次带载流出 $\dot I_2$ 产生去磁磁动势 $N_2\dot I_2$，一次侧必须立刻多吸取负载电流分量 $-\dot I_2/k$ 来把磁动势账抵平：
   $$\dot I_1 N_1 + \dot I_2 N_2 = \dot I_0 N_1 \implies \dot I_1 = \dot I_0 + \left(-\frac{\dot I_2}{k}\right) = \dot I_0 + \dot I_2',\qquad k=\frac{N_1}{N_2}=\frac{E_1}{E_2}$$

## 二、页内自推归算铁律：$U\times k$、$I/k$、$Z\times k^2$（补垫 Ch.6 空缺）

一、二次侧匝数不同、电位隔离，不能直接写在同一张 KVL 回路里。把二次侧全部 $N_2$ 匝等效替换为一个与一次同匝数的新绕组 **$N_2'=N_1=kN_2$**（自二次归算到一次侧），只准守住两条物理不变量，全部换算系数自动掉出来：

1. **不变量 1：归算前后磁动势不变 $\implies$ 电流除以 $k$**：
   $$I_2' N_2' = I_2 N_2 \implies I_2'(k N_2) = I_2 N_2 \implies \mathbf{I_2' = \frac{I_2}{k}}$$
2. **不变量 2：归算前后电磁功率/视在功率不变 $\implies$ 电压与电动势乘以 $k$**：
   $$U_2' I_2' = U_2 I_2 \implies U_2'\left(\frac{I_2}{k}\right) = U_2 I_2 \implies \mathbf{U_2' = k U_2},\qquad \mathbf{E_2' = k E_2 = E_1}$$
3. **不变量 3：归算前后铜耗/无功损耗不变 $\implies$ 阻抗乘以 $k^2$**：
   $$I_2'^2 r_2' = I_2^2 r_2 \implies \left(\frac{I_2}{k}\right)^2 r_2' = I_2^2 r_2 \implies \mathbf{r_2' = k^2 r_2},\quad \mathbf{x_{2\sigma}' = k^2 x_{2\sigma}},\quad \mathbf{Z_L' = k^2 Z_L}$$

> **与《电路原理》第 6 章接口对照（[习题册第六章#选-4-8-9-11-16-同一道折算题](../../电路原理/作业/习题册第六章.md#选-4-8-9-11-16-同一道折算题)）**：电路原理里的理想变压器折算公式 $Z_{\text{in}} = n^2 Z_L$（$n=N_1/N_2$）与此处 $Z_L'=k^2 Z_L$ 完全是同一条功率不变律（顺便提示：`习题册第六章.md#1-依赖` 表格把 $n:1$ 误记作 $Z_L/n^2$，与其正文中 `#选-4` 及 `#5-小结` 的 $n^2 Z_L$ 相反，应以 $n^2 Z_L$ 为准）；差别仅在电机学保留了励磁支路 $Z_m$ 与绕组漏阻抗 $Z_1, Z_2'$，理想变压器则取 $Z_m\to\infty$、$Z_1=Z_2'=0$。

## 三、T 形、近似、简化三种等效电路与铭牌 $u_k\%$

归算后 $E_2'=E_1$，中间磁性耦合彻底消失，变压器变成标准电路网络（[10-15 三种等效电路](../../电机学/课堂笔记/10-15-空载运行与负载运行.md#三种等效电路-t-形-近似-简化)）：

| 等效电路 | 拓扑结构 | 成立近似理由 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **T 形等效电路** | $Z_1$ 串在左臂、$Z_m$ 并在中点、$Z_2'$ 串在右臂接 $Z_L'$ | 精确（仅用正弦等效波近似非线性 $Z_m$） | 严格方程分析、精确相量图 |
| **近似等效电路** | 把 **$Z_m$ 移到电源端口最左侧**，使 $Z_1$ 与 $Z_2'$ 合并为 **$Z_k=Z_1+Z_2'=r_k+jx_k$** | $I_0\ll I_1$（$<1\%$ 对上百倍，$Z_m\gg Z_1$），前移误差在 $1\%$ 级 | **空载/短路参数测定、效率与 $\Delta U\%$ 工程计算** |
| **简化等效电路** | 直接略去励磁支路（$Z_m$ 开路），全图只剩串联 **$Z_k = r_k+jx_k$** | 关注大负载或短路电流时 $I_0$ 可全忽略 | **电压变化率推导、电力系统短路计算** |

- **算例核对（`2.0` `#pass-2-2`/`#pass-2-3`，Octave 复核）**：$f=50\ \text{Hz}, N_1=960, S=200\ \text{cm}^2, B_m=1.4\ \text{T}\implies E_1=4.44\times 50\times 960\times(1.4\times 0.02)=\mathbf{5967.36\ \text{V}}$；若 $k=5.5, r_2=0.02\,\Omega, x_{2\sigma}=0.03\,\Omega\implies r_2'=5.5^2\times 0.02=\mathbf{0.605\,\Omega},\ x_{2\sigma}'=\mathbf{0.9075\,\Omega}$。
- **铭牌短路阻抗百分数 $u_k\%$**：$u_k\%=\dfrac{Z_k I_N}{U_N}\times 100\%$。$u_k\%$ 越小，负载波动时电压变化越小（配变仅约 $4\%$）；越大则突发短路电流 $I_k\approx I_N/u_k^*$ 被压得越小。
