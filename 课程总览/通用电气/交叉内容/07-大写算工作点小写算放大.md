# 07 · 大写算工作点小写算放大

<figure class="fig"><img src="figures/fig-ge-08.svg" alt="共射放大电路交直流分离：直流通路确定Q点，交流微变等效电路计算放大" loading="lazy"><figcaption>共射放大电路的交直流分离：直流通路定 Q 点，交流微变等效电路算动态指标</figcaption></figure>

## 一、记号约定：大小写分清两套账

在放大电路中，电压与电流同时包含直流成分和交流成分。电路分析采用严格的大小写记号区分两套世界：

- **大写字母加下标**（$I_B$、$I_C$、$U_{CE}$）：表示**直流工作点**（静态值），是电路不加输入交流信号时由直流电源维持的稳定基准。
- **小写字母加下标**（$i_b$、$i_c$、$u_{ce}$）：表示**交流信号**（动态微变），是输入小信号引起的微小波动。

整个分析策略就是「各算各的」：先用直流通路算大写工作点，再用交流微变等效算小写放大倍数。

## 二、直流通路：定出静态工作点 Q

计算直流工作点时，电路处于纯直流状态。元器件遵循两条规则：

- **电容当断开**（直流无法穿过隔直电容）。
- **电感当短路**（直流下电感相当于理想导线）。

### 先说清这个电路长什么样

固定偏置共射放大电路只有五个零件，接法是一条直线加一条旁路：

```
        U_CC（直流电源正极）
          │
         R_b        ← 基极偏置电阻，接在 U_CC 与基极之间
          │
  输入 ──┤├── B（基极）
        C1（隔直电容）     三极管
                    C（集电极）── R_c ── U_CC
                    E（发射极）── 地
                    输出从 C 取，经 C2（隔直电容）到负载 R_L 到地
```

**三个电阻各管什么**：$R_b$ 决定基极电流有多大；$R_c$ 是集电极的负载电阻；
$R_L$ 是接在输出端的外接负载。**两个电容**（$C_1$、$C_2$）只让交流通过、挡住直流。

在这个拓扑下，直流回路只有一条：$U_{CC}\to R_b\to$ 基极 $\to$ 发射极 $\to$ 地。
所以 $R_b$ 上的压降就是 $U_{CC}-U_{BE}$，除一下就是基极电流——这就是下面第一条式子。
静态工作点 $Q$（$I_{BQ}$、$I_{CQ}$、$U_{CEQ}$）按初中欧姆定律可一步步估算：

1. **基极电流**：
   $$I_{BQ} = \frac{U_{CC} - U_{BE}}{R_b}$$
   其中 $U_{CC}$ 是直流电源电压，$U_{BE}$ 是三极管基极-发射极导通压降（硅管通常取 $0.7\text{ V}$ 或依题意取 $0.6\text{ V}$）。
2. **集电极电流**（受控放大 $\beta$ 倍）：
   $$I_{CQ} = \beta I_{BQ}$$
3. **管压降**（电源减去集电极电阻压降）：
   $$U_{CEQ} = U_{CC} - I_{CQ}R_c$$

算出 $Q$ 点，三极管就稳稳停在放大区，交流信号才能以它为中心无失真上下摆动。

## 三、微变等效：三极管换成电阻与受控源

算交流放大时，只看交流微小波动。直流电源对交流等效接地，耦合电容对交流短路。

在交流通路中，三极管本身被替换为**线性等效模型**：

- **输入端（B-E 之间）**：换成一个输入等效电阻 $r_{be}$。
  *直觉解释*：$r_{be}$ 本质是工作点 $Q$ 处 PN 结伏安特性的切线电阻，$Q$ 点电流越大，管子导通越充分，该动态电阻越小。
- **输出端（C-E 之间）**：换成一个**受控电流源** $\beta i_b$。
  受控源的输出电流大小直接由输入电流 $i_b$ 按 $\beta$ 倍比例控制，方向由集电极指向发射极。

经过这一步替换，包含三极管的电路变成了纯由普通电阻与受控源构成的标准电路。

## 四、动态三指标：放大倍数与输入输出电阻

**先约一个记号**：$R_1\parallel R_2$ 读作「$R_1$ 与 $R_2$ 并联」，就是
$\dfrac{R_1R_2}{R_1+R_2}$（初中并联电阻公式，两个电阻并联总是比小的那个还小）。

**推导只有两行**（这就是全部依据）：

- 输入端：$u_i = i_b\,r_{be}$（输入电压全落在 $r_{be}$ 上，因为 $R_b$ 与它并联但 $R_b$ 很大）
- 输出端：$u_o = -i_c(R_c\parallel R_L) = -\beta i_b (R_c\parallel R_L)$（负号：电流从集电极流出，输出电压与输入反相）

两式相除，$i_b$ 约掉，得到 $A_u$。其余两个指标是「从哪一端看进去」的定义式。

在微变等效电路上应用电阻串并联和欧姆定律，即可直接写出放大电路的三大动态指标：

1. **电压放大倍数** $A_u$：
   $$A_u = -\frac{\beta (R_c \parallel R_L)}{r_{be}}$$
   分子是输出端总并联电阻 $R_c \parallel R_L$ 产生的电压降，分母是输入电阻 $r_{be}$ 上的电压降。负号表示输出电压与输入电压在相位上相差 $180^\circ$（反相放大）。
2. **输入电阻** $r_i$：
   $$r_i \approx R_b \parallel r_{be}$$
   从输入端看进去，是偏置电阻 $R_b$ 与管子输入电阻 $r_{be}$ 的并联。
3. **输出电阻** $r_o$：
   $$r_o \approx R_c$$
   将信号源置零、断开负载后从输出端看进去，受控电流源内部断路，回路只剩下集电极电阻 $R_c$。

## 五、为什么能拆：从非线性到线性的统一哲学

为什么可以把一个同时流过直流和交流的电路硬生生拆成「直流通路」和「微变等效」两半独立计算？

根本原因在于：**交流小信号在工作点 $Q$ 附近近似线性**。三极管原本是非线性的弯曲曲线，但当交流信号幅度足够小时，曲线在 $Q$ 点附近的微小局部完全可以当成一段平直的切线。直流负责把这个切点（$Q$ 点）立牢，交流信号则沿着切线做纯比例放大。

这一思路与 [03 微积分变成乘除法](03-微积分变成乘除法.md) 中的**相量法**具有相同的物理与数学内核：

- **相量法**：利用正弦信号导数仍在同频旋转的特性，把包含微分方程的动态非线性演化问题，转换为乘除 $j\omega$ 的线性复数代数。
- **微变等效法**：利用小信号局部近似线性的特性，把三极管复杂的非线性伏安特性曲线，转换为 $r_{be}$ 与受控源 $\beta i_b$ 的简单比例运算。

两者都遵循同一个工程数学方法：**通过合理限定条件，把复杂的非线性问题变线性**。
