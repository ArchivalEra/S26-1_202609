## 一、对称分量法：$a=e^{j120^\circ}$ 把不对称化回三套单相

当三相电源、变压器或负载不对称时，[15 篇](./15-三相换算与联结组时钟法.md) 依赖对称性的单相等效电路失效。引入复数单位旋转算子 **$a = e^{j120^\circ} = -\frac{1}{2}+j\frac{\sqrt{3}}{2}$**（满足 $a^2=e^{j240^\circ}$、$a^3=1$、$1+a+a^2=0$），任意一组不对称三相相量 $(\dot A, \dot B, \dot C)$ 可唯一分解为三组对称分量之和（[11-05 五·对称分量法](../../电机学/课堂笔记/11-05-并联运行与瞬态过程.md#五-对称分量法-教师赠送-约-1-14-50-1-27-33)）：

$$\dot A = \dot A_1 + \dot A_2 + \dot A_0,\qquad \dot B = a^2\dot A_1 + a\dot A_2 + \dot A_0,\qquad \dot C = a\dot A_1 + a^2\dot A_2 + \dot A_0$$

反解 A 相三序分量（B、C 相按各序相序推得）：

| 序分量 | 相序特征 | 各序提取公式 | 现场/后续继保对应 |
| :--- | :--- | :--- | :--- |
| **正序（下标 1）** | $A_1\to B_1\to C_1$ 依次滞后 $120^\circ$ | $\dot A_1 = \dfrac{1}{3}\big(\dot A + a\dot B + a^2\dot C\big)$ | 正常对称运行工况 |
| **负序（下标 2）** | $A_2\to C_2\to B_2$ 反序（$B_2$ 超前 $A_2$） | $\dot A_2 = \dfrac{1}{3}\big(\dot A + a^2\dot B + a\dot C\big)$ | 两相短路等不对称故障分量 |
| **零序（下标 0）** | **三相等幅值、严格同相位** | $\dot A_0 = \dfrac{1}{3}\big(\dot A + \dot B + \dot C\big) = \dot B_0 = \dot C_0$ | CT 并联取 $3\dot I_0$、PT 开口三角形取 $3\dot U_0$ |

## 二、为什么三次谐波天然变成「同相零序」，引发铁芯畸变

1. **相位倍频规则（[2.3.1 #2-2](../../电机学/作业/2.3.1三相电力变压器.md#2-2-谐波的时间相位)）**：基波三相互差 $120^\circ$，则 $3$ 次谐波频率与电角度翻 $3$ 倍，三相三次谐波相角差变为 **$3\times 120^\circ = 360^\circ \equiv 0^\circ$**。因此**三相三次谐波严格同相（天然就是零序分量）**。
2. **因果链与波形互逆（[2.3.1 #2-4](../../电机学/作业/2.3.1三相电力变压器.md#2-4-yy-接线的适用边界)）**：
   - 正弦磁通需要励磁电流在饱和 $B\text{-}H$ 曲线上呈**尖顶波**（含 3 次谐波）；
   - 一旦 Y 接无中性线堵死了同相三次谐波电流的通路（$I_{03}=0$），**励磁电流被迫变成正弦波 $\implies$ 饱和曲线将其压成含 3 次谐波的平顶主磁通 $\implies$ 求导后感应出尖顶形二次相电动势**（务必咬准因果：电流被迫正弦在先，磁通平顶在后！）。

## 三、组式 vs 心式（芯式）分岔与「三次谐波三道防线」

面对三次谐波磁通/电动势威胁，工程判定永远只有一条主线：**三次谐波电流有没有闭合回路**，依次过 [11-05 二·三道防线](../../电机学/课堂笔记/11-05-并联运行与瞬态过程.md#二-三次谐波三道防线复盘-约-5-21-17-59)：

1. **第一道防线（一次侧接线）**：一次侧选用 **单相独立**、**YN（带中性线）** 或 **D（三角形环内闭流）** $\implies$ 三次谐波电流在一次侧自行流通，磁通直接保持正弦，问题根除；若一次侧选了无中性线 Y，失守。
2. **第二道防线（二次侧接线）**：一次失守时，二次侧选用 **d（三角形环流）**、**yn（注意不可空载运行，必须带负荷才有通路）** 或专门**加装不对外供电的平衡三角形绕组** $\implies$ 靠全电流定律由二次侧补齐三次谐波磁动势，主磁通仍保正弦；若二次侧又选 y（即 **Yy** 接线），两道防线全失守。
3. **第三道防线（铁心磁路结构）**：Yy 接线无三次谐波电流通道，后果由磁路结构决定：
   - **组式（三台单相独立铁心）**：三次谐波磁通顺利在低磁阻主铁心内闭合，谐波磁通极大 $\implies$ 二次相电动势三次谐波高达基波的 **$45\%\sim 60\%$（`11-05` 笔记口述作 $45\%\sim 65\%$）**，造成① **相电动势波形严重畸变** 与 ② **过电压危及绝缘** $\implies$ **组式严禁用 Yy**（思考题 3-3 第一问两条缺一不可）。
   - **心式 / 芯式（三铁心柱磁路相关）**：三相三次谐波磁通同相零序，在铁心柱间互相顶住借不了道，只能**被迫穿出铁心经绝缘油、空气、油箱壁闭合**，路径磁阻极大 $\implies$ 谐波磁通被压得很小、电动势接近正弦；代价是**油箱壁等铸铁未叠片构件产生 9 倍频（$\propto f^2$）涡流局部过热，加速绝缘老化** $\implies$ **心式（芯式）可用 Yy，但容量必须限制在 $\le 1800\ \text{kVA}$、低电压配电变压器**（思考题 3-3 第二问）。
