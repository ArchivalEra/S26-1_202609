## 一、页内自推 $r_{be}$：高数一阶泰勒展开把曲线换成电阻

> **闭环说明**：`09-21` / `09-23` 笔记未给出 PN 结肖克莱指数公式，`11-09` 与 `11-11` 只口播报出 $r_{be}=200\,\Omega+(1+\beta)\frac{26\ \text{mV}}{I_E}$ 工程公式而未展开求导；以下用高数一阶微商就地闭环推导，并明示其与课堂口径一致。

1. **发射结电流-电压指数律与热电压 $U_T$**：PN 结正向导通时，发射极电流遵循指数规律（常温 $T=300\ \text{K}$ 下热电压 $U_T=\dfrac{kT}{q}\approx \mathbf{26\ \text{mV}}$，与 `11-09`/`11-11` 取值同源）：
   $$i_E = I_S\left(e^{u_{BE}/U_T}-1\right)\approx I_S e^{u_{BE}/U_T}$$
2. **在 Q 点作一阶泰勒展开（以直代曲）**：当小信号增量 $|\Delta u_{BE}|\ll U_T$ 时，在静态工作点 $Q(U_{BEQ},I_{EQ})$ 处做一阶导数近似：
   $$\frac{\Delta i_E}{\Delta u_{BE}} \approx \left.\frac{\mathrm d i_E}{\mathrm d u_{BE}}\right|_{Q} = \frac{I_S}{U_T}e^{U_{BEQ}/U_T} = \frac{I_{EQ}}{U_T} \implies r_e = \frac{\Delta u_{BE}}{\Delta i_E} = \frac{U_T}{I_{EQ}} = \frac{26\ \text{mV}}{I_{EQ}}$$
3. **从 $i_e$ 换回基极微变电阻 $r_{be}'$ 再加基区体电阻 $r_{bb'}$**：放大区动态关系 $\Delta i_E=(1+\beta)\Delta i_B$，故结电阻看进基极为 $(1+\beta)r_e$；串联不可忽略的基区半导体体电阻 $r_{bb'}$（本教材与 `11-09`/`11-11` 统一取 $r_{bb'}=200\ \Omega$），即得核心微变公式：
   $$r_{be} = r_{bb'} + (1+\beta)\frac{U_T}{I_{EQ}} \approx 200\ \Omega + (1+\beta)\frac{26\ \text{mV}}{I_{EQ}}$$

## 二、小信号分析三张纸：替换管子后全回第 1–4 章

按 [11-11 动态分析三步](../../电子技术/课堂笔记/11-11-共射放大电路与耦合.md#动态分析的三步-三张纸-一步都不能少)，只要先算出 Q 点与 $r_{be}$，非线性放大器立即彻底线性化：

1. **画交流通路**：所有**电容一律短路**（隔直电容、旁路电容全变导线）；**直流电源 $U_{CC}$ 对地短路**（视为交流零电位点）。
2. **微变模型替换 BJT**：B–E 间换电阻 $r_{be}$；C–E 间换**受控电流源 $\beta\dot I_b$**（参考方向由 C 指向 E，忽略极大的 $r_{ce}$）。
3. **退化为 Ch.1–4 含受控源直流/相量网络算三大指标**：
   - 电压放大倍数 $A_u=\dot U_o/\dot U_i$（若含信号源内阻 $R_S$，再用分压公式乘 $A_{us}=A_u\dfrac{R_i}{R_S+R_i}$）；
   - 输入电阻 $R_i=\dot U_i/\dot I_i$（不含 $R_S$，从输入端口往里看串联并联）；
   - 输出电阻 $R_o$：信号源置零（$u_s=0$，注意若发射极有未旁路电阻或为共集接法时，需用 Ch.4 外加电源法保留受控源，见 [11-11 输出电阻](../../电子技术/课堂笔记/11-11-共射放大电路与耦合.md#输出电阻-按端口定义求-结论是) 与 [共集三指标](../../电子技术/课堂笔记/11-11-共射放大电路与耦合.md#共集电极的动态三指标)）。

## 三、动态负载线、失真与共射/共集四组指标总表

### 1. 直流负载线 vs 交流负载线与动态失真

接入负载 $R_L$ 后，集电极交流负载变为 $R_L'=R_C\parallel R_L < R_C$：交流负载线过 Q 点且斜率 $-1/R_L'$ **比直流负载线更陡**（[11-11 交直流负载线](../../电子技术/课堂笔记/11-11-共射放大电路与耦合.md#图解法-直流负载线与交流负载线不是一条)）。因此动态最大不失真摆幅同时受限（$u_o$ 与 $i_C$ **反相**，见 [11-11 失真](../../电子技术/课堂笔记/11-11-共射放大电路与耦合.md#失真-与-的削平侧是反的)）：

- **饱和失真**（Q 点过高）：$i_C$ 撞顶上限、**$u_o$ 负半周被削平**（调大 $R_B$ 降 Q 点修复）；
- **截止失真**（Q 点过低）：$i_C$ 撞零截止、**$u_o$ 正半周被削平**（调小 $R_B$ 抬 Q 点修复）。

### 2. 共射 4 种接法与共集（射极输出器）核心指标

关键抓手只有一个：**发射极串联未旁路电阻时流过 $i_e=(1+\beta)i_b$，从基极往里看阻抗自动放大 $(1+\beta)$ 倍；反过来从发射极往基极回看阻抗自动缩小 $(1+\beta)$ 倍**：

| 组态与接法 | 电压放大倍数 $A_u$ | 输入电阻 $R_i$ | 输出电阻 $R_o$ |
| :--- | :--- | :--- | :--- |
| 固定偏置共射（发射极接地） | $-\beta\dfrac{R_C\parallel R_L}{r_{be}}$ | $R_B\parallel r_{be}$ | $R_C$ |
| 固定偏置共射（接未旁路 $R_E$） | $-\dfrac{\beta(R_C\parallel R_L)}{r_{be}+(1+\beta)R_E}$ | $R_B\parallel\big[r_{be}+(1+\beta)R_E\big]$ | $R_C$ |
| 分压偏置共射（$R_E$ 有旁路 $C_E$） | $-\beta\dfrac{R_C\parallel R_L}{r_{be}}$ | $R_{B1}\parallel R_{B2}\parallel r_{be}$ | $R_C$ |
| 分压偏置共射（$R_E$ 无旁路） | $-\dfrac{\beta(R_C\parallel R_L)}{r_{be}+(1+\beta)R_E}$ | $R_{B1}\parallel R_{B2}\parallel\big[r_{be}+(1+\beta)R_E\big]$ | $R_C$ |
| 共集电极（射极输出器，$R_L'=R_E\parallel R_L$） | $\dfrac{(1+\beta)R_L'}{r_{be}+(1+\beta)R_L'}<1$（同相） | $R_B\parallel\big[r_{be}+(1+\beta)R_L'\big]$（极大） | $R_E\parallel\dfrac{r_{be}+R_S\parallel R_B}{1+\beta}$（极小） |

- **真题实算（[2026-11-09 作业 习题 2.7](../../电子技术/作业/2026-11-09作业.md#2-习题-2-7)，Octave 复核）**：射极输出器 $U_{CC}=20\ \text{V}, R_B=30\ \text{k}\Omega, R_E=800\ \Omega, R_L=1.2\ \text{k}\Omega, r_{be}=0.45\ \text{k}\Omega, \beta=50$。
  - 直流 Q 点（$C_2$ 开路，**只用 $R_E=0.8\ \text{k}\Omega$**）：$I_B=\frac{20-0.7}{30+51\times 0.8}=\mathbf{0.273\ \text{mA}}$，$I_C=\mathbf{13.6\ \text{mA}}$（精确 $13.63\ \text{mA}$），$U_{CE}=20-13.9\times 0.8=\mathbf{8.88\ \text{V}}$；
  - 动态指标（$C_2$ 短路，**必用 $R_L'=R_E\parallel R_L=0.48\ \text{k}\Omega$**）：$R_i=30\parallel(0.45+51\times 0.48)=\mathbf{13.62\ \text{k}\Omega}$（若错用直流 $R_E$ 会虚高 28% 至 $17.4\ \text{k}\Omega$），$A_u=\frac{24.48}{24.93}=\mathbf{0.982}$（同相电压跟随，作缓冲级）。

## 四、多级阻容耦合、级间加载与频响边界

按 [11-16 级间加载](../../电子技术/课堂笔记/11-16-多级放大与差分电路.md#级间加载-第二级的输入电阻就是第一级的负载) 与 [总阻与只认一头](../../电子技术/课堂笔记/11-16-多级放大与差分电路.md#总输入电阻与总输出电阻-只认一头)：

1. **直流割开算、交流连起来算**：耦合电容隔直，各单级 Q 点互不牵连；交流下后级输入电阻 $R_{i2}$ 直接并联在第一级输出端充当第一级负载，即 **$R_{L1}' = R_{C1}\parallel R_{i2}$**（级间加载效应），总放大倍数连乘 $A_u = A_{u1}A_{u2}\cdots A_{un}$。
2. **总端口指标只认两头（唯一依赖顺序例外）**：总输入电阻 $R_i=R_{i1}$、总输出电阻 $R_o=R_{on}$（末级）；若第一级是**共集电极**，其 $R_{i1}$ 含 $R_{L1}'=R_{E1}\parallel R_{i2}$，必须**先算第二级 $R_{i2}$、再倒推第一级 $R_{i1}$**。
3. **频率特性一句话边界**（[11-16 三个频段](../../电子技术/课堂笔记/11-16-多级放大与差分电路.md#三个频段-谁短路-谁开路) 定性收口）：**低频段增益下降是因为大容量耦合/旁路电容的串联容抗分压，高频段增益下降是因为极间结电容与分布电容的并联容抗分流**（通频带按 $|A_u|\ge 0.707|A_{um}|$ 划定）。
