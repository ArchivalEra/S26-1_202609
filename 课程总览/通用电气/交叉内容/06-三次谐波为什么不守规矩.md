# 06-三次谐波为什么不守规矩

<figure class="fig"><img src="figures/fig-ge-06.svg" alt="基波三相箭头互差120度呈辐射状；三次谐波三相相角乘3变成360度完全重合" loading="lazy"><figcaption>基波与三次谐波的相位几何：基波三相箭头互差 120° 平衡抵消，三次谐波三相角度翻三倍变为 360° 完全同向重合</figcaption></figure>

## 一、角度乘三：三相箭头完全重合

在三相对称电网中，基波的三相电压与电流步调交错开来：A、B、C 三相依次相差 120°。如果画成平面的三支箭头，它们各自朝向不同的方向，彼此均匀叉开 120°，首尾相接恰好闭合抵消。

三次谐波的频率是基波的 3 倍。基波相差 120° 的相位差，到了三次谐波里就会放大 3 倍：

$$3 \times 120^\circ = 360^\circ$$

在圆周运动与旋转向量中，转过 360° 等价于转过 0°，回到出发点。

这意味着在任意同一个瞬间，B 相三次谐波滞后 A 相三次谐波 $360^\circ$（同相），C 相三次谐波滞后 A 相三次谐波 $720^\circ = 2 \times 360^\circ$（依然同相）。三相三次谐波不再像基波那样各自指着相差 120° 的三个方向，而是变成三支**方向完全一致、步调完全重合**的箭头。

## 二、同相意味着它属于零序

在对称分量法中，三相量如果大小相等、方向完全相同（三箭头重合齐步走），属于**零序分量**。

因此，**三次谐波属于零序**。

基波三相电流互差 120°，在没有中性线的星形（Y 接）接线节点处汇合时，因为彼此抵消，不需要中性线也能自成通路循环。

但三次谐波是零序分量，三相大小相等、方向一致。三个同方向的电流涌向中性点，如果不给它提供一条回流线路，它们就无处可去：
- **零序电流流不流，取决于有没有零序通路**。
- 如果没有中性线、也没有让它们顺着转圈的闭合回路，三次谐波电流受制于基尔霍夫电流定律，数值只能被硬生生卡成零。

不是三次谐波「特别坏」，是它「不走寻常路」，所以绕开了常规设计。常规设计都是按三相差 120°、首尾抵消的基波规律布置的，三次谐波却齐步同向走，把常规的设计假设全部避开。

## 三、零序没有通路会怎样：三道防线的由来

前面说「零序有没有通路决定三次谐波流不流」。把这句话往下推一步，就得到电机学那三条规矩：

- **零序有通路**（三角形接法的闭合回路、或带中性线的星形）⇒ 三次谐波电流能流 ⇒ 磁通保持正弦；
- **零序没通路** ⇒ 三次谐波电流被卡成零 ⇒ 磁通畸变成平顶波 ⇒ 感应出三次谐波电压。

所以设计时按「先给通路、再兜底」的顺序查三处，这就是教材里说的三道防线：

| 顺序 | 查什么 | 一句话判据 |
| :--- | :--- | :--- |
| 第一道 | 一次侧接线 | 三角形（D）自带环流、或星形带中性线（YN）——有通路 |
| 第二道 | 二次侧接线 | 一次侧没给通路时，二次侧能不能接替（d 或 Yyn） |
| 第三道 | 铁芯结构 | 前两道都失守时，心式铁芯能否把零序磁通挤到空气里抑制掉 |

**三道防线的完整判据与后果**（含组式变压器为什么严禁 Yy、三次谐波电压可达基波的多少）
