# 04 · 阻抗三角形

<figure class="fig"><img src="figures/fig-ge-04.svg" alt="阻抗三角形示意图：实部电阻R与虚部电抗X合成总阻抗Z" loading="lazy"><figcaption>阻抗三角形：底边电阻 $R$、对边电抗 $X$、斜边阻抗模 $|Z|$，三边单位全为 $\Omega$</figcaption></figure>

## 一、三件串联：总阻抗 $Z$ 的合成

电阻 $R$、电感 $L$、电容 $C$ 串联接在交流电源上，流过每个元件的电流相同。由前文可知各元件的阻抗分别为 $R$、$j\omega L$ 与 $\dfrac{1}{j\omega C}$。串联总阻抗直接相加：

$$Z = R + j\omega L + \frac{1}{j\omega C} = R + j\left(\omega L - \frac{1}{\omega C}\right) = R + jX$$

其中总电抗 $X$ 等于感抗与容抗之差：

$$X = X_L - X_C$$

- 感抗 $X_L = \omega L$
- 容抗 $X_C = \dfrac{1}{\omega C}$

## 二、勾股定理与反正切：阻抗三角形

在复平面上，阻抗 $Z = R + jX$ 构成一个直角三角形：

- **底边（实部）**：电阻 $R$
- **竖边（虚部）**：总电抗 $X$
- **斜边（模长）**：总阻抗的模 $|Z|$
- **夹角（阻抗角）**：$\varphi$

根据初中几何的勾股定理与三角函数定义：

$$|Z| = \sqrt{R^2 + X^2}$$

$$\varphi = \arctan\frac{X}{R}$$

特别强调几何单位：**三角形三个边的单位全都是 $\Omega$（欧姆）**。它表示电路对电流的阻碍能力，不是电压（$\mathrm{V}$），也不是电流（$\mathrm{A}$）。

## 三、电流多大、谁先谁后

总阻抗 $Z$ 决定了串联电路中的电流大小与相位关系：

1. **电流大小**：满足交流欧姆定律，由阻抗的模决定：
   $$I = \frac{U}{|Z|}$$
2. **相位超前与滞后**：由阻抗角 $\varphi$ 的正负决定：
   - 当 $\varphi > 0$（即 $X_L > X_C$，$X > 0$）时，电路呈**感性**，电压超前电流，**电流滞后**电压 $\varphi$；
   - 当 $\varphi < 0$（即 $X_L < X_C$，$X < 0$）时，电路呈**容性**，电流超前电压，**电流超前**电压 $|\varphi|$。

## 四、谐振：阻抗最小、电流最大

当感抗恰好抵消容抗时：

$$X = X_L - X_C = 0$$

此时电路发生串联谐振：

- 总阻抗模达到最小值：$|Z| = R$
- 阻抗角 $\varphi = 0^\circ$，电压与电流同相
- 在给定外加电压 $U$ 下，电路中的电流达到最大值：$I = \dfrac{U}{R}$

## 五、算例：初中直角三角形

设串联电路参数为 $R = 3\,\Omega$、$X = 4\,\Omega$（感抗比容抗大 $4\,\Omega$）：

1. **计算总阻抗的模**（勾股数 3-4-5）：
   $$|Z| = \sqrt{3^2 + 4^2} = 5\,\Omega$$
2. **计算阻抗角**：
   $$\varphi = \arctan\frac{4}{3} \approx 53.1^\circ$$

因为 $\varphi = 53.1^\circ > 0$，电路呈感性，电流滞后电压 $53.1^\circ$；若电源电压有效值为 $10\,\mathrm{V}$，则回路电流有效值为 $I = \dfrac{10}{5} = 2\,\mathrm{A}$。
