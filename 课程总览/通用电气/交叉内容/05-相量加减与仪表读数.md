## 一、同频相量加减铁律：乘除走极坐标，加减回直角坐标

由高数复数代数可知，两个极坐标复数 $\dot A_1=A_1\angle\psi_1$ 与 $\dot A_2=A_2\angle\psi_2$ 不能直接把模相加、把角相加（即 $|\dot A_1+\dot A_2|\neq A_1+A_2$，$\arg(\dot A_1+\dot A_2)\neq \psi_1+\psi_2$）。按 [11-09 笔记](../../电路原理/课堂笔记/11-09-相量运算与向量图.md#同频正弦量的相量加减-为什么可以这样算)，固定四步走：

1. **极坐标拆直角坐标**：$\dot A_k = A_k\cos\psi_k + j A_k\sin\psi_k = a_k + jb_k$；
2. **实虚各加各**：$\dot A = (a_1+a_2) + j(b_1+b_2)$（求差 $\dot A_1-\dot A_2$ 则作 $\dot A_1+(-\dot A_2)$，实虚部分别相减）；
3. **重算模与象限角**：$|\dot A|=\sqrt{(a_1+a_2)^2+(b_1+b_2)^2}$，按 `03` 篇四象限表定 $\psi$；
4. **图形校验（平行四边形定则）**：把 $\dot A_1,\dot A_2$ 从原点画出，邻边平行四边形对角线即为 $\dot A_1+\dot A_2$；做减法 $\dot A_1-\dot A_2$ 时将 $\dot A_2$ 反向旋转 $180^\circ$ 再合成。

## 二、为什么电压表与电流表读数不能直接加减

交流电压表与电流表测量的是周期交变信号的**有效值模长**（$U=|\dot U|$、$I=|\dot I|$），丢掉了相位角信息：

- **瞬时值** $u(t), i(t)$ 与**相量** $\dot U, \dot I$ 在同频条件下严格满足 KCL 和 KVL：$\sum \dot I_k = 0$、$\sum \dot U_k = 0$；
- **有效值** $U_k, I_k$ 是标量模长，一般**不满足** KCL/KVL，只能满足三角不等式 $\big||A_1|-|A_2|\big|\le |\dot A_1+\dot A_2|\le |A_1|+|A_2|$。

具体退化规律只需盯紧三个夹角（设两分相量夹角为 $\Delta\psi$）：

| 两分相量关系 | 元件属性判断 | 合成有效值公式 | 题库典型样题 |
| :--- | :--- | :--- | :--- |
| **同相（$\Delta\psi=0^\circ$）** | 两支路/元件性质完全相同（如同为纯电阻） | $A = A_1 + A_2$（唯一可直接相加） | [选 18](../../电路原理/作业/习题册第五章.md#选-18-图-5-7)：$3\ \text{A}+4\ \text{A}=7\ \text{A}\implies Z_2$ 为纯阻 |
| **正交（$\Delta\psi=\pm 90^\circ$）** | 纯电阻 $R$ 配纯电抗（$L$ 或 $C$） | $A = \sqrt{A_1^2 + A_2^2}$（勾股定理） | [选 3](../../电路原理/作业/习题册第五章.md#选-3-图-5-2)、[选 11](../../电路原理/作业/习题册第五章.md#选-11)、[选 26](../../电路原理/作业/习题册第五章.md#选-26-图-5-10) |
| **反相（$\Delta\psi=180^\circ$）** | 纯电感 $L$ 配纯电容 $C$ | $A = \lvert A_1 - A_2\rvert$（直接相减抵消） | [11-16 例题二](../../电路原理/课堂笔记/11-16-相量法解题与串并联.md#例题二-三只交流电压表测-串联各元件电压-求端口电压有效值)：$U_L,U_C$ 抵消 |

## 三、相量图参考量选法：串联找电流，并联找电压，混联从最远端倒推

画相量图前不要凭空乱画，先看电路结构选定唯一的「参考基准（固定放在 $0^\circ$ 水平右向）」：

1. **纯串联（[串联相量图](../../电路原理/课堂笔记/11-16-相量法解题与串并联.md#串联相量图与电压三角形)）**：各元件电流相同，选**电流 $\dot I$ 为参考**：$\dot U_R$ 与 $\dot I$ 同相（水平）、$\dot U_L$ 超前 $90^\circ$（竖直向上）、$\dot U_C$ 滞后 $90^\circ$（竖直向下），合成得总电压三角形 $U=\sqrt{U_R^2+(U_L-U_C)^2}$。
2. **纯并联（[并联相量图](../../电路原理/课堂笔记/11-16-相量法解题与串并联.md#并联相量图与电流三角形)）**：各支路电压相同，选**端口电压 $\dot U$ 为参考**：$\dot I_R$ 与 $\dot U$ 同相（水平）、$\dot I_C$ 超前 $90^\circ$（竖直向上）、$\dot I_L$ 滞后 $90^\circ$（竖直向下），合成得总电流三角形 $I=\sqrt{I_R^2+(I_C-I_L)^2}$。
3. **混联（先并后串，如 [计 10](../../电路原理/作业/习题册第五章.md#计-10-图-5-31)）**：若用总电源电压当基准往往算不出，必须**从并联子块电压 $\dot U_p$ 起步**！先用 $\dot U_p=U_p\angle 0^\circ$ 画出各并联支路电流并合成为干路电流 $\dot I$，再往回画干路阻抗压降 $R\dot I$ 与 $\dot U_p$ 相加得到电源总电压 $\dot U$。

## 四、真题演算（对齐《习题册第五章》）

1. **正交仪表三角形知二求一（选 3、选 11、选 26）**：
   - **选 3**（[习题册第五章#选-3-图-5-2](../../电路原理/作业/习题册第五章.md#选-3-图-5-2)）：$R$ 与 $C$ 并联，干路读数 $I=10\ \text{A}$、$R$ 支路 $I_1=6\ \text{A}$。因 $\dot I_C$ 超前 $\dot U$ $90^\circ$ 而 $\dot I_R$ 同相，二者正交 $\implies I_2=\sqrt{I^2-I_1^2}=\sqrt{10^2-6^2}=\mathbf{8\ \text{A}}$（不能错选 $10-6=4\ \text{A}$ 或加和 traps）。
   - **选 11**（[习题册第五章#选-11](../../电路原理/作业/习题册第五章.md#选-11)）：$R$ 与 $L$ 串联，总电压 $U=30\ \text{V}$、$U_L=18\ \text{V}$。正交得 $U_R=\sqrt{30^2-18^2}=\mathbf{24\ \text{V}}$。
   - **选 26**（[习题册第五章#选-26-图-5-10](../../电路原理/作业/习题册第五章.md#选-26-图-5-10)）：$R$ 串 $jX_L$，$U_R=3\ \text{V}$、$U_L=4\ \text{V}\implies U=\sqrt{3^2+4^2}=\mathbf{5\ \text{V}}$。
2. **有效值直接相加反推同相元件（选 18）**：
   - **选 18**（[习题册第五章#选-18-图-5-7](../../电路原理/作业/习题册第五章.md#选-18-图-5-7)）：两支路并联，$Z_1=R$ 支路 $A_1=3\ \text{A}$、$Z_2$ 支路 $A_2=4\ \text{A}$，干路读数恰好 $A_0=7\ \text{A}=3+4$。说明 $\dot I_2$ 与 $\dot I_1$ 相角差 $\Delta\psi=0^\circ$（同相），因此 $Z_2$ 只能也是**纯电阻**（若为电感或电容则会算出 $\sqrt{3^2+4^2}=5\ \text{A}$）。
3. **混联相量图参考量倒推（计 10）**：
   - **计 10**（[习题册第五章#计-10-图-5-31](../../电路原理/作业/习题册第五章.md#计-10-图-5-31)）：干路电阻 $R=5\ \Omega$ 串联并联块「$-jX_C$ 并（$R_2$ 串 $jX_L$）」，已知总电压有效值 $U=200\ \text{V}$、$I_1=10\ \text{A}$、$I_2=10\sqrt{2}\ \text{A}$、$R_2=X_L$，求 $I, X_C, X_L, R_2$。
   - **第一步定参考量**：设并联块电压 $\dot U_p=U_p\angle 0^\circ$ 为基准。
   - **第二步画并联电流**：容性支路超前 $90^\circ$，得 $\dot I_1=10\angle 90^\circ=j10\ \text{A}$；感性支路因 $R_2=X_L$，阻抗角 $\varphi_2=\arctan(X_L/R_2)=45^\circ$，电流滞后电压 $45^\circ$，得 $\dot I_2=10\sqrt{2}\angle-45^\circ=10-j10\ \text{A}$。
   - **第三步 KCL 合成干路电流**：
     $$\dot I=\dot I_1+\dot I_2=j10+(10-j10)=10+j0=\mathbf{10\angle 0^\circ\ \text{A}}$$
     恰与 $\dot U_p$ 同相（电路等效成纯阻串联，几何上两个虚部 $+j10$ 与 $-j10$ 恰好抵消）。
   - **第四步反推电压与参数**（Octave 复核 `I=10, Up=150, XC=15, R2=XL=7.5`）：干路电阻压降 $\dot U_R=I R=10\times 5=50\angle 0^\circ\ \text{V}$，因 $\dot U_R$ 与 $\dot U_p$ 同相 $\implies U_p=U-U_R=200-50=150\ \text{V}$。从而：
     $$X_C=\frac{U_p}{I_1}=\frac{150}{10}=\mathbf{15\ \Omega},\qquad |Z_2|=\frac{U_p}{I_2}=\frac{150}{10\sqrt{2}}\ \Omega \implies R_2=X_L=\frac{|Z_2|}{\sqrt{2}}=\mathbf{7.5\ \Omega}$$
