## 一、运放内部四级如何收束 `08–10`，以及为什么必须加深度负反馈

打开集成运放的三角形符号，内部恰是前 3 篇拼起来的四段电路（[11-18 运放内部](../../电子技术/课堂笔记/11-18-差分与功率放大电路.md#运放内部-输入级-中间级-输出级-偏置)）：

- **偏置电路（`08` 篇恒流源 Q 点）** $\to$ **输入级（`10` 篇带恒流源差分对）** $\to$ **中间级（`09` 篇共射有源负载高增益级）** $\to$ **输出级（`10` 篇互补对称/射极输出级）**。

因此典型运放开环指标呈现极端值：$A_{uo}\sim 10^5\sim 10^6$、开环输出电阻约 $100\ \Omega$、共模抑制比 $>100\ \text{dB}$；开环输入电阻 $r_i$ 在 `11-18` 课堂口述存在两处不同量级记录（前文提 **10 MΩ** 对应 $10\ \text{V}$ 下约 $1\ \mu\text{A}$，后文按 **$10^6\ \Omega$** 算得约 $10\ \mu\text{A}$，本篇并列保真、统称兆欧级）。

### 虚短的生死边界与闭环公式 $A_f = \dfrac{A}{1+AF}$ 页内自推

1. **为什么开环进不去线性区**：电压传输特性 $u_o=A_{uo}(u_+-u_-)$ 的线性区宽度只有 $\pm\dfrac{U_{OPP}}{A_{uo}}\sim\mu\text{V}$ 级，稍微有一点差值立刻撞向正负限饱和（非线性区）。在非线性区：**虚断仍成立（$i_+\approx i_-\approx 0$），但虚短（$u_+\approx u_-$）彻底失效！** 只有引入**深度负反馈**才能把工作点死死按在线性区内（[11-18 为什么线性区必须加负反馈](../../电子技术/课堂笔记/11-18-差分与功率放大电路.md#为什么线性区必须加负反馈)）。
2. **闭环放大倍数 $A_f$（页内代数闭环，补齐 `11-18` L433 缺失）**：
   从 [11-18 三个环节的三个式子](../../电子技术/课堂笔记/11-18-差分与功率放大电路.md#三个环节的三个式子) 出发：$X_o=AX_d$、$X_F=FX_o$、$X_d=X_i-X_F$。消去 $X_d$ 与 $X_F$：
   $$X_o = A(X_i - FX_o) \implies (1+AF)X_o = A X_i \implies A_f = \frac{X_o}{X_i} = \frac{A}{1+AF}$$
   - **$1+AF$ 称为反馈深度**：负反馈满足 $|1+AF|>1$（以降低增益换取放大倍数极其稳定）；
   - **深度负反馈条件 $|1+AF|\gg 1$**：$A_f \approx \dfrac{1}{F}$——闭环增益**与内部极不稳定的晶体管参数 $A$ 彻底脱钩，只由外部精密反馈电阻网 $F$ 决定**！这正是运放能用「虚短 + 虚断」两句小学四则运算写死增益的代数根源。

## 二、四组 8 维分类与双运放级联实操四步法（双锚定实操）

对两级运放级联电路（如 [习题 3.1](../../电子技术/作业/2026-11-18作业.md#2-习题-3-1)），**先守住一条前提**：各运放自身回接的反相电阻 $R_{F1},R_{F2}$ 是**级内局部负反馈**，判别时**只盯住从最终输出 $u_o$ 跨级回送到第一级输入端的反馈支路 $R_F$**，而且**绝不能凭「接在 `+` 端就是正反馈」这种单级速记去盲猜**！

结合 [11-18 反馈的分类](../../电子技术/课堂笔记/11-18-差分与功率放大电路.md#反馈的分类) 与 [2026-11-18 作业#1-依赖](../../电子技术/作业/2026-11-18作业.md#1-依赖) 的机械判别四步：

| 维度 | 机械判别动作（只看跨级 $R_F$ 支路） | 物理意义与阻抗验证 |
| :--- | :--- | :--- |
| **1. 直/交反馈** | 沿 $R_F$ 支路从 $u_o$ 走到第一级落点：全程只有电阻 $\implies$ **交直流反馈**；路上串有电容（如 $C_F$）$\implies$ **交流反馈**（直流断路） | 直流稳 Q 点，交流改善动态波形与增益稳定性 |
| **2. 正/负反馈（瞬时极性法）** | 令跨级 $R_F$ 回接的输入点 F 瞬时升高 $+\delta$，沿前向通路逐级数「反相次数」（运放进 `+` 同相不反、进 `−` 反相 1 次）：**反相总次数为奇** $\implies u_o$ 降拉回 F 点 $\implies$ **负反馈**；**为偶** $\implies$ **正反馈** | 净输入被削弱（$\lvert 1+AF\rvert>1$）为负，被增强则自激为正 |
| **3. 串/并反馈（同节点法）** | 对比信号源 $u_i$ 落点与跨级 $R_F$ 落点：**落在同一个输入节点**（按电流 KCL 相加减）$\implies$ **并联反馈**；**落在不同节点**（`+` 与 `−` 分开比较电压差）$\implies$ **串联反馈** | 串联负反馈**增大 $r_i$**；并联负反馈**减小 $r_i$** |
| **4. 电压/电流反馈（输出短路法）** | 假想令负载端输出电压对地短路（$u_o=0$）：跨级取样直接接在 $u_o$ 节点上，短路后反馈信号立刻归零 $\implies$ **电压反馈**；若取自串在负载上的采样电阻，短路 $u_o$ 后负载电流还在 $\implies$ **电流反馈** | 取样电压稳输出电压（**减小 $r_o$**）；取样电流稳输出电流（**增大 $r_o$**） |

| 判别维度 | 图 (a)（双端输入，纯阻跨级） | 图 (b)（单端反相，跨级串电容） | 图 (c)（上下翻转，纯阻跨级） |
| :--- | :--- | :--- | :--- |
| **直 / 交** | 跨级无电容 $\implies$ **交直流**（直流是、交流是） | 跨级串 **$C_F$ 隔直** $\implies$ **纯交流**（直流不是、交流是） | 跨级无电容 $\implies$ **交直流**（直流是、交流是） |
| **正 / 负** | F 在 `+`（同相 0 次）$\to A_2$ 进 `−`（反相 **1 次，奇**）$\implies$ **负反馈** | 前向通路反相次数同 (a)（**1 次，奇**）$\implies$ **负反馈** | 端子上下画反不改接线逻辑：$A_1$ 从 `+` 看同相、$A_2$ 仍从 `−` 看反相（**1 次，奇**）$\implies$ **负反馈** |

| **电 / 流** | $R_F$ 取自 $u_o$ 节点，令 $u_o=0$ 归零 $\implies$ **电压反馈** | 同 (a)，取自 $u_o$ 节点 $\implies$ **电压反馈** | 回线虽绕到图上方但仍取自 $u_o$ 节点 $\implies$ **电压反馈** |
