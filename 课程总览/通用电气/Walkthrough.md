# Walkthrough

> **这一页是什么**：把跨课接口按前置依赖串成可自学的顺序；每一步只打通一个具体卡点，需要某条定理或作业原题时直接链接回原课程锚点。

## 第一站 · 从网孔/节点方程到矩阵消元判解

**前置底座**：你已经在电路原理第 1–4 章会列网孔方程 $\mathbf{R}\boldsymbol{I}_M=\boldsymbol{U}_S$（[10-21 网孔电流法](../电路原理/课堂笔记/10-21-网孔电流法.md)）和节点方程 $\mathbf{G}\boldsymbol{V}=\boldsymbol{I}_S$（[10-26 节点电压法](../电路原理/课堂笔记/10-26-节点电压法.md)），现在需要接通《工程数学》[作业 5](../工程数学/作业/作业5.md) 的一般线性方程组判解。

- 先用增广矩阵 $A^*=(A\mid\boldsymbol{b})$ 做初等行变换化行阶梯形，由 $R(A)$ 与 $R(A^*)$ 判清无解、唯一解或无穷多解；
- 对电路法常见的 $n\times n$ 方阵情形，统一 $\det A\neq 0 \iff R(A)=n \iff A$ 可逆 $\iff$ 非齐次唯一解 $\boldsymbol{x}=A^{-1}\boldsymbol{b}$（且齐次仅有零解）；
- 拆清矩阵乘法写方程组为什么要求叠加时受控源置零、非独立电源不能拆开各算各的。

→ 展开：[01-电路矩阵与消元判解](./交叉内容/01-电路矩阵与消元判解.md)

## 第二站 · 从行最简形到基础解系与通解结构

**前置底座**：你已会按 [01-电路矩阵与消元判解](./交叉内容/01-电路矩阵与消元判解.md) 把方程组化到行阶梯形判清两秩，现在要解决《工程数学》[作业 5](../工程数学/作业/作业5.md) 里 $R(A)=r<n$ 时「无穷多解怎么写齐」，并把自由未知量接到电路参考节点与降秩情形。

- 继续消元到行最简形（主元列定主元、非主元列定自由未知量），说明为什么自由坐标逐个取单位向量必得 $n-r$ 个线性无关的基础解系向量；
- 对非齐次方程组 $A\boldsymbol{x}=\boldsymbol{b}$，一次化行最简形同时读出特解 $\boldsymbol{\eta}^*$（自由量取 $0$）与导出组基础解系（去常数列），分别代回各自方程组验残差；
- 对照未选参考节点的全节点导纳矩阵 $\mathbf{G}_{\text{全}}$ 降秩零空间 $c(1,1,\dots,1)^{\mathrm{T}}$、重选回路降秩，以及叠加定理保持同一线性算子 $A$ 的代数实质。

→ 展开：[02-行最简形与通解结构](./交叉内容/02-行最简形与通解结构.md)

## 第三站 · 从高数定积分与欧拉公式到正弦相量

**前置底座**：你已具备高数定积分与三角降幂公式，准备打通电路原理 [11-04 正弦量与相量](../电路原理/课堂笔记/11-04-正弦量与相量.md) 的第 5.1–5.2 节，并接轨 [习题册第五章](../电路原理/作业/习题册第五章.md) 选 1/15、填 7/10/13/19。

- 用热等效定积分自包含推出正弦有效值 $I=I_m/\sqrt2$；
- 用欧拉公式把 $e^{j\omega t}$ 剥离，讲清为什么同频才能写成复代数；
- 按「查同频→统正弦→正幅值→作差→折回 $\pm180^\circ$」求相位差，并用四象限定角与四层记号规范防错。

→ 展开：[03-正弦量、有效值与相量](./交叉内容/03-正弦量、有效值与相量.md)

## 第四站 · 从复指数求导到复阻抗、导纳与直流平移

**前置底座**：你已按 [03 篇](./交叉内容/03-正弦量、有效值与相量.md) 建立有效值相量，并会直流第 1–4 章网孔/节点/叠加/戴维南法，现打通 [11-11 相量复习与复阻抗](../电路原理/课堂笔记/11-11-相量复习与复阻抗.md) 与 [习题册第五章](../电路原理/作业/习题册第五章.md) 选 2/4/17/19、填 3/4、计 1/3/4。

- 由 $\frac{\mathrm d}{\mathrm dt}e^{j\omega t}=j\omega e^{j\omega t}$ 把微积分变乘 $j\omega$、除 $j\omega$；
- 在页内推完导纳实虚分解 $Y=G+jB$，纠偏 $G=R/(R^2+X^2)\neq 1/R$；
- 把串并联、分压分流、网孔、节点、同频叠加与含受控源外加电源法直接平移到相量域。

→ 展开：[04-微积分变乘除与复阻抗](./交叉内容/04-微积分变乘除与复阻抗.md)

## 第六站 · 交流功率全链与并联电容无功补偿

**前置底座**：在 [11-18 交流功率与功率因数](../电路原理/课堂笔记/11-18-交流功率与功率因数.md) 的基础上，一次打穿 [习题册第五章](../电路原理/作业/习题册第五章.md) 全部 16 道功率计算与选择填空。

- 从瞬时功率 $p=ui$ 积化和差积分出 $P=UI\cos\varphi$ 与 $Q=UI\sin\varphi$；
- 页内自包含补全视在功率 $S=UI=\sqrt{P^2+Q^2}$ 与共轭复功率 $\bar S=\dot U\dot I^*$（并证为何必须对电流取共轭）；
- 纠偏串联/并联口径矛盾，推出保持负载电压不变的并联电容补偿公式 $C=\dfrac{P(\tan\varphi_1-\tan\varphi_2)}{\omega U^2}$。

→ 展开：[06-交流功率与电容补偿](./交叉内容/06-交流功率与电容补偿.md)
