# 通用电气 · Walkthrough

> **这一页是什么**：把四门课的交叉点排成一条**能顺着走的路**。每一步只回答一个问题，
> 走完你就能把「一条正弦」一路推到「一个放大电路的放大倍数」。
>
> **它不是**任何一门课的复述。单门课的笔记在各自那里，这里只标「该去看哪个锚点」。

## 怎么用这一页

1. 从上往下走。**每一站都有「你现在应该能做什么」**——做不到就停在那里，看它链的篇。
2. 每站只有 2–4 句话。看不懂不是你的问题，是那一站的依赖没读——它会指出是哪一篇。
3. 走到最后一站，回头看 A 节：那时候整条链应该能自己重讲一遍。

## 起点：为什么会有这门课

四门课在同一个地方撞车：

- **电路原理**从 11-04 起把「正弦」变成「相量」，11-09 把 R、L、C 的电压电流关系
  写成乘法——但默认你懂复数和向量加法（那是**工程数学**的内容）；
- **电机学** 11-05 讲三相对称分量，默认你懂「互差 120°」和向量合成——同一套复数语言；
- **电子技术** 11-09 讲共射放大，把电路拆成「直流一条、交流一条」，默认你懂直流分析
  和「小信号」——那是电路原理的地盘。

三处用的是同一个工具：**把转圈的箭头写成复数**。这门课就讲这一件事。

## 第一站 · 一条正弦能被三个数说清

**你现在应该能做什么**：看到 `u = 311 sin(314t + 0°)`，说出它三个数字各管什么。

| 数字 | 名字 | 管什么 |
| :--- | :--- | :--- |
| 311 | 幅值 $U_m$ | 最高冲到多少 |
| 314 | 角频率 $\omega$ | 一秒转多少弧度（50 Hz 对应 314） |
| 0° | 初相位 $\psi$ | 从哪儿起步 |

工程上说的「220 V」不是幅值，是**有效值**：$U=U_m/\sqrt2=311/\sqrt2\approx220$ V。
**日常说的电压电流都是有效值**，除非明说是幅值。

→ 展开：[01 正弦量的三张脸](./交叉内容/01-正弦量的三张脸.md)

## 第二站 · 同一个东西还有两张脸

**你现在应该能做什么**：把 `u = 311 sin(314t + 0°)` 写成一个**相量**，并说清它和复数是什么关系。

一张图三栏——波形、转动的箭头、复平面上的一支箭头——指的是同一个东西。
写作 $\dot U = 220\angle 0^\circ$ V：**模取有效值，角取初相位**。

相量**不等于**正弦量，它们是**一一对应**：就像一个人的照片不是本人，但看照片就知道是谁。

→ 展开：[01 正弦量的三张脸](./交叉内容/01-正弦量的三张脸.md)

## 第三站 · 两个正弦相加，不用三角公式

**你现在应该能做什么**：把两个同频正弦相加，走「化代数 → 实加实虚加虚 → 化回极坐标」三步。

以前：$\sin A+\sin B$ 要背和差化积。
现在：两个相量在复平面上**首尾相接**，合力就是和；代数上就是分别加实部、加虚部。

**前提**：必须**同频**。不同频的两个相量不能画在一张图上——它们的夹角一直在变。

→ 展开：[02 相量加减为什么变简单](./交叉内容/02-相量加减为什么变简单.md)

## 第四站 · 微积分变成乘除法

**你现在应该能做什么**：说出 L 和 C 的电压电流关系，并解释「为什么不用解微分方程了」。

时域里电感是 $u=L\dfrac{di}{dt}$（要会求导），电容是 $i=C\dfrac{du}{dt}$。
换成相量以后：

$$\dot U=j\omega L\,\dot I,\qquad \dot I=j\omega C\,\dot U$$

**求导变成了乘一个 $j\omega$**。这就是这一整门课的技术核心：微积分在相量世界里是乘法。

→ 展开：[03 微积分变成乘除法](./交叉内容/03-微积分变成乘除法.md)

## 第五站 · 三件串起来叫阻抗

**你现在应该能做什么**：给一个 R-L-C 串联电路，一次算出电流的大小和相位。

$$Z=R+j\omega L+\frac{1}{j\omega C}=R+jX,\qquad |Z|=\sqrt{R^2+X^2},\qquad \varphi=\arctan\frac{X}{R}$$

$Z$ 是复数，它的**模**决定电流多大（$I=U/|Z|$）、**角**决定电流超前还是滞后。
三角形三个边**单位都是 Ω**——这条最容易画错。

→ 展开：[04 阻抗三角形](./交叉内容/04-阻抗三角形.md)

## 第六站 · 三根线互差 120°，还是一回事

**你现在应该能做什么**：说出正序、负序、零序各是什么，并知道「任一组不对称三相能拆成三组对称的」。

电机学 11-05 送的对称分量法，用的就是你第五站已经会的向量加法：
互差 120° 的三支箭头，乘上 $a=e^{j120°}$ 就是转一格。

→ 展开：[05 三相对称分量](./交叉内容/05-三相对称分量.md)

## 第七站 · 三次谐波为什么不守规矩

**你现在应该能做什么**：解释「3×120°=360°」为什么让三次谐波变成零序。

基波的三相相差 120°，画出来是三支分开的箭头；三次谐波相差 **360°**，画出来是
**三支完全重合**——这就是零序。所以「零序有没有通路」决定三次谐波流不流。

这也是电机学里「三次谐波三道防线」的物理来源。

→ 展开：[06 三次谐波为什么不守规矩](./交叉内容/06-三次谐波为什么不守规矩.md)

## 第八站 · 一个放大电路，拆成两半算

**你现在应该能做什么**：把一个共射放大电路拆成「直流通路算工作点」「微变等效算放大倍数」两半。

- **大写**（$I_B$、$I_C$、$U_{CE}$）算**直流工作点**：电容当断开，电感当短路；
- **小写**（$i_b$、$i_c$、$u_{ce}$）算**交流放大**：把三极管换成一个电阻 $r_{be}$
  加一个受控电流源 $\beta i_b$。

**为什么能这样拆**：因为交流小信号在相量世界里是线性运算——第七站之前那套工具直接搬过来用。

→ 展开：[07 大写的算工作点，小写的算放大](./交叉内容/07-大写算工作点小写算放大.md)

## 知识终点

走完这一页，你应该能独立做到：

1. **一条正弦 ↔ 一个相量 ↔ 一个复数**，三向互转，并说清模与角各取什么；
2. **两个同频正弦相加**，不用三角公式，走代数相加再化回极坐标；
3. 说出**求导在相量世界里是乘 $j\omega$**，并据此写出 L、C 的相量伏安关系；
4. 给一个 R-L-C 串联电路，用 **$|Z|$ 与 $\varphi$** 一次算出电流大小与相位；
5. 说出**正序/负序/零序**各是什么，并把一组不对称三相拆成三组对称的；
6. 解释**三次谐波为什么是零序**（3×120°=360°）；
7. 把共射放大电路**拆成直流通路与微变等效两半**，各算一半。
