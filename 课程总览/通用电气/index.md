# 通用电气

[返回课程总索引](../index.md)

## 这门课是什么

**不按教材走。** 这是一门**交叉课**：电路原理、电子技术、电机学、工程数学四门课在
「正弦量 / 相量 / 复数」这一点上汇到了一处，而这四门各自的教材都默认你已经在别的课上
学会了另一门。站长 11-04 与 11-09 的电路原理、11-09 的电子技术都没上，只看单门课的
笔记接不上——所以这里把**交叉处**单独拆出来讲一遍。

- **读者定位**：初中生的数学水平能跟上。不假设你懂微积分、不假设你懂三相电机。
- **写作口径**：极简练。一个概念只给「它解决什么问题 + 怎么用 + 一个例子」，不铺陈。
- **不做的事**：不复述任何单门课的教材体系，不替代那四门课的笔记与作业页。

## 为什么叫这个名字

「通用电气」是公司名（General Electric），这里借它做**双关**：这些内容对四门课都通用。
站长为这门课指定了这个名字，不是笔误。

## 资料实况

本课只有两类资料：**Walkthrough 一页**与**交叉内容栏目**（含 `交叉内容/figures/` 的概念图，七篇已入库）。不建作业、教材解析、课堂笔记、
原始资料四类——它不从属于任何一门教材，也没有自己的课堂。
