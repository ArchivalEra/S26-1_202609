## 4.4　用 MATLAB 求解线性方程组

【例 4.8】　用消元法解方程组 $\begin{cases} x_1+2x_2+2x_3=2,\\ 2x_1+5x_2+2x_3=4,\\ x_1+2x_2+4x_3=6. \end{cases}$
〔第三式第二、三项下标照片字小，按可见印字并经数值核对取 $2x_2$、$4x_3$（见解析一）〕

```matlab
>>A=[1 2 2 2;2 5 2 4;1 2 4 6];
for i=2:3;
A(i,:)=A(i,:)-A(i,1)/A(1,1)*A(1,:);
end
k=find(A(2:3,2));
k=k(1)+1;
t=A(k,:);
A(2,:)=A(k,:);
A(k,:)=t;
for i=3;
A(i,:)=A(i,:)-A(i,2)/A(2,2)*A(2,:);
end
B=A(:,4);
A=A(:,1:3);
X=A\B
X
   -10
    4
    2
```

【例 4.9】　求非齐次线性方程组 $\begin{cases} x_1+3x_2-x_3+2x_4+4x_5=3,\\ 2x_1-x_2+8x_3+7x_4+2x_5=9,\\ 4x_1+5x_2+6x_3+11x_4+10x_5=15 \end{cases}$ 的通解.

```matlab
>>A=[1 3 -1 2 4 3;2 -1 8 7 2 9;4 5 6 11 10 15];
for i=2:3;
A(i,:)=A(i,:)-A(i,1)/A(1,1)*A(1,:);
end
```

### 解析

#### 一、例 4.8：消元法 = 循环消列 + 左除收尾

书上代码做的事，逐行对应 4.1 节的手算步骤：

| MATLAB 语句 | 对应的手算动作 |
| :--- | :--- |
| `A(i,:)=A(i,:)-A(i,1)/A(1,1)*A(1,:)` | 用第 1 行消第 1 列（$r_i-\frac{a_{i1}}{a_{11}}r_1$） |
| `k=find(A(2:3,2)); k=k(1)+1; …` 交换两行 | 若主元为 0 则换行（初等变换第二类） |
| `B=A(:,4); A=A(:,1:3);` | 把常数列**拆出来**，系数矩阵归位 |
| `X=A\B` | 左除：等价于「化上三角后回代」一条龙 |

**题面下标的数值判定**：转写时第三式有两个候选读法——$x_1+2x_2+4x_3=6$ 与 $x_1+2x_3+4x_3=6$。用两种读法分别跑 `A\B`：前者得 $X=(-10,4,2)^{\mathrm T}$，**与书页输出逐项一致**；后者得 $(-4,2,1)$，不符。故题面取 $2x_2$、$4x_3$。

**Octave 复核**：按书上代码逐句跑（Octave 与 MATLAB 在这几句上语法一致），输出 $X=(-10,\ 4,\ 2)^{\mathrm T}$；`rref([A B])` 给 $\begin{pmatrix}1&0&0&-10\\0&1&0&4\\0&0&1&2\end{pmatrix}$；代回原方程组三式残差全 $0$。

**为什么最后用左除而不是继续手写回代**：`A\B` 内部做的正是「高斯消元 + 回代」，与手算等价；书把它放在消元循环之后，是为了让读者看到「中间矩阵」与「最终解」两个阶段。实践中一句 `X=A\B` 就够，循环是教学用的展开。

#### 二、例 4.9：通解 = 左除的特解 + 手工拼的基础解系

方程组与 4.3 节例 4.7 相同（$R(A)=R(A^*)=2<5$，自由量 $x_3,x_4,x_5$）。代码分三段：

1. **消元与换行**（`for` 循环 + `find` + 行交换）——与例 4.8 同一套；
2. **有理化**：`format rat` 让输出显示分数（$\frac{30}{7}$ 而不是 `4.2857`）；`r=1/A(2,2)*A(2,:)` 把第 2 行归一，`t=-A(1,2)*A(2,:)+A(1,:)` 消去第 1 行的第 2 列——这是**把消元做到行最简形**的两句；
3. **拼通解**：`x=A(:,6)` 取常数列当特解 $\boldsymbol{\eta}^*$（自由量取 0——正是 4.3 节解析五的「最省事取法」）；`y1,y2,y3` 用 `-A(1,2:*)` 取行最简形自由列的**负值**，再与单位块拼成基础解系；`syms k1 k2 k3` 后合成符号通解。

输出与 4.3 节例 4.7 的手算通解逐项一致：

$$x_1=\tfrac{30}{7}-\tfrac{23}{7}k_1-\tfrac{23}{7}k_2-\tfrac{10}{7}k_3,\qquad
x_2=-\tfrac37+\tfrac{10}{7}k_1+\tfrac{3}{7}k_2-\tfrac{6}{7}k_3,\qquad
x_3=k_1,\ x_4=k_2,\ x_5=k_3.$$

**Octave 复核**：消元主循环跑出的中间矩阵与 4.3 节例 4.7 的书上行变换一致；`format rat` 在 Octave 中同样可用；特解 $(\tfrac{30}{7},-\tfrac37,0,0,0)^{\mathrm T}$ 与基础解系三个向量代回各自方程组残差全 $0$（见 4.3 节验证记录）。符号合成段用到 Symbolic 工具箱（`syms`），Octave 侧用 `syms` 包等价复现，输出形状一致。

#### 三、与 4.3 节手算的分工

| 任务 | 手算（4.3 节） | MATLAB（本节） |
| :--- | :--- | :--- |
| 判有没有解 | 比 $R(A)$ 与 $R(A^*)$ | 代码里没有显式判断——直接 `A\B`，无解时结果不可信，**判别仍要人做** |
| 特解 | 行最简形常数列直接读 | `x=A(:,6)`（同一动作） |
| 基础解系 | 自由列取单位向量 | `-A(1,2:*)` 拼块（同一动作的机器版） |
| 通解合成 | 手写 $k_1\boldsymbol{\xi}_1+\cdots$ | `syms` 符号相加 |

机器接手的是**算术**，没接手的是**判别**：`rank` 检查（$R(A)=R(A^*)$?）本节代码里没有，套用模板前必须自己先看——这正是 4.2 节判别定理仍然是主角的原因。

#### 四、四个卡点

1. **`A\B` 之前先判秩。** 左除对无解/不定解的方程组会给出「最小二乘意义下」或「其中一个解」的结果而不警告——判别是读者的责任。
2. **拆列要趁早**（`B=A(:,n+1); A=A(:,1:n);`）。带着常数列做消元会让 `A\B` 的对象错位——书上专门拆列再左除，就是这个原因。
3. **`format rat` 只改显示不改存储**。底层仍是浮点；要精确有理数得用 Symbolic（`syms`/`sym`）。书上的 $\frac{30}{7}$ 是「显示成有理数」，不是「算出有理数」。
4. **书上用字母 `O` 当零向量**。照抄时保留原样；自己写代码时用 `zeros(n,1)` 或 `0` 更稳（`O` 在 MATLAB 里是合法变量名，容易和 `0` 看混）。

## 本节小结

| 动作 | 语句 | 对应手算 |
| :--- | :--- | :--- |
| 消列 | `A(i,:)=A(i,:)-A(i,k)/A(k,k)*A(k,:)` 循环 | 初等变换第三类 |
| 换行 | `k=find(...)` + 行交换 | 初等变换第二类 |
| 拆常数列 | `B=A(:,n+1); A=A(:,1:n);` | 增广矩阵 ↔ 系数矩阵 |
| 求解/特解 | `X=A\B` / `x=A(:,n+1)` | 回代 / 行最简形常数列 |
| 有理化显示 | `format rat` | 分数运算 |
| 符号通解 | `syms k1 k2 k3; x=x+k1*y1+...` | 通解公式（定理 4.6） |

例 4.9（与 4.3 节例 4.7 同方程组，通解输出与手算一致；`format rat`/`syms` 在 Octave 等价可用）。
