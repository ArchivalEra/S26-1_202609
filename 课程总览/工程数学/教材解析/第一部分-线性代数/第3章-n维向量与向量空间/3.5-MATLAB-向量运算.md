## 3.5　用 MATLAB 进行向量运算

在 MATLAB 中可以把向量看作是特殊的矩阵，其中行向量相当于行矩阵，列向量相当于列矩阵，因此，有关向量的线性运算可以看成矩阵的线性运算．

向量组的求法等价于对应矩阵的秩的求法，向量的输入可当作 $1\times n$ 矩阵一样输入，也常采用":"和函数 linspace、logspace 两种输入方式，它们的用法可以从下面的例子知道．

**【例 3.15】**（从 1 到 5 公差为 1(可缺省)的等差数列）

```
>>a=1:5
a =

    1  2  3  4  5
```

**【例 3.16】**（从 1 到 7 公差为 2 的等差数列，如果输入 $b=1:2:8$，得到同样结果）

```
>>b=1:2:7
b =

    1  3  5  7
```

**【例 3.17】**（从 6 到 $-6$ 公差为 $-3$ 的等差数列）

```
>>c=6:-3:-6
c =

    6  3  0  -3  -6
```

**【例 3.18】**（从 0 到 1 共 9 个数值的等差数列）

```
>>linspace(0,1,9)
ans =

    0  0.1250  0.2500  0.3750  0.5000  0.6250  0.7500  0.8750
    1.0000
```

函数 `linspace(a,b,n)` 生成从 $a$ 到 $b$ 共 $n$ 个数值的等差数列，公差不必给出．与它相仿的是函数 `logspace(a,b,n)`，生成从 $10^a$ 到 $10^b$ 共 $n$ 个数值的等比数组．

**【例 3.19】** 4 等分 $\pi$（MATLAB 中 $\pi$ 的符号是 pi）的数组可以用以下两种方式输入：

```
>>x=0:pi/4:pi
```

### 解析

#### 三种建向量的方式，各自适合什么

| 写法 | 生成什么 | 什么时候用 |
| :--- | :--- | :--- |
| `a:step:b` | 从 a 到 b，步长 step（缺省为 1） | **等差数列**，尤其整数序列 |
| `linspace(a,b,n)` | 从 a 到 b 共 n 个点（**两端都含**） | 需要「恰好 n 个点」，不想算步长 |
| `logspace(a,b,n)` | 从 $10^a$ 到 $10^b$ 共 n 个点（等比） | 需要**等比**数列（数量级跨度大时） |

**`a:step:b` 的一个坑**（例 3.16 特意点出）：`1:2:7` 与 `1:2:8` 都给 `1 3 5 7`。
因为步长 2 从 1 出发只到 7，**8 超了就不进去**，不会因为写了 8 就补一个。所以：
**终点只是「上界」，不是「保证取到」**。要保证取到终点，用 `linspace`。

**`linspace` 的第三个参数是「个数」不是「步长」**。例 3.18 里 `linspace(0,1,9)` 给 9 个点，
步长自动算成 $1/8=0.125$。这个位数容易记混——`linspace(a,b,n)` 里 $n$ 是**点数**。

**`logspace` 的底是 10**：`logspace(a,b,n)` 生成 $10^{a}, 10^{a+\Delta}, \dots, 10^{b}$，
相邻比值相同。书上只给了定义没给例子，用到时按定义算即可。

#### 本节真正要带走的三条 MATLAB 命令

本节例子只演示了「建向量」。但前四节的算法怎么落到 MATLAB？三条命令：

| 数学动作 | MATLAB |
| :--- | :--- |
| 向量组的秩 | `rank(A)`（A 的**列**向量组的秩） |
| 化行最简形（读极大无关组） | `rref(A)` |
| 解 $AX=B$（求坐标 / 求表示系数） | `X = A \ B` |

**这正好对应 3.3、3.4 两节的两个核心动作**：

- 3.3 求秩与极大无关组：`[R, jb] = rref(A)`，`R` 是秩，`jb` 是主元列号（对应极大无关组）
- 3.4 求坐标：`X = A \ B`

书上本节没写这三条（只写了怎么建向量），但它们是这章算法在 MATLAB 里的直接对应，
**考试若考「用 MATLAB 求秩/求坐标」，用的是这三条而不是本节例子**。

#### 一个对照：书上的例子 vs 手算

例 3.15–3.19 全是「输入什么、输出什么」的演示，没有计算难度。
它们的价值只在**记住写法**：

- 行向量用空格或逗号分隔：`[1 2 3]` 或 `[1,2,3]`
- 列向量用分号分隔：`[1;2;3]`
- 转置用 `'`：`[1 2 3]'` 就是列向量
- 冒号表达式生成的**默认是行向量**

**这与 3.1 节那个「行向量 ≠ 列向量」的区分直接相关**：MATLAB 里搞错行/列，
后续矩阵乘法会直接报错（`3×1` 乘 `3×1` 不合法）。所以建向量时就要想清楚方向。

## 本节小结

| 要做什么 | 写法 |
| :--- | :--- |
| 等差数列（整数） | `a:step:b`，**终点是上界、不保证取到** |
| 恰好 n 个点的等距数组 | `linspace(a,b,n)`，n 是**点数**、两端都含 |
| 等比数组 | `logspace(a,b,n)`，底为 10 |
| 行/列向量 | `[1 2 3]` / `[1;2;3]`（或 `[1 2 3]'`） |
| 求秩 | `rank(A)` |
| 行最简形 + 主元列 | `[R, jb] = rref(A)` |
| 解矩阵方程 $AX=B$ | `X = A \ B` |
