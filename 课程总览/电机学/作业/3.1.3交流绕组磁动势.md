## 2. 判断题（第 1–5 题）

### 第 1 题

三相对称绕组通入三相对称电流产生圆形旋转磁动势，其转向为由产生磁势的电流的超前相转向滞后相。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  哪一相电流**先达到正最大值**，合成磁动势峰值那一刻就正对哪一相的绕组轴线——因此空间移动方向就是时间上先达峰的相 $\to$ 后达峰的相。
- 完整解答
  正确。设空间互差 $120^\circ$ 电角度的 A、B、C 三相绕组通入 $i_A$ 超前 $i_B$ $120^\circ$、$i_B$ 超前 $i_C$ $120^\circ$ 的三相对称电流，则合成基波旋转磁动势为：
  $$f_1(\theta, t) = \frac{3}{2}F_{\Phi 1}\cos(\omega t - \theta)$$
  当 $\omega t = 0$（A 相电流达正向最大）时，合成波峰值落在 $\theta = 0$（A 相轴线）；当 $\omega t = 120^\circ$（B 相电流达正向最大）时，峰值移至 $\theta = 120^\circ$（B 相轴线）；依此类推转至 C 相。可见旋转磁动势总是**由电流超前相转向电流滞后相**（调换任意两相接线即可反转转向）。

  **答案：对（A）**（平台实测得分：20/20 分，作答 `对`）
- 复盘 :-
  - **快速口诀**：「谁先到最大，磁极就先指谁」$\implies$ **超前相 $\to$ 滞后相**。
:::

### 第 2 题

若绕组极对数为 $p$，则基波的极对数为 $p$，$\nu$ 次谐波极对数为 $p/\nu$。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  空间 $\nu$ 次谐波的意思是在**基波一对极（$2\tau$）内完整重复 $\nu$ 个周期**：极对数应该变多（$\nu p$）还是变少（$p/\nu$）？
- 完整解答
  错误。气隙空间 $\nu$ 次谐波磁动势在基波的一对极距 $2\tau$ 内变化 $\nu$ 个空间正弦周期，即其极距缩小为 $\tau_\nu = \tau/\nu$，在整个圆周上形成的磁极对数为：
  $$p_\nu = \nu p$$
  而非 $p/\nu$（例如 $p=2$ 的电机，5 次谐波的极对数为 $2\times 5 = 10$，极数翻 5 倍而不是缩小为 $2/5$）。同步转速相应为 $n_\nu = n_1/\nu$，与 $p/\nu$ 混淆容易把乘除方向记反。

  **答案：错（B）**（平台实测得分：20/20 分，作答 `错`）
- 复盘 :-
  - **量纲直觉**：谐波次数 $\nu$ 越大，空间波形振荡越密，对应的磁极对数 $p_\nu = \nu p$ 越多、转速 $n_\nu = n_1/\nu$ 越慢。
:::

### 第 3 题

磁动势幅值取决于槽内导体电流的大小和方向，与线圈连接次序无关，所以短距线圈组可等效为整距线圈组磁动势。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  对照 11-19 课堂「磁动势与绕组型式无关（革命不分先后）」一节：气隙磁动势只认各槽导体里的电流，单层等元件与双层短距均可通过重排配对等效为整距线圈组来计算磁动势。
- 完整解答
  正确。磁动势沿闭合磁路累加，气隙磁动势的分布与幅值**仅取决于每个定子槽内有效边导体电流的大小与流向**，而与端部线圈的连接次序（单层等元件式、交叉式、同心式或双层短距等）无关：
  - 对单层各类绕组（无论采用何种端部跨接次序），重配槽内正负导体即可直接等同整距线圈组磁动势；
  - 对双层短距线圈组，亦可将上层有效边与下层有效边分别看作两套相互错开短距角的**整距线圈组**磁动势进行等效叠加（因此幅值在叠加后乘以 $k_{y1}$）。

  （注：盲测核验曾严格指出双层短距单组叠加后需乘短距因数 $k_{y1}<1$、不可直接按单个未折减整距线圈组代值；本题按教材「槽电流决定论 + 拆为整距线圈组等效计算」口径命题，平台实测作答 `对` 获满分。）

  **答案：对（A）**（平台实测得分：20/20 分，作答 `对`）
- 复盘 :-
  - **两句不要混**：**概念层面**「短距可按两套错位整距线圈组等效分析，且连接次序不影响槽电流贡献」判**对**；**数值计算层面**求双层短距基波幅值时，不能忘掉短距角错位叠加产生的**短距因数 $k_{y1}$**。
:::

### 第 4 题

一个在空间按正弦波分布随时间按正弦规律变化的脉振磁动势，可分解为两个旋转磁动势分量，每个旋转磁动势的转速相等、转向相反，旋转磁动势的振幅同脉振磁动势的振幅。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  默写三角积化和差恒等式 $\cos\omega t\cos\theta = \frac{1}{2}\cos(\omega t-\theta) + \frac{1}{2}\cos(\omega t+\theta)$，盯住前面的系数 $\frac{1}{2}$！
- 完整解答
  错误。将空间按正弦分布、时间按正弦脉振的基波磁动势展开：
  $$f_1(x, t) = F_{\Phi 1}\cos\omega t\cos\frac{\pi}{\tau}x = \frac{1}{2}F_{\Phi 1}\cos\!\left(\omega t - \frac{\pi}{\tau}x\right) + \frac{1}{2}F_{\Phi 1}\cos\!\left(\omega t + \frac{\pi}{\tau}x\right)$$
  分解出的两个旋转磁动势虽然转速相等（$n_1 = 60f/p$）、转向相反（分别沿 $+x$ 与 $-x$ 行进），但**每个旋转磁动势的振幅均为原脉振磁动势振幅的一半（$\frac{1}{2}F_{\Phi 1}$）**，而非「同脉振磁动势的振幅」。

  **答案：错（B）**（平台实测得分：20/20 分，作答 `错`）
- 复盘 :-
  - **关键数字链**：单个脉振波振幅为 $F_{\Phi 1}$ $\to$ 拆成正反两个各占 **$\frac{1}{2}F_{\Phi 1}$** 的旋转波 $\to$ 三相合成时反向波相消、三个正向 $\frac{1}{2}F_{\Phi 1}$ 叠加，刚好得到 **$\frac{3}{2}F_{\Phi 1}$**。
:::

### 第 5 题

单相绕组的脉振磁动势特点是在空间位置固定，而大小和极性随电流交变。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  写出时空分离函数 $f(x,t) = F_{\Phi 1}\cos\omega t \cdot \cos(\frac{\pi}{\tau}x)$：空间位置坐标由谁定、幅度与正负号由谁定？
- 完整解答
  正确。单相绕组各次谐波磁动势均可写为时间因子与空间因子的乘积形式 $f_\nu(x,t) = F_{\Phi\nu}\cos(\omega t)\cos\left(\nu\frac{\pi}{\tau}x\right)$：空间轴线（波腹与过零点位置）完全固定在单相绕组自身轴线上、原地不移动；而各点磁动势的幅值大小及 N/S 极性则随时间因子 $\cos\omega t$（即绕组交流电流的正负交变）在原地脉振。

  **答案：对（A）**（平台实测得分：20/20 分，作答 `对`）
- 复盘 :-
  - **单相电机为什么没有起动转矩**（延伸理解）：正因为单相脉振波只在原地脉振、分解出的正反两个旋转波等大反向，静止时正反转矩抵消为零，必须靠电容分相或罩极打破对称才能自起动。
:::
