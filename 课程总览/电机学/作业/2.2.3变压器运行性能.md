| 第 2 题 | **分接开关调压**：$U_2=U_1\cdot N_2/N_1$；一次侧接电网、二次绕组绕死 ⇒ 能动的只有 $N_1$；**抽头做在高压侧**（电流小、触点小、电弧好灭）。$U_2$ 与 $N_1$ 成反比 | 见下「§2 补充：分接开关」 |

### 补充：分接开关为什么改的是一次匝数

电压比 $U_1/U_2=N_1/N_2$，反解 $U_2=U_1\cdot N_2/N_1$。

- $U_1$ 由电网决定，改不了；
- 二次绕组在运行中已经绕死，$N_2$ 也改不了（抽头做在高压侧 ⇒ 现场唯一可动的就是 $N_1$）；
- **分接开关的抽头做在一次（高压）绕组上**，只能改变接入的 $N_1$。

放在高压侧是工程选择：那里电流小，触点截面可以很小、引线好做、切换时电弧容易熄灭；
放在低压侧要承受大电流，成本与可靠性都不划算。

因为 $U_2$ 与 $N_1$ 成**反比**，二次电压偏低时要**减小 $N_1$**。

## 3. 单选题

### 第 1 题

当（　）时，变压器运行效率最高。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | D | $\beta^2 P_{kN}=P_0$ |
| B | B | $\beta^{2}P_0=P_{kN}$ |
| C | C | $\beta P_0=P_{kN}$ |
| D | A | $\beta P_{kN}=P_0$ |

:::collapse 提示
写出效率公式 $\eta=\dfrac{P_2}{P_2+p_0+\beta^2p_{kN}}$，把 $p_0$、$p_{kN}$ 看成定值，$\beta$ 看成变量，对 $\beta$ 求极值：令分子分母同除 $\beta$（$\beta>0$），分母变成 $\beta S_N\cos\varphi_2+\dfrac{p_0}{\beta}+p_{kN}$，再对 $\dfrac{p_0}{\beta}+p_{kN}\beta$ 用均值不等式。
:::

:::collapse 完整解答
**第一步：把效率写成只含 $\beta$ 的函数。**

$$\eta(\beta)=\frac{\beta S_N\cos\varphi_2}{\beta S_N\cos\varphi_2+p_0+\beta^2 p_{kN}}$$

**第二步：分子分母同除以 $\beta S_N\cos\varphi_2$。**

$$\eta=\frac{1}{1+\dfrac{p_0}{\beta S_N\cos\varphi_2}+\dfrac{\beta p_{kN}}{S_N\cos\varphi_2}}$$

要让 $\eta$ 最大，等价于让分母最小，即让

$$f(\beta)=\frac{p_0}{\beta}+\beta p_{kN}$$

最小。

**第三步：均值不等式。** 对正数 $\dfrac{p_0}{\beta}$ 与 $\beta p_{kN}$：

$$f(\beta)\ge 2\sqrt{\frac{p_0}{\beta}\cdot\beta p_{kN}}=2\sqrt{p_0p_{kN}}$$

等号当且仅当 $\dfrac{p_0}{\beta}=\beta p_{kN}$ 时成立，即

$$\boxed{\ \beta^2 p_{kN}=p_0\ }$$

**第四步：对选项。** 显示位 A（原始位 D）正是 $\beta^2P_{kN}=P_0$。

**答案：A**（原始位 D）

顺带记住等号条件的物理含义：**可变损耗（铜耗 $\beta^2p_{kN}$）等于不变损耗（铁耗 $p_0$）时效率最大**。这不是数学巧合——可变损耗随 $\beta$ 涨、不变损耗不随 $\beta$ 变，两者相等时那一份损耗被两侧摊得最匀。
:::

:::collapse 复盘
- **最常错的是把 $p_0$ 与 $p_{kN}$ 摆反**：写成 $\beta^2p_0=p_{kN}$。检查办法——$p_0$ 是空载损耗（铁耗），与负载无关；含 $\beta^2$ 的必须是**随负载平方增长的那一项**，也就是铜耗 $p_{kN}$。
- **$\beta$ 的幂次**：铜耗是 $I^2r$，电流随负载正比变化，所以是 $\beta^2$，不是 $\beta$。
- 平台上这题选项被打乱，**按字母选之前先看公式本身**。
:::

### 第 2 题

一降压变压器，若二次侧电压过低，则需通过调整安装在油箱盖上的分接开关，（　），调高二次侧电压。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | C | 增大 $N_1$ |
| B | D | 增大 $N_2$ |
| C | B | 减小 $N_2$ |
| D | A | 减小 $N_1$ |

:::collapse 提示
两件事要想清：① 从 $U_1/U_2=N_1/N_2$ 反解 $U_2=U_1\cdot N_2/N_1$，看 $U_2$ 与哪个匝数成反比；
② **分接开关的抽头做在哪一侧**——题目说它「安装在油箱盖上」，而变压器运行中**二次绕组已经绕死、不许改**，
能抽头的只有一次绕组。这两点合起来才能从两个「都能抬压」的选项里选出唯一那个。
:::

:::collapse 完整解答
**第一步：写出电压比。**

$$\frac{U_1}{U_2}=\frac{N_1}{N_2}\quad\Longrightarrow\quad U_2=U_1\cdot\frac{N_2}{N_1}$$

**第二步：看清哪几个量能变。** 一次侧接电网，$U_1$ 由电网决定，不能动；二次侧绕组已经绕好，$N_2$ 也不能动。**分接开关唯一的作用是改变一次绕组接入的匝数 $N_1$。**

**第三步：要让 $U_2$ 变大。** $U_2$ 与 $N_1$ 成反比——$N_1$ 减小，$U_2$ 增大。

**答案：D**（原始位 A，减小 $N_1$）

物理上说得通：一次绕组少接几匝，每匝分到的电压变高，铁芯里主磁通变大，二次每匝感应电动势也随之变大，于是 $U_2$ 升高。
:::

:::collapse 复盘
- **最容易错的是「增大 $N_2$」**：直觉上「电压不够就多绕几匝」，但变压器运行中**二次绕组已经绕死，改不了**。分接开关装在一次侧（高压侧），动的永远是一次匝数。
- **记这个工程事实**：分接抽头做在**高压侧**，因为那里电流小——触点截面小、引线好做、切换时电弧好灭；做在低压侧则要承受大电流，成本与可靠性都不划算。这条不在公式里，是题的隐含前提。
- 记忆抓手：**二次电压低 → 一次匝数少**（反比关系）。
- 再提一句：分接开关装在**高压侧**是因为高压侧电流小，触点好做、电弧好灭。
:::

### 第 3 题

变压器带感性（电阻＋电感）负载运行时，则其二次侧电压 $U_2$ 数值上一定（　）二次侧空载电压 $U_{20}$。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | D | 以上选项皆有可能 |
| B | B | 等于 |
| C | A | 小于 |
| D | C | 大于 |

:::collapse 提示
变压器内部有漏阻抗 $Z_k=r_k+jx_k$，负载电流流过它就产生压降。关键在于：这个压降**既有大小又有相位**，$U_2$ 与 $U_{20}$ 的差别是相量相减，不只是代数相减。想清楚感性负载时 $\dot I_2$ 相对 $\dot U_2$ 滞后这个前提。
:::

:::collapse 完整解答
**第一步：写下电压方程。**

$$\dot U_{20}=\dot U_2+\dot I_2(r_k+jx_k)$$

即空载电压等于二次端电压加上内部漏阻抗上的压降（全部归算到二次侧）。

**第二步：看相量关系。** 带感性负载时，$\dot I_2$ 滞后 $\dot U_2$ 一个角度 $\varphi_2$。于是 $\dot I_2 r_k$ 与 $\dot U_2$ 同相（在 $\dot I_2$ 方向），$\dot I_2 jx_k$ 超前 $\dot I_2$ 90°，两者合成的压降相量落在 $\dot U_2$ 的**前方**（沿 $\dot U_2$ 方向有正投影）。

**第三步：结论。** 压降相量在 $\dot U_2$ 方向上的投影为正 ⇒ $|\dot U_{20}|>|\dot U_2|$，即 $U_2<U_{20}$。

用电压变化率的式子看得更直接：

$$\Delta U\%\approx\beta(u_{kr}\cos\varphi_2+u_{kx}\sin\varphi_2)$$

感性负载 $\varphi_2>0$，$\cos\varphi_2>0$、$\sin\varphi_2>0$，两项都为正 ⇒ $\Delta U>0$ ⇒ $U_2<U_{20}$。

**答案：C**（原始位 A，小于）
:::

:::collapse 复盘
- **为什么不是「皆有可能」**：只有容性负载（$\varphi_2<0$，$\sin\varphi_2<0$）才可能让 $\Delta U<0$、出现 $U_2>U_{20}$。题目明确限定感性，所以只有「小于」。
- 判据抓手：看 $\Delta U\%$ 的式子里 $\sin\varphi_2$ 的符号——感性取正、容性取负、纯电阻取零（此时 $\Delta U\approx\beta u_{kr}\cos\varphi_2>0$，仍然小于）。
- 这一条常被当成「电压应该不变」，那是把变压器当成理想元件了；实际变压器的漏阻抗在带载时必然吃掉一部分电压。
:::

## 4. 判断题

### 第 4 题

电力变压器带额定负载时的电压变化率，称为额定电压变化率。（　）

:::collapse 提示
查「额定电压变化率」的定义：它固定的是**负载条件**（额定负载，$\beta=1$）还是**功率因数条件**，还是两者都固定？
:::

:::collapse 完整解答
额定电压变化率的定义是：一次侧加**额定电压**、二次侧**开路**时的二次电压 $U_{20}$，与一次侧加额定电压、二次侧带**额定电流**（即 $\beta=1$）且功率因数为**额定值**（通常取 $\cos\varphi_2=0.8$ 滞后）时的二次电压 $U_2$ 之差，相对 $U_{20}$ 的百分比。

题目说的是「带额定负载时的电压变化率」——负载系数 $\beta=1$，这正是额定电压变化率的负载条件。

**答案：对**

严格说定义里还规定了功率因数，但题目问的是「带额定负载时」这个条件下这个量叫什么名字，问的是命名而非完整定义，表述成立。
:::

:::collapse 复盘
- 这题考的是**名字与条件的对应**，不是算数值。
- 要注意区分：**额定电压变化率**是铭牌上的一个定值（$u_k\%$ 相关的那个），而**电压变化率**是随负载变化的函数 $\Delta U(\beta,\varphi_2)$。前者是后者在额定点的一个特例。
:::

### 第 5 题

变压器的电压变化率与变压器参数、负载大小及性质有关。（　）

:::collapse 提示
看 $\Delta U\%\approx\beta(u_{kr}\cos\varphi_2+u_{kx}\sin\varphi_2)$ 这个式子，把它拆成「哪些量来自变压器本身」「哪些量来自负载」。
:::

:::collapse 完整解答
$$\Delta U\%\approx\beta\big(u_{kr}\cos\varphi_2+u_{kx}\sin\varphi_2\big)$$

逐个对照题目里的三项：

| 题目说的 | 式子里对应的 | 属于 |
| :--- | :--- | :--- |
| 变压器参数 | $u_{kr}=r_k^*$、$u_{kx}=x_k^*$（短路电阻与短路电抗的标幺值） | 变压器本身 |
| 负载大小 | $\beta$ | 负载 |
| 负载性质 | $\varphi_2$（功率因数角） | 负载 |

三者都在式子里，都影响 $\Delta U$。

**答案：对**
:::

:::collapse 复盘
- **负载「性质」指的是功率因数角 $\varphi_2$，不是功率大小**。感性与容性会让 $\sin\varphi_2$ 变号，这是「性质」二字的全部含义。
- 这条判断可以当成一张清单用：以后算 $\Delta U$ 漏了哪个量，回头看这张表。
:::

## 5. 多选题

### 第 6 题

反映变压器运行性能的主要指标有（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | A | 电压调整率（又称电压变化率） |
| B | B | 空载电流 |
| C | C | 效率 |
| D | D | 变压比 |

:::collapse 提示
「运行性能」是教材里一个有固定范围的说法，特指变压器**带负载运行**时表现出来的两个指标。回想第六节的小标题。
:::

:::collapse 完整解答
变压器运行性能的两个主要指标是：

1. **电压变化率（电压调整率）$\Delta U\%$** —— 反映带载后端电压跌落多少；
2. **效率 $\eta$** —— 反映能量转换的经济性。

**空载电流**属于**励磁性能**（空载特性），描述的是铁芯与励磁回路的状态，不是带载运行的指标；**变压比**是**变比参数**，由一二次匝数决定，是变压器的固有参数而不是运行表现。

**答案：A、C**

（四个选项的 `orichoice` 与显示位一致，本题未乱序。）
:::

:::collapse 复盘
- 空载电流容易被误选，因为它确实是变压器的一个重要量。但它属于**空载特性**，教材把「空载运行」与「负载运行」分成两块讲，指标也分属两块。
- 判断口径：**指标**是「运行时表现出来的好不好」，**参数**是「造出来就定死的」；变压比属于后者。
:::
