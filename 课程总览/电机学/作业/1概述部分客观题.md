## 2. 单选题（第 1–5 题）

### 第 1 题

下列与磁导率无关的物理量是（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 磁感应强度 |
| B | 磁阻 |
| C | 磁场强度 |
| D | 磁通 |

:::collapse accordion
- 提示
  把四个量各自写成只含电流 $I$、匝数 $N$、磁路平均长度 $l$、磁路截面积 $S$ 和磁导率 $\mu$ 的表达式：$B = \mu H$、$R_m = \dfrac{l}{\mu S}$、$\Phi = BS = \dfrac{NI}{R_m}$，再对照全电流定律 $Hl = NI$ 反解出的 $H$，看哪一个式子里消掉了 $\mu$。
- 完整解答
  **第一步：用全电流定律与磁路公式写出四者表达式。**
  在均匀闭合磁路（平均长度 $l$、截面积 $S$）中，由安培环路定律（全电流定律）$\oint \vec{H}\cdot\mathrm{d}\vec{l} = \sum I$ 得：
  $$H = \frac{NI}{l}$$
  可见磁场强度 $H$ 仅由励磁磁动势 $NI$ 和磁路长度 $l$ 决定，**与磁导率 $\mu$ 无关**。

  **第二步：逐项检验是否依赖 $\mu$。**
  - **A（磁感应强度 $B$）**：$B = \mu H = \mu\dfrac{NI}{l}$，直接正比于 $\mu$（与介质磁导率有关）。
  - **B（磁阻 $R_m$）**：$R_m = \dfrac{l}{\mu S}$，反比于 $\mu$（与介质磁导率有关）。
  - **C（磁场强度 $H$）**：$H = \dfrac{NI}{l}$，表达式不含 $\mu$（**正确**）。
  - **D（磁通 $\Phi$）**：$\Phi = BS = \mu H S = \dfrac{NI}{R_m} = \dfrac{NI\mu S}{l}$，正比于 $\mu$（与介质磁导率有关）。

  **答案：C**（平台正确答案：C，磁场强度）
- 复盘 :-
  - **最易记反的一对**：很多同学误选 B 或以为 $H = B/\mu$ 所以 $H$ 也跟 $\mu$ 有关——因果关系正好反了。在电流和几何尺寸给定后，是**先由 $H = NI/l$ 定出 $H$**（跟材料无关），**再乘以不同材料的 $\mu$ 算出各自能激出多大的 $B = \mu H$**。
:::

### 第 2 题

为减小剩磁，电磁线圈的铁心应采用（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 矩磁性材料 |
| B | 硬磁性材料 |
| C | 非磁性材料 |
| D | 软磁性材料 |

:::collapse accordion
- 提示
  电磁线圈的铁心同时要求两件事：① 通电时**容易被磁化、磁导率高**；② 断电后**剩磁小、磁滞回线窄**（矫顽力小）。按磁滞回线形状把软磁、硬磁、矩磁和非磁四类材料一一筛过。
- 完整解答
  **第一步：明确电磁铁心的性能要求。**
  电磁线圈铁心需要高磁导率来集中磁通，同时在交流磁化或断电去磁时要求**矫顽力小、剩磁小、磁滞损耗小**（即磁滞回线狭长）。

  **第二步：逐类排除。**
  - **A（矩磁性材料）**：磁滞回线接近矩形，剩磁接近饱和磁密，用来保持记忆状态，不适合减小剩磁。
  - **B（硬磁性材料）**：磁滞回线很宽，矫顽力与剩磁都很大，一旦磁化不易退磁，专用于制造**永久磁铁**。
  - **C（非磁性材料）**：虽然没有剩磁，但相对磁导率 $\mu_r \approx 1$，无法起到铁心聚集磁通的作用。
  - **D（软磁性材料）**：磁滞回线窄、矫顽力小、易磁化也易退磁（剩磁与磁滞损耗均很小），且磁导率高，专用于电机、变压器与电磁铁的铁心（**正确**）。

  **答案：D**（平台正确答案：D，软磁性材料）
- 复盘 :-
  - **选材口诀**：**软磁做铁心**（回线窄、易磁易退、剩磁小），**硬磁做永磁**（回线宽、剩磁矫顽力大），**矩磁做存储**。不要被「非磁性材料没剩磁」绕进去——非磁材料根本聚不了磁，成不了铁心。
:::

### 第 3 题

空心线圈插入铁心后，（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 磁性将减弱 |
| B | 不能确定 |
| C | 磁性基本不变 |
| D | 磁性将大大增强 |

:::collapse accordion
- 提示
  对比插入前（空气，$\mu_r \approx 1$）与插入后（铁心，$\mu_r \gg 1$）磁导率 $\mu$ 和磁阻 $R_m = \dfrac{l}{\mu S}$ 的量级变化，再代入 $\Phi = \dfrac{NI}{R_m}$ 与 $B = \mu H$ 判断磁场强弱变化方向。
- 完整解答
  **第一步：比较磁导率与磁阻变化。**
  空心线圈内部介质是空气，相对磁导率 $\mu_r \approx 1$；插入铁磁材料（如硅钢片或电工纯铁）制成的铁心后，其相对磁导率 $\mu_r \gg 1$（通常达数百至数万），磁路磁阻 $R_m = \dfrac{l}{\mu S}$ 急剧减小。

  **第二步：从磁畴磁化与磁路定律判别结果。**
  在相同励磁磁动势 $NI$ 下，铁心内部磁畴沿外磁场方向强烈取向并叠加附加磁化磁场，使总磁感应强度 $B = \mu_0 \mu_r H$ 与磁通 $\Phi = \dfrac{NI}{R_m}$ 均呈数量级增大，即线圈的**磁性将大大增强**。
  - A（减弱）只可能出现在极弱的抗磁效应中，不适用于铁磁铁心；
  - B（不能确定）与铁磁材料增磁规律不符；
  - C（基本不变）仅对应插入顺磁/抗磁等 $\mu_r \approx 1$ 的非铁磁芯。

  **答案：D**（平台正确答案：D，磁性将大大增强）
- 复盘 :-
  - **直觉落地**：硅钢片等铁磁材料的磁导率是空气的数千倍，铁心在相同电流下把绝大部分磁阻「削掉」了，这是电机和变压器都要用铁心做磁路的根本原因。
:::

### 第 4 题

铁、钴、镍及其合金的相对磁导率（ ）真空磁导率。

| 选项 | 内容 |
| :---: | :--- |
| A | 等于 |
| B | 略大于 |
| C | 略小于 |
| D | 远大于 |

:::collapse accordion
- 提示
  按磁性材料分类表对照四档量级：真空为 $1$，抗磁材料略小于 $1$，顺磁材料略大于 $1$，而铁、钴、镍及其合金属于**铁磁材料**，对应哪一档。
- 完整解答
  **第一步：识别材料类别与量级。**
  铁、钴、镍及其合金属于典型的**铁磁材料**（强磁性材料），其内部存在磁畴，磁导率 $\mu \gg \mu_0$（真空磁导率 $\mu_0 = 4\pi \times 10^{-7}\text{ H/m}$），相对磁导率 $\mu_r = \dfrac{\mu}{\mu_0} \gg 1$（通常在数百至数万量级）。

  **第二步：对照选项分档。**
  - **A（等于）**：对应真空自身（$\mu = \mu_0, \mu_r = 1$）；
  - **B（略大于）**：对应顺磁材料（如铝、空气，$\mu_r$ 略大于 $1$）；
  - **C（略小于）**：对应抗磁材料（如铜、铋，$\mu_r$ 略小于 $1$）；
  - **D（远大于）**：对应铁、钴、镍等铁磁材料（**正确**）。

  **答案：D**（平台正确答案：D，远大于）
- 复盘 :-
  - **题面表述微瑕提醒**：严格量纲上「相对磁导率 $\mu_r = \mu/\mu_0$」无量纲，与之比较的是数值 $1$；而有量纲的「磁导率 $\mu$」才与「真空磁导率 $\mu_0$」比较。题面写「相对磁导率（　）真空磁导率」属题库略称，物理判别仍毫无疑义为**远大于**（$\mu \gg \mu_0$、$\mu_r \gg 1$）。
:::

### 第 5 题

电机是指依据（ ）定律实现能量转换或信号传递的一种电磁装置。

| 选项 | 内容 |
| :---: | :--- |
| A | 牛顿运动 |
| B | 电磁感应 |
| C | 热力学 |
| D | 欧姆 |

:::collapse accordion
- 提示
  电机包含变压器、发电机和电动机三类，它们在电路与磁场（或机械运动）之间耦合的核心定律是哪一条（即写出感应电动势 $e = -N\dfrac{\mathrm{d}\Phi}{\mathrm{d}t}$ 或 $e = Blv$ 的那条定律）。
- 完整解答
  **第一步：回到《电机学》绪论的电机定义。**
  《电机学》开篇对电机的定义是：**以磁场为媒介，依据电磁感应定律实现能量转换（电-磁-电或机-电能量转换）或信号传递（控制电机）的一种电磁装置**。其中变压器利用交变磁通产生感生电动势，旋转电机利用导体切割磁感线产生运动电动势并配合电磁力实现机电能量转换，核心均以**电磁感应定律**为基础。

  **第二步：逐项排错。**
  - **A（牛顿运动定律）**：只描述机械转子的惯性与运动力学关系，不能解释电磁耦合。
  - **B（电磁感应定律）**：电机能量转换与信号传递的根本电磁规律（**正确**）。
  - **C（热力学定律）**：支配损耗发热与温升散热过程，不是电机工作机理。
  - **D（欧姆定律）**：仅描述电阻元件两端电压与电流的线性关系，无法完成交变感应或机电能量转换。

  **答案：B**（平台正确答案：B，电磁感应）
- 复盘 :-
  - **定义三要素**：考填空或概念题时按三段背——① **依据**：电磁感应定律；② **媒介**：磁场；③ **功能**：能量转换或信号传递（把变压器和控制电机也包进来了）。
:::
