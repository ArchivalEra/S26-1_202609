## 2. 单选题（第 1–5 题）

### 第 1 题

变压器负载运行时的磁动势平衡式书写正确的是（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | $N_1 I_1 + N_2 I_2 = N_1 I_0$ |
| B | $N_1 \dot{I}_1 = N_2 \dot{I}_2 + N_1 \dot{I}_0$ |
| C | $N_1 \dot{I}_1 + N_2 \dot{I}_2 = N_1 \dot{I}_0$ |
| D | $N_1 I_1 = N_2 I_2 + N_1 I_0$ |

:::collapse accordion
- 提示
  检验两个硬标准：① 交流稳态磁动势叠加必须用**相量**（字母带点 $\dot{I}$），标量代数和直接排除；② 一、二次正方向均取与主磁通同右手螺旋时，合成磁动势为相加而非 $N_1\dot{I}_1 = N_2\dot{I}_2 + N_1\dot{I}_0$。
- 完整解答
  **第一步：排掉标量错式。**
  交流电流存在相位差，$\dot{I}_0$ 与 $\dot{I}_2$ 并不同相，不能写有效值标量等式，排除 A、D。

  **第二步：核对正方向下的相量符号。**
  按《电机学》标准约定，一、二次电流正方向均与主磁通成右手螺旋定则，因此一次磁动势 $N_1\dot{I}_1$ 与二次磁动势 $N_2\dot{I}_2$ 共同建立空载时的合成主磁通励磁磁动势 $N_1\dot{I}_0$：
  $$N_1 \dot{I}_1 + N_2 \dot{I}_2 = N_1 \dot{I}_0$$
  B 项移项后符号反了（等价于 $N_1\dot{I}_1 - N_2\dot{I}_2 = N_1\dot{I}_0$）。

  **答案：C**（平台正确答案：C）
- 复盘 :-
  - **两处陷阱同时考**：① 漏写相量点号；② 把右边正号写成与 $\dot{I}_1 = \dot{I}_0 + (-\dot{I}_2')$ 混淆的移项错号。
:::

### 第 2 题

正常运行中的变压器保持主磁通不变，当负载电流 $I_2$ 变大时，则一次侧电流 $I_1$ 将（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 不能够确定 |
| B | 变大 |
| C | 变小 |
| D | 不变 |

:::collapse accordion
- 提示
  用第 1 题磁动势平衡方程变形为 $\dot{I}_1 = \dot{I}_0 - \dot{I}_2/k = \dot{I}_0 + (-\dot{I}_2')$：$\dot{I}_0$ 很小且几乎恒定，负载分量 $-\dot{I}_2' = -\dot{I}_2/k$ 随 $I_2$ 同比增大。
- 完整解答
  由磁动势平衡式得一次电流与二次电流关系：
  $$\dot{I}_1 = \dot{I}_0 - \frac{\dot{I}_2}{k}$$
  正常运行时，主磁通不变意味着励磁电流 $\dot{I}_0$ 基本保持不变（且远小于额定负载电流）；当二次负载电流 $I_2$ 增大时，一次侧必须同步提供更大的负载分量 $-\dot{I}_2/k$ 以抵消二次去磁磁动势，因此一次侧电流 $I_1$ 随之**变大**。

  **答案：B**（平台正确答案：B，变大）
- 复盘 :-
  - **物理因果**：变压器自身并不「主动限流」，一次电流跟随二次负载需求按变比成比例「补位」。
:::

### 第 3 题

变压器负载运行，若负载电流（二次侧电流）增大，忽略一、二次侧阻抗压降影响，则主磁通不变、（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 铁芯损耗变大、铜损耗变大 |
| B | 铁芯损耗变大、铜损耗不变 |
| C | 铁芯损耗不变、铜损耗变大 |
| D | 铁芯损耗不变、铜损耗不变 |

:::collapse accordion
- 提示
  把两种损耗拆开绑定各自自变量：铁损 $\leftrightarrow$ 主磁通 $\Phi_m$（固定损耗）；铜损 $\leftrightarrow$ 电流平方 $I^2 r$（可变损耗）。
- 完整解答
  1. **铁芯损耗**：取决于铁芯中的主磁通幅值 $\Phi_m$ 与电源频率 $f$。忽略一、二次侧漏阻抗压降时，由 $U_1 \approx E_1 = 4.44 f N_1 \Phi_m$ 知主磁通保持不变，故**铁芯损耗不变**（属于固定损耗 $p_0 \approx p_{Fe}$）。
  2. **铜损耗**：即绕组电阻热损耗 $p_{Cu} = I_1^2 r_1 + I_2^2 r_2$。负载电流 $I_2$ 增大带动 $I_1$ 同步增大，故**铜损耗随电流平方显著变大**（属于可变损耗）。

  **答案：C**（平台正确答案：C，铁芯损耗不变、铜损耗变大）
- 复盘 :-
  - **直通后续章节**：铁损「不随负载变」而铜损「正比于 $\beta^2$」，正是后续损耗分离法与最大效率点 $\beta^2 p_{kN} = p_0$ 的出发点。
:::

### 第 4 题

一台正常运行中的变压器，其主磁通幅值 $\Phi_m$ 的大小主要取决于（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 空载电流的大小和频率 |
| B | 电源电压的大小和频率 |
| C | 铁芯截面积和磁导率的大小 |
| D | 负载的性质和负载电流的大小 |

:::collapse accordion
- 提示
  忽略一次漏阻抗小压降，由 $U_1 \approx E_1 = 4.44 f N_1 \Phi_m$ 反解 $\Phi_m$。
- 完整解答
  对于既定变压器，绕组匝数 $N_1$ 为构造常数。正常运行时一次漏阻抗压降很小，端电压近似等于感应电动势：
  $$U_1 \approx E_1 = 4.44 f N_1 \Phi_m \implies \Phi_m \approx \frac{U_1}{4.44 f N_1}$$
  可见主磁通幅值 $\Phi_m$ 主要取决于外施**电源电压的大小 $U_1$ 和频率 $f$**，而几乎不受铁芯磁阻/磁导率（它们决定 $I_0$）或负载电流（由一次补位抵消）影响。

  **答案：B**（平台正确答案：B，电源电压的大小和频率）
- 复盘 :-
  - **主因果链**：恒压电源定死 $\Phi_m$；铁芯材质与气隙（C 项）改变磁阻 $R_m$ 后，改变的是建立同一 $\Phi_m$ 所需的励磁电流 $I_0$，而非 $\Phi_m$ 本身。
:::

### 第 5 题

折算应保持变压器电磁平衡关系不变，当需要从二次侧折算到一次侧时应（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 保持折算前后电动势和一次侧电磁功率不变。 |
| B | 保持折算前后磁动势和一次侧电磁功率不变。 |
| C | 保持折算前后磁动势和二次侧电磁功率不变。 |
| D | 保持折算前后电动势和二次侧电磁功率不变。 |

:::collapse accordion
- 提示
  我们改动的是「二次绕组」（把它等价成 $N_2'=N_1$），因此必须守恒的是**折算前后的二次侧磁动势**与**二次侧能量/电磁功率关系**（从而推导 $I_2'=I_2/k$、$E_2'=kE_2$、$Z'=k^2 Z$）。
- 完整解答
  把二次侧折算到一次侧，是用匝数为 $N_2'=N_1=kN_2$ 的等效二次绕组替代原绕组：
  1. 为不扰动原磁路与一次侧工作状态，必须**保持折算前后二次侧磁动势不变**：$N_1 \dot{I}_2' = N_2 \dot{I}_2 \implies \dot{I}_2' = \dot{I}_2/k$；
  2. 为不改变能量转换与电路损耗，必须**保持折算前后二次侧电磁功率（含视在功率、有功/无功及铜耗）不变**：$E_2' I_2' \cos\varphi = E_2 I_2 \cos\varphi$，即 $E_2' = k E_2$、$Z_2' = k^2 Z_2$。

  **答案：C**（平台正确答案：C，保持折算前后磁动势和二次侧电磁功率不变。）
- 复盘 :-
  - **排错要点**：折算后电动势从 $E_2$ 变为 $E_2' = kE_2$，本身发生了 $k$ 倍变化，故「保持电动势不变」（A、D）错误；且折算对象是二次侧，守恒约束落在「二次侧电磁功率」（B 错写一次侧）。
:::

## 3. 多选题（第 6 题）

### 第 6 题

在下列对变压器负载运行的描述中，正确的有（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 负载运行时磁动势是由各侧电流共同产生，因此负载电流的变化时，主磁通也将随之变化。 |
| B | 变压器负载运行时的功率因数比空载运行时的功率因数低。 |
| C | 变压器负载运行时的功率因数比空载运行时的功率因数高。 |
| D | 主磁通与负载电流无关，不随负载电流的变化而变化。 |

:::collapse accordion
- 提示
  两组直接二选一矛盾命题：①「主磁通随负载变化（A）」vs「主磁通与负载无关（D）」；②「负载功率因数比空载低（B）」vs「比空载高（C）」。
- 完整解答
  1. **判断 A vs D**：虽然主磁通由一、二次磁动势合成建立，但恒压运行下一次电流会自动调整负载分量抵消二次去磁磁动势，主磁通仍由 $U_1, f$ 决定，**与负载电流无关** ⇒ **D 正确**，A 错误。
  2. **判断 B vs C**：空载时一次电流几乎全部用来建磁场（感性无功分量占绝对主导），空载功率因数极低（约 0.1–0.2）；带载后一次电流以向负载传递有功功率为主，功率因数显著升高 ⇒ **C 正确**，B 错误。

  **答案：C、D**（平台正确答案：CD）
- 复盘 :-
  - **串联前节**：空载功率因数极低正是 [2.2.1-1](./2.2.1-1变压器空载运行.md) 第 9 题与空载试验要用**低功率因数瓦特表**的物理根源；负载起来后，功率因数才由负载本身性质主导而显著抬高。
:::
