## 2. 单选题（第 1–10 题）

### 第 1 题

对变压器空载运行时，下列对变压器各时间相量参数的相位关系描述正确的是（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 主磁通与感生电动势的相位相同，超前磁化电流 90°。 |
| B | 主磁通与感生电动势的相位相同，滞后磁化电流 90°。 |
| C | 磁化电流与主磁通的相位相同，超前感生电动势 90°。 |
| D | 磁化电流与主磁通的相位相同，滞后感生电动势 90°。 |

:::collapse accordion
- 提示
  画空载相量图的三步锚定顺序：① 磁化电流 $\dot{I}_\mu$ 直接建磁场 ⇒ 与主磁通 $\dot{\Phi}$ 同相（设为 $0^\circ$）；② 按正方向 $e = -N\dfrac{\mathrm{d}\Phi}{\mathrm{d}t}$ 对 $\sin\omega t$ 求导带负号 ⇒ 感生电动势 $\dot{E}_1, \dot{E}_2$ 落在 $-90^\circ$；③ 看 $\dot{I}_\mu$、$\dot{\Phi}$ 相对 $\dot{E}$ 是超前还是滞后 $90^\circ$。
- 完整解答
  **第一步：写出主磁通与磁化电流的相位关系。**
  空载电流的磁化无功分量 $i_\mu$ 专门负责在铁芯中建立主磁通 $\Phi$，两者**同相位**（若指总空载电流 $i_0$，则在不计铁耗角/磁滞角时亦近似与 $\Phi$ 同相）。设 $\Phi = \Phi_m \sin\omega t$（相量 $\dot{\Phi}$ 取 $0^\circ$），则磁化电流相量 $\dot{I}_\mu$ 也在 $0^\circ$。

  **第二步：由电磁感应定律求感生电动势相位。**
  取与磁通成右手螺旋的电动势正方向：
  $$e = -N\frac{\mathrm{d}\Phi}{\mathrm{d}t} = -\omega N \Phi_m \cos\omega t = \omega N \Phi_m \sin(\omega t - 90^\circ)$$
  可见感生电动势 $\dot{E}_1$、$\dot{E}_2$ 滞后主磁通 $\dot{\Phi}$ 与磁化电流 $\dot{I}_\mu$ 各 $90^\circ$——换言之，**$\dot{I}_\mu$ 与 $\dot{\Phi}$ 相位相同，且超前感生电动势 $\dot{E}$ $90^\circ$**。

  **第三步：逐项排错。**
  A、B 均误称主磁通与感生电动势同相；D 把感生电动势 $\dot{E}_1$ 与一次端电压 $\dot{U}_1 \approx -\dot{E}_1$ 混淆（$\dot{I}_\mu$ 滞后 $\dot{U}_1$ $90^\circ$，超前 $\dot{E}_1$ $90^\circ$）。

  **答案：C**（平台正确答案：C）
- 复盘 :-
  - **高危混淆**：$\dot{I}_\mu$（和 $\dot{\Phi}$）**滞后**外施电压 $\dot{U}_1$ $90^\circ$，但**超前**感生电动势 $\dot{E}_1, \dot{E}_2$ $90^\circ$。做题时看清题干问的是「端电压 $\dot{U}_1$」还是「感生电动势 $\dot{E}$」。
:::

### 第 2 题

关于对变压器等效电路中励磁电抗 $X_m$ 和一次漏电抗 $X_1$ 的说法正确的是（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | $X_m$ 是常数，$X_1$ 不是常数 |
| B | $X_m$ 和 $X_1$ 都是常数，而且 $X_m \gg X_1$ |
| C | $X_1$ 是常数，$X_m$ 不是常数 |
| D | $X_m$ 和 $X_1$ 都是常数，而且 $X_m \ll X_1$ |

:::collapse accordion
- 提示
  按两路磁通走什么介质判断「线性还是非线性」：走空气/油等非铁磁介质 ⇒ 磁导率恒定 ⇒ 电抗是常数；走硅钢片铁芯 ⇒ 存在磁饱和非线性 ⇒ 电抗随饱和程度变化、不是常数。
- 完整解答
  **第一步：比较主磁路与漏磁路介质特性。**
  电抗满足 $X = \omega L = \omega \dfrac{N^2}{R_m}$，是否恒定取决于磁路磁阻 $R_m = \dfrac{l}{\mu S}$ 是否恒定：
  1. **一次漏电抗 $X_1$**：一次漏磁通主要经过空气、绝缘油和绕组间隙等**非铁磁介质**闭合，其磁导率 $\mu \approx \mu_0$ 恒定、无磁饱和效应，故 $X_1$ **是常数**；
  2. **励磁电抗 $X_m$**：主磁通全部经**铁芯**闭合，铁磁材料 $B$-$H$ 曲线呈非线性饱和特性，磁导率 $\mu$ 随磁通密度（即外加电压与饱和程度）变化，因此 $X_m$ **不是常数**。

  **第二步：逐项排错。**
  A 把二者特性写反；B、D 均错把 $X_m$ 当成常数（且 D 把 $X_m \gg X_1$ 写反）。

  **答案：C**（平台正确答案：C）
- 复盘 :-
  - **数量级与常变属性双记**：空载时 $X_m$ 确实远大于 $X_1$（所以 B 最具迷惑性），但它**不是常数**；只有线性非饱和媒质对应的漏电抗 $X_1$ 才是常数。
:::

### 第 3 题

三相电力变压器的变压比 $k$（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 为二次绕组电动势与一次绕组的电动势之比，近似等于额定电压之比 |
| B | 为二次绕组相电动势与一次绕组的相电动势之比，近似等于额定相电压之比 |
| C | 为一次绕组相电动势与二次绕组的相电动势之比，近似等于额定相电压之比 |
| D | 为一次绕组电动势与二次绕组的电动势之比，近似等于额定电压之比 |

:::collapse accordion
- 提示
  两道关同时卡死唯一选项：① 比值方向永远是**一次侧 ÷ 二次侧**；② 三相变压器绕组接法（Y 或 D）不同，线电压比不一定等于匝数比，必须取**相**电动势之比与额定**相**电压之比。
- 完整解答
  **第一步：写出变比 $k$ 的标准定义。**
  电力变压器变比定义为一次绕组与二次绕组的**相电动势之比**（等于一、二次每相串联匝数之比）：
  $$k = \frac{E_{1\phi}}{E_{2\phi}} = \frac{N_1}{N_2}$$
  空载运行且忽略一次绕组漏阻抗压降时，$U_{1N\phi} \approx E_{1\phi}$、$U_{2N\phi} = U_{20\phi} = E_{2\phi}$，因此近似等于一、二次侧**额定相电压之比**。

  **第二步：逐项排错。**
  - A、B 把一次与二次的比值顺序写反（写成二次比一次）；
  - D 漏掉关键限定词「**相**」——三相变压器铭牌额定电压为线电压，当一、二次分别为星形与三角形接法（如 `Y,d` 或 `D,y`）时，线电压比与相电动势比相差 $\sqrt{3}$ 倍。

  **答案：C**（平台正确答案：C）
- 复盘 :-
  - **和第 2.1 节第 11 题联动**：`D,y11` 的 $10/0.4\text{ kV}$ 线电压比是 25，但相电压比 $k$ 是 $25\sqrt{3} \approx 43.3$——正是「必须用相电压之比」的直接例证。
:::

### 第 4 题

变压器运行在额定电压及频率下，若铁芯导磁性能越好，则该变压器的（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 励磁电抗 $X_m$ 越大、空载电流 $I_0$ 越小 |
| B | 励磁电抗 $X_m$ 越大、空载电流 $I_0$ 越大 |
| C | 励磁电抗 $X_m$ 越小、空载电流 $I_0$ 越大 |
| D | 励磁电抗 $X_m$ 越小、空载电流 $I_0$ 越小 |

:::collapse accordion
- 提示
  沿三步因果链推：① 导磁性能越好 ⇒ $\mu$ 越大、磁阻 $R_m = \dfrac{l}{\mu S}$ 越小；② 由 $X_m = \omega \dfrac{N_1^2}{R_m}$ 看 $X_m$ 变大还是变小；③ 额定电压和频率固定时 $\Phi_m \approx \dfrac{U_1}{4.44fN_1}$ 恒定，再由 $\dfrac{N_1 I_0}{R_m} \approx \Phi_m$（或 $I_\mu \approx \dfrac{E_1}{X_m}$）看 $I_0$ 变大还是变小。
- 完整解答
  **第一步：判断励磁电抗 $X_m$ 的变化。**
  铁芯导磁性能越好，铁芯磁导率 $\mu$ 越大，磁路磁阻 $R_m = \dfrac{l}{\mu S}$ 越小（磁导 $\Lambda = 1/R_m$ 越大），因此励磁电抗
  $$X_m = \omega \Lambda N_1^2 = \frac{\omega N_1^2}{R_m}$$
  必然**越大**。

  **第二步：判断空载电流 $I_0$ 的变化。**
  在额定电压 $U_1$ 与额定频率 $f$ 下，由 $\Phi_m = \dfrac{E_1}{4.44 f N_1} \approx \dfrac{U_1}{4.44 f N_1}$ 可知主磁通幅值 $\Phi_m$ 基本不变；由磁路欧姆定律 $\dfrac{N_1 I_0}{R_m} \approx \Phi_m$（或 $I_0 \approx I_\mu \approx \dfrac{E_1}{X_m}$），$R_m$ 越小（$X_m$ 越大），产生同一主磁通所需的空载电流 $I_0$ 就**越小**。

  **答案：A**（平台正确答案：A）
- 复盘 :-
  - **为什么用优质冷轧硅钢片**：高导磁取向硅钢片就是通过提高 $\mu$ 来拉高 $X_m$、把空载励磁电流 $I_0$ 压到额定电流的 1%–3% 以下。
:::

### 第 5 题

变压器空载运行时的主磁通和漏磁通描述正确的是（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 主磁通只和二次绕组交链，漏磁通只和一次绕组交链 |
| B | 主磁通只和一次绕组交链，漏磁通只和二次绕组交链 |
| C | 漏磁通和一、二次绕组同时交链，主磁通只与一次绕组交链 |
| D | 主磁通和一、二次绕组同时交链，漏磁通只与一次绕组交链 |

:::collapse accordion
- 提示
  空载运行意味着**二次绕组开路（$I_2 = 0$）**——先看有没有二次电流产生二次漏磁通，再看沿着主铁芯闭合的主磁通穿过哪几个绕组。
- 完整解答
  **第一步：明确主磁通交链对象。**
  一次绕组在铁芯中激励的主磁通 $\Phi$ 沿着高导磁闭合铁芯流通，**同时交链一次绕组和二次绕组**（分别感应 $E_1$ 和 $E_2$，实现能量/电压耦合）。

  **第二步：明确空载时的漏磁通。**
  漏磁通只交链产生它的那一方绕组并经非铁磁空间闭合。空载运行时二次侧开路（$I_2 = 0$），不存在二次漏磁通，只有一次空载电流 $I_0$ 产生一次漏磁通 $\Phi_{\sigma 1}$，故**漏磁通只与一次绕组交链**。

  **答案：D**（平台正确答案：D）
- 复盘 :-
  - **负载时对比**：一旦二次带负载（$I_2 \neq 0$），二次绕组也会出现只交链自己的二次漏磁通 $\Phi_{\sigma 2}$；而本题限定在**空载运行**，所以只有一次漏磁通。
:::

### 第 6 题

某单相变压器，一次侧绕组 $N_1 = 100$ 匝，二次侧绕组 $N_2 = 5$ 匝，则变压器变比 $k$ 为（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 5 |
| B | 1 |
| C | 20 |
| D | 0.02 |

:::collapse accordion
- 提示
  单相变压器的相电压就是绕组自身电压，直接代入变比公式 $k = \dfrac{N_1}{N_2}$ 计算。
- 完整解答
  **计算**：
  由变压器变比定义
  $$k = \frac{E_1}{E_2} = \frac{N_1}{N_2} = \frac{100}{5} = 20$$
  排除 A（5，误抄 $N_2$）、B（1）与 D（0.02）。

  **答案：C**（平台正确答案：C，20）
- 复盘 :-
  - **注意区分 $N_2/N_1$**：偶见学生算成 $5/100 = 0.05$，国标与本课一律定义为一次匝数比二次匝数 $N_1/N_2$。
:::

### 第 7 题

变压器空载运行时主磁通 $\Phi_m$ 和空载电流 $I_0$ 的关系是（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 若主磁通 $\Phi_m$ 为正弦波时，则空载电流 $I_0$ 为尖顶波 |
| B | 若主磁通 $\Phi_m$ 为尖顶波时，则空载电流 $I_0$ 为正弦波 |
| C | 若空载电流 $I_0$ 为平顶波时，则主磁通 $\Phi_m$ 为平顶波 |
| D | 若空载电流 $I_0$ 为平顶波时，则主磁通 $\Phi_m$ 为正弦波 |

:::collapse accordion
- 提示
  拿起磁化曲线 $\Phi = f(i_0)$ 看非线性饱和区：若想让纵轴 $\Phi$ 在峰值处继续按正弦往高处走，横轴电流 $i_0$ 在峰值附近必须「突然飙上去」⇒ 是尖顶波还是平顶波？反过来若电流只按正弦走，饱和会把磁通峰值削平 ⇒ 平顶波。
- 完整解答
  **第一步：从铁芯饱和非线性出发推导波形对应关系。**
  铁芯材料的磁化曲线 $\Phi = f(i_0)$ 在高磁密区发生**磁饱和**（电流增大很多，磁通只增大很少）：
  1. 当外加正弦电网电压时，由 $u_1 \approx -e_1 = N_1 \dfrac{\mathrm{d}\Phi}{\mathrm{d}t}$，主磁通 $\Phi$ 被强迫为**正弦波**。在磁通接近峰值的区间，铁芯进入饱和区、磁导率下降，为达到正弦波峰所需的励磁电流必须急剧增大，从而把空载电流 $i_0$ 的波峰拉成又高又窄的**尖顶波**（含显著三次谐波）。
  2. 反之，若强迫励磁电流 $i_0$ 为**正弦波**（如三相 `Y,y` 无中性线阻断三次谐波电流时），由于峰值处铁芯饱和、磁通跟不上去，主磁通 $\Phi$ 顶部会被削平，变为**平顶波**。

  **第二步：对照选项排错。**
  - **A 正确**（正弦磁通 $\Rightarrow$ 尖顶空载电流）；
  - B 把对应方向写反（正弦电流对应的是**平顶**磁通，而非尖顶磁通）；
  - C、D 均把「平顶波」错安到空载电流上（饱和时被削成平顶的是磁通，电流只会被拉成尖顶）。

  **答案：A**（平台正确答案：A）
- 复盘 :-
  - **原题错因复盘（平台原选 D 得 0 分）**：误把「正弦电流对应平顶磁通」记反成「平顶电流对应正弦磁通」。死记一句物理画面：**谁被限制、谁就不变形，铁芯饱和永远把电流「挤」成尖顶、把磁通「削」成平顶**——所以正弦 $\Phi \Rightarrow$ 尖顶 $i_0$，正弦 $i_0 \Rightarrow$ 平顶 $\Phi$，绝对没有「平顶电流」。
:::

### 第 9 题

变压器空载励磁电流是（ ）性质。

| 选项 | 内容 |
| :---: | :--- |
| A | 感性无功 |
| B | 阻性有功 |
| C | 容性无功 |
| D | 阻性无功 |

:::collapse accordion
- 提示
  空载时一次侧的主要任务是**建磁场**而不是传输有功功率：$\dot{I}_0 = \dot{I}_{Fe} + \dot{I}_\mu$ 里，$I_\mu$（滞后 $\dot{U}_1$ $90^\circ$）占绝大多数还是 $I_{Fe}$（与 $\dot{U}_1$ 同相）占绝大多数？
- 完整解答
  **第一步：拆解空载电流的两个分量。**
  空载电流 $\dot{I}_0 = \dot{I}_{Fe} + \dot{I}_\mu$：
  - **铁耗有功分量 $\dot{I}_{Fe}$**：与 $\dot{U}_1$ 近乎同相，仅对应极小的空载铁芯损耗（功率占比很低）；
  - **磁化无功分量 $\dot{I}_\mu$**：用于建立主磁场，滞后 $\dot{U}_1 \approx -\dot{E}_1$ 整 $90^\circ$。

  **第二步：比较量级定性质。**
  在正常电力变压器中励磁电抗 $X_m \gg r_m$，导致 $I_\mu \gg I_{Fe}$，合成空载电流 $\dot{I}_0$ 滞后外施电压 $\dot{U}_1$ 约 $80^\circ\sim 88^\circ$（$\cos\varphi_0 \approx 0.1\sim 0.2$ 很低），主要从电网吸收建立磁场所需的无功功率，故呈**感性无功**性质。D「阻性无功」本身概念自相矛盾。

  **答案：A**（平台正确答案：A，感性无功）
- 复盘 :-
  - **后续串联**：正因为空载励磁电流主要为感性无功、功率因数极低（$\cos\varphi_0 \approx 0.1$–$0.2$），做空载试验时必须使用**低功率因数瓦特表**。
:::

### 第 10 题

一台单相变压器 $U_{1N}/U_{2N} = 35\text{ kV}/6.6\text{ kV}$，若一次侧所接电源电压为 $38\text{ kV}$，则变压器等效电路中励磁电抗 $X_m$ 将（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 不变 |
| B | 变小 |
| C | 变大 |
| D | 不能确定 |

:::collapse accordion
- 提示
  先看外施电压 $38\text{ kV} > 35\text{ kV}$ 让主磁通 $\Phi_m \approx \dfrac{U_1}{4.44fN_1}$ 怎么变；再看主磁通增大后铁芯进入更深饱和区，磁导率 $\mu$ 下降、磁阻 $R_m$ 增大，最后用 $X_m = \dfrac{\omega N_1^2}{R_m}$ 或 $X_m = \dfrac{E_1}{I_\mu}$ 定出增减方向。
- 完整解答
  **第一步：从电压升高推出铁芯饱和加深。**
  一次侧外施电压从额定 $35\text{ kV}$ 升至过压 $38\text{ kV}$（频率不变），由 $U_1 \approx E_1 = 4.44 f N_1 \Phi_m$ 知主磁通 $\Phi_m$ 随之增大。电力变压器额定工作点设计在磁化曲线膝部附近，磁通增大使铁芯进入更深饱和区，等效磁导率 $\mu$ 明显下降、磁路磁阻 $R_m = \dfrac{l}{\mu S}$ 增大。

  **第二步：判定 $X_m$ 的变化。**
  由 $X_m = \dfrac{\omega N_1^2}{R_m}$（等价地，饱和区磁化电流 $I_\mu$ 的增长幅度远大于 $E_1$ 的增幅，$X_m = \dfrac{E_1}{I_\mu}$），可知励磁电抗 $X_m$ 将**变小**。

  **答案：B**（平台正确答案：B，变小）
- 复盘 :-
  - **过电压危险的双重后果**：一旦电源电压偏高（过励磁），不仅主磁通增大使铁耗上升，更因为 $X_m$ **变小**，导致空载励磁电流呈非线性急剧飙升，极易引起绕组与铁芯过热。
:::

### 第 11 题

下列对变压器参数描述正确的是（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | $I_0$ 与 $U_1$、$f$、$N_1$ 和 $R_m$ 有关。 |
| B | $R_m$ 和磁路材质及几何尺寸有关。 |
| C | $\Phi_m$ 与 $U_1$、$f$、$N_1$ 和 $R_m$ 有关。 |
| D | $\Phi_m$ 与 $U_1$、$f$、$N_1$ 有关，和 $R_m$ 无关。 |
| E | $R_m$ 和磁路材质及几何尺寸无关。 |
| F | $I_0$ 与 $U_1$、$f$、$N_1$ 有关，和 $R_m$ 无关。 |

:::collapse accordion
- 提示
  把三个核心公式写在同一行里依次看依赖自变量（图 09 官方解析正是这三步）：① $R_m = \dfrac{l}{\mu S}$ 看磁阻由谁定；② $\Phi_m \approx \dfrac{U_1}{4.44 f N_1}$ 看恒压电源下主磁通由谁定；③ $I_0 \approx \dfrac{\Phi_m R_m}{N_1}$ 看空载电流由谁定。
- 完整解答
  **第一步：逐一写明三个物理量的决定式（对照图 09 解析）。**
  1. **磁阻 $R_m$**：
     $$R_m = \frac{1}{\Lambda} = \frac{l}{\mu S}$$
     其中 $\mu$ 由**磁路材质**决定，$l, S$ 为**磁路几何尺寸**，故 $R_m$ 与磁路材质及几何尺寸有关 ⇒ **B 正确**，E 错误。
  2. **主磁通幅值 $\Phi_m$**：
     在电源电压 $U_1$ 给定、忽略一次漏阻抗压降时，由 $U_1 \approx E_1 = 4.44 f N_1 \Phi_m$ 反解得
     $$\Phi_m = \frac{E_1}{4.44 f N_1} \approx \frac{U_1}{4.44 f N_1}$$
     可见在恒压交流励磁下，$\Phi_m$ **仅由 $U_1$、$f$、$N_1$ 决定，而与磁阻 $R_m$ 无关** ⇒ **D 正确**，C 错误。
  3. **空载电流 $I_0$**：
     由磁路欧姆定律 $N_1 I_0 \approx \Phi_m R_m$，代入 $\Phi_m$ 得
     $$I_0 \approx \frac{\Phi_m R_m}{N_1} \approx \frac{U_1 R_m}{4.44 f N_1^2}$$
     可见 $I_0$ **同时与 $U_1$、$f$、$N_1$ 和 $R_m$ 有关** ⇒ **A 正确**，F 错误。

  **答案：A、B、D**（平台正确答案：ABD）
- 复盘 :-
  - **整章最关键的物理因果链**：变压器接在**恒压电网**上，是**电压 $U_1$ 先强行定死主磁通 $\Phi_m$**（所以气隙变大、材质变差时 $\Phi_m$ 几乎不跌），然后磁路再拿磁阻 $R_m$ 去「索要」维持这个磁通所需的空载电流 $I_0$（所以铁芯叠片有缝或导磁变差时，遭殃的是 **$I_0$ 暴涨**，而不是 $\Phi_m$ 变小）。
:::
