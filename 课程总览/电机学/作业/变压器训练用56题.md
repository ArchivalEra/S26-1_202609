### 1.2 本页反复用的算式

$$U_1\approx E_1=4.44fN_1\Phi_m,\qquad k=\frac{N_1}{N_2},\qquad \Delta U\%\approx\beta\big(u_{kR}\cos\varphi_2+u_{kX}\sin\varphi_2\big)$$

$$\eta_{\max}\ \text{当}\ \beta^2p_{kN}=p_0$$

相位方向先说清：$\Phi=\Phi_m\sin\omega t$ 时 $e=-N\dfrac{\mathrm d\Phi}{\mathrm dt}$ 得 $e$ 滞后 $\Phi$ 恰好 $90°$；
励磁电流 $i_\mu$ 与 $\Phi$ 同相，所以它**超前** $e$ 90°。第 35 题只考这一个方向。

## 2. 单选题（第 1–37 题）

### 第 1 题

变压器负载运行，若负载电流（二次侧电流）增大，忽略一、二次侧阻抗压降影响，则主磁通不变、（　）。

⚠ 题面疑有笔误：显示位 D（原始位 C）的「铜损耗变不变」应为「铜损耗不变」。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | B | 铁芯损耗不变、铜损耗变大 |
| B | A | 铁芯损耗不变、铜损耗不变 |
| C | D | 铁芯损耗变大、铜损耗变大 |
| D | C | 铁芯损耗变大、铜损耗变不变 |

:::collapse accordion
- 提示
  主磁通既已不变，铁耗由什么定？铜耗由什么定？
- 完整解答
  **答案：A**（原始位 B，铁芯损耗不变、铜损耗变大）。依据：铁耗由 $\Phi_m$ 与频率决定，$\Phi_m$ 不变故铁耗不变；铜耗 $p_{Cu}=I^2r$ 随电流增大。
- 复盘
  别去「改正」题面：显示位 D 写作「铜损耗变不变」，照原样对待即可——它是错字，不是另一个可选答案。
:::

### 第 2 题

三相组式变压器（即三相变压器组）各相磁路（　），三相芯式变压器各相磁路（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | A | 彼此独立 彼此独立 |
| B | C | 彼此相关 彼此独立 |
| C | D | 彼此相关 彼此相关 |
| D | B | 彼此独立 彼此相关 |

:::collapse accordion
- 提示
  组式是几台变压器？芯式是一个铁芯几根柱？
- 完整解答
  **答案：D**（原始位 B，彼此独立　彼此相关）。依据：组式＝三台独立单相变压器，各有完整闭合铁芯，磁通不跨台；芯式＝一台三柱铁芯，上下两轭连成整体，任一相磁通须经另外两柱闭合。
- 复盘
  记法：**组＝三台分开（独立），芯＝一台三柱（相关）**。方向写反，后面三次谐波的题会跟着错。

### 第 3 题

下列与磁导率无关的物理量是（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | C | 磁场强度 |
| B | B | 磁通 |
| C | D | 磁阻 |
| D | A | 磁感应强度 |

:::collapse accordion
- 提示
  哪个量的定义式里根本没有 $\mu$？
- 完整解答
  **答案：A**（原始位 C，磁场强度）。依据：$\oint H\cdot\mathrm dl=\sum I$，$H$ 只由电流与几何决定；而 $B=\mu H$、$\Phi=BA$、$R_m=l/(\mu S)$ 都含 $\mu$。
- 复盘
  最容易误选「磁感应强度」——它恰恰是乘了 $\mu$ 的那个量，材料一换它就变。
:::

### 第 4 题

判定通电导线或通电线圈产生磁场的方向用（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | B | 左手定则 |
| B | D | 欧姆定律 |
| C | C | 楞次定律 |
| D | A | 右手螺旋法则 |

:::collapse accordion
- 提示
  「电流生磁」与「电流受力」是两个方向问题，本题问哪个？
- 完整解答
  **答案：D**（原始位 A，右手螺旋法则）。依据：电流生磁用右手螺旋；左手定则管电流在磁场中受力；楞次定律管感应电动势的方向。
- 复盘
  三个定则按「谁生谁」分工，别混用：电生磁→右手螺旋，磁对电流的力→左手，磁变生电→楞次。

### 第 5 题

单相双绕组变压器的两个绕组中，与电源连接的绕组是（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | B | 二次绕组 |
| B | D | 四次绕组 |
| C | A | 一次绕组 |
| D | C | 三次绕组 |

:::collapse accordion
- 提示
  一次／二次是按接线位置分的，还是按绕制先后分的？
- 完整解答
  **答案：C**（原始位 A，一次绕组）。依据：接电源侧称一次绕组（原边），接负载侧称二次绕组（副边）——「几次」讲接线位置，不是绕组编号。

### 第 6 题

Dyn11型变压器的低压侧线电压的时间相位滞后于高压侧相应线电压（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | C | 30° |
| B | D | 330° |
| C | A | 0° |
| D | B | 11° |

:::collapse accordion
- 提示
  标号末位数字是时钟点数，一点等于多少度？「滞后」从谁量到谁？
- 完整解答
  **答案：B**（原始位 D，$330°$）。依据：高压侧线电压摆 12 点、低压侧指 11 点，一点＝$30°$，滞后 $11\times30°=330°$（Octave：$11\times30=330$）。
- 复盘
  题问「滞后」多少，$30°$ 是**超前**量。$330°=360°-30°$，两者是同一相位关系的两种说法。
:::

### 第 7 题

变压器带感性（电阻+电感）负载运行时，则其二次侧电压U2数值上一定（　）二次侧空载电压U20。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | D | 以上选项皆有可能 |
| B | C | 大于 |
| C | B | 等于 |
| D | A | 小于 |

:::collapse accordion
- 提示
  把 $U_2$ 与 $\Delta U$ 的关系写出来，再判 $\Delta U$ 在感性负载下的正负。
- 完整解答
  **答案：D**（原始位 A，小于）。依据：$\Delta U\%\approx\beta(u_{kR}\cos\varphi_2+u_{kX}\sin\varphi_2)>0$，而 $U_2=U_{20}(1-\Delta U\%)$，故 $U_2<U_{20}$。
- 复盘
  「一定」要守住：只有**容性**负载 $\sin\varphi_2<0$ 时 $\Delta U$ 才可能为负、$U_2>U_{20}$。
:::

某单相变压器，一次侧绕组N1=100匝，二次侧绕组N2=5匝，则变压器变比k为（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | D | 5 |
| B | A | 0.02 |
| C | C | 20 |
| D | B | 1 |

:::collapse accordion
- 提示
  变比取 $N_1/N_2$ 还是 $N_2/N_1$？

### 第 9 题

当正弦变化的交流电源电压施加到变压器的一次绕组后，在变压器铁芯中产生的磁通为（　）磁通。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | D | 脉冲 |
| B | A | 恒定 |
| C | C | 旋转 |
| D | B | 交变 |

:::collapse accordion
- 提示
  $e=-N\,\mathrm d\Phi/\mathrm dt$：正弦的积分还是正弦，频率不变。
- 完整解答
  **答案：D**（原始位 B，交变）。依据：由 $e=-N\dfrac{\mathrm d\Phi}{\mathrm dt}$ 反解，正弦电压对应同频正弦磁通，$\Phi_m\approx U_1/(4.44fN_1)$。
- 复盘
  「旋转磁通」是异步机、同步机定子才有的；变压器铁芯里是**脉振（交变）**磁通。
:::

### 第 10 题

变压器利用（　）将一种电压等级的交流电能转变为同频率的另一种电压等级的交流电能。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | A | 电磁感应原理 |
| B | C | 基尔霍夫定律 |
| C | D | 双反应理论和叠加原理 |
| D | B | 电机可逆性原理 |

:::collapse accordion
- 提示
  一次通交流→主磁通交变→二次感应电动势，这条链只用哪条定律？
- 完整解答
  **答案：A**（原始位 A，电磁感应原理）。依据：一次绕组产生交变主磁通，与二次绕组交链感应出同频电动势，全过程只用电磁感应定律与 $E=4.44fN\Phi_m$。
- 复盘
  「电机可逆性原理」讲同一台电机可作发电机也可作电动机；「双反应理论」属同步机，都与变压无关。
:::

### 第 11 题

在发电厂安装在输电线路始端的变压器为（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | C | 降压变压器 |
| B | B | 配电变压器 |
| C | A | 厂用变压器 |
| D | D | 升压变压器 |

:::collapse accordion
- 提示
  电厂把发电机电压（如 10–20 kV）抬到输电电压（220–500 kV）才能送出去，始端这台干的是升还是降？
- 完整解答
  **答案：D**（原始位 D，升压变压器）。依据：输电线路始端要把发电机电压升高以减小线路电流与损耗，故为升压变压器；线路末端与配电侧才是降压变压器。
- 复盘
  「厂用变压器」也装在电厂，但它供厂内辅机用电、从发电机电压降下来用，不在输电线始端这个位置上。
:::

### 第 12 题

当（　）时，变压器运行效率最高。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | A | $\beta p_{kN}=P_0$ |
| B | D | $\beta^{2}p_{kN}=P_0$ |
| C | C | $\beta p_0=p_{kN}$ |
| D | B | $\beta^{2}p_0=p_{kN}$ |

:::collapse accordion
- 提示
  效率最大的条件是「可变损耗＝不变损耗」。哪一个随 $\beta$ 平方变？含 $\beta^2$ 的必须是铜耗那一项。
- 完整解答
  **答案：B**（原始位 D，$\beta^{2}p_{kN}=P_0$）。依据：效率 $\eta=\dfrac{\beta S_N\cos\varphi_2}{\beta S_N\cos\varphi_2+p_0+\beta^{2}p_{kN}}$，对 $\beta$ 求极值得 $\beta^{2}p_{kN}=p_0$，即铜耗（可变损耗）等于铁耗（不变损耗）时效率最高（Octave 代入 $p_0=1$、$p_{kN}=4$ 得 $\beta_m=0.5$，数值扫描 $\eta(\beta)$ 的最大值点也是 0.5）。
- 复盘
  三个错项各错一处：A 把 $\beta^2$ 写成 $\beta$；C、D 把 $p_0$ 与 $p_{kN}$ 摆反了——含 $\beta$ 的必须是随负载变的那一项（铜耗）。
  这题在 [2.2.3 变压器运行性能](2.2.3变压器运行性能.md) 第 1 题出现过，**四个原始位逐一对得上**（原始位 A＝$\beta p_{kN}=P_0$、B＝$\beta^2p_0=p_{kN}$、C＝$\beta p_0=p_{kN}$、D＝$\beta^2p_{kN}=P_0$）——两页只是显示顺序不同，答案同为 $\beta^2p_{kN}=P_0$，可互相校对。

> 四张选项图取自平台（需登录会话，匿名直连返回 403），按导出件 `images` 数组顺序对应显示位 A–D。
:::

### 第 13 题

YNy连接的变压器负载运行时如果主磁通为正弦波，则相电动势为（　）波。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | B | 平顶波 |
| B | C | 尖顶波 |
| C | A | 正弦波 |
| D | D | 矩形波 |

:::collapse accordion
- 提示
  $e=-N\,\mathrm d\Phi/\mathrm dt$：正弦的导数是什么形状？题面给的前提是哪一条？
- 完整解答
  **答案：C**（原始位 A，正弦波）。依据：$\Phi=\Phi_m\sin\omega t$ 代入 $e=-N\dfrac{\mathrm d\Phi}{\mathrm dt}$ 得 $e=-N\omega\Phi_m\cos\omega t$，仍是同频正弦，不含新谐波。
- 复盘
  别被「YNy」「三次谐波」带偏：题面已把**主磁通为正弦**写死，铁芯饱和那条路被堵掉了。
:::

### 第 14 题

我国国标规定电力变压器的额定频率为（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |

- 复盘
  「110 kV 及以上」正好是最不能用的那一头；「以上说法都不正确」是干扰项，读它之前先判其余三项。
:::

### 第 33 题

变压器运行在额定电压及频率下，若铁芯导磁性能越好，则该变压器的（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | B | 励磁电抗Xm越小、空载电流I0越大 |
| B | A | 励磁电抗Xm越小、空载电流I0越小 |
| C | C | 励磁电抗Xm越大、空载电流I0越小 |
| D | D | 励磁电抗Xm越大、空载电流I0越大 |

:::collapse accordion
- 提示
  导磁好意味着同样的磁通只需更小的励磁磁动势，也就是 $Z_m$ 怎么变？
- 完整解答
  **答案：C**（原始位 C，$X_m$ 越大、$I_0$ 越小）。依据：$X_m\propto \mu$、$I_0\approx U_1/X_m$；导磁性能好 ⇒ $\mu$ 大 ⇒ $X_m$ 大 ⇒ 空载电流小。
- 复盘
  别把「导磁好」想成「电抗小」：$X_m=\omega L_m$ 与 $\mu$ 成正比，导磁越好电抗越大，电流才越小。
:::

### 第 34 题

单相变压器负载运行时的磁动势平衡式书写正确的是（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | C | $N_1\dot I_1=N_2\dot I_2+N_1\dot I_0$ |
| B | B | $N_1I_1=N_2I_2+N_1I_0$ |
| C | D | $N_1\dot I_1+N_2\dot I_2=N_1\dot I_0$ |
| D | A | $N_1I_1+N_2I_2=N_1I_0$ |

:::collapse accordion
- 提示
  磁动势平衡说的是「一次磁动势＝二次磁动势＋励磁磁动势」，三项同在一侧相加的两项里，二次那一项必须与励磁项同号；此外这些量是正弦相量，写法上要带相量符号。
- 完整解答
  **答案：C**（原始位 D，$N_1\dot I_1+N_2\dot I_2=N_1\dot I_0$）。依据：负载时磁动势由一、二次电流共同产生并共同平衡励磁磁动势，即 $\dot I_1N_1+\dot I_2N_2=\dot I_0N_1$；无论取哪一侧作参考，这一式都能等价写成 $\dot I_1=\dot I_0-\dfrac{N_2}{N_1}\dot I_2$（第 24 题正是它的推论）。
- 复盘
  A、B 把二次项搬到等号右边并保持正号，等价于 $\dot I_1N_1-\dot I_2N_2=\dot I_0N_1$，符号错了。D 的式子与 C 完全相同，唯一差别是四个电流符号上没有相量点——正弦量之间的平衡必须按相量写，所以「书写正确」的只有 C。

> 四张选项图取自平台（需登录会话，匿名直连返回 403），按导出件 `images` 数组顺序对应显示位 A–D。
:::

### 第 35 题

对变压器空载运行时，下列对变压器各时间相量参数的相位关系描述正确的是（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | A | 主磁通与感生电动势的相位相同，滞后磁化电流90°。 |
| B | D | 磁化电流与主磁通的相位相同，超前感生电动势90°。 |
| C | B | 主磁通与感生电动势的相位相同，超前磁化电流90°。 |
| D | C | 磁化电流与主磁通的相位相同，滞后感生电动势90°。 |

:::collapse accordion
- 提示
  $\Phi=\Phi_m\sin\omega t$ 代入 $e=-N\,\mathrm d\Phi/\mathrm dt$，$e$ 与 $\Phi$ 差多少度？$i_\mu$ 与 $\Phi$ 同相还是差 90°？
- 完整解答
  **答案：B**（原始位 D）。依据：$e=-N\dfrac{\mathrm d\Phi}{\mathrm dt}$ 得 $e$ 滞后 $\Phi$ 90°；励磁（磁化）电流 $i_\mu$ 与 $\Phi$ 同相，故 $i_\mu$ **超前** $e$ 90°。
- 复盘
  A、C 开头就说「主磁通与电动势相位相同」，这一步就错了——两者恒差 90°。D 的「同相」对了、「滞后」反了。
:::

### 第 36 题

变压器变比k为10，一次侧绕组匝数N1为1000匝，则二次侧绕组匝数N2为（　）匝。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | B | 100 |
| B | A | 10 |
| C | D | 10000 |
| D | C | 1000 |

:::collapse accordion
- 提示
  $k=N_1/N_2$ 反解：$N_2=N_1/k$。
- 完整解答
  **答案：A**（原始位 B，100）。依据：$N_2=N_1/k=1000/10=100$ 匝（Octave 验算得 100）。
- 复盘
  10000 是把 $k$ 乘上去（当成 $N_2=kN_1$）；10 是把 $k$ 当匝数差，两个都是把除乘弄反。
:::

### 第 37 题

当需要折算时，应保持变压器电磁平衡关系不变，当需要从二次侧折算到一次侧时应（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | A | 保持折算前后磁动势不变。 |
| B | D | 保持折算前后一次侧电磁功率及损耗不变。 |
| C | B | 保持折算前后电动势不变。 |
| D | C | 保持折算前后二次侧电磁功率及损耗不变。 |

:::collapse accordion
- 提示
  折算的出发点是让一、二次两个电路能接到同一个等效回路上——靠保持哪条平衡关系来定折算系数？
- 完整解答
  **答案：A**（原始位 A，保持折算前后磁动势不变）。依据：折算原则是保持折算前后**磁动势不变**（$I_2N_2$ 不变，故 $I_2'=I_2/k$、$E_2'=kE_2$），由此电磁功率与损耗自动守恒——功率、损耗不变是**结果**，不是出发点。
- 复盘
  提醒一句：本课笔记把「磁动势不变」与「功率、损耗不变」并列为两条不变量（[10-15 空载运行与负载运行](../课堂笔记/10-15-空载运行与负载运行.md) 归算一节），显示位 D 说的正是第二条。定**折算系数**用的仍是磁动势那一条，故按原则取 A；若某个答案键标 D，那是并列两条里挑了另一条，不是物理上的分歧。B 必然错：折算本身就是按 $k$ 改电动势。
:::

## 3. 判断题（第 38–53 题）

### 第 38 题

电力变压器带额定负载时的电压变化率，称为额定电压变化率。（　）

:::collapse accordion
- 完整解答
  **答案：对。** 依据：额定电压变化率的定义就是一次加额定电压、二次由空载到带**额定电流**（$\beta=1$）时 $U_{20}$ 与 $U_2$ 之差相对 $U_{20}$ 的百分比，负载条件正是「带额定负载」。
- 复盘
  注意「额定电压变化率」是铭牌上的一个定值，而 $\Delta U(\beta,\varphi_2)$ 是随负载变化的函数；前者是后者在 $\beta=1$ 处的特例，别把两者混为一谈。
:::

### 第 39 题

变压器空载实验测得的损耗近似等于铁损耗 ，短路实验测得的损耗近似等于铜损耗 。（　）

:::collapse accordion
- 完整解答
  **答案：对。** 依据：空载时 $I_0$ 不到额定的 1%，铜耗 $I_0^2r$ 可忽略，功率表读到的基本是铁耗（$p_0\approx p_{Fe}$）；短路时外施电压只有额定的几个百分点，磁通极小、铁耗可忽略，读到的是铜耗（$p_k\approx I_k^2r_k$）。
- 复盘
  「近似」二字不能删：空载时仍含一点点铜耗，短路时仍含一点点铁耗，两个近似各有依据，方向都是「另一项小到可以忽略」。
:::

### 第 40 题

如果想调低一降压变压器二次侧电压，则须通过调整分接开关使N2减小来实现。（　）

:::collapse accordion
- 完整解答
  **答案：错。** 依据：分接开关的抽头做在**高压（一次）绕组**上，运行中能改的只有 $N_1$；$U_2=U_1N_2/N_1$，要调低 $U_2$ 须**增大 $N_1$**。$N_2$ 已绕死、现场不可改。
- 复盘
  这题与第 28 题是同一台设备的一对反向问法：二次电压低→减小 $N_1$；二次电压高→增大 $N_1$。改了 $N_2$ 的说法一律错。
:::

### 第 41 题

空载实验时须用低功率因数瓦特表测量变压器的损耗，因为变压器空载运行时的功率因数很低。（　）

:::collapse accordion
- 完整解答
  **答案：对。** 依据：空载时 $I_0$ 以感性无功为主、有功只占极小比例，$\cos\varphi_0$ 只有 0.1–0.2 量级；普通瓦特表在这个区间读数误差大，故用低功率因数瓦特表（额定 $\cos\varphi$ 为 0.1 或 0.2 的表）。
- 复盘
  因果要摆对：不是「低功率因数表让功率因数变低」，而是「功率因数本来就低，所以要用低功率因数表」——量程与被测量匹配。
:::

### 第 42 题

从正常运行的角度看，希望短路阻抗小一些，这样二次侧电压波动小；但从短路故障的角度看，希望短路阻抗大一些，这样相应的短路电流就会小些。（　）

:::collapse accordion
- 完整解答
  **答案：对。** 依据：$\Delta U\%\approx\beta(u_{kR}\cos\varphi_2+u_{kX}\sin\varphi_2)$，$u_k$ 小则电压变化率小、端电压稳；而稳态短路电流 $I_k=I_N/u_k$，$u_k$ 大则短路电流小、对绕组与开关设备的冲击小。两个要求方向相反，选值只能折中。
- 复盘
  这是「一对矛盾指标」的典型题：两边都成立，所以整句对。别因为它前后主张相反就判错——题目说的是两种不同工况下的不同愿望。
:::

### 第 43 题

一台正常运行中的变压器，其主磁通幅值Φm的大小主要取决于电源电压的大小和频率。（　）

:::collapse accordion
- 完整解答
  **答案：对。** 依据：$\Phi_m\approx\dfrac{U_1}{4.44fN_1}$，$N_1$ 出厂已定，故 $\Phi_m$ 由 $U_1$ 与 $f$ 决定，与负载无关。
- 复盘
  与第 21 题同一条式子，说法换了个语序。这两题一起练，确认「主磁通由电压锁死」这条不因题型变化。
:::

### 第 44 题

变压器的电压变化率与变压器参数、负载大小及性质有关。（　）

:::collapse accordion
- 完整解答
  **答案：对。** 依据：$\Delta U\%\approx\beta(u_{kR}\cos\varphi_2+u_{kX}\sin\varphi_2)$——$u_{kR},u_{kX}$ 来自变压器参数，$\beta$ 是负载大小，$\varphi_2$ 是负载性质，三者都在式子里。
- 复盘
  「性质」指的是功率因数角 $\varphi_2$ 而非功率数值：容性负载 $\sin\varphi_2<0$ 会让 $\Delta U$ 变号，这才是「性质」二字的分量。
:::

### 第 45 题

若变压器短路阻抗标幺值Zk*=0.06，则短路电压Uk%=6%。（　）

:::collapse accordion
- 完整解答
  **答案：对。** 依据：$u_k\%=Z_k^*\times100\%$（短路电压的标幺值就是短路阻抗的标幺值），故 $Z_k^*=0.06$ 对应 $u_k\%=6\%$（Octave 验算 $0.06\times100=6$）。
- 复盘
  标幺值与百分值差一个 100 倍：$Z_k^*=0.06$ 与 $u_k\%=6\%$ 是同一个数，别写成 $0.06\%$。
:::

### 第 46 题

为求取变压器短路参数，在实验中要求短路电流必须等于额定值时才可以读取短路电压和短路功率。（　）

:::collapse accordion
- 完整解答
  **答案：错。** 依据：短路特性在低电压下是**直线**，工作在磁路线性区，任意电流点测得的值都可按比例推到额定点（$U_k$ 与 $I_k$ 同比、$p_k$ 与 $I_k^2$ 同比）；只要不超太多以免绕组过热，取哪点都行。教材口径：只有上铭牌的 $u_k\%$ 才必须在 $I_k=I_N$ 那一刻取值。
- 复盘
  题干的错在「必须先让电流等于额定值才能读」。正确说法是「不必等于，但要折算到额定电流」。这与空载试验相反——空载特性是弯的，必须在额定电压那一点测。
:::

### 第 47 题

空载实验时，记录温度是为将励磁电阻值换算到运行温度75℃值，以方便比较。（　）

:::collapse accordion
- 完整解答
  **答案：错。** 依据：需要按 75 ℃ 换算的是**绕组直流电阻**（$r_1$、$r_k$ 是真实铜电阻，随温度变，铜的温度系数约 $0.004/\mathrm{^\circ C}$）；而空载试验得到的 $r_m$ 是用 $p_0/I_0^2$ **等效**出来的励磁电阻，代表铁耗，铁耗基本不随绕组温度变，没有「换算到 75 ℃」这回事。空载试验记录温度（以及短路试验记录温度）是为了给**铜电阻**换算留依据。
- 复盘
  这题的错法很有代表性：把「试验要记温度」这条纪律，安到了「励磁电阻要换到 75 ℃」这个不存在的规定上。记住 75 ℃ 只跟铜（直流电阻）有关。
:::

### 第 48 题

单相变压器空载运行时若主磁通Φ为正弦波，则空载励磁电流I0为尖顶波。（　）

:::collapse accordion
- 完整解答
  **答案：对。** 依据：铁芯饱和使 $\Phi$–$i_0$ 非线性，正弦磁通需要**尖顶**电流才够（过零附近磁通上升慢，要额外电流把它顶上去）；尖顶电流含三次谐波为主。
- 复盘
  与第 15 题同一条结论的判断题形式：磁通正弦 ⇒ 电流尖顶；反过来电流正弦 ⇒ 磁通平顶。方向反了就错。
:::

### 第 49 题

空载实验时并不要求外施电压一定等于额定电压，但要求必须同时读取空载电流、空载电压和空载损耗。（　）

:::collapse accordion
- 完整解答
  **答案：错。** 依据：空载特性是**弯的**（$I_0$、$p_0$、$Z_m$ 都随电压变，因为饱和程度在变），所以教材要求外施电压**必须做到额定电压**（再在额定值上下各取一两点作对照），否则算出的 $x_m$ 不是工作点的值。后半句「同时读三点」是对的，但前半句的「并不要求」与这条硬规定相反。
- 复盘
  易错在只看后半句就判对。判断题一律整句判：只要有一个分句与教材口径相反，整句就是错。这句与第 46 题正好构成一对——短路试验不要求额定值，空载试验要求。
:::

### 第 50 题

若变压器二次侧三相基波电流时间相位互相差120°，则各相三次谐波电流时间相位互相差40°。（　）

:::collapse accordion
- 完整解答
  **答案：错。** 依据：$k$ 次谐波相位差为 $k\times120°$，三次谐波 $3\times120°=360°$，即同相、互差 $0°$（Octave：$\mathrm{mod}(3\times120,360)=0$）。40° 是把 $120°$ 除以 3 得来的，方向正好弄反。
- 复盘
  「除以次数」是把谐波当成了「频率变成 1/3」；谐波是频率变**大** $k$ 倍，相位差也跟着变**大** $k$ 倍。这条与第 18 题同源。
:::

### 第 51 题

铁磁性物质的磁滞回线包围的面积越大,说明磁滞损耗也越大。（　）

:::collapse accordion
- 完整解答
  **答案：对。** 依据：磁滞损耗 $p_h\propto f\,S_{\text{回线}}$，回线面积 $S=\oint H\,\mathrm dB$ 就是一个周期内单位体积的磁滞能耗。
- 复盘
  与第 25 题同一条结论。面积大＝磁滞能耗大，所以电机、变压器铁芯都用磁滞回线窄的软磁材料。
:::

### 第 52 题

采用标幺值计算同时也起到了归算作用。（　）

:::collapse accordion
- 完整解答
  **答案：对。** 依据：各量都以本侧基准值（$U_N$、$I_N$、$Z_N=U_N/I_N$）表出，而基准值本身按变比挂钩（$Z_{2N}=Z_{1N}/k^2$），所以两侧标幺值直接可比，不必再逐项折算。
- 复盘
  严格说「起到」二字要理解成「省掉了折算这一步」，不是说折算可以不做：标幺值让 $k$ 从式子里消失，副作用正是归算已被基准值吸收。
:::

### 第 53 题

油浸式电力变压器的铁芯和绕组完全放置在充满油的油枕中。（　）

:::collapse accordion
- 完整解答
  **答案：错。** 依据：铁芯与绕组（器身）浸在**油箱**里；油枕（储油柜）装在油箱上方，容积小，只用来补偿油因温度变化引起的体积增减、并减小油面与空气的接触。
- 复盘
  与第 17 题是同一处混淆的两种题型。器身在油箱，油枕只管油位——「完全放置在油枕中」在结构上根本装不下。
:::



## 4. 多选题（第 54–56 题）

### 第 54 题

变压器铁芯导磁性能越好，则其运行在额定电压及频率下，（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | A | 励磁电抗Xm越小 |
| B | D | 空载电流I0越大 |
| C | B | 励磁电抗Xm越大 |
| D | C | 空载电流I0越小 |

:::collapse accordion
- 提示
  导磁性能好 ⇒ $\mu$ 大 ⇒ 励磁电抗 $X_m$ 变大，还是变小？空载电流与 $X_m$ 成什么关系？
- 完整解答
  **答案：C、D**（显示位 C＝$X_m$ 越大，原始位 B；显示位 D＝$I_0$ 越小，原始位 C）。依据：$X_m=\omega L_m$，$L_m$ 与铁芯磁导率成正比，导磁越好 ⇒ $X_m$ 越大。额定电压下 $I_0\approx U_1/X_m$，故 $X_m$ 越大、$I_0$ 越小。两项是同一件事的两面，必须一起选。
- 复盘
  只选一项是这题最常见的失分点：命题人把一条因果关系拆成「因（$X_m$ 大）」和「果（$I_0$ 小）」两个选项，漏一项就等于只说了一半。A 与 B 把大小关系写反，C、D 才是自洽的一组。
:::

### 第 55 题

在下列对变压器负载运行的描述中，正确的有（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | D | 变压器负载运行时的功率因数比空载运行时的功率因数低。 |
| B | A | 主磁通与负载电流无关，不随负载电流的变化而变化。 |
| C | C | 变压器负载运行时的功率因数比空载运行时的功率因数高。 |
| D | B | 负载运行时磁动势是由各侧电流共同产生，因此负载电流的变化时，主磁通也将随之变化。 |

:::collapse accordion
- 提示
  主磁通由谁决定？磁动势由谁产生？把第 21 题与磁动势平衡式合起来看。
- 完整解答
  **答案：B、C**（显示位 B＝主磁通与负载电流无关，原始位 A；显示位 C＝负载时功率因数比空载高，原始位 C）。依据：$\Phi_m\approx U_1/(4.44fN_1)$ 由电源电压与频率锁定，负载电流变化时一次电流同步补偿（$\dot I_1=\dot I_0-\dot I_2N_2/N_1$），磁动势平衡的结果恰是主磁通近似不变；而空载时电流几乎全是感性无功、$\cos\varphi_0$ 只有 0.1–0.2 量级，带上正常功率因数的负载后功率因数显著提高。
- 复盘
  A 与 C 方向相反、只能选一个，判断依据是空载的功率因数**极低**：空载电流几乎全是建立主磁通的感性无功分量，$\cos\varphi_0$ 只有 0.1–0.2，所以带载后是「变高」而不是「变低」。D 的前半句（磁动势由各侧电流共同产生）本身没错，错在后半句「因此主磁通也随之变化」——磁动势平衡恰恰保证了主磁通不变。这种「前半句对、后半句错」的选项在多选题里最容易被整套勾上。
:::

### 第 56 题

下列关于Yy连接的三相变压器描述正确的是（　）。

⚠ 题面疑有笔误：原始位 B 段「因磁阻小副使…值较大小」应为「因磁阻小致使…值较大」；原始位 D 段「经过油箱壁灯铁磁构件」应为「等」；原始位 A 段「$I_{03}=O$」用了字母 O 而非数字 0。三处均照原样抄录。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | D | 三相芯式变压器可用Yy接线时，3次谐波分量经过油箱壁灯铁磁构件时，产生电涡流发热，会引起材料老化和效率降低，因此Yy连接方式只能用于1800kVA及以下的三相芯式变压器中。 |
| B | A | 采用Yy连接的三相变压器，由于I03=O,又因铁磁材料的饱和特性使I0、Φm呈非线性关系，因此正弦波I0产生平顶波Φm， Φm除基波分量外，还含有3、5、7......奇次谐波分量………，其中主要为3次谐波分量。 |
| C | B | 三相组式变压器中Φm中的3次谐波分量因和基波分量同样经过主磁路、因磁阻小副使3次谐波分量值较大小，在二次侧产生的3次谐波电势大，约有基波分量50-60%，使电势波形严重畸变、而且产生过电压，因此三相组式变压器不选用Yy接线。 |
| D | C | 三相芯式变压器中Φm中的3次谐波分量主要经过部分主磁路、绝缘油、套管、空气、油箱壁构成的磁路，磁阻较大使3次谐波分量值较小，在二次侧产生的3次谐波电势小，对电势波形畸变不严重，仍然近似正弦波，因此三相芯式变压器可用Yy接线。 |

:::collapse accordion
- 提示
  四段话构成一条链：为什么会有三次谐波 → 组式会怎样 → 芯式会怎样 → 所以 Yy 的边界在哪。逐段核对方向。
- 完整解答
  **答案：A、B、C、D**（全选）。依据：B 段（原始位 A）讲 Yy 无中性线 ⇒ $I_{03}=0$ ⇒ 正弦 $I_0$ 在饱和铁芯里得平顶 $\Phi_m$、含奇次谐波，与 1.2 节推的一致；C 段（原始位 B）组式磁路独立、三次谐波磁通与基波同走主磁路、磁阻小、二次谐波电动势可达基波的 50%–60%，故组式不用 Yy；D 段（原始位 C）芯式三次谐波磁通走油、套管、空气、油箱壁，磁阻大、谐波电动势小，故芯式可用 Yy；A 段（原始位 D）芯式 Yy 的谐波磁通扫过油箱壁产生涡流发热，故限 1800 kVA 及以下。四段与教材口径一致。
- 复盘
  全选题最容易漏选。检查办法：把四段排成「因 → 组式果 → 芯式果 → 边界」，链条闭合就没有错项。另注意 C 段原文「磁阻小副使 3 次谐波分量值较大小」是平台录题时的错字（应为「磁阻小致使 3 次谐波分量值较大」），不影响判断。
:::

## 5. 小结：这份训练真正想教的三件事

1. **主磁通由电压锁死，不由负载决定。** $\Phi_m\approx U_1/(4.44fN_1)$ 一条式子统住了十来道题：第 1、21、24、43 题问它为什么不变，第 55 题问它为什么与负载无关，第 33 题与第 54 题问它靠什么参数变小、又怎样才能小。负载的变化被磁动势平衡吸收在一次电流里——这正是「负载增、一次电流增」与「主磁通不动」能同时成立的原因。
2. **两个试验各管一半，且对电流的要求正好相反。** 空载看铁耗、短路看铜耗（第 26、39 题）；空载特性是**弯**的，所以必须做到额定电压（第 49 题）；短路特性是**直**的，所以任意电流点都行、只要折算到额定（第 46 题）。记这两条时把「弯/直」当作总纲，其余细节都能推出来。
3. **磁通与电流的波形互变、组式与芯式的磁路之别。** 前者管第 15、48 题（磁通正弦⇒电流尖顶）与第 13 题（磁通正弦⇒电动势正弦）；后者管第 2、32、56 题（组式磁路独立、谐波走得通；芯式磁路相关、谐波只能出油箱壁），并直接给出 Yy 接线的容量边界。
