# 3.1.1旋转电机及交流绕组

| 题号 | 用到的知识 | 说明 |

| 第 3 题 | **相电动势公式与变压器电动势公式的差别** | 变压器 $E=4.44fN\Phi_m$ 没有绕组因数；旋转电机多一个 $k_w\le1$ |

| 第 6 题 | **波绕组的使用场合** | 绕线式异步电动机转子、多极水轮发电机定子 |

| 第 9 题 | **极距、每极每相槽数、槽距角三式计算** | $\tau=Z/(2p)$、$q=Z/(2pm)$、$\alpha=360°p/Z$ |

### 1.1 三个基本算式（第 9 题直接用）

对 $m$ 相、$Z$ 槽、极对数 $p$ 的电机：

$$\tau=\frac{Z}{2p}\ (\text{槽}),\qquad q=\frac{Z}{2pm},\qquad \alpha=\frac{360°\cdot p}{Z}\ (\text{电角度})$$

三者互为校验：$q\alpha=180°/m$。三相对称绕组就是靠这一条把 $60°$ 相带定下来的。

### 1.2 电角度与机械角度

沿圆周走一圈是 $360°$ **机械角度**，而磁场在一对极下完成一个完整变化周期、对应 $360°$ **电角度**。
极对数为 $p$ 时

$$\alpha_{\text{电}}=p\cdot\alpha_{\text{机械}}$$

所以「槽距角」问的是电角度——这是第 2 题的唯一考点。

## 2. 单选题（第 1–4 题）

### 第 1 题

同步发电机的相序（　）。

| 显示位 | 选项 |
| :---: | :--- |
| A | 只跟定子绕组分布 |
| B | 跟转子转向和定子绕组分布都没有关系 |
| C | 跟转子转向和定子绕组分布都有关 |
| D | 只跟转子转向有关 |

:::collapse accordion
- 提示
  相序是「三相对称电动势到达最大值的先后次序」。它既要看**谁在动**（转子），也要看**三相绕组摆在哪**（定子）。
- 完整解答
  **第一步：相序是怎么产生的。** 同步发电机的转子由原动机拖动、以同步转速旋转，转子磁极的磁场
  依次扫过定子的 A、B、C 三相绕组，三相绕组里就依次感应出电动势。**谁先被扫到，谁的电动势就先到最大**——这就是相序。

  **第二步：两个因素各管什么。**

  - **转子转向**：磁场扫过三相绕组的**次序**由它决定。反转就变成 A→C→B。
  - **定子绕组分布**：三相绕组在空间上的**排列次序**（A、B、C 谁在哪个槽位）同样决定扫过的次序。

  **第三步：组合。** 转向改变、或三相绕组排列改变，任一项单独变化都会翻转相序；两项同时改变则相序不变。
  所以相序**同时**取决于这两者。

  **答案：C**（跟转子转向和定子绕组分布都有关）
- 复盘
  - 最容易错选 D「只跟转子转向有关」。错在忽略了绕组的**空间排列**——绕组接反（比如 B、C 两相对调），
    转子转向没变，相序却反了。这是现场接线时真会碰到的故障。
  - 反过来，若把转向与绕组排列同时改，相序**回到原样**——这一点可以用来出「两个都改会怎样」的变式题。
:::

### 第 2 题

旋转电机绕组槽距角 $\alpha$ 为相邻两槽之间的（　）。

| 显示位 | 选项 |
| :---: | :--- |
| A | 电角度 |
| B | 弧度 |
| C | 机械角度 |
| D | 夹角 |

:::collapse accordion
- 提示
  想想「槽距角为什么要乘极对数」——凡是要乘 $p$ 的，都是电角度。
- 完整解答
  **第一步：定义。** 槽距角是**相邻两个槽中心线之间**的角度，按**电角度**计：

  $$\alpha=\frac{360°\,p}{Z}$$

  **第二步：与机械角度的区别。** 同一台电机，相邻两槽的机械角度是 $360°/Z$，是个定值；
  而电角度要乘极对数 $p$。$p=2$ 时电角度是机械角度的 2 倍。**只有电角度才反映电动势的相位差**，
  因为电动势的相位差取决于磁场极性的变化，而一对极对应一个完整周期。

  **第三步：为什么不是 B、D。**

  - B「弧度」是**单位**，不是量的种类——电角度也能用弧度表示（$\pi$ 弧度 $=180°$），所以 B 是把单位和量混淆。
  - D「夹角」是泛指，没有说明是机械的还是电的，而这一题问的正是**哪一种角度**。

  **答案：A**（电角度）
- 复盘
  - 关键判据一句话：**凡是与电动势相位、与极对数相乘有关的角，都是电角度**；凡是与几何尺寸、与圆周均分有关的角，都是机械角度。
  - 口算校验：$Z=36$、$p=2$ 时 $\alpha=360°\times2/36=20°$ **电角度**，而机械角度只有 $10°$。第 9 题用的就是这个数。
:::

### 第 3 题

同步发电机的感生电动势有效值公式（　）。

| 显示位 | 选项 |
| :---: | :--- |
| A | 和变压器的不同，为（式略） |
| B | 和变压器的不同，为（式略） |
| C | 和变压器的相同，为（式略） |
| D | 和变压器的不同，为（式略） |

⚠ 平台本题三个「式略」选项各自内嵌的公式图片在导出件里未保存下来，**只留下文字部分**，
因此无法逐字比对四处公式的差别；下列解析按教材口径说明两者的**结构差别**，不代为判定选项里具体写的是哪一式。

:::collapse accordion
- 提示
  把两个公式并排写出来，只有一处不同——那一处就是答案。
- 完整解答
  **第一步：变压器感应电动势。**

  $$E_1=4.44fN_1\Phi_m$$

  **第二步：旋转电机一相绕组的感应电动势。**

  $$E_\Phi=4.44fNk_w\Phi_m$$

  其中 $k_w=k_yk_q$ 是**绕组因数**（节距因数 × 分布因数），恒有 $k_w\le1$。

  **第三步：差别的物理来源。** 变压器的绕组是集中式的，一个线圈的每一匝都处在大致相同的磁通变化里，
  所以各匝电动势直接代数相加，不需要打折。旋转电机的绕组**分布**在多个槽里、还可能**短距**，
  各线圈边感应出的电动势相位不完全相同，合成时要做**相量相加**，合出来的幅值一定小于代数相加——这个「折扣」就是 $k_w$。

  **答案：B**（和变压器的不同）
  > 判定依据是「同/不同」这一层：两者**结构不同**（旋转电机多一个 $k_w$），所以凡是说「相同」的选项都错；
  > 具体写的是 $k_w$ 还是别的字母，因公式图片缺失本页不代为断言。
- 复盘
  - 记法：**变压器 $k_w=1$**（集中绕组、整距、不分布），旋转电机 $k_w\le1$。这也是为什么变压器公式里看不到 $k_w$。
  - 常见错法：把 $4.44$ 记成 $2.22$。$4.44=\pi/\sqrt2\times2$ 是**有效值**系数（幅值 $E_m=\pi fN\Phi_m$，除以 $\sqrt2$ 得 $4.44$ 的一半再乘…），
    而 $2.22$ 是**平均值**那一支。做题前先问「要的是有效值还是平均值」。
:::

### 第 4 题

旋转电机主磁路和变压器主磁路（　）。

| 显示位 | 选项 |
| :---: | :--- |
| A | 作用相同；但结构有差异：不连续，在转子铁芯和定子铁芯中间由气隙隔开。 |
| B | 作用不相同；结构也有差异：不连续，在转子铁芯和定子铁芯中间由气隙隔开。 |
| C | 作用相同；结构也相同：都是由铁芯和铁轭组成，是连续的。 |
| D | 作用不相同；但结构相同：都是由铁芯和铁轭组成，是连续的。 |

:::collapse accordion
- 提示
  分两问：**作用**一样吗？**结构**一样吗？两问分别作答，再组合。
- 完整解答
  **第一步：作用。** 两者的主磁路都是**主磁通的闭合路径**，都承担「把励磁电流产生的磁通引导到该去的地方」这件事。
  变压器靠它把一次侧磁通耦合到二次侧；旋转电机靠它让磁场既能穿过定子、又能穿过转子，从而完成机电能量转换。**作用相同。**

  **第二步：结构。** 变压器的铁芯是一个**连续的**闭合框（铁芯柱 + 铁轭），磁通全程走铁磁材料。
  旋转电机的定子铁芯与转子铁芯是**两个独立部件**，中间被**空气间隙**隔开——主磁路**不连续**，
  磁通必须两次跨过气隙才能闭合。

  **第三步：后果。** 气隙的磁阻远大于铁芯（空气的 $\mu_r\approx1$，硅钢片数千），
  所以旋转电机的励磁电流里有很大一部分是用来「推」磁通过气隙的。这是旋转电机与变压器最本质的结构差别。

  **答案：A**（作用相同；但结构有差异：不连续，由气隙隔开）
- 复盘
  - 四个选项其实是「作用同/不同 × 结构同/不同」的 $2\times2$ 组合，**只有 A 这一格是对的**。
    做题时先把两问拆开判定，能避免被「结构有差异」这半句带走而误选 B。
  - 一条推论：气隙越大、励磁电流越大、功率因数越差——所以气隙尺寸是设计里要抠的量。
:::

## 3. 判断题（第 5–8 题）

### 第 5 题

线圈放在铁芯槽中的两个有效边是有用的，槽外连接两个有效边的端部是没有用的。（　）

| 显示位 | 选项 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  问一句「端部拿掉，电流还流得通吗？」
- 完整解答
  **第一步：有效边做什么。** 槽内的两个边是**切割磁通、产生电动势**的地方（也是通电时受力产生转矩的地方），
  所以叫「有效边」。

  **第二步：端部做什么。** 端部把各线圈的两个有效边**连成一个闭合回路**。没有端部，
  有效边产生的电动势就没有外电路可接、电流也流不起来——**电路不完整，电动势再多也输出不了功率**。

  **第三步：结论。** 端部本身不产生电动势，但它是**电流回路的必需环节**，因此不能说「没有用」。

  **答案：错**
- 复盘
  - 这题考的是「有没有用」的口径：**不产生电动势 ≠ 没有用**。端部还承担机械固定与散热的作用，
    而且它是绕组电阻与漏抗的重要来源（端部漏抗）。
  - 记住这个对照：**有效边管「电」，端接管「路」**。
:::

### 第 6 题

波绕组常用于绕线式异步电动机转子绕组和多极水轮发电机的定子绕组。（　）

| 显示位 | 选项 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  波绕组的特点是「一个线圈绕行将近一周才回到相邻槽」——这种走法适合**什么极数**的电机？
- 完整解答
  **第一步：波绕组的形态。** 波绕组（wave winding）的相邻两个线圈沿圆周**前进将近一整圈**
  （$2\tau$ 左右）再回到相邻槽，形似波浪，因此得名。它的**并联支路数恒为 2**，与极数无关。

  **第二步：为什么适合这两个场合。**

  - **绕线式异步电动机的转子**：转子绕组要能承受较高电压、且希望端部连线少、结构紧凑，波绕组端部交叉少，正合适。
  - **多极水轮发电机的定子**：水轮发电机是**低转速、多极数**（几十个极）。若用叠绕组，极数越多并联支路越多、
    端部越复杂；波绕组支路数固定为 2，极数再多也不必增加支路，端部简单、省铜。

  **第三步：与叠绕组的分工。** 叠绕组（lap winding）支路数 $=2p$，适合**极数少、电流大**的场合；
  波绕组支路数 $=2$，适合**极数多、电压高**的场合。两者正好互补。

  **答案：对**
- 复盘
  - 一句话记：**叠绕组跟极数走（支路 $2p$），波绕组不跟极数走（支路 2）**。
  - 这与 11-12 笔记里的「波绕组后一个线圈压到前一个上去、斜着走」是同一件事的两种说法。
:::

### 第 7 题

线圈是构成绕组的基本单元，分单匝线圈和多匝线圈。（　）

| 显示位 | 选项 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  从「导体 → 线圈 → 线圈组 → 绕组」这条链上看：线圈处在第几层？
- 完整解答
  **第一步：构成链。** 一根**导体**放进一个槽里；若干导体按规律连成**线圈**；若干线圈串联成**线圈组**；
  各线圈组再串并联成**一相绕组**。所以线圈确实是**基本单元**（组成绕组的独立可绕制单元）。

  **第二步：匝数。** 一个线圈可以由**一匝**（单匝线圈）或**多匝**（多匝线圈）绕成。
  匝数不同直接影响感应电动势的大小（$E\propto N$），所以这是设计参数而不只是「形式」。

  **答案：对**
- 复盘
  - 这条链要能默写：**导体 → 线圈 → 线圈组 → 相绕组 → 三相绕组**。每一级都对应一次「相量相加」，
    对应一次「打折」（第 3 题的 $k_w$ 就是在后两级产生的）。
:::

### 第 8 题

把旋转电机电枢上各槽内导体按正弦规律变化的电动势分别用相量表示，构成一个辐射星形图，称槽电动势星形图。（　）

| 显示位 | 选项 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  「星形图」的画法：把所有相量的**首端重合并在一起**，只看它们的箭头朝哪。
- 完整解答
  **第一步：这张图画的是什么。** 把电枢上**每个槽内导体**的电动势用一个相量表示。这些电动势都是同频率的正弦量，
  只是相位依次错开一个槽距角 $\alpha$。把它们的**尾端放在同一点**、箭头射向四周，就得到一张辐射状的星形图。

  **第二步：为什么首端重合。** 相量的相位是相对量，只有把起点放在一起才能看出彼此的**相位差**。
  相邻两槽的箭头夹角正好是 $\alpha$，绕一圈共 $Z$ 个相量、累计 $p\times360°$ 电角度，于是这张图上会出现
  **$p$ 个重叠的星形**（每对极一圈）——这正是它最有用的地方：能直接定出哪几个槽的导体可划进同一相，
  从而定出 $60°$ 相带。

  **答案：对**
- 复盘
  - 三个用途要记住：**① 定 $60°$ 相带**（每 $60°$ 电角度划一相）；**② 算分布因数 $k_q$**；
    **③ 判三相绕组是否对称**。
  - 与「相量图」的区别：相量图画的是**电压电流**（时间量），槽电动势星形图画的是**槽内导体的电动势**（空间分布 + 时间相位合一）。
:::

## 4. 多选题（第 9 题）

### 第 9 题

某旋转电机定子采用单层叠绕组，定子槽数 $Z=36$、相数 $m=3$、极对数 $p=2$，则极距 $\tau$、每极每相槽数 $q$、槽距角 $\alpha$ 分别为（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |

- 提示
  三个式子各算一遍，然后把算得的值在选项里对号。注意「极对数 $p=2$」意味着极数 $2p=4$。
- 完整解答
  **第一步：极距 $\tau$。**

  $$\tau=\frac{Z}{2p}=\frac{36}{4}=9\ (\text{槽})$$

  极距是**相邻两个磁极中心线之间的距离**，用槽数表示。⇒ 选 **D**（$\tau=9$），B（$\tau=18$）是把 $2p$ 当成 $p$ 算的结果。

  **第二步：每极每相槽数 $q$。**

  $$q=\frac{Z}{2pm}=\frac{36}{4\times3}=3\ (\text{槽/极/相})$$

  ⇒ 选 **F**（$q=3$），A（$q=6$）是把 $m$ 漏掉算的结果。

  **第三步：槽距角 $\alpha$。**

  $$\alpha=\frac{360°\cdot p}{Z}=\frac{360°\times2}{36}=20°\ (\text{电角度})$$

  ⇒ 选 **C**（$\alpha=20°$ 电角度），E（$\alpha=40°$）是把 $p$ 乘了两次算的结果。

  **第四步：自校验。** 三相 $60°$ 相带要求 $q\alpha=60°$：$3\times20°=60°$ ✓。三式互相咬合，说明三个答案同时正确。

  **答案：C、D、F**
- 复盘
  - 三题一个套路：**分母里 $2p$ 是极数**，别把极对数 $p$ 当极数用。这是本组题唯一的高频错因。
  - 用 $q\alpha=180°/m$ 做终检：只要这条不成立，三个答案里必有算错的。
  - 单层与双层只影响**线圈数**（单层 $Z/2$、双层 $Z$），不影响 $\tau$、$q$、$\alpha$ 这三个量——题目给「单层」是干扰信息。

## 5. 小结：这份作业真正想教的三件事

1. **电角度与机械角度不能混。** 第 2、9 两题都在这上面设卡：槽距角是电角度、要乘极对数；
   $\tau$、$q$、$\alpha$ 三式又都用 $2p$（极数）而不是 $p$。把「$2p$ 是极数」写在草稿纸角上，这一组题就不会错。
2. **旋转电机比变压器多两个「不连续」。** 一是**磁路不连续**（被气隙切断，第 4 题），二是**绕组不集中**
   （分布 + 短距，于是多了 $k_w$，第 3 题）。这两条是旋转电机与变压器的全部分野，也是后续所有推导的起点。
3. **绕组三件事都要能说清。** 线圈是基本单元（第 7 题）、端接是回路必需（第 5 题）、
   波绕组与叠绕组按极数分工（第 6 题）、槽电动势星形图用来定相带算 $k_q$（第 8 题）——四道题合起来就是「交流绕组」这一节的地图。
