## 2. 单选题（第 1–10 题）

### 第 1 题

变压器采用较薄的硅钢片可以使运行时的铁芯损耗（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 降低 |
| B | 不变 |
| C | 无法确定 |
| D | 增大 |

:::collapse accordion
- 提示
  把铁芯损耗拆成「磁滞损耗」与「涡流损耗」两项，再检查涡流损耗随硅钢片厚度 $d$ 的几倍次方变化（片间刷绝缘漆隔断涡流路径）。
- 完整解答
  **第一步：写出铁芯损耗的组成与片厚关系。**
  铁芯损耗 $p_{Fe} = p_h + p_e$（磁滞损耗 $p_h$ + 涡流损耗 $p_e$）。由涡流损耗规律，$p_e$ 正比于硅钢片厚度 $d$ 的平方（$p_e \propto f^2 B_m^2 d^2 / \rho$）。
  **第二步：判别结果。**
  采用较薄且片间涂绝缘漆的硅钢片，能把涡流限制在薄片内部、使 $d^2$ 项显著减小，从而使运行时总铁芯损耗**降低**。A 正确，B、C、D 均不符合涡流损耗机理。

  **答案：A**（平台正确答案：A，降低）
- 复盘 :-
  - **记忆要点**：降涡流三板斧——**薄片（减 $d$）、涂漆绝缘（断路）、掺硅（提电阻率 $\rho$）**。工业常用 0.35 mm 或 0.30 mm 冷轧硅钢片正是基于此。
:::

### 第 2 题

当交流电源电压加到变压器的一次绕组后，在变压器铁芯中产生的磁通为（ ）磁通。

| 选项 | 内容 |
| :---: | :--- |
| A | 旋转 |
| B | 交变 |
| C | 恒定 |
| D | 脉冲 |

:::collapse accordion
- 提示
  一次绕组接的是随时间按正弦正负交替的交流电压，静止铁芯柱内的磁通方向沿轴向周期性往返变化还是在空间圆周上连续旋转？
- 完整解答
  **第一步：从交流励磁推导出磁通形态。**
  一次绕组施加正弦交流电压 $u_1$，在忽略绕组漏阻抗压降时感应电动势 $e_1 = -N_1\dfrac{\mathrm{d}\Phi}{\mathrm{d}t}$、有效值满足 $U_1 \approx E_1$（$u_1 \approx -e_1 = N_1\dfrac{\mathrm{d}\Phi}{\mathrm{d}t}$），从而在静止铁芯内激励出大小与方向均随时间按同频率正弦规律周期性交替变化的**交变磁通**。
  **第二步：逐项排错。**
  A（旋转磁通）产生于三相对称交流绕组的空间气隙；C（恒定磁通）对应直流励磁；D（脉冲磁通）对应单向脉冲激励。

  **答案：B**（平台正确答案：B，交变）
- 复盘 :-
  - **对比记法**：变压器（静止器件）铁芯里是**时间上交变、空间位置固定**的交变磁通；三相对称旋转电机气隙里才是**旋转磁通**。
:::

### 第 3 题

按照（ ）的不同，变压器可分为干式变压器和油浸式变压器。

| 选项 | 内容 |
| :---: | :--- |
| A | 绕组在铁芯中的排列方式 |
| B | 用途 |
| C | 用途和调压方式 |
| D | 绝缘介质和冷却方式 |

:::collapse accordion
- 提示
  想一想「干式」与「油浸式」这两个名字直接点出了变压器内部用什么做**绝缘**、靠什么把热量带走（**冷却**），对照变压器的五大分类维度选出对应项。
- 完整解答
  **第一步：对照「干式 / 油浸式」的物理含义。**
  - **油浸式变压器**：器身浸在变压器油中，以绝缘油作为主**绝缘介质**和热对流**冷却介质**；
  - **干式变压器**：无绝缘油，依靠空气或环氧树脂等固体**绝缘介质**，通过空气自然或强迫风冷实现**冷却**。
  **第二步：排除其余分类维度。**
  A（绕组排列方式）分出同心式与交叠式；B（用途）分出电力、仪用、试验、电炉变压器等；C（调压方式）分出无励磁调压与有载调压。

  **答案：D**（平台正确答案：D，绝缘介质和冷却方式）
- 复盘 :-
  - **易错区分**：铁芯式 vs 铁壳式看**铁芯结构**；同心式 vs 交叠式看**绕组排列**；干式 vs 油浸式 vs 充气式看**绝缘介质和冷却方式**。
:::

### 第 4 题

油浸式电力变压器的铁芯和绕组完全放置在充满油的（ ）中。

| 选项 | 内容 |
| :---: | :--- |
| A | 散热器 |
| B | 空气 |
| C | 油枕或储油柜 |
| D | 油箱 |

:::collapse accordion
- 提示
  变压器器身（铁芯 + 绕组）装在哪里，而油枕/储油柜、散热器分别装在主箱体的哪个外部位置？
- 完整解答
  **第一步：明确油浸式变压器本体容器。**
  油浸式电力变压器的器身（铁芯与绕组）全部浸放在充满绝缘油的主**油箱**内，油箱既承担机械承载和密封防护，又为绝缘油对流散热提供主体空间。
  **第二步：逐项排错。**
  A（散热器）是挂载在油箱外壁促进热油循环降温的管片附件；B（空气）对应干式结构或油箱外部；C（油枕/储油柜）装在油箱顶部，仅用于容纳油随温度的热胀冷缩并减少油面与空气接触面积，内部不放器身。

  **答案：D**（平台正确答案：D，油箱）
- 复盘 :-
  - **附件分工一句话**：**油箱**装器身，**储油柜**保满油，**呼吸器**挡水汽，**散热器**加快油循环。
:::

### 第 5 题

某变压器型号为 SF9-180/110 变压器，那么它的额定电压和额定容量分别为（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 9 kV 和 180 MVA |
| B | 9 kV 和 110 MVA |
| C | 110 kV 和 180 MVA |
| D | 180 kV 和 110 MVA |

:::collapse accordion
- 提示
  把型号 `SF9-180/110` 按国标字段拆开：`S`（相数）、`F`（冷却）、`9`（设计序号）、`-` 后面是 `额定容量 / 高压额定电压`，同时看清题干问的是**先额定电压、后额定容量**。
- 完整解答
  **第一步：按国标电力变压器型号规则逐段解码。**
  对于 `SF9-180/110`：
  - `S`：三相；`F`：油浸风冷；`9`：性能设计序号（第 9 代设计）；
  - 短横后分子 `180`：额定容量 $S_N = 180\text{ MVA}$（大型电力变压器常用 MVA 表示，即 $180\,000\text{ kVA}$）；
  - 斜杠后分母 `110`：高压侧额定线电压 $U_{1N} = 110\text{ kV}$。
  **第二步：按题干顺序作答。**
  题干先问「额定电压」、后问「额定容量」，对应 **110 kV 和 180 MVA**（排除把序号 9 当电压的 A/B，以及把容量与电压颠倒的 D）。

  **答案：C**（平台正确答案：C，110 kV 和 180 MVA）
- 复盘 :-
  - **审题防坑**：型号写法永远是**容量在前、电压在后**（如 `400/10`、`180/110`），但考题题干常故意反过来问「电压和容量分别为」，C 与 D 正是专考这个次序陷阱。
:::

### 第 6 题

变压器利用（ ）将一种电压等级的交流电能转变为同频率的另一种电压等级的交流电能。

| 选项 | 内容 |
| :---: | :--- |
| A | 电磁感应原理 |
| B | 基尔霍夫定律 |
| C | 双反应理论和叠加原理 |
| D | 电机可逆性原理 |

:::collapse accordion
- 提示
  变压器一、二次绕组之间在电路上是绝缘隔离的，能量与电压变换全靠同一铁芯内的交变磁通实现互感耦合，对应哪一条基本电磁定律？
- 完整解答
  **第一步：回顾变压器能量传递机理。**
  一次绕组接交变电源在铁芯中建立交变主磁通 $\Phi$，主磁通同时交链一、二次绕组，依据**电磁感应原理**分别感应出同频率电动势 $e_1 = -N_1\dfrac{\mathrm{d}\Phi}{\mathrm{d}t}$、$e_2 = -N_2\dfrac{\mathrm{d}\Phi}{\mathrm{d}t}$，从而在电路隔离条件下将一种电压等级的交流电能转变为同频率另一电压等级的交流电能。
  **第二步：逐项排错。**
  B（基尔霍夫定律）只描述电路拓扑约束；C（双反应理论用于凸极同步电机，叠加原理用于线性电路多源求解）；D（可逆性原理指旋转电机可作电动机或发电机互逆运行）。

  **答案：A**（平台正确答案：A，电磁感应原理）
- 复盘 :-
  - **高频对照**：凡问「变压器靠什么把电压变高/变低或传能量」一律是**电磁感应定律（互感原理）**；改变匝数比只是实现手段，没有交变磁通感应就变不了压。
:::

### 第 7 题

变压器变比 $k$ 为 10，一次侧绕组匝数 $N_1$ 为 1000 匝，则二次侧绕组匝数 $N_2$ 为（ ）匝。

| 选项 | 内容 |
| :---: | :--- |
| A | 100 |
| B | 10 |
| C | 10000 |
| D | 1000 |

:::collapse accordion
- 提示
  写出标准变比定义 $k = \dfrac{N_1}{N_2}$，代入 $k = 10$ 与 $N_1 = 1000$ 直接反解 $N_2$。
- 完整解答
  **计算与核对**：
  由变压器变比定义
  $$k = \frac{E_1}{E_2} = \frac{N_1}{N_2}$$
  代入已知 $k = 10$、$N_1 = 1000$ 匝：
  $$N_2 = \frac{N_1}{k} = \frac{1000}{10} = 100\text{ 匝}$$
  C（10000）把乘除关系写反成 $N_2 = kN_1$；B（10）、D（1000）均不符合比例关系。

  **答案：A**（平台正确答案：A，100）
- 复盘 :-
  - **随手验算**：本题 $k = 10 > 1$（通常为降压变），二次侧电压低所以匝数必然少于一次侧，$100 < 1000$，一眼排除 $10000$。
:::

### 第 8 题

电力变压器中的绝缘油的作用是（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 干燥和绝缘 |
| B | 冷却和润滑 |
| C | 润滑和干燥 |
| D | 绝缘和冷却 |

:::collapse accordion
- 提示
  油浸式变压器属于**静止**设备，内部既没有高速旋转轴承（不需要润滑），油本身也不能当干燥剂；回想绝缘油对绕组击穿强度与损耗散热两件事的作用。
- 完整解答
  **第一步：分析变压器油的双重功能。**
  1. **绝缘作用**：变压器油击穿场强远高于空气，且渗入绝缘纸/纸板微孔隙，显著提升绕组匝间、层间及对地主绝缘耐压水平；
  2. **冷却作用**：铁芯与绕组损耗使附近油温升高、密度下降而上浮，经散热器或箱壁冷却后下沉回流，通过自然或强迫油循环持续把热量带出油箱。
  **第二步：逐项排错。**
  变压器为静止电机不需要「润滑」；油只能防潮隔氧、并无「干燥」能力（干燥防潮靠储油柜加硅胶呼吸器）。

  **答案：D**（平台正确答案：D，绝缘和冷却）
- 复盘 :-
  - **区分附件角色**：**绝缘油**管「绝缘 + 冷却」；**硅胶呼吸器**才管「吸湿除水（防受潮）」。
:::

### 第 9 题

变压器的铁芯是变压器的（ ），也是它的支撑骨架。

| 选项 | 内容 |
| :---: | :--- |
| A | 主绝缘 |
| B | 电路 |
| C | 主磁路 |
| D | 油路 |

:::collapse accordion
- 提示
  变压器「器身 = 铁芯 + 绕组」里，绕组构成了电的通路，那么用高导磁硅钢片叠装且上面套装绕组的铁芯在电磁上充当什么通道？
- 完整解答
  **第一步：明确铁芯的双重角色。**
  变压器铁芯由高磁导率硅钢片叠成，包含套装绕组的**铁芯柱**与闭合磁路的**铁轭**，电磁上为交变主磁通提供低磁阻的**主磁路**，机械结构上同时作为套装并夹紧固定一、二次绕组的**支撑骨架**。
  **第二步：逐项排错。**
  A（主绝缘）由油、纸筒及绝缘垫块承担；B（电路）是一、二次绕组；D（油路）指散热油道与管路。

  **答案：C**（平台正确答案：C，主磁路）
- 复盘 :-
  - **两句话定器身**：**铁芯＝主磁路（兼骨架）**，**绕组＝电路**。
:::

### 第 10 题

在以下选项中，（ ）是安装在发电厂高压输电线路的始端。

| 选项 | 内容 |
| :---: | :--- |
| A | 升压变压器 |
| B | 发电厂用变压器 |
| C | 降压变压器 |
| D | 配电变压器 |

:::collapse accordion
- 提示
  发电机机端出口电压受定子绝缘限制通常只有 6–24 kV，而远距离输电需要 110–1000 kV 高压以降低电流和线损 $\Delta P \propto I^2 R$，在发电厂出线始端接哪种变压器？
- 完整解答
  **第一步：从电力系统传输链条定位。**
  发电厂发电机输出电压较低，为减小远距离高压输电电流及线路铜损（一定功率下 $\Delta P = 3I^2 R \propto 1/U^2$），必须在发电厂高压输电线路始端设置主变压器，将机端电压升高至高压输电等级——即**升压变压器**。
  **第二步：逐项排错。**
  B（厂用变压器）降压供发电厂自身辅机用电；C（降压变压器）安装在受端变电站逐级降压；D（配电变压器）安装在配网末端向低压用户供电。

  **答案：A**（平台正确答案：A，升压变压器）
- 复盘 :-
  - **电网四段串联**：发电厂出线端（**升压**）→ 高压输电线 → 枢纽变电站（**降压**）→ 台区末端（**配电**）。

## 3. 多选题（第 11 题）

### 第 11 题

已知一台三相变压器，额定容量 $S_N = 100\text{ kVA}$，额定电压 $U_{1N}/U_{2N} = 10/0.4\text{ kV}$，`D,y11` 接法，下列说法正确的有（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 变压比 $k$ 为 43.3 |
| B | 变压比 $k$ 为 25.0 |
| C | 一次侧额定电流 $I_{1N}$ 和额定相电流 $I_{1N\phi}$ 均为 10 A，二次侧额定电流 $I_{2N}$ 和额定相电流 $I_{2N\phi}$ 分别为 250 A 和 144.3 A。 |
| D | 一次侧额定电流 $I_{1N}$ 和额定相电流 $I_{1N\phi}$ 分别为 5.774 A 和 3.333 A，二次侧额定电流 $I_{2N}$ 和额定相电流 $I_{2N\phi}$ 均为 144.3 A。 |
| E | 一次侧额定电流 $I_{1N}$ 和额定相电流 $I_{1N\phi}$ 均为 5.774 A，二次侧额定电流 $I_{2N}$ 和额定相电流 $I_{2N\phi}$ 分别为 250 A 和 144.3 A。 |
| F | 一次侧额定电流 $I_{1N}$ 和额定相电流 $I_{1N\phi}$ 分别为 10 A 和 5.774 A，二次侧额定电流 $I_{2N}$ 和额定相电流 $I_{2N\phi}$ 均为 250 A。 |

:::collapse accordion
- 提示
  严格按三步计算，不要把线电压直接相除：① 铭牌电压和电流永远是**线值**，用 $I_N = \dfrac{S_N}{\sqrt{3}U_N}$ 分别算一、二次额定线电流；② `D,y11` 表示一次侧三角形 `D` 接（$U_{1N\phi} = U_{1N},\; I_{1N\phi} = I_{1N}/\sqrt{3}$）、二次侧星形 `y` 接（$U_{2N\phi} = U_{2N}/\sqrt{3},\; I_{2N\phi} = I_{2N}$）；③ 用**相电压之比**算变比 $k = \dfrac{U_{1N\phi}}{U_{2N\phi}}$。
- 完整解答
  **第一步：计算一次侧（三角形 `D` 接）额定线电流、相电流与相电压。**
  三相变压器铭牌给出的是线值：$S_N = 100\text{ kVA}$、$U_{1N} = 10\text{ kV}$：
  $$I_{1N} = \frac{S_N}{\sqrt{3}\,U_{1N}} = \frac{100}{\sqrt{3}\times 10} \approx 5.774\text{ A}$$
  一次侧为 `D` 接（线电压等于相电压，线电流等于 $\sqrt{3}$ 倍相电流）：
  $$I_{1N\phi} = \frac{I_{1N}}{\sqrt{3}} = \frac{100}{3\times 10} \approx 3.333\text{ A}, \qquad U_{1N\phi} = U_{1N} = 10\text{ kV}$$

  **第二步：计算二次侧（星形 `y` 接）额定线电流、相电流与相电压。**
  已知 $U_{2N} = 0.4\text{ kV}$，二次侧为 `y` 接（线电流等于相电流，线电压等于 $\sqrt{3}$ 倍相电压）：
  $$I_{2N\phi} = I_{2N} = \frac{S_N}{\sqrt{3}\,U_{2N}} = \frac{100}{\sqrt{3}\times 0.4} \approx 144.3\text{ A}$$
  $$U_{2N\phi} = \frac{U_{2N}}{\sqrt{3}} = \frac{0.4}{\sqrt{3}} \approx 0.23094\text{ kV}$$

  **第三步：按相电压之比计算变比 $k$。**
  $$k = \frac{U_{1N\phi}}{U_{2N\phi}} = \frac{10}{0.4/\sqrt{3}} = 25\sqrt{3} \approx 43.30$$

  **第四步：核对选项与自检。**
  - **A 正确**（$k \approx 43.3$），B 错在直接拿线电压比 $10/0.4 = 25.0$ 当成变比 $k$；
  - **D 正确**（$I_{1N}=5.774\text{ A}$、$I_{1N\phi}=3.333\text{ A}$、$I_{2N}=I_{2N\phi}=144.3\text{ A}$），C/E/F 分别在算线电流漏除 $\sqrt{3}$ 或把星/角线相电流关系套反；
  - 交叉校验相电流比：由视在功率平衡 $3U_{1N\phi}I_{1N\phi} = 3U_{2N\phi}I_{2N\phi}$ 得 $\dfrac{I_{2N\phi}}{I_{1N\phi}} = \dfrac{U_{1N\phi}}{U_{2N\phi}} = k$；代入数值 $\dfrac{144.34}{3.3333} \approx 43.30 = k$ ✓。

  **答案：A、D**（平台正确答案：AD）
- 复盘 :-
  - **唯一高频坑**：`D,y` 和 `Y,d` 一样，两端接法**一角一星**，变比 $k$ 绝不等于线电压比 $\frac{U_{1N}}{U_{2N}}$，必须先各自换算成**相电压**再相除（`D,y` 多乘一个 $\sqrt{3}$，`Y,d` 则除以 $\sqrt{3}$）。
  - **反手验算诀窍**：算完四个电流后顺手检查 $I_{2N\phi}/I_{1N\phi}$ 是否等于 $k$——若不相等，必有某一侧把星/角关系套反或漏了 $\sqrt{3}$。
:::
