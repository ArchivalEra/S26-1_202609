## 2. 判断题（第 1–5 题）

### 第 1 题

当电源电压初相角 $\alpha = 0$ 时，变压器空载合闸的励磁涌流可达几十甚至上百倍空载电流 $I_0$，变压器绕组因发热和机械效应而受损。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  分清两句话各自的归属：**「几倍额定电流 $I_N$（数十～百倍 $I_0$）+ 衰减快，伤不到本体但保护易误动」**属于空载合闸涌流；**「20～30 倍额定电流 $I_N$，电动力与发热损坏绕组」**属于突然短路冲击电流。
- 完整解答
  **第一步：判断涌流量级（前半句对）。**
  当 $\alpha = 0$（电压过零瞬间合闸）时，半周期后总磁通达到约 $2\Phi_m$，铁芯高度饱和使励磁涌流可达正常空载电流 $I_0$ 的几十甚至上百倍。

  **第二步：核对危害后果（后半句错）。**
  因为正常 $I_0$ 本身通常只有额定电流 $I_N$ 的 $1\%$ 左右，几十到上百倍 $I_0$ 折合到额定电流也仅约数倍 $I_N$，且衰减很快、持续时间短，**一般不会因发热和机械效应损伤绕组**（与第 5 题对照），真正危险的是使过流/差动保护误动作。题干将「突然短路」造成的绕组变形受损张冠李戴到了「空载合闸」上。

  **答案：错（B）**（平台正确答案：错）
- 复盘 :-
  - **对比记忆（第 1 题 vs 第 5 题）**：同样是 $\alpha=0$ 产生几十至上百倍 $I_0$ 涌流，「使绕组受损」判**错**，「对变压器本身无大危害、可能使保护误动作」判**对**。
:::

### 第 2 题

当电源电压初相角 $\alpha = \theta_k$ 时，变压器突然发生二次侧短路，可产生很大的冲击电流，其热效应和机械应力可使变压器绕组变形而损坏。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  代入突然短路瞬态解中的非周期分量系数 $\sin(\alpha - \theta_k)$：$\alpha = \theta_k$ 时 $\sin 0$ 等于多少？
- 完整解答
  忽略短路前空载小电流，二次侧突然短路的电流解为：
  $$i_k(t) = I_{km}\left[\sin(\omega t + \alpha - \theta_k) - \sin(\alpha - \theta_k)e^{-t/T_a}\right]$$
  当 $\alpha = \theta_k$ 时，$\sin(\alpha - \theta_k) = \sin 0 = 0$，自由（非周期）分量为零，短路电流**直接进入稳态周期分量**，这是**最有利**的短路时刻，不会产生倍增的冲击电流（$\alpha = \theta_k \pm \pi/2$ 才是最坏情况）。

  **答案：错（B）**（平台正确答案：错）
- 复盘 :-
  - **两个「零筹码」最好角对比**：突然短路最好角为 $\alpha = \theta_k$（电流初值零）；空载合闸最好角为 $\alpha = \pi/2$（磁通初值零）。
:::

### 第 3 题

当电源电压初相角 $\alpha = \pi/2$ 时，变压器空载合闸后磁通立即进入稳定状态。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  稳态磁通滞后电源电压 $90^\circ$：电压按 $\sin(\omega t + \alpha)$ 变化，在 $\alpha = \pi/2$（电压峰值）时，稳态磁通 $\cos(\omega t + \pi/2)$ 在 $t=0$ 时恰为多少？
- 完整解答
  忽略电阻压降且不计铁芯剩磁，空载合闸时磁通满足：
  $$\Phi(t) = -\Phi_m\cos(\omega t + \alpha) + \Phi_m\cos\alpha\,e^{-t/T}$$
  当 $\alpha = \pi/2$（电源电压达峰值瞬间合闸）时，$\cos\alpha = 0$，暂态自由分量磁通为零，总磁通直接按稳态正弦规律 $\Phi(t) = \Phi_m\sin\omega t$ 变化，**立即进入稳定状态**，不产生励磁涌流。

  **答案：对（A）**（平台正确答案：对）
- 复盘 :-
  - **为什么反而「电压最高时合闸最安全」**：因为空载电感电路中磁通滞后电压 $90^\circ$，电压最大（$\alpha=\pi/2$）的瞬间，稳态磁通正好过零，与合闸前 $0$ 磁通无缝衔接，无需暂态过渡。
:::

### 第 4 题

当电源电压初相角 $\alpha = \theta_k \pm \pi/2$ 时，变压器突然发生二次侧短路，可产生很大的冲击电流，其热效应和机械应力可使变压器绕组变形而损坏。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  把 $\alpha = \theta_k \pm \pi/2$ 代入 $\sin(\alpha - \theta_k)$ 看非周期分量幅值，再核对冲击电流的平方级电动力与热效应后果。
- 完整解答
  当 $\alpha = \theta_k \pm \pi/2$ 时，$|\sin(\alpha - \theta_k)| = 1$，非周期分量取得最大值；经过约半个周期（$t \approx T/2$）时稳态分量与尚未明显衰减的非周期分量同向叠加，形成高达约 $1.8 I_{km}$（约 $20\sim 30\,I_N$）的冲击电流。由于电磁力与发热均与电流平方 $i^2$ 成正比（放大 $400\sim 900$ 倍），其强烈的热效应与机械应力确实可使绕组变形甚至损坏。

  **答案：对（A）**（平台正确答案：对）
- 复盘 :-
  - **平方放大规律**：电流倍数 20～30 倍 $\implies$ 动稳定电动力与热稳定发热倍数均按平方放大至 400～900 倍（对照第 2 题与第 1 题）。
:::

### 第 5 题

当电源电压初相角 $\alpha = 0$ 时，变压器空载合闸的励磁涌流可达几十甚至上百倍 $I_0$ 的励磁涌流，这对变压器本身没有多大危害，但在最初几个周期内，冲击电流可能使过电流保护装置误动作。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  直接对照第 1 题的物理辨析：空载合闸涌流倍数虽高（相对于微小的 $I_0$），但相对 $I_N$ 有限且衰减快，真正的问题出在继电保护误动。
- 完整解答
  当 $\alpha = 0$ 合闸时，暂态磁通与稳态磁通在半周期后叠加趋近 $2\Phi_m$，引起铁芯深度饱和并激发高达正常空载电流 $I_0$ 几十至上百倍的励磁涌流。因 $I_0$ 基数极小且涌流衰减迅速，对变压器绕组本体通常没有多大危害；但涌流幅值可达额定电流数倍且含直流与二次谐波特征，在最初几个周期内极易导致过电流保护或差动保护误动作。

  **答案：对（A）**（平台正确答案：对）
- 复盘 :-
  - **工程应对（11-05 笔记延伸）**：生产中通过给继电保护加装**速饱和变流器**或利用**二次谐波制动**识别涌流特征，躲开合闸初期的几个周期防止误跳闸。
:::
