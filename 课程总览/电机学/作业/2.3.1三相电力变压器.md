### 2.1 三相磁路结构

**组式**＝三台独立的单相变压器。每台有自己完整闭合的铁芯，磁通不跨台 ⇒ 各相磁路**独立**。
**芯式**＝一台三柱铁芯，三柱由上下两轭连成整体，任一相磁通都要经另外两柱闭合 ⇒ 各相磁路**相关**。

后果：三次谐波磁通能否在铁芯内闭合。组式能（独立铁芯、磁阻小），芯式不能（只能绕出铁芯经油、
套管、空气、油箱壁，磁阻大）。

### 2.2 谐波的时间相位

对称三相基波相差 $120°$；$k$ 次谐波的相位差是基波的 $k$ 倍，即 $k\times120°$。

- $k=3,6,9\dots$ ⇒ $360°$ 的整数倍 ⇒ 相量回原位 ⇒ 三相同相（零序）
- $k=5,11\dots$ 负序；$k=7,13\dots$ 正序

⇒ **三相三次谐波电流同相**。星形无中线时这三条同相电流没有回路，所以 $I_{03}=0$。

### 2.3 励磁电流与磁通波形

铁芯饱和使 $\Phi$ 与 $i_\mu$ 非线性，两个波形互为「变形」：磁通正弦 ⇒ 电流**尖顶**；
电流正弦 ⇒ 磁通**平顶**（互逆）。

磁通与电动势由 $e=-N\dfrac{\mathrm d\Phi}{\mathrm dt}$ 联系：正弦的导数仍正弦；
平顶波过零陡峭 ⇒ 导数成尖顶；尖顶波导数为平顶。
⇒ **磁通正弦则电动势正弦**（只靠感应定律即可，不需要铁芯知识）。

### 2.4 Yy 接线的适用边界

两侧都星形、不带中性线 ⇒ **三次谐波电流没有回路** ⇒ 励磁电流里那部分三次谐波被拿掉，
电流只能接近**正弦** ⇒ 铁芯饱和把正弦电流"变"成**平顶**磁通 ⇒ 磁通含三次谐波分量。

⚠️ 这里的因果方向要咬准：**电流是被迫变正弦的，磁通是被迫变平顶的**。
反过来（"电流非正弦、磁通含谐波"）看起来也像回事，但那描述的是**有**三次谐波通路时的情形。

- **组式**：三次谐波磁通在主磁路顺畅闭合（磁阻小）⇒ 谐波磁通大 ⇒ 二次三次谐波电动势大
  （约基波的 45%–60%）⇒ **组式不能用 Yy**。
- **芯式**：三次谐波磁通只能经油/套管/空气/油箱壁闭合（磁阻大）⇒ 谐波磁通被压小 ⇒ 二次谐波
  电动势小；但磁通扫过油箱壁产生**涡流**发热、绝缘老化。

⇒ 芯式 Yy 只能用在谐波影响可忽略的范围内：**容量 1800 kVA 以下、电压较低的配变**。

### 2.5 联结组别与时钟表示法

字母：大写＝高压侧、小写＝低压侧；`D/d` 三角、`Y/y` 星形、`N/n` 中性点引出。
数字：**时钟点数**——高压侧线电压相量摆 12 点，看低压侧指在哪一点。一圈 12 小时＝$360°$，
所以**一点＝$30°$**。从 12 点顺时针走到 $n$ 点即**滞后**，故滞后角 $=n\times30°$，
超前角 $=360°-n\times30°$。

## 2. 单选题

### 第 1 题

Dyn11 型变压器的低压侧线电压的时间相位滞后于高压侧相应线电压（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | A | $0°$ |
| B | D | $330°$ |
| C | C | $30°$ |
| D | B | $11°$ |

:::collapse accordion
- 提示
  联结组标号里的数字是**时钟点数**，一点 = 30°。Dyn**11** 的 11 点意味着低压侧线电压相量指在 11 点位置，高压侧指在 12 点。先想清楚「滞后」是从谁量到谁。
- 完整解答
  **第一步：读标号。**

  - `D`：高压侧三角形（Delta）
  - `y`：低压侧星形（star）
  - `n`：低压侧中性点引出
  - `11`：时钟点数

  **第二步：时钟点数的含义。** 把高压侧线电压相量摆在 12 点位置，低压侧对应线电压相量指在 11 点。时钟顺时针走，11 点在 12 点**之前**，即低压侧**滞后**。

  **第三步：换算成角度。** 一点 = 30°。

  $$11\times30°=330°$$

  低压侧线电压滞后高压侧 $330°$。

  （也可等价地说成低压侧**超前** $30°$，或滞后 $330°$——同一件事，因为 $330°+30°=360°$。）

  **答案：B**（原始位 D，$330°$）
- 复盘
  - **最常错的是把 $330°$ 与 $30°$ 弄混**：$30°$ 是「超前」的量，$330°$ 是「滞后」的量。题目问的是**滞后**多少，所以是 $330°$。
  - 检查办法：$330°=360°-30°$。滞后 $330°$ 等于超前 $30°$，两者描述同一相位关系。若选项里有 $30°$，那是把超前当成了滞后。
  - 联结组标号是「$U_2$ 相对 $U_1$ 的位置」，**永远从高压侧量到低压侧**。
:::

### 第 2 题

YNy 连接的变压器负载运行时如果主磁通为正弦波，则相电动势为（　）波。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | C | 尖顶波 |
| B | A | 正弦波 |
| C | B | 平顶波 |
| D | D | 矩形波 |

:::collapse accordion
- 提示
  $e=-N\dfrac{\mathrm d\Phi}{\mathrm dt}$——相电动势是磁通的导数。正弦的导数还是正弦。再看题目给的前提是什么。
- 完整解答
  **第一步：题目给的前提。** 「主磁通为正弦波」，即

  $$\Phi(t)=\Phi_m\sin\omega t$$

  **第二步：用电磁感应定律求相电动势。**

  $$e=-N\frac{\mathrm d\Phi}{\mathrm dt}=-N\Phi_m\omega\cos\omega t$$

  导数仍是**同频率的正弦（余弦）函数**，没有新的谐波成分。

  **答案：B**（原始位 A，正弦波）

  **这一步的意义**：波形形状由磁通唯一决定，磁通是正弦，电动势就必然是正弦。题目故意给了「主磁通为正弦」这个强前提，就是为了把「铁芯饱和产生谐波」这条路堵掉——YNy 带负载、且给定磁通为正弦，那就是理想情形。
- 复盘
  - **容易被「变压器」「三次谐波」这些词带偏**，以为一定出尖顶波。注意题目把前提写死了：**主磁通为正弦**。
  - 一般规律要分清：
    - 磁通正弦 ⇒ 电动势正弦；
    - 磁通平顶 ⇒ 电动势尖顶（因为平顶波的导数在过零处陡峭）；
    - 磁通尖顶 ⇒ 电动势平顶。
  - 这条是后面第 6 题的基础：那里讨论的正是「磁通为什么不是正弦」。
:::

### 第 3 题

三相组式变压器（即三相变压器组）各相磁路（　），三相芯式变压器各相磁路（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | D | 彼此相关　彼此相关 |
| B | B | 彼此独立　彼此相关 |
| C | C | 彼此相关　彼此独立 |
| D | A | 彼此独立　彼此独立 |

:::collapse accordion
- 提示
  「组式」是**三台单相变压器**拼成三相，每台有自己的铁芯；「芯式」是**一台**变压器有三个铁芯柱，三柱之间有轭连起来。
- 完整解答
  **第一步：组式。** 三相变压器组＝三台独立的单相变压器，每台有自己**完整的闭合铁芯**。某一相的磁通只在自己那台的铁芯里走，**不经过另外两相**。⇒ 各相磁路**彼此独立**。

  **第二步：芯式。** 三相芯式变压器是**一个**三柱铁芯，三个柱由上下两道轭连成一个整体。任一相的磁通都要经**另外两柱**（或柱与轭）闭合，三相互为通路。⇒ 各相磁路**彼此相关**。

  **答案：B**（原始位 B，彼此独立　彼此相关）
- 复盘
  - **这题的差别后来会决定「三次谐波走哪条路」**：组式磁路独立、三次谐波磁通磁阻小，能流得很通；芯式三次谐波磁通只能走油、套管、油箱壁，磁阻大。第 6 题就考这个。
  - 记法：**组 = 三台分开（独立）；芯 = 一台三柱（相关）**。
  - 「芯式」也叫「三铁芯柱式」，现在电网里绝大多数三相变压器都是芯式。
:::

### 第 4 题

Yy 接线的三相铁芯式变压器，只适用于（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | B | 电压较低且容量 1800 kVA 以下的配变 |
| B | D | 以上说法都不正确 |
| C | C | 110 kV 及以上电压等级的电力变压器 |
| D | A | 10 kV 的冶炼变压器 |

:::collapse accordion
- 提示
  Yy 接线的问题在**三次谐波**：芯式结构里三次谐波磁通走油箱壁，会涡流发热。容量越大、电压越高，这个问题越严重。所以它的适用范围是朝「小容量、低电压」还是朝「大容量、高电压」？
- 完整解答
  **第一步：Yy 接线的固有毛病。** 星形接线没有中性线时，三次谐波电流无通路，励磁电流不能是正弦，于是磁通含三次谐波分量。

  **第二步：芯式结构下三次谐波磁通的去向。** 芯式各相磁路相关，三次谐波磁通不能像组式那样在铁芯里闭合，只能穿出铁芯、经**绝缘油、套管、空气、油箱壁**构成回路。这条路径磁阻大，磁通虽被压小，但它**扫过油箱壁等铁磁构件**时会产生**涡流**：

  - 涡流损耗发热 ⇒ 效率降低；
  - 局部过热 ⇒ 加速绝缘材料老化。

  **第三步：限制适用范围的正是「容量」与「电压」。** 容量小 ⇒ 谐波磁通绝对值小、发热可控；电压低 ⇒ 绝缘裕度大、结构简单。教材给的上限就是 **1800 kVA 以下、电压较低的配电变压器**。

  **答案：A**（原始位 B）
- 复盘
  - **为什么"沿用至今"**：小容量配电变压器用 Yy 接线便宜（只需一二次各一套星形绕组），在限制范围内问题不显著。一旦容量上去，涡流发热就受不了，必须改用 Δ 接一侧（提供三次谐波电流通路）或加第三绕组。
  - **「以上说法都不正确」是干扰项**：看到这种选项先别急着选，先看其余三项有没有正确表述。
:::

### 第 5 题

若变压器三相基波电流时间相位互相差 $120°$，则三相三次谐波电流互相差（　）。

| 显示位 | 原始位 | 选项 |
| :---: | :--- | :--- |
| A | B | $30°$ |
| B | C | $40°$ |
| C | A | $0°$ |
| D | D | 以上选项皆错 |

:::collapse accordion
- 提示
  三次谐波频率是基波的 3 倍。写 $i=\sin(\omega t)$ 和它的三次谐波 $\sin(3\omega t)$，把基波的 $120°$ 差异代进去。
- 完整解答
  **第一步：写出三相基波。**

  $$i_A=\sin\omega t,\quad i_B=\sin(\omega t-120°),\quad i_C=\sin(\omega t-240°)$$

  **第二步：写出三次谐波。** 对每一相，三次谐波的相位是基波相位的 **3 倍**：

  $$i_{A3}=\sin 3\omega t$$
  $$i_{B3}=\sin 3(\omega t-120°)=\sin(3\omega t-360°)=\sin(3\omega t-360°)\equiv\sin 3\omega t$$
  $$i_{C3}=\sin 3(\omega t-240°)=\sin(3\omega t-720°)=\sin(3\omega t-720°)\equiv\sin 3\omega t$$

  $360°$ 与 $720°$ 都是整圈，相量回到原位。

  **第三步：结论。** 三相三次谐波电流**同相位**，互相差 **$0°$**。

  **答案：C**（原始位 A，$0°$）
- 复盘
  - **不要写成 $120°\times3=360°$ 然后说「等于零」就完事**——$360°$ 与 $0°$ 在相位上是同一个值，但要说清「三次谐波相差 $0°$」这个结论本身。思路对，表述要落在这。
  - **一般公式**：$k$ 次谐波在对称三相系统里的相位差是 $k\times120°$。
    - $k=3,6,9\dots$（3 的倍数）⇒ 相差 $360°$ 的整数倍 ⇒ $0°$ ⇒ **零序分量**（同相）；
    - $k=5,11\dots$ ⇒ $120°$ 的整个反向序列（负序）；
    - $k=7,13\dots$ ⇒ 正序。
  - 这条零序性质正是「星形无中性线时三次谐波电流流不通」的直接原因：三相三次谐波同相，星形接法里它们没有回路。
:::

## 3. 多选题

### 第 6 题

下列关于 Yy 连接的三相变压器描述正确的是（　）。

| 显示位 | 原始位 | 选项要点 |
| :---: | :---: | :--- |
| A | A | 采用 Yy 连接的三相变压器，由于 $I_{03}=0$，又因铁磁材料的饱和特性使 $I_0$、$\Phi_m$ 呈非线性关系，因此正弦波 $I_0$ 产生平顶波 $\Phi_m$，$\Phi_m$ 除基波分量外…（题干续见下） |
| B | D | 三相芯式变压器可用 Yy 接线时，3 次谐波分量经过油箱壁等铁磁构件时，产生电涡流发热，会引起材料老化和效率降低，因此 Yy 连接方式只能用于 1800 kVA…（题干续见下） |
| C | B | 三相组式变压器中 $\Phi_m$ 中的 3 次谐波分量因和基波分量同样经过主磁路、因磁阻小致使 3 次谐波分量值较大，在二次侧产生的 3 次谐波电势大，约有基波分量…（题干续见下） |
| D | C | 三相芯式变压器中 $\Phi_m$ 中的 3 次谐波分量主要经过部分主磁路、绝缘油、套管、空气、油箱壁构成的磁路，磁阻较大使 3 次谐波分量值较小，在二次侧产生的 3 次谐波电势小…（题干续见下） |

> 平台选项文字较长，本页照抄了每项**开头能判别对错的实质内容**；四段都以「…」收尾处为平台原文的省略位置，未强行补全。

:::collapse accordion
- 提示
  四项分别讲四件事：①正弦 $I_0$ 为什么产生平顶 $\Phi_m$；②芯式 Yy 的涡流发热限制；③组式三次谐波磁通大、二次谐波电势大；④芯式三次谐波磁通小、二次谐波电势小。逐项判断是否与教材口径一致。
- 完整解答
  逐项核对：

  **A：正确。** 星形无中性线 ⇒ 三次谐波电流 $I_{03}=0$ ⇒ 励磁电流只能是非正弦。铁芯饱和使 $I_0$ 与 $\Phi_m$ 呈非线性关系：正弦的 $I_0$ 在饱和铁芯里得到**平顶**的 $\Phi_m$。这是「正弦励磁电流 → 平顶磁通」的标准链条。

  **B：正确。** 芯式结构下三次谐波磁通只能经油箱壁等铁磁构件闭合，扫过导体产生涡流 ⇒ 发热、材料老化、效率下降。所以 Yy 只能用于 1800 kVA 以下的小容量配电变压器。

  **C：正确。** 组式各相磁路**独立**，三次谐波磁通与基波一样在主磁路里闭合，磁阻小 ⇒ 三次谐波磁通分量**较大** ⇒ 二次侧三次谐波电势大（教材给出的量级约为基波的 45%–60%）。因此组式变压器不能采用 Yy 接线。

  **D：正确。** 芯式三次谐波磁通走「铁芯 + 油 + 套管 + 空气 + 油箱壁」这条复合磁路，磁阻大 ⇒ 三次谐波磁通被压小 ⇒ 二次侧三次谐波电势**小**。所以在限制容量后，芯式可以用 Yy。

  **答案：A、B、C、D**（全选）

  四段合起来是一套完整的因果链：**为什么会有三次谐波（A）→ 组式会怎样（C）→ 芯式会怎样（D）→ 所以 Yy 的适用边界在哪（B）**。
- 复盘
  - **全选题最容易漏选**，因为读到第三、四项就疲劳了。检查办法：把四项排成「因 → 组式果 → 芯式果 → 结论」看逻辑是否闭合，闭合就没有错的。
  - **组式与芯式的差别要背住方向**：组式磁路独立 ⇒ 三次谐波磁通走得通 ⇒ **谐波大**；芯式磁路相关 ⇒ 三次谐波磁通走不通（只能出油箱）⇒ **谐波小**。方向反了，C、D 就会判错。
  - 一个常见误解：以为「磁阻大」是坏事。在三次谐波这件事上，芯式磁阻大恰恰是**好事**——它把谐波压小了。
