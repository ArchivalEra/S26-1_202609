## 2. 判断题（第 1–8 题）

### 第 1 题

为求取变压器短路参数，在实验中要求短路电流必须等于额定值时才可以读取短路电压和短路功率。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  判断一条物理曲线是不是直线：短路时铁芯不饱和、特性是**直线**，只要不过载烤坏绕组，任取若干电流点都可以反算参数并换算至 $I_N$（与第 6 题对调对比）。
- 完整解答
  错误。短路试验中电源电压很低（约额定电压的 $4\%\sim 10\%$），主磁通极小，磁路远未饱和，短路特性为线性直线——由此求得的 $z_k = U_k/I_k$、$r_k = P_k/I_k^2$ 基本不随电流大小变化，因此**并不要求短路电流必须严格等于额定值**（常在 $(0.5\sim 1.0)I_N$ 或附近多点同步测读 $U_k, I_k, P_k$ 后换算至额定点）。真正要求必须做到额定值的是磁路非线性的**空载试验**。

  **答案：错（B）**（平台正确答案：错）
- 复盘 :-
  - **错题复盘（平台原选 对，得分 0）**：把空载试验的「必须加额定电压」和只有额定电流点才称 $U_{kN}/P_{kN}$ 的定义，误记成了「实验时必须严卡 $I_k=I_N$ 才允许读数」。牢记：**空载看饱和（必须 $U_0=U_N$），短路看线性（电流不必等于 $I_N$，只要求同时读数）**。
:::

### 第 2 题

空载实验时，记录温度是为将励磁电阻值换算到运行温度 $75^\circ\text{C}$ 值，以方便比较。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  区分「等效铁耗电阻 $r_m$」与「真实铜绕组电阻 $r_k$」：谁的阻值随绕组铜线温度线性变化、需要换算到 $75^\circ\text{C}$？
- 完整解答
  错误。**短路试验**测得的短路电阻 $r_k = r_1 + r_2'$ 是实际一、二次铜/铝绕组的电阻之和，随温度变化明显，必须记录试验温度并按电阻温度系数换算到标准运行温度 $75^\circ\text{C}$（以铜绕组常用式为例，教材写常数 $234.5$，工程常简写为 $235$；铝绕组取 $228$）：
  $$r_{k(75^\circ\text{C})} = r_{k(\theta)} \frac{234.5 + 75}{234.5 + \theta}$$
  而**空载试验**测得的励磁电阻 $r_m$ 是用来等效铁芯涡流与磁滞损耗的虚拟电阻，并非实测绕组直流电阻，不做 $75^\circ\text{C}$ 温度换算。

  **答案：错（B）**（平台正确答案：错）
- 复盘 :-
  - **真假电阻口诀**：$r_k$ 是实实在在的铜线电阻 $\to$ 记温度、折 $75^\circ\text{C}$；$r_m$ 是等效铁耗的「影子电阻」 $\to$ 只按电压取点，不折温度。
:::

### 第 3 题

变压器空载实验测得的损耗近似等于铁损耗 $p_{Fe} = I_0^2 r_m$，短路实验测得的损耗近似等于铜损耗 $p_{Cu} = I_k^2 r_k$。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  检验「两个试验各管一半」的两个近似前提：① 空载电流小 + $r_m \gg r_1$；② 短路电压低 + 主磁通小。
- 完整解答
  正确。
  1. **空载试验**：二次侧开路（$I_2 = 0$），一次空载电流 $I_0$ 极小，一次铜耗 $I_0^2 r_1$ 远小于铁耗（即 $r_m \gg r_1$），故空载输入功率 $P_0 \approx p_{Fe} = I_0^2 r_m$；
  2. **短路试验**：一次外施短路电压仅约为额定电压的百分之几，铁芯主磁通极微、铁芯损耗可忽略不计，故短路输入功率 $P_k \approx p_{Cu} = I_k^2 r_k$（当 $I_k = I_N$ 时即为额定铜耗 $p_{kN}$）。

  **答案：对（A）**（平台正确答案：对）
- 复盘 :-
  - **两式对比**：$r_m = P_0 / I_0^2$（铁耗），$r_k = P_k / I_k^2$（铜耗），两试验正好干净地把两种损耗拆开测出。
:::

### 第 4 题

从正常运行的角度看，希望短路阻抗小一些，这样二次侧电压波动小；但从短路故障的角度看，希望短路阻抗大一些，这样相应的短路电流就会小些。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  同时看两个方向：① 正常运行时 $\Delta U\% \approx \beta(u_{kr}\cos\varphi_2 + u_{kx}\sin\varphi_2)$；② 突发短路时 $I_k^* = 1 / Z_k^*$。
- 完整解答
  正确。
  - **正常运行**：负载变化时在短路阻抗 $Z_k$ 上引起的内部压降波动与 $Z_k$（即 $u_k\%$）成正比，故 $Z_k$ 越小，二次侧端电压随负载的波动越小、供电质量越高；
  - **短路故障**：二次侧突然短路时，稳态短路电流标幺值 $I_k^* = 1 / Z_k^*$，故 $Z_k$ 越大，限流作用越强、短路冲击电流及电动力越小。因此工程设计须按配电变压器与电力系统大变压器的不同定位折中选取 $u_k\%$。

  **答案：对（A）**（平台正确答案：对）
- 复盘 :-
  - **工程选型直观印象**：配电变压器面对用户要求稳压，常取较低的 $u_k\% \approx 4\%\sim 4.5\%$；大容量高压主变需限制系统短路电流，常取更大的 $u_k\%$。
:::

### 第 5 题

若变压器短路阻抗标幺值 $Z_k^* = 0.06$，则短路电压 $U_k\% = 6\%$。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  由标幺值定义展开 $Z_k^* = Z_k / (U_{1N}/I_{1N}) = (I_{1N}Z_k)/U_{1N}$ 与 $u_k\%$ 比较。
- 完整解答
  正确。以各自额定值为基准值时，由短路阻抗标幺值与短路电压百分数定义：
  $$Z_k^* = \frac{z_k}{Z_{1N}} = \frac{z_k}{U_{1N}/I_{1N}} = \frac{I_{1N}z_k}{U_{1N}} = \frac{U_{kN}}{U_{1N}} = u_k^*$$
  因此 $U_k\% = Z_k^* \times 100\% = 0.06 \times 100\% = 6\%$（Octave 复核 `0.06 * 100 = 6`）。

  **答案：对（A）**（平台正确答案：对）
- 复盘 :-
  - **一数多用**：在额定基值体系下，铭牌短路电压百分数 $u_k\%$ 除以 $100$ 就是短路阻抗标幺值 $z_k^*$（进而 $I_k^* = 1/0.06 \approx 16.7$ 倍额定电流）。
:::

### 第 6 题

空载实验时并不要求外施电压一定等于额定电压，但要求必须同时读取空载电流、空载电压和空载损耗。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  与第 1 题正好反过来检查：空载特性由于铁芯饱和而是弯曲的，不同电压下算出的 $r_m, x_m$ 并不相同——测额定励磁参数必须加到什么电压？
- 完整解答
  错误。空载试验测定的是额定工作点下的铁芯励磁参数（$Z_m, r_m, x_m$）和铁耗，由于铁芯存在磁路饱和，$I_0$、$p_0$、$Z_m$ 均随外施电压非线性变化；为得到额定工作点参数，试验必须加到额定电压 $U_0 = U_N$（通常从约 $1.1 U_N$ 沿下降支路逐点测至额定点及以下），不能任选非额定电压代替。前半句把短路试验的特性错套到了空载试验上。

  **答案：错（B）**（平台正确答案：错）
- 复盘 :-
  - **第 1 题与第 6 题对照表**：
    - 第 1 题：说「短路实验必须等于额定值」 $\to$ **错**；
    - 第 6 题：说「空载实验不要求等于额定电压」 $\to$ **错**。两题把两个实验的条件恰好互换挖坑。
:::

### 第 7 题

采用标幺值计算同时也起到了归算作用。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  写出两侧基准阻抗关系 $Z_{1b} = k^2 Z_{2b}$，比较 $Z_2'^*$ 与 $Z_2^*$ 的比值结果。
- 完整解答
  正确。在变压器标幺值系统中，一次侧与二次侧各自选取自己的额定值为基准值（$U_{1b}=U_{1N},\ U_{2b}=U_{2N},\ I_{1b}=I_{1N},\ I_{2b}=I_{2N}$），满足 $U_{1b} = k U_{2b}$、$I_{1b} = I_{2b}/k$、$Z_{1b} = k^2 Z_{2b}$。因此将二次量归算至一次侧后再求标幺值，折算系数在分子分母中自动消去：
  $$Z_2'^* = \frac{Z_2'}{Z_{1b}} = \frac{k^2 Z_2}{k^2 Z_{2b}} = Z_2^*,\qquad U_2'^* = U_2^*,\qquad I_2'^* = I_2^*$$
  可见用标幺值计算时一、二次侧无需再作绕组折算，自动起到了归算作用。

  **答案：对（A）**（平台正确答案：对）
- 复盘 :-
  - **四大优点之一**：「免除折算」是工程上在大型多电压等级电力系统中全面采用标幺值的核心原因。
:::

### 第 8 题

空载实验时须用低功率因数瓦特表测量变压器的损耗，因为变压器空载运行时的功率因数很低。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  由空载相量图回忆：空载电流主要是滞后电压近 $90^\circ$ 的无功磁化分量，$\cos\varphi_0$ 只有约 $0.1\sim 0.2$。
- 完整解答
  正确。变压器空载时一次电流几乎全部用于建立主磁通（磁化无功分量 $I_\mu \gg I_{Fe}$），因此 $\dot{I}_0$ 滞后 $\dot{U}_0$ 接近 $90^\circ$，空载功率因数 $\cos\varphi_0$ 极低（一般仅 $0.1\sim 0.2$）。普通瓦特表在这种「高电压、一定电流、但有功极小」的工况下满刻度偏转过小、读数误差极大，故必须使用低功率因数瓦特表。

  **答案：对（A）**（平台正确答案：对）
- 复盘 :-
  - **前后闭环**：该考点与 [2.2.1-1](./2.2.1-1变压器空载运行.md) 第 9 题以及 [2.2.1-2](./2.2.1-2变压器负载运行.md) 第 6 题共同围绕同一事实：空载 $\cos\varphi_0$ 极低，负载后功率因数明显高于空载。
:::
