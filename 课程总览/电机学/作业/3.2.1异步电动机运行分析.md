### 1.1 气隙磁场相对静止与转子频率

以下按交流定子旋转磁场（$n_1 = \dfrac{60f_1}{p} \neq 0$）讨论。定子通入频率为 $f_1$ 的对称三相电流，建立转速为 $n_1$ 的定子旋转磁动势 $\dot{F}_1$。当转子以机械转速 $n$ 旋转时，转差率 $s = \dfrac{n_1 - n}{n_1}$，转子绕组感应电动势及电流频率为

$$f_2 = s f_1$$

该转子电流在气隙中产生转子旋转磁动势 $\dot{F}_2$，其**相对转子**的转速为

$$n_2 = \frac{60 f_2}{p} = \frac{60 s f_1}{p} = s n_1 = n_1 - n$$

因此 $\dot{F}_2$ **相对定子空间**的绝对转速恒为

$$n + n_2 = n + (n_1 - n) = n_1$$

无论是电动机（$0<s<1$）、发电机（$s<0$，相序反转使 $n_2<0$）还是反接电磁制动（$s>1$，$n<0$ 使 $n_2>n_1$），$\dot{F}_2$ 与 $\dot{F}_1$ 始终**同向同速**、空间相对静止。（若为定子通直流的能耗制动，$n_1=0$，不再代入 $s=(n_1-n)/n_1$，转子切割静止磁场产生的 $\dot{F}_2$ 同样在空间上与定子直流磁场保持相对静止。）

### 1.2 异步电动机等效电路与功率拆分

对频率为 $f_2 = sf_1$ 的转子电路作频率折算（分子分母同除 $s$）：

$$\dot{I}_2 = \frac{s\dot{E}_2}{r_2 + \mathrm{j}sx_{2\sigma}} = \frac{\dot{E}_2}{\dfrac{r_2}{s} + \mathrm{j}x_{2\sigma}}$$

再经绕组归算到定子侧后，每相转子等效电路的总串联电阻为 $\dfrac{r_2'}{s}$，拆成两段：

$$\frac{r_2'}{s} = r_2' + \frac{1-s}{s}r_2'$$

因正常运行时 $f_2 = sf_1$ 很小（如 1–3 Hz），转子铁耗可忽略不计，于是气隙电磁功率 $P_M$ 全部按下列路径分配：

- 气隙传向转子的电磁功率：$P_M = m_1 I_2'^2 \dfrac{r_2'}{s}$；
- 转子铜耗：$p_{Cu2} = m_1 I_2'^2 r_2' = s P_M$；
- **附加电阻 $\dfrac{1-s}{s}r_2'$ 消耗的功率**：$m_1 I_2'^2 \dfrac{1-s}{s}r_2' = (1-s)P_M = P_M - p_{Cu2} = P_i$（转轴上的**总机械功率**）；
- 扣除机械损耗 $p_{mec}$ 与附加损耗 $p_\Delta$ 后，才是轴上输出功率：$P_2 = P_i - p_{mec} - p_\Delta$。

### 1.3 转子绕组归算与变比推导

将实际转子 $(m_2, N_2, k_{w2})$ 折算为参数 $(m_1, N_1, k_{w1})$ 与定子相同的假想绕组，遵循「磁动势不变」与「总功率（有功损耗与无功）不变」两项原则（下式中 $\Phi_m$ 即 [11-19 笔记](../课堂笔记/11-19-交流绕组电动势与谐波.md#五-绕组因数与相电动势-约-56-06-1-03-46) 所写的每极主磁通 $\Phi$）：

- 由一般 $m$ 相绕组基波旋转磁动势幅值 $F_m = \frac{m}{2}\cdot\frac{2\sqrt2}{\pi}\frac{Nk_wI}{p} = \frac{\sqrt2}{\pi}\frac{mNk_wI}{p} \approx 0.45\frac{mNk_wI}{p}$ 相等：$m_1 N_1 k_{w1} I_2' = m_2 N_2 k_{w2} I_2 \implies K_i = \dfrac{I_2}{I_2'} = \dfrac{m_1 N_1 k_{w1}}{m_2 N_2 k_{w2}}$；
- 由相同气隙主磁通与基准频率 $f_1$ 下相电动势 $E = 4.44 f_1 N k_w \Phi_m$（不含相数 $m$）且 $E_2' = E_1$：$K_e = \dfrac{E_1}{E_2} = \dfrac{E_2'}{E_2} = \dfrac{N_1 k_{w1}}{N_2 k_{w2}}$；
- 由总功率不变 $m_1 I_2'^2 Z_2' = m_2 I_2^2 Z_2$：$K_z = \dfrac{Z_2'}{Z_2} = \dfrac{m_2}{m_1}K_i^2 = \dfrac{m_1}{m_2}\left(\dfrac{N_1 k_{w1}}{N_2 k_{w2}}\right)^2 = K_e K_i$。

## 2. 单选题（第 1–3 题）

### 第 1 题

关于异步电机定、转子旋转磁场描述正确的是（ ）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | D | 不论进入什么运行状态，其转子磁势 $\dot{F}_2$ 与定子磁势 $\dot{F}_1$ 总是同向同速旋转，在空间上保持相对静止。 |
| B | C | 进入电制动运行状态时，转子磁势 $\dot{F}_2$ 与定子磁势 $\dot{F}_1$ 旋转方向相反。 |
| C | A | 进入电动机运行状态时，转子磁势 $\dot{F}_2$ 与定子磁势 $\dot{F}_1$ 旋转方向相同、转速略小。 |
| D | B | 进入发电机运行状态时，转子磁势 $\dot{F}_2$ 与定子磁势 $\dot{F}_1$ 旋转方向相同、转速略大。 |

:::collapse accordion
- 提示
  把「转子**机械**转速 $n$」和「转子**磁势**相对定子的转速 $n + n_2$」严格分开：先算 $\dot{F}_2$ 相对转子的转速 $n_2 = s n_1 = n_1 - n$，再叠加转子机械转速 $n$，看结果是否还依赖运行状态。
- 完整解答
  **第一步：计算转子磁动势 $\dot{F}_2$ 相对定子的转速。**
  设同步转速为 $n_1 = \dfrac{60f_1}{p}$，转子机械转速为 $n$，则转差率 $s = \dfrac{n_1 - n}{n_1}$，转子感应电流频率 $f_2 = sf_1$。
  由旋转磁动势转速公式，$\dot{F}_2$ 相对转子的转速为
  $$n_2 = \frac{60 f_2}{p} = s n_1 = n_1 - n$$
  将转子本身的机械转速 $n$ 叠加上去，$\dot{F}_2$ 相对定子空间的转速为
  $$n + n_2 = n + (n_1 - n) = n_1$$

  **第二步：逐项检验运行状态。**
  - **A（原始位 D）正确**：不论处于电动机（$0<s<1$）、发电机（$s<0$）还是电制动（$s>1$）状态，定转子磁动势相对定子的转速始终同为 $n_1$，同向同速、空间相对静止（这也是产生稳定平均电磁转矩的前提）。
  - **B（原始位 C）错误**：反接电制动时是**转子机械转向**与 $n_1$ 相反（$n<0$），此时 $s>1$、$n_2 = n_1 - n > n_1$，叠加后 $\dot{F}_2$ 对定子仍以 $n_1$ 同向旋转（能耗制动时定子通直流 $n_1=0$，双方仍相对静止）。
  - **C（原始位 A）错误**：电动机运行时「略小于 $n_1$」的是**转子机械转速 $n$**，不是转子磁动势 $\dot{F}_2$ 的空间转速。
  - **D（原始位 B）错误**：发电机运行时「略大于 $n_1$」的是**转子机械转速 $n$**（此时 $s<0$，转子电流相序反转使 $n_2 = n_1-n<0$，$\dot{F}_2$ 相对定子仍为 $n_1$）。

  **答案：A**（原始位 D）
- 复盘 :-
  - **核心陷阱**：B、C、D 全部把「**转子的机械转速 $n$**」偷换成了「**转子磁动势 $\dot{F}_2$ 的空间转速**」。记住口诀：转子无论怎么转（快一点、慢一点、倒着转），转差频率 $f_2=sf_1$ 会自动把缺少或多余的那部分速度补平，使 $\dot{F}_2$ 永远卡死在同步速 $n_1$ 上与 $\dot{F}_1$ 相对静止。
  - **乱序提醒**：本作答页显示位 A 对应原始位 D，提交时按当前页面字母（A）或文字核对，不要照抄未对照的原始字母。
:::

### 第 2 题

异步电动机等效电路图中的附加电阻所消耗的有功功率应等于（ ）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | B | 空载损耗功率 $p_0$ |
| B | A | 气隙电磁功率 $P_M$ |
| C | C | 转轴上总的机械功率 $P_i$ |
| D | D | 转轴上输出的机械功率 $P_2$ |

:::collapse accordion
- 提示
  把转子等效总电阻 $\dfrac{r_2'}{s}$ 拆成 $r_2' + \dfrac{1-s}{s}r_2'$：总电阻吃掉的是气隙传过来的电磁功率 $P_M$，实际铜电阻 $r_2'$ 吃掉的是转子铜耗 $p_{Cu2}$，剩下的「附加电阻」就是两者的差，对照功率流程图里的名称。
- 完整解答
  **第一步：列出转子回路功率关系。**
  在归算并频率折算后的等效电路中，转子支路总电阻为 $\dfrac{r_2'}{s}$，拆分为实际转子电阻与附加模拟电阻两项：
  $$\frac{r_2'}{s} = r_2' + \frac{1-s}{s}r_2'$$
  其中：
  - 气隙电磁功率：$P_M = m_1 I_2'^2 \dfrac{r_2'}{s}$；
  - 转子铜耗：$p_{Cu2} = m_1 I_2'^2 r_2' = s P_M$；
  - 附加电阻消耗的有功功率：
    $$m_1 I_2'^2 \frac{1-s}{s}r_2' = (1-s)P_M = P_M - p_{Cu2} = P_i$$

  **第二步：逐项排错。**
  - **A（原始位 B）错误**：空载损耗 $p_0$ 包括铁耗（对应励磁电阻 $r_m$）和空载机械损耗，与附加电阻无关。
  - **B（原始位 A）错误**：气隙电磁功率 $P_M$ 对应转子支路**总电阻 $\dfrac{r_2'}{s}$** 消耗的功率（即 $P_M = p_{Cu2} + P_i$）。
  - **C（原始位 C）正确**：附加电阻将实际不存在于转子绕组发热中的机电能量转换部分等效出来，其功率等于转轴上产生的**总机械功率 $P_i$**（有时也记作 $P_\Omega$）。
  - **D（原始位 D）错误**：轴上输出机械功率 $P_2 = P_i - p_{mec} - p_\Delta$ 还需从 $P_i$ 中扣除机械损耗和附加损耗，等效电路里的附加电阻尚未扣除这两项损耗。

  **答案：C**（原始位 C）
- 复盘 :-
  - **易混边界**：最容易误选 B（$P_M$）或 D（$P_2$）。区分三者只需一条线：$\dfrac{r_2'}{s}$ → $P_M$；$r_2'$ → $p_{Cu2}$；$\dfrac{1-s}{s}r_2'$ → $P_i$；最后再从 $P_i$ 减去机械与杂散损耗才得到轴输出 $P_2$。
:::

### 第 3 题

一台三相 4 极异步电动机额定运行时，转子转速为 1470 r/min，如果电源频率为 50 Hz，则在转子绕组中产生的感应电流的频率为（ ）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | A | 1 Hz |
| B | C | 30 Hz |
| C | B | 4 Hz |
| D | D | 50 Hz |

:::collapse accordion
- 提示
  按三步依次代数字：① 4 极对应极对数 $p = 4/2 = 2$，先求同步速 $n_1 = \dfrac{60 f_1}{p}$；② 代入 $n = 1470\text{ r/min}$ 求转差率 $s = \dfrac{n_1 - n}{n_1}$；③ 计算 $f_2 = s f_1$。
- 完整解答
  **第一步：求极对数与同步转速。**
  已知磁极数 $2p = 4$，故极对数 $p = 2$；电源频率 $f_1 = 50\text{ Hz}$：
  $$n_1 = \frac{60 f_1}{p} = \frac{60 \times 50}{2} = 1500\text{ r/min}$$

  **第二步：求转差率 $s$。**
  额定运行时 $n = 1470\text{ r/min}$，因此
  $$s = \frac{n_1 - n}{n_1} = \frac{1500 - 1470}{1500} = \frac{30}{1500} = 0.02$$

  **第三步：求转子感应电流频率 $f_2$。**
  $$f_2 = s f_1 = 0.02 \times 50 = 1\text{ Hz}$$
  （亦可直接用转速差算：$f_2 = \dfrac{p(n_1 - n)}{60} = \dfrac{2 \times 30}{60} = 1\text{ Hz}$。）

  **第四步：排错与自检。**
  B（30 Hz）误把转速差 $n_1-n=30\text{ r/min}$ 当成频率；D（50 Hz）是堵转（$s=1, n=0$）时的频率；C（4 Hz）数值误算。

  **答案：A**（原始位 A）
- 复盘 :-
  - **秒检规律**：50 Hz 4 极电机同步速永远是 1500 r/min，每 1% 转差对应 $0.01 \times 50 = 0.5\text{ Hz}$（等价于转差每少 15 r/min 对应 0.5 Hz）；本题少 30 r/min ⇒ 直接得 $1\text{ Hz}$。
  - **数值验算**：Octave 已独立复核 `n1=1500`, `s=0.02`, `f2=1` ✓。
:::

## 3. 多选题（第 4 题）

### 第 4 题

下列关于异步电动机绕组归算的说法正确的有（ ）。

| 显示位 | 原始位 | 选项 |
| :---: | :---: | :--- |
| A | A | 用一个相数、每相串联匝数以及绕组因数和定子绕组相同的假想绕组替代实际的转子绕组，而且应保持归算前后转子磁动势和转子总的功率不变。 |
| B | C | 电流比 $K_i = \dfrac{I_2}{I_2'} = \dfrac{m_1 N_1 k_{w1}}{m_2 N_2 k_{w2}}$ |
| C | B | 电势比 $K_e = \dfrac{E_1}{E_2} = \dfrac{E_2'}{E_2} = \dfrac{N_1 k_{w1}}{N_2 k_{w2}}$ |
| D | D | 阻抗变比 $K_e K_i = \dfrac{m_1}{m_2}\left(\dfrac{N_1 k_{w1}}{N_2 k_{w2}}\right)^2$ |

:::collapse accordion
- 提示
  先把变压器归算的两个「不许动」扩写到旋转电机（多出相数 $m_1/m_2$ 与绕组因数 $k_{w1}/k_{w2}$）：① 写旋转电机基波磁动势幅值比例式 $m_1 N_1 k_{w1} I_2' = m_2 N_2 k_{w2} I_2$ 反解 $I_2/I_2'$；② 用相电势式 $E=4.44 f_1 N k_w \Phi_m$ 写 $E_1/E_2$；③ 用有功/无功功率不变 $m_1 I_2'^2 Z_2' = m_2 I_2^2 Z_2$ 推 $Z_2'/Z_2$ 并核对它是否正好等于 $K_e K_i$。
- 完整解答
  **逐项推导与核对**：

  1. **选项 A（原始位 A）：正确。**
     异步电动机定子与转子不仅每相匝数、绕组因数不同，相数也可能不同（例如笼型转子 $m_2 \neq 3$）。转子绕组归算就是用一个**相数 $m_1$、每相串联匝数 $N_1$、绕组因数 $k_{w1}$ 均与定子相同**的假想绕组代替实际转子 $(m_2, N_2, k_{w2})$，且必须保持归算前后**转子磁动势不变**与**转子总功率（有功损耗与无功功率）不变**。

  2. **选项 B（原始位 C）：正确。**
     由转子基波旋转磁动势幅值不变（$F_{2m}' = F_{2m}$，其余常数如 $\frac{0.45}{p}$ 或 $\frac{\sqrt2}{\pi p}$ 两侧相同约去）：
     $$m_1 N_1 k_{w1} I_2' = m_2 N_2 k_{w2} I_2 \quad\Longrightarrow\quad K_i = \frac{I_2}{I_2'} = \frac{m_1 N_1 k_{w1}}{m_2 N_2 k_{w2}}$$

  3. **选项 C（原始位 B）：正确。**
     对同一气隙主磁通 $\Phi_m$（即 `11-19` 中的 $\Phi$）与同一基准频率 $f_1$（频率折算后转子基准电势记为 $E_2$，归算后满足 $E_2' = E_1$），相电动势 $E = 4.44 f_1 N k_w \Phi_m$ 与相数 $m$ 无关，因此：
     $$K_e = \frac{E_1}{E_2} = \frac{E_2'}{E_2} = \frac{N_1 k_{w1}}{N_2 k_{w2}}$$

  4. **选项 D（原始位 D）：正确。**
     由转子总功率（含铜耗与漏抗无功）不变，$m_1 I_2'^2 Z_2' = m_2 I_2^2 Z_2$，得阻抗归算系数：
     $$K_z = \frac{Z_2'}{Z_2} = \frac{m_2}{m_1}\left(\frac{I_2}{I_2'}\right)^2 = \frac{m_2}{m_1} K_i^2 = \frac{m_2}{m_1}\left(\frac{m_1 N_1 k_{w1}}{m_2 N_2 k_{w2}}\right)^2 = \frac{m_1}{m_2}\left(\frac{N_1 k_{w1}}{N_2 k_{w2}}\right)^2$$
     另一方面直接相乘：
     $$K_e K_i = \frac{N_1 k_{w1}}{N_2 k_{w2}} \cdot \frac{m_1 N_1 k_{w1}}{m_2 N_2 k_{w2}} = \frac{m_1}{m_2}\left(\frac{N_1 k_{w1}}{N_2 k_{w2}}\right)^2$$
     二者完全一致。

  **答案：A、B、C、D**
- 复盘 :-
  - **和变压器归算的联系与区别**：变压器里 $m_1=m_2=1$（或同为三相）、$k_{w1}=k_{w2}=1$，所以退化为 $K_e = K_i = k = N_1/N_2$、$K_z = k^2$。异步电动机因为 $m_1\neq m_2$ 且存在绕组因数 $k_{w1}, k_{w2}$，所以 **$K_i$ 带 $\frac{m_1}{m_2}$，而 $K_e$ 不带 $\frac{m_1}{m_2}$**，于是阻抗变比 $K_e K_i$ 里正好留下一次方 $\frac{m_1}{m_2}$。
  - **做题常见错觉**：多选题看到四个全对常怀疑是不是少看了一个细节，只要核对「相电势公式不含 $m$、磁动势含 $m$、总功率为 $m I^2 Z$」三件事，就能把 $K_e$、$K_i$、$K_e K_i$ 里的 $\frac{m_1}{m_2}$ 次幂当场验死。
