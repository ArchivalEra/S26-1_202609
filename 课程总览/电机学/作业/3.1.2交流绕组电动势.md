## 2. 单选题（一、1–4 题）

### 一、1

某交流绕组极数 $2p=4$，若机械角度为 $180^\circ$，则对应的电角度是（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | $45^\circ$ |
| B | $180^\circ$ |
| C | $360^\circ$ |
| D | $720^\circ$ |

:::collapse accordion
- 提示
  先从极数 $2p=4$ 算出极对数 $p$（别直接把 $4$ 当 $p$！），再乘以机械角度 $\alpha_e = p\alpha_m$。
- 完整解答
  由极数 $2p = 4$ 得极对数 $p = 2$。
  每经过一对磁极（N 极加 S 极），空间电磁量恰好走完一个完整电周期 $360^\circ$，故电角度与机械角度换算关系为：
  $$\alpha_e = p \cdot \alpha_m = 2 \times 180^\circ = 360^\circ$$
  （Octave 复核 `(4/2)*180 = 360`）。

  **答案：C**（双签盲测一致）
- 复盘 :-
  - **高频粗心坑**：看清题面给的是「极数 $2p=4$」还是「极对数 $p=4$」——直接拿 $4\times 180^\circ$ 就会误选 D（$720^\circ$）。
:::

### 一、2

一台 $m$ 相交流电机，定子槽数 $Z$，极对数 $p$，则极距为（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | $Z/p$ |
| B | $Z/(2p)$ |
| C | $Z/(pm)$ |
| D | $Z/(2pm)$ |

:::collapse accordion
- 提示
  极距是**一个磁极**所占的槽数：一共 $2p$ 个磁极均分 $Z$ 个槽，与相数 $m$ 无关。
- 完整解答
  极对数为 $p$ 对应气隙圆周共有 $2p$ 个磁极（$p$ 对 N–S 极）。以定子槽数表示的极距 $\tau$ 为相邻两磁极轴线之间的槽数：
  $$\tau = \frac{Z}{2p}$$
  选项 D（$Z/(2pm)$）是**每极每相槽数 $q$**，注意不要把极距 $\tau$ 和 $q$ 混为一谈。

  **答案：B**（双签盲测一致）
- 复盘 :-
  - **三量区别**：$\tau = Z/(2p)$（极距，每个极下多少槽）；$q = \tau/m = Z/(2pm)$（每极每相槽数）；$\alpha = 360^\circ p / Z$（槽距角）。
:::

### 一、3

关于交流绕组的电动势 $E = 4.44 f N k_w \Phi_m$ 的说法正确的是（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | $N = p q N_c / a$ |
| B | 集中绕组时，$k_w = 1$ |
| C | $\Phi_m$ 是指随时间作正弦变化的磁通的最大值 |
| D | $\Phi_m$ 是指每个磁极对应的总的磁通量 |

:::collapse accordion
- 提示
  逐个核对四项边界：双层绕组串联匝数公式还带系数 $2$；集中绕组只保证 $k_d=1$，若同时短距则 $k_w=k_p<1$；旋转电机 $\Phi_m$ 是空间正弦气隙磁场**每极总磁通**而非某点交变铁芯磁通。
- 完整解答
  逐项判别：
  - **A 错误**：对于通用教材主流讨论的双层绕组，每对极每相共有 $2q$ 个线圈、各匝 $N_c$ 串联再分 $a$ 条并联支路，故每相串联匝数为 $N = \frac{2pqN_c}{a}$（单层绕组才是 $\frac{pqN_c}{a}$，且按 $11\text{-}19$ 课堂统一记作 $\frac{FpqN_c}{a}$）；
  - **B 错误**：集中绕组仅指 $q=1$（不分布），因此分布因数 $k_d = 1$，但绕组仍可采用短距线圈，只有「集中整距」才一定有 $k_w = k_p k_d = 1$；
  - **C 错误**：那是变压器铁芯交变磁通随时间变化的最大值；在旋转电机稳态下，气隙旋转磁场扫过定子，每极下的空间积分磁通幅值才是 $\Phi_m$；
  - **D 正确**：公式中 $\Phi_m$ 的物理含义即气隙空间正弦分布磁场下**每个磁极所对应的总磁通量**（面积分 $\Phi = \frac{2}{\pi}B_{\delta 1}\tau l_{ef}$）。

  **答案：D**（双签盲测一致）
- 复盘 :-
  - **变压器 vs 旋转电机对照**：变压器铁芯 $\Phi_m$ 是「时间正弦交变磁通最大值」；旋转电机 $\Phi$ 是「气隙里一个磁极下面的总磁通」。
:::

### 一、4

一台三相交流电机，定子槽数为 $Z=36$，极对数为 $p=2$，则每极每相槽数 $q=$（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 3 |
| B | 6 |
| C | 9 |
| D | 18 |

:::collapse accordion
- 提示
  「三相」即相数 $m=3$；直接代公式 $q = \frac{Z}{2pm}$，看清极对数是 $p=2$（不是 $2p=2$）。
- 完整解答
  已知 $Z = 36$，$p = 2$，三相电机 $m = 3$，代入每极每相槽数公式：
  $$q = \frac{Z}{2pm} = \frac{36}{2 \times 2 \times 3} = 3$$
  （Octave 复核 `36/(2*2*3) = 3`）。极距 $\tau = Z/(2p) = 9$，每极每相占 $q = 9/3 = 3$ 槽。

  **答案：A**（双签盲测一致）
- 复盘 :-
  - **防错验算**：$q = 3 \implies$ 极距 $\tau = 3q = 9$ 槽 $\implies$ 总槽数 $2p\tau = 4\times 9 = 36$ 槽，一步回代即可自洽闭环。
:::

## 3. 判断题（二、1–4 题）

### 二、1

选择 $y_1 = \frac{5}{6}\tau$ 的短距线圈，可同时削弱电机绕组相电动势中的第 5 次和第 6 次谐波。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  记住两条硬事实：① 对称气隙磁场只含**奇次**谐波（$1, 3, 5, 7, \dots$），根本没有 6 次谐波；② $y_1 = \frac{5}{6}\tau$（短距角 $\beta = 30^\circ$）同时大幅压低相邻的**第 5 次与第 7 次**谐波（而对假设存在的 6 次计算 $|k_{p6}| = |\cos(6\times 15^\circ)| = 0$？注意 $11\text{-}19$ 笔记记法用 $\cos\frac{\nu\beta}{2}$ 时 $\cos 90^\circ=0$ 恰是 6 次被消位置，但真实波形只含奇次、工程上用 $\frac{5}{6}\tau$ 削弱的是第 5 与第 7 次！）。
- 完整解答
  错误。气隙磁场具有半波对称性，分解出的空间谐波**只含奇次谐波**（3、5、7、9…次），并不存在第 6 次偶次谐波。工程上最常用的 $y_1 = \frac{5}{6}\tau$（短距角 $\beta = \frac{1}{6}\times 180^\circ = 30^\circ$）在形式上对应消 6 次的中间节距，实际作用是**同时把相邻的 5 次与 7 次奇次谐波的短距因数压低至 $|k_{p5}| = |k_{p7}| = \cos(75^\circ) = 0.2588$**（Octave 复核：`abs(cosd(5*30/2)) = 0.2588`），而非同时削弱第 5 次和第 6 次。

  **答案：错（B）**（双签盲测一致）
- 复盘 :-
  - **经典高频考点**：「用 $\frac{5}{6}\tau$ 节距，夹在 5 和 7 中间 $\implies$ 同时大幅削弱 **5 次和 7 次**谐波」。看到「5 次和 6 次」必判错。
:::

### 二、2

在三相对称绕组相电动势中不会出现 3 及 3 的奇数倍次谐波。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  盯紧题干里的一个字——它写的是「**相**电动势」还是「**线**电动势」？
- 完整解答
  错误。在三相对称绕组中，3 次及 3 的奇数倍次谐波电动势在 A、B、C 三相中**大小相等、相位相同**（均成零序关系）：
  - 在每一**相**绕组内部，只要该次谐波绕组因数 $k_{w\nu} \neq 0$，**相电动势中依然存在 3 及 3 的奇数倍次谐波**；
  - 当绕组**星形联结**取**线电动势** $\dot{E}_{AB} = \dot{E}_A - \dot{E}_B$ 时，等幅同相的 3 倍数次谐波相减相互抵消而不出现在线电动势中（三角形联结时线端由闭合三角形内零序环流压降消去三次谐波，同样不出线端）。

  题干将「线电动势」偷换为「相电动势」，故错误。

  **答案：错（B）**（双签盲测一致）
- 复盘 :-
  - **11-19 课堂原话警句**：「关键字是**线**电动势；改成**相**电动势，结论立刻反了。」
:::

### 二、3

短距因数又称短距系数，它是指短距线圈电动势与整距线圈电动势之比。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  按四级链条的物理含义核对定义：单根线圈由整距改成短距时电动势打了多少折，就是短距因数 $k_p$。
- 完整解答
  正确。在匝数相同、每极磁通相同的条件下，短距线圈两有效边感应电动势相量之和（$2E_1\cos\frac{\beta}{2}$）与整距线圈电动势（代数和 $2E_1$）之比定义为短距因数（亦称节距因数或短距系数）：
  $$k_p = \frac{\text{短距线圈电动势}}{\text{整距线圈电动势}} = \cos\frac{\beta}{2} = \sin\!\left(\frac{y_1}{\tau}\cdot\frac{\pi}{2}\right)$$

  **答案：对（A）**（双签盲测一致）
- 复盘 :-
  - **等价两种写法**：用短距角 $\beta = (1-y_1/\tau)\pi$ 记为 $\cos(\beta/2)$（$11\text{-}19$ 笔记写法），用节距比 $y_1/\tau$ 记为 $\sin(\frac{y_1}{\tau}\frac{\pi}{2})$，二者三角恒等。
:::

### 二、4

分布因数又称分布系数，它是指线圈组 $q$ 个线圈电动势的相量和与代数和之比。（ ）

| 选项 | 内容 |
| :---: | :--- |
| A | 对 |
| B | 错 |

:::collapse accordion
- 提示
  同一线圈组内 $q$ 个线圈嵌在不同槽里，彼此差槽距角 $\alpha$，合成总电动势只能求相量和；相量和（弧的弦）除以代数和（弧长）正是分布因数 $k_d$。
- 完整解答
  正确。分布绕组将每极每相 $q$ 个线圈依次嵌在相邻差槽距角 $\alpha$ 的槽中，其串联总电动势的相量和幅值小于各自电动势的算术（代数）和。二者之比定义为分布因数（又称分布系数）：
  $$k_d = \frac{q\text{ 个线圈电动势相量和}}{\text{代数和}} = \frac{\sin\frac{q\alpha}{2}}{q\sin\frac{\alpha}{2}}$$

  **答案：对（A）**（双签盲测一致）
- 复盘 :-
  - **两级折扣对比**：短距因数 $k_p$ 发生在**单个线圈内部两边之间**；分布因数 $k_d$ 发生在**同一线圈组 $q$ 个线圈之间**。
:::

## 4. 多选题（三、1 题）

### 三、1

下列关于电机采用分布绕组和短距绕组的说法正确的是（ ）。

| 选项 | 内容 |
| :---: | :--- |
| A | 采用分布绕组和短距绕组时会牺牲部分相电动势，但可改善交流电机相电动势波形。 |
| B | 采用短距绕组可消除高次谐波，当节距缩短 $\tau/\nu$，可消除 $\nu$ 次谐波。 |
| C | 采用分布绕组削弱高次谐波电动势，$q$ 越大，分布因数越小。 |
| D | 采用分布绕组削弱高次谐波电动势，$q$ 越大，分布因数越大。 |

:::collapse accordion
- 提示
  重点检查 B、C、D：① 缩短 $\tau/\nu$ 对应 $y_1 = \tau - \tau/\nu = (1-\frac{1}{\nu})\tau$，$\beta = 180^\circ/\nu \implies \cos(\nu\beta/2) = \cos 90^\circ = 0$；② C 与 D 互斥二选一：分布槽数 $q$ 越多，向量圆弧弯折越厉害，相量和相对代数和的比值 $k_d$ 越大还是越小？
- 完整解答
  逐项判别：
  - **A 正确**：短距与分布均使基波绕组因数 $k_{w1} = k_{p1}k_{d1} < 1$，略微牺牲了基波相电动势，但使高次谐波因数以更快幅度衰减，从而显著改善电动势波形；
  - **B 正确**：将线圈节距缩短 $\tau/\nu$，即取 $y_1 = \left(1 - \frac{1}{\nu}\right)\tau$、短距角 $\beta = \frac{180^\circ}{\nu}$，代入 $\nu$ 次谐波短距因数得 $k_{p\nu} = \cos\left(\nu\cdot\frac{90^\circ}{\nu}\right) = \cos 90^\circ = 0$，可彻底消除 $\nu$ 次谐波；
  - **C 正确、D 错误**：C 与 D 直接矛盾。在相带固定为 $60^\circ$（$\alpha = 60^\circ/q$）及基波与主要奇次（5、7 次）谐波下，随 $q$ 增大，相邻线圈相量展开弧度细化、相量和与代数和之比单调下降（例如 Octave 复核 5 次谐波分布因数 $|k_{d5}|$ 在 $q=1,2,3$ 时分别为 $1.0000 \to 0.2588 \to 0.2176$），即 $q$ 越大分布因数越小。

  **答案：A、B、C**（双签盲测 + Octave 复核一致）
- 复盘 :-
  - **工程选槽边界（11-19 笔记）**：虽说 $q$ 越大 $k_{d1}$ 与 $k_{d\nu}$ 越低，但 $q \ge 4\sim 6$ 后下降趋于饱和，再增加槽数反而徒增制造成本，故交流电机通常取 $q = 2\sim 6$。
:::
