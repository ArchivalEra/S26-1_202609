# 课程总览

目前已确认七门课程：**工程数学**、**电力大数据与人工智能**、**形势与政策**、**电路原理**、**电子技术**、**电机学**与**劳动教育**。历史领域分类不是真实课程清单。

| 课程 | 入口 |
| :--- | :--- |
| 工程数学 | [课程索引](./工程数学/index.md) —— 行列式、矩阵与逆、初等变换与秩、向量组的线性相关性与秩；教材第 1–3 章解析、3 次作业、技法库 |
| 电力大数据与人工智能 | [课程索引](./电力大数据与人工智能/index.md) · [备考](./电力大数据与人工智能/备考.md) —— 安全稳定与暂态评估、电力大数据特点与 AI 算法、聚类与神经网络、密度初筛与智能校核、一次调频与性能评价 |
| 形势与政策 | [课程索引](./形势与政策/index.md) |
| 电路原理 | [课程索引](./电路原理/index.md) —— 电路模型、KCL/KVL 与等效变换、网孔与节点电压法、叠加与戴维南诺顿、习题册第三章讲评、正弦量与相量 |
| 电子技术 | [课程索引](./电子技术/index.md) —— 器件基础、逻辑代数与卡诺图、组合逻辑、触发器与时序逻辑；实验一（常用逻辑门电路）与实验二（译码器与三人表决器） |
| 电机学 | [课程索引](./电机学/index.md) —— 磁路基础、变压器空载与负载运行、参数测定与效率、三相变压器（联结组标号与三次谐波） |
| 劳动教育 | [课程索引](./劳动教育/index.md) |

> 每门课四类：作业、教材解析、课堂笔记、原始资料。形势与政策**不设教材解析**（该课没有需要逐节整理的教材正文，属允许的按课程声明豁免分类）。
> **2026-10-30 删去「音频」类**：七门课那个目录里从来只有一份「尚未提供音频下载链接」的占位，既无内容、又违反「资料页零未竟表述」；课堂录音的转写已在「原始资料」登记，读者要的是「课堂笔记」。
**题号与公式分离**：题面的 `(1)`、`(2)` 等小题编号写在公式**外**（不是 `$$(1)\quad…$$`）。题号是排版标签，塞进公式会让转译产物变成 `(1) [3 2 -4; …]` 这种两个操作数并置的非法形态 —— 分离之后纯矩阵才能算。
> **可算公式按 `{:calc}` 标记**：显示公式带这个标记才出「计算」按钮（站内 Octave 求值）。标记由作者逐个挑、不自动推断；标错在构建期报错。
