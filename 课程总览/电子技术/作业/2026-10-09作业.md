## 一、习题 7.8(1)（提公因子 + 消去法）

证明 $A\overline{B} + BD + \overline{A}D + DC = A\overline{B} + D$。

:::collapse accordion
- 提示
  先把含 $D$ 的项归并成组，再提公因子
  ① $BD$ 与 $\overline{A}D$ 两项都含 $D$，用交换律/结合律归并到一起，提取公因子：$D(B + \overline{A})$。
  ② 括号里的 $\overline{A}+B$ 由摩根定律正是 $A\overline{B}$ 的**反**（$\overline{A\overline{B}}=\overline{A}+B$）——这就是**消去法**的形状 $X+\overline{X}Y$。
- 完整解答
  **第一步：把两个含 $D$ 的项归并成一组**（交换律 + 结合律，只重排、不变形）

  $$A\overline{B} + \big(BD + \overline{A}D\big) + DC.$$

  **第二步：从 $BD + \overline{A}D$ 提公因子 $D$**（分配律反用；交换律把 $B+\overline{A}$ 写成 $\overline{A}+B$）

  $$BD + \overline{A}D = D(B + \overline{A}) = D(\overline{A} + B).$$

  代入：

  $$A\overline{B} + D(\overline{A} + B) + DC.$$

  **第三步：对 $A\overline{B}$ 与 $D(\overline{A}+B)$ 用消去法**（$DC$ 由结合律暂留，末步再处理）。
  取 $X=A\overline{B}$，由摩根定律 $\overline{X}=\overline{A\overline{B}}=\overline{A}+B$，于是 $D(\overline{A}+B)=D\cdot\overline{X}=\overline{X}\cdot D$。
  由消去法 $X + \overline{X}Y = X + Y$（取 $Y=D$）：

  $$A\overline{B} + D(\overline{A} + B) = A\overline{B} + D.$$

  **第四步：剩下的 $DC$ 被 $D$ 吸收**（吸收律 $D + DC = D$）

  $$A\overline{B} + D + DC = A\overline{B} + D. \qquad\blacksquare$$

  **答案**：左边 $= A\overline{B} + D =$ 右边。

  **验算（真值表穷举）**：$A,B,C,D$ 的全部 16 组取值代入左右两边，逐组相等；上面每一步也都与原式逐组比对过（Octave 16/16 一致）。
- 复盘
  这题的钥匙是「**先提公因子，再消去**」
  $BD$ 与 $\overline{A}D$ 都含 $D$，提出来即可。提完之后括号里出现 $\overline{A}+B$，由摩根定律它正是第一项 $A\overline{B}$ 的反
  （$\overline{A\overline{B}}=\overline{A}+B$），直接套消去法收尾。**凡某变量在多项里都出现，第一步永远是提公因子**；
  **提完用摩根定律把括号写成另一项的反**——能对上，就能消去。$DC$ 不必急着并进括号，留到最后被 $D$ 吸收更省事。
:::

## 二、习题 7.8(2)（展开消零 + 两次消去法）

证明 $BC + D + \overline{D}(\overline{B}+\overline{C})(DA+B) = B + D$。

> **先看清题面**：中间一项是 $\overline{D}(\overline{B}+\overline{C})(DA+B)$——**$D$、$B$、$C$ 各自带横线**。
> 其中 $\overline{B}+\overline{C}$ 是**两个字母分别取反**（$B$ 上一条横线、$C$ 上一条横线），
> **不是**整段 $\overline{B+C}$（一条横线把 $B+C$ 整段盖住）。$\overline{D}$ 与后面两个括号是**相乘**关系。
> 这两种写法是两个不同的函数，读错一处整题就废。

:::collapse accordion
- 提示
  先把括号展开、划掉必为 0 的项，式子会立刻瘦下来
  ① $(DA+B)$ 展开成两项；② $\overline{D}$ 乘 $DA$ 里有 $\overline{D}D=0$，整项归零；
  ③ $B$ 乘 $(\overline{B}+\overline{C})$ 里有 $B\overline{B}=0$，也只剩一项；④ 剩下两项之间用消去法，最后吸收收口。
- 完整解答
  **第一步：展开 $(DA+B)$**

  $$\overline{D}(\overline{B}+\overline{C})(DA+B) = \overline{D}(\overline{B}+\overline{C})DA + \overline{D}(\overline{B}+\overline{C})B.$$

  **第二步：第一项含 $\overline{D}D=0$，整项归零**

  $$\overline{D}(\overline{B}+\overline{C})DA = (\overline{D}D)(\overline{B}+\overline{C})A = 0.$$

  只剩

  $$\overline{D}(\overline{B}+\overline{C})B.$$

  **第三步：展开 $(\overline{B}+\overline{C})B$，划掉 $B\overline{B}=0$**

  $$(\overline{B}+\overline{C})B = B\overline{B} + B\overline{C} = 0 + B\overline{C} = B\overline{C}.$$

  所以第三项 $= \overline{D}B\overline{C}$。原式化为

  $$BC + D + \overline{D}B\overline{C}.$$

  **第四步：对 $BC$ 与 $\overline{D}B\overline{C}$ 提公因子 $B$**

  $$BC + \overline{D}B\overline{C} = B\big(C + \overline{D}\,\overline{C}\big).$$

  **第五步：对括号用消去法**。取 $X=C$，则 $\overline{X}=\overline{C}$，由 $X+\overline{X}Y=X+Y$（取 $Y=\overline{D}$）：

  $$C + \overline{D}\,\overline{C} = C + \overline{D}.$$

  于是 $BC + \overline{D}B\overline{C} = B(C + \overline{D}) = BC + B\overline{D}$。原式 $= BC + B\overline{D} + D$。

  **第六步：对 $B\overline{D}$ 与 $D$ 用消去法**。取 $X=D$（则 $\overline{X}=\overline{D}$），$B\overline{D}=\overline{D}\cdot B$：

  $$B\overline{D} + D = D + B.$$

  原式 $= BC + B + D$。

  **第七步：吸收**（吸收律 $B + BC = B$）

  $$BC + B + D = B + D. \qquad\blacksquare$$

  **答案**：左边 $= B + D =$ 右边。

  **验算（真值表穷举）**：$A,B,C,D$ 全部 16 组取值代入左右两边，逐组相等；上述七步每一步也与原式逐组比对，全部等价（Octave 16/16 一致）。
- 复盘
  展开消零 + 两次消去法
  拆完**先展开划掉必为 0 的项**（$\overline{D}DA=0$、$B\overline{B}=0$），式子会立刻瘦下来；
  剩下的互补对（$C$ 与 $\overline{C}$、$D$ 与 $\overline{D}$）就是消去法的下手点。**本题消去法用了两次**
  （先关于 $C$ 消掉 $\overline{C}$，再关于 $D$ 消掉 $\overline{D}$），最后一步吸收律收口。
  读题时务必看清**横线盖住谁**：$\overline{B}+\overline{C}$（两个字母各自取反）与 $\overline{B+C}$（整段取反）是两个不同的函数。
:::

## 三、习题 7.8(3)（互补律：四个最小项合起来等于 1）

证明 $AB + A\overline{B} + \overline{A}B + \overline{A}\,\overline{B} = 1$。

:::collapse accordion
- 提示
  四项恰好是 $A$、$B$ 的全部四种组合（穷举，无遗漏）
  ① 前两项提 $A$、后两项提 $\overline{A}$：$A(B+\overline{B}) + \overline{A}(B+\overline{B})$。
  ② 括号里 $B+\overline{B}=1$（**互补律**），式子变成 $A\cdot1 + \overline{A}\cdot1 = A + \overline{A} = 1$。
- 完整解答
  **第一步：分组提公因子**

  $$AB + A\overline{B} + \overline{A}B + \overline{A}\,\overline{B} = A(B+\overline{B}) + \overline{A}(B+\overline{B}).$$

  **第二步：互补律 $B+\overline{B}=1$**

  $$= A\cdot 1 + \overline{A}\cdot 1 = A + \overline{A}.$$

  **第三步：再互补律**

  $$A + \overline{A} = 1. \qquad\blacksquare$$

  **答案**：左边 $= 1 =$ 右边。

  **验算**：四组取值代入，四项里**恰有一项为 1**（对应该组取值），左边恒为 1（Octave 4/4 一致）。
- 复盘
  这是「最小项之和恒为 1」的实例
  四个与项恰好是二变量全部 4 个最小项。**一个逻辑式若列全了某几个变量的所有组合，它就恒等于 1**
  ——这是互补律的推广，也是后面卡诺图「全 1 可以圈成一整块」的根据。
:::

## 四、习题 7.8(4)（两边都化到最小项再比）

证明 $A\overline{B} + B\overline{C} + C\overline{A} = \overline{A}B + \overline{B}C + \overline{C}A$。

:::collapse accordion
- 提示
  两边结构对称（三项轮换）——都化到最小项再比集合
  ① 每项缺一个变量，用 $X+\overline{X}=1$ 补上，把两边都展开成**最小项表达式**。
  ② 两边最小项集合相同 ⇒ 逻辑函数相同 ⇒ 恒等。最小项表达式是唯一的，所以这是恒等的**机械判据**。
- 完整解答
  **左边展开成最小项**（每项缺的变量补齐）：

  - $A\overline{B}$ 缺 $C$：$A\overline{B}=A\overline{B}(C+\overline{C})=A\overline{B}C+A\overline{B}\,\overline{C}$；
  - $B\overline{C}$ 缺 $A$：$B\overline{C}=B\overline{C}(A+\overline{A})=AB\overline{C}+\overline{A}B\overline{C}$；
  - $C\overline{A}$ 缺 $B$：$C\overline{A}=C\overline{A}(B+\overline{B})=\overline{A}BC+\overline{A}\,\overline{B}C$。

  左边 $= A\overline{B}C+A\overline{B}\,\overline{C}+AB\overline{C}+\overline{A}B\overline{C}+\overline{A}BC+\overline{A}\,\overline{B}C$。

  **右边展开成最小项**：

  - $\overline{A}B$ 缺 $C$：$\overline{A}B=\overline{A}BC+\overline{A}B\overline{C}$；
  - $\overline{B}C$ 缺 $A$：$\overline{B}C=A\overline{B}C+\overline{A}\,\overline{B}C$；
  - $\overline{C}A$ 缺 $B$：$\overline{C}A=AB\overline{C}+A\overline{B}\,\overline{C}$。

  右边 $= \overline{A}BC+\overline{A}B\overline{C}+A\overline{B}C+\overline{A}\,\overline{B}C+AB\overline{C}+A\overline{B}\,\overline{C}$。

  **两边的最小项完全相同** ⇒ 逻辑函数相同 ⇒ 恒等。 $\blacksquare$

  **验算**：$A,B,C$ 全部 8 组取值代入左右两边，逐组相等（Octave 8/8 一致）。
- 复盘
  「两边都复杂」时就都化到最小项
  证明恒等式有个机械判据：**两边各自化成最小项表达式，集合相同就恒等**（教材原话：最小项表达式唯一）。
  本题两边都是三项轮换，本质是**三变量奇校验**（1 的个数为奇数时输出 1）。
:::

## 小结：这份作业要带走的东西

1. **提公因子是第一步**：某变量在多项里重复出现（7.8(1) 的 $D$）就先提出来，提完再看括号里有没有互补对。
2. **消去法 $X+\overline{X}Y=X+Y$ 是主力**：本题用了三次。用法——认准 $X$，把另一项写成 $\overline{X}\cdot Y$，就能消掉 $\overline{X}$ 只留 $Y$。
3. **展开后先划掉必为 0 的项**：$\overline{D}D=0$、$B\overline{B}=0$ 这类项一出现就整项归零，式子立刻变短（7.8(2)）。
4. **互补律把「全组合」收成 1**：式子若列全了某几个变量的所有组合，恒等于 1（7.8(3)）。
5. **恒等式的机械判据 = 最小项集合相同**：两边都复杂时，各自展开成最小项再比集合，不靠灵感（7.8(4)）。
6. **横线盖住谁必须看清**：$\overline{B}+\overline{C}$（各自取反）与 $\overline{B+C}$（整段取反）是两个函数——读错一处整题就废。
