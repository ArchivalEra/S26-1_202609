## 2. 习题 2.7

**题面**（逐字）：

> 2.7 在如图 2.05 所示射极输出器电路中，已知 $r_{be}=0.45\,\text{k}\Omega$，$\beta=50$。试求：
> (1) Q 点；
> (2) 输入电阻 $r_i$；
> (3) 电压放大倍数 $A_u$。

**图 2.05 接线转写**（图注原文「图 2.05　习题 2.7 图」；射极输出器即共集电极电路）：

| 元件／端子 | 接法 |
| :--- | :--- |
| $+U_{CC}$ 母线 | 顶部横线，右端标 `+U_CC` 与 `(+20 V)`；$R_B$ 上端与晶体管**集电极**都接此母线（集电极向上直连，中间无电阻） |
| $R_B=30\ \text{k}\Omega$ | 竖直，上端接 $+U_{CC}$，下端接**基极节点** |
| $C_1$ | 水平耦合电容，接在 $R_S$ 上端节点与基极节点之间；靠基极一侧（右侧）标 `+` |
| $\dot U_s$ 与 $R_S$ | 信号源在左（上正下负），上端串 $R_S$ 后接 $C_1$ 左极板，下端接公共地。**$R_S$ 图上未标阻值**（原件如此） |
| $R_E=800\ \Omega$ | 竖直，上端接**发射极**，下端接底部公共地（有接地符号） |
| $C_2$ | 水平耦合电容，左端接发射极节点（左侧标 `+`），右端接 $R_L$ 上端 |
| $R_L=1.2\ \text{k}\Omega$ | 竖直，上端接 $C_2$ 右端，下端接公共地 |
| $\dot U_o$ | 取自 $R_L$ 上端（即 $C_2$ 右端）对地，`+` 在上 |
| 公共端 | 底部一条水平线把 $\dot U_s$ 负端、$R_E$ 下端、$R_L$ 下端连通 |

**一题两套负载（本页最重要的一条）**：同一张图，第 (1) 问与第 (2)(3) 问用的**发射极到地的那只电阻不是同一个**——直流量看 $C_2$ 开路、只剩 $R_E$；交流量看 $C_2$ 短路、$R_E\parallel R_L$。混用这一处，$r_i$ 会大 28%、$A_u$ 会高 0.7 个百分点。

| 对比项 | 直流（第 (1) 问 Q 点） | 交流（第 (2)(3) 问 $r_i$、$A_u$） |
| :--- | :--- | :--- |
| $C_1$、$C_2$ | **开路**（隔直） | **短路**（容抗可忽略） |
| $U_{CC}$ 母线 | $+20$ V 直流电源 | **交流接地** |
| 发射极到地 | 只有 $R_E=0.8\ \text{k}\Omega$ | $R_L'=R_E\parallel R_L=0.48\ \text{k}\Omega$ |
| 基极电阻 $R_B$ | 串在基极回路里，限流 | 并在 B–地之间 |
| 管子参数 | $\beta$、$U_{BE}$ | $r_{be}$、$\beta$（受控源 $\beta i_B$） |

**两处口径先说明**（题面与图上没有、但做题必须先定）：

1. **$r_i$ 的定义域**：按射极输出器的常规定义，$r_i$ 指**从基极看进去**的输入电阻（**不含** $R_S$）——这是通行口径。图上 $\dot U_i$ 的标注跨哪两端不明确，本页不靠那处标注判定义，只按上面的通行口径算。
2. **$U_{BE}$ 取值**：硅管放大状态发射结正偏，$U_{BE}$ 取 $0.7$ V（课堂口径：题目一般给 $0.6$ 或 $0.7$，本题未给，取 $0.7$ V；取 $0.6$ V 时 $I_C=13.70$ mA、$U_{CE}=8.82$ V，与 0.7 V 的差别在 1% 以内）。

- 提示
  入口判据：先画**直流通路**（$C_1$、$C_2$ 开路 ⇒ $R_L$ 不参与），再画**交流通路**（$C_1$、$C_2$ 短路 ⇒ $R_E\parallel R_L$）。第 (1) 问只在直流通路上做，是一条单回路 KVL。

  走法：直流通路里从 $U_{CC}$ 到地只有一条路——$R_B$ → 发射结 → $R_E$。写 KVL $U_{CC}=I_B R_B+U_{BE}+I_E R_E$，用 $I_E=(1+\beta)I_B$ 把未知量收成一个 $I_B$，解出来，再乘 $\beta$ 得 $I_C$、乘 $(1+\beta)$ 得 $I_E$，最后 $U_{CE}=U_{CC}-I_E R_E$。

  已收录旁注（不接管步骤）：[共集电极的静态分析](../课堂笔记/11-11-共射放大电路与耦合.md#共集电极的静态分析)与本题同一条 KVL；[图解法：直流负载线与交流负载线不是一条](../课堂笔记/11-11-共射放大电路与耦合.md#图解法-直流负载线与交流负载线不是一条)讲同一件事的图形版本——本题只求估算法数值，不画负载线。这两处只作背景。
- 完整解答
  **第一步：画直流通路。** $C_1$、$C_2$ 隔直，一律开路：$\dot U_s$ 一侧断开、$R_L$ 一侧也断开（$R_L$ 上没有直流电流）。剩下的直流通路只有一条：

  $$U_{CC}\ \to\ R_B\ \to\ \text{基极 B}\ \to\ \text{发射结}\ \to\ \text{发射极 E}\ \to\ R_E\ \to\ \text{地}$$

  注意这条路上**没有 $R_C$**：集电极直接接 $U_{CC}$ 母线。

  **第二步：写 KVL。** 沿上面这条唯一回路降压一圈：

  $$U_{CC}=I_B R_B+U_{BE}+I_E R_E$$

  **第三步：用 $I_E=(1+\beta)I_B$ 收成单个未知量。** 代入上式：

  $$U_{CC}=I_B\big[R_B+(1+\beta)R_E\big]+U_{BE}$$

  解得

  $$I_B=\frac{U_{CC}-U_{BE}}{R_B+(1+\beta)R_E}=\frac{20-0.7}{30+51\times0.8\ \text{k}\Omega}=\frac{19.3}{70.8\ \text{mA}}=0.273\ \text{mA}$$

  分母里的 $51\times0.8=40.8\ \text{k}\Omega$ 是 $R_E$ 折算到基极的结果：**发射极电阻被放大 $(1+\beta)$ 倍**，所以 $R_E$ 虽然只有 $0.8\ \text{k}\Omega$，在基极回路上却比 $R_B=30\ \text{k}\Omega$ 还大——这也是共集电路 $I_B$ 小、Q 点电流不大的原因。

  **第四步：算三个电流与 $U_{CE}$。**

  $$I_C=\beta I_B=50\times0.273\ \text{mA}=13.6\ \text{mA},\qquad I_E=(1+\beta)I_B=51\times0.273\ \text{mA}=13.9\ \text{mA}$$

  $$U_{CE}=U_{CC}-I_E R_E=20-13.9\times0.8\ \text{V}=20-11.12\ \text{V}=8.88\ \text{V}$$

  自洽核对：$U_B=U_{CC}-I_B R_B=20-0.273\times30=11.82$ V，$U_E=I_E R_E=11.12$ V，$U_B-U_E=0.70$ V ✓（正好回到取定的 $U_{BE}$）。放大区核对：$U_C=20$ V $>U_B=11.82$ V ⇒ 集电结反偏；$U_B>U_E$ ⇒ 发射结正偏——两结极性合放大区，$U_{CE}=8.88$ V 有足够余量 ✓。

  **Q 点**：

  $$Q:\quad I_C=13.6\ \text{mA},\qquad U_{CE}=8.88\ \text{V}$$

  （对应 $I_B=0.273$ mA、$I_E=13.9$ mA。）
- 复盘 :-
  - **卡点一**：$R_L$ 不能进直流通路。$C_2$ 把 $R_L$ 与发射极隔开，直流下 $R_L$ 上一个电流都没有；把 $R_L$ 串进来算（$R_E+R_L=2.0\ \text{k}\Omega$），$I_B$ 掉到 $0.146$ mA、$I_C=7.31$ mA，Q 点几乎减半。第 (1) 问的发射极负载就是 $R_E$ 单独。
  - **卡点二**：$I_C$ 与 $I_E$ 差一个 $I_B$。$I_C=\beta I_B=13.6$ mA、$I_E=(1+\beta)I_B=13.9$ mA，$U_{CE}$ 里减掉的是 $I_E R_E$（流过 $R_E$ 的是发射极电流），不是 $I_C R_E$。
  - **卡点三**：$R_E$ 进基极回路要乘 $(1+\beta)$。写成 $R_B+R_E$ 得 $I_B=0.627$ mA，Q 点整套错；折算项 $51\times0.8=40.8\ \text{k}\Omega$ 比 $R_B$ 还大，丢不得。
  - **卡点四**：这条回路里没有 $R_C$。共射的 $U_{CE}=U_{CC}-I_C R_C-I_E R_E$ 在这里少一项；硬套共射公式会凭空减掉一个不存在的压降。
:::

:::collapse accordion
- 提示
  入口判据：先画**交流通路**（$C_1$、$C_2$ 短路、$U_{CC}$ 接地），再把管子换成微变模型（B–E 间 $r_{be}$、C–E 间受控源 $\beta i_B$），最后**从基极端口看进去**求等效电阻。

  走法：$R_L'=R_E\parallel R_L$（两只都并在 E–地）；基极端口看到 $R_B$ 一条支路、以及「$r_{be}$ 串 $R_L'$」另一条支路，两者并联。串联那段的电压是 $u_i=i_b r_{be}+i_e R_L'$，用 $i_e=(1+\beta)i_b$ 提出 $i_b$，括号里就是 $(1+\beta)$ 折算。
- 完整解答
  **第一步：画交流通路。** $C_1$、$C_2$ 短路；$U_{CC}$ 是直流源，对交流接地 ⇒ 集电极接地。于是 $R_B$ 接在 B–地之间，$R_E$ 与 $R_L$ 都接在 E–地之间：

  $$R_L'=R_E\parallel R_L=\frac{0.8\times1.2}{0.8+1.2}\ \text{k}\Omega=0.48\ \text{k}\Omega$$

  **第二步：换微变模型。** B–E 之间是 $r_{be}=0.45\ \text{k}\Omega$，C–E 之间是受控电流源 $\beta i_B$（参考方向 C→E，本题集电极是交流地，故源从地流向 E）。

  **第三步：写输入端口电压。** 从基极看进去，两条支路并联：一条是 $R_B$，另一条是「B–E 的 $r_{be}$」串「E–地的 $R_L'$」。串联段上流过的是同一个 $i_b$（$r_{be}$ 段）与 $i_e$（$R_L'$ 段），电流不同所以**不能合并成一只电阻**：

  $$u_i=i_b r_{be}+i_e R_L'=i_b r_{be}+(1+\beta)i_b R_L'=i_b\big[r_{be}+(1+\beta)R_L'\big]$$

  括号里 $r_{be}+(1+\beta)R_L'=0.45+51\times0.48=0.45+24.48=24.93\ \text{k}\Omega$——这就是基极端口看到的另一条支路。

  **第四步：并联求 $r_i$。**

  $$r_i=R_B\parallel\big[r_{be}+(1+\beta)(R_E\parallel R_L)\big]=\frac{30\times24.93}{30+24.93}\ \text{k}\Omega=13.6\ \text{k}\Omega$$

  **结论**：$r_i\approx 13.6\ \text{k}\Omega$（口径：从基极看进去，不含 $R_S$）。

  自检：两手。一、量级——$r_i$ 被 $(1+\beta)$ 折算项撑到 $10\ \text{k}\Omega$ 以上，正是「射极输出器输入电阻大」这条结论；二、若把并联的另一条支路 $R_B$ 忘掉，会得 $24.93\ \text{k}\Omega$，与 $13.6\ \text{k}\Omega$ 差近一倍，所以 $R_B$ 不能丢。
- 复盘 :-
  - **卡点一**：交流下的发射极负载是 $R_E\parallel R_L=0.48\ \text{k}\Omega$，不是 $R_E$ 单独。用 $R_E=0.8$ 单独算得 $r_i=17.4\ \text{k}\Omega$，比正解大 28%——$C_2$ 在交流下是短路线，$R_L$ 直接并在 $R_E$ 上。
  - **卡点二**：串联段不能合成一只电阻。$r_{be}$ 上流 $i_b$、$R_L'$ 上流 $i_e=(1+\beta)i_b$，两段电流不同；写成 $r_{be}+R_L'=0.93\ \text{k}\Omega$ 就丢了整个 $(1+\beta)$ 折算，$r_i$ 会掉到 $0.9\ \text{k}\Omega$ 量级。
  - **卡点三**：$R_B$ 是并联不是串联。交流通路里 $R_B$ 一端接基极、一端接交流地（$U_{CC}$ 接地），所以与「$r_{be}$ 串 $R_L'$」并联。
  - **卡点四**：$R_S$ 不在 $r_i$ 里。算含 $R_S$ 的源内阻总阻值会另有其值；本题 $R_S$ 图上未标阻值，按通行口径 $r_i$ 只算到基极为止。
:::

:::collapse accordion
- 提示
  入口判据：$A_u=u_o/u_i$，两个量都从上一段的输入端口写起：$u_o$ 是 $R_L'$ 上的电压（流过的是 $i_e$），$u_i$ 是基极端口电压。两个式子一比，$i_b$ 约掉。

  走法：$u_o=i_e R_L'=(1+\beta)i_b R_L'$；$u_i=i_b[r_{be}+(1+\beta)R_L']$；相除得 $A_u=\dfrac{(1+\beta)R_L'}{r_{be}+(1+\beta)R_L'}$。分子分母同阶、分母多一项正的 $r_{be}$，所以 $0<A_u<1$；无负号 ⇒ 同相。
- 完整解答
  **第一步：输出侧。** $\dot U_o$ 取自 $R_L$ 上端对地，交流通路里 $R_E$ 与 $R_L$ 并联在 E–地，所以 $u_o$ 就是 $R_L'$ 上的电压，流过它的电流是 $i_e=(1+\beta)i_b$：

  $$u_o=i_e R_L'=(1+\beta)i_b R_L'$$

  **第二步：输入侧**（同上一段）：

  $$u_i=i_b r_{be}+i_e R_L'=i_b\big[r_{be}+(1+\beta)R_L'\big]$$

  **第三步：相除。**

  $$A_u=\frac{u_o}{u_i}=\frac{(1+\beta)(R_E\parallel R_L)}{r_{be}+(1+\beta)(R_E\parallel R_L)}=\frac{24.48}{24.93}=0.982$$

  等价写法（直接读出它离 1 有多远）：

  $$A_u=1-\frac{r_{be}}{r_{be}+(1+\beta)R_L'}=1-\frac{0.45}{24.93}=1-0.018$$

  **第四步：读结论。** 分母比分子只多 $r_{be}=0.45\ \text{k}\Omega$，相对 $24.93\ \text{k}\Omega$ 只有 1.8% ⇒

  - $0<A_u<1$，**恒小于 1**（不是「等于 1」：共集没有电压放大能力，只有电流放大）；
  - **同相**——式子里没有负号，$u_o$ 与 $u_i$ 同相增减；
  - 数值上 $A_u\approx 0.982$，即输出幅度约为输入的 98%。这就是「射极输出器＝电压跟随器」的来处。

  自检：一、极限核对——把 $r_{be}\to0$ 则 $A_u\to1$，把 $R_L'\to0$ 则 $A_u\to0$，两个方向都对；二、代数核对——分子 $24.48$、分母 $24.93$，$24.48/24.93=0.98195$，与 $1-0.45/24.93=1-0.01805$ 一致。
- 复盘 :-
  - **卡点一**：$A_u$ 不带负号。共射是 $-\beta R_L'/r_{be}$（反相），共集分子分母都是 $(1+\beta)R_L'$ 打头、没有负号，**同相**；把共射的负号搬过来会得出反相的错结论。
  - **卡点二**：分母那一项是 $r_{be}$ 不是 $R_B$。$R_B$ 在基极端口处与信号源并联，只影响 $r_i$、不进 $A_u$ 的分母；$A_u$ 的分母只由 B–E–E–地这条串联段决定。
  - **卡点三**：$R_L'$ 仍取 $R_E\parallel R_L=0.48\ \text{k}\Omega$。若错用 $R_E=0.8$ 单独，$A_u=0.989$——数值只差 0.7%，看着「差不多」，但这是口径错误；两种负载的差别在这一问恰好被 $\beta$ 放大得几乎看不出来，不能因为数对得上就认为用法对。
  - **卡点四**：$A_u<1$ 与「放大器」不矛盾。共集靠电流放大与阻抗变换吃饭（$r_i$ 大、$R_o$ 小），做缓冲级；衡量它的指标是 $r_i$、$R_o$，不是 $A_u$。
