:::collapse accordion
- 提示
  入口判据：本题落在[JK 特性方程 $J=K=1$ 逐沿翻转](../课堂笔记/10-28-触发器与时序逻辑电路.md)，两级是「前一的输出当后一的时钟」的级联，不是共时钟。

  先给两级各写一条状态方程：$J=K=1$ 代进 $Q_{n+1}=J\overline{Q_n}+\overline{K}Q_n$，化简到 $\overline{Q_n}$。再分清两级各自的触发沿清单——第一级看 $CP$ 的下降沿，第二级只看 $Q_1$ 的下降沿。初态 $Q_1=Q_2=0$，从原点起逐沿抄。

  频率另走一条机械路：每翻转两次才走完一个完整周期，所以一级输出是输入的一半，两级各减半一次。
- 完整解答
  两式是全部依据（[JK 特性方程](../课堂笔记/10-28-触发器与时序逻辑电路.md)）：

  $$Q_{n+1}=J\overline{Q_n}+\overline{K}Q_n$$

  两级都是 $J=1$、$K=1$（$\overline{K}=0$），代入得

  $$Q_{n+1}=1\cdot\overline{Q_n}+0\cdot Q_n=\overline{Q_n}$$

  即每到自己的有效沿翻一次。区别只在「有效沿由谁给」：

  | 级 | 有效沿来源 | 该沿处状态方程 |
  | :--- | :--- | :--- |
  | 第一级 $Q_1$ | $CP$ 下降沿（25%、40%、60%、80%） | $Q_{1,n+1}=\overline{Q_{1,n}}$ |
  | 第二级 $Q_2$ | $Q_1$ 下降沿 | $Q_{2,n+1}=\overline{Q_{2,n}}$ |

  先逐沿算 $Q_1$（初态 $Q_{1}=0$）：

  | $CP$ 下降沿 | 25% | 40% | 60% | 80% |
  | :--- | :-: | :-: | :-: | :-: |
  | 沿前 $Q_{1,n}$ | 0 | 1 | 0 | 1 |
  | $Q_{1,n+1}=\overline{Q_{1,n}}$ | 1 | 0 | 1 | 0 |

  $Q_1$ 电平线：0–25% 为 0，25%–40% 为 1，40%–60% 为 0，60%–80% 为 1，80%–100% 为 0。它的**下降沿**落在 40%、80%（25%、60% 是上升沿）。

  再从这条 $Q_1$ 线取有效沿算 $Q_2$（初态 $Q_2=0$）：

  | $Q_1$ 下降沿 | 40% | 80% |
  | :--- | :-: | :-: |
  | 沿前 $Q_{2,n}$ | 0 | 1 |
  | $Q_{2,n+1}=\overline{Q_{2,n}}$ | 1 | 0 |

  $Q_2$ 只在 40%、80% 各翻一次：0–40% 为 0，40%–80% 为 1，80%–100% 为 0。

  **两条波形结论**（区间按 0–100%）：

  - $Q_1$：0–25% 为 0，25%–40% 为 1，40%–60% 为 0，60%–80% 为 1，80%–100% 为 0。
  - $Q_2$：0–40% 为 0，40%–80% 为 1，80%–100% 为 0。

  频率按「每出现两个有效沿、输出才走完一个完整周期」逐级联算（[分频是它的副产品](../课堂笔记/11-02-时序分析与设计.md)）：
  每出现一次自己的有效沿、翻转触发器（$J=K=1$）就翻转一次输出，两个有效沿才回原态，完整周期是输入的 2 倍、频率是输入的 $1/2$。

  $$f_{Q_1}=\frac{f_{CP}}{2}=\frac{400}{2}=200\ \text{Hz},\qquad f_{Q_2}=\frac{f_{Q_1}}{2}=\frac{200}{2}=100\ \text{Hz}$$

  自检：把 $Q_1$ 的四个跳变时刻与 CP 四个下降沿一一对齐，$Q_2$ 的两个跳变时刻与 $Q_1$ 的两个下降沿（40%、80%）一一对齐；$f_{Q_2}=f_{CP}/4=100$ Hz 与「两级各二分频一次」自洽。
- 复盘 :-
  - **卡点一**：第二级的时钟是 $Q_1$，不是 $CP$。若把两级都挂在 $CP$ 下降沿上，$Q_2$ 会被算成与 $Q_1$ 同频同相（或只差一次翻转），四分频的结果出不来。
  - **卡点二**：第二级认的是 $Q_1$ 的**下降沿**（两级同为下降沿触发器）。$Q_1$ 在 25%、60% 是上升沿、在 40%、80% 才是下降沿；若把 $Q_1$ 的上升沿当有效沿，$Q_2$ 的跳变会错移到 25%、60%。
  - **卡点三**：频率不是「看到 4 个脉冲就除以 4」。先定第二级有效沿的个数（$Q_1$ 在本图里只给出 2 个下降沿），再用 $f_{Q_1}=f_{CP}/2$、$f_{Q_2}=f_{Q_1}/2$ 两级链路，避免把波形格数与周期数混为一谈。

:::collapse accordion
- 提示
  入口判据：本题落在[D 特性方程 $Q_{n+1}=D$](../课堂笔记/10-28-触发器与时序逻辑电路.md)与[JK 特性方程](../课堂笔记/10-28-触发器与时序逻辑电路.md)，两级都按 $CP$ **上升沿**取值。

  先把第二级的 $J=Q_1$、$K=\overline{Q_1}$ 代进 JK 特性方程化简一次，得到一条只含 $Q_1$ 的状态方程；再按五个上升沿逐个把题面 $D$ 表的值代进第一级，并把每个沿**前一刻**的 $Q_1$ 代进第二级。异步端 $\overline{S_D}=1$、$\overline{R_D}$ 在 $t=0$ 起为 1，全程不动作。
- 完整解答
  两式是全部依据（[D 特性方程](../课堂笔记/10-28-触发器与时序逻辑电路.md)、[JK 特性方程](../课堂笔记/10-28-触发器与时序逻辑电路.md)）：

  $$Q_{1,n+1}=D,\qquad Q_{2,n+1}=J\overline{Q_{2,n}}+\overline{K}Q_{2,n}$$

  第二级 $J=Q_1$、$K=\overline{Q_1}$，故 $\overline{K}=Q_1$，代入：

  $$Q_{2,n+1}=Q_1\overline{Q_{2,n}}+Q_1 Q_{2,n}=Q_1\left(\overline{Q_{2,n}}+Q_{2,n}\right)=Q_1$$

  用到 $\overline{Q_{2,n}}+Q_{2,n}=1$。于是第二级等价于 $D$ 接 $Q_1$ 的 D 触发器，两级都在 $CP$ 上升沿取值。注意两个触发器在同一沿同时更新：**第二级读的是沿前一刻的 $Q_1$**，所以 $Q_2$ 比 $Q_1$ 滞后一个 $CP$ 周期。

  逐沿（初态 $Q_1=Q_2=0$），$D$ 取自题面表：

  | CP 上升沿 | $\uparrow_1$ | $\uparrow_2$ | $\uparrow_3$ | $\uparrow_4$ | $\uparrow_5$ |
  | :--- | :-: | :-: | :-: | :-: | :-: |
  | 该沿处 $D$ | 1 | 0 | 0 | 0 | 1 |
  | 沿前 $Q_1$ | 0 | 1 | 0 | 0 | 0 |
  | $Q_{1,n+1}=D$ | 1 | 0 | 0 | 0 | 1 |
  | 沿前 $Q_2$ | 0 | 0 | 1 | 0 | 0 |
