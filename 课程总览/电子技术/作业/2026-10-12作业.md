## 一、六个门的逻辑表达式（先立式，再画波形）

| 门 | 结构 | 表达式 | 化简结果 |
| :-: | :--- | :--- | :--- |
| (b) | 与门（输入 A 与常数 1），输出取反 | $Y_b=\overline{A\cdot 1}$ | $Y_b=\overline{A}$ |
| (c) | 与门（输入 C 与常数 0），输出取反 | $Y_c=\overline{C\cdot 0}$ | $Y_c=1$ |
| (d) | 三输入与门（A、B、C），输出取反 | $Y_d=\overline{ABC}$ | $Y_d=\overline{ABC}$ |
| (e) | 或门（B、D），输出取反 | $Y_e=\overline{B+D}$ | $Y_e=\overline{B+D}$ |
| (f) | 异或门（A、D），输出取反 | $Y_f=\overline{A\oplus D}$ | $Y_f=A\odot D$（同或） |
| (g) | 与或非门：上 $(A\cdot B)$、下 $(C\cdot D)$ 各进一个与门，再进或门取反 | $Y_g=\overline{AB+CD}$ | $Y_g=\overline{AB+CD}$ |

> **两个「接常数」的门先看穿**：$A\cdot 1=A$（常数 1 让与门「透明」，再取反就是**把 A 反相**）；
> $C\cdot 0=0$（常数 0 把与门钉死为 0），取反后**恒为 1**——C 的波形再怎么样都不影响 (c) 的输出。

## 三、逐门解析

### (b) 与门（A、1）取反

:::collapse accordion
- 提示
  与门一个输入接常数 1，先化简再想取反泡
  ① $A\cdot 1=A$，所以这就是**把 A 取反**；② 输出端的小圆圈再做一次取反，合起来就是 $\overline{A}$。
- 完整解答
  表达式：$Y_b=\overline{A\cdot 1}=\overline{A}$。
  波形：**A 的反相**——A 为高时 $Y_b$ 低、A 为低时 $Y_b$ 高；A 有 10 个脉冲，$Y_b$ 就有 10 个互补脉冲。

:::figure wave-7-04-b | 波形：A、Y(b)
- 复盘
  **接常数 1 的与门是「透明门」**：$A\cdot 1=A$，它不改变信号，输出端有没有取反泡才决定波形是 A 还是 $\overline{A}$。
  这类门考的就是「常数 + 取反泡」两层都别漏。
:::

### (c) 与门（C、0）取反

:::collapse accordion
- 提示
  与门一个输入接常数 0，先把乘积算出来
  ① 任何数与 0 相与都是 0；② 输出端取反泡把 0 变成 1——于是输出与 C 无关。
- 完整解答
  表达式：$Y_c=\overline{C\cdot 0}=\overline{0}=1$。
  波形：**恒为高电平的一条直线**（全时段为 1），C 的波形完全不影响输出。

:::figure wave-7-04-c | 波形：C、Y(c)
- 复盘
  **接常数 0 的与门是「死门」**：输出恒 0，再加取反泡就是恒 1。
  与 (b) 对照——同样是「与门 + 取反泡」，一个接 1 得到 $\overline{A}$、一个接 0 得到恒 1，常数是谁直接决定结果。
:::

### (d) 三输入与门（A、B、C）取反

:::collapse accordion
- 提示
  三个输入同时为 1 时输出才被拉低
  $Y_d=\overline{ABC}$：只有 A、B、C **同时为 1** 时 $ABC=1$、$Y_d=0$；其余时刻 $Y_d=1$。
- 完整解答
  表达式：$Y_d=\overline{ABC}$。
  波形：**大部分时间为高**，只在 A、B、C 三者**重叠为高**的少数时段出现**低电平**。
  本题里 C 只有 2 个宽脉冲，$ABC=1$ 只可能落在 C 的两个脉冲内、且 A、B 同时为高处——所以 $Y_d$ 的低电平是**两段短凹口**。

:::figure wave-7-04-d | 波形：A、B、C、Y(d)
- 复盘
  三输入与门取反 = **与非门**。「三者同时为 1」在波形上就是**三条高电平的重叠区**——先把 C 的两个宽脉冲找出来，
  再在其中挑出 A、B 也同时为高的段，凹口就定位了。
:::

### (e) 或门（B、D）取反

:::collapse accordion
- 提示
  或门取反 = 或非：两个输入都为 0 时才输出 1
  $Y_e=\overline{B+D}$：只要 B 或 D 有一个为 1，输出就是 0；**只有 B、D 同时为 0** 时才为 1。
- 完整解答
  表达式：$Y_e=\overline{B+D}$。
  波形：**大部分时间为低**（B 的 5 个脉冲、D 的 1 个宽脉冲都把它压低），只在 **B 与 D 同时为低**的几段出现高电平。

:::figure wave-7-04-e | 波形：B、D、Y(e)
- 复盘
  或非门的输出高电平 = **两条输入都低的交集**。D 的宽脉冲横跨中部，把 (e) 的中段整段压低；只在 D 之外、B 也为低处才有高电平。
:::

### (f) 异或门（A、D）取反

:::collapse accordion
- 提示
  异或门（`=1`）再带取反泡 = 同或：两输入**相同**时输出 1
  $Y_f=\overline{A\oplus D}=A\odot D$：A 与 D **相同**（同为 0 或同为 1）时 $Y_f=1$，不同时为 0。
- 完整解答
  表达式：$Y_f=\overline{A\oplus D}=A\odot D$。
  波形：**A 与 D 的电平相同处为高**。D 为低的前段，$Y_f$ 跟随 $\overline{A}$（与 A 相反）；D 为高的中段，$Y_f$ 跟随 $A$（与 A 相同）。

:::figure wave-7-04-f | 波形：A、D、Y(f)
- 复盘
  「异或门符号 `=1` + 输出取反泡」是本题最容易看错的一处：**`=1` 本身是异或，加泡才是同或**。
  记法：异或「不同为 1」，同或「相同为 1」——波形上就是「A、D 相同则高」。
:::

### (g) 与或非门

:::collapse accordion
- 提示
  两个与门先各算一项，或门相加，最后取反
  ① 上支路 $A\cdot B$、下支路 $C\cdot D$；② 或门把两项相加 $AB+CD$；③ 输出取反得 $\overline{AB+CD}$。
- 完整解答
  表达式：$Y_g=\overline{AB+CD}$。
  波形：**只要 $AB=1$ 或 $CD=1$ 就输出低**，两项都为 0 时输出高。
  - $AB=1$：A、B 同时为高（A 的窄脉冲落在 B 的宽脉冲内时）；
  - $CD=1$：C、D 同时为高（C 的宽脉冲与 D 的宽脉冲重叠的那一段）。
  两处都会把 $Y_g$ 拉低。

:::figure wave-7-04-g | 波形：A、B、C、D、Y(g)
- 复盘
  与或非（AOI）门是**复合门**：读图时先把它拆成「两个与门 + 一个或门 + 一个取反」四块，
  分别写出中间量再合并，就不会把结构看错。它与 (d) 的区别是：(d) 是「三个输入全与」，(g) 是「两项之或」。
:::

## 小结：这份作业要带走的东西

1. **常数输入先化简**：与门接 1 → 透明（等于另一个输入）；接 0 → 死门（恒 0）。取反泡再翻一次。
2. **取反泡只在输出端**：读门时先看门体符号（`&`/`≥1`/`=1`），再看输出端有没有小圆圈——有泡就把整个结果取反。
3. **或非 / 与非 / 同或**：分别是「或门 + 泡」「与门 + 泡」「异或门（`=1`）+ 泡」；`=1` 加泡 = 同或，别看成异或。
4. **画波形三步**：写表达式 → 化简 → 逐段代入。多输入门就找「高电平重叠区」。
5. **复合门拆开读**：像 (g) 这种与或非门，拆成「与门 → 或门 → 取反」再逐块写式子。
