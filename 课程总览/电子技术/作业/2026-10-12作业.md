# 2026-10-12作业

## 1. 依赖

**题型**：画波形——已知输入 A、B、C、D 的波形，画出 (b)~(g) 六个门电路的**输出波形**。六个门的输出波形是答案，在解答层给出。

| 做之前先过掉（点击直达） | 到那里你该已经会了 |
| :--- | :--- |
| [基本逻辑门与复合逻辑门的符号](../课堂笔记/10-10-逻辑代数与公式法化简.md#课件补充) | **读门三步**：门体符号（`&`/AND 与、`≥1` 或、`=1` 异或、`1` 非）；输入端接信号还是常数；**输出端小圆圈＝对该门输出取反**。含与非/或非/与或非/异或/同或的表达式与口诀 |
| [基本定律（五组）与常用公式](../课堂笔记/10-10-逻辑代数与公式法化简.md#基本定律-五组-与常用公式) | 与、或、非的运算规则；$A\cdot1=A$、$A\cdot0=0$（**门的一端接常数**时用这两条看穿） |

> **怎么用这份作业**：先自己按输入波形把六个门的输出画出来，再逐题展开「提示 → 完整解答 → 复盘」对照。
> **本类题的三步套路**：① **写表达式**——把每个门（含输入端的常数 0/1、输出端的取反泡）写成逻辑式；
> ② **化简**——接常数的门往往直接退化（如 $A\cdot 1=A$、$C\cdot 0=0$）；③ **照表达式画波形**——逐段把输入的高低电平代进去。

## 2. 题面

> **7.4** 已知输入信号 A、B、C、D 的波形如图 7.01(a) 所示。试画出图 7.01（b）、（c）、（d）、（e）、（f）、（g）各图所示门电路的输出波形。

**图 7.01(a)　输入波形**（横轴为时间 $t$，高电平为逻辑 1；A 有 10 个窄脉冲、B 有 5 个、C 有 2 个、D 有 1 个）：

![波形：A、B、C、D](figures/wave-7-04-in.svg)

### (c) 与门（C、0）取反

:::collapse accordion
- 提示
  与门一个输入接常数 0，先把乘积算出来
  ① 任何数与 0 相与都是 0；② 输出端取反泡把 0 变成 1——于是输出与 C 无关。
- 完整解答
  表达式：$Y_c=\overline{C\cdot 0}=\overline{0}=1$。
  波形：**恒为高电平的一条直线**（全时段为 1），C 的波形完全不影响输出。

![波形：C、Y(c)](figures/wave-7-04-c.svg)

### (d) 三输入与门（A、B、C）取反

:::collapse accordion
- 提示
  三个输入同时为 1 时输出才被拉低
  $Y_d=\overline{ABC}$：只有 A、B、C **同时为 1** 时 $ABC=1$、$Y_d=0$；其余时刻 $Y_d=1$。
- 完整解答
  表达式：$Y_d=\overline{ABC}$。
  波形：**大部分时间为高**，只在 A、B、C 三者**重叠为高**的少数时段出现**低电平**。
  本题里 C 只有 2 个宽脉冲，$ABC=1$ 只可能落在 C 的两个脉冲内、且 A、B 同时为高处——所以 $Y_d$ 的低电平是**两段短凹口**。

![波形：A、B、C、Y(d)](figures/wave-7-04-d.svg)

### (e) 或门（B、D）取反

:::collapse accordion
- 提示
  或门取反 = 或非：两个输入都为 0 时才输出 1
  $Y_e=\overline{B+D}$：只要 B 或 D 有一个为 1，输出就是 0；**只有 B、D 同时为 0** 时才为 1。
- 完整解答
  表达式：$Y_e=\overline{B+D}$。
  波形：**大部分时间为低**（B 的 5 个脉冲、D 的 1 个宽脉冲都把它压低），只在 **B 与 D 同时为低**的几段出现高电平。

![波形：B、D、Y(e)](figures/wave-7-04-e.svg)

### (f) 异或门（A、D）取反

:::collapse accordion
- 提示
  异或门（`=1`）再带取反泡 = 同或：两输入**相同**时输出 1
  $Y_f=\overline{A\oplus D}=A\odot D$：A 与 D **相同**（同为 0 或同为 1）时 $Y_f=1$，不同时为 0。
- 完整解答
  表达式：$Y_f=\overline{A\oplus D}=A\odot D$。
  波形：**A 与 D 的电平相同处为高**。D 为低的前段，$Y_f$ 跟随 $\overline{A}$（与 A 相反）；D 为高的中段，$Y_f$ 跟随 $A$（与 A 相同）。

![波形：A、D、Y(f)](figures/wave-7-04-f.svg)

### (g) 与或非门

:::collapse accordion
- 提示
  两个与门先各算一项，或门相加，最后取反
  ① 上支路 $A\cdot B$、下支路 $C\cdot D$；② 或门把两项相加 $AB+CD$；③ 输出取反得 $\overline{AB+CD}$。
- 完整解答
  表达式：$Y_g=\overline{AB+CD}$。
  波形：**只要 $AB=1$ 或 $CD=1$ 就输出低**，两项都为 0 时输出高。
  - $AB=1$：A、B 同时为高（A 的窄脉冲落在 B 的宽脉冲内时）；
  - $CD=1$：C、D 同时为高（C 的宽脉冲与 D 的宽脉冲重叠的那一段）。
  两处都会把 $Y_g$ 拉低。

![波形：A、B、C、D、Y(g)](figures/wave-7-04-g.svg)

## 小结：这份作业要带走的东西

1. **常数输入先化简**：与门接 1 → 透明（等于另一个输入）；接 0 → 死门（恒 0）。取反泡再翻一次。
2. **取反泡只在输出端**：读门时先看门体符号（`&`/`≥1`/`=1`），再看输出端有没有小圆圈——有泡就把整个结果取反。
3. **或非 / 与非 / 同或**：分别是「或门 + 泡」「与门 + 泡」「异或门（`=1`）+ 泡」；`=1` 加泡 = 同或，别看成异或。
4. **画波形三步**：写表达式 → 化简 → 逐段代入。多输入门就找「高电平重叠区」。
5. **复合门拆开读**：像 (g) 这种与或非门，拆成「与门 → 或门 → 取反」再逐块写式子。
