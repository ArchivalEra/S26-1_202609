# 2026-11-18作业

## 1. 依赖

本题四个提问（直/交、正/负、串/并、电/流）都是**照做就能出结论**的动作，不需要算数。先把四个动作列全，再往电路上套。

| 判据 | 机械步骤（照做） | 一句话依据 |
| :--- | :--- | :--- |
| **正反馈／负反馈** | ① 认准 $R_F$ 回接的是哪个输入端，把这个端记为 F 点；② 在 F 点注入 $+\delta$（假设它瞬时升高）；③ 沿前向通路推到 $u_o$，逐级记「反相／不反相」：运放从 `+` 端看进去**同相**、从 `−` 端看进去**反相**；④ **反相次数为奇** ⇒ $u_o$ 与 $\delta$ 反向 ⇒ 环路自我抵偿 ⇒ 负反馈；**反相次数为偶** ⇒ 同向 ⇒ 正反馈 | 净输入被削弱为负反馈、被增强为正反馈；操作口径是「反馈信号引回到**与输入信号同极性作用**的那个输入端则为负反馈」——两级级联时这句要数满两级才成立，见下方第 2 条先定事项 |
| **直流反馈／交流反馈** | ① 沿 $R_F$ 支路从 $u_o$ 一路走到 F 点；② 数这条路上**有没有电容**；③ 有电容 ⇒ 直流量被挡住，直流分析里该支路**开路**，只有交流量能过 ⇒ 交流反馈（纯交流）；④ 全程只有电阻 ⇒ 直流量、交流量都过 ⇒ 交直流反馈 | 电容「隔直通交」：串在反馈支路里就只让交流反馈回去 |
| **串联反馈／并联反馈** | ① 找 $R_F$ 在输入端的**落点** X；② 找信号源 $u_i$ 驱动 $A_1$ 的**落点** Y；③ X 与 Y 是**同一节点** ⇒ 两路电流在该节点求和，净输入是**电流差** ⇒ 并联反馈；④ X ≠ Y ⇒ 两路电压沿同一条输入回路串接，净输入是**电压差** ⇒ 串联反馈 | 串联以电压形式相减、输入电阻增大；并联以电流形式相减、输入电阻减小（这两条可拿来做复核） |
| **电压反馈／电流反馈** | ① 看 $R_F$ 的取样端接在哪个节点；② 直接接 $u_o$ 节点（与负载**并联**取样）⇒ 令 $u_o$ 对地短路，反馈量随之归零 ⇒ 电压反馈；③ 接在串入负载的电阻上（与负载**串联**取样）⇒ 只有让负载开路，反馈量才归零 ⇒ 电流反馈 | 取样什么就稳定什么：取电压稳定输出电压（输出电阻减小），取电流稳定输出电流 |

判之前先定三件事，三件都影响结论：

1. **判的是哪条支路。** 本页四组结论都针对那条**跨级**的 $R_F$（从 $u_o$ 引回 $A_1$）。每个运放自己的 $R_{F1}$、$R_{F2}$ 是**级内**负反馈，纯电阻、直流也通，不参与组态命名——否则三幅图都会被写成「有直流负反馈」，(a)(b)(c) 就拉不开了。
2. **极性要沿环路数，不能按端子名猜。** 「输入在 `−` 端、反馈回 `+` 端就是正反馈」只是**一级**电路的速记；本题是两级级联，$u_o$ 要经过 $A_1$、$A_2$ 两次才回到 F 点。按上表第④步数反相次数，才不会翻结论。
3. **阻值不影响结论。** 四个判据只问「接在哪个节点、路上有没有电容、取样自哪里」；电阻大小只改增益，不改组态。题面也没给阻值，本页一个数都不用。

> **怎么用**：三幅电路各一层「提示 → 完整解答 → 复盘」，**默认收起**——先动笔判，卡住再逐层展开。

## 2. 习题 3.1

**题面**（逐字）：

> 3.1 判断如图 3.01 所示的各电路哪些是直流反馈，哪些是交流反馈，哪些是正反馈，哪些是负反馈，哪些是串联反馈，哪些是并联反馈，哪些是电压反馈，哪些是电流反馈。

**图 3.01 三幅接线转写**（三幅都是两个运放两级级联：左 $A_1$、右 $A_2$，三角形内标 $\infty$）：

| 元件／端子 | (a) | (b) | (c) |
| :--- | :--- | :--- | :--- |
| $A_1$ 上端／下端 | `−` ／ `+` | `−` ／ `+` | **`+` ／ `−`** |
| $u_i$ 落点 | 经电阻到 `−` 端；**又经另一电阻到 `+` 端**，该 `+` 端另有电阻接地 | 经电阻到 `−` 端（`+` 端经电阻接地） | 经电阻到 `−` 端（`+` 端经电阻接地） |
| $R_{F1}$ | $A_1$ 输出 → $A_1$ 的 `−` 端 | 同 (a) | 同 (a)（回线画在图下方） |
| $A_2$ 上端／下端 | `−` ／ `+` | `−` ／ `+` | **`+` ／ `−`** |
| 级间耦合 | $A_1$ 输出经电阻 → $A_2$ 的 `−` 端 | 同 (a) | 同 (a) |
| $A_2$ 的 `+` 端 | 经电阻接地 | **直接接地** | 经电阻接地 |
| $R_{F2}$ | $u_o$ → $A_2$ 的 `−` 端 | 同 (a) | 同 (a) |
| $R_F$ 支路 | $u_o$ → $A_1$ 的 `+` 端（图下方长回线） | $u_o$ → **$C_F$ → $R_F$** → $A_1$ 的 `+` 端（图下方） | $u_o$ → $A_1$ 的 `+` 端（图**上方**最长回线） |
| 电容 | 无 | **仅 $C_F$ 一只**，串在 $R_F$ 支路里（$C_F$ 在右、$R_F$ 在左） | 无 |

**三幅共有的骨架**（先用一句话认出来）：都是「$A_1$ 一级 + $A_2$ 一级」的两级电压放大，$R_F$ 从 $u_o$ **跨越两级**回到 $A_1$。所以四组结论的差别只可能来自三处——$C_F$ 有没有、$u_i$ 落在哪个节点、两只运放的 `+`/`−` 怎么排。逐个找出这三处，八个小问就能一次答完。

:::collapse accordion
- 提示
  入口判据：先分「这条支路上有没有电容」，再分「$u_i$ 与 $R_F$ 是不是落在同一个节点」，最后用注入 $+\delta$ 数反相次数定极性，末了用短路法定取样。四步与每一步的推理都在下面「完整解答」里，逐步做完即可。

  走法：(a) 沿 $R_F$ 走一遍，确认全程只有电阻；再看 $u_i$ 的一条电阻也接在 $A_1$ 的 `+` 节点上（与 $R_F$ 同节点）；然后设 $A_1$ 的 `+` 端升一点，推 $u_{o1}$ 与 $u_o$ 各自朝哪边动；最后把 $u_o$ 短路，看反馈是否消失。

  已收录旁注（不接管步骤）：[正反馈与负反馈](../课堂笔记/11-18-差分与功率放大电路.md#正反馈与负反馈)给的是「净输入被增强／削弱」这条总判据；[反馈的分类](../课堂笔记/11-18-差分与功率放大电路.md#反馈的分类)给的是四组分类的对照表，含串/并对输入电阻的影响——本页把它们翻成了上表那几步动作。这两处只作背景。
- 完整解答
  **接线要点。** $A_1$ 是 `−` 在上、`+` 在下的运放，$u_i$ 经两只电阻分别进 `−` 与 `+`（`+` 那一路另有电阻接地）；$A_1$ 输出经电阻进 $A_2$ 的 `−` 端，$A_2$ 的 `+` 端经电阻接地；$R_{F1}$、$R_{F2}$ 各自回接本运放的 `−` 端；跨级的 $R_F$ 从 $u_o$ 回到 $A_1$ 的 `+` 端。全图无电容。

  **第一步：直/交——数 $R_F$ 支路上的电容。** 从 $u_o$ 走到 $A_1$ 的 `+` 端，这条路上只有电阻 $R_F$，**没有电容**。直流量与交流量都能原样反馈回去 ⇒ **交直流反馈**。判据依据：电容隔直通交，支路里没串电容就没有断开直流的环节；把图按直流通路看，$u_o$ 的直流分量仍经 $R_F$ 与接地电阻分压加到 $A_1$ 的 `+` 端，静态工作点被这条回线拉在一起。

  **第二步：正/负——注入 $+\delta$ 数反相次数。** 反馈落点是 $A_1$ 的 `+` 端（记 F 点）。设该点电位瞬时升高 $\delta>0$：

  1. F 点升 ⇒ $A_1$ 净输入 $u_+-u_-$ 升 ⇒ 从 `+` 端看进去 $A_1$ **同相** ⇒ $u_{o1}$ 升（反相次数 0）；
  2. $u_{o1}$ 升 ⇒ 经电阻进 $A_2$ 的 `−` 端 ⇒ $A_2$ 净输入 $u_+-u_-=0-u_-$ 降 ⇒ 从 `−` 端看进去 $A_2$ **反相** ⇒ $u_o$ 降（反相次数 1）；
  3. $u_o$ 降 ⇒ 经 $R_F$ 回送，把 F 点往下拉，与最初注入的 $+\delta$ **方向相反**。

  反相次数为 **1（奇）**，反馈信号回到的是「与净输入反极性作用」的输入端 ⇒ **负反馈**。等价说法：$\delta$ 注入后 $u_o$ 与 $\delta$ 反向，$1+AF>0$，环路自我抵偿。

  **第三步：串/并——看 $R_F$ 与 $u_i$ 的落点是否同一节点。** $R_F$ 落在 $A_1$ 的 `+` 节点上；$u_i$ 也有一条电阻直接接到**同一个** `+` 节点（该节点另有电阻接地）。反馈量与输入量在同一节点上以**电流**形式求和，净输入是电流差 ⇒ **并联反馈**。判据依据：同节点比较的是节点电流，故为并联；复核口径可用「并联使输入电阻减小」——$R_F$ 相当于从 $u_o$ 侧向该节点灌电流，看进去的电阻确实被拉低。

  **第四步：电/流——把 $u_o$ 短路看反馈是否消失。** $R_F$ 的取样端直接接在 $u_o$ 节点上，与负载**并联**取样。令 $u_o$ 对地短路（$u_o=0$），$R_F$ 下端的取样电压归零，反馈量随之归零 ⇒ 反馈消失 ⇒ **电压反馈**。若为电流反馈，短路后反馈应当仍在（反馈量取自串在负载支路上的电流），而这里恰好消失了，说明取的是电压。

  **结论（(a) 逐条对八问）：**

  | 问 | 结论 | 依据 |
  | :--- | :--- | :--- |
  | 直流反馈 | 是（与交流并存） | $R_F$ 支路纯电阻，直流分量照过 |
  | 交流反馈 | 是 | 支路无电容，交流量照过 |
  | 正反馈 | 不是 | 注入 $\delta$ 后 $u_o$ 反向 |
  | 负反馈 | **是** | 环路反相次数 1（奇），净输入被削弱 |
  | 串联反馈 | 不是 | $u_i$ 与 $R_F$ 落在同一节点 |
  | 并联反馈 | **是** | 同一 `+` 节点上电流求和 |
  | 电压反馈 | **是** | 取样自 $u_o$，短路则反馈消失 |
  | 电流反馈 | 不是 | 无串入负载的取样电阻 |

  自检：三处互不依赖的复核。一、换方向数极性：设 $u_o$ 自己升一点，经 $R_F$ 抬 F 点 ⇒ $u_{o1}$ 升 ⇒ $A_2$ 反相 ⇒ $u_o$ 降——扰动被压回，说明环路是负的，与「注入 $\delta$ 看 $u_o$ 反向」同一结论。二、短路法复算取样。三、串/并复算：把那条输入电阻从 `+` 节点拆掉，节点就只剩 $R_F$ 与接地电阻——这正是 (c) 的接法，结论也从并联变串联。
- 复盘 :-
  - **卡点一**：极性不能按端子名直接套。看到「反馈回到 `+` 端」就写正反馈，(a) 会判错；(a) 的 `+` 端是**第一级**的输入端，而 $u_o$ 到 F 点之间还隔着 $A_2$ 自己的一次反相。反相次数数满两级，才谈得上正负。
  - **卡点二**：$u_i$ 在 (a) 里进了两个端，这件事只影响串/并，不影响极性、也不影响取样。它把输入的一条电阻同时也落在了 $A_1$ 的 `+` 节点上，于是输入与反馈同节点 ⇒ 并联。若只看「输入是反相输入在 `−` 端」就写串联，这一项会错。
  - **卡点三**：级内 $R_{F1}$、$R_{F2}$ 不算组态。它们各自也是负反馈、也通直流，但那是每一级自己的局部反馈；跨级的那条 $R_F$ 才是本题问的「反馈」。两处混起来，(a) 的结论其实不变，但 (b) 会从「交流」被写成「交直流」。

- 提示
  入口判据：先找那只电容落在哪条支路上。全图只有一只 $C_F$，恰好串在 $R_F$ 支路里——这一只电容就把「直/交」这一问定死了。其余三问照 (a) 的四步走，唯一要重新确认的是 $u_i$ 的落点换了位置。

  走法：沿 $R_F$ 支路从 $u_o$ 走到 $A_1$ 的 `+` 端，路上要穿过 $C_F$ ⇒ 直流断、交流通；再注入 $+\delta$ 数反相次数（与 (a) 同一条前向通路）；再看 $u_i$ 落在 `−` 端、$R_F$ 落在 `+` 端，两点不同；最后短路 $u_o$。

  已收录旁注（不接管步骤）：[反馈的分类](../课堂笔记/11-18-差分与功率放大电路.md#反馈的分类)把「按信号形式」与「按比较方式」分成两张表，本题 (b) 正是「只传交流 + 串联比较」这一格；[直流负反馈稳定 Q 点，交流负反馈修波形](../课堂笔记/11-18-差分与功率放大电路.md#直流负反馈稳定-q-点-交流负反馈修波形)交代了直、交流反馈各自稳定什么。这两处只作背景。
- 完整解答
  **接线要点。** 与 (a) 相比，$A_1$ 的 `−`/`+` 位置相同（上 `−` 下 `+`）、$A_2$ 相同（上 `−` 下 `+`）、$R_{F1}$、$R_{F2}$ 相同；差别有两处：$u_i$ 只经一只电阻进 `−` 端；跨级回线改成了 $u_o$ → $C_F$ → $R_F$ → $A_1$ 的 `+` 端，**$C_F$ 与 $R_F$ 串联**，全图只有这一只电容。另外 $A_2$ 的 `+` 端是**直接接地**（不串电阻）——该端没有输入电流，串不串电阻都不影响结论。

  **第一步：直/交——电容就串在这条支路上。** 从 $u_o$ 走到 $A_1$ 的 `+` 端，必须穿过 $C_F$。直流量被 $C_F$ 挡住，作直流分析时把 $C_F$ 开路，这条支路等于不存在；交流量容抗可忽略，等效为一条纯电阻支路。⇒ $R_F$ 支路引入的是**纯交流反馈**。判据依据：电容隔直通交，串在反馈支路里就只把交流量送回去。直流下 $A_1$ 的 `+` 端只剩接地电阻（电位 0），静态工作点由级内 $R_{F1}$ 自己稳住。

  **第二步：正/负——交流下数反相次数。** 交流通路上 $C_F$ 短路，$R_F$ 直接接 $u_o$，与 (a) 的前向通路完全一致。注入 $\delta>0$ 到 $A_1$ 的 `+` 端：$A_1$ 同相 ⇒ $u_{o1}$ 升（0 次反相）；$u_{o1}$ 经电阻进 $A_2$ 的 `−` 端 ⇒ $A_2$ 反相 ⇒ $u_o$ 降（1 次反相）。反相次数 1（奇）⇒ **交流负反馈**。

  **第三步：串/并——$u_i$ 与 $R_F$ 落在不同节点。** $R_F$ 的落点是 $A_1$ 的 `+` 端；$u_i$ 经电阻落在 $A_1$ 的 `−` 端，`+` 端没有输入支路。反馈电压与输入电压沿输入回路前后串接、以**电压**形式相减 ⇒ **串联反馈**。判据依据：两点不同节点，比较的是 $u_+-u_-$ 这个电压差；复核口径「串联使输入电阻增大」也成立。

  **第四步：电/流——短路法。** $R_F$ 取样端接 $u_o$ 节点（与负载并联）。令 $u_o=0$，$C_F$–$R_F$ 支路两端电位不再随输出变化，反馈量归零 ⇒ **电压反馈**。

  **结论（(b) 逐条对八问）：**

  | 问 | 结论 | 依据 |
  | :--- | :--- | :--- |
  | 直流反馈 | **不是**（$R_F$ 支路） | $C_F$ 隔直，直流量过不去 |
  | 交流反馈 | **是** | $C_F$ 交流短路，交流量照过 |
  | 正反馈 | 不是 | 交流下注入 $\delta$ 后 $u_o$ 反向 |
  | 负反馈 | **是（交流负反馈）** | 环路反相次数 1（奇） |
  | 串联反馈 | **是** | $u_i$ 在 `−` 端、$R_F$ 在 `+` 端，不同节点 |
  | 并联反馈 | 不是 | 输入与反馈不共节点 |
  | 电压反馈 | **是** | 取样自 $u_o$，短路则反馈消失 |
  | 电流反馈 | 不是 | 无串入负载的取样电阻 |

  自检：一、把 $C_F$ 短路，本图的反馈拓扑与 (c) **逐项对得上**——反馈都落在 $A_1$ 的同相端、输入都进反相端、级间都进 $A_2$ 的 `−` 端；两图只差 $A_1$ 的 `+`/`−` 上下位置对调与 $A_2$ 的 `+` 端是否串电阻，都不进判据。所以四项结论与 (c) 应当一致，实际也一致（负、串联、电压），只多一个「只对交流」的限定。二、直流下再走一遍：$C_F$ 开路，$A_1$ 的 `+` 端电位为 0，剩下的两条反馈是级内 $R_{F1}$、$R_{F2}$，都不属于本题问的跨级反馈。三、短路法复算取样。
- 复盘 :-
  - **卡点一**：电容只决定「交/直」，不决定极性、不决定串并。把「串了电容所以是交流正反馈」当一条推下去，四项里会错三项。
  - **卡点二**：直流反馈并没有在全图消失，只是不在 $R_F$ 这条路上——它藏在 $R_{F1}$、$R_{F2}$ 里。题目问的是哪条支路引回的反馈，本页统一按跨级 $R_F$ 判；把级内支路也算进来，(b) 就成了「交直流」，与 (a)(c) 拉不开。
  - **卡点三**：(b) 的 $A_2$ `+` 端直接接地，看着与 (a)(c)「经电阻接地」不同，但该端没有别的支路，没有电流流过，串不串电阻对四组结论都没有影响——别把它当成第四个变量。
:::

:::collapse accordion
- 提示
  入口判据：先比端子排列。(c) 两只运放都是**上 `+` 下 `−`**，与 (a)(b) 恰好上下对调——但接线表里写着 $A_1$ 的输出**仍然进 $A_2$ 的 `−` 端**。这一句决定极性，先盯住它，再注入 $+\delta$。

  走法：$R_F$ 支路纯电阻 ⇒ 交直流；设 $A_1$ 的 `+` 端升一点，$A_1$ 从 `+` 看同相、$A_2$ 从 `−` 看反相，数出一次反相 ⇒ 负；$u_i$ 在 `−`、$R_F$ 在 `+`，且 `+` 端没有输入支路 ⇒ 串联；短路 $u_o$ ⇒ 电压。

  已收录旁注（不接管步骤）：[反馈的定义与框图](../课堂笔记/11-18-差分与功率放大电路.md#反馈的定义与框图)给的是 $X_o=AX_d$、$X_F=FX_o$、$X_d=X_i-X_F$ 三式，注入 $+\delta$ 就是在这三式上取符号；[为什么线性区必须加负反馈](../课堂笔记/11-18-差分与功率放大电路.md#为什么线性区必须加负反馈)说明为什么这类电路实际工作时必须落在负反馈这一侧（否则运放进饱和、虚短不成立）。这两处只作背景。
- 完整解答
  **接线要点。** $A_1$ 是 `+` 在上、`−` 在下；$u_i$ 经电阻进 `−` 端，`+` 端经电阻接地；$R_{F1}$ 从 $A_1$ 输出回接 `−` 端（画在图下方）。$A_2$ 也是 `+` 在上、`−` 在下；$A_1$ 输出经电阻进 $A_2$ 的 `−` 端，$A_2$ 的 `+` 端经电阻接地；$R_{F2}$ 从 $u_o$ 回接 $A_2$ 的 `−` 端。跨级回线 $R_F$ 从 $u_o$ 回到 $A_1$ 的 `+` 端，画在图**上方**，是三幅里最长的一条。无电容。

  **第一步：直/交。** $R_F$ 从 $u_o$ 到 $A_1$ 的 `+` 端全程只有电阻，无电容 ⇒ 直流量、交流量都过 ⇒ **交直流反馈**。

  **第二步：正/负——端子对调不等于极性翻转。** 反馈落点仍是 $A_1$ 的 `+` 端。注入 $\delta>0$：

  1. `+` 端升 ⇒ $A_1$ 净输入 $u_+-u_-$ 升 ⇒ 从 `+` 端看进去 $A_1$ **同相** ⇒ $u_{o1}$ 升（反相次数 0）；
  2. $u_{o1}$ 经电阻进 **$A_2$ 的 `−` 端** ⇒ $A_2$ 净输入 $u_+-u_-=0-u_-$ 降 ⇒ $A_2$ **反相** ⇒ $u_o$ 降（反相次数 1）；
  3. $u_o$ 降 ⇒ 经 $R_F$ 把 $A_1$ 的 `+` 端往下拉，与注入的 $+\delta$ 相反 ⇒ 环路自我抵偿。

  反相次数 1（奇）⇒ **负反馈**。这里的关键只有一个：虽然两只运放的 `+`/`−` 上下对调了，$A_1$ 的输出**仍然接在 $A_2$ 的 `−` 端**，所以第二级照旧反相一次。若误按「信号进 `+` 端、第二级不反相」数成 0 次，$u_o$ 就会与 $\delta$ 同向，整题会翻成正反馈——这是三幅图里唯一能翻结论的一步，必须先看清级间电阻接的是 `−` 还是 `+`。

  **第三步：串/并。** $R_F$ 落在 $A_1$ 的 `+` 节点；这个节点上**只有** $R_F$ 与一只接地电阻，没有输入支路（$u_i$ 走 `−` 端）。反馈与输入落在不同节点，比较的是 $u_+-u_-$ 这个电压差 ⇒ **串联反馈**。判据依据：不同节点 ⇒ 电压形式串接；复核口径「串联使输入电阻增大」成立。

  **第四步：电/流。** $R_F$ 取样端直接接 $u_o$ 节点。令 $u_o=0$，反馈量归零 ⇒ **电压反馈**。

  **结论（(c) 逐条对八问）：**

  | 问 | 结论 | 依据 |
  | :--- | :--- | :--- |
  | 直流反馈 | 是（与交流并存） | $R_F$ 支路纯电阻 |
  | 交流反馈 | 是 | 支路无电容 |
  | 正反馈 | 不是 | 注入 $\delta$ 后 $u_o$ 反向 |
  | 负反馈 | **是** | 环路反相次数 1（奇） |
  | 串联反馈 | **是** | $u_i$ 在 `−`、$R_F$ 在 `+`，不同节点且 `+` 无输入支路 |
  | 并联反馈 | 不是 | 不共节点 |
  | 电压反馈 | **是** | 取样自 $u_o$，短路则反馈消失 |
  | 电流反馈 | 不是 | 无串入负载的取样电阻 |

  自检：一、与 (a) 对照，两幅的反馈落点、输入落点、级间落点、取样点都相同，只差一处——(a) 的 `+` 节点上多接了一条输入电阻，(c) 没有；串/并由这一处定，(a) 并联、(c) 串联，其余三项完全相同。二、与 (b) 对照，(c) 的反馈拓扑与 (b) 的交流通路逐项相同（$C_F$ 短路即同）——(b) 只多一个「交流」限定。三、短路法复算取样。
- 复盘 :-
  - **卡点一**：这题的陷阱全在端子排列上。(a)(b) 是上 `−` 下 `+`，(c) 两只都换成上 `+` 下 `−`，看上去像「反馈接到了同相端所以是正反馈」。但正负只由**反馈注入端到 $u_o$ 这条前向通路上的反相次数**定：$A_1$ 从 `+` 看同相、$A_2$ 从 `−` 看反相，一次反相 ⇒ 负反馈。端子名是绘图习惯，反相次数才是判据。
  - **卡点二**：(a) 与 (c) 的唯一差别是一条输入电阻。它落在 $A_1$ 的 `+` 节点上 ⇒ 输入与反馈共节点 ⇒ 并联；拆掉它 ⇒ 串联。这条电阻不改极性、不改取样，只改比较方式——四处差别里它只管一处，别外溢。
  - **卡点三**：三幅都是电压反馈。$R_F$ 一端接在 $u_o$ 节点上，与负载并联取样，短路法一测就归零；(c) 的回线画得最长、绕到图上方，看着像另取了一路信号，实际仍是从 $u_o$ 出发的那一个点。判取样只看接点，不看线的长短与走法。
