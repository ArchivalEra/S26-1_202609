## 没编号但讲了的知识点

### 显示译码器：把运算结果变成看得见的十进制数字

**链路**（`00:50`–`01:44`）：BCD 编码（二-十进制代码）→ **译码器** → **驱动器** → **显示器**。数字仪表、计算机的数字系统都是靠这条链路把运算结果用十进制数显示出来。

**数码管的两种接法**（`01:44`–`03:04`）：七段**发光二极管**排成"日"字形。

| 接法 | 公共端接法 | 各段另一端 | 译码输出的有效电平 |
| :--- | :--- | :--- | :--- |
| **共阴极** | 所有阴极接在一起**接地** | 各阳极接译码信号 | **高电平有效**（输出高 → 该段亮） |
| **共阳极** | 所有阳极接在一起**接电源正极** | 各阴极接译码信号 | **低电平有效**（输出低 → 该段亮） |

两种接法的段码排列完全一样，**不一样的是输出极性**，所以译码器与数码管必须配对使用，配错就整片显示乱码。

**段的排布**（`03:04`–`03:58`）：最上面那一横记 $a$，然后**顺时针**方向 $b$、$c$、$d$、$e$、$f$，**中间那一横是 $g$**。

⚠ 教师报出「共阴极时第 8 个引脚和第 3 个引脚都接地，共阳极时 3 和 8 接电源正极」，但转写里没有交代这是**数码管模块**的公共端脚号还是 **74LS47** 的控制端脚号，两处引号编号的口径见文末条件备注。段码表本身不受这一条影响。

### 七段码：每位数字点哪几段

**规则只有一条**：某位数字需要哪几段亮，就是那几位取有效电平。

- **显示 1**：只要点亮 $b$、$c$ 两段（`04:13`）。共阴极接法下这两端给高电平 → 导通点亮。按教师采用的 **"G 到 A"读法**（$g$、$f$、$e$、$d$、$c$、$b$、$a$ 依次），段码是 **0000110**（`05:22`）。
- **显示 2**：要点亮 $a$、$b$、$d$、$e$、$g$ **五段**（`05:35`），其余两段不亮。
- **0000 → 显示 0**：$a$、$b$、$c$、$d$、$e$、$f$ 六段高电平点亮，只有中间那一横 $g$ 低电平熄灭（`08:38`–`09:03`）。
- **1001 → 显示 9**：只要 $e$ 这一段不亮，其余都亮（`07:34`）。

把码字与点亮段合成一张表（就是教师说的"七段译码显示器这个状态表"，`11:49`）：

| BCD 码 | 显示数码 | 点亮的段 | 熄灭的段 | 段码（G→A，高电平有效） |
| :--- | :-: | :--- | :--- | :--- |
| 0000 | 0 | $a,b,c,d,e,f$ | $g$ | 0111111 |
| 0001 | 1 | $b,c$ | $a,d,e,f,g$ | **0000110**（教师当场报出） |
| 0110 | 6 | $a,c,d,e,f,g$ | $b$ | 1111101 |
| 1001 | 9 | $a,b,c,d,f,g$ | $e$ | 1101111 |

教师当场报出的段码只有数字 1 那一格；其余各行的段码按**同一条读法**排出——读法是 G→A，**亮的段记 1、灭的段记 0**。

⚠ **0110 这一行**：教师在 `09:18` 把 0110 说成「编码二」并给出数字 2 的段码（$c$、$f$ 不亮），在 `11:01` 又以「0110 只要 $b$ 一段不亮」为例——那是**数字 6** 的段码（$b$ 灭、其余亮）。两处口述互斥；按 BCD 编码 0110 就是 6，上表取后者（$b$ 灭），差异见文末条件备注。

**表怎么用**：输入端接四位 BCD 码，译码器输出直接接数码管的七段（`07:07`）。教师让同学把码字与段码的关系"捋顺"——把七段按数码管的形状摆好，亮的那几格拼起来就该是那个数字（`11:26`）。

### 74LS47：低电平有效与三个控制端

**芯片**（`11:59`）：七段译码显示器做成一块集成芯片 **74LS47**。四个 BCD 输入端接码字，输出是七段，外加一个控制端。

⚠ 教师报出四个 BCD 输入端对应的引脚号，转写作「1、2、1、2、6」，读法含糊，**不能确定每个脚对应码字的哪一位**；本页只写"四个输入端分别接 BCD 码的四位 $A_3$、$A_2$、$A_1$、$A_0$"，脚号口径见文末条件备注。

**输出极性**（`12:28`–`13:13`）：输出端符号上**标了非号**，即**直接输出低电平有效**。由此定下配对规则：

- **低电平有效 → 配共阳极接法**。教师原话："你的阳极已经是接高电平了……你只要你的阴极出现低电平，它就亮了。"
- **高电平有效 → 配共阴极接法**。

所以同一张段码表，搬到 74LS47（配共阳极）上时**亮的段输出 0、灭的段输出 1**，与上表正好相反。

**三个控制端**（`14:03`–`15:11`）：

| 控制端 | 作用 | 教师的原话口径 |
| :--- | :--- | :--- |
| **LTC**（灯测试） | $=1$ 时译码器**正常译码工作** | "当 LTC 等于 1 的时候，译码器是属于正常译码工作状态" |
| **BI**（灭灯） | $=0$ 时各输出为低电平 → **灭灯** | 输出低电平有效，所以灭灯对应的是低电平而不是高电平 |
| **RBI** | **把数码管显示的零熄灭** | "将数码管显示的零熄灭" |

三个信号组合起来，就能控制哪一段按要求显示、哪一段灭灯。

**实验接法**（`15:34`）：前面的四个 BCD 编码输入端接好，输出端**通过电阻**接数码管。

### 触发器的定义与三个特点

**定义**（`19:24`）：**能够储存或者记忆一位二进制信息的基本逻辑单元**。

**三个特点**（`19:24`–`22:06`）：

1. **两个稳定状态**：一位二进制信息就是 0 和 1，所以触发器有**状态 0** 与**状态 1** 两个稳定状态。
2. **可以被输入控制**：通过不同的输入可以对输出状态进行控制——**可以置 0，也可以置 1**；这两种状态能通过改变输入互相改变。
3. **输入消失后状态被保存**（教师说"第三点特别重要"）：输入信号消失之后，输出的 0 或 1 **被保存下来，不变化**——**这就是记忆功能**。

**与组合逻辑电路的分界**（`21:14`–`22:06`）：组合逻辑电路的输出**随着输入状态的改变而改变**，与前一时刻的状态**没有任何关系**；触发器则**下一时刻的状态跟现在的状态有关系**——它不只跟输入有关，还跟当下的状态有关，**当下的状态可以对下一刻的状态产生影响**。

### 按功能分三大类

**三类**（`22:14`–`22:55`）：

| 类别 | 包含什么 |
| :--- | :--- |
| **双稳态触发器** | 接下来重点学的 **RS 触发器**，以及下节课的 **JK 触发器、D 触发器、T 触发器** |
| **单稳态触发器** | — |
| **无稳态触发器** | 又名**多谐振荡器** |

教师强调"三大类，大家要记住"。双稳态触发器是**最基本**的一类，其中最基本的就是**基本 RS 触发器**。

### 基本 RS 触发器的电路结构

**组成**（`23:12`–`24:45`）：**两个与非门** $G_1$、$G_2$，**输出互为对方的输入**（交叉耦合）。

- $G_1$ 的输出记作 $Q$，$Q$ 是 **$G_2$ 的一个输入信号**；$Q$ 与 $\overline{R}_D$ **共同组成 $G_2$ 的两个输入**。
- $G_2$ 的输出记作 $\overline{Q}$，$\overline{Q}$ **反过来作为 $G_1$ 的输入信号**。
- 所以 $G_1$ 与 $G_2$ 的两个输出是**互补关系**。

电路结构（两只交叉耦合的与非门，$Q$ 与 $\overline{Q}$ 互补）：

```text
        ┌───────┐
  S̄_D ─┤       │
        │  G1   ├──── Q ─────┐
  Q̄ ───┤  与非  │            │
        └───────┘            │
                             ▼
        ┌───────┐         ┌───────┐
        │       │◄────────┤       │
  R̄_D ─┤  G2   │         │  G1   │
        │  与非  ├──── Q̄ ─┤  与非  │
        └───────┘         └───────┘
```

输入端 $\overline{S}_D$、$\overline{R}_D$ **带非号，是低电平有效**——这一条决定了下面四种组合的一切。

### 基本 RS 的四种输入组合

教师在第一段末尾停在问句"假设 $\overline{S}_D$ 和 $\overline{R}_D$ 都不起作用的时候，那应该是什么？"（`25:06`），第二段开头直接给答案并接讲第三种情况。**两种接法要分清**：基本 RS 的 $\overline{S}_D$、$\overline{R}_D$ 是**低电平有效**（带非号）；钟控 RS 的 $S$、$R$ 是**高电平有效**（不带非号）——两者极性相反。

| # | $\overline{S}_D$ | $\overline{R}_D$ | 谁有效 | $Q_{n+1}$ | 功能 | 教师原话依据 |
| :-: | :-: | :-: | :--- | :--- | :--- | :--- |
| 1 | 1 | 0 | $R$ 有效 | 0（不管 $Q_n$） | **置 0** | `05:17` |
| 2 | 0 | 1 | $S$ 有效 | 1（不管 $Q_n$） | **置 1** | `05:57` |
| 3 | 1 | 1 | 都无效 | $Q_n$ | **保持** | `00:17`–`01:17` |
| 4 | 0 | 0 | 都有效 | **不确定** | **不允许出现** | `01:17`–`03:40` |

**第 3 种（保持）怎么推出来的**（`00:33`–`01:17`）：设原状态 $Q=0$。$G_2$ 的输入是 $Q$ 与 $\overline{R}_D$，即 0 与 1 相与得 0，取反得 1，所以 $\overline{Q}=1$；$G_1$ 的输入是 $\overline{Q}=1$ 与 $\overline{S}_D=1$，相与得 1，取反得 0，所以 $Q$ 仍为 0。**原状态是 0 就保持 0；原状态是 1 就保持 1**——两个状态各自"往复循环"，输出不变。

**第 4 种（不确定）到底怎么来的**（`01:17`–`03:40`）：

- 两个输入**同时为 0** 时，$G_1$ 与 $G_2$ 的输入里各有一个 0，**两个输出都是 1**（$Q=1$，$\overline{Q}=1$）——这一瞬间的状态是**确定的**。
- 但在这个状态下**两个输入一起由 0 变 1** 时，要看**这两个与非门谁先翻转**；谁先谁后无法确定，于是**次态不可控**。
- 所以"同时为零"这一刻有确定值，"同时由低翻高"这一段才是**不定状态**。

教师在第二段末尾特别把这条澄清了一遍（`36:21`–`37:23`）："注意这个不确定是不是说同时出现零的时候是确定的啊……同时是零的时候，状态是确定的，$Q$ 等于 1，$\overline{Q}$ 也等于 1……如果只翻转一个呢，是确定的……你两个同时由低电平往高电平去翻的时候，那就出现状态不可控了。"

结论：**正确使用时不允许 $\overline{S}_D$ 与 $\overline{R}_D$ 同时为 0**。

### 记忆法：S 是 set，R 是 reset

教师专门教了一套记法（`13:21`–`14:41`）：

- **$S$ 管置 1**，对应的英文单词是 **set（设置）**；
- **$R$ 管置 0**，对应的英文单词是 **reset（复位）**；
- **两个同时无效 → 保持不变**；
- **$S$、$R$ 上面有没有非号，决定它是高电平有效还是低电平有效**——有一个非号就是**低电平有效**，没有就是**高电平有效**。基本 RS 的两个输入都带非号，所以是低电平有效；等下讲钟控 RS 时，$S$、$R$ **没有非号，是高电平有效**，两者正好相反（`45:53`："注意这里是 $S$ 是没有戴帽子的"）。

### 描述触发器功能的四种方式

教师说"再去看第 3 块的内容"（`03:55`），把描述一个触发器的逻辑功能分成**四种方式**。先把两个记号立起来：

- **次态** $Q_{n+1}$：**下一个时刻**的状态；
- **现态** $Q_n$：**现在**的状态。

按教师自己的编号（`07:11`"第二种描述触发器功能的叫做特征方程"、`21:21`"第三种……状态转移图"、`28:27`"第四种……也叫时序图"），四种方式是：**状态转移真值表（状态表）→ 特性方程 → 状态转移图 → 工作波形图（时序图）**。
**逻辑符号**是第一种（状态表）里附带的画法，画图时用来认器件。下面按讲的先后逐个展开。

#### ① 状态转移真值表（状态表）

**列法**：把四种输入组合逐条列成表，写清每一种下 $Q_{n+1}$ 是什么。

| $\overline{S}_D$ | $\overline{R}_D$ | $Q_n$ | $Q_{n+1}$ | 功能 |
| :-: | :-: | :-: | :-: | :--- |
| 1 | 0 | 0 | 0 | 置 0 |
| 1 | 0 | 1 | 0 | 置 0 |
| 0 | 1 | 0 | 1 | 置 1 |
| 0 | 1 | 1 | 1 | 置 1 |
| 1 | 1 | 0 | 0 | 保持（$Q_{n+1}=Q_n$） |
| 1 | 1 | 1 | 1 | 保持（$Q_{n+1}=Q_n$） |
| 0 | 0 | 0 | **不确定** | 不允许出现 |
| 0 | 0 | 1 | **不确定** | 不允许出现 |

教师说这张表"组合怎么这么复杂"（`13:06`），于是给了上面那套 set／reset 记忆法——**记住 $S$ 管置 1、$R$ 管置 0、两个都无效就保持**，表就不用死记。

**逻辑符号**（画图时认它）

（`06:38`–`07:11`）一个方框，**两个输入、两个输出**：

- 方框里写 $S$ 和 $R$；
- **两个输入端都加小圆圈**——因为是低电平有效；
- 输出是 $Q$ 和 $\overline{Q}$，**互补**。

#### ② 特性方程（状态方程）

**写法**：像组合逻辑电路写**逻辑表达式**那样，把次态写成**次态 + 输入条件**的逻辑式。

**先把两组信号分清**（这是本讲最容易记反的地方）：

| 记号 | 含义 | 有效电平 |
| :--- | :--- | :--- |
| $\overline{S}_D$、$\overline{R}_D$ | **引脚上的电平**（方框里画的就是这两个带非号的输入端） | **低电平有效**：$\overline{S}_D=0$ 才表示置 1 有效，$\overline{R}_D=0$ 才表示置 0 有效 |
| $S$、$R$ | **逻辑有效信号**：$S=1$ 表示置 1，$R=1$ 表示置 0 | 由引脚各取一次反得到：$S=\overline{\overline{S}_D}$、$R=\overline{\overline{R}_D}$ |

**怎么列**（`15:23`–`19:00`）：

1. **列输入信号**：一共**三个**——现态 $Q_n$，以及两个输入端。
2. **画卡诺图**（按前面的状态表）。
3. **处理约束项**：$\overline{S}_D$ 与 $\overline{R}_D$ **同时等于 0** 的那两格是**无关项**，用**约束项**表示——因为那是不确定的状态。
4. **圈组化简**（教师在课件上用绿、红两个圈标出来）：
   - **绿色圈**：圈住"置 1 有效"的那两格（$\overline{S}_D=0$，$Q_n$ 取 0 或 1）与两格约束项。这一列全是 1 或无关项，**保留 1** 得到的那一项就是**逻辑置位信号 $S$**——教师原话"当 $\overline{S}_D=0$ 也就是 $S_D=1$……本来是 $S_D$ 非再取反，所以就是 $S_D$"。
   - **红色圈**：圈住"$R$ 无效且 $Q_n=1$"那两格，**保留**的那一项是 $\overline{R}\cdot Q_n$——教师原话"保留相同量……$R$ 非乘以 $Q_n$"。
5. **得结果**：

$$Q_{n+1}=S+\overline{R}\cdot Q_n$$

换回引脚写，就是

$$Q_{n+1}=\overline{\overline{S}_D}+\overline{R}_D\cdot Q_n$$

（第一项那个**双重取反不能省**：它表示"引脚 $\overline{S}_D$ 取反后才是逻辑置位信号"。）

**约束条件**（`20:26`–`20:43`）：$S$ 与 $R$ 不能同时为 1，也就是引脚 $\overline{S}_D$ 与 $\overline{R}_D$ **不能同时等于 0**——这正是四种组合里第 4 种不允许出现的那个条件，写在方程旁边作为限制。

**自查办法只有一条**：把四种输入组合逐行代入这个式子，结果必须与状态表一致（置 1 得 1、置 0 得 0、保持得 $Q_n$）。方程与状态表对不上时，以状态表为准——推导过程与这句话见文末条件备注。

#### ③ 状态转移图（状态图）

**画法**（`21:21`–`22:36`）：

- 用**两个圆圈**代表 0 和 1 两种状态；
- 用**箭头**从一个圆圈指向另一个圆圈，表示**状态转移的方向**；
- 在**箭头旁标注转移条件**。

**四条边逐条推**（`23:05`–`26:28`）：

| 转移 | 条件 | 依据 |
| :--- | :--- | :--- |
| 0 → 1 | $\overline{S}_D=0$、$\overline{R}_D=1$（置 1） | 置 1 过程 |
| 0 → 0 | $\overline{R}_D=X$（**任意** 0 或 1），但 $\overline{S}_D$ **必须为 1** | 只要 $\overline{S}_D$ 无效，就不会是置 1；此时要么保持、要么置 0，末态仍是 0 |
| 1 → 0 | $\overline{R}_D=0$、$\overline{S}_D=1$（置 0） | 置 0 过程 |
| 1 → 1 | $\overline{R}_D=1$（**不能为 0**），$\overline{S}_D$ 可 0 可 1 | $\overline{R}_D$ 有效就会变 0；$\overline{R}_D$ 无效时要么置 1、要么保持，末态仍是 1 |

教师专门提醒："**这个不变是很关键的，这个不变很容易让我们漏掉**……在状态转移的过程当中，就是我 $\overline{S}_D$ 和 $\overline{R}_D$ 都等于 1 的情况下，我的次态和现态是……这个状态你别忘了"（`26:28`）。画状态图时**保持**那两条边必须画出来。

**为什么要画**（`27:08`–`28:27`）：后面学**计数器**时，状态转移图是重要分析工具——比如从 0000 → 0001 → 0010 依次转移，每来一个时钟状态转移一次，"每一个时钟过后，你的每一个输出端输出的状态到底是怎么样的"，到集成计数器那一章时，状态转移图就是分析它的标准工具。

#### ④ 工作波形图（时序图）

**给什么**（`28:27`–`29:41`）：通常给**输入信号随时间变化的波形图**，再加上一段**状态图**；然后按**特性方程、状态转移图或状态表**判断次态。

**推法**：$Q$ 与 $\overline{Q}$ 是**由 $\overline{R}_D$、$\overline{S}_D$ 的变化 + 之前的状态共同决定的**——不是只看当前输入。

### 基本 RS 的时序图例题

教师把一段波形逐段推过去（`29:41`–`34:01`）：

| 时刻 | 输入条件 | $Q_{n+1}$ | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | $\overline{S}_D=0$、$\overline{R}_D=1$ | 高电平 | **置 1**，$\overline{Q}$ 相应为低电平 |
| 2 | $\overline{R}_D=1$、$\overline{S}_D$ 也变为 1 | 保持高电平 | 查状态表：保持不变，$Q_{n+1}=Q_n$ |
| 3 | $\overline{S}_D=0$、$\overline{R}_D=1$ | 仍高电平 | 仍是置 1 的条件 |
| 4 | $\overline{S}_D=1$、$\overline{R}_D=0$ | **由高变低** | $R$ 有效 → **置 0** |
| 5 | $\overline{R}_D=1$、$\overline{S}_D=0$ | **由低变高** | 满足置 1 的条件 → 置 1 |
| 6 | 两个**同时为 0** | $Q=1$、$\overline{Q}=1$ | **都是 1**，是"一态" |
| 7 | 两个**同时由低翻高** | **不可控** | 虚线段画成"无序混乱"：谁翻得快，结果就不一样 |

**这一段要记住的分辨**（`36:21`–`37:23`）：

- **同时为 0 的那一段**：状态是**确定的**——$Q=1$，$\overline{Q}=1$；
- **只翻转一个**：状态也是**确定的**——要么置 1 有效，要么置 0 有效；
- **两个同时由低电平往高电平翻**：才进入**不定状态**，$Q$ 不再由输入信号确定，而是由"谁翻得快、谁翻得慢"的**偶然因素**决定。

所以使用中**不允许**让两个输入同时为低电平有效。

### 基本 RS 触发器的两个固有缺陷

（`37:55`–`39:25`）教师点出两条，作为下一讲铺垫：

1. **状态只由两个控制信号决定，与时间无关**——"你的这 2 个输入状态是什么样的，就确定了是什么样的状态，包括它原来的这个状态……它跟时间就没有任何关系"。所以**做不了计时器**。
2. **实际电路里两个输入无法完全控制**——输入状态控制不住，就有可能出现不定状态。

### 钟控（可控）RS 触发器

**电路**（`39:25`–`40:30`）：在基本 RS 触发器的基础上**再加两只与非门 $G_3$、$G_4$**。这两只门有**一个共同的输入 $C$**（**时钟脉冲信号**）。$C$ 作为 $G_1$、$G_2$ 的一个输入信号的控制信号——**它加入了这个导引电路和控制端 $C$**。

**工作分析**（`40:30`–`42:41`）：

- **$C=0$**：$G_3$、$G_4$ 的输出**都是 1**。与非门有一个输入是 1 时，输出不受另一个输入影响（"1 作为与门……与开头的那个门，你就影响不了输出结果"），所以 **$G_1$、$G_2$ 的输入不变，触发器状态不改变**。
- **$C=1$**：$G_3$、$G_4$ 才开始起作用。$G_3$ 的输出由 $S$ 决定、$G_4$ 的输出由 $R$ 决定，再由这两个输出去决定 $G_1$、$G_2$ 的输入，从而决定 $Q$。

**四种输入组合**（`43:47`–`47:15`）：

| $S$ | $R$ | $G_3$、$G_4$ 的输出 | $Q_{n+1}$ | 功能 |
| :-: | :-: | :--- | :-: | :--- |
| 0 | 0 | 都为 1 | $Q_n$ | **保持不变** |
| 0 | 1 | $G_4$ 输出 0 | 0 | **置 0** |
| 1 | 0 | $G_3$ 输出 0 | 1 | **置 1** |
| 1 | 1 | 都为 0 | — | **出现"一态"，随后进入不稳定状态** |

第 2 行的推法（`44:40`）：$R=1$ 与 $C=1$ 相与再取反得 0，$G_4$ 输出 0 → $G_2$ 的输入里有一个 0 → $G_2$ 输出 1 → $Q=0$，**置 0**。第 4 行：$S$、$R$ 都为 1 时 $G_3$、$G_4$ 输出**都是 0**，$G_1$、$G_2$ 的输入端**同时出现 0** → 出现"一态"，同时翻转后又进入**不稳定状态**。

**与基本 RS 的三点对照**（`45:53`–`50:04`）——这是本讲最容易记反的地方：

1. **有效电平相反**：基本 RS 的 $\overline{S}_D$、$\overline{R}_D$ 是**低电平有效**（带非号）；钟控 RS 的 $S$、$R$ **没有非号，是高电平有效**（教师原话"注意这里是 $S$ 是没有戴帽子的"）。虽然记法反了，**功能对应关系却一致**——$S$ 有效仍置 1、$R$ 有效仍置 0。
2. **特性方程形式一致**：钟控 RS 同样是

   $$Q_{n+1}=S+\overline{R}\cdot Q_n$$

   教师强调"**你不要去记反了**"（`48:28`–`49:01`）——它与基本 RS 的 $Q_{n+1}=S+\overline{R}\cdot Q_n$ **形式一致**：两边的 $S$、$R$ 都是**逻辑有效信号**（$S=1$ 置 1、$R=1$ 置 0），所以式子形状相同，**区别只在基本 RS 的两个信号要各取一次反**（$\overline{S}_D$ 的反是 $S$，$\overline{R}_D$ 的反是 $\overline{R}$）。约束条件也不变（$S$、$R$ 不能同时为 1）。
3. **状态表与状态图必须括注 $CP=1$ 才有效**："你画这个 RS 触发器的时候，状态表记住这里**必须括弧，要有一个 CP 等于 1 的时候**，这个只有它等于 1 的时候有效啊……这个状态图也是一样的，也要标一个 $CP=1$，这个不标不行"（`49:10`–`49:57`）。

**状态图的对照**（`50:04`–`51:09`）：0 → 1 只在 $S=1$、$R=0$（置 1）；1 → 0 只在 $R=1$、$S=0$（置 0）；0 → 0 只要**不出现 $S=1$**，$R$ 是什么都行；1 → 1 只要**满足 $R=0$**，$S$ 是 0（保持）还是 1（置 1）都不影响末态仍是 1。

### 空翻现象

**现象**（`51:47`–`52:16`）：钟控 RS 触发器的 $Q$ 只在 **$CP$ 的高电平窗口**内才可能变化。
当 **$CP$ 的高电平脉冲持续时间过长**时——"在这个过程当中，我的 $S$ 跟 $R$ 它已经发生了好多次的翻转了"——
而**每一次翻转都落在 $CP$ 高电平的有效范围之内**，于是 **$Q$ 在一个时钟脉冲期间翻转多次**。
教师原话："那就会发生这个 $Q$ 会发生空翻，就我不希望它翻转，它翻转了啊，这个我们就叫**空翻**。"

**后果**：输出在不该翻转的时候翻转，信号受干扰，**抗干扰能力下降**。

**解法**：教师一句"**那么怎么解决，我们下一节课来讲**"（`52:40`）收束本讲。
