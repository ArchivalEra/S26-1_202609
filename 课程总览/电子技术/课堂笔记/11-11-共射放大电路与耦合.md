# 11-11-共射放大电路与耦合

## 这节课在干什么

前半节（`00:04`–`43:08`）**复盘共射放大电路的整套分析方法**，但复盘不是重讲，是把上节散落的口头结论收成
一条可复制的流程：直流通路算 Q 点 → 交流通路 → 微变等效替换 → 按定义算三个指标。沿这条流程，课上把
共射的不同接法一次性排开：固定偏置（发射极不接电阻 / 接电阻）、分压式偏置（发射极旁路 / 不旁路），
每一种给出 $A_u$、$R_i$、$R_o$ 的差别在哪里、为什么差别只落在分母那一项。

后半节是新内容：**共集电极放大电路**（`45:47`–`1:19:08`）——从「它为什么也叫共集电极」这个最容易被
电路图骗过去的点讲起，静态分析、动态三指标一路推完，落到「射极输出器、放大倍数约等于 1 且同相、
输入电阻大、输出电阻小」。最后 5 分钟开**多级放大电路的耦合方式**（`1:20:23`–`1:23:44`），只给了
定义、三种接法与两条要求，具体分析留到下星期。

要会五件事：

1. 不看公式、只看电路图，就能列出直流通路的回路方程，把 $I_B$、$I_C$、$U_{CE}$ 一项一项解出来；
2. 说清发射极串 $R_E$ 后，为什么**输入回路的电阻被放大 $(1+\beta)$ 倍**，而输出电阻一点不变；
3. 分清 $i_C$ 波形与 $u_o$ 波形，饱和失真、截止失真各自削平哪一侧；
4. 会讲分压式偏置的稳定链条（$I_C\uparrow\to V_E\uparrow\to U_{BE}\downarrow\to I_B\downarrow\to I_C\downarrow$）；
5. 会推共集电极的 $A_u$、$R_i$、$R_o$，并说清它为什么被拿去做缓冲级。

## 没编号但讲了的知识点

### 复盘：静态分析与动态分析各管什么

**分工**（`03:26`–`04:18`）：静态分析在**直流通路**上做，只求 Q 点四个量 $I_B$、$U_{BE}$、$I_C$、$U_{CE}$；
动态分析在**交流通路**上做，只求三个指标——电压放大倍数、输入电阻、输出电阻。教师给的理由是
叠加：`06:48`「用叠加的原理，我们把交流的部分和直流的部分给它分开进行分析」，所以两张通路图
各管一半，最后再叠回去。

**Q 点为什么是四个量定一个点**（`07:56`–`08:44`）：$I_B$ 与 $U_{BE}$ 在**输入特性曲线**上定一个点；
$I_C$、$U_{CE}$ 再加 $I_B$ 在**输出特性曲线**上定一个点——$I_B$ 在这里的身份不是坐标，而是**选曲线族的
下标**：「输出曲线它是一组一系列对应的不同的 $i_B$……通过 $i_B$ 我们可以确定输出曲线上到底它是哪一条」。

**四个指标的定义与方向**（`04:18`–`06:48`，与 11-09 衔接）：

| 指标 | 定义 | 想要的方向 |
| :--- | :--- | :--- |
| $A_u$ | $u_o/u_i$；含信号源内阻时另有 $A_{us}$ | 越大越好 |
| $R_i$ | 输入端电压除以输入端电流 | 越大越好（有效输入信号大、减轻信号源负担） |
| $R_o$ | 信号源置零、负载开路，端口外加电压除以流入电流 | 越小越好（带负载能力强） |
| 通频带 | 幅频特性降到最大值的 $1/\sqrt2$ 所夹的频段 | 越宽越好 |

$1/\sqrt2=0.7071$，对应低频截止频率与高频截止频率两点，中间是通频带；超出这段「放大性能就会
容易失真」。

### 微变等效电路：只等效晶体管那两个口

**「微变」的来处**（`12:40`–`13:21`）：输入信号相对 Q 点很小，只在 Q 点附近摆动，所以曲线在 Q 点
附近可以**用切线代替**；切线斜率就是等效参数。输入侧

$$r_{be}=\frac{\Delta u_{BE}}{\Delta i_B}\Big|_{\text{Q 点}}$$

**工程公式**（`1:05:35`，本教材口径，要求记）：

$$r_{be}=200\ \Omega+(1+\beta)\,\frac{26\ \text{mV}}{I_E}$$

第一次出现时（`13:21`）转写记作「200 欧加上一个贝塔乘以 26 除以 $R_E$」，漏了「$1+$」、分母也读成
$R_E$；到 `1:05:35` 教师完整复述成「200 欧加上 $1+\beta$ 的 26 除以 $I_E$」，按后者记。

**管子只换两个口**（`14:02`–`15:22`）：B–E 之间换成一个电阻 $r_{be}$；C–E 之间换成一个**受控电流源**
$i_c=\beta i_B$。中间那个 $r_{ce}$ 数值很大，「形成一个恒流特性」，工程计算里忽略。教师把这句话说成
一个必须背下来的结构：「你 B 和 E 之间我是用一个等效电阻，集电极 C 和发射极 E 之间我是一个受控
电流源」。

### 动态分析的三步：三张纸，一步都不能少

`55:23`–`56:15`。教师把动态分析的路径倒着讲了一遍，正着走就是三步：

1. 要求 $A_u$、$R_i$、$R_o$，得先有**微变等效电路**；
2. 要画微变等效电路，得先把管子换掉，而换管子前必须先画**交流通路**；
3. 有了等效电路，再按三个指标的**定义**逐个列式、算出来。

所以考卷上的顺序固定是「交流通路 → 微变等效电路 → 三个指标」，教师在 `15:40` 专门强调前两张图
「考试的时候这两步都不能少」。他也说了为什么不能背公式（`1:10:58`）：「你死记这个公式，实际这个
公式很可能会记反了……你还是要去学会用电路原理的分析，分析的流程掌握了，肯定不会错」。

### 画交流通路的两条固定动作

`12:19`、`56:31`–`56:42`：第一步把**电容一律短路**（耦合电容 $C_1$、$C_2$ 与旁路电容 $C_E$ 都是）；第二步把
**直流电压源 $U_{CC}$ 的端点接地**。之后逐节点整理：同一节点上有哪些元件、每个元件两端各连哪个节点。

共射（固定偏置、发射极直接接地）整理出来是：$R_B$ 上端接 $U_{CC}$ = 地，故 $R_B$ 并在 B–地之间；
$R_C$ 上端接 $U_{CC}$ = 地，故 $R_C$ 并在 C–地之间；$R_L$ 经 $C_2$ 也在 C–地之间，于是 $R_C\parallel R_L$
并在 C–地之间；发射极接地。

### 共射的 $A_u$：从 $u_o/u_i$ 两式相除

`15:59`–`16:54`：$u_o$ 与 $u_i$ 都能写成 $i_B$ 乘电阻的形式，相除时 $i_B$ 约掉：

1. $u_i=i_B r_{be}$（$R_B$ 并在输入端，但 $u_i$ 就是 $r_{be}$ 两端电压）；
2. $u_o=-i_C R_L'=-\beta i_B R_L'$，其中 $R_L'=R_C\parallel R_L$；
3. 相除得

$$A_u=\frac{u_o}{u_i}=-\beta\frac{R_L'}{r_{be}}=-\beta\frac{R_C\parallel R_L}{r_{be}}$$

负号的来处是参考方向：$i_C$ 由 C 流向 E，而 $u_o$ 取自 C 对地、上正下负，两者方向相反。这个负号
就是共射**反相**的全部内容。

### 发射极串 $R_E$：只改分母

`17:05`–`18:34`：加上 $R_E$ 后，交流通路上 E 点不再直接接地，输入电压变成两段串联：

$$u_i=i_B r_{be}+i_E R_E=i_B\big[r_{be}+(1+\beta)R_E\big]$$

$u_o$ 那一侧完全不变（$R_L'$ 还是 $R_C\parallel R_L$，受控源电流还是 $\beta i_B$），所以

$$A_u=-\frac{\beta R_L'}{r_{be}+(1+\beta)R_E}$$

教师把结论说成一句可直接记的话：「原来是没有 $(1+\beta)R_E$ 这一块的，现在分母多加了一个，那整个
放大倍数就变低了」。**分母多出的 $(1+\beta)R_E$ 就是 $R_E$ 折算到基极回路后的等效电阻**——从基极看
进去，发射极上那只电阻被放大了 $(1+\beta)$ 倍。

### 输入电阻：两种口径，别混

**不含信号源内阻**（`18:40`–`22:54`）：从输入端看进去，$i_i=i_B+i_{R_B}$，两条支路并联：

$$R_i=R_B\parallel\big[r_{be}+(1+\beta)R_E\big]$$

推导的落点是「这条支路的等效电阻等于 $u_i$ 除以 $i_B$」——不是除以 $i_i$，因为并联的另一条（$R_B$）
已经单独算了。$R_E$ 被旁路电容短路时，方括号里只剩 $r_{be}$，回到 $R_i=R_B\parallel r_{be}$。

**含信号源内阻**（`03:54`、`42:34`）：$u_i$ 只是信号源电压 $u_s$ 在 $R_S$ 与 $R_i$ 串联分压中分到的
那一份，所以

$$A_{us}=A_u\frac{R_i}{R_S+R_i}$$

这一乘号解释了「为什么希望 $R_i$ 越大越好」：$R_i\to\infty$ 时 $A_{us}\to A_u$，且有效输入信号大、
减轻信号源负担。

### 输出电阻：按端口定义求，结论是 $R_o=R_C$

**四步法**（`23:00`–`24:52`）：① 输入信号源置零；② 负载断开（$R_L=\infty$）；③ 在输出端口外加电压；
④ 外加电压除以流入端口的电流。

按这四步走一遍共射：信号源置零 ⇒ $i_B=0$ ⇒ 受控源电流 $\beta i_B=0$ ⇒ **受控源相当于开路**（这一步
最容易做错：受控源电流为零是开路，不是短路）。于是端口往里看，只剩 $R_C$ 一条到地：

$$R_o=R_C$$

教师顺带答了一个常被问的问题（`25:19`–`26:08`）：**发射极串 $R_E$ 对 $R_o$ 没有影响**——因为 $i_B=0$
时 $R_E$ 上也没有电流，它不参与端口看进去的那条路。所以「串了电阻以后，它的输出电阻还是不变的，
$R_o$ 还是等于集电极上的电阻 $R_C$」。

### 图解法：直流负载线与交流负载线不是一条

`26:16`–`27:31`：

- **直流负载线**：由 $U_{CE}=U_{CC}-I_C R_C$ 定两点——$(U_{CC},0)$ 与 $(0,U_{CC}/R_C)$，斜率 $-1/R_C$。
- **交流负载线**：接上负载后，交流分量的等效负载是 $R_L'=R_C\parallel R_L$，斜率 $-1/R_L'$。因为并联
  后阻值变小，**交流负载线比直流负载线更陡**，并且**过 Q 点**（信号为零时仍回到 Q）。
- 由此得两条结论：输出波形与输入波形**相位相反**、幅度成 $A_u$ 倍；**接上负载后放大倍数变小**
  （$R_L'<R_C$）。

### 失真：$i_C$ 与 $u_o$ 的削平侧是反的

`27:39`–`33:24`。教师按两条来源讲失真：Q 点位置不对（饱和区／截止区），以及 Q 点没问题但输入信号
幅度太大。

**先分清两张波形**。教师这一段口述的是 $i_C$ 波形（`32:16`「这边 $i_C$ 它的波形……」），而同学复习时
看到的是输出 $u_o$。两者由 $u_{CE}=U_{CC}-i_C R_C$ 联系：$i_C$ 涨则 $u_{CE}$ 降，即 $u_o$ 与 $i_C$ **反相**，
所以削平侧相反：

| 失真 | 起因 | $i_C$ 波形 | $u_o$ 波形（与 $i_C$ 反相） |
| :--- | :--- | :--- | :--- |
| 饱和失真 | Q 点过高，$i_C$ 撞上限 $U_{CC}/R_C$ | 正半周被削平 | 负半周被削平 |
| 截止失真 | Q 点过低，$i_C$ 撞零轴（管子截止） | 负半周被削平 | 正半周被削平 |

教师原话是饱和失真时「上面的波形的上半部分会被削平」（`31:34`）——照上下文指的是 $i_C$ 那一侧；若
把这句直接搬到 $u_o$ 上，削平侧会记反。这是本节最值得留意的一处口径差。

**Q 点该放哪**（`28:19`）：放在「两个区域中间」，使放大的工作区间越大越好。

**消除办法**（`31:48`、`33:24`）：Q 点过高就**增大基极电阻**让 $I_B$ 减小，把 Q 点拉回来；信号幅度太大
就**减小输入信号幅度**——后者是上下两侧同时削平，加电阻救不了。

### 固定偏置的病：温度一升，Q 点自己往上爬

`28:33`–`31:34`：

- **优点**：结构简单、元器件少。**缺点**：温度变化时 Q 点漂移。
- **器件层面的三条变化**：温度升高 ⇒ $U_{BE}$ 变小、$\beta$ 变大、穿透电流 $I_{CBO}$ 变大。
- **连锁**：$\beta$ 变大 ⇒ $I_C=\beta I_B$ 变大 ⇒ Q 点沿负载线**上移** ⇒ 靠近饱和区 ⇒ 饱和失真；
  $I_C$ 过大还会让管子过热，「容易烧坏」。
- 教师点明这是**非线性**引起的波形畸变，与频率特性里的失真不是一回事。

### 分压式偏置：先钉住 $V_B$，再用 $R_E$ 负反馈

`34:09`–`38:58`。改法：基极与地之间加 $R_{B2}$（上边是 $R_{B1}$ 接 $U_{CC}$），发射极串 $R_E$ 并在
$R_E$ 上并一只电容 $C_E$（旁路电容）。

**稳定链条有两段，缺一不可**：

1. **钉住 $V_B$**。前提是流入基极的 $I_B$ 远小于分压支路电流 $I_2$（教师：「这个 $I_1$ 相对于这个 $I_2$
   数量级是很小很小的，可以忽略不计」）。于是 $I_1\approx I_2$，基极电位只由两只电阻分压决定：
   $$V_B\approx\frac{R_{B2}}{R_{B1}+R_{B2}}U_{CC}$$
   它**与 $\beta$、与温度无关**，这是全链条的支点。
2. **用 $R_E$ 做温度补偿**：温度升高 ⇒ $I_C\uparrow$ ⇒ $V_E=I_E R_E\uparrow$（教师按 $I_C\approx I_E$ 算）
   ⇒ $U_{BE}=V_B-V_E\downarrow$ ⇒ $I_B\downarrow$ ⇒ $I_C=\beta I_B\downarrow$，被拉回来。教师把这一圈
   直接叫「加了一个负反馈电路」。

**旁路电容 $C_E$ 的作用**（`40:59`–`42:38`）：$C_E$ 只旁路交流。有 $C_E$ 时，交流通路上 $R_E$ 被短路，
动态指标与「固定偏置、发射极不接电阻」**完全一样**；没有 $C_E$ 时，$R_E$ 留在交流回路里，就跟
「固定偏置、发射极接电阻」一样。教师原话：「有旁路电容的，放大倍数跟原来的一样……输入电阻、
输出电阻都一样的」。

把两种情形并起来看，四种接法的差别只落在两处：

| 接法 | $A_u$ 的分母 | $R_i$ |
| :--- | :--- | :--- |
| 固定偏置，发射极不接 $R_E$ | $r_{be}$ | $R_B\parallel r_{be}$ |
| 固定偏置，接 $R_E$ 且无旁路 | $r_{be}+(1+\beta)R_E$ | $R_B\parallel[r_{be}+(1+\beta)R_E]$ |
| 分压式，$R_E$ 有旁路 $C_E$ | $r_{be}$ | $R_{B1}\parallel R_{B2}\parallel r_{be}$ |
| 分压式，$R_E$ 无旁路 | $r_{be}+(1+\beta)R_E$ | $R_{B1}\parallel R_{B2}\parallel[r_{be}+(1+\beta)R_E]$ |

四行的 $R_o$ 都是 $R_C$——$R_o$ 只认端口往里看到的那条路，与偏置方式、与 $R_E$ 都无关。

### 分压式偏置的静态估算：四步

`39:29`–`40:59`。顺序是**从上往下算，最后回到输出回路**：

1. $V_B\approx\dfrac{R_{B2}}{R_{B1}+R_{B2}}U_{CC}$；
2. $I_E=\dfrac{V_B-U_{BE}}{R_E}$（这一步已经用了 $I_C\approx I_E$）；
3. 要精确一点时 $I_B=\dfrac{I_E}{1+\beta}$（教师：「我们要算的精确一点，那你这个 $i_B$ 就可以用
   $i_E$ 除以 $1+\beta$」）；
4. $U_{CE}=U_{CC}-I_C R_C-I_E R_E$（两个电阻上的压降都要减）。

第 1 步的「$I_2\gg I_B$」是个**有条件的近似**，条件不成立时第 1 步就要修正。定量判据是把 $I_B$ 对分压
的影响折算进基极等效电阻：$I_E=(V_B-U_{BE})\big/\big[R_E+(R_{B1}\parallel R_{B2})/(1+\beta)\big]$。
取 $U_{CC}=12$ V、$R_{B1}=60$ kΩ、$R_{B2}=20$ kΩ、$R_E=1$ kΩ、$\beta=50$、$U_{BE}=0.7$ V 对一遍：
近似式给 $I_E=2.30$ mA，修正式给 $1.78$ mA，差 29%——此时 $(R_{B1}\parallel R_{B2})/(1+\beta)=294\ \Omega$
已经和 $R_E=1$ kΩ 同量级，近似不成立。加大分压电流或换高 $\beta$ 管，这一项才真正可以丢。（这组数只是
整理者拿来量级对照的，不是题目数据。）

### 共集电极：为什么它也叫「共集」

`45:47`–`50:30`。这是本次课最容易看错的一点，教师专门停下来问「这跟集电极有啥关系啊？」

答案在**交流通路**里，不在电路图上：$U_{CC}$ 端点对交流接地，而集电极直接接 $U_{CC}$，所以**集电极
交流接地**。于是输入信号经 B、E 到地，输出信号从 E 到地，两条回路**共用集电极这个交流地**，故称
共集电极。教师这一段是连问带答推下来的（`48:55`–`49:32`）：「直流源相当于是接地的……$U_{CC}$ 是不是
直接跟这个集电极相连？那是不是相当于把集电极接地了？……输入信号也经过它，输出信号也经过它，
那集电极就是公共端。」

输出取自发射极，所以它又叫**射极输出器**（转写读作「设计输出器」）。静态分析与共射的唯一区别：
**集电极与 $U_{CC}$ 之间没有 $R_C$**（`51:35`「集电极和这个直流电源之间没有了一个电阻 $R_C$」）。

### 共集电极的静态分析

`51:01`–`54:34`。直流通路上只有一条从 $U_{CC}$ 到地的路：

$$U_{CC}=I_B R_B+U_{BE}+I_E R_E$$

用 $I_E=(1+\beta)I_B$ 替换，得

$$I_B=\frac{U_{CC}-U_{BE}}{R_B+(1+\beta)R_E},\qquad U_{CE}=U_{CC}-I_E R_E$$

$U_{BE}$ 照旧「题目里头一般就会告诉你，要么 0.6 要么 0.7」（`54:34`）。$U_{CE}$ 里只有 $R_E$ 一项可减，
这正是「集电极没有 $R_C$」在直流通路上的直接后果。

### 共集电极的动态三指标

`55:23`–`1:17:55`。交流通路：$C_1$、$C_2$ 短路，$U_{CC}$ 接地 ⇒ 集电极接地；$R_B$ 并在 B–地之间；
$R_E$ 与 $R_L$ 都并在 E–地之间 ⇒ $R_L'=R_E\parallel R_L$；受控源 $\beta i_B$ 从 C（地）流向 E。

1. **输出**：流过 $R_L'$ 的电流是 $i_E=(1+\beta)i_B$，故 $u_o=i_E R_L'=(1+\beta)i_B R_L'$。
2. **输入**：B–E 之间是 $r_{be}$、E–地之间是 $R_L'$，两段串联（**不能合并成一只电阻**，因为两段电流
   不同，教师专门提醒「因为三极管的存在，这一段支路的电流值是不一样的」）：
   $$u_i=i_B r_{be}+i_E R_L'=i_B\big[r_{be}+(1+\beta)R_L'\big]$$
3. **相除**：

$$A_u=\frac{(1+\beta)R_L'}{r_{be}+(1+\beta)R_L'}=1-\frac{r_{be}}{r_{be}+(1+\beta)R_L'}$$

分子分母同阶、分母多一项正的 $r_{be}$，所以 $0<A_u<1$：**恒小于 1、且同相**（没有负号）。$r_{be}$ 相对
$(1+\beta)R_L'$ 很小，故 $A_u$ 约等于 0.9 几到 0.99 几。教师由此给两个别名：**射极输出器**、**电压跟随器**。

4. **输入电阻**：从 B 端口看，$R_B$ 与「$r_{be}+(1+\beta)R_L'$」并联：

$$R_i=R_B\parallel\big[r_{be}+(1+\beta)R_L'\big]$$

数值上很大——这是共集最值钱的指标。

5. **输出电阻**：按端口定义，信号源置零（$u_s$ 短路，于是 B 经 $R_S$、$R_B$ 接地，记 $R_S'=R_S\parallel R_B$）、
   $R_L$ 断开、在 E 端口外加电压。此时 $i_B$ 不再为零，受控源不再开路，**$(1+\beta)$ 的倍数关系还在**：
   那条 $r_{be}+R_S'$ 支路的电流是 $i_B$，而端口电流是 $i_E=(1+\beta)i_B$，所以折算到 E 端口要除以
   $(1+\beta)$：

$$R_o=R_E\parallel\frac{r_{be}+R_S'}{1+\beta},\qquad R_S'=R_S\parallel R_B$$

$R_E$ 通常远大于折算后的那一项，故 $R_o\approx\dfrac{r_{be}+R_S'}{1+\beta}$，可以做得很小。

**一句话对比共射与共集**：共射（$R_E$ 未被旁路）的分母被 $(1+\beta)R_E$ 撑大，$A_u$ 大而反相；共集的分母
被 $(1+\beta)R_L'$ 撑大，$A_u$ 小于 1 而同相。同一个 $(1+\beta)$ 折算，在共射里拉低放大倍数，在共集里
拉高输入电阻。

### 共集电极为什么被拿去做缓冲级

`1:17:55`–`1:18:34`。教师总结的三条（$A_u\le1$ 且同相、$R_i$ 大、$R_o$ 小）连起来就是一条用途链：

- $A_u\approx1$、同相 ⇒ 接在中间不改变信号大小与相位；
- $R_i$ 大 ⇒ 从信号源取用的电流小，**减轻信号源负担**；
- $R_o$ 小 ⇒ 带负载能力强，后级接重载也不掉压。

所以它常接在两级之间做**阻抗匹配**，叫**缓冲级**或**隔离级**：前级看到的是一个大电阻，后级看到的是
一个小内阻的源。这也正是 11-09 那节「$R_i$ 越大、$R_o$ 越小越好」两条结论的用处。

- 受控方式：三极管是**电流控制电流源**，场效应管是**电压控制电流源**（教师口述成「这个是电流控制
  电压型的，这个是电压控制电压型的」，两个「电压型」都是口误）。

关系）、把 $\beta i_B$ 换成 $g_m u_{gs}$。

### 多级放大电路与三种耦合方式

`1:20:23`–`1:23:44`。实际电路不会只有一级：典型结构是**输入级 → 中间推动级 → 输出级**，各级之间要
接起来。

**耦合方式的定义**（`1:21:23`）：信号源与放大电路之间、两级放大电路之间、放大器与负载之间的连接
方式，统一叫耦合方式。

| 耦合方式 | 接法 |
| :--- | :--- |
| 直接耦合 | 前一级的输出直接接后一级的输入，中间不接元件 |
| 阻容耦合 | 前后级的输入输出之间用电阻、电容连接（转写读作「主融耦合」） |
| 变压器耦合 | 前级输出先进变压器一次侧，从二次侧取出送后级输入 |

**两条要求**（`1:22:34`）：静态上要保证各级都有合适的静态工作点（教师：「要求静态工作」）；动态上传送的
信号波形不失真，并且**减小传输损失**（压降损失小）。

教师只讲到定义与要求，具体分析（多级 $A_u$ 怎么连乘、$R_i$ 与 $R_o$ 怎么折算）明说「下个星期再来
分析」。
