# 11-02-时序分析与设计

**这节课在干什么**：这一晚是**连堂两段**：18:00 起讲「怎么分析」，讲到 37:17；18:39 接上讲「怎么设计」，讲到 42:27。两段合起来是时序逻辑电路的一套完整方法论：

① 时序电路与组合电路的分界——输出除了取决于当下的输入，还取决于电路原来的状态，记忆功能由触发器承担；
② **分析**：写四个方程 → 列状态转换真值表 → 画状态图与时序图 → 判断逻辑功能（含自启动的判据）；
③ **设计**：逻辑抽象 → 状态图与状态转移表 → 状态化简 → 状态分配与编码 → 选触发器类型 → 求输出方程与状态方程 → 与特性方程比较反推驱动方程 → 画逻辑电路图 → 检查能否自启动；
④ 两类例子各走一遍：教材例题一（同步六进制加法计数器，**分析**）与例题一（同步三位二进制加法计数器，**设计**）；末尾的例题二（同步五进制）没讲完。

**行政与考核**

- **作业上的提问**：上次作业有人问 JK 触发器的波形（`05:23`）。教师借此讲教材约定：**JK 触发器的 J、K 端单独悬空时，一般默认接高电平**；要接 0，教材上会标一个 0 的符号，或者直接把它接地。
- **课后自查**：教师指出课件上设计步骤的顺序反了（`39:18`），并要求学生回去自己对照验证一遍推导过程（`40:22`）——即按「先得状态方程 → 与触发器特性方程比较 → 反推驱动方程」这条顺序重走一次。

## 题号条目

### 例一（分析）：同步六进制加法计数器（教材例题一）

**题面**（教师口述与板书）：三个 JK 触发器 FF0、FF1、FF2 组成，CP 端接同一路时钟脉冲；输出 $Y$ 由 $Q_2$ 与 $Q_0$ 经一只与门产生；各触发器的 J、K 端按驱动方程接线。

⚠ 这一题的**驱动方程那一行转写失真**（语音识别把上下标与取反号全部听丢）。正文给出的驱动方程是按教师自己报出的状态序列与自启动路径反解得到的，解法步骤全部写出、可以逐步复核；板书原件不在手上，文字符号以推导结果为准，详见文末「条件备注」。

**解析**（分析步骤逐条走，每一步的依据写在旁边）：

1. **先判同步还是异步**：三个触发器的 CP 都接在同一路时钟脉冲上 ⇒ **同步时序电路**。这一句必须写出来（`10:15`）。同步电路的时钟方程可以省略，也可以统一写成 $\mathrm{CP}_0=\mathrm{CP}_1=\mathrm{CP}_2=\mathrm{CP}$（`04:26`）；异步电路则要逐个分析每个 CP 由哪几个信号组合而成。
2. **写输出方程**：$Y$ 是一只与门的输出，两个输入是 $Q_2$ 和 $Q_0$ ⇒ $Y=Q_2Q_0$。
3. **写驱动方程**：JK 的特性方程是 $Q_{n+1}=J\overline{Q_n}+\overline{K}Q_n$（教师要求背下来，`12:05`：「这个式子不会给你的，你要自己去记住」）。教师报出的状态序列是 $000\to001\to\cdots\to101\to000$，无效状态路径是 $110\to111\to010$。据此列出各位的变化表：

   | 现态 | $Q_0$ 的变化 | $Q_1$ 的变化 | $Q_2$ 的变化 |
   | :--- | :--- | :--- | :--- |
   | 000 | 0→1 置位 | 0→0 保持 | 0→0 保持 |
   | 001 | 1→0 复位 | 0→1 置位 | 0→0 保持 |
   | 010 | 0→1 置位 | 1→1 保持 | 0→0 保持 |
   | 011 | 1→0 复位 | 1→0 复位 | 0→1 置位 |
   | 100 | 0→1 置位 | 0→0 保持 | 1→1 保持 |
   | 101 | 1→0 复位 | 0→0 保持 | 1→0 复位 |
   | 110 | 0→1 置位 | 1→1 保持 | 1→1 保持 |
   | 111 | 1→0 复位 | 1→1 保持 | 1→0 复位 |

   再用特性方程逐格解出 J、K，规则是固定的四句：现态为 0 而次态为 1 ⇒ 该格 $J=1$；现态为 1 而次态为 0 ⇒ 该格 $K=1$；现态为 0 而次态为 0 ⇒ 该格 $J=0$；现态为 1 而次态为 1 ⇒ 该格 $K=0$。按触发器分开整理：

   - **FF0（$Q_0$）**：八个状态全部翻转 ⇒ $J_0=K_0=1$。
   - **FF1（$Q_1$）**：只在 $001$、$011$ 两格翻转 ⇒ 这两格 $J_1=K_1=1$，其余为 0；这两格的共同特征是「$Q_0=1$ 且 $Q_2=0$」⇒ $J_1=K_1=Q_0\overline{Q_2}$。
   - **FF2（$Q_2$）**：$J_2$ 需在 $011$（置位）为 1、在 $000$、$001$、$010$（保持）为 0、在 $101$、$110$、$111$ 处因现态为 1 而无关 ⇒ $J_2=Q_0Q_1$；$K_2$ 需在 $101$、$111$（复位）为 1、在 $100$、$110$（保持）为 0、在 $000\sim011$ 处因现态为 0 而无关 ⇒ $K_2=Q_0$。

   于是驱动方程为

   $$J_0=K_0=1,\qquad J_1=K_1=Q_0\overline{Q_2},\qquad J_2=Q_0Q_1,\quad K_2=Q_0$$

4. **写状态方程**：把驱动方程代入 JK 特性方程 $Q_{n+1}=J\overline{Q_n}+\overline{K}Q_n$：

   $$Q_0(n+1)=\overline{Q_0}$$

   $$Q_1(n+1)=Q_0\overline{Q_2}\,\overline{Q_1}+(\overline{Q_0}+Q_2)Q_1$$

   $$Q_2(n+1)=Q_0Q_1\overline{Q_2}+\overline{Q_0}Q_2$$

5. **列状态转换真值表**：把现态、次态、输出列成一张表（`07:17` 起教师讲的列法：现态列 $Q_2(n),Q_1(n),Q_0(n)$，次态列 $Q_2(n+1),Q_1(n+1),Q_0(n+1)$，一行行的次态就是下一行的现态）：

   | 现态 $Q_2Q_1Q_0$ | 次态 $Q_2(n+1)Q_1(n+1)Q_0(n+1)$ | 输出 $Y$ |
   | :--- | :--- | :-: |
   | 000 | 001 | 0 |
   | 001 | 010 | 0 |
   | 010 | 011 | 0 |
   | 011 | 100 | 0 |
   | 100 | 101 | 0 |
   | 101 | 000 | 1 |
   | 110 | 111 | 0 |
   | 111 | 010 | 1 |

   表里 $Y$ 只有 $101$ 与 $111$ 两行为 1，与教师口述一致（`14:59`：「$101$ 刚好 $Q_2$ 与 $Q_0$ 等于 1」，主循环里其余各状态 $Y$ 全为 0）。
6. **画状态图与时序图**：
   - **状态图**：每个状态画一个圈，圈里写三位状态码，箭头从现态指向次态，输出标在转移箭头上。$000\to001$、$001\to010$、$010\to011$、$011\to100$、$100\to101$ 这五条箭头标输出 0，$101\to000$ 标输出 1（`18:14`）。输出只挂在状态转移上，所以这个电路是 Moore 型的输出形式。
   - **时序图**：一个 CP 来一个下降沿，$Q_0$ 翻一次；再来一个下降沿，$Q_0$ 与 $Q_1$ 同时翻，$Q_2$ 因为不满足翻转条件不动；再往下依此类推（`16:40`）。
7. **判断逻辑功能**：环上有 $000\sim101$ 六个状态，按递增规律从 0 数到 5，数满六个又回到 000 ⇒ **同步六进制加法计数器**（教师原话 `15:49`：「从零计数到 5……总共记了六个数，记完六个数以后他又回头回到零重新记了」）。
8. **检查能否自启动**：三位触发器共 8 个状态，主循环只用了 6 个，剩下 $110$ 与 $111$ 是**无效状态**。把它们代入状态方程：$110\to111\to010$，$010$ 已经在主循环里 ⇒ 经过有限个 CP 能自动回到有效循环 ⇒ **能自启动**。
   教师给的判据原话是 `20:53`：「经过若干个有限的 CP，它能够自动的返回有效状态……这个叫做这个电路是能够实现自启动的」；反过来，若无效状态只在它们自己之间循环、进不了主循环，就叫**不能自启动**，那说明这个电路设计得有问题（`21:48`）。

**这一题在讲什么**：这一题把「分析」的四步从头到尾走了一遍，示范的是**顺序而不是结论**：先判同步/异步，再写四个方程，然后列表、画图，最后才下功能判断。四个方程一个都不能省（`06:38`：「记住要写四个方程啊，对步骤不能省略」），因为后面每一步都靠它——驱动方程代进特性方程才出状态方程，状态方程才列得出转换真值表，转换真值表才画得出状态图，状态图才判得出功能与自启动。

这一题还有一层用意：**自启动是设计的验收项，不是可选项**。功能判断只说明「正常情况下它是六进制计数器」，自启动判断才说明「上电瞬间进了无效状态也能自己爬回来」。教师把这两件事分开讲，是为了让你在设计完电路后还能回头验一遍。

### 例一（设计）：同步三位二进制加法计数器

**题面**（教师口述，`12:39`）：设计一个同步的三位二进制加法计数器。

**解析**（按设计步骤逐条走）：

1. **逻辑抽象**（`12:59`）：三位二进制加法计数器 ⇒ 状态是 $000\sim111$，共 **8 个状态**；初态取 $000$；每来一个 CP 加 1；**计到 $111$ 时输出一个进位信号 $Y$，并同时返回 $000$**。要表示三位二进制，至少要 3 个触发器（$2^2=4<8\le 2^3=8$）。
2. **画状态图 / 状态转移表**（`13:59` 起）：八个状态全部用上，$000\to001\to\cdots\to110$ 每一步都没有进位，只有 $111\to000$ 这一步产生进位。
3. **状态化简**（`14:32`）：八个状态两两不同——每个状态的输入相同、输出也各不相同，没有可以合并的等价状态，所以**不需要化简**。
4. **状态分配与编码**（`14:55`）：用三位二进制码给八个状态编码，$000\sim111$ 依次对应。
5. **求输出方程**（`16:51`）：教师在这里专门强调一条规矩——**输出方程用现态描述**（原话：「注意是不是描述现态方程……是由现态来组成的」）。$Y=1$ 只有 $111$ 这一行，三个现态全为 1 ⇒
   $$Y=Q_2Q_1Q_0$$
   电路上一只三输入与门即可。
6. **求状态方程**（`18:05` 起）：把现态与次态列在同一张表里，取**次态的每一个变量当作输出变量**，把该输出变量取 1 的那些行圈起来，用卡诺图化简成关于现态 $Q_2,Q_1,Q_0$ 的表达式，得到

   $$Q_0(n+1)=\overline{Q_0}$$

   $$Q_1(n+1)=Q_0\overline{Q_1}+\overline{Q_0}Q_1$$

   $$Q_2(n+1)=\overline{Q_2}Q_1Q_0+(\overline{Q_1}+\overline{Q_0})Q_2$$

7. **选触发器类型 + 反推驱动方程**（`19:16` 起）：选 JK 触发器，特性方程 $Q_{n+1}=J\overline{Q_n}+\overline{K}Q_n$。把它与上面三条状态方程**逐条比较**，反推 J、K：
   - $Q_0(n+1)=\overline{Q_0}$：每次都翻转 ⇒ $J_0=K_0=1$（教师原话 `22:40`：「$J_0$，$K_0$ 应该等于什么？等于 1……每来一个时钟，我这个 $Q_0$ 要翻转一次」）。
   - $Q_1(n+1)=Q_0\overline{Q_1}+\overline{Q_0}Q_1$：$Q_0=1$ 时翻转、$Q_0=0$ 时保持 ⇒ $J_1=K_1=Q_0$（`23:53`）。
   - $Q_2(n+1)=\overline{Q_2}Q_1Q_0+(\overline{Q_1}+\overline{Q_0})Q_2$：$Q_1Q_0=1$ 时翻转、否则保持 ⇒ $J_2=K_2=Q_1Q_0$（`24:11`）。

   这一步就是教师指出来「课件顺序反了」的地方：正确的次序是**先得状态方程，再与特性方程比较，反推驱动方程**（`39:18`）。
8. **画逻辑电路图**（`25:02` 起）：
   - 3 个 JK 触发器，**CP 端全部接到同一路时钟**（同步）；
   - **清零端置高**，让它不起作用（「你让他那个什么就是要给他置高点……要置高一点你就让他不要清零」）；
   - $J_0$、$K_0$ 悬空（悬空默认就是 1），也可以把两个端连在一起、再标一个「1」表示高电平接进这两个端（`26:02`）；
   - $J_1$、$K_1$ 两个端都接 $Q_0$；$J_2$、$K_2$ 两个端都接 $Q_1$ 与 $Q_0$ 的与门输出（`26:39`、`26:55`）；
   - 三个触发器的输出 $Q_2$、$Q_1$、$Q_0$ 送进一只与门，得到输出方程 $Y$（`27:38`）。

**这一题在讲什么**：这是**分析的镜像**——分析是「给定电路求功能」，设计是「给定功能求电路」，两条路最后落在同一批方程上，只是先后颠倒。教师特意在讲完例题后停下来纠正课件的流程图顺序（`39:18`），因为流程图是照着做的依据，顺序错了整条推导链就会倒着走。

另一件要记住的事是**输出方程必须用现态写**。学生最容易在这里把 $Y=Q_2Q_1Q_0$ 写成次态，于是得到 $Y$ 恒为 1 之类的怪结论；教师专门把这条拎出来说了一遍。

### 例一（设计）的另一种做法：不画卡诺图，直接从状态转移表找规律

**题面**（`28:39` 起）：同样的同步三位二进制加法计数器，换一条路做。

**解析**（这条路教师称为「直接分析状态转移的规律」，`32:03`）：

1. 先把状态转移表列清楚：现态一行、次态一行，上面那行的次态就是下面那行的现态（`29:11`）。
2. **看每一位什么时候翻转**：
   - **FF0**：每来一个 CP 就翻转一次 ⇒ 接成 T 触发器（$J_0=K_0=1$），教师说这里用的是 JK 触发器接成的 T 触发器（`31:01`、`32:03`）。
   - **FF1**：**$Q_0=1$** 时再来一个 CP 就翻转一次 ⇒ $J_1=K_1=Q_0$，效果等价于「$Q_0$ 决定这个 T 触发器能不能翻」（`31:36`、`33:07`）。
   - **FF2**：**$Q_0$ 与 $Q_1$ 都等于 1** 时再来一个 CP 就翻转一次 ⇒ $J_2=K_2=Q_0Q_1$，输入信号是前两个信号相与的结果（`33:45`）。
3. **画电路与波形**，并说明它与前面卡诺图那条路**接出来的电路形式不同但功能一样**（`34:31`：「三个二进制的一个分布加的电路画出来电路是不一样的」）。
4. **工作过程**（`35:16` 起）：同步计数器的特点是**每来一个时钟都要同步判断**——在这个时钟到来的同时，要一起看 $Q_0$、$Q_1$、$Q_2$ 的状态对下一时刻的影响。第 2 个 CP（状态 $001\to010$）时 $Q_0$ 与 $Q_1$ 同时翻转；第 4 个 CP（状态 $011\to100$）时 $Q_0$、$Q_1$ 翻转，同时 $Q_0Q_1=1$ 满足了 $Q_2$ 的翻转条件，于是**三个触发器在同一时刻同步翻转**——这就是「同步加法计数器」这个名字的来处。

**这一题在讲什么**：这一题的价值在于**同一道题有两条路，而两条路给出同一个答案**。前面那条路是标准的卡诺图化简法（先列状态转移表 → 化简出状态方程 → 比较特性方程反推驱动方程），这条是「读懂状态转移表里每一位的翻转规律」。教师把两条路并排摆出来，是为了让你在做设计时**能自己选**：功能简单、状态少的时候直接找规律更快；状态一多，卡诺图才是靠得住的。

两条路得到同一组驱动方程（$J_0=K_0=1$、$J_1=K_1=Q_0$、$J_2=K_2=Q_0Q_1$），这一点本身就是对两条路的交叉验证。

### 十进制计数器：10 个有效状态，6 个无效状态

**题面**（`36:58` 起）：设计一个十进制计数器。

**解析**：

1. **定状态数与位数**：十进制计数器有 **10 个状态**（$0\sim9$）；$2^3=8<10\le 2^4=16$ ⇒ **至少 4 个触发器**。四个触发器有 16 个状态，取其中 10 个当有效状态 ⇒ **6 个是无效状态**。
2. **列状态图与状态转移表**（`37:25`）：10 个有效状态依次 0→1→…→9，每个 CP 加 1；计到 9 之后回到 0，同时产生进位。课件上用红框把这 6 个无效状态框了出来（`37:48`）。
3. **同步设计**：CP 端**全部接在同一端**（`37:48`：「他是用同步的，所以我们同步的时空方程都是接在同一端，CD 端」）。
4. **求方程**：状态方程仍然用卡诺图求——把次态的每个变量当输出变量，把该变量取 1 的那些行圈起来，化简成关于四个现态变量的表达式（`38:21`）。
5. **检查自启动**：把这 6 个无效状态分别代入状态方程，看能不能回到有效状态（`41:13`：「启动之前，我就把剩余的六种状态分别带入到状态方程」）。

**这一题在讲什么**：十进制计数器和二进制计数器**在方法上没有任何区别**，差别只在状态数与无效状态的数量。而无效状态数量的由来是纯算术：位数向上取整，多出来的组合全是无效状态，要逐个代入状态方程验一遍能不能回来——这就是「设计完必须回头验自启动」这条规矩的用武之地。

### 例二（设计）：用 JK 设计同步五进制计数器（**没讲完**）

**题面**（`41:48`）：用 JK 触发器设计同步五进制计数器。

**解析**（课上只走到这里）：

1. 列 5 个状态，五进制计数器的状态循环一次。

## 没编号但讲了的知识点

### 什么叫时序逻辑电路：功能与两类描述方式

时序逻辑电路的特点：**任何时刻的电路输出，不仅与当下的输入有关，还取决于电路原来的状态**（`00:06`）。这个「原来的状态」由**有记忆功能的触发器**记录——它把原始状态存下来，与当下的输入一起决定输出。

描述一个时序电路的功能有两种方式，**两者并列，不是二选一**（`01:12`）：

| 描述方式 | 具体内容 |
| :--- | :--- |
| **表达式** | 三类方程：**驱动方程**、**输出方程**、**状态方程** |
| **图表** | **状态表**（状态转换真值表）、**卡诺图**、**状态图**、**时序图** |

### 时序逻辑电路的三种分类口径

按**逻辑功能**分（`01:23`）：**计数器**、**寄存器**、**存储器**、**脉冲与顺序脉冲发生器**等。

按**时钟控制方式**分（`01:51` 起）：

| 类型 | 判据 | 状态变化 |
| :--- | :--- | :--- |
| **同步时序电路** | 所有触发器的状态都在**同一个时钟脉冲 CP** 作用下变化 | **同时**发生 |
| **异步时序电路** | 触发器**各有自己的时钟信号**（也可以几个共用一个，但**不是全部**共用同一个） | **有先后**：有的先翻转，有的**跟随着**前一级翻转之后再翻 |

按**输出与状态的关系**分（`02:47` 起）：

| 类型 | 输出取决于 |
| :--- | :--- |
| **Moore 型** | 只与**存储电路的状态**有关（与输入无关） |
| **Mealy 型** | 不仅与存储电路的状态有关，**还与电路中其他组合逻辑电路的输入状态**有关 |

### 分析步骤：四个方程，一步都不能省

教师给的分析流程（`03:35` 起）。**第一步永远是先拿到时序逻辑电路**，然后：

1. **写方程式——四个方程，顺序固定**（`06:38`：「记住要写四个方程啊，对步骤不能省略啊，你们反正牢牢记住要写四个方程」）：
   1. **时钟方程**：每个触发器的 CP 接的是谁。**同步电路可以省略**，或统一写成 $\mathrm{CP}_0=\mathrm{CP}_1=\cdots=\mathrm{CP}$；**异步电路必须逐个分析**每个 CP 由哪几个信号组合而成（`04:00`、`04:46`）。
   2. **输出方程**：电路的输出逻辑表达式，通常是**现态**的函数（`04:46`）。
   3. **驱动方程**：每个触发器**输入端**的逻辑表达式（`05:23`）。
   4. **状态方程**：把驱动方程代入相应触发器的**特性方程**解出来的表达式（`06:38`）。
2. **列状态转换真值表**（`07:17` 起）：三个触发器就列 $Q_2(n),Q_1(n),Q_0(n)$ 三个现态变量与 $Q_2(n+1),Q_1(n+1),Q_0(n+1)$ 三个次态变量，从 $000$ 起步，把每一行的现态代进状态方程算出次态填进去；**上一行的次态就是下一行的现态**。
3. **由状态表画状态图与时序图**（`09:11`）。
4. **由状态表、状态图、时序图共同判断逻辑功能**。

### 教材约定：JK 触发器

- **J、K 端单独悬空时，一般默认接高电平**（`05:23`）。要接 0，教材上会标一个「0」符号，或者直接把它接地。
- **JK 特性方程**（`12:05`）：

  $$Q_{n+1}=J\overline{Q_n}+\overline{K}Q_n$$

  教师明确要求学生自己记住：「这个式子不会给你的，你要自己去记住啊」。

### 计数器的特点、分类与作用

**作用**（`22:53` 起，`27:27` 复述）：在自动化生产线里应用非常广泛。**对时钟脉冲 CP 计数**——来一个脉冲记一个数；**产生节拍脉冲与脉冲序列**；**定时**；**进行数字运算**。组成单元是触发器。

**分频是它的副产品**（`23:26` 起）：每一位输出的频率不同，$Q_0$ 是 CP 的 $1/2$，$Q_1$ 是 $1/4$，$Q_2$ 是 $1/8$……把高频率信号通过分频电路变成低频率信号，所以**计数器也叫做分频器**（`37:04`）。

**两种分类口径**（`25:06` 起）：

| 分类依据 | 类别 |
| :--- | :--- |
| **进制** | 二进制计数器、十进制计数器、任意 **N 进制**计数器 |
| **计数方式** | 加法计数器、减法计数器、**可逆**计数器 |
| **触发器翻转是否同时** | 同步计数器、异步计数器 |

**状态数的算术**（`26:21` 起）：选 $N$ 位（$N$ 个触发器）时，状态数**大于等于 $2^{N-1}$、小于等于 $2^N$**；多出来的那些就是**无效状态**。无效状态代入状态方程后能回到有效状态，就是**能自启动**；否则**不能自启动**，说明电路设计有问题。

### 三位二进制异步加法计数器

**题面**（`27:52` 起）：三位二进制异步加法计数器。

**解析**：

1. **接线与判定**：FF0 的时钟是 **CP**，FF1 的时钟是 **$Q_0$**，FF2 的时钟是 **$Q_1$**。三个触发器的时钟信号**各不相同** ⇒ 这是**异步**电路（`28:30`）。
2. **逐拍分析**（`29:09` 起）：
   - 来一个 CP 的下降沿 ⇒ **$Q_0$ 先翻转**（$0\to1$）。此时 $Q_1$、$Q_2$ 不动——它们的时钟是 $Q_0$、$Q_1$，而 $Q_0$ 这次是**上升沿**，没有下降沿。
   - 再来一个 CP ⇒ $Q_0$ 由 1 变 0，这个**下降沿**就是 FF1 的有效触发信号 ⇒ **$Q_1$ 翻转**。
   - $Q_1$ 翻转后，它自己由 1 变 0 的那个**下降沿**又去触发 FF2 ⇒ **$Q_2$ 翻转**。
   - 到 111 再来一个下降沿时，$Q_2$、$Q_1$、$Q_0$ **三个同时翻转**，回到 000。
   - 归纳成一句：**$Q_0$ 出现下降沿，$Q_1$ 翻转；$Q_1$ 出现下降沿，$Q_2$ 翻转**（`31:59`）。这就是「CP 管 $Q_0$、$Q_0$ 管 $Q_1$、$Q_1$ 管 $Q_2$」的级联关系。
3. **触发器接法**：把 J、K 悬空（默认高电平），即 $J_0=K_0=J_1=K_1=J_2=K_2=1$，相当于用 JK 触发器接成 **T′ 触发器**，**下降沿触发**（`33:18`）。
4. **另一种接法**（`34:25` 起）：把后面两级的时钟信号换成 $\overline{Q_1}$、$\overline{Q_0}$，就得到**上升沿触发**的版本。**功能完全相同**，只是一个下降沿有效、一个上升沿有效。教师说如果需要接成上升沿，就用后一级接 $\overline{Q}$ 的那种接法。
5. **对比同步与异步**（`35:35` 起）：异步计数器**每一步的翻转都不是同时进行的**，只有最后一个状态 111→000 是三个同时翻转。同步计数器则是各位在同一 CP 时刻**同步翻转**。

**这一题在讲什么**：异步计数器的价值在于**电路最省**——后级的时钟直接用前级的输出，不额外引入时钟；而它的代价就是各位不在同一时刻更新。**"翻转为同步还是异步"**这件事的分界线，落在「各触发器的 CP 是不是都接同一路」这一条上，看图先看时钟端。

### 设计步骤：分析的反向

教师在 `03:44` 起给出。**最简的标准**（`04:14`）：**元器件越少越好**——具体拆成三条：**触发器用的个数最少**、**输入端最少**、**连线最少**。

设计步骤（`04:37` 起，与课件流程图对应）：

1. **逻辑抽象**：分析因果关系，确定输入变量、输出变量、状态数与每个状态的含义，找出状态之间的转换关系（`09:26`）。
2. **画状态图 / 列状态转移表**（`05:03`）。
3. **状态化简**：在状态转移图里，**若两个状态在相同输入下输出相同、且转换到同一个状态，就是等价状态，可以合并**（`10:16`）。化简的目标是**建立最小状态转换图**。
4. **状态分配**（`10:39`）：先定**触发器的个数** $N$——有效状态有几个，就要满足 $2^N\ge$ 有效状态数，且 $2^{N-1}\le$ 有效状态数（`11:05`）。有效状态数由逻辑功能本身决定。
5. **状态编码**（`11:34`）：给每个状态分配一个二进制代码。标准是**以组合电路是否最简为准**（`12:01`）。
6. **选触发器类型**（`12:08`）。
7. **求输出方程、状态方程**（`07:01`、`07:14`）。
8. **反推驱动方程**：用状态方程与所选触发器的**特性方程**比较，反推出来（`07:14`、`08:27`）。
9. **画逻辑电路图**（`08:27`）。
10. **检查能否自启动**（`08:55`）：把逻辑电路图上出现的**所有状态**都列出来，主循环之外的状态逐个检查，看能不能经过若干个 CP 重新进入有效状态。

**两条要单独记住的规矩**：

- **输出方程用现态描述**（`16:51`：「注意是不是描述现态方程……是由现态来组成的」）。
- **状态方程由卡诺图得来**：把现态和次态列在同一张表里，**取次态的每一个变量当作输出变量**，把这个输出变量取 1 的那些行圈起来，画卡诺图化简成关于现态的表达式；然后与触发器的**特性方程**比较，反推驱动方程（`39:47`、`40:22`）。

### 教师指出课件的设计步骤顺序反了

`39:18` 原话：「我们在设计的过程当中，其实应该是先得到一个状态方程，那你根据状态方程加上触发器的特性方程，反推回去……这里的课件上这个步骤是反了一下」。
