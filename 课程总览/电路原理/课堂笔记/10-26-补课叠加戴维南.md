# 10-26-补课叠加戴维南

## 这节课在干什么

这是**国庆冲掉的课**（本周一第 6、7 节补）。两小时连讲三段：先把**节点电压法的例题收尾**并做**网孔法与节点法的比较**，
再进入**第四章**，讲**叠加定理**（含受控源的处理、功率为什么不能叠加），最后开**戴维南定理**（等效内阻的三种求法）。

要会五件事：

1. 拿一道含理想电压源与受控源的电路，**选对参考点、列全方程、补一个控制量方程**；
2. 说清**网孔法与节点法各自的适用面**（独立回路少 / 独立节点少），并据此选题；
3. 用**叠加定理**把一个多电源电路的响应拆成几个单电源电路之和，**电压源置零即短路、电流源置零即开路**；
4. 叠加时**受控源必须留在每个分电路里、不能置零**，且**功率不能叠加**；
5. 用**电阻化简法 / 外加电压法 / 开路短路法**求戴维南等效内阻，并知道**前两种置零独立源、第三种保留独立源**。

## 题号条目

### 节点电压法例（含理想电压源与受控电压源）

**解析**：

1. 先看有没有**理想电压源**：有，就**取它的一端作参考点**。这样与它相连的那个节点电压直接等于该源电压，
   未知量从三个降成两个（本例 $V_1$ 已知，只列 $V_2$、$V_3$）。
2. $V_2$ 的方程按标准形式：自电导是接在 $V_2$ 上的几条支路电导之和（其中两条串联，先合成 $5\,\Omega$），
   互电导项 $-\tfrac{1}{2}V_3$，右端是流入该节点的电流源电流与该节点所连实际电压源等效电流之和
   （本例含一项 $-\tfrac{4U}{5}$，因该支路电压源方向使出端为负）。
3. $V_3$ 同法写一条。
4. **补一个方程**把受控电压源的控制量用节点电压表示：$U=V_3$。
5. 三个方程解三个未知量。

**这一题在讲什么**：**受控源与理想电压源同时出现时的标准流程**——先按"理想电压源定参考点"砍掉一个未知量，
再把受控源当独立源写进方程，最后补控制量方程。教师反复强调：**整个第三章，受控源都是这一套**。

### 叠加定理例一（求 $4\,\Omega$ 两端电压，得 $-5.6$ V）

**解析**：

1. 参考方向已给（$4\,\Omega$ 上端为 $+$），第一步省掉。
2. **电压源单独工作**：电流源置零 = **开路**，电路只剩左边串联支路。
   $I=10/(6+4)=1$ A，$4\,\Omega$ 上电压 $=1\times4=4$ V（也可直接用分压公式）。
3. **电流源单独工作**：电压源置零 = **短路**，$4\,\Omega$ 与 $6\,\Omega$ 并联，
   $R=4\parallel 6=2.4\,\Omega$，$4$ A 电流流过它，电压 $=4\times2.4=9.6$ V；按所设参考方向为**负**，即 $-9.6$ V。
4. **叠加**（按参考方向取代数和）：$U=4+(-9.6)=-5.6$ V。

**这一题在讲什么**：叠加定理的**最小完整示范**——两个分电路各是一次串并联计算，最后代数和。
教师强调负号不是"算错"，而是**分电路的实际方向与原设参考方向相反**。

### 叠加定理例二（求支路电流，得 $-16/7$ A）

**解析**：

1. **电压源单独工作**（电流源开路）：先做**电阻等效**——$6\,\Omega$ 与 $2\,\Omega$ 先并联得 $1.5\,\Omega$，
   再与 $2\,\Omega$ 串联得 $3.5\,\Omega$；支路电流 $=7/3.5=2$ A，但实际方向与所设参考方向相反，记 $-2$ A。
2. **电流源单独工作**（电压源短路）：分析拓扑——电流在节点处**分成三支**，其中两支先并联再与 $2\,\Omega$ 串联，
   整个组合再与 $4\,\Omega$ 并联；用分流公式得该支路分到 $4/7$ A，再在并联的一对里分成 $2/7$ A，
   方向与参考方向相反，记 $-2/7$ A。
3. **叠加**：$I=-2-2/7=-16/7$ A。

**这一题在讲什么**：叠加定理的难点**不在叠加本身，在分电路的拓扑识别**——电源置零后电路"变形"，
必须先看清串并联结构再算。教师说这一步"很多同学卡住"，卡的是看图不是公式。

### 叠加定理例三（含受控电压源，求 $U_S$）

**解析**：

1. 电路里有一个受控电压源，控制量是 $10I_1$（$I_1$ 为某支路电流）。
2. **受控源不能置零**：在每个分电路里它都**保留为一个受控电压源**，控制量照原样写成 $10I_1$。
3. **电压源单独工作**（电流源开路）：右边开路，左边自成闭合回路，$1$ A 电流 $(10/10)$，$4\,\Omega$ 上 $4$ V，
   上方电阻上 $10$ V；沿逆时针列 KVL：$-U_S'-10\times1+4=0$，得 $U_S'=-6$ V。
4. **电流源单独工作**（电压源短路）：用分流公式求支路电流，再求受控源上的电流，
   由 KVL 得该分电路的响应（教师给的是 $-16$ V 一档）。
5. **叠加**：两个分量代数和即 $U_S$。

⚠ 第 4、5 步的数值与最终和值在转写中互相矛盾（教师先后说出 $-16$、$9.6$、$16+9.6=25.6$、$16.9$ / $19.6$、$-1.6$ 等多个口径），
本页只保留方法与第 3 步自洽的分量 $U_S'=-6$ V，**最终结果不择一断言**。

**这一题在讲什么**：叠加定理与第三章受控源处理的**唯一区别**。第三章（网孔法、节点法）可以把受控源**当独立源**处理；
叠加定理里**不行**——受控源不是激励，置零就违背了它的控制关系，所以它必须**每一份分电路都在场**。
教师自评这道题"第一次讲的时候自己都讲得云里雾里"，提醒学生重点是记住这条**保留规则**。

### 戴维南定理例（等效内阻 $2\,\Omega$）

**解析**：

1. 要求某支路电流，把该支路以外的部分当作**有源二端网络**。
2. **等效内阻**：内部独立源**全部置零**（电压源短路、电流源开路），剩下的纯电阻网络按串并联化简，
   端口处得 $2\,\Omega$。
3. **开路电压**：把待求支路断开，用 KVL/KCL 求端口电压。
4. 等效成"电压源 $U_{OC}$ 串 $R_{eq}$"，再接回负载求电流 $I=U_{OC}/(R_{eq}+R)$。

**这一题在讲什么**：**没有受控源**时，等效内阻就是"把源拿掉、量端口电阻"——二年级的串并联问题。
教师用这道题把"戴维南定理 = 第二章等效 + 一次开路电压计算"这个定位钉住。

### 戴维南定理例（外加电压法求内阻，得 $6\,\Omega$）

**解析**：

1. 内部独立源置零后，端口**外加电压 $U$**、流入电流 $I$。
2. 一条支路电流设 $I'$，另一支路因两电阻并联、电压相同，电流为其一半，故 $I'=I+0.5I=1.5I$。
3. 沿回路列 KVL：$6I+3I=9I$ 与 $U$ 的关系解出。
4. 得 $R_{eq}=U/I=6\,\Omega$。

**这一题在讲什么**：**含受控源时等效内阻不能靠串并联**，必须"设端口电压电流、消中间量"。
这与第二章 2.5 的外加电压法**完全同一个动作**，只是这次对象是"有源网络置零后的内部"。

### 戴维南定理例（开路短路法求内阻）

**解析**：

1. **开路电压**：断开端口，内部形成闭合回路，求得支路电流与各段电压，$U_{OC}=6$ V。
2. **短路电流**：端口直接短接，列方程解出短路电流 $i_{SC}$。
3. $R_{eq}=U_{OC}/i_{SC}$。

⚠ 本题参数在转写中矛盾：教师一处说 $U_{OC}=6$ V、$i_{SC}=9/6=1.5$ A，另一处把结果说成"$6$ 或 $5$"。
$6/1.5=4\,\Omega$，与口述的两个数都对不上，**不择一断言**。

**这一题在讲什么**：第三种求内阻的办法，也是**唯一不置零独立源**的一种——因为开路和短路都要求内部电路原样工作。
代价是**多做一次完整计算**（开路电压 + 短路电流），收益是**含受控源时往往比外加电压法省事**。

### 戴维南定理例（$15$ V 串 $5\,\Omega$）

**解析**：

1. 开路电压：断开后电路仍有回路，电流 $0.5$ A，$10\,\Omega$ 上 $5$ V，加上 $10$ V 电压源，$U_{OC}=15$ V。
2. 等效内阻：无受控源，两个 $10\,\Omega$ 并联，$R_{eq}=5\,\Omega$。
3. 等效电路：$15$ V 理想电压源串 $5\,\Omega$。

**这一题在讲什么**：**标准戴维南题的完整模板**——一算开路电压、一算内阻、画出等效支路。教师说这是考试里可能以选择题出现的基础题。

## 没编号但讲了的知识点

### 网孔法与节点法的比较

| | 网孔（回路）法 | 节点电压法 |
| :--- | :--- | :--- |
| 实质 | **KVL**（闭合回路电压和） | **KCL**（节点电流和） |
| 左边 | 电阻 × 电流（电压关系） | 电导 × 电压（电流关系） |
| 自项 | 自电阻 = 回路内全部电阻之和，**恒正** | 自电导 = 与节点相连全部电导之和，**恒正** |
| 互项 | 互电阻，**正负看两电流穿过公共电阻的方向** | 互电导，**恒负**或为零 |
| 右端 | 沿绕行方向的**电压升**之和 | **流入**该节点的电流源电流 + 电压源等效电流之和 |
| 适用 | **独立回路少** 的电路 | **独立节点少** 的电路 |
| 受控源 | 当独立源 + 补控制量方程 | 当独立源 + 补控制量方程 |

- 选择依据一句话：**数一数独立回路和独立节点，哪个少用哪个**。
- 极端情形：只有两个节点时，节点法一个方程解决；同一电路网孔法要三个方程。
- 注意两处易混：**两种方法的自项都为正**，但**"自电阻"是回路里的电阻、"自电导"是节点上的电导**，
  不要把两者的定义串在一起。

### 叠加定理

- **适用前提：线性电路**——只由线性元件（电阻、线性受控源、线性 $L$、线性 $C$）和独立源构成。
- **内容**：线性电路中任一支路的电压或电流，等于**各个独立源单独作用**时在该支路产生的响应的**代数和**。
- **"单独作用"的实现**：其余独立源**置零**——**电压源置零 = 短路（一根导线）**，**电流源置零 = 开路**。
- 只对**多于一个独立源**的电路有意义；只有一个源时叠加是空操作。
- **适用量**：电压、电流可以叠加；**功率不能叠加**。
- **分组**：独立源可以分批作用（两个电压源可分两轮，也可以一次两个一起），分组方式不影响结果。

### 为什么功率不能叠加

设支路电流 $I=I'+I''$，则

$$P=I^2R=(I'+I'')^2R=I'^2R+I''^2R+2I'I''R\;\neq\;P'+P''$$

多出来的 $2I'I''R$ 是**交叉项**。所以求功率必须**先叠加出总电压、总电流，再相乘**（$P=UI$ 或 $P=I^2R$），
不能把各分电路的功率相加。教师用这个展开式当"一眼就能看出"的证法。

### 叠加定理里受控源的处理（与第三章的区别）

- 第三章（支路法、网孔法、节点法）：受控源**按独立源一样写进方程**，最后补控制量方程。
- 叠加定理：受控源**不是激励**，**不能置零、不能当短路或开路**，
  **每一份分电路里都必须保留为受控源**，且**控制量按该分电路的实际值写**。
- 这是本次课最强调的一条对照，也是例三的全部难点。

### 叠加定理里出现电桥平衡的情形

- 某一分电路里若电桥平衡（对角电阻乘积相等），则**桥臂中间支路电流为零**，可直接砍掉该支路再算。
- 教师用这个观察省掉一次分流计算；它属于"先看结构再算"的技巧，不是叠加定理本身的内容。

### 戴维南定理

- **内容**：任一**线性有源二端网络**对外可等效成**一个理想电压源串一个电阻**：
  电压源 = 端口**开路电压** $U_{OC}$，电阻 = 端口**等效内阻** $R_{eq}$。
- **用途**：只需要**某一条支路**的电压电流时，不必求全部支路——这正是节点法、网孔法的短板
  （它们必须把所有节点电压或网孔电流都解出来）。
- **求负载电流**：接上负载后 $I=\dfrac{U_{OC}}{R_{eq}+R}$。
- **负载可变时最有用**：把 $R$ 以外的部分一次等效掉，$R$ 怎么变都只是代数式代入。
- 与第二章的关系：第二章用**电源等效 + 串并联逐步化简**也能得到同一个结果；
  戴维南定理是**直接求开路电压与内阻**，殊途同归。
- **对外等效、对内不等效**（与第二章一致）。

### 等效内阻的三种求法

| 方法 | 独立源 | 受控源 | 适用 |
| :--- | :--- | :--- | :--- |
| **电阻化简法** | **置零**（电压源短路、电流源开路） | 不允许含受控源 | 纯电阻网络 |
| **外加电压法** | **置零** | **保留** | 含受控源 |
| **开路短路法** | **保留**（原样工作） | **保留** | 含受控源，且开路电压本来就要算 |

- **开路短路法**：先求 $U_{OC}$，再把端口短路求 $i_{SC}$，$R_{eq}=U_{OC}/i_{SC}$。
  教师提示：戴维南题本来就要算开路电压，所以这个方法**只多算一个短路电流**，实际很划算。
- **外加电压法**：端口设 $U$、流入 $I$，用 KVL/KCL 消中间量，得 $U=RI$。
- 三者共同点：**受控源永远不置零**；差别只在**独立源是否置零**。

### 戴维南定理的解题步骤

1. 判断能不能用：**被求量是否集中在一条支路**（或负载是否可变）。
2. **把待求支路分离出去**，其余部分作为有源二端网络（必要时画出等效电路图）。
3. 求**开路电压** $U_{OC}$：简单电路用 KVL/KCL，复杂电路用节点电压法、网孔法或叠加定理。
4. 求**等效内阻** $R_{eq}$：按上表三选一。
5. 画出"$U_{OC}$ 串 $R_{eq}$"，接回负载求待求量。

- 「置顶」→ **置零**（教师口音，"源置顶"即"源置零"）。
- 「4 7／2 7」→ 分数 $4/7$、$2/7$（分流得到的分支电流）。
