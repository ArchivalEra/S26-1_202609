# 11-23-功率因数与谐振

## 这节课在干什么

本节收尾第五章正弦稳态电路：先接续上一道 $R$-$L$ 串联算参题的结尾（`00:00–01:55`），再讲一道三支路并联正弦电路功率计算例题（`01:56–12:38`）；随后集中讲解**功率因数的提高**——意义、并联电容补偿原则、欠/全/过三种补偿状态及经济性比较、补偿电容公式推导与发电机带日光灯例题（`14:54–52:38`）；最后带过正弦交流电路**最大功率传输**（`52:39–55:59`），并略讲 5.7 **电路的频率响应**（`55:59–60:45`）与 5.8 **正弦稳态电路的谐振**（`60:46–63:24`）。

要掌握六件事：

1. 功率计算两条路：求端口 $\dot{U}$、$\dot{I}$ 按定义算 $P$、$Q$、$S$，或按各支路有功守恒（$\sum I_k^2 R_k$）与无功守恒（$\sum I_k^2 X_k$）相加；
2. 提高功率因数的两大意义：提升电源设备有功输出利用率，减小输电电流 $I = P/(U\cos\varphi)$ 与线路热损耗 $I^2 R$；
3. 补偿原则与方案：保持负载额定电压与有功功率不变，在感性负载两端**并联电容**（$Q_C < 0$ 与感性无功局部互换），工程上因成本与容值精度选**欠补偿**；
4. 并联补偿电容计算式：$C = \dfrac{P}{\omega U^2}(\tan\varphi_1 - \tan\varphi_2)$，电容提供无功 $Q_C = Q_2 - Q_1 = P(\tan\varphi_2 - \tan\varphi_1) < 0$；
5. 交流最大有功功率传输：$R_L, X_L$ 独立可变时满足共轭匹配 $Z_L = Z_S^*$（$P_{\max} = \dfrac{U_S^2}{4 R_S}$），$R_L, X_L$ 成比例仅模可变时满足模匹配 $\lvert Z_L \rvert = \lvert Z_S \rvert$；
6. 网络函数 $H(j\omega) = \text{响应相量}/\text{激励相量}$ 分出幅频与相频特性，四类滤波器概念，以及谐振时总电压与总电流同相（呈纯电阻性，串联谐振满足 $\omega L = \frac{1}{\omega C}$）。

### 1. 前题收尾与三支路并联电路功率例题（00:00–12:38）

- **前题收尾（00:00–01:55，无题号，缺完整题干与电路原图）**：录音自解题末尾切入，场景为已知有功功率与 $\cos\varphi = 0.6$、无功功率 $Q = 40\text{ var}$（单位大写写为 $\text{var}$，勿写成小写）的 $R$-$L$ 串联电路求元件参数。课堂总结三条等效求法：由 $P = I^2 R$、$Q = I^2 X_L$ 及 $L = X_L/\omega$；由 $P = UI\cos\varphi$ 求 $\varphi$ 与 $Q = UI\sin\varphi$；或利用功率三角形与阻抗三角形相似，由斜边 $Z$ 与 $\cos\varphi$ 直接求直角边 $R$、$X_L$。
- **例题（无编号）：三支路并联正弦电路功率计算（01:56–12:38，缺原图及部分支路元件值）**
  - **口述已知**：电源电流相量 $\dot{I}_s = 5\angle 0^\circ\text{ A}$（有效值 $I = 5\text{ A}$，$\varphi_i = 0^\circ$）；电路由三条并联支路组成——支路一为电流源 $i_s$ 与电阻 $R = 2\,\Omega$ 串联，支路二为 $R$-$L$ 串联，支路三为 $R$-$C$ 串联。具体 $i_s(t)$ 表达式与后两支路 $R, L, C$ 数值仅在课件显示、未逐一读出。
  - **要求**：电路吸收的有功功率 $P$、无功功率 $Q$、视在功率 $S$ 及功率因数 $\cos\varphi$。
  - **解法一（端口电压法）**：将各元件转为相量模型，求电流源端口等效阻抗 $Z = 2 + Z_{\text{并}}$（转写在此处数字损坏），得端口电压相量 $\dot{U}_s = Z\dot{I}_s$（电流由上向下、端口电压上正下负，取关联参考方向）。课堂给出端口电压相角 $\varphi_u = 6.34^\circ$，故 $\varphi = \varphi_u - \varphi_i = 6.34^\circ$，$\cos\varphi = \cos 6.34^\circ > 0$；再代入 $P = UI\cos\varphi$、$Q = UI\sin\varphi$、$S = UI$。因 $Q > 0$（电感无功恒大于零、电容无功恒小于零），整体呈感性。
  - **解法二（功率守恒法）**：$2\,\Omega$ 电阻电流即 $I = 5\text{ A}$，其有功为 $I^2 R$；对后两条并联支路作相量分流求出各自支路电流有效值，分别按 $I_k^2 R_k$ 与 $I_k^2 X_k$ 计算各支路有功与无功（感性为正、容性为负），再各自求和得总 $P$、$Q$，最后得 $S = \sqrt{P^2 + Q^2}$、$\cos\varphi = P/S$。

### 2. 功率因数的提高（14:54–45:22）

- **定义与行业标准**：功率因数 $\lambda = \cos\varphi = \dfrac{P}{S}$，与有功 $P = UI\cos\varphi$、无功 $Q = UI\sin\varphi$、视在功率 $S = UI$ 构成功率三角形。教材第 135 页更新数据：一般工业企业要求 $\cos\varphi \ge 0.9$，高压供电企业要求不低于 $0.95$；同一设备满载时功率因数高于空载。
- **两大作用**：
  1. 提高电源设备容量利用率：额定容量 $S$ 固定时，$\cos\varphi$ 越大，输出有功 $P = S\cos\varphi$ 越大。
  2. 减小输电线路损耗：当负载有功 $P$ 与端电压 $U$ 一定时，线路电流 $I = \dfrac{P}{U\cos\varphi}$ 与 $\cos\varphi$ 成反比；提高 $\cos\varphi$ 可减小电流 $I$，从而降低线路电阻发热损耗 $I^2 R$ 并减少导线截面需求。（顺带提及：长电源线或插排线勿绕圈使用，交流电下绕圈形成电感易发热起火。）
- **原则与方法**：保证原用电器额定电压 $U$ 与所需有功 $P$ 不变（不影响正常工作），在感性负载两端**并联电容**（串联会分压改变负载电压）。电容支路无功 $Q_C < 0$ 与电感无功 $Q_L > 0$ 在局部相互充放交换，减少无功在电源与负载间往返，总无功 $Q$ 减小使 $\lvert\varphi\rvert$ 变小、$\cos\varphi$ 增大。
- **三种补偿状态对比**：

| 补偿状态 | 并联电容大小 | 总无功与相角符号 | 端口性质 | 工程取舍与原因 |
| :--- | :--- | :--- | :--- | :--- |
| 欠补偿 | 偏小 | $Q > 0,\ \varphi > 0$ | 感性 | 工程选用：与等 $\lvert\varphi\rvert$ 过补偿 $\cos\varphi$ 相同但电容更小、成本更低 |
| 全补偿 | 恰好抵消 | $Q = 0,\ \varphi = 0$ | 纯电阻性 | 理论最理想，但所需电容常需极高精度且难随负载匹配 |
| 过补偿 | 偏大 | $Q < 0,\ \varphi < 0$ | 容性 | 不选：与等 $\lvert\varphi\rvert$ 欠补偿相比增加电容容量与材料成本 |

- **补偿电容公式推导**：以端电压 $\dot{U}$ 为参考相量，补偿前电流 $\dot{I}_1$ 滞后角 $\varphi_1$，并联电容电流 $\dot{I}_C$（$I_C = \omega C U$，超前 $\dot{U}$ $90^\circ$）后总电流 $\dot{I}_2 = \dot{I}_1 + \dot{I}_C$ 滞后角降为 $\varphi_2$。保持 $P$、$U$ 不变，由垂直分量得：
  $$I_C = I_1\sin\varphi_1 - I_2\sin\varphi_2 = \frac{P}{U}(\tan\varphi_1 - \tan\varphi_2)$$
  结合 $I_C = \omega C U$，得并联电容：
  $$C = \frac{I_C}{\omega U} = \frac{P}{\omega U^2}(\tan\varphi_1 - \tan\varphi_2)$$

### 3. 无编号例题：交流发电机带日光灯补偿计算（45:23–52:38）

- **已知条件**：交流发电机额定容量 $S_N = 10\text{ kVA}$，额定电压 $U = 220\text{ V}$，电源频率 $f = 50\text{ Hz}$（$\omega = 2\pi f = 100\pi\text{ rad/s}$）；所接日光灯负载总有功功率 $P = 8000\text{ W}$，原功率因数 $\cos\varphi_1 = 0.6$。
- **第（1）问：负载电流是否超过发电机额定值？**
  - 发电机额定电流：$I_N = \dfrac{S_N}{U} = \dfrac{10000}{220} \approx 45.5\text{ A}$
  - 负载电流：$I_1 = \dfrac{P}{U\cos\varphi_1} = \dfrac{8000}{220 \times 0.6} \approx 60.6\text{ A}$
  - 结论：$60.6\text{ A} > 45.5\text{ A}$，超过额定值，不能正常工作。
- **第（2）问：功率因数提高到 $\cos\varphi_2 = 0.9$ 应并联多大电容？**
  - 由 $\cos\varphi_1 = 0.6$、$\cos\varphi_2 = 0.9$ 求 $\varphi_1, \varphi_2$ 及正切值，代入公式：
    $$C = \frac{P}{\omega U^2}(\tan\varphi_1 - \tan\varphi_2) = \frac{8000}{100\pi \times 220^2}(\tan\varphi_1 - \tan\varphi_2) \approx 447\,\mu\text{F}$$
- **第（3）问：提高到 $0.9$ 后的线路负载总电流是多少？**
  - $I_2 = \dfrac{P}{U\cos\varphi_2} = \dfrac{8000}{220 \times 0.9} \approx 40.4\text{ A} < 45.5\text{ A}$，低于额定电流，发电机尚有余力带其他负载。
- **第（4）问：电容器提供的无功功率是多少？**
  - 补偿前 $Q_1 = P\tan\varphi_1$（一万多 var），补偿后 $Q_2 = P\tan\varphi_2$（三千多 var），电容发出无功（吸收负无功）：
    $$Q_C = Q_2 - Q_1 \approx -6.8\text{ kvar}$$

### 4. 最大功率传输（52:39–55:59）

- 将含源单口网络经戴维南等效为电压源 $\dot{U}_S$ 与内阻抗 $Z_S = R_S + jX_S$ 串联，外接可变负载阻抗 $Z_L = R_L + jX_L$；最大功率指**有功功率** $P = I^2 R_L$ 最大，分两种情形：
  1. **共轭匹配**（$R_L$ 与 $X_L$ 可独立变化）：当 $Z_L = Z_S^*$，即 $R_L = R_S$ 且 $X_L = -X_S$（电抗互为相反数）时有功最大，
     $$P_{\max} = \frac{U_S^2}{4 R_S}$$
  2. **模匹配**（$R_L$ 与 $X_L$ 保持固定比例、仅调整阻抗模长；课堂口述一度混说为「阻抗角 $\varphi$ 可变、模不变」后又指明为 $R, X$ 比例定值）：当 $\lvert Z_L \rvert = \lvert Z_S \rvert$ 时取得最大有功功率。

### 5. 5.7 电路的频率响应（55:59–60:45，仅概念）

- **频率特性与网络函数**：电路响应随正弦激励频率 $\omega$ 变化的规律。网络函数定义为
  $$H(j\omega) = \frac{\text{响应相量}}{\text{激励相量}} = \lvert H(j\omega) \rvert \angle \theta(\omega)$$
  只取决于电路结构与参数，与激励大小无关。模 $\lvert H(j\omega) \rvert$ 随 $\omega$ 的变化为**幅频特性**，辐角 $\theta(\omega)$ 随 $\omega$ 的变化为**相频特性**，合称电路的频率特性。
- **滤波器分类**：允许所需频段（**通带**）通过、抑制不需要频段（**阻带**）的电路。按幅频特性分为**低通**、**高通**、**带通**（保留中间某频段）、**带阻**（抑制中间某频段）四类。

### 6. 5.8 正弦稳态电路的谐振（60:46–63:24，仅概念与串联条件）

- **谐振概念**：在同时含有电感与电容的交流电路中，若端口总电压与总电流**同相**，电路处于谐振状态。此时端口呈纯电阻性，电源与电路间不再发生无功交换，无功仅在 $L$ 与 $C$ 内部互换（等效于全补偿）。分为**串联谐振**与**并联谐振**；工程上既用于无线电与电子测量选频，也需在一般电力网络中防止非预期谐振危害。
- **串联谐振条件**：电抗虚部完全抵消，即
  $$\omega L = \frac{1}{\omega C}$$
  并联谐振未展开推导即下课。
