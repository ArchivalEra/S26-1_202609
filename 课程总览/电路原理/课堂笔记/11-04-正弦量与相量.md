## 题号条目

### 例 5.1.1（求 $U_1$ 与 $U_2$、$U_1$ 与 $I_3$ 的相位差）

**解析**：相位差的求法有固定的五步，先按顺序走完，再回头读结论。

1. **先确认同频率**。频率不同的两个正弦量之间没有相位差可比，这是前提条件，不是结论。
2. **统一函数形式**。本课统一用正弦。电流若给的是余弦，按
   $$\cos(\omega t+\theta)=\sin(\omega t+\theta+90^\circ)$$
   化成正弦后再比；化成正弦后还要把原来的初相位一并带上。
3. **统一幅值符号**。若一条曲线的幅值为负，把它画成同幅值的正幅值，相当于沿横轴移 $180^\circ$：
   加 $180^\circ$ 或减 $180^\circ$ 都对；若选了加 $180^\circ$，末尾按下一步折回 $\pm 180^\circ$。
4. **相减取差**。两个初相位相减即相位差。
5. **折回 $\pm 180^\circ$**。差值大于 $180^\circ$ 就减 $360^\circ$，小于 $-180^\circ$ 就加 $360^\circ$，
   使结果落在一个周期的一半以内，再读「谁超前谁、差多少」。

⚠ 本题在转写里只有老师的这段**方法提示**（把 $U_2$ 的负 $50^\circ$ 画成正的 $50^\circ$ 再算、电流 $I$ 化成 $\sin$ 形式再算），
**题面与数值答案都没有出现**；本页因此只写方法，不给结论数值。

**这一题在讲什么**：相位差不是「算出一个角度」就完事，前面有三个改写动作挡在中间——
函数形式不同、幅值符号不同、角度没折回 $\pm 180^\circ$。老师把这三步先讲成流程，例 5.1.1 只是这个流程的第一个套用对象；
以后遇到任何求相位差的题，都按这五步走，不要跳步。

### 例 5.2.1 与 5.2.2（复数的形式转换与复数运算）

**解析**：老师把这两个例题并称为「这两个类型」，课堂没有逐题演算，只讲了每类操作的机械做法。

1. **形式转换这一类**（老师点名 5.2.1 是「代数形式 ↔ 极坐标形式」的转换）：
   - 代数形式 → 极坐标形式：先取模 $A=\sqrt{a^2+b^2}$，再定角 $\varphi=\arctan(b/a)$，**角必须按所在象限定**；
   - 极坐标形式 → 代数形式：$a=A\cos\varphi$、$b=A\sin\varphi$，直接代三角函数。
2. **复数运算这一类**：
   - **加减用代数形式**：实部与实部相加，虚部与虚部相加；
   - **乘除用极坐标形式**：乘法是模相乘、角相加；除法是模相除、角相减；
   - **混合运算按「先乘除、后加减」**：先把代数形式化成极坐标做乘除，再把结果化回代数形式做加减。

⚠ 两个例题的**题面数据与课堂算式都没有出现在转写里**；老师只点了「这两种类型」并让学生自己看课本数据。本页只写两类操作的规则。

**这一题在讲什么**：复数运算之所以要先学「形式转换」，是因为**加减和乘除各自认一种形式**——
加减硬要用极坐标，就得退回图形法（平行四边形定则）才能求和；乘除硬要用代数形式，公式会复杂到算不动。
老师把「加减用代数、乘除用极坐标」定成规矩，后面所有复数计算题都按这条规矩走。

### 5.1 为什么要引入正弦量

- **线性电路里的电源，提供的电压或电流是随时间变化的函数**；直流电路里这些量大小、方向都不随时间变，交流电路里则周期性变化。
- **选正弦（或余弦）的理由**：同频率的正弦量做加减、微分、积分，结果仍是**同频率**的正弦量——
  频率在运算中不变，电路的频率成分才不会在运算中跑掉。
- 本书统一用**正弦函数**（有的书用余弦，道理相同：二者在 $2\pi$ 范围内都是周期为 $2\pi$ 的函数）。

### 5.1 正弦量的三要素

一个正弦量由三个量**唯一确定**，三者定下则函数定下：

1. **幅值 $I_m$**：正弦函数的最大值，最小值是 $-I_m$。它决定正弦量**变化的幅度**。
   记号规则是**大写字母加小写 $m$**（$I_m$、$U_m$、电动势幅值），国际通用。
   从 $-I_m$ 到 $I_m$ 的整个变化范围称为**峰值**，即 $2I_m$。
2. **角频率 $\omega$**：决定正弦量**变化的快慢**，$\omega$ 越大变化越快。
   $$\omega=\frac{2\pi}{T}=2\pi f,\qquad f=\frac{1}{T}$$
   $f$ 的单位是**赫兹**，$\omega$ 的单位是**弧度每秒**。
   我国电力系统的**工频为 $50\ \mathrm{Hz}$**，对应 $\omega=2\pi\times50=314\ \mathrm{rad/s}$。
3. **初相位 $\varphi$**：$t=0$ 时刻的相角，决定正弦量的**起始位置**（在纵轴正半轴还是负半轴）。
   初相位与频率合称**相位**，相位反映正弦函数的变化进程。初相位一般取在 $0\sim\pm180^\circ$ 之间。

### 5.1 有效值

- **为什么要引入**：交流量逐时变化，研究某一个时刻的电流、电压很少见，一般研究的是**一段时间内**的变化；
  而这段时间内的最大值、最小值代表不了整体效果，所以要用一个量来代表**这段时间的平均效果**——这就是有效值。
- **定义**：一个电阻通以交流电与通以直流电，若在**同一段时间内消耗的能量相同**，
  则这个直流值就是这个交流电的**有效值**。它反映的是交流在一个周期内的平均效果。
- **与幅值的关系**（把交流代入正弦函数、按能量相等推导）：
  $$I=\frac{I_m}{\sqrt{2}}$$
  电压同理：$U=U_m/\sqrt{2}$。
- **正弦量的两种写法**（一一对应）：
  $$i(t)=\sqrt{2}\,I\sin(\omega t+\varphi),\qquad u(t)=\sqrt{2}\,U\sin(\omega t+\varphi)$$
- **三个记号必须分清**：
  - 小写 $i$（或 $u$）：**瞬时值**，随时间变化的那一条曲线；
  - 大写 $I_m$（或 $U_m$）：**幅值**，正弦量的最大值；
  - 大写 $I$（或 $U$）：**有效值**。
- **工程上用哪个**：说的电压电流「多大」、**铭牌上的标注**、**电压表与电流表的读数**，**全都是有效值**；
  只有**绝缘水平上的耐压值**这类场合才用幅值。所以有效值在后面各节里用得极多，幅值用得少。

### 5.1 初相位与相位差

- **相位差**：两个**同频率**正弦量的**初相位之差**。它是一个**常数**，**与计时起点无关**；
  不同频率之间没有相位差可比。
- **相位差用来干什么**：判断两个量的**超前 / 滞后 / 正交 / 同相 / 反相**关系。
  - 电压超前电流 $\varphi$：电压的起始位置在电流之前；
  - 电流超前电压 $\varphi$：反过来；
  - **正交**：一个达到最大值时另一个恰好为零；
  - **同相**：两者同时到最大、同时到最小；**反相**：两者同时到最大、同时到最小但方向相反。
- **求相位差的五步**（与例 5.1.1 的解析同源）：

| 步 | 做什么 | 依据 |
| :--- | :--- | :--- |
| 1 | 确认两边**同频率** | 不同频率无相位差 |
| 2 | 统一**函数形式**（余弦化正弦加 $90^\circ$） | $\cos(\omega t+\theta)=\sin(\omega t+\theta+90^\circ)$ |
| 3 | 统一**幅值符号**（负幅值移 $180^\circ$） | 两边同向才可比 |
| 4 | 初相位相减，结果折回 $\pm 180^\circ$ | 大于 $180^\circ$ 减 $360^\circ$，小于 $-180^\circ$ 加 $360^\circ$ |
| 5 | 读**超前 / 滞后 / 正交 / 同相** | 差值为正即前者超前 |

- **两个容易漏的改写**：
  - **函数形式不同**：$I_1=A\sin(\omega t-30^\circ)$ 与 $I_2=B\cos(\omega t+\theta)$，先把 $I_2$ 化成正弦得
    $I_2=B\sin(\omega t+\theta+90^\circ)$，再与 $I_1$ 比。
    转写里这一例的口播数字含混（「用这个 40 减去一个负 30 就是 70」），本页只保方法与结论——**$I_2$ 超前 $I_1$**。
  - **幅值符号不同**：把负幅值换算成正幅值，等价于移相 $180^\circ$；加或减 $180^\circ$ 都成立，
    若选了加 $180^\circ$，末尾按折回 $\pm 180^\circ$ 那一步处理。

### 5.2 为什么要引入相量

- **正弦量直接运算很麻烦**：两个支路电流相加、电压除以电流求电阻，都是正弦函数之间的加减乘除，
  而**正弦函数相除没有好办法**。
- 正弦量求和只有两条路：**用公式做等效变换**，或者**用图形方法**；两条路都不省事。
- **相量就是为省这一步而设的**：把同频率正弦量换成相量后，加减乘除按复数规则做。

### 5.2 复数的三种形式

- **代数形式（直角坐标形式）**：$a+jb$，实部在横坐标、虚部在纵坐标。
- **指数形式**。
- **极坐标形式**：$A\angle\varphi$，其中 $A$ 是**模**，$\varphi$ 是**相角**。
- 电路运算里**最常用的是代数形式与极坐标形式**：加减用代数形式，乘除用极坐标形式。

### 5.2 形式互转：定角必须按象限（课堂演算）

课堂演算的例子是四个直角坐标形式的复数，实部与虚部分别取 $\pm3$、$\pm4$ 的四种符号组合，因此**模全都相同**：

1. **先算模**（只跟大小有关）：
   $$A=\sqrt{a^2+b^2}=\sqrt{3^2+4^2}=5$$
2. **再定象限**（只跟符号有关）：
   - $3+4j$：实部 $>0$、虚部 $>0$ → **第一象限**；
   - $3-4j$：实部 $>0$、虚部 $<0$ → **第四象限**；
   - $-3+4j$：实部 $<0$、虚部 $>0$ → **第二象限**；
   - $-3-4j$：实部 $<0$、虚部 $<0$ → **第三象限**。
3. **再定角**：先算出锐角 $\arctan(4/3)=53.1^\circ$，再按象限配符号、加减 $180^\circ$：
   - 第一象限：$\varphi=53.1^\circ$；
   - 第四象限：$\varphi=-53.1^\circ$；
   - 第二象限：$\varphi=180^\circ-53.1^\circ=126.9^\circ$；
   - 第三象限：$\varphi=53.1^\circ-180^\circ=-126.9^\circ$。
4. **写成极坐标形式**：$5\angle 53.1^\circ$、$5\angle(-53.1^\circ)$、$5\angle 126.9^\circ$、$5\angle(-126.9^\circ)$。

**反向转换**（极坐标 → 代数）用 $a=A\cos\varphi$、$b=A\sin\varphi$。课堂演算用的数是 $5\angle(-32.15^\circ)$，
口播给出实部为正、虚部算得 $-2.66$。

⚠ 反向转换演算例的口播数字（$32.15^\circ$、$-2.66$）在转写里含混，本页按口播登记。

**这一段在讲什么**：**模由实部、虚部的大小决定，角由它们的符号决定**——这是两件分开的事。
先算锐角、再按象限定角，就不会把 $126.9^\circ$ 误写成 $53.1^\circ$、也不会把第三象限的角写成正的。
四个数模都是 5、角各不相同，正好把四种象限一次走完。

### 5.2 复数运算的规矩

| 运算 | 用哪种形式 | 做法 |
| :--- | :--- | :--- |
| 加、减 | **代数形式** | 实部与实部相加，虚部与虚部相加 |
| 乘 | **极坐标形式** | 模相乘，角相加 |
| 除 | **极坐标形式** | 模相除，角相减 |

- **为什么加减要用代数形式**：两个极坐标形式的复数要相加，只能先用图形法（**平行四边形定则**）求和；
  要拿到数值，还得再化成代数形式。既然最后总要化，不如一开始就化。
- **为什么乘除要用极坐标形式**：代数形式做乘除公式很复杂；只有**实部为零、只有虚部**时还算简单。
  乘比除好记一些，除更难。
- **混合运算**：与数学运算一样**先乘除、后加减**——先把代数形式化成极坐标做乘除，再把结果化回代数形式做加减。
- **计算器**：这类运算基本都要用计算器（$30^\circ$、$45^\circ$、$60^\circ$ 好口算，其余不便）；
  **考试要带黑色科学计算器，不能用手机**。

### 5.2 相量：与正弦量一一对应，但不相等

- **前提条件是频率相同**。同频率时三要素里频率已经固定，只剩**幅值与初相位**两项要处理；
  幅值对应复数的**模**，初相位对应复数的**相角**，幅值又是有效值的 $\sqrt{2}$ 倍——
  于是「用复数代替正弦量」这一步就成立。
- **推导路径**：把复数写成指数形式后，它的**虚部就是正弦函数形式**，实部就是对应的余弦函数形式，
  所以正弦量与复数之间是**一一对应**的。
- **在电路里，复数改称「相量」**（老师口播里「向量」与「相量」混用），记号是**大写字母上加一点**：
  $\dot I$、$\dot U$；加点的用意是把它与普通复数区分开。
- **相量一般默认指「有效值相量」**（设备上读出来的都是有效值）；幅值相量也可写，数值是有效值相量的 $\sqrt{2}$ 倍。
- **相量与正弦量不是相等关系**，理由有两条：
  - 正弦量是**随时间变化的函数**，本身携带**频率**信息；相量只有**有效值与初相位**两项，看不出频率与时间关系；
  - 正弦量有三个参数，相量只有两个参数。

### 5.2 相量的表示与互求（课堂演算）

- **由幅值求有效值相量**：把幅值除以 $\sqrt{2}$，再把初相位接上。
  课堂例：幅值 $141.4$ A → 有效值 $141.4/\sqrt{2}=100$ A。

  ⚠ 该例的**初相位数值没有在转写里出现**，本页只保 $141.4 \to 100$ 这一步。
- **由有效值相量写回瞬时表达式**：幅值取 $\sqrt{2}$ 倍，角频率由频率换算。
  课堂例：有效值相量 $50\angle 15^\circ$ A、频率 $50\ \mathrm{Hz}$ →
  $$i(t)=50\sqrt{2}\sin(314t+15^\circ)\ \mathrm{A}$$
- **三个 220 V 的相量**：有效值都是 $220$ V，初相位分别是 $0^\circ$、$-120^\circ$、$120^\circ$，即
  $$\dot U_a=220\angle 0^\circ\ \mathrm{V},\qquad
  \dot U_b=220\angle(-120^\circ)\ \mathrm{V},\qquad
  \dot U_c=220\angle 120^\circ\ \mathrm{V}$$
  幅值相量则为 $220\sqrt{2}$ 倍。
