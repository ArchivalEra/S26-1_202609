# 10-14-电源等效变换

## 这节课在干什么

本次课把**第二章「电路的等效变换」讲完**。主体是 **2.3 电源的等效变换**——实际电压源与实际电流源的模型及互换、
理想电源的串并联、两条「吞并」规则；接着用 **2.4 的几道例题**把电阻等效与电源等效合起来练；
最后讲 **2.5 无源二端网络的等效电阻**（纯电阻用串并联，含受控源用外加电压法，并出现负电阻）。

要会三件事：

1. 把**实际电压源与实际电流源**按 $I_S=U_S/R$ 互相替换，并判对方向（电流源流出的方向对应电压源正极）；
2. 把**理想电源的串并联**按方向记账化简，并会用两条「吞并」规则；
3. 对**含受控源的一端口**用**外加电压法**写出 $U$ 与 $I$ 的关系，得等效电阻（可能为负）。

## 题号条目

### 课本例题 2.3.1（实际电压源 → 实际电流源 → 理想电流源并联）

**解析**：

1. A 图是 $5$ V 理想电压源串 $2\,\Omega$ 电阻，即一个**实际电压源**。
2. 按互换条件（两侧电阻相等、$I_S=U_S/R$）化成**实际电流源**：$I_S=5/2=2.5$ A，电阻仍是 $2\,\Omega$ 并联，得 B 图。
3. B 图里 $2.5$ A 的理想电流源再与 $1$ A 的理想电流源**并联**，按「理想电流源并联相加」（同向取正）合并，
   得 $3.5$ A，即 C 图。

**这一题在讲什么**：一条固定流程——**先把电压源换成电流源，统一成「电流源并联电阻」的形式，再按并联规则合并**。
同方向才相加、方向不同要取负，是这一章反复出现的记账动作。

### 课本例题 2.3.2（含理想电压源二端网络的功率）

**解析**：

1. 端口处并着一个 $5$ V 理想电压源，由「吞并规则」，该支路对外就是 $5$ V，**端口电压 $U=5$ V**。
2. 与电压源并联的 $2\,\Omega$ 电阻上电压也是 $5$ V，其电流为 $5/2=2.5$ A。
3. 该支路与 $1$ A 的电流源在节点处分流：$I_1=2.5-1=1.5$ A。
4. $I_1$ 与 $5$ V 方向**非关联**，所以发出功率 $P=UI=1.5\times5=7.5$ W。

**这一题在讲什么**：把「吞并规则」直接当结论用——**端口电压被理想电压源定死，其余支路电流用 KCL 分出来**，
最后才判关联性算功率。

### 2.4 例一（理想电流源并电阻的一端口）

**解析**：端口处是理想电流源并一个电阻。**并联支路的电流由理想电流源定死**，端口电压由外电路决定，
所以这一部分对外可等效成**一个理想电流源**。

**这一题在讲什么**：判断一个一端口等效成什么，看**端口处哪个量被内部元件定死**——电压被定死就等效成电压源，
电流被定死就等效成电流源。

### 2.4 例二（理想电流源与理想电压源串联的化简）

**解析**：

1. 一个理想电流源与一个理想电压源（及电阻）**串联**，串联支路的**电流由电流源定死**，故这一部分等效成理想电流源。
2. 与后面的理想电流源**并联**合并。转写里只给了符号 $I_{S1}$、$I_{S2}$，教师**默认 $I_{S2}>I_{S1}$、取 $I_{S2}$ 的方向**，
   得 $I=I_{S2}-I_{S1}$。

**这一题在讲什么**：串联时谁定电流、并联时按方向求和——**合并前先规定正方向，再逐项定正负**。

### 2.4 例三（两个实际电压源的串联化简）

**解析**：

1. 上面一部分化成**实际电压源**：$15$ V 串 $3\,\Omega$（上正下负）。
2. 下面一部分也是实际电压源：$8$ V 串 $4\,\Omega$（下正上负）。
3. 两个电压源**串联**，方向相反：$15-8=7$ V；电阻串联：$3+4=7\,\Omega$，再加图中第三个电阻共 $14\,\Omega$。
4. 支路电流 $I=7/14=0.5$ A。

**这一题在讲什么**：电源等效的收益——**先把每块化成同一种「电压源串电阻」，再像纯电阻串联一样合并**，
省去对原始复杂图反复列方程。

### 2.4 例四（三个电源混合的电路化简）

**解析**：

1. 把三个电源**分别化成统一形式**：$6$ V 串 $3\,\Omega$ 化成 $2$ A 并 $3\,\Omega$；另一处是 $2$ A 并 $6\,\Omega$；
   上面那部分实际电流源再化成实际电压源（$2$ V 串电阻）。
2. 红色与绿色两路电流**并联相加**得 $4$ A，并联电阻 $2\,\Omega$。
3. 再化成实际电压源，与剩下的电源**串联**，取**逆时针**方向相减（$8-6$），配合总电阻得支路电流（教师算得 $1$ A）。

**这一题在讲什么**：混合电路化简的**顺序纪律**——先把所有电源统一成一种形式，再逐级串并联，
不能随手挑两个「看起来并联」的支路先合。

### 2.4 例五（含实际电流源的综合化简求电流）

**解析**：

1. 把一个实际电压源化成**实际电流源**（$2$ A 并 $3\,\Omega$），与相邻支路统一成电流源并联形式。
2. 按**从右往左**的顺序逐级合并：两路合并后为 $4$ A 并 $2\,\Omega$。
3. 再化成**实际电压源**，与相邻支路串联（$8$ V 串 $4\,\Omega$）。
4. 最后两路并联，用**分流公式**求支路电流；也可以再等效成 $6$ V 串 $3\,\Omega$，得 $I=6/3=2$ A。

**这一题在讲什么**：教师借它强调**等效方向要统一**——「我们不会随手挑两个看起来并联的先合，
一般从一个方向往另一个方向走」；化简方向一致，才不会把等效关系搞乱。

### 2.5 例一（含受控源一端口的外加电压法，得 $16\,\Omega$）

**解析**：

1. 在端口**外加电压 $U$**（设从端口流入电流 $I$）。
2. 两条并联支路上的电压都是 $U$（记作 $U_0$），支路电流分别为 $U_0/12$、$U_0/6$。
3. 对节点列 **KCL**，把 $U_0$ 与 $I$ 的关系解出：$U_0=16I$。
4. 等效电阻 $R=U/I=16\,\Omega$。

**这一题在讲什么**：**外加电压法是含受控源一端口求等效电阻的标准动作**——把端口电压设成 $U$，
用 KVL/KCL 消掉中间量，得到 $U=RI$ 的形式，$R$ 就是等效电阻。受控源不能用串并联直接合，所以必须走这一步。

### 2.5 例二（含受控源一端口，得负电阻 $-1\,\Omega$）

**解析**：

1. 端口外加电压 $U$、流入电流 $I$，把两支路电流设为 $I_1$、$I_2=I-I_1$。
2. 对受控源所在回路列 **KVL**（顺时针）：$2I_2+5I_1-2I_1=0$，整理得 $2I_2=-3I_1$，即 $I_2=-1.5I_1$。
3. 由节点 **KCL**：$I=I_1+I_2=I_1-1.5I_1=-0.5I_1$，即 $I_1=-2I$。
4. 再对含端口的大回路列 **KVL**，把 $U$ 用 $I_1$ 表示，代入 $I_1=-2I$，得 $U=-1\cdot I$。
5. 等效电阻 $R=U/I=-1\,\Omega$。

**这一题在讲什么**：受控源的一端口的**等效电阻可以是负的**——受控源能对外提供功率（有源性），
所以消掉中间量后 $U$ 与 $I$ 的比值可能为负。纯电阻网络的等效电阻恒为正，出现负值就说明里面有受控源在起作用。

## 没编号但讲了的知识点

### 2.3 的两类电源模型

- 电源等效分两大类：**实际电源的等效**与**理想电源的等效**。
- **实际电压源 = 理想电压源串联一个内阻**。内阻通常很小，**内阻趋近 0 时就等于理想电压源**。
  端口电压 $U=U_S-IR$（对回路列 KVL 得 $U_S-IR-U=0$）。
- **实际电流源 = 理想电流源并联一个内阻**。内阻通常很大，**内阻趋近无穷大（趋于开路）时就等于理想电流源**，
  此时支路电流 $I=I_S$。
- 课本 41–42 页有这两者的完整推导。教师说这一节**最难理解的就是实际电压源与实际电流源的互换**，
  理想电源部分相对简单；「实在理解不了，就先记住会用」。

### 实际电压源与实际电流源的互换

- **互换条件**：两侧电阻相等（$R_1=R_2$）；电流源的电流 = 电压源的电压 ÷ 电阻，即 $I_S=U_S/R$（反向 $U_S=I_S R$）。
- **方向**：电流源**流出**的方向对应电压源的**正极**。
- **只对外电路等效、对内不等效**：对外看，两个端口处的电压电流关系相同；对内看，
  电压源的内阻上**有电流、耗功率**，电流源的内阻在同样开路情况下**没有电流、不耗功率**，两者不同。
- **理想电压源与理想电流源之间不能互换**：理想电压源两端电压由自身决定、电流由外电路决定，理想电流源正好相反，
  端口伏安关系（VCR）不同，画不了等号。

### 理想电源的串并联

- **理想电压源只能串联**：总电压 = 各部分电压之和（KVL）。方向一致直接相加；方向不一致先**规定一个正方向**，
  同向取正、反向取负。**不允许并联**（违反 KVL），只有电压完全相同的电压源才可并联，且并了也没有意义。
- **理想电流源常见的是并联**：总电流 = 各支路电流之和，同样**注意方向**（同向取正、反向取负），
  可等效成一个理想电流源。**不允许串联**（串联电路电流处处相等），只有电流值相同的电流源才能串联。

### 两条「吞并」规则

- **理想电压源与任何元件 $X$ 并联，对外就等于该理想电压源**。$X$ 可以是电阻、电感、电容，甚至电流源。
  理由：并联支路的端口电压被电压源定死（等于 $U_S$），支路电流由外电路决定，与并的那个元件无关——**对外等效、对内不等效**。
- **理想电流源与任何元件 $X$ 串联，对外就等于该理想电流源**。理由：串联支路的电流被电流源定死（等于 $I_S$），
  两端电压由外电路决定。
- 教师把 2.3 归为**三点**：① 实际电压源与实际电流源的互换；② 理想电源的串并联；③ 上面这两条「吞并」规则。

### 2.5 无源二端网络的等效电阻

- **无源二端网络**：内部只有电阻（不含独立源）的一端口。端口电压 ÷ 端口电流 $R=U/I$，就可用一个电阻代替整个网络。
- **纯电阻网络**：直接用**串并联**求等效电阻。
- **含受控源的网络**：串并联合不动，改用**外加电压法**——在端口假设电压 $U$、电流 $I$，用 KVL/KCL 把 $U$ 与 $I$
  的关系写出来，$R=U/I$。
- **等效电阻可以为负**：含受控源的一端口可能得到**负电阻**（本例 $-1\,\Omega$），这是受控源**有源性**的体现；
  纯电阻网络的等效电阻恒为正。

### 章节地图与 2.2 回顾

- 教师给的方法地图：第二章**等效的分析方法** → 第三章**节点电压法**（考试多）与**网孔电流法**（考得少）→
  第四章**戴维南定理** → 第五章。分析方法说到底就是**基尔霍夫定律 + 等效网络 + 节点电压法 + 戴维南定理**这几样，
  第二章的概念是后面各章的地基。
- 2.2 电阻等效回顾：串联等效电阻为各电阻之和；并联用倒数相加（电导之和）。
  $\mathrm{Y}$–$\Delta$ 变换记一个关系即可——**各电阻相同时，$\Delta$ 边电阻是 $\mathrm{Y}$ 臂电阻的 3 倍**。
